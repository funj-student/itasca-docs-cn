模块术语词库

本词库按通用基础、FLAC3D、3DEC、PFC 与 FISH 五个模块拆分，收录约 250 条高频术语。与 核心术语对照 冲突时，以核心术语表为准；命令、变量与函数名保留英文原文。

通用基础术语

English中文名称说明
acceleration加速度质点或网格点速度的时间变化率。
advanced model高级本构模型需显式启用或单独授权的本构模型集合。
boundary condition边界条件模型边界上的位移、速度、力、应力、渗流或温度约束。
bulk modulus体积模量静水压力与体积应变之比，常记为 K。
convergence收敛计算量趋于稳定、不平衡力或能量残差降至容差内的状态。
cycle计算循环 / 时步一次显式求解步；FISH 与命令中 cycle/step 保持英文。
damping阻尼耗散振动能量、加快静力收敛或模拟动力耗散的机制。
degrees of freedom自由度节点或结构节点可独立运动的位移与转动分量。
displacement位移点或对象位置的变化量。
dynamic analysis动力分析考虑惯性效应与时间历程的计算模式。
elastic弹性卸载后变形可恢复的材料响应。
equilibrium平衡内力与外力、惯性力达到可忽略不平衡的状态。
factor of safety安全系数强度折减或荷载倍增得到的稳定性指标。
failure破坏 / 失效材料或结构达到强度极限后的不可逆响应。
finite difference有限差分FLAC/FLAC3D 的基本数值离散方法。
finite element有限元另一类常用数值离散方法；与有限差分区分。
force力作用于节点、颗粒或结构单元的外力或内力。
frequency频率周期运动的每秒循环数。
grid网格有限差分计算区域的离散单元集合。
hardening硬化屈服后强度随塑性应变增长的现象。
history历史 / 历史变量采样并存储的时程变量；曲线称“时程曲线”。
initial condition初始条件加载前模型中应力、速度、孔压、温度等状态。
isotropic各向同性材料性质与方向无关。
large strain大应变几何非线性显著、需更新网格/单元构形的模式。
load荷载施加于模型的外力、压力或位移约束。
local coordinate system局部坐标系结构单元或接触面采用的内部坐标方向。
material property材料性质密度、模量、强度、渗透率等参数。
mechanical analysis力学分析求解应力、应变、位移与稳定的计算模式。
mesh网格与 grid 类似，偏重几何剖分结果。
moment力矩力对点或轴的转动效应。
nonlinear非线性响应与荷载不成比例，需迭代或显式时步求解。
numerical stability数值稳定计算不因时步、刚度或阻尼设置而发散的状态。
oscillation振荡变量在平衡值附近往复波动。
overdamped过阻尼阻尼过大导致系统缓慢趋于平衡。
plastic塑性卸载后仍保留的不可逆变形。
pore pressure孔隙水压力孔隙流体承担的压力。
quiet boundary安静边界动力分析中的吸收边界，亦称无声边界；勿译作静态边界。
range范围由坐标、单元号、分组等条件限定的空间区域。
residual残差迭代或时步求解中未满足的方程量。
shear modulus剪切模量剪应力与剪应变之比，常记为 G。
small strain小应变几何变化可忽略的线性或弱非线性模式。
softening软化屈服后强度随塑性应变下降的现象。
solution解 / 求解结果计算得到的场变量或状态。
static solution稳态解 / 静力解动能趋于零、体系达到平衡的解。
stiffness刚度单位位移或应变产生的力或应力。
strain应变变形的度量，含正应变与剪应变。
stress应力单位面积上的内力，含正应力与剪应力。
time step时步显式求解单个计算循环代表的时间增量。
tolerance容差判断收敛或数值比较允许的误差范围。
unconstrained无约束未施加位移或速度边界条件的状态。
velocity速度位移对时间的变化率；静力下可理解为每步位移。
viscous damping黏性阻尼与速度成正比的阻尼形式。
yield屈服材料开始产生显著塑性变形的应力状态。
yield criterion屈服准则判断材料是否屈服的应力条件。
cohesion黏聚力抗剪强度中的截距项，亦称内聚力。
dilation剪胀剪切过程中体积增大的现象。
effective stress有效应力总应力扣除孔隙水压力后的应力。
explicit method显式方法按时间步逐步推进的求解方法。
implicit method隐式方法通过联立方程整体求解的方法。
Poisson ratio泊松比横向应变与轴向应变之比的负值。
residual strength残余强度峰值后材料可维持的稳定强度。
steady state稳态变量不随时间变化的状态。
transient瞬态变量随时间变化的过程。
unloading卸载荷载或约束减小的过程。
active pane活动窗格在任意时刻，程序中总会有一个获得焦点的窗格（pane），称为活动窗格。
alias别名为绘图项或绘图项中的某个元素指定的替代名称。
attribute显示属性显示属性（有时也称为“开关”）是一种控件，通过控制绘图项外观或显示方式的某个方面（例如透明度、颜色和大小）来影响绘图项的显示。
bitmap位图位图（更准确且更广义的名称为栅格图像）是由像素组成的矩形图像。
bundle file打包文件打包文件由打包（Bundle）工具（工具 ‣ 打包）生成。
command prompt命令提示符命令提示符用于在 PFC 中逐行输入命令，位于控制台窗格底部。
console控制台对i 控制台（Console）窗格的通称。
Console (pane)控制台窗格控制台窗格包括命令提示符及其上方的显示区。
Console pane控制台窗格该窗格分为两部分。
Control Panel控制面板控制面板是一个窗格，包含操作视图的工具。
control set控件组控制面板提供三个控件组。
data file数据文件包含 PFC 命令的文本文件。
dock停靠“停靠”指将窗格或工具栏放置在界面内的固定位置。
Editor (pane)编辑器窗格编辑器窗格提供创建、编辑和校验数据文件的功能。
element单元参见网格单元（zone）。
geometry file几何文件几何文件表示空间中节点、边或多边形的集合，有时也称为 CAD 数据。
group分组在 FLAC3D 模型中，分组是指可赋予一个或多个对象的名称。
history file历史文件历史文件是用户通过 导出历史（history export） 命令要求生成的格式化 ASCII 文件。
id number标识编号FLAC3D 模型中的各个元素通过标识（ID）编号识别。
item项目项“项目项”泛指 PFC 项目中使用或创建的任何单个文件，可包括数据文件、FISH 文件、SAV 文件、绘图文件、网格文件等。
layout布局“布局”指 PFC 中窗格、菜单和工具栏的当前配置。
legend图例所有绘图都包含图例。
Listing (pane)列表窗格当执行一条 LIST 命令，且其生成的文字输出超过指定行数时，程序就会创建一个列表窗格。
log file日志文件日志文件是记录控制台窗格全部输出文字的格式化 ASCII 文件。
main menu主菜单程序只有一个主菜单，紧邻程序标题栏下方。
model state模型状态模型状态是程序此刻在计算机内存中保存的、与计算模型有关的全部信息。
names名称对于某些类型的模型元素对象，例如历史、数据表或接触面，为对象指定一个清晰简短的自定义名称，便于随后引用。
pane窗格窗格指程序中以矩形容器形式显示的任意“页面”，具有自己的标题栏和打开／关闭控件。
pane menu窗格菜单用于操作活动窗格的一组命令，通过活动窗格标题栏右端的窗格菜单按钮（）访问。
pane type窗格类型常见的窗格类型包括控制台、项目、编辑器、视图、列表、状态记录和IPython 控制台。
plot (file)绘图文件“绘图文件”是保存某幅绘图全部绘图设置的二进制文件。
plot (term)绘图绘图是视图窗格中对 PFC 模型的可视化表达。
plot item绘图项绘图项是能够添加到绘图中的任意单个可视元素。
primitive基本体基本体是一种模板化形状，可配合 创建网格单元（zone create） 命令创建多种 FLAC3D 网格。
program state程序状态程序状态指专属于 PFC 程序本身的全部信息、设置或默认行为。
project项目项目指构成一个 FLAC3D 模型的数据文件（data file）及其他输入，以及保存文件（save file）及其他输出的集合。
Project (pane)项目窗格项目窗格跟踪一次建模运行中创建的输入文件，即数据文件，以及输出文件，即模型状态（SAV）文件。
project (term)项目项目是一份保存在文件中的记录，用于存储和跟踪组成 PFC 数值模拟的各个项目项。
project file项目文件项目文件表示某个 FLAC3D 项目涉及的全部文件和用户界面元素，该项目可包含多个不同的具体模型和模型状态。
project state项目状态项目状态指与当前项目有关的全部信息，即所有会记录到项目文件中的内容。
result file结果文件结果文件是保存文件的精简版本，参见前文。
SAV fileSAV 文件参见保存文件（save file）。
save file保存文件保存文件也称为SAV 文件（SAV file）或已保存状态（saved state），是一种二进制文件，包含截至程序当前执行时刻全部状态变量的值和用户定义条件。
saved state已保存状态参见保存文件（save file）。
State Record (pane)状态记录窗格状态记录窗格跟踪模型状态，并提供两种视图。
state record (term)状态记录状态记录是创建当前模型状态所经历步骤的文字记录。
step计算步由于 FLAC3D 采用显式算法，求解一个问题需要若干计算步。
switch开关参见“显示属性”。
table file数据表文件数据表文件是通过 导出数据表（table export） 命令导出数据表而生成的格式化 ASCII 文件。
title bar标题栏PFC 中所有窗格以及程序主窗口都有标题栏。
toolbar工具栏程序有一个工具栏，位于主菜单（main menu）旁。
user data file用户数据文件FLAC3D 目前支持三类用户自定义数据，即标量场、矢量场和张量场。
vector image矢量图矢量图是使用数学描述的基本图元来表示的图像。
View (pane)视图窗格视图窗格是包含绘图的窗格。

dynamic solution动力求解考虑惯性效应的动力分析求解模式。

grid (file)网格文件网格文件是一种 ASCII 文件，描述网格点坐标、每个网格单元由哪些网格点组成，以及每个分组包含哪些网格单元。
grid (term)网格网格是由网格单元组成的几何域，也是 PFC 模型中的主要对象。

piece片body 的接触检测单元；教材亦译“片”，旧译“部件”。
rolling resistance滚动阻力抵抗颗粒相对转动的接触模型或力矩。

coordination number配位数单个颗粒平均接触数量。

簇簇颗粒集合体的通用译名；clump 为刚性簇，cluster 为柔性簇。
