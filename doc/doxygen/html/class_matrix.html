详细说明

template<class T, unsigned SX, unsigned SY = SX>
class Matrix< T, SX, SY >

基于模板的矩阵类，尺寸在编译时固定。默认为对称尺寸的矩阵。

这种基于模板的原始矩阵类应在矩阵尺寸于编译时固定的场合使用。可以使用 m(x,y) 访问成员，也可以使用 m[x][y]。
