pure virtual

通过从上一条边的自由端向该点创建并添加一个边对象，向多边形添加一个节点。返回所创建的边。添加的第一个点将创建一条长度为零的边（从该点连到该点）。添加的第二个点将扩展第一条边，因此会返回 0，因为并未创建新边。后续添加的点将创建新的边，并返回所创建的边。

◆ computeMidpoints()

virtual void body::IBodySet::computeMidpoints ( const IBodyBlock *  block,
const IGeomPoly *  face,
const DVect &  midfacePointIn,
DVect &  midfacePointOut,
FArray< DVect > &  edgesMidp 
) const
pure virtual

computeMidpoints：输入为块体、其面以及输入中点。输出为 midfacepointOut（正好位于双线性曲面上）与各边中点。对于四边形：使用双线性曲面插值由面中点计算各边中点。应当同时适用于平面与曲面四边形。输入中点应位于曲面附近。它将沿法线投影到双线性曲面上。各边中点并非一定是 “中点”，而是依据双线性拆分位于边上某处。

对于三角形：输入的面中点无关紧要。midfacePointOut 将为面形心，所有边中点将为边形心，即真正的中点。

根据点数组创建一个与该集关联的 本体区块接口（IBodyBlock） 对象。若未指定 id 编号，则会自动为其分配一个。若具有该 id 编号的 本体区块接口（IBodyBlock） 对象已存在，则会发生异常。blocktype 枚举量指定所创建块体的类型。若设置了 validateFlag（默认即设置），它会先针对所有其他块体检查所提议的块体是否有效（不与其他块体相交且至少共享一个公共面）：若无效，则不会执行任何操作，并返回 null（0）。
