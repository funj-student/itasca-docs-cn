详细说明

信号基类。

信号基类是所有 0 个、1 个或 2 个参数信号的基类。

信号基础接口（ISignalBase） 派生自 槽位基础接口（ISlotBase），以便将各信号串联起来。

virtual bool itasca::ISignalBase::remove ( ISlotBase *  slot,
const QString &  name = QString() 
)
pure virtual

从该 信号基础接口（ISignalBase） 对象中移除 槽位基础接口（ISlotBase） slot。
若 name 为空，则移除所有基类匹配的槽位。
若 slot 为空，则移除所有名称匹配的槽位。
若二者均为空，则移除所有槽位。

参数
slot指向要移除的 槽位基础接口（ISlotBase） 对象的指针。
name要移除的 槽位基础接口（ISlotBase） 的默认空 QString 名称。

在 itasca::Signal2< Param1, Param2 > 中实现。
