详细说明

用于访问结构单元链接的接口。

结构单元之间可以通过共享节点、或将某个节点链接到另一节点或网格单元而彼此连接。若两个或多个结构单元共享一个节点，则全部力和力矩都在该节点处的结构单元之间传递。

virtual QString sel::ISELLink::getAttachConditionSymbol ( quint32  dof) const
pure virtual

给定 0 到 5 范围内的 dof，返回该链接连接条件的描述性名称。参见 获取附着条件（getAttachCondition()）
可能的取值为：- (SELLK_FREE)、+ (SELLK_RIGID)、LIN（SELLK_DEFORM 且 SELCM::SELCM_LIN）、SY（SELLK_DEFORM 且 SELCM::SELCM_SY）、SY（SELLK_DEFORM 且 SELCM::SELCM_NY）、PY（SELLK_DEFORM 且 SELCM::SELCM_PY）、PYDP（SELLK_DEFORM 且 SELCM::SELCM_PYDP）、?（默认）
