详细说明

范围元素的接口，用于将整数与所存储的整数列表进行匹配。

该接口与 IFilterElementInt 类似。
状态为 false 的条目不会被内核以任何方式使用。
它们的存在是为了方便处理界面问题（例如，一个区域列表中有一部分未被选中）。

若该条目被加入列表，则其状态值用于新条目。
