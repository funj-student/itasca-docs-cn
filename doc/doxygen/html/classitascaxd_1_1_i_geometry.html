const DVect &  proj,

const QString &  slot,

)
pure virtual

基于从 t->getLocation() 投射的射线与表面的交点计数，为 IContainer 中的对象分配分组名称。通过对一个集内由公共边相连的所有表面赋予相同的表面 ID 编号，自动为各表面分配表面 ID 编号。（在二维中，则为由公共点相连的所有边。）con 是将被分配分组名称的对象容器。proj 是所用投影矢量的方向。sets 是要对照检查的几何集列表。三维中只使用多边形，二维中只使用边。slot 是要分配分组名称的槽位。filter 用于过滤容器中的对象，仅容器中的对象会被分配分组名称。返回容器中已分配分组名称的对象数。

◆ create()

创建新的 几何集合接口（IGeomSet），名称为 name，并返回指向它的指针。可以可选地指定 id，否则会自动分配一个。如果给定了 Id 编号且已存在具有该 ID 的 几何集合接口（IGeomSet），则发生异常。

尝试按指定的格式将几何单元从 set 导出到文件 filename。binary 表示应使用二进制格式（在文本与二进制均可选时）。nodes 表示应导出符合过滤条件的所有 IGeomPoints。edges 表示应导出符合过滤条件的所有 IGeomEdges。comment 表示可嵌入文件的注释字符串（如适用）。注意，与所导出多边形相连的点和边会自动导出。
