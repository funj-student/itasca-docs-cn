virtual bool itasca::ISettings::getLog ( ) const
pure virtual

若文本输出同时被发送到日志文件，则返回 TRUE。

若字符串比较区分大小写，则返回 TRUE。
这包括宏、命令匹配、FISH 等。

◆ getUnrepeatable()

virtual bool itasca::ISettings::getUnrepeatable ( ) const

若模型状态已被标记为不可重复，则为 true，这表示从输入记录重新运行模型不会重现该模型状态。
