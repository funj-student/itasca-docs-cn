详细说明

用于存储 ZoneThings 的容器。BlockThing 的 ID 存放在 Fortran 网格单元链表的偏移 $KZCPP 处。

◆ claimBit()

virtual int block::IZoneArray::claimBit ( ) const
pure virtual

从网格单元的工具位字段中申请一个位。

有时，在与实际模型循环逻辑无关的计算过程中，能够将标志和数据存储在网格单元中是很有用的。
为此提供了两个工具数组，它们主要用于被短暂申请、使用，随后再释放回去供其他算法使用。
申请位（claimBit()） 返回一个位索引，该索引可与 IZone::getBit() 和 IZone::setBit() 函数配合使用。该函数是线程安全的（IZone::getBit 和 IZone::setBit 则不是）。

另请参见
释放位（releaseBit()） IZone::setBit() IZone::getBit()
