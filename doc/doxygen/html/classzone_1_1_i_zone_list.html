◆ claimBit()

virtual int zone::IZoneList::claimBit ( ) const
pure virtual

从网格单元的工具位字段中申请一个位。

在与实际模型循环逻辑无关的计算中，有时需要在网格单元中存储标志和数据，这会很有用。
为此提供两个工具数组，它们主要用于短暂申请、使用，然后释放以供其他算法使用。
申请位（claimBit()） 返回一个位索引，可与 单元接口获取位（IZone::getBit()） 和 单元接口设置位（IZone::setBit()） 函数配合使用。该函数是线程安全的（单元接口获取位（IZone::getBit） 和 单元接口设置位（IZone::setBit） 则不是）。

另请参见
释放位（releaseBit()） 单元接口设置位（IZone::setBit()） 单元接口获取位（IZone::getBit()）
