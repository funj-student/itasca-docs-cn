详细说明

用于访问特定数值表的接口。

一个 表格接口（ITable） 是数值对 (x,y) 的列表，这些数值对可能按 x 递增排序，也可能未排序。
某些函数只有在表已排序时才会产生有效结果。

返回位置 x 处的斜率。假定表已排序。
不进行高阶运算，只取与 x 相邻线段的斜率。
