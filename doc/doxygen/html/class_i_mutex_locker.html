详细说明

一个自动加锁/解锁 QMutex 的辅助类。

类似于 QMutexLocker，但增加了一些调试辅助功能。
具体而言，可跟踪是谁在请求该互斥量的文件与行号。
此外，还允许抛出“timeout”错误，以帮助检测竞态条件。本类不应直接创建，而应使用宏 LOCK_MUTEX1、LOCK_MUTEX2 和 LOCK_MUTEX3。QMutexLocker 类本身已通过预处理器的使用而被禁用，以强制编码者使用此版本。
