◆ isThreadSafe()

virtual bool itascaxd::IRangeElement::isThreadSafe ( ) const
pure virtual

若该范围元素是线程安全的（即可用于多线程循环），则返回 true。可选择提供一个 IThing 指针；若给出，则该 IThing 指针就是该范围元素作用的对象——范围元素会检查其类型，以确保该类型未被用于范围元素筛选中。若确实被使用，则该范围元素不应用于多线程循环。实际上在这种情况下，该范围元素根本就不应使用，而应抛出错误。
