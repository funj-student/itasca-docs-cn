◆ processCommand()

virtual QString itasca::IKernel::processCommand ( const InputLine &  s,
const QString &  inputPath = QString(),
bool  recursive = false 
)
pure virtual

将 s 的内容作为一条命令发送。

命令处理会立即执行，除非因命令已在处理中而被递归调用。此时命令会被添加到栈中最底层的项，因此将在该栈处理完毕并耗尽其先前命令之后才被执行。若产生错误，则返回错误消息；若无错误，则返回 QString()。source 与 line 指明 sl 中命令的来源，以及 sl 中首行在原始来源中的行号。inputPath 指明源文件名的绝对路径名。将捕获并处理命令处理过程中抛出的异常。
