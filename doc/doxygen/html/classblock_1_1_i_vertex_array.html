virtual int block::IVertexArray::claimBit ( ) const
pure virtual

从顶点工具位字段中申请一个位。

有时在计算过程中需要在网格单元中存储与模型循环逻辑无关的标志和数据。
为此提供了两个工具数组，它们主要供短暂申请、使用，然后再释放回供其他算法使用。
申请位（claimBit()） 返回一个位索引，可与 顶点对象接口获取位（IVertexThing::getBit()） 和 顶点对象接口设置位（IVertexThing::setBit()） 函数配合使用。该函数是线程安全的（顶点对象接口获取位（IVertexThing::getBit） 和 顶点对象接口设置位（IVertexThing::setBit） 则不是）。

另请参见
释放位（releaseBit()） 顶点对象接口设置位（IVertexThing::setBit()） 顶点对象接口获取位（IVertexThing::getBit()）
