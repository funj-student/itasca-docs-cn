详细说明

template<class T, quint64 S = 32>
class FArray< T, S >

一种尽量减小不必要的堆访问的数组类。

T 为数据类型。
S 为栈长度。
本类旨在为绘图生成提供一个速度优化的数组。
它通过两种方式做到这一点。
第一，它通过不释放内存来尽量减小堆的频繁变动。
第二，它具有一个第二模板参数，用于指明应在栈上创建多少内存。只有当数组大小需要超过 S 时，它才实际使用堆内存。
