详细说明

用于访问分组交集过滤元素的接口，该元素用于按分组交集过滤对象。

分组交集过滤元素按成对分组的交集来过滤对象。例如，某个接触可能位于两个块体分组的交集处。目前，这只适用于输入的 BLOCK 分组。
