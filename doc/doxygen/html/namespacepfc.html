class  IWall
 通用墙的接口。这是通用墙的接口。具体的墙类型必须由此派生。墙被设定为某种几何对象，其他模型组件（球体和刚性团簇）可以与其相互作用，但墙本身不产生反作用。因此它们起到提供边界条件的作用。该接口提供访问与墙关联的 Body 和 Piece 的基本功能。可通过该接口访问的属性包括位置、旋转点、速度、角速度、位移、角位移、力和力矩。位置的含义取决于具体实现。除力和力矩外，所有这些属性都可以设置。 更多…（More...）
