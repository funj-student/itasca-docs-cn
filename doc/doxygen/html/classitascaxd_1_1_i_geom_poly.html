向多边形添加一条边。边一端的点必须与多边形最后一条边自由端的点一致。成功则返回 true，否则返回 false。默认情况下，如果无法有效添加该边，则抛出异常。如果不想抛出异常，请将 throwException 设为 false。如果希望强制在加入时翻转该边，请将 forceFlip 设为 true——仅对添加的第一条边适用。

将表面上的点转换为全局坐标。若 (u,v) = (0,0)，则为形心的位置；若 (u,v) = (1,0)，为 point(0) 的位置；(u,v) = (0,1)，为 point(1) 的位置。如果多边形无效，则返回零矢量。

◆ isPlanar()

virtual bool itascaxd::IGeomPoly::isPlanar ( const double &  tolerance = 1e-7) const
pure virtual

如果多边形在 tolerance 范围内共面，则返回 true，判定方式是检查各顶点到平均平面的距离。若 maxdist*cendist > tolerance*area，则返回 false，其中 maxdist 是顶点到平均平面的最大距离，cendist 是形心到该顶点的距离，area 是假定多边形共面时的面积。
