详细说明

通过从上一条边的自由端向该点创建并添加一个边对象，向多边形添加一个节点。返回所创建的边。添加的第一个点将创建一条长度为零的边（从该点连到该点）。添加的第二个点将扩展第一条边，因此会返回 0，因为并未创建新边。后续添加的点将创建新的边，并返回所创建的边。
