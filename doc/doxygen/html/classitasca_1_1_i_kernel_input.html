详细说明

描述内核需要从驱动它的任意接口接收的全部输入支持的接口。

用于汇聚内核进程自身之外所需的全部输入的集中管道。这包括来自用户界面的输入，以及（最终）来自文件系统、套接字和进程间通信的输入。
本类是严格的单例——因此来自外部的所有输入（理论上）都应首先经过此处。ingroup utility
