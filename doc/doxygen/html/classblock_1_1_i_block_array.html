◆ claimBit()

virtual int block::IBlockArray::claimBit ( ) const
pure virtual

从块体的辅助位字段中申请一位。

在计算过程中，有时需要在网格单元中存储与实际模型循环逻辑无关的标志和数据。
为此提供了两个辅助数组，它们主要用于被短暂申请、使用，然后释放回去以供其他算法使用。
申请位（claimBit()） 返回一个位索引，该索引可与 IBlock::getBit() 和 IBlock::setBit() 函数配合使用。该函数是线程安全的（IBlock::getBit 和 IBlock::setBit 则不是）。

另请参见
释放位（releaseBit()） IBlock::setBit() IBlock::getBit()
