◆ FishExample()

FishExample::FishExample ( uint  id,
const QString &  name,

const QString &  returnDescription,

const QString &  argumentDescription = QString::null

构造函数允许您指定与 此特定内部函数相关联的 id、名称、参数及其他数据。
请注意，每添加一个内部函数，都会创建库类的一个独立实例。
每个独立的内部函数都通过唯一的 ID 编号来标识。
在此实现中，内部函数特有的数据作为成员存储，并在构造时赋值。
另一种有效的实现方式是不在本地存储任何内容，只存储 ID，并在 获取名称（getName()）、获取读取仅（getReadOnly()） 等的实现中使用 CASE 语句（或类似结构）。

◆ getMajorVersion()

EXPORT_TAG unsigned getMajorVersion ( )

返回主版本号。

该编号表示二进制兼容性，必须与 FISH DLL 所期望的编号一致。

◆ getMinorVersion()

EXPORT_TAG unsigned getMinorVersion ( )

返回次要版本号，用于指示内部变更。用户可在 load 命令加载期间指定所需的最低次要版本。
