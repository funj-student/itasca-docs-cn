详细说明

二维角矢量类。

这种矢量类的特化版本用于存储“角”值，即在二维中为标量（仅 z 分量）、在三维中为完整矢量的值。

其目的在于更便于编写在二维和三维中相同的代码，同时不浪费计算时间和存储空间。

此外，希望它们能与标准 Vector2<> 类型“正确”地交互。

例如，叉乘和点乘运算符 “&” 与 “|” 应返回正确的类型，就像它们是完整的三维矢量对象一样。

Vector2<T> 与 AVector2<T> 叉乘将返回 Vector2<T>。

Vector2<T> 与 AVector2<T> 点乘将返回 0.0。
