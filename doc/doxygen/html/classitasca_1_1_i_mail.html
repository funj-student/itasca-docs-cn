◆ send()

virtual bool itasca::IMail::send ( )
pure virtual

发送电子邮件。必须设置以下邮件元素：
1) 有效的 SMTP 主机地址，参见 设置 SMTP 服务器地址（setSmtpServerAddress()） 和 获取 SMTP 服务器地址（getSmtpServerAddress()）
2) 有效的“Mail From”地址，参见 获取邮件从（getMailFrom()）、设置邮件从（setMailFrom()）
3) 至少一个有效的收件人，参见 添加收件人（addRecipient()）
