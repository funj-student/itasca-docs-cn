详细说明

template<class T>
class itascaxd::IUDTypeList< T >

用户自定义数据值类型容器的接口。

支持按 ID 和按位置查找，也可创建 用户数据类型接口（IUDType） 的新对象。模板类类型 T 应为列表中所含类的接口。例如，标量集合可定义为 用户数据类型列表接口（IUDTypeList<IUDScalar>）。假定类 T 提供与 IUDType<> 相同的基本功能。
