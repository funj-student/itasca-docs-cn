详细说明

template<class Param1, class Param2>
class itasca::Signal2< Param1, Param2 >

定义 信号 2（Signal2） 对象，其中保存 槽位 2 接口（ISlot2） 对象的列表。

这是一套自定义细粒度回调工具的一部分，其目的是在不引入额外开销的情况下模拟 Qt 的 signal/slot 范式。一个 信号 2（Signal2） 对象持有 槽位 2 接口（ISlot2） 对象的列表。信号 2（Signal2） 派生自 槽位基础接口（ISlotBase），因此一个 信号 2（Signal2） 可以被链式联结或联结到另一个 信号 2（Signal2）（参见 附着信号（attachSignal()） 与 移除信号（removeSignal()））。已联结的方法通过 执行（execute()） 调用。在内部，槽通过 AutoSlot0、AutoSlot1 与 AutoSlot2 模板类创建。这些类分别对应带有 0、1 或 2 个参数的方法。因此，可以将带有 0、1 或 2 个参数的方法联结到一个 信号 2（Signal2） 对象上。这分别由 附着方法 0（attachMethod0()）、附着方法 1（attachMethod1()） 与 附着方法 2（attachMethod2()） 函数完成。此外还有与之匹配的 移除方法 0（removeMethod0()）、移除方法 1（removeMethod1()） 与 移除方法 2（removeMethod2()） 函数。附着（attach()） 与 移除（remove()） 方法需要 槽位 2 接口（ISlot2） 参数。在定义该方法的类内部联结方法的语法为

signal2->attachMethod2<Fred,&Fred::func>(this);

其中 signal2 是 信号 2（Signal2） 对象，Fred 是成员函数 func 所在的类（派生自 Slot）。也可以使用 attach 方法：

signal2->attach<Fred,&Fred::func>(&fred);

其中 fred 是类 Fred 的一个特定实例。移除语法类似：

signal2->remove(&fred,&Fred::func);
