3DEC 接口规范（3DEC interface specification）

这是 SubcontactThing 的接口，该类保存 Fortran 数组中不存在的附加数据。这些数据将存放在一个容器中，其 ID 存放在 Fortran 子接触链表的偏移 $KCXCPP 处。它继承自 Thing，因此可以使用分组和附加变量。它还与对应的 Fortran 数据块之间具有双向可访问性。 更多…（More...）

详细说明

这是 SubcontactThing 的接口，该类保存 Fortran 数组中不存在的附加数据。这些数据将存放在一个容器中，其 ID 存放在 Fortran 子接触链表的偏移 $KCXCPP 处。它继承自 Thing，因此可以使用分组和附加变量。它还与对应的 Fortran 数据块之间具有双向可访问性。
