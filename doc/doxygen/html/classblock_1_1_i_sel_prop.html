详细说明

该接口提供对锚索 Thing 的访问。SelProp ID 在 Fortran 结构单元属性数据数组中的偏移为 $ktypcpp。

由于存在由用户设置的材料编号，现在还多了一个在将该 SelProp Thing 添加到 C++ 数组时设置的 id，这无疑会造成很多混淆。
