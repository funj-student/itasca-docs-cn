详细说明

用于指定特定三维笛卡尔坐标系并在其间进行转换的类。

本类提供一个笛卡尔坐标系（3 个正交轴加中心点），并支持局部空间与全局空间之间的映射。本类是 Axes 的三维版本，同时也存在二维版本。在可能的范围内，两者的 API 已保持一致。
