详细说明

主命令处理类的接口。

这是主命令处理类的接口。具体而言，该类接收命令字符串并将其切分为词元，使其能够被解释为命令。

类 解析接口标记接口（IParse::IMark） 用于指示词元列表中的位置。该类完全不透明，必须使用 解析接口（IParse） 的成员函数来创建和修改它们。尤其要注意——不要 执行 “*im1 = *im2;”，其中 im1 与 im2 都是指向 解析接口标记接口（IParse::IMark） 的指针。这样做能通过编译并执行，但不会得到你想要的结果。我无法让它产生编译时错误 ;(。

一个 解析接口（IParse） 对象包含一个内部位置指示器，如果命令中未指定位置，则默认使用该指示器。所有接受 标记接口（IMark） 的函数都（不加检查地）假定该 标记接口（IMark） 是由使用它的同一个 解析接口（IParse） 创建的。

函数大致分为四类
isXXX()（检查转换函数）检查词元是否能以某种方式解释，并返回 解析接口返回码（IParse::RetCode） 以指示成功或失败。若成功，则填充指向对象的指针（若已提供），并递增 解析接口标记接口（IParse::IMark） 位置指示器。
toXXX()（自动抛出例程）直接转换为指定类型并返回值；若无法解释该词元，则抛出 Exception。
解析接口标记接口（IParse::IMark） 操作函数用于创建、检查和修改 解析接口标记接口（IParse::IMark） 对象的位置。
通用实用工具函数。

函数 getTokenIndex、getLineNumber 与 getTokenExtent 返回有关词元在输入行上原始位置的信息。注意，若词元是宏展开的结果，则该信息指示其来源宏。

◆ RetCode

enum itasca::IParse::RetCode

isXXX() 函数可能返回的返回码。

枚举值
rcOK 

词元已成功解释。

rcMiss 

该位置处不存在词元。

rcBad 

无法按所要求的方式解释该词元。

rcRange 

词元已被正确解释，但其值超出了所给定的限制范围。

rcExtra 

在命令行末尾发现了一个多余的未使用词元。
