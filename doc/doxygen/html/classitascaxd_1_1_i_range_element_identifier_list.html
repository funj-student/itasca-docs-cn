详细说明

范围元素的接口，用于将字符串与所存储的字符串列表进行匹配。

该接口与 范围元素无符号界面指针列表接口（IRangeElementUIntPtrList） 类似。
状态为 false 的条目不会被内核以任何方式使用。
它们的存在是为了方便处理界面问题（例如，一个区域列表中有一部分未被选中）。
