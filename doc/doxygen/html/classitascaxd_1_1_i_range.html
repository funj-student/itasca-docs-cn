详细说明

筛选器的接口，是对对象进行筛选的主要方式。

这是主命令处理类的接口。其思路是把 IThing 传给 Range［是否为在……内（isIn()）］，由 Range 判定它落在内部还是外部。
Range 是范围元素（Range Element）的容器，给定的 IThing 必须落在其中全部元素之内（交集，默认），或任意元素之内（并集，配合 设置并集（setUnion()））。
默认情况下 Range 是其所有筛选元素的逻辑交集。若设置了并集标志，则筛选器被视为其各元素的逻辑并集。

◆ isThreadSafe()

virtual bool itascaxd::IRange::isThreadSafe ( ) const
pure virtual

若所有范围元素都是线程安全的（即该范围可用于多线程循环），则返回 true。可选择提供一个 IThing 指针；若给出，则该 IThing 指针就是该范围作用的对象——各范围元素会检查其类型，以确保该类型未被用于范围元素筛选中。若确实被使用，则该范围不应用于多线程循环。实际上在这种情况下，该范围根本就不应使用，而应抛出错误。

◆ setSelected()

设置“选定”状态，默认值为 false。默认情况下筛选器会忽略 IThing 的选定状态。若将其设为 true，则任何设置了选定标志的对象（t->获取已选择（getSelected()））都会被纳入筛选元素的考虑范围（注意并集与交集规则仍适用于其他筛选元素），同时隐藏属性将被忽略。
