virtual InputLine itasca::ITextInput::getInput ( const InputContext &  context)
pure virtual

从当前源返回一行输入。如果当前源已耗尽，将自动弹出栈并使用下一个源。如果 undoTag 为 false，则该行会被标记为在查找撤销位置时跳过。如果没有可用的输入，本函数将立即返回 NULL 字符串；除非 wait 为 true，此时应阻塞直到可以返回字符串。
