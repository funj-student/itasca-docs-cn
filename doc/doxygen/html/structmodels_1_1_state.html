详细说明

用于向本构模型传递信息的结构体。

FLAC3D 与用户编写模型之间最重要的联系是成员函数 run(unsigned dim, State *ps)，它在循环计算期间计算模型的力学响应。
结构体 状态（State）（定义于 state.h？）用于在模型与程序之间传递信息。
状态（State） 也会传给 initialize() 方法，不过在那种情况下并非所有字段都保证有效。
状态（State） 的成员（全部为公有）如下。
并非所有信息都会被某个特定程序使用；该结构旨在服务于全部 Itasca 程序。

由 ID 返回表索引。

按 id 编号查找表可能是开销很大的操作。
一般而言，更好的做法是在 initialize() 期间用本函数保存一个引用指针，并在 run() 期间用它访问该表。索引指针不应被保存和恢复，而应在每次调用 initialize() 时重新查找。（在此期间表数据可能已发生变化）。

Double models::State::pore_pressure_increment_

若模量（约束模量、剪切模量、体积模量）发生变化，应在 run() 中设为 true。

平均塑性应力变化值，节点混合离散化计算需要用到。若塑性流动改变了压力，必须在此指明，以便正确进行压力平均。模型提供的孔隙压力增量。

◆ state_

unsigned long models::State::state_

子单元状态位标志。

模型状态指示位标志。
该整数中的各个位对应 getStates() 成员函数中的名称。
例如，标志值为 1（第 0 位）表示第一个状态，值为 2（第 1 位）表示第二个，值为 4（第 2 位）表示第三个，值为 8（第 3 位）表示第四个，依此类推。
可同时选中任意多个位（例如，剪切屈服与拉伸屈服可能同时发生）。

◆ sub_zone_

unsigned int models::State::sub_zone_

正在处理的子单元序号（从 0 开始）。

该信息可用于正确缩放累积的子单元数据。例如，若有十个子单元（见 total_sub_zones_），则累积值需除以十，才能得到整个网格单元的平均值。

◆ viscous_

bool models::State::viscous_

若要计算黏性应变，则为 true。

若要为 Rayleigh 阻尼的刚度比例分量计算黏性应变，则为 true。
若未设置，该标志默认为 false。
通常，对于弹性增量应设为 true，对于发生屈服的增量应设为 false。
