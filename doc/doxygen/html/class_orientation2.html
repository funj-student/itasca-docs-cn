详细说明

用于存储“方位”即二维或三维空间中方向的类。

方位可视为定义了一个法向方向，或定义了空间中垂直于该方向的一个平面。
2D 方位由平面倾角（自 +X 轴顺时针度量）或法向矢量指定。
3D 方位由倾角（自 XY 平面顺时针度量）和倾向（最陡 Z 下降线投影到 XY 平面上，自 +Y 轴顺时针度量）指定。

三维方位对象会记住它们是用倾角/倾向还是法向矢量指定的。

所指定的原始数据（未归一化的方向矢量、超出范围的倾角与倾向）会被保留，以便用户按分量对其进行修改或更新。

出于历史（3DEC）原因，方位具有全局的左手系统模式——它会改变倾角与倾向的三维定义。

方位还可以返回“节理角”，其定义为该平面与 xy 平面的交线，自 x 轴起逆时针量取为正值。在二维情形下，节理角是倾角的负值。注意，“节理角”无法完整确定法向矢量，因为它没有正反之分；因此，节理角 45 与节理角 225 等价。节理角始终在 0 至 180 的范围内返回。

三维法向矢量的“方位角”是该矢量在 XY 平面上的投影自 +Y 起顺时针量取的角度。在左手系统（LHS）中，YZ 轴互换。
三维法向矢量的“倾伏角”是该矢量与 XY 平面之间的夹角。在左手系统（LHS）中，YZ 轴互换。

注意
Orientation2 依赖默认的（由编译器提供的）拷贝构造函数和 = 运算符。
