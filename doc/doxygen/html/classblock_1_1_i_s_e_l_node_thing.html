这是 SELNodeThing 的接口，该类保存 Fortran 数组中不存在的附加数据。这些数据将存放在一个容器中，其 ID 将存放在相应 Fortran 数组的对应偏移 $xxCPP 处。它继承自 Thing，因此可以使用分组和附加变量。 更多…（More...）
