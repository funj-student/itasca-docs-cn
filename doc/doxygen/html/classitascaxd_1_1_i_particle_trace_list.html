获取粒子轨迹数据。start 是假定为值（第一个始终为 0）的文件位置。
用该记录中的各条粒子轨迹填充 position 数组、velocity 数组与 valid 数组。
同时将记录的步号返回到 *step。返回获取数据之后的文件位置（可作为 start 用于取下一记录）。
