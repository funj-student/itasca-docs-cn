◆ claimBit()

virtual int zone::IGpList::claimBit ( ) const
pure virtual

从网格点工具位字段中申请一个位。

在与实际模型循环逻辑无关的计算中，有时需要在网格点中存储标志和数据，这会很有用。
为此提供两个工具数组，它们主要用于短暂申请、使用，然后释放以供其他算法使用。
申请位（claimBit()） 返回一个位索引，可与 获取工具位（IGp::getBit()） 和 设置工具位（IGp::setBit()） 函数配合使用。该函数是线程安全的（获取工具位（IGp::getBit） 和 设置工具位（IGp::setBit） 则不是）。

另请参见
释放位（releaseBit()） 设置工具位（IGp::setBit()） 获取工具位（IGp::getBit()）

bool  bTherm,
bool  bOr 
)
pure virtual

返回最接近位置 dv3 的网格点指针。
参数 bMech、bFluid 和 bTherm 用于返回与一个或多个具有活动力学、流体和/或热学模型的网格单元相连的网格点。
参数 bOr 影响参数 bMech、bFluid 和 bTherm 的组合方式：true = 并集，false = 交集
若不满足准则，则函数返回 0。
