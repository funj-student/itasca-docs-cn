详细说明

用于访问网格单元场数据类的接口。本类允许在模型中的任意点访问 gp 与网格单元的标量场数据（如密度、位移大小、sxx 等），而不必位于网格点或网格单元形心处。
对于基于网格单元的变量可能需要进行插值，该过程的具体细节可通过 单元插值接口（IZoneInterpolate） 接口设置。

◆ initialize()

virtual void block::IZoneFieldData::initialize ( )
pure virtual

初始化场数据对象，以便高效地计算大量数值。
初始化后，数值将存储在 Gp 和 Zone 数据的临时偏移中，以尽量减少重复计算。
仅当需要通过 获取数据（getData()） 依次查询大量数值时，这样做才有意义。
如果在调用 initialize 之后、reset() 之前模型发生了变化，那么此后对 获取数据（getData()） 的任何调用都将返回无效数据。
