详细说明

本构模型插件的基类。

所有本构模型（null、elastic、mohr-coulomb 等）都派生自该类。
任何作为插件提供的自定义本构模型都必须派生自该类。
纯虚方法必须由用户提供——本类已提供若干工具函数。

注意
生成的 DLL 文件名必须为 model|name|###|.dll（发行版）和 model|name|###|_debug.dll（调试版）。
其中 |name| 是 获取名称（getName()） 返回的字符串，|###| 是主版本号（3 位数字，右对齐，用零填充）。
例如 modelelastic001.dll 和 modelelastic001_debug.dll

inlinevirtual

初始化本构模型，为调用 运行（run()） 做准备。

当发出 SOLVE/Step/CYCLE 命令时（进行大应变更新之际），以及当 是否为有效（isValid()） 返回 false 时在 运行（run()） 方法开头，该函数会为每个模型对象（即每个完整网格单元）调用一次。
模型对象可对其属性或状态变量进行初始化，也可不做任何操作。
维数（例如 FLAC3D 中为 3）以 dim 给出，结构体 s 包含该模型对象所属网格单元的当前信息。
注意，调用 初始化（initialize()） 时应变可能尚未定义。
完整网格单元的平均应力分量可在状态结构中获取；初始化（initialize()） 成员函数不应改变它们。
基类实现会调用 setValid(dim)。

◆ run()

virtual void models::ConstitutiveModel::run ( UByte  d,

)
inlinevirtual

由应变增量计算应力增量。

在每个循环中，FLAC3D 扫描网格单元时会对每个网格单元中的每个四面体调用一次该函数。
模型必须由应变增量更新应力张量。
结构体 状态（State） s 包含正在处理的网格单元的当前应力分量和计算得到的应变增量分量。
dim 为 2 或 3，取决于调用程序的维数。调用 运行（run()） 时，应力分量中已包含旋转校正项。
若 是否为有效（isValid()） 返回 false，基类实现将调用 初始化（initialize()）。
