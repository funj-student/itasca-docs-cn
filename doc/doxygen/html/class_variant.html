详细说明

QVariant 的一个更简单（且略快）的版本，为不使用 Qt 的接口而添加。

本类实现了一种变体。当需要传递或返回参数而类型可能变化时使用。
这些类型可以是整型、浮点型、字符串、二维或三维矢量等。
该类型用于本构模型的属性接口，以及 FISH。
如果启用了 QT，建议使用 Qt 的 QVariant 类。
QVariant 更为通用，但本实现在运行时应具有更好的性能。
