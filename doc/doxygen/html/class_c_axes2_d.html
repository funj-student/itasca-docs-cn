详细说明

用于指定特定二维笛卡尔坐标系并在其间进行转换的类。

本类允许用户指定一个笛卡尔坐标系，并在笛卡尔空间中从“局部”坐标（相对于此 CAxes 对象）转换到“全局”坐标。本类是 CAxes 的二维版本，同时也存在三维版本。引入它是为了让坐标系无需承担存储中心和附加矢量的额外开销，这一点与 CAxes2D 及三维类不同 —— 后者的附加矢量是在运行时获取的，代价是增加一些计算开销。API 的功能与 Axes API 基本相同，只是无法访问坐标系中心。
