详细说明

用于指定特定二维笛卡尔坐标系并在其间进行转换的类。

本类允许用户指定一个替代的笛卡尔坐标系（包括原点平移），并在“局部”坐标（相对于该 Axes 对象）与默认的“全局”笛卡尔空间之间进行转换。本类是 Axes 的二维版本，同时也存在三维版本。在可能的范围内，两者的 API 已保持一致。
