返回给定节点对结构单元所施加力矢量的某一个分量
dof 的有效取值范围为 0 到 5——例如 0 表示平动 x，3 表示转动 x
end 的有效取值范围为 0 到 获取数量节点（getNumNd()）-1
local 设为 true 时返回局部坐标系中的节点力，否则返回全局坐标系中的力
