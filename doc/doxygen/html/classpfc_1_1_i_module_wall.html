详细说明

墙模块的接口。

这是墙模块的接口。外部世界通过该接口访问墙的信息。目前仅实现了面片墙，该接口也反映了这一事实。预计将为加入该模块的其他墙型（点墙、线墙等）提供并行的方法来访问信息。其意图是：所有类型的墙都具有唯一 id，从而 findWallWithID 方法可以按相应 id 找到任意 墙体接口（IWall）。
