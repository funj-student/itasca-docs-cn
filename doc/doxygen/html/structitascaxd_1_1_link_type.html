LinkType<> 对象的接口。它是 POD 结构，既包含指向下一个对象的指针 且 包含在该对象内引用的索引。LinkType<> 对象用于简化那些需要同时引用目标对象和目标对象内引用索引的链表。典型例子是与某个网格点相连的全部网格单元的列表，链表中的每个连接都需要知道该网格点在后续网格单元中的索引。
