详细说明

DIM - 提供 2D 与 3D 代码之间的代码可移植性。

本文件提供 2 维与 3 维代码之间的代码可移植性。
根据 DIM 的定义方式，本文件为矢量、区间、坐标轴、立方体等声明 TYPEDEF 与模板函数。
为 2D 与 3D 的矢量、坐标轴、区间等提供声明。
其目的是使编写在 2D 与 3D 中相同的可移植代码更为容易。
