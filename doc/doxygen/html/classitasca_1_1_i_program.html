详细说明

主程序访问入口。

位于“树”的根部，提供对描述整个代码的接口的访问。
使用 IFLAC3D 接口（未在内核层面定义）将应用专用数据添加到接口树中。

注意
若 getIxxx 函数带有 Optional 注释标记，则意味着该功能可能不可用，且若其返回 0，界面应能优雅降级。
