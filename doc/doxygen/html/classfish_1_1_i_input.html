virtual void fish::IInput::debug ( IDebug *  fishdebug,
const QString &  message 
)
pure virtual

停止 FISH 处理并等待，同时提供 IFishDebug 接口，使函数实现有机会调试 FISH 代码。该接口可用于查询变量、单步执行函数等。本函数旨在作为由控制 FISH 的程序所实现的 FISH 调试器的主接口。

参数
fishdebug指向 IFishDebug 接口的指针，该接口用于控制调试会话。
message说明 FISH 处理为何停止并将控制权交给调试器的消息。

从当前源返回一行输入。若当前源已用尽，将自动弹出堆栈并使用下一个源。

参数
prompt适当时在命令行上使用的提示符。
interactive若 FISH 输入源被视为“交互式”，即不适合从数据文件读取下一行，则为 TRUE。
