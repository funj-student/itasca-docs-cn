◆ getGp()

virtual const IGp* zone::IFace::getGp ( quint32  gpIdx) const
pure virtual

给定索引，返回与该索引对应的网格点（gpIdx）。网格点顺序为：沿法向量向下看时顺时针，沿法向量方向看时逆时针。

◆ isOnGroupSurface()

virtual bool zone::IFace::isOnGroupSurface ( const ISlotID &  slot,
IGroupID *  group1 = nullptr,
IGroupID *  group2 = nullptr 
) const
pure virtual

若该面位于给定槽位中某一分组与另一分组的边界上，则返回 TRUE。若 slot 为 ANY，则只要任一槽位中的分组在相邻网格单元之间发生变化即返回 TRUE。若该网格单元属于力学表面（isSurface(true,false,false,-1)==true），则始终返回 true。若提供了 group1 与 group2，则填入边界两侧的分组名称。

若某一侧不存在分组，则 group2 为 null。若使用 ANY 槽位且存在多个分组表面，则使用最先找到的一个。

判断该面是否可视为表面面。mech、therm、fluid 指示在相应过程中若网格单元为 NULL，是否应视为缺失。若 bit>0，则 getBit(bit) 返回 0 表示该网格单元应视为缺失。

◆ isVisibleSurface()

virtual bool zone::IFace::isVisibleSurface ( ) const
pure virtual

基于非隐藏网格单元判断该面是否视为表面面。若该面属于全部可见且非空网格单元集合的表面，则为 true，否则为 false
