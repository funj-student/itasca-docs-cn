class SymTensor
 

详细说明

对称张量（SymTensor） 特征值与方向辅助类。

这一刻意保持不透明的结构体表示由特征值（主分量）重建完整对称张量所需的方位信息。
请注意，在调用 对称张量特征值信息（SymTensor::getEigenInfo()） 与 对称张量信息解析（SymTensorInfo::resolve()） 之间，特征值可能发生变化。
