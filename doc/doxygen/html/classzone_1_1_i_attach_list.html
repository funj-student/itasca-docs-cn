创建联结

参数
type是联结类型（网格点、边或面）
slave是从属网格点
it1,it2,faceNo对于网格点类型的联结，it1 为主网格点，参数 it2 与 faceNo 不使用。对于边类型，it1 与 it2 为构成该边的网格点指针，参数 faceNo 不使用。对于面类型，it1 为网格单元指针，it2 不使用，faceNo 为面编号，有效取值为 0 到 5。
snap行为参见 ATTACH 命令参考。
