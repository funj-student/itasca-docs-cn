详细说明

IFishLibrary 接口的示例实现。

定义一个类，当作为 Itasca DLL 插件加载时，它会创建七个新的 FISH 内部函数。
这些内部函数允许用户按指定的频率、幅值、相位、采样间隔和长度创建正弦 Table 的数据。创建的函数为：

  • example_freq 要使用的频率
  • example_amp 幅值
  • example_phase 相位
  • example_int 间隔
  • example_num 点个数，interval*num 为长度（或持续时间）。
  • example_all 允许一次性指定上述全部内容。
  • example_create 使用上述参数创建表数据。
