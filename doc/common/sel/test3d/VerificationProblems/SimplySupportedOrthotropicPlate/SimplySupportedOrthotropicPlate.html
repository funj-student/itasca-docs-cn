简支正交各向异性板

问题描述

注意

本例的项目文件可在 FLAC3D 中查看/运行。[1] 所用 主数据文件（main data files） 示于本例末尾。其余数据文件可在该项目中找到。

对承受均布荷载的简支矩形正交各向异性板，用数值方法确定挠度与应力。

闭式解

该问题的解析解由 Ugural（1981，第 144-145 页）给出。考虑边长 \(a\) 与 \(b\)、四边简支、承受均布荷载 \(p_0\) 的矩形板，其正交各向异性主方向与 \(x\)、\(y\) 轴对齐，如 图 1（Figure 1） 所示。

图 1：用于表示闭式解的矩形板与坐标系。

挠度（\(w\)）、弯曲应力合力（\(M_x\)、\(M_y\) 与 \(M_{xy}\)）以及横向剪应力合力（\(Q_x\) 与 \(Q_y\)）由下式给出

\[w = {{16 p_0} \over {\pi^6}} \sum^{\infty}_m \sum^{\infty}_n \Biggl[{1 \over \beta}\Biggr] {\rm sin} (m \pi x / a) {\rm sin} (n \pi y / b)\]
\[M_x = {{16 p_0} \over {\pi^4}} \sum^{\infty}_m \sum^{\infty}_n \Biggl[{{D_x (m^2 / a^2) + D_{xy} (n^2 / b^2)} \over {\beta}}\Biggr] {\rm sin} (m \pi x / a) {\rm sin} (n \pi y / b)\]
\[M_y = {{16 p_0} \over {\pi^4}} \sum^{\infty}_m \sum^{\infty}_n \Biggl[{{D_{xy} (m^2 / a^2) + D_y (n^2 / b^2)} \over {\beta}}\Biggr] {\rm sin} (m \pi x / a) {\rm sin} (n \pi y / b)\]
\[M_{xy} = {{16 p_0} \over {\pi^4}} \sum^{\infty}_m \sum^{\infty}_n \Biggl[{{2G_{xy} (mn/ab)} \over {\beta}}\Biggr] {\rm cos} (m \pi x / a) {\rm cos} (n \pi y / b)\]
\[Q_x = {{16 p_0} \over {\pi^4}} \sum^{\infty}_m \sum^{\infty}_n \Biggl[{{D_x (m^3 \pi / a^3) + H (mn^2 \pi / ab^2)} \over {\beta}}\Biggr] {\rm cos} (m \pi x / a) {\rm sin} (n \pi y / b)\]
\[Q_y = {{16 p_0} \over {\pi^4}} \sum^{\infty}_m \sum^{\infty}_n \Biggl[{{D_y (n^3 \pi / b^3) + H (m^2n \pi / a^2b)} \over {\beta}}\Biggr] {\rm sin} (m \pi x / a) {\rm cos} (n \pi y / b)\]
\[(m,n=1,3,...)\]
\[\beta = mn \Biggl[D_x (m^4 / a^4) + 2H (m^2 n^2 / a^2 b^2) + D_y (n^4 / b^4)\Biggr]\]
\[H = D_{xy} + 2G_{xy}\]

其中 \(D_x\)、\(D_y\)、\(D_{xy}\) 与 \(G_{xy}\) 为刚度。对各向同性板的情形，\(D_x = D_y = H = D = {t^3 \over 12} \bigl({E \over {1 - \nu^2}}\bigr), D_{xy} = \nu D\) 且 \(G_{xy} = \bigl({{1 - \nu} \over 2}\bigr) D\)。

考虑一块 4 × 8 的 3/4 英寸胶合板，由等间距加劲肋（板上下各 1 × 2 木板）加强，并沿各边钉在支承框架上，如 图 2（Figure 2） 所示。该体系在均布荷载下的结构响应可用闭式解近似，因为全部荷载由弯曲作用承受。（部分荷载由膜作用承受的更一般情形见 下文（below）。）板上放置一个矩形箱，箱内干砂装至高度 \(H\)。若箱壁无摩擦，则板承受均布压力 \(p_0 = \gamma H\)，其中 \(\gamma\) 为干砂重度。该问题由以下参数描述（所示值取三位有效数字，实际所用值由给定关系算出）：

\[a = 1.22 \ {\rm m,} \ b = 2.44 \ {\rm m}\]
\[p_0 = \gamma g H = 19.6 \ {\rm kPa} \ (\gamma = 2000 \ {\rm kg/m^3,} \ g = 9.81 \ {\rm m/s^2,} \ H = 1 \ {\rm m})\]
\[t = 19 \ {\rm mm,} \ s = 0.41 \ {\rm m,} \ w = 25 \ {\rm mm,} \ h = 50 \ {\rm mm}\]
\[D_x=H={Et^3 \over {12(1 - \nu^2)}}=5.72\times10^3{\rm Nm}\]
\[D_y={Et^3 \over {12(1 - \nu^2)}}+{E^\prime I \over s}=91.0\times10^3{\rm Nm}\]
\[D_{xy}=0\]
\[E = E^\prime = 10 \ {\rm GPa,} \ \nu = 0\]
\[I = 2 \biggl[{1 \over 12} wh^3 + (wh) \biggl({{t + h} \over 2}\biggr)^2\biggr] = 3.50 \times 10^{-6} {\rm m^4}\]

其中刚度取 Ugural（1981，表 6.1，情形 B）。

输入 FLAC3D 所需的正交各向异性弯曲刚度（假定正交各向异性主方向与 图 1（Figure 1） 与 图 2（Figure 2） 所示 \(x\)、\(y\) 轴对齐）为

\[{c^b_{11}}^\prime = {12 \over t^3} D_x = 10 \ {\rm GPa}\]
\[{c^b_{22}}^\prime = {12 \over t^3} D_y = 159 \ {\rm GPa}\]
\[{c^b_{33}}^\prime = {12 \over t^3} G_{xy} = 5 \ {\rm GPa}\]
\[{c^b_{12}}^\prime = {12 \over t^3} D_{xy} = 0\]

对该体系，全部荷载由弯曲作用抵抗，因此正交各向异性膜刚度无关。若去掉加劲肋，板将为各向同性，\(c^m_{ij} = c^b_{ij} = c_{ij}\) 与 \(c^{\prime}_{11} = c^{\prime}_{22}\) = 10.0 GPa、\(c^{\prime}_{33}\) = 5.0 GPa、\(c^{\prime}_{12}\) = 0。（若木材泊松比不为零，则 \(c^{\prime}_{12}\) 也不为零。）最大挠度出现在板中心。正交各向异性板与各向同性板的理论值分别为 49.9 mm 与 77.0 mm。

图 2：由等间距加劲肋加强的胶合板。

FLAC3D Model

4 × 8 网格的 FLAC3D 模型含 128 个壳单元，如 图 3（Figure 3） 所示。为清晰起见对整个板建模，尽管可用四分之一对称以减小模型规模。四条边的 \(z\) 速度都固定以模拟简支。（尽管经典板理论中简支的恰当边界条件还包括约束绕板平面内垂直于该边的轴的转动，但这种经典边界条件往往使网格过度约束并产生过刚的结果（Cook 1989，第 332 页）。）压力荷载用 structure shell apply 命令施加。采用交叉对角网格模式以确保响应对称。

图 3：矩形板问题（4 × 8 网格）的 FLAC3D 模型。

各向同性情形只施加压力荷载建模，因此无膜荷载。由于这是小应变问题，弯曲与膜响应之间不存在耦合。因此各向同性情形采用 DKT 单元类型（只求解弯曲），且不必提供 \(x\) 与 \(y\) 方向的边界条件。

正交各向异性情形用 “ortho_prop.dat” 中定义的 FISH 函数计算壳性质。

正交各向异性情形还对板的外边缘附加 30 MPa 的膜压力，因此采用默认的 DKT-CST 单元类型。内边缘给定滚轴条件。注意由于弯曲与膜响应不耦合，这不影响与解析解的比较，但模型也检查了膜响应是否正确。若模型处于大应变模式，则当弯曲响应引起 \(z\) 方向位移时会发生耦合。

沿 \(x = a/2\) 与 \(x = a/4\) 线比较理论解与数值解。理论值取无穷级数的前 10 项（\(m\) ≤ 21 且 \(n\) ≤ 21）。挠度的数值取自各条线上节点。应力合力以与全局系对齐的表面坐标系表示。

推广体系以计入膜效应

上述体系只承受弯曲荷载。还通过沿板边界施加面力使正交各向异性体系承受膜荷载。可用 DKT-CST 或 DKT-CST 杂交单元，但本例采用默认的 DKT-CST 单元。除弯曲材料刚度（见 上文方程（equation above））外，还必须指定膜材料刚度，可近似如下。

膜材料刚度的选取，使真实板代表部分（示于 图 2（Figure 2））在 \(x\) 与 \(y\) 两个方向上的膜刚度与正交各向异性壳相同。代表部分是边长 \(s\)、沿 \(x\) 与 \(y\) 方向的方形（见 图 20（Figure 20））。

图 20：板的代表部分。

真实板与正交各向异性壳在 \(x\) 与 \(y\) 方向上的膜刚度（\(AE/L\)）为

\[k_x = {{(st) E} \over s}, \ k_y = {{(st) E + (2wh)E^{\prime}} \over s} \ \ ({\rm real \ sheet})\]
\[k_x = {{(st) E_x} \over s} = tE_x, \ k_y = {{(st) E_y} \over s} = tE_y \ \ ({\rm orthotropic \ shell})\]

其中 \(s\)、\(t\)、\(E\) 与 \(E^{\prime}\) 定义于 上文方程（equation above），\(E_x\) 与 \(E_y\) 为等效模量（Ugural 1981，第 141 页）。等效模量通过令相应刚度相等求得：

\[E_x = E, \ E_y = E + \biggl({2wh \over st}\biggr)E^{\prime}\]

输入 FLAC3D 所需的正交各向异性膜刚度为

\[{c^m_{11}}^{\prime} = {E_x \over {1 - \nu_x \nu_y}}\]
\[{c^m_{22}}^{\prime} = {E_y \over {1 - \nu_x \nu_y}}\]
\[{c^m_{33}}^{\prime} = G\]
\[{c^m_{12}}^{\prime} = {{E_x \nu_y} \over {1 - \nu_x \nu_y}} = {{E_y \nu_x} \over {1 - \nu_x \nu_y}}\]

其中 \(\nu_x\) 与 \(\nu_y\) 为有效泊松比，\(G\) 为剪切模量。该表达式使用了 结构单元 一节壳单元性质讨论中的 本方程（this equation）。若假定 \(\nu_x = \nu_y\) = 0 且 \(G = E/2\)，则：

\[{c^m_{11}}^{\prime} = 10 {\rm \ GPa}\]
\[{c^m_{22}}^{\prime} = 13.2 {\rm \ GPa}\]
\[{c^m_{33}}^{\prime} = 5 {\rm \ GPa}\]
\[{c^m_{12}}^{\prime} = 0\]

上述体系具有作用于整个板边界的 30 MPa 均匀膜应力。\(x\) = 0 与 \(y\) = 0 处的边给定滚轴边界条件，\(x = a\) 与 \(y = b\) 处的边用 结构节点施加力边（structure node apply force-edge） 命令加载，其取值计入壳厚度。每个节点承担沿其 tributary 面积作用的总力。[2] 对这些条件，板内应力将均匀，且等于

\[\sigma_{xx} = \sigma_{yy} = 30 \ {\rm MPa,} \ \ \tau_{xy} = 0\]

沿 \(x = a\) 与 \(y = b\) 处边的位移将均匀，且等于

\[\Delta_x = \biggl({\sigma_m \over {c^m_{11}}^{\prime}}\biggr) a = 3.66 \ {\rm mm,} \ \ \Delta_y = \biggl({\sigma_m \over {c^m_{22}}^{\prime}}\biggr) b = 5.55 \ {\rm mm}\]

4 × 8 网格的结果如下。

\[\sigma_{xx} = \sigma_{yy} = 30 \ {\rm MPa,} \ \ \tau_{xy} \approx 0\]
\[\Delta_x = 3.660 \ {\rm mm,} \ \ \Delta_y = 5.542 \ {\rm mm}\]

ortho_prop.dat

; 根据下列输入计算正交各向异性壳参数 
;    e = 壳的杨氏模量，
;    t = 壳厚， 
;    nu = 壳的泊松比， 
;    swidth = 加劲肋宽度，
;    sheight = 加劲肋高度， 
;    se = 加劲肋刚度，以及 
;    sspace = 加劲肋间距
; 返回包含膜刚度和弯曲刚度的 4x1 数组， 
; 存于全局量 memb_stiff 和 bend_stiff。
; 还将抗弯刚度存入全局映射 rigidity
fish automatic-create off
fish define ortho_prop(e,t,nu,swidth,sheight,se,sspace)
    global rigidity = map
    rigidity('Dxy') = 0.0
    rigidity('Dx')  = e * t^3 / (12.0*(1.0 - nu^2))
    rigidity('H')   = rigidity('Dx')
    rigidity('Gxy') = (rigidity('H') - rigidity('Dxy')) / 2.0
    local Iv = swidth*sheight*sheight*sheight / 12.0
          Iv = Iv + (swidth*sheight*(t + sheight)^2) / 4.0
          Iv = 2.0 * Iv
    rigidity('Dy') = rigidity('Dx') + (se * Iv) / sspace
    
    global bend_stiff = matrix(4,1)
    bend_stiff(1,1) = (12.0 / t^3) * rigidity('Dx')
    bend_stiff(2,1) = (12.0 / t^3) * rigidity('Dxy')
    bend_stiff(3,1) = (12.0 / t^3) * rigidity('Dy')
    bend_stiff(4,1) = (12.0 / t^3) * rigidity('Gxy')
    
    ; 膜刚度，仅用于 membrane.f3dat
    global memb_stiff = matrix(4,1)
    memb_stiff(1,1) = e
    memb_stiff(2,1) = 0.0
    memb_stiff(3,1) = e + (2.0 * swidth * sheight / (sspace * t)) * se
    memb_stiff(4,1) = e / 2.0
end
