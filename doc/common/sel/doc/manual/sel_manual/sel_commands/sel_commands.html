对结构单元进行操作的命令。本页内容：

  • link 命令（link commands）

结构单元是基于显式有限单元、用壳与梁理论表述的对象。与网格单元一样，所有单元的力-位移计算均为增量形式。

各单元通过结构节点与其他单元相连。与其他对象（主要是网格单元）的相互作用由与节点关联的结构连接处理。

共支持六种结构单元——每种都规定默认的内部行为与默认的连接表述。其中三个为线性单元（beam、cable 与 pile），三个为二维板类单元（shell、liner 与 geogrid）。

结构单元逻辑在处理 id 号的方式上与其他模块不同。在本模块中，id 号指单元的集合，用于标识由任意数目单个单元构成的某根梁或锚索结构。每个单元由component-id 号标识，该号对每个单元唯一。节点与连接可按 id 号选择，即选择附着于具有该编号单元集合的节点。节点与连接也有各自的 component-id 号。

更多细节见 结构单元逻辑的一般表述（General Formulation of Structural-Element Logic）。
