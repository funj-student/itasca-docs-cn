structure results 命令

语法

structure results keyword

主要关键字：

活动（active）    displacements    extra    forces    groups    链接（links）    参数（properties）    导出速度（velocities）

控制导出结果文件中是否保存网格单元取值以及保存哪些取值。见 导出模型结果（model results export） 命令。默认情况下网格单元取值为 active。默认导出的取值为 forces、groups 与 displacements。

active b

控制是否导出任何结构单元取值

displacements b

节点处的位移向量

extra b

单元、节点与连接处的所有额外变量

forces b

节点处的力信息，包括应力恢复所需的节点力

groups b

赋给单元、节点与连接的组赋值

links b

存储所有连接信息，包括模型与性质

properties b

单元属性

velocities b

节点处的速度向量
