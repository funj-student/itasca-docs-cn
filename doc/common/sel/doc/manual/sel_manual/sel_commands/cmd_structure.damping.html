structure damping 命令

语法

structure damping keyword

主要关键字：

combined-local    local    none    瑞利（rayleigh）

设置结构单元逻辑的阻尼方案。该命令已弃用。请改用静态模式下的 structure mechanical damping 命令或动力模式下的 structure dynamic damping。该设置的取值可用 structure list information 命令打印。可用以下关键字：

combined-local

把结构单元逻辑所用阻尼方案设为组合局部阻尼。局部阻尼常数按节点分别存储，并由命令 structure node damping-local 设置。

local

把结构单元逻辑所用阻尼方案设为局部阻尼。这是静态模式的默认设置。局部阻尼常数按节点分别存储，并由命令 structure node damping-local 设置。

none

把结构单元逻辑所用阻尼方案设为无阻尼。这是动力模式的默认设置。

rayleigh f1 f2

把结构单元逻辑所用阻尼方案设为 Rayleigh 阻尼。刚度比例常数为 f1 = beta，质量比例常数为 f2 = alpha。该命令必须在已配置并开启动力选项时使用。
