struct.shell.prop.ortho

语法

l := struct.shell.prop.ortho(p,itype)
struct.shell.prop.ortho(p,itype) := l

获取/设置正交各向异性材料性质，形式为 4 个值的列表。

膜刚度由 接触类型ID（itype） = 1 表示，弯曲刚度由 接触类型ID（itype） = 2 表示。

若该单元不具有正交各向异性性质，则产生错误。

见 structure shell property、structure geogrid property 与 structure liner property 命令。

在循环过程中修改单元刚度可能引起不稳定。应使用 结构单元几何更新标志（struct.force.update） 强制更新相关值。关于其代价的说明见 结构单元几何更新标志（struct.force.update） 的文档。

返回值：

l - 接触类型ID（itype） 对应的壳正交各向异性材料刚度系数
接受：

l - 接触类型ID（itype） 对应的壳正交各向异性材料刚度系数
参数：

p - 指向壳单元的指针

接触类型ID（itype） - 表示膜刚度（1）或弯曲刚度（2）
