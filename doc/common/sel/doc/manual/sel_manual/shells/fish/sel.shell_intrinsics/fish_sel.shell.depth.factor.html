struct.shell.depth.factor

语法

f := struct.shell.depth.factor(p)

获取已恢复应力的深度因子。深度等于 \(Ft/2\)，其中 \(t\) 为壳单元厚度。+1.0 或 -1.0 的 \(F\) 值对应壳外/内表面。外表面由局部壳单元系的正 \(z\) 方向定义。0.0 的 \(F\) 值对应壳中面。深度因子可用 恢复壳单元应力命令（structure shell recover stress）、恢复土工格栅单元应力命令（structure geogrid recover stress） 或 恢复衬砌单元应力命令（structure liner recover stress） 命令修改。

返回值：f - 已恢复应力的深度因子
参数：p - 指向壳单元的指针
