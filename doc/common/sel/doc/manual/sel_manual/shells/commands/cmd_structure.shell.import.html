structure shell import 命令

语法

structure shell import keyword

主要关键字：

从文件导入（from-file）    按几何集生成（from-geometry）

由外部来源创建壳单元。

from-file s [shellimportblock]

由几何文件 s 创建单元。

from-geometry s [shellimportblock] <range>

由名为 s 的几何集合创建单元。范围作用于该几何集合中的边列表。


structure shell import 关键字块

以下任何关键字都可选择性地提供，与 structure shell import 的主要关键字配合使用：从文件导入（from-file） 与 按几何集生成（from-geometry）。

cross-diagonal <b >

若指定，则创建由四个三角形构成的对角交叉网格，并在所有四边形的形心处设一个节点；否则创建由两个三角形构成的交叉网格来划分该四边形。

把单元连接到网格时，最好把节点置于网格点处。若有限单元类型能抵抗弯曲（DKT、DKT-CST 或 DKT-CST 杂交单元），则单元面与网格单元面之间可能出现不协调，因为横向（平面外）位移场在单元面上按三次变化，而在网格单元面上仅按线性变化。因此把抗弯单元与网格单元面刚性连接时，最好采用交叉 hatch 网格，因为交叉对角网格的中间节点将被迫按网格单元面的线性位移场平动。这会使单元过度约束，在存在非零力矩场时可能在这些中间节点处产生近零力矩。

distinct

取消所创建单元之间的节点共享。每个单元都会新建一组节点，即便它们位于相同空间位置且单元共享相同 ID 号。该选项最常与后续 structure node join 命令配合，在相同位置节点之间创建连接以实现自定义单元间行为。

element-type keyword

指定各结构单元所用的有限元表述。若未指定单元类型，则单元类型为 DKT-CST。注意有限元类型在创建时即与各结构单元关联，此后不可更改。已有结构单元的有限元类型由 结构壳单元列表元素类型（structure shell list element-type） 命令打印。所给关键字的值必须是以下三节点有限单元之一：

s

尝试把字符串 s 与下文某个可用关键字匹配，并按该选项处理

cst

CST（6 自由度）有限单元。这是膜单元；它承受膜荷载但不承受弯曲荷载。

csth

CST 杂交（9 自由度）有限单元。这是膜单元；它承受膜荷载但不承受弯曲荷载。

dkt

DKT（9 自由度）有限单元。这是板弯曲单元；它承受弯曲荷载但不承受膜荷载。

dkt-cst

DKT-CST（15 自由度）有限单元。这是结合 DKT 与 CST 单元的壳单元，可同时承受弯曲与膜荷载。

dkt-csth

DKT-CST 杂交（18 自由度）有限单元。这是结合 DKT 与 CST 杂交单元的壳单元，可同时承受弯曲与膜荷载。

format keyword

指定文件格式。只能与 from-file 关键字一起给出。

该关键字只能与 structure shell import 命令的以下关键字一起使用：from-file。

dxf

指定 DXF 文件格式。

geom

指定几何文件格式。

stl

指定 STL 文件格式。

group s1 <slot s2 >

把所创建的单元赋给组 s1。若提供 s2，则该组被赋给该名称的槽位；否则赋给名为 默认（Default） 的槽位。组逻辑的用法见 组（Groups）。

id i

指定将赋给该命令所创建的全部新单元的 ID。若未给出该值，则使用下一个可用 ID。该 ID 按下述方式控制单元节点与已有单元的可能连接：在每个潜在新节点位置都会新建节点，除非同时满足以下条件：1) 已给出 ID；2) 在潜在新节点位置附近找到已有节点；3) 所找到的节点属于 ID 等于 i 的同类型单元。

internal

该关键字仅在使用了 from-faces 选项时适用。它指定范围内所有内部面与表面都将在其上创建单元。通常只考虑表面。

maximum-length f

把单元分成长度不超过 f 的各段。若同时给出 segments 设置，则按需被该设置覆盖。

offset v

指定壳的平动偏移量。

segments i

把单元分成 i 个等长段，按需创建新节点。默认值为 1，表示只创建一个单元。
