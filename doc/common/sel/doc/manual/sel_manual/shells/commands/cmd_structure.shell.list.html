structure shell list 命令

语法

structure shell list keyword <range>

主要关键字：

apply    depth-factor    element-type    分组（group）    information    节点力（force-node）    property    合力（resultant）    应力（stress）    stress-principal    system-local

列出范围内各壳单元的性质与响应。

apply

作用于单元的均布压力

depth-factor

应力恢复中所用深度因子

element-type

所用有限单元类型

group <slot s >

列出该单元的组赋值。若提供 slot，则列出该单元在槽位 s 中的组赋值（若有）。

information

列出单元一般信息，包括 id 与 component-id 号、相连节点、形心、表面积、体积以及隐藏与选择状态

force-node keyword

列出节点力。默认情况下分量按单元局部坐标系显示。这些是节点施加在单元上的力。

local

按单元局部坐标系列出力（默认）

global

按全局坐标系列出力

property keyword
density

密度，\(ρ\)

thickness

壳厚度

thermal-expansion

热膨胀系数

anisotropic-membrane

anisotropic membrane material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{13}, c^{\prime}_{22}, c^{\prime}_{23}, c^{\prime}_{33}\)}

anisotropic-bending

anisotropic bending material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{13}, c^{\prime}_{22}, c^{\prime}_{23}, c^{\prime}_{33}\)}

material-x

用于确定材料坐标系局部 \(x\) 方向的向量

isotropic

各向同性材料性质：\(E\) 与 \(v\)，其中 \(E\) 为杨氏模量 \([F/L^2\)\(]\)，\(v\) 为泊松比

orthotropic-membrane

orthotropic membrane material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{22}, c^{\prime}_{33}\)}

orthotropic-bending

orthotropic membrane material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{22}, c^{\prime}_{33}\)}

resultant <nodes>

用 恢复壳单元合力命令（structure shell recover resultants） 命令最后计算的八个应力合力量。若给出 nodes 关键字，则除单元形心处取值外，还在单元各节点处给出这些量的取值。

stress <nodes>

用 恢复壳单元应力命令（structure shell recover stress） 命令计算的应力状态。若给出 nodes 关键字，则除单元形心处取值外，还在单元各节点处给出这些量的取值。

stress-principal <nodes>

用 恢复壳单元应力命令（structure shell recover stress） 命令计算的主应力。若给出 nodes 关键字，则除单元形心处取值外，还在单元各节点处给出这些量的取值。

system-local

单元局部坐标系
