struct.maxid

语法

i := struct.maxid()

获取本模型中赋给任何结构单元的最大 component-ID 号。下一个创建的单元将被赋予该值加一。

注意

与 FLAC3D 中其他对象不同，结构对象（单元、连接与节点）的 ID 号指一起创建、代表单个整体结构的单元及相关对象的集合。对结构对象，与对象关联的内部赋予的唯一 ID 号称为 component-ID 号。见 结构单元组件ID（struct.id.component） 函数。

返回值：i - 模型中任何结构单元的最大 component-ID 号。
