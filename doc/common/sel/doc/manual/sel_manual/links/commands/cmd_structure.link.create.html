structure link create 命令

语法

structure link create keyword ... <range>

主要关键字：

默认附着（default-attach）    按节点 ID（on-nodeid）    偏移量（offset）    侧（side）    target    目标范围（target-range）    分组（group）

在范围内结构节点上创建新连接。若该节点已有关联连接，则忽略。已有连接可用 structure link delete 命令删除。若未提供源与目标 ID 号，则该命令会在范围内所有潜在新连接的有效目标中自动搜索。

default-attach b

默认情况下，用该命令在侧一创建的连接在全部六个自由度上均为刚性连接，在侧二创建的连接在全部六个自由度上均为自由连接。把该关键字设为 真值（true） 后，所创建连接将获得与其宿主节点所连第一个单元相关的默认附着条件。该设置与 target node 不兼容。请注意，只有这样才能让单元把性质值传递给各自由度的连接模型；否则即便连接模型与单元所期望的相符，也不会发生传递。

on-nodeid i
指定要在其上创建连接的具体节点 component-id 号。
若使用该关键字，则不使用范围短语。若使用 target 关键字并给出具体 id，则必须用 on-nodeid 指定源节点。
offset v
未指定具体目标时，可用偏移向量搜索不位于源节点位置处的节点或网格单元。
所检查的位置为源节点位置加偏移向量 v。注意若目标为网格单元且使用了偏移，则应通过单元的 sliding 性质关闭大应变滑动更新。
side i
指定附着于嵌入式衬砌单元的节点上，连接应附着于哪一侧。
默认值为侧 1。必须为 1 或 2。
target keyword
标识目标实体。
若未提供 target，则使用默认目标 zone。
zone <i >
指定连接应寻找网格单元作为目标。
若未指定 i，则使用与源节点距离 δ 以内的非空网格单元。若指定 i，则当该网格单元非空且源节点距其边界在 δ 以内时使用它。（δ 的定义见前述讨论。）
node <i >
指定连接应寻找节点作为目标。
若未指定 i，则使用与源节点距离 δ 以内的节点。若指定 i，则两节点必须相互邻近才能创建连接。“邻近”定义为彼此距离在 δ 以内，其中 δ 为节点容差的全局值（见 structure link tolerance-contact 命令）。若连接位于侧 1，则新连接的附着条件在全部六个方向上设为“刚性”；若位于侧 2，则设为“自由”。
target-range keyword ...

指定用于过滤目标对象（由 target 关键字指定）的范围。只有落在该范围内的对象才会被考虑用于创建连接。默认情况下将考虑该类型的所有对象。

范围短语中可包含的范围元素与控制关键字清单见 范围短语（Range Phrase） 文档。注意此处不使用 range 关键字。

group s1 <slot s2 >
把所创建的连接赋给名为 s1 的组。
若提供可选 slot s2，则该组被赋给名为 s2 的槽位；若省略，则该组被赋给名为 默认（Default） 的槽位。组逻辑的用法见 组（Groups）。

用法示例

下例将在已赋予组名 第一（First） 的衬砌单元所连节点的侧 2 上，为所有连接创建到网格单元的连接。

structure link create target zone side 2 range group 'First'

下例将对与组名 连接（Connection） 关联的所有节点，若该位置处存在另一节点，则创建到节点的连接。

structure link create target node range group 'Connection'

下例将在 component-id 为 5 的节点与其位置容差范围内找到的第一个节点之间创建连接。

structure link create on-nodeid 5 target node

下例将在 component-id 为 5 的节点与 component-id 为 16 的节点之间创建连接。

structure link create on-nodeid 5 target node 16
