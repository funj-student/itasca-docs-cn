structure link attach 命令

语法

structure link attach keyword ... <range>

主要关键字：

x    y    z    rotation-x    rotation-y    rotation-z

为所指定的连接方向设置附着条件。当前附着条件将被此处指定的条件替换。条件以关键字对形式指定：第一个（keyword）为自由度，第二个（[linkattachblock]）为所用条件类型。可用以下关键字指定自由度：

x [linkattachblock]

平动 \(x\) 方向，即自由度 1

y [linkattachblock]

平动 \(y\) 方向，即自由度 2

z [linkattachblock]

平动 \(z\) 方向，即自由度 3

rotation-x [linkattachblock]

转动 \(x\) 方向，即自由度 4

rotation-y [linkattachblock]

转动 \(y\) 方向，即自由度 5

rotation-z [linkattachblock]

转动 \(z\) 方向，即自由度 6


关键字块

附着条件由以下取值给出，它们分别作用于：rotation-x、rotation-y、rotation-z、x、y 与 z。

free

free

linear

可变形线性弹簧

normal-yield

可变形法向屈服弹簧

pile-yield

桩屈服弹簧。该条件仅在 \(x\) 或 \(y\) 平动自由度中可用，其从属模型分别自动安装于 \(y\) 或 \(z\)。

rigid

rigid

shear-yield

剪切屈服可变形弹簧（仅可用于平动自由度）
