对结构单元连接的操作。

连接是结构单元逻辑跟踪与周围对象相互作用的方式。连接有两类，取决于所相互作用的对象。目前结构单元逻辑支持节点->节点连接与节点->网格单元连接，将来会增加更多相互作用类型。

每个连接在全部六个自由度上支持不同的相互作用——连接的坐标系始终是宿主节点的局部坐标系。

默认情况下，连接性质与相互作用细节由其相连的单元提供。
