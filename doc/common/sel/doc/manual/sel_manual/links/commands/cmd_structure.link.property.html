structure link property 命令

语法

structure link property keyword ... <range>

主要关键字：

x    y    z    rotation-x    rotation-y    rotation-z

列出连接中 keyword 所指定自由度处可变形力-位移模型的某个性质。各连接本构模型可用性质的清单见 结构单元连接性质（Structural Element Link Properties）。

x <[linkpropertyblock]>

平动 \(x\) 方向，即自由度 1

y <[linkpropertyblock]>

平动 \(y\) 方向，即自由度 2

z <[linkpropertyblock]>

平动 \(z\) 方向，即自由度 3

rotation-x <[linkpropertyblock]>

转动 \(x\) 方向，即自由度 4

rotation-y <[linkpropertyblock]>

转动 \(y\) 方向，即自由度 5。

rotation-z <[linkpropertyblock]>

转动 \(z\) 方向，即自由度 6。


关键字块

以下关键字指代一个或多个连接本构模型中可用的性质名称。作为性质值使用的数据类型各不相同：通常为单个实数值，但也可能多于一个值，或完全为另一种类型。可用性质名称为：rotation-x、rotation-y、rotation-z、x、y 与 z。

area f

与连接关联的面积。默认值为 1.0。该值适用于所有当前可变形连接模型。

cohesion f

围压为零时的单位面积极限力。默认值为 0.0。该值适用于剪切屈服与桩屈服模型。

cohesion-table s

用于把黏聚力与相对位移关联的表格名称。默认值为空，表示不启用黏聚力的表格查找。该值适用于剪切屈服模型。

confinement-table s

用于把围压调整因子与围压中剪切成份量关联的表格名称。默认值为空，表示不启用围压的表格查找。该值适用于剪切屈服模型。

friction f

摩擦角（度），作为围压的函数修正极限力。默认值为 0.0。该值适用于剪切屈服与桩屈服模型。

friction-table

用于把摩擦与相对位移关联的表格名称。默认值为空，表示不启用摩擦的表格查找。该值适用于剪切屈服模型。

gap b

标志，表示间隙跟踪将影响行为。默认值为 关闭（off）。该值适用于法向屈服与桩屈服模型。

incremental-confinement-flag

增量围压标志——围压按相对初始应力状态的差值计算。默认值为 关闭（off）。该值适用于剪切屈服模型。

perimeter f

为计算性质之目的，与连接相连结构的有效周长。默认值为 0.0。该值适用于剪切屈服模型。

stiffness f

弹簧刚度。默认值为 1.0。该值适用于所有当前可变形连接模型。

yield-compression f

由负相对位移（目标减源）产生的力的负限值。默认值为 0.0。该值适用于法向屈服模型。

yield-tension f

由负相对位移（目标减源）产生的力的正限值。默认值为 0.0。该值适用于法向屈服模型。
