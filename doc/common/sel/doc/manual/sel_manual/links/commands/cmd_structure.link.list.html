structure link  list 命令

语法

structure link list keyword <range>

主要关键字：

attach    displacement    力（force）    property    slide    slide-tolerance    source-node    状态（state）    target

列出范围内连接对象的取值与信息。

attach

附着条件

displacement

各自由度中的相对位移

force

各自由度中所施加的力

property <s >

列出与当前模型关联的连接性质。s 的取值对应所需性质。[DR：请协助明确下一句的处理方式] 关于各可变形模型所对应性质的清单，见 :flag2:-此处链接至可用连接力-位移模型的讨论-。

slide

滑动标志

slide-tolerance

滑动容差

source-node

源节点——连接从此节点发出

state

各具有可变形力-位移模型的自由度的破坏状态

target

连接类型：节点-网格单元或节点-节点，以及该连接具体目标的 component-id
