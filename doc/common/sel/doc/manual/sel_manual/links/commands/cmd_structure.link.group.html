structure link group 命令

语法

structure link group s1 <keyword> <range>

主要关键字：

槽位（slot）    remove

把范围内所有连接赋给名为 s 的组。组逻辑的用法见 组（Groups）。在给定槽位中一个连接只能属于一个组；把单元赋给该槽位中的新组会使它从原组赋值中移除。structure link list 命令列出已有的连接组名。

组与槽位都可编码进单个字符串 s。为此请使用组合 “slotname=groupname”，其中等号左侧名称为槽位，右侧名称为组。

slot s

把该组赋给槽位 s。若省略，则该组被赋给名为 默认（Default） 的槽位。

remove

从指定槽位移除所指定的组。若未指定槽位，则从该组所在的所有槽位移除。
