struct.link.delete

语法

i := struct.link.delete(p)

删除该结构连接。返回值被忽略。

若在多线程环境中调用，实际删除可能被延迟。

返回值：i - 整数 0
参数：p - 指向结构连接的指针；删除后该指针将失效（并被设为 无接触（null））
