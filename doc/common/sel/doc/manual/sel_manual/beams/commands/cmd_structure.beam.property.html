structure beam property 命令

语法

structure beam property keyword ... <range>

主要关键字：

density    youngs    poisson    plastic-moment    thermal-expansion    cross-sectional-area    moi-y    moi-z    moi-polar    direction-y

为范围内的单元赋予某个性质。可用以下性质。

density f

密度（动力模式或重力启用时需要），\(ρ\)

youngs f

杨氏模量，\(E\)

poisson f

泊松比 \(ν\)

plastic-moment f

塑性弯矩承载力 \(M^P\)

thermal-expansion f

热膨胀系数 \(α_t\)

cross-sectional-area f

横截面积 \(A\)

moi-y f

关于局部 \(y\) 轴的二次矩 \(I_y\)

moi-z f

关于局部 \(z\) 轴的二次矩 \(I_z\)

moi-polar f

极惯性矩 \(J\)

direction-y v

\(y\) 轴向量的分量（Yx、Yy、Yz），其在单元横截面上的投影定义单元体系的 \(y\) 轴
