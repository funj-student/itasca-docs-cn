structure pile history 命令

语法

structure pile history keyword

主要关键字：

法向位移耦合（coupling-displacement-normal）    法向应力耦合（coupling-stress-normal）    coupling-yield-normal    剪切位移耦合（coupling-displacement-shear）    剪切应力耦合（coupling-stress-shear）    剪切屈服耦合（coupling-yield-shear）    力（force）    force-x    force-y    force-z    moment    x 向弯矩（moment-x）    y 向弯矩（moment-y）    z 向弯矩（moment-z）

桩响应采样。可采样的量包括作用于桩本身的力与力矩，以及法向与剪切耦合弹簧中的位移、应力与屈服状态。

若桩是用 structure pile create 命令创建的，则如此创建的每个单元的节点将按整体桩方向从起点指向终点排序（即每个单元的节点连接使从 v1 到 v2 的方向与从起点到终点的方向一致）。

coupling-displacement-normal [pilehistoryblock]

单元端部法向耦合弹簧中的位移。法向弹簧的符号约定为 +/-，表示分离/重叠。

coupling-stress-normal [pilehistoryblock]

单元端部法向耦合弹簧中的应力。法向弹簧的符号约定为 +/-，表示分离/重叠。

coupling-yield-normal [pilehistoryblock]

单元端部法向耦合弹簧的屈服状态。取值 {0, 1, 2} 分别表示从未屈服、正在屈服或曾经屈服。

coupling-displacement-shear [pilehistoryblock]

单元端部剪切方向耦合弹簧中的位移。剪切弹簧的符号约定为 +/-（相对桩的平均轴向方向）。

coupling-stress-shear [pilehistoryblock]

单元端部剪切方向耦合弹簧中的应力。剪切弹簧的符号约定为 +/-（相对桩的平均轴向方向）。

coupling-yield-shear [pilehistoryblock]

单元端部剪切耦合弹簧的屈服状态。取值 {0, 1, 2} 分别表示从未屈服、正在屈服或曾经屈服。

force [pilehistoryblock]

力的大小

force-x [pilehistoryblock]

力（\(x\) 分量，单元系）

force-y [pilehistoryblock]

力（\(y\) 分量，单元系）

force-z [pilehistoryblock]

力（\(z\) 分量，单元系）

moment [pilehistoryblock]

力矩大小

moment-x [pilehistoryblock]

力矩（\(x\) 分量，单元系）

moment-y [pilehistoryblock]

力矩（\(y\) 分量，单元系）

moment-z [pilehistoryblock]

力矩（\(z\) 分量，单元系）


structure pile history 关键字块

必须提供 cid 关键字或 position 关键字。end 关键字可选。法向位移耦合（coupling-displacement-normal）、剪切位移耦合（coupling-displacement-shear）、法向应力耦合（coupling-stress-normal）、剪切应力耦合（coupling-stress-shear）、coupling-yield-normal、剪切屈服耦合（coupling-yield-shear）、力（force）、force-x、force-y、force-z、moment、x 向弯矩（moment-x）、y 向弯矩（moment-y） 与 z 向弯矩（moment-z）。

component-id i

具体单元由 CID 号标识。若使用该关键字，则不应使用 position。

end i

该量在端部 i（其中 i 为 1 或 2）采样，与节点连接列表的顺序一致。若未给出该关键字，则在端部 1（默认）采样历史记录。

position v

该特定单元由坐标（v）标识（取最近的单元）。若使用该关键字，则不应使用 component-id。
