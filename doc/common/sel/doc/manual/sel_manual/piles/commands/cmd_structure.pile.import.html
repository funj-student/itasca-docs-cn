structure pile import 命令

语法

structure pile import keyword

主要关键字：

从挤出器（from-extruder）    从文件导入（from-file）    按几何集生成（from-geometry）

由外部来源创建桩单元。

from-extruder s [pileimportblock] <range>

由名为 s 的挤出器集合创建单元。范围作用于该挤出器集合中的边列表。

from-file s [pileimportblock]

由几何文件 s 创建单元。

from-geometry s [pileimportblock] <range>

由名为 s 的几何集合创建单元。范围作用于该几何集合中的边列表。


structure pile import 关键字块

以下任何关键字都可选择性地提供，与 structure pile import 的主要关键字配合使用：从挤出器（from-extruder）、从文件导入（from-file） 与 按几何集生成（from-geometry）。

distinct

取消所创建单元之间的节点共享。每个单元都会新建一组节点，即便它们位于相同空间位置且单元共享相同 ID 号。该选项最常与后续 structure node join 命令配合，在相同位置节点之间创建连接以实现自定义单元间行为。

format keyword

指定文件格式。只能与 from-file 关键字一起给出。

该关键字只能与 structure pile import 命令的以下关键字一起使用：from-file。

dxf

指定 DXF 文件格式。

geom

指定几何文件格式。

stl

指定 STL 文件格式。

group s <slot s >

把所创建的单元赋给组 s。组逻辑的用法见 组（Groups）。若未指定，默认组名为 桩单元数量（Pile N），其中 N 为赋给这些单元的 ID 号。

group-begin s <slot s >

沿直线所创建单元的第一个节点将被赋予的组名。默认名称为 桩单元开始（Pile Begin）。

group-end str:`s` <slot s >

沿直线所创建单元的最后一个节点将被赋予的组名。默认名称为 桩单元结束（Pile End）。

id i

指定将赋给该命令所创建的全部新单元的 ID。若未给出该值，则使用下一个可用 ID。该 ID 按下述方式控制两个单元端节点与已有单元的可能连接：在每个端节点位置都会新建节点，除非同时满足以下条件：1) 已给出 ID；2) 在潜在新节点位置“附近”找到已有节点；3) 所找到的节点属于 ID 等于 i 的单元。

maximum-length f

把单元分成长度不超过 f 的各段。若同时给出 segments 设置，则按需被该设置覆盖。

segments i

把单元分成 i 个等长段，按需创建新节点。默认值为 1。

snap <b >

表示所创建单元的首末位置将尝试“吸附”到单元长度一半半径内最近的结构节点（附着于任何单元类型）的位置。若只一端以这种方式吸附，则所创建的整条线将按原位置与吸附位置之差整体偏移。
