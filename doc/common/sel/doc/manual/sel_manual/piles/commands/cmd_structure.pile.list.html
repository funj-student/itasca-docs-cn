structure pile list 命令

语法

structure pile list keyword

主要关键字：

apply    coupling-confinement    coupling-normal    coupling-shear    coupling-yield    force-end    节点力（force-node）    分组（group）    information    长度（length）    property    system-local

列出桩的信息。

apply

所施加的分布荷载

coupling-confinement

垂直于单元作用的围压，含两个主值

coupling-normal

法向耦合弹簧的取值，包括位移、应力与方向

coupling-shear

剪切方向耦合弹簧的取值，包括位移、应力与方向

coupling-yield

剪切与法向耦合弹簧的状态，以及当前间隙值

force-end

端部节点施加在单元上的力，按单元局部坐标给出

force-node keyword

列出节点力。默认情况下分量按单元局部坐标系显示。这些是节点施加在单元上的力。

local

按单元局部坐标系列出力（默认）

global

按全局坐标系列出力

group <slot s >

列出该单元所属的组。默认列出所有具有组赋值的槽位。若使用 slot 关键字，则只列出该槽位的内容。

information

列出单元一般信息，包括 id 与 component-id 号、相连节点、形心、表面积、体积以及隐藏与选择状态

length

单元长度

property keyword ...

用以下关键字之一列出某个桩性质

density

密度，\(ρ\)

young

杨氏模量，\(E\)

plastic-moment

塑性弯矩 \(M^P\)

poisson

泊松比 \(ν\)

thermal-expansion

热膨胀系数 \(α_t\)

cross-sectional-area

横截面积 \(A\)

moi-y

关于局部 \(y\) 轴的二次矩 \(I_y\)

moi-z

关于局部 \(z\) 轴的二次矩 \(I_z\)

moi-polar

极惯性矩 \(J\)

direction-y

\(y\) 方向向量的分量

slide

滑动标志

slide-tolerance

滑动容差

coupling-confining-flag

激活增量围压逻辑的标志（默认：关闭（off））

coupling-confining-table

把有效围压因子与偏应力关联的表格名称

coupling-cohesion-normal

法向耦合弹簧黏聚强度 \(c_n\)

coupling-cohesion-shear

剪切耦合弹簧黏聚强度 \(c_s\)

coupling-cohesion-table

把剪切耦合弹簧的黏聚力与相对剪切位移关联的表格名称

coupling-friction-normal

法向耦合弹簧摩擦角 \(φ_n\)

coupling-friction-shear

剪切耦合弹簧摩擦角 \(φ_s\)

coupling-friction-table

把剪切耦合弹簧的摩擦角与相对剪切位移关联的表格名称

coupling-gap-normal

法向耦合弹簧间隙启用标志 \(g\)

coupling-stiffness-normal

法向耦合弹簧刚度 \(k_n\)

coupling-stiffness-shear

剪切耦合弹簧刚度 \(k_s\)

perimeter

外露周长 \(p\)

rockbolt-flag

激活锚杆逻辑的标志（默认：关闭（off））

tensile-failure-strain

拉伸破坏应变（无量纲）

tensile-yield

轴向抗拉屈服强度（力单位），[F]

system-local

单元局部坐标系
