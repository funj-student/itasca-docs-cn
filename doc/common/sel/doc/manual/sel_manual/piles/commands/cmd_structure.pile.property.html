structure pile property 命令

语法

structure pile property keyword ... <range>

主要关键字：

coupling-cohesion-normal    coupling-cohesion-shear    coupling-cohesion-table    coupling-confining-flag    coupling-confining-table    coupling-friction-normal    coupling-friction-shear    coupling-friction-table    coupling-gap-normal    coupling-stiffness-normal    coupling-stiffness-shear    cross-sectional-area    density    direction-y    moi-polar    moi-y    moi-z    perimeter    plastic-moment    塑性弯矩 y（plastic-moment-y）    塑性弯矩 z（plastic-moment-z）    poisson    rockbolt-flag    slide    slide-tolerance    tensile-failure-strain    yield-compression    yield-tension    thermal-expansion    young

把所指定的性质赋给范围内的所有单元。

coupling-cohesion-normal f

法向耦合弹簧黏聚强度 \(c_n\)

coupling-cohesion-shear f

剪切耦合弹簧黏聚强度 \(c_s\)

coupling-cohesion-table s

把剪切耦合弹簧的黏聚力与相对剪切位移关联的表格名称

coupling-confining-flag b

激活增量围压逻辑的标志（默认：关闭（off））

coupling-confining-table s

把有效围压因子与偏应力关联的表格名称

coupling-friction-normal f

法向耦合弹簧摩擦角 \(f_n\)

coupling-friction-shear f

剪切耦合弹簧摩擦角 \(f_s\)

coupling-friction-table s

把剪切耦合弹簧的摩擦角与相对剪切位移关联的表格名称

coupling-gap-normal b

法向耦合弹簧间隙启用标志 \(g\)

coupling-stiffness-normal f

法向耦合弹簧刚度 \(k_n\)

coupling-stiffness-shear f

剪切耦合弹簧刚度 \(k_s\)

cross-sectional-area f

横截面积 \(A\)

density f

density, \(\rho\)

direction-y v

\(y\) 方向向量的分量

moi-polar f

极惯性矩 \(J\)

moi-y f

关于局部 \(y\) 轴的二次矩 \(I_y\)

moi-z f

关于局部 \(z\) 轴的二次矩 \(I_z\)

perimeter f

外露周长 \(p\)

plastic-moment f

塑性弯矩 \(M^P\)

注意这会把 plastic-moment-y 与 plastic-moment-z 两个值都设为 f。

plastic-moment-y f

关于局部 Y 方向的塑性弯矩 \(M_y^P\)

plastic-moment-z f

关于局部 Z 方向的塑性弯矩 \(M_z^P\)

poisson f

泊松比，\(\nu\)

rockbolt-flag b

激活锚杆逻辑的标志（默认：关闭（off））

slide b

滑动标志

slide-tolerance f

滑动容差

tensile-failure-strain f (Only active if :lkwd:`rockbolt-flag` is :lbool:`true`)

拉伸破坏应变（无量纲）

yield-compression f

轴向抗压屈服强度（力单位），[F] （仅当 rockbolt-flag 为 真值（true） 时有效）

yield-tension f

轴向抗拉屈服强度（力单位），[F] （仅当 rockbolt-flag 为 真值（true） 时有效）

thermal-expansion f

热膨胀系数 \(a_t\)

young f

杨氏模量，\(E\)
