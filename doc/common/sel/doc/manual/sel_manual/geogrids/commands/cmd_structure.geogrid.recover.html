structure geogrid recover 命令

语法

structure geogrid recover keyword <range>

主要关键字：

合力（resultants）    应力（stress）    测量面（surface）

土工格栅单元的应力恢复。应力恢复流程可施加于所有单元，以同时计算应力合力与指定深度处的应力。range 关键字确定该命令所施加的单元集合。注意所恢复的量取决于恢复所覆盖的单元范围，因为节点平均只在范围内的单元之间进行。

resultants <range>

为可选范围内所有单元恢复八个应力合力。应力合力以表面坐标系表示。该命令假定已为范围内该组单元建立一致的表面坐标系（见 surface 关键字）。弯曲与膜应力合力（\(M_x\)、\(M_y\)、\(M_{xy}\)、\(N_x\)、\(N_y\) 与 \(N_{xy}\)）在各单元内线性变化，而横向剪应力合力（\(Q_x\) 与 \(Q_y\)）在各单元内为常量。恢复流程先计算弯曲与膜应力合力的平均值（在节点处对范围内各单元的贡献取平均），再在空间上对该平均弯曲场沿各单元求导，从而得到横向剪应力合力。

应力合力可在恢复后用命令 列出土工格栅单元合力命令（structure geogrid list resultant） 与 FISH 函数 壳单元节点应力合力（struct.shell.resultant） 查询。特定单元的应力合力是否有效可用 FISH 函数 壳单元应力合力有效性（struct.shell.resultant.valid） 查询。

stress <depth-factor f >

为可选范围内所有单元在指定深度处恢复应力张量（以全局坐标系表示）。深度等于 \(v\) 乘以 \(t\)/2，其中 \(t\) 为壳厚度。深度因子 \(v\) 必须在 [-1, +1] 范围内。\(v\) 等于 +1/-1 对应壳外/内表面（外表面由表面系正 \(z\) 方向定义），\(v\) 等于零对应壳中面。若未指定 \(v\)，则默认为 +1。

在各单元的三个节点与形心处恢复应力。若用 \(xy\) 轴表示壳中面，则 1) 应力分量 \(σ_{xx}\)、\(σ_{yy}\) 与 \(σ_{xy}\) 在各单元内线性变化；2) 应力分量 \(σ_{zy}\) 与 \(σ_{zx}\) 在各单元内为常量；3) 各单元内 \(σ_{zz}\) = 0。应力由单元内部力导出（见 列出土工格栅单元节点力命令（structure geogrid list force-node））。若执行该命令时应力合力无效，则先尝试恢复它们；若该尝试失败，则显示错误消息指出问题——通常是表面系不一致，此时必须用 恢复土工格栅单元表面命令（structure geogrid recover surface） 命令手动建立（见下一关键字）。

应力与主应力可在恢复后用命令 列出土工格栅单元应力命令（structure geogrid list stress） 与 列出土工格栅单元主应力命令（structure geogrid list stress-principal） 以及 FISH 函数 壳单元节点应力（struct.shell.stress） 与 壳单元主应力（struct.shell.stress.prin） 查询。已恢复应力的深度可用 列出土工格栅单元深度系数命令（structure geogrid list depth-factor） 与 FISH 函数 壳单元应力恢复深度系数（struct.shell.depth.factor） 查询。特定单元的应力与主应力是否有效可用 FISH 函数 壳单元应力有效性（struct.shell.stress.valid） 查询。

surface v

向量 v 使可为可选范围内单元所用的所有节点生成表面坐标系。表面坐标系 \(x'\) \(y'\) \(z'\) 具有以下性质：(1) \(z'\) 垂直于表面；(2) \(x'\) 为所给向量在表面上的投影；(3) \(y'\) 与 \(x'\)、\(z'\) 正交。\(z'\) 方向在每个节点处取范围内所有单元平均法向得到。若 surface v 在任何节点处与 \(z'\) 对齐，则处理停止并显示错误消息。要继续，请指定不同的 v，或限制所考虑单元的范围。

表面坐标系可用 列出土工格栅单元局部坐标系命令（structure geogrid list system-local） 与 FISH 函数 结构节点表面坐标系（struct.node.system.surface） 查询。也可用 FISH 函数 结构节点局部坐标系（struct.node.system.local） 为单个节点设置。可通过选择相应的 System 属性，用 Geogrid 绘图项可视化。

在以下情况下节点表面系自动失效：1) 大应变更新；2) 创建或删除使用该节点的单元。必须用命令 恢复土工格栅单元表面命令（structure geogrid recover surface） 重新建立有效性。
