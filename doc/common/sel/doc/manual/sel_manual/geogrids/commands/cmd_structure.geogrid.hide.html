structure geogrid hide 命令

语法

structure geogrid hide keyword

主要关键字：

占位参数（adummy）    undo

该命令隐藏或取消隐藏范围内所有土工格栅单元。默认情况下使用范围过滤器的命令会跳过隐藏对象。可在范围指定中用 use-hidden 关键字覆盖该行为。

可用以下关键字：

b

若指定布尔类型且为 开启（on），则隐藏范围内所有单元。若为 关闭（off），则取消隐藏（即显示）范围内所有单元，并隐式对该范围应用 use-hidden 关键字。未给出关键字时默认为 开启（on）。

undo

这将撤销上一条 structure geogrid hide 命令的操作。FLAC3D 最多保留 12 层撤销栈。
