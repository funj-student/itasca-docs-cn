structure geogrid history 命令

语法

structure geogrid history keyword

主要关键字：

位移耦合（coupling-displacement）    应力耦合（coupling-stress）    coupling-yield    力（force）    force-x    force-y    force-z    moment    x 向弯矩（moment-x）    y 向弯矩（moment-y）    z 向弯矩（moment-z）    合力 mx（resultant-mx）    合力 my（resultant-my）    合力 mxy（resultant-mxy）    合力 nx（resultant-nx）    合力 ny（resultant-ny）    合力 nxy（resultant-nxy）    合力 qx（resultant-qx）    合力 qy（resultant-qy）    中间主应力（principal-intermediate）    最大主应力（principal-maximum）    最小主应力（principal-minimum）    stress-xx    stress-xy    stress-xz    stress-yy    yz 向应力（stress-yz）    stress-zz

土工格栅响应采样。单元各节点相对于创建该土工格栅的网格单元面外侧按逆时针排序。

被采样单元必须由 component-id 或 position 标识。若使用 position v，则取距 v 最近的单元。

对某些历史记录类型，可用关键字 node i 选择性地指定被采样单元的节点（其中 i = 1、2 或 3）。若省略 node，默认使用节点 1。

对合力类历史记录，表面系与所给 Surface-X v 值一致（即每次采样应力合力历史记录时，都对指定单元用该向量调用 恢复土工格栅单元表面命令（structure geogrid recover surface） 命令的逻辑）。这些历史记录必须给出 Surface-X v。

对应力类历史记录，按 Depth-Factor f 所给壳深度计算应力如下。壳深度等于 \(Ft\)/2，其中 \(F\) 为深度因子，\(t\) 为壳厚度。\(F\) 等于 +1/-1 对应壳外/内表面（外表面由壳正 \(z\) 方向定义），\(F\) = 0 对应壳中面。

coupling-displacement [geogridhistoryblock]

单元节点处耦合弹簧中的位移大小（始终为正）。该选项使用 node 关键字。

coupling-stress [geogridhistoryblock]

单元节点处耦合弹簧中的应力大小（始终为正）。该选项使用 node 关键字。

coupling-yield [geogridhistoryblock]

单元节点处耦合弹簧的屈服状态。取值 {0, 1, 2} 分别表示从未屈服、正在屈服或曾经屈服。该选项使用 node 关键字。

force [geogridhistoryblock]

力的大小，全局系。该选项使用 node 关键字。

force-x [geogridhistoryblock]

节点力（\(x\) 分量，全局系）。该选项使用 node 关键字。

force-y [geogridhistoryblock]

节点力（\(y\) 分量，全局系）。该选项使用 node 关键字。

force-z [geogridhistoryblock]

节点力（\(z\) 分量，全局系）。该选项使用 node 关键字。

moment [geogridhistoryblock]

力矩大小，全局系。该选项使用 node 关键字。

moment-x [geogridhistoryblock]

节点力矩（\(x\) 分量，全局系）。该选项使用 node 关键字。

moment-y [geogridhistoryblock]

节点力矩（\(y\) 分量，全局系）。该选项使用 node 关键字。

moment-z [geogridhistoryblock]

节点力矩（\(z\) 分量，全局系）。该选项使用 node 关键字。

resultant-mx [geogridhistoryblock]

单元表面系中的应力合力 \(M_x\)。该选项使用 surface-x 关键字。

resultant-my [geogridhistoryblock]

单元表面系中的应力合力 \(M_y\)。该选项使用 surface-x 关键字。

resultant-mxy [geogridhistoryblock]

单元表面系中的应力合力 \(M_{xy}\)。该选项使用 surface-x 关键字。

resultant-nx [geogridhistoryblock]

单元表面系中的应力合力 \(N_x\)。该选项使用 surface-x 关键字。

resultant-ny [geogridhistoryblock]

单元表面系中的应力合力 \(N_y\)。该选项使用 surface-x 关键字。

resultant-nxy [geogridhistoryblock]

单元表面系中的应力合力 \(N_{xy}\)。该选项使用 surface-x 关键字。

resultant-qx [geogridhistoryblock]

单元表面系中的应力合力 \(Q_x\)。该选项使用 surface-x 关键字。

resultant-qy [geogridhistoryblock]

单元表面系中的应力合力 \(Q_y\)。该选项使用 surface-x 关键字。

principal-intermediate [geogridhistoryblock]

中间主应力，全局系。该选项使用 depth-factor 关键字。

principal-maximum [geogridhistoryblock]

最大主应力，全局系。该选项使用 depth-factor 关键字。

principal-minimum [geogridhistoryblock]

最小主应力，全局系。该选项使用 depth-factor 关键字。

stress-xx [geogridhistoryblock]

应力的 \(xx\) 分量，全局系。该选项使用 depth-factor 关键字。

stress-xy [geogridhistoryblock]

应力的 \(xy\) 分量，全局系。该选项使用 depth-factor 关键字。

stress-xz [geogridhistoryblock]

应力的 \(xz\) 分量，全局系。该选项使用 depth-factor 关键字。

stress-yy [geogridhistoryblock]

应力的 \(yy\) 分量，全局系。该选项使用 depth-factor 关键字。

stress-yz [geogridhistoryblock]

应力的 \(yz\) 分量，全局系。该选项使用 depth-factor 关键字。

stress-zz [geogridhistoryblock]

应力的 \(zz\) 分量，全局系。该选项使用 depth-factor 关键字。


关键字块

可用以下关键字控制历史记录的位置及其他细节。部分关键字仅在注明时可用。位移耦合（coupling-displacement）、应力耦合（coupling-stress）、coupling-yield、力（force）、force-x、force-y、force-z、moment、x 向弯矩（moment-x）、y 向弯矩（moment-y）、z 向弯矩（moment-z）、中间主应力（principal-intermediate）、最大主应力（principal-maximum）、最小主应力（principal-minimum）、合力 mx（resultant-mx）、合力 mxy（resultant-mxy）、合力 my（resultant-my）、合力 nx（resultant-nx）、合力 nxy（resultant-nxy）、合力 ny（resultant-ny）、合力 qx（resultant-qx）、合力 qy（resultant-qy）、stress-xx、stress-xy、stress-xz、stress-yy、yz 向应力（stress-yz） 以及 stress-zz。

component-id i

按单元各自的 component ID 号选择该单元

depth-factor f

用于确定单元应力的深度因子。仅在注明时可用。

node i

从单元取值时所用的节点位置。必须为 1 到 3。仅在注明时可用。

position v

选取形心距 v 最近的单元

surface-x v

用于确定局部表面坐标系的局部 \(x\) 方向。仅在注明时可用。
