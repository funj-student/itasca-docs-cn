struct.node.resultant

语法

m := struct.node.resultant(p<,ires>)

获取与该节点相连单元最后计算的应力合力。

将按以下顺序返回应力合力的 6x1 矩阵：{ \(M_x\), \(M_y\), \(M_{xy}\), \(N_x\), \(N_y\), \(N_{xy}\), } 紧急：DR：此前带花括号的表达式被如此标记：:flag2:-{ M_x,M_y,M_xy,N_x,N_y,N_xy }- 原因何在？。注意 \(Q_x\) 与 \(Q_y\)1 项在节点处无效，因为它们在单元上为常数。

应力合力在节点表面系中表示；见 恢复壳单元表面命令（structure shell recover surface）、恢复土工格栅单元表面命令（structure geogrid recover surface） 与 恢复衬砌单元表面命令（structure liner recover surface） 命令。

若提供可选参数 内力结果（ires），则该函数以单个值返回该特定应力合力（按上述顺序索引）。

注意必须用 structure shell recover、structure geogrid recover 与 structure liner recover 命令计算应力合力。另见 壳单元应力合力有效性（struct.shell.resultant.valid） 函数。

返回值：

m - 全部应力合力的 6x1 矩阵，或特定合力的单个值
参数：

p - 结构单元节点指针

内力结果（ires） - 可选参数，表示特定合力索引，从 1 到 6
