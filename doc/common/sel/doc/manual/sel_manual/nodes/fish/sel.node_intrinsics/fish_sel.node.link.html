struct.node.link

语法

l := struct.node.link(sn<,i>)

获取与结构节点 FISH 符号名（sn） 关联的连接。若该结构节点无关联连接则返回 无接触（null）。

返回值：

l - 连接指针
参数：

FISH 符号名（sn） - 结构节点指针

i - 可选的侧面指示符。若未指定则该值默认为 1，但最大可达 16。
