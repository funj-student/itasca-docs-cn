结构单元节点

力学行为

每个节点关联六个自由度，由三个平动分量与三个转动分量组成。与结构单元关联的所有质量集中到节点上；每个节点从使用它的结构单元继承质量。

每个节点关联两个坐标系（全局系与节点局部系）：

  1. 全局系可用于指定广义速度与位移边界条件、节点位置以及施加荷载。全局系在整个模拟过程中不变。
  2. 节点局部系用于指定控制节点与网格相互作用的附着条件。此外运动方程在这些局部方向上求解。因此只能在这些方向上 fix 或 free 速度。

节点局部系的方位在一组循环开始时（或执行 执行计算时步（model cycle） 0 命令时）依据使用该节点的单元类型自动设定。对梁与壳，局部系与全局系对齐。对锚索与桩，局部系满足：(1) \(x\) 轴与使用该节点的所有锚索或桩单元的平均轴向方向对齐；(2) \(yz\) 轴在锚索或桩横截面平面内任意取向。对土工格栅与衬砌，局部系满足：(1) \(z\) 轴与使用该节点的所有土工格栅或衬砌单元的平均法向对齐；(2) \(xy\) 轴在土工格栅或衬砌切平面内任意取向。在大应变模式下运行时，节点局部系的方位依据使用该节点的单元运动自动更新（除非该行为被 structure node system-local 命令抑制）。

一般而言，几何创建按 几何创建（Geometry Creation） 所述进行。此外可用 初始化结构节点位置命令（structure node initialize position） 命令重新定位单个节点。因移动节点而被移动的单元将保留其默认附着条件。

可用 structure node initialize 命令为节点的累积位移与转角赋初值。例如可在分析任一阶段把这些分量初始化为零。注意位移值不参与计算循环；实际是由节点速度乘以时步计算增量位移。

用 group 范围元素选择时，默认情况下只要节点本身或该节点所连任何单元属于该组，就认为该节点是该组成员。可用 by 关键字把该范围限定到特定对象类型。

响应量

节点响应包括位移、速度、位置与不平衡力。这些量可在全局系或节点局部系中表示。节点响应可通过 FISH 访问，并

  • 用 structure node list 命令打印；
  • 用 structure node history 命令监测；以及
  • 用各结构单元绘图项绘制。
