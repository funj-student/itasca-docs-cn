structure node list 命令

语法

structure node list keyword <range>

主要关键字：

apply    connectivity    damping-local    displacement    固定（fixity）    fix-local    unbalanced-force    link    mass    position    stiffness    system-local    system-surface    velocity

显示范围内结构节点的信息。

apply <keyword>

列出节点上施加条件的取值。可提供以下关键字之一以指定列出哪种施加条件。

force

局部系中作用于节点的施加力。若未指定关键字则此为默认。

moment

局部系中作用于节点的施加力矩

connectivity

列出与该节点相连的所有单元的 component-id 号

damping-local

节点的局部阻尼因子

displacement <keyword>

列出节点的平动与转动（角）位移。若给出以下关键字，可选择显示所用的坐标系：

global

在全局坐标系中显示取值

local

在局部坐标系中显示取值；若未指定则此为默认。

fixity

按节点局部坐标系表示的速度固定状态

fix-local

节点局部坐标系的固定状态

unbalanced-force

不平衡力与力矩按节点局部坐标系显示

link

列出附着于该节点的任何连接的 component-id 号

mass

平动与转动（角）分量按节点局部坐标系显示

position <keyword>

范围内节点的位置。可能有两个不同的位置值；以下关键字（若存在）可让你选择显示哪个位置。默认使用 reference 位置。

current

节点当前位置；即便在小应变模式下也由起始（或参考）位置更新

reference

节点的参考位置；仅在大应变模式下更新。小应变模式下为节点的初始位置且不变。

stiffness

平动与转动（角）分量按节点局部坐标系显示

system-local

显示节点所用局部坐标系的方向

system-surface

显示应力恢复期间所用表面坐标系的方向。该坐标系由 恢复壳单元表面命令（structure shell recover surface）、恢复土工格栅单元表面命令（structure geogrid recover surface） 或 恢复衬砌单元表面命令（structure liner recover surface） 命令计算。

velocity <keyword>

平动与转动（角）速度按全局系或节点局部系（默认）表示。以下关键字（若存在）可选择显示所用坐标系：

global

在全局坐标系中显示取值

local

在局部坐标系中显示取值；若未指定则此为默认。
