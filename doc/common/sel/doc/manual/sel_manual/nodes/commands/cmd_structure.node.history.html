structure node history 命令

语法

structure node history <name s > keyword

主要关键字：

displacement-x    displacement-y    displacement-z    x 向转动位移（displacement-rotational-x）    y 向转动位移（displacement-rotational-y）    z 向转动位移（displacement-rotational-z）    force-x    force-y    force-z    x 向弯矩（moment-x）    y 向弯矩（moment-y）    z 向弯矩（moment-z）    position-x    position-y    position-z    velocity-x    velocity-y    velocity-z    x 向转动速度（velocity-rotational-x）    y 向转动速度（velocity-rotational-y）    z 向转动速度（velocity-rotational-z）

采样节点响应。包括位移、速度、位置与不平衡力。

若使用可选关键字 name，则可给该历史记录提供名称以便日后识别。若未提供名称，则将依据历史记录对象内部创建的 ID 号自动赋予一个名称。

具体节点必须用坐标（position v）或节点 ID（component-id i）标识。

除非指定可选关键字 local，否则所采样量在全局系中表示；若指定则在节点局部系中表示。local 关键字不适用于位置历史记录（position-x、position-y、position-z），它们始终在全局系中表示。

关键字块

用 structure node initialize 命令指定的初始值可用以下关键字选择性地修改。这些关键字（除 local 关键字另有说明外）适用于该命令的所有主要关键字：x 向转动位移（displacement-rotational-x）、y 向转动位移（displacement-rotational-y）、z 向转动位移（displacement-rotational-z）、displacement-x、displacement-y、displacement-z、force-x、force-y、force-z、x 向弯矩（moment-x）、y 向弯矩（moment-y）、z 向弯矩（moment-z）、position-x、position-y、position-z、x 向转动速度（velocity-rotational-x）、y 向转动速度（velocity-rotational-y）、z 向转动速度（velocity-rotational-z）、velocity-x、velocity-y 与 velocity-z。

component-id i

具体节点由 component ID 号标识。若使用该关键字，则不应使用 position。

local

指定该值取在节点局部坐标系中。默认情况下该值取在全局坐标系中。

position v

具体节点由坐标（v）识别（取最近节点）。若使用该关键字，则不应使用 component-id。
