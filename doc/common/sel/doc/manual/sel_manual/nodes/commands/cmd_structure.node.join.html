structure node join 命令

语法

structure node join <keyword> <range>

主要关键字：

分组（group）    目标范围（range-target）    侧（side）

该命令在范围内所有节点上创建节点-节点连接，做法是尝试在范围内找到位于同一位置的另一节点。若找到且该节点尚无节点-节点连接，则删除任何已有连接并创建新的节点-节点连接。新连接在全部六个自由度上刚性附着于目标节点。

目标节点上已有的任何连接都不被修改。

可用以下关键字修改连接创建过程：

group s <slot slot >

指定将赋给该命令所创建全部连接的组赋值。可用 slot 关键字指定所用槽位，否则槽位为 默认（Default）。组逻辑的用法见 组（Groups）。

range-target range

指定用于选择目标节点的范围（与 <range> 短语相同）。目标节点必须落在该范围内才会被考虑。注意可同时给出 range-target 与 range。

side i

指定所创建的任何连接位于单元的 side i 上。这只适用于附着于用 embedded 关键字创建的衬砌单元的节点。默认情况下连接创建于 side 1。
