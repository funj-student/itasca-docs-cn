structure node initialize 命令

语法

structure node initialize keyword ... <range>

主要关键字：

displacement    displacement-x    displacement-y    displacement-z    转动位移（displacement-rotational）    x 向转动位移（displacement-rotational-x）    y 向转动位移（displacement-rotational-y）    z 向转动位移（displacement-rotational-z）    position    position-x    position-y    position-z    目标力比（ratio-target）    velocity    velocity-x    velocity-y    velocity-z    转动速度（velocity-rotational）    x 向转动速度（velocity-rotational-x）    y 向转动速度（velocity-rotational-y）    z 向转动速度（velocity-rotational-z）

初始化范围内所有结构节点上的量。注意位置只能在全局系中指定。

请注意在结构单元逻辑中，节点速度与位移存储在局部系中。这意味着局部系的改变可能改变全局系中的值。这一点尤其重要，因为节点局部系要到第一个循环或步才按给定结构单元体系计算，在此之前节点系为默认值，即与全局系相同。当第一个循环命令执行时，节点局部系被调整，已赋的任何速度值在全局系中很可能改变方向。

处理该问题的最佳方式是在给节点赋速度之前发出 执行计算时步（model cycle） 0 命令——这会使节点局部系被更新。

position v <[nodeinitializeblock]>

节点位置（全局系）。用于结构单元网格的定位；必须在创建节点之后、执行任何循环之前使用。任何被移入网格单元的节点（见 structure link list 命令）的既有连接将被删除，并按使用该节点的结构单元类型（见 本表（this table））创建带相应附着条件的新连接。若某节点被多种单元类型使用，则附着条件将对应以下列表中的第一个单元类型：衬砌、土工格栅、桩、锚索、壳、梁。因此若某节点同时被土工格栅与锚索使用，则移动该节点后的附着条件将对应土工格栅。

ratio-target f <[nodeinitializeblock]>

设置力学计算中被视为收敛的目标局部力比。默认值为 1e-4。局部力比等于该值时，节点的收敛值为 1.0。见 求解模型（model solve） 命令中的 convergence 关键字。

structure node initialize 关键字块

用 structure node initialize 命令指定的初始值可用以下关键字选择性地修改。

它们（除就 local 关键字注明者外）适用于该命令的所有主要关键字：displacement、转动位移（displacement-rotational）、x 向转动位移（displacement-rotational-x）、y 向转动位移（displacement-rotational-y）、z 向转动位移（displacement-rotational-z）、displacement-x、displacement-y、displacement-z、position、position-x、position-y、position-z、目标力比（ratio-target）、velocity、转动速度（velocity-rotational）、x 向转动速度（velocity-rotational-x）、y 向转动速度（velocity-rotational-y）、z 向转动速度（velocity-rotational-z）、velocity-x、velocity-y 与 velocity-z。

add

（范围内所有节点的）参数现有值被设为当前值加所给值。例如可用命令 structure node initialize displacement-x 0.1 add 把所有节点的 \(x\) 向位移加上 0.1。

multiply

（范围内所有节点的）参数现有值被乘以所给值，而非设为所给值。例如可用命令 初始化结构节点 x 向位移命令（structure node initialize displacement-x） 1.5 multiply 把所有节点的 \(x\) 向位移乘以 1.5。

local

指定所给值将以局部坐标初始化该节点。该关键字不得与位置类关键字（position、position-x 等）一起使用。

gradient v

范围内各节点所赋的值为 \(val_f\) = \(v\) + \(xg_x\) + \(yg_y\) + \(zg_z\)，其中 gradient 关键字紧跟在所给值（此处为 \(val\)）之后，而 (\(x\), \(y\), \(z\)) 由 v 给出，它指定节点的参考位置。若同时存在 multiply 关键字，则所给梯度作用于乘数。
