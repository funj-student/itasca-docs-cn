structure node apply 命令

语法

structure node apply keyword <range>

主要关键字：

力（force）    边力（force-edge）    moment    remove    system

为范围内所有节点设置广义点荷载。广义点荷载由施加力与施加力矩组成。可用 structure shell apply、structure geogrid apply 或 structure liner apply 命令对壳面施加压力荷载。可用 structure beam apply 或 施加桩单元条件（structure pile apply） 命令对梁与桩表面施加分布荷载。可用以下关键字定义广义点荷载。

force v <keyword>

施加力向量（按 system 关键字所定义的体系）。可用以下关键字之一修改 v 施加于节点的方式：

add

把向量 v 加到该节点现有的施加力向量上

multiply

把向量 v 与该节点现有的施加力向量按分量相乘

force-edge v <add>

把向量 v 作为单位长度力加到连接范围内各节点的所有 边 上。由该边赋予的力被集中到两个节点上，每个节点各分一半。这些力始终在全局系中，并把节点设为全局系，如同 施加结构节点全局坐标系条件命令（structure node apply system global） 命令。

默认情况下这些力会覆盖节点上此前施加的力；不过可给出 add 关键字把它们加到当前已有的力上。注意若这改变了其施加时所处的体系，此前的力不会针对体系变化进行修正。

moment v <keyword>

施加力矩向量（按 system 关键字所定义的体系）。可用以下关键字修改 v 施加于节点的方式：

add

把向量 v 加到该节点现有的施加力矩向量上

multiply

把向量 v 与该节点现有的施加力矩向量按分量相乘

remove keyword

所施加的条件一直有效，直到用该命令移除。可用以下关键字选择要移除的施加条件：

force

移除该节点上任何施加力条件

moment

移除该节点上任何施加力矩条件

system keyword

设置表示力与力矩向量所用的坐标系。默认系为全局。若把该系设为局部，则在大应变模式下力与力矩向量将随局部系旋转而保持对齐。

local
global
