structure liner list 命令

语法

structure liner list keyword

主要关键字：

apply    coupling-normal    coupling-shear    depth-factor    element-type    分组（group）    information    节点力（force-node）    property    合力（resultant）    应力（stress）    stress-principal    system-local

列出范围内各衬砌单元的性质与响应。

apply

作用于单元的均布压力

coupling-normal

连接衬砌与网格单元的法向耦合弹簧的信息。给出围压、位移与方向。

coupling-shear

连接衬砌与网格单元的剪切耦合弹簧的信息。给出围压、位移、屈服状态与方向。

depth-factor

应力恢复中所用深度因子

element-type

所用有限单元类型

group <slot s >

列出该单元的组赋值。若提供 slot，则列出该单元在槽位 s 中的组赋值（若有）。

information

列出单元一般信息，包括 id 与 component-id 号、相连节点、形心、表面积、体积以及隐藏与选择状态

force-node keyword

列出节点力。默认情况下分量按单元局部坐标系显示。这些是节点施加在单元上的力。

local

按单元局部坐标系列出力（默认）

global

按全局坐标系列出力

property
density

密度，\(ρ\)

thickness

衬砌厚度

thermal-expansion

热膨胀系数

anisotropic-membrane

anisotropic membrane material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{13}, c^{\prime}_{22}, c^{\prime}_{23}, c^{\prime}_{33}\)}

anisotropic-bending

anisotropic bending material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{13}, c^{\prime}_{22}, c^{\prime}_{23}, c^{\prime}_{33}\)}

material-x

材料性质类型：各向同性、正交各向异性或各向异性

isotropic

各向同性材料性质：\(E\) 与 \(v\)，其中 \(E\) 为杨氏模量 \([F/L^2\)\(]\)，\(v\) 为泊松比

orthotropic-membrane

orthotropic membrane material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{22}, c^{\prime}_{33}\)}

orthotropic-bending

orthotropic membrane material-stiffness coefficients {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{22}, c^{\prime}_{33}\)}

coupling-cohesion-shear

耦合弹簧黏聚力（应力单位）

coupling-cohesion-shear-2

侧 2 上的耦合弹簧黏聚力（应力单位）

coupling-cohesion-shear-residual

耦合弹簧黏聚力（应力单位）

coupling-cohesion-residual-2

侧 2 上的耦合弹簧黏聚力（应力单位）

coupling-friction-shear

耦合弹簧摩擦角（度）

coupling-friction-shear-2

侧 2 上的耦合弹簧摩擦角（度）

coupling-stiffness-normal

耦合弹簧单位面积刚度

coupling-stiffness-normal-2

侧 2 上的耦合弹簧单位面积刚度

coupling-stiffness-shear

耦合弹簧单位面积刚度

coupling-stiffness-shear-2

侧 2 上的耦合弹簧单位面积刚度

coupling-yield-normal

法向耦合弹簧抗拉强度

coupling-yield-normal-2

侧 2 上的法向耦合弹簧抗拉强度

slide

大应变滑动标志

slide-tolerance

大应变滑动容差

effective

用于计算耦合法向应力的有效应力标志

resultant <nodes>

用 恢复衬砌单元合力命令（structure liner recover resultants） 命令最后计算的八个应力合力量。若给出 nodes 关键字，则除单元形心处取值外，还在单元各节点处给出这些量的取值。

stress <nodes>

用 恢复衬砌单元应力命令（structure liner recover stress） 命令计算的应力状态。若给出 nodes 关键字，则除单元形心处取值外，还在单元各节点处给出这些量的取值。

stress-principal <nodes>

用 恢复衬砌单元应力命令（structure liner recover stress） 命令计算的主应力。若给出 nodes 关键字，则除单元形心处取值外，还在单元各节点处给出这些量的取值。

system-local

单元局部坐标系
