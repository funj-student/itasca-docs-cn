对结构单元衬砌的操作。

衬砌单元使用与壳单元相同的内部表述。默认情况下它们为可变形，并沿所有方向与其周围连接。假定它们置于模型表面上，因此垂直于单元表面的连接相互作用是有方向性的。它们在结构单元逻辑中独有地在每个节点上支持两个连接，从而使衬砌可嵌入两个面之间（创建时使用 embedded 关键字）。
