structure liner create 命令

语法

structure liner create keyword

主要关键字：

按单元面（by-zone-face）    按区块面（by-block-face）    按节点 ID（by-nodeids）    按四边形（by-quadrilateral）    按三角形（by-triangle）

创建衬砌。有四种不同的创建方式：由一组网格单元面创建单元集合（by-zone-face 或 by-block-face）；由四个已有节点（by-nodeids）创建单个单元；由指定的四边形（by-quadrilateral）创建；或由三角形（by-triangle）创建。

by-zone-face (FLAC3D) [linercreateblock] <range>

创建新单元并附着到范围内的一组三边或四边网格单元面。默认只考虑表面；可用 internal 关键字选择内部面。与该单元关联的新节点也会被创建（见 id 关键字）。各新单元的节点相对于所指定网格单元面的外侧按逆时针排序，从而使单元的 \(z\) 轴指向外侧。单元在其节点处以适于该单元类型的连接附着条件与网格附着（见 结构单元连接 主题中的 本表（this table））。注意用该命令创建单元后可删除网格单元，并用 初始化结构节点位置命令（structure node initialize position） 命令移动其节点来定位这些单元。

by-block-face <tolerance f> (3DEC) [linercreateblock] <range>

创建新单元并附着到范围内的一组三边网格单元面。单元只能创建在块体表面上。与该单元关联的新节点也会被创建（见 id 关键字）。各新单元的节点相对于所指定网格单元面的外侧按逆时针排序，从而使单元的 \(z\) 轴指向外侧。单元在其节点处以适于该单元类型的连接附着条件与网格附着（见 结构单元连接 主题中的 本表（this table））。注意用该命令创建单元后可删除网格单元，并用 初始化结构节点位置命令（structure node initialize position） 命令移动其节点来定位这些单元。

可用 tolerance 关键字在因大应变变形而分离的面上启用衬砌单元的连接。默认情况下，若相邻衬砌单元节点之间距离小于 f = 1e-5，则这些节点被连接。

by-nodeids i1 i2 i3 [linercreateblock]

由已有节点集创建单元。新单元不会附着到网格；若希望附着到网格，则在创建后用 初始化结构节点位置命令（structure node initialize position） 命令确定其节点位置（该命令会为所有被移入网格单元的节点创建连接并设置适当的附着条件）。

by-quadrilateral v1 v2 v3 v4 [linercreateblock]

按顺序根据构成四边形的四个点创建单元。单元局部系将按右手规则确定的方向指向。

用该命令创建的节点会自动附着到其位置处找到的第一个有效对象类型，各自由度的连接附着条件与单元类型相适应。

by-triangle v1 v2 v3 [linercreateblock]

根据构成三角形的三个点创建单元。单元局部系将按右手规则确定的方向指向。

用该命令创建的节点会自动附着到其位置处找到的第一个有效对象类型，各自由度的连接附着条件与单元类型相适应。


关键字块

使用任一主要关键字创建衬砌时，可选择性地提供以下关键字：按区块面（by-block-face）、按节点 ID（by-nodeids）、按四边形（by-quadrilateral）、按三角形（by-triangle） 与 按单元面（by-zone-face）。

id i

指定将赋给该命令所创建的全部新单元的 ID。若未给出该值，则使用下一个可用 ID。该 ID 按下述方式控制单元节点与已有单元的可能连接：在每个潜在新节点位置都会新建节点，除非同时满足以下条件：1) 已给出 ID；2) 在潜在新节点位置附近找到已有节点；3) 所找到的节点属于 ID 等于 i 的同类型单元。

group s1 <slot s2 >

把所创建的单元赋给组 s1。若提供 s2，则该组被赋给该名称的槽位；否则赋给名为 默认（Default） 的槽位。组逻辑的用法见 组（Groups）。

cross-diagonal <b >

若指定，则创建由四个三角形构成的对角交叉网格，并在所有四边形的形心处设一个节点；否则创建由两个三角形构成的交叉网格来划分该四边形。

把单元连接到网格时，最好把节点置于网格点处。若有限单元类型能抵抗弯曲（DKT、DKT-CST 或 DKT-CST 杂交单元），则单元面与网格单元面之间可能出现不协调，因为横向（平面外）位移场在单元面上按三次变化，而在网格单元面上仅按线性变化。因此把抗弯单元与网格单元面刚性连接时，最好采用交叉 hatch 网格，因为交叉对角网格的中间节点将被迫按网格单元面的线性位移场平动。这会使单元过度约束，在存在非零力矩场时可能在这些中间节点处产生近零力矩。

distinct

取消所创建单元之间的节点共享。每个单元都会新建一组节点，即便它们位于相同空间位置且单元共享相同 ID 号。该选项最常与后续 structure node join 命令配合，在相同位置节点之间创建连接以实现自定义单元间行为。

element-type keyword

指定各结构单元所用的有限元表述。若未指定单元类型，则单元类型为 DKT-CST。注意有限元类型在创建时即与各结构单元关联，此后不可更改。已有结构单元的有限元类型由 列出衬砌单元单元类型命令（structure liner list element-type） 命令打印。所给关键字的值必须是以下三节点有限单元之一：

s

尝试把字符串 s 与下文某个可用关键字匹配，并按该选项处理

cst

CST（6 自由度）有限单元。这是膜单元；它承受膜荷载但不承受弯曲荷载。

csth

CST 杂交（9 自由度）有限单元。这是膜单元；它承受膜荷载但不承受弯曲荷载。

dkt

DKT（9 自由度）有限单元。这是板弯曲单元；它承受弯曲荷载但不承受膜荷载。

dkt-cst

DKT-CST（15 自由度）有限单元。这是结合 DKT 与 CST 单元的壳单元，可同时承受弯曲与膜荷载。

dkt-csth

DKT-CST 杂交（18 自由度）有限单元。这是结合 DKT 与 CST 杂交单元的壳单元，可同时承受弯曲与膜荷载。

embedded

指定该衬砌为双面。若使用 embedded 关键字，则即使未显式给出也隐含 internal 关键字。

internal

该关键字仅在使用了 from-faces 选项时适用。它指定范围内所有内部面与表面都将在其上创建单元。通常只考虑表面。

maximum-length f

把单元分成长度不超过 f 的各段。若同时给出 segments 设置，则按需被该设置覆盖。

segments i

把单元分成 i 个等长段，按需创建新节点。默认值为 1，表示只创建一个单元。

separate keyword

选择一组内表面，并按 zone separate 命令的方式把它们分离为若干曲面。将在两个曲面之间创建衬砌单元。该关键字隐含 embedded 与 internal。可用以下关键字：

origin v

点 v 用于确定所选面中哪一侧被视为侧 1、哪一侧被视为侧 2。把从 v 到面形心的向量与面法向比较：指向 v 的一侧为侧 1，背离 v 的一侧为侧 2。若未指定 origin 关键字，则假定为 (0,0,0)。

clear-attach

若指定，则清除边界上的任何附着条件。默认情况下，已有附着条件会导致错误。

size i1 i2

该关键字仅在使用了 from-quadrilateral 选项时适用。它把四边形沿第一条边细分为 i1 段、沿第二条边细分为 i2 段，从而增加所创建的单元数量。默认只创建一个四边形单元。
