structure liner property 命令

语法

structure liner property keyword ... <range>

主要关键字：

density    厚度（thickness）    thermal-expansion    anisotropic-membrane    anisotropic-bending    material-x    isotropic    orthotropic-membrane    orthotropic-bending    slide    slide-tolerance    coupling-yield-normal    coupling-yield-normal-2    coupling-stiffness-normal    coupling-stiffness-normal-2    coupling-stiffness-shear    coupling-stiffness-shear-2    coupling-cohesion-shear    coupling-cohesion-shear-2    coupling-cohesion-shear-residual    残余剪切黏聚力耦合 2（coupling-cohesion-shear-residual-2）    coupling-friction-shear    coupling-friction-shear-2    effective

为范围内的单元赋予某个性质。单元可具有各向同性、正交各向异性或各向异性弹性材料性质。注意若衬砌为嵌入式，则必须在侧 2 上单独输入耦合弹簧性质。可用以下性质：

density f

密度（动力模式或重力启用时需要）

thickness f

衬砌厚度

thermal-expansion f

热膨胀系数

anisotropic-membrane f1 f2 f3 f4 f5 f6

各向异性膜材料性质 {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{13}, c^{\prime}_{22}, c^{\prime}_{23}, c^{\prime}_{33}\)} \([F/L^2]\)，分别在材料方向 \(x'\)、\(y'\)、\(z'\) 上定义膜材料刚度矩阵 \([Eʹ_m]\) 与 \([Eʹ_b]\)

anisotropic-bending f1 f2 f3 f4 f5 f6

各向异性弯曲材料性质 {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{13}, c^{\prime}_{22}, c^{\prime}_{23}, c^{\prime}_{33}\)} \([F/L^2]\)，分别在材料方向 \(x'\)、\(y'\)、\(z'\) 上定义弯曲材料刚度矩阵 \([Eʹ_m]\) 与 \([Eʹ_b]\)。

material-x v

指定向量 v，其在土工格栅表面上的投影定义材料坐标系的 \(xʹ\) 轴。材料方向对应正交各向异性主方向（更多信息见 下文（see below））。

isotropic f1 f2

各向同性材料性质：\(E\) 与 \(v\)，其中 \(E\) 为杨氏模量 \([F/L^2]\)，\(v\) 为泊松比

orthotropic-membrane f1 f2 f3 f4

正交各向异性膜材料性质 {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{22}, c^{\prime}_{33}\)} \([F/L^2]\)，分别在材料方向 \(x\)‘、\(y\)‘、\(z\)‘ 上定义膜材料刚度矩阵 \([Eʹ_m]\) 与 \([Eʹ_b]\)。

orthotropic-bending f1 f2 f3 f4

正交各向异性弯曲材料性质 {\(c^{\prime}_{11}, c^{\prime}_{12}, c^{\prime}_{22}, c^{\prime}_{33}\)} \([F/L^2]\)，分别在材料方向 \(x\)‘、\(y\)‘、\(z\)‘ 上定义弯曲材料刚度矩阵 \([Eʹ_m]\) 与 \([Eʹ_b]\)。

slide b

大应变滑动标志

slide-tolerance f

大应变滑动容差

coupling-yield-normal f

法向耦合弹簧抗拉强度（应力单位）

coupling-yield-normal-2 f

侧 2 上的法向耦合弹簧抗拉强度（应力单位）

coupling-stiffness-normal f

法向耦合弹簧单位面积刚度

coupling-stiffness-normal-2 f

侧 2 上的法向耦合弹簧单位面积刚度

coupling-stiffness-shear f

剪切耦合弹簧单位面积刚度

coupling-stiffness-shear-2 f

侧 2 上的剪切耦合弹簧单位面积刚度

coupling-cohesion-shear f

剪切耦合弹簧黏聚力（应力单位）

coupling-cohesion-shear-2 f

侧 2 上的剪切耦合弹簧黏聚力（应力单位）

coupling-cohesion-shear-residual f

剪切耦合弹簧残余黏聚力

coupling-cohesion-shear-residual-2 f

侧 2 上的剪切耦合弹簧残余黏聚力

coupling-friction-shear f

剪切耦合弹簧摩擦角（度）

coupling-friction-shear-2 f

侧 2 上的剪切耦合弹簧摩擦角（度）

effective b

有效应力标志（默认为 开启（on））。若为 关闭（off），则在确定剪切破坏限值时，不从衬砌法向应力中扣除孔隙压力。



关于 material-x 关键字的更多信息

材料坐标系 \(xʹ\)、\(yʹ\)、\(zʹ\) 定义正交各向异性与各向异性性质，并满足以下条件：1) \(xʹ\) 为所给向量在表面上的投影；2) \(zʹ\) 垂直于表面并与壳类单元坐标系的 z 轴对齐；3) \(yʹ\) = \(zʹ\) × \(xʹ\)。大应变更新过程中材料坐标系随壳面运动，这意味着该系与单元局部系的相对方位不变（本图（this figure） 中的角度 \(β\) 不变）。若未指定材料 \(x\) 向量，则 \(xʹ\) 轴将与结构单元局部坐标系的 \(x\) 轴对齐。

材料坐标系可用命令 列出衬砌单元 x 向材料属性命令（structure liner list property material-x） 与 FISH 函数 壳单元材料系统β角（struct.shell.beta） 查询。可通过选择相应的 System 属性，用结构几何绘图项可视化。
