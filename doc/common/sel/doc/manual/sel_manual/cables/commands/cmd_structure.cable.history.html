structure cable history

语法

structure cable history keyword

主要关键字：

力（force）    应力（stress）    yield-tension    yield-compression    浆液位移（grout-displacement）    浆液滑移（grout-slip）    浆液应力（grout-stress）

采样锚索响应。可采样的量包括锚索单元力、应力与屈服状态，以及剪切耦合弹簧的位移、应力与滑动状态。若锚索是用 structure cable create 创建的，则如此创建的每个单元的节点将按整体锚索方向自起点指向终点排序（即各单元的节点连接排序使自端 1 到端 2 的方向与自起点到终点的方向一致）。

force [cablehistoryblock]

单元中的平均轴力（正为拉力，负为压力）

stress [cablehistoryblock]

单元中的平均轴向应力（正为拉力，负为压力）

yield-tension [cablehistoryblock]

单元的拉伸屈服状态。取值 {0, 1, 2} 分别表示从未屈服、正在屈服或曾经屈服。

yield-compression [cablehistoryblock]

单元的压缩屈服状态。取值 {0, 1, 2} 分别表示从未屈服、正在屈服或曾经屈服。

grout-displacement [cablehistoryblock]

单元端部浆体（剪切耦合弹簧）中的位移。符号约定为 +/-（相对锚索平均轴向方向）。

grout-slip [cablehistoryblock]

单元端部浆体（剪切耦合弹簧）中的滑动状态。取值 {0, 1, 2} 分别表示从未滑动、正在滑动或曾经滑动。

grout-stress [cablehistoryblock]

单元端部浆体（剪切耦合弹簧）中的应力。符号约定为 +/-（相对锚索平均轴向方向）。


structure cable history 关键字块

必须提供 component-id 关键字或 position 关键字。end 关键字为可选。这些关键字与 锚索单元历史设置（structure cable history） 的以下关键字一起提供：力（force）、浆液位移（grout-displacement）、浆液滑移（grout-slip）、浆液应力（grout-stress）、应力（stress）、yield-compression 与 yield-tension。

component-id i

具体单元由 component ID 号标识。若使用该关键字，则不应使用 position。

end i

该量在端部 i（其中 i 为 1 或 2）采样，与节点连接列表的顺序一致。若未给出该关键字，则在端部 1（默认）采样历史记录。

position v

该特定单元由坐标（v）标识（取最近的单元）。若使用该关键字，则不应使用 component-id。
