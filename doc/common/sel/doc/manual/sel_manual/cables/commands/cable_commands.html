对结构单元锚索的操作。

锚索单元不支持力矩传递。锚索通常在其单元方向的法向上与周围刚性连接，而在平行于单元的方向上为可变形连接（由浆体性质控制）。

结构单元锚索命令

施加锚索单元条件（structure cable apply）
structure cable create
删除锚索单元（structure cable delete）
锚索单元分组（structure cable group）
隐藏锚索单元（structure cable hide）
锚索单元历史设置（structure cable history）
structure cable import
初始化锚索单元（structure cable initialize）
列出锚索单元（structure cable list）
设置锚索单元属性（structure cable property）
细化锚索单元（structure cable refine）
选择锚索单元（structure cable select）
