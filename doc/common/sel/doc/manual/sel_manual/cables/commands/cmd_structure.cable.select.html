structure cable select

语法

structure cable select <keyword>

主要关键字：

占位参数（adummy）    new    undo

该命令选择或取消选择范围内所有单元。已选对象可用 selected 关键字在范围过滤器中指定；未被选中的对象可用 deselected 关键字指定。

可用以下关键字：

b

若指定布尔类型且为 开启（on），则选择范围内所有单元。若为 关闭（off），则取消选择范围内所有单元。未给出关键字时默认为 开启（on）。

new

隐含 开启（on）。这将选择范围内单元并自动取消选择范围外单元。

undo

这将撤销上一条 structure cable select` 的操作。FLAC3D 最多保留 12 层撤销栈。
