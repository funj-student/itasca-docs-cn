structure cable create 命令

语法

structure cable create keyword ...

主要关键字：

沿线（by-line）    按节点 ID（by-nodeids）    按射线（by-ray）

创建一个由一个或多个单元表示的锚索。

三个主要关键字对应三种不同的创建方式：创建位于起点与终点之间的一组单元（by-line）；由一对已有节点创建指定单元（by-nodeids）；或指定起始点与前进方向（by-ray）。

注意锚索的各单元将被赋予组名 锚索 N（Cable N），其中 N 为该锚索的 ID 号；起始与终止节点将分别被赋予组名 锚索起点（Cable Begin） 与 锚索终点（Cable End）。要自定义这些赋值，见 group、grop-begin 与 group-end 关键字。

by-line v1 v2 [cablecreateblock]

创建一个位于 v1 与 v2 之间直线上的单元。与该单元关联的新节点也会被创建（见 id 关键字）。各新单元的节点连接排序使自 v1 到 v2 的方向与自起点到终点的方向一致。若这些位置有网格单元，则单元在其节点处与网格单元附着，使平动自由度与网格单元刚性连接、转动自由度自由。若不需要与网格单元附着，则可在创建并定位单元后用 structure link delete 命令删除连接。

by-nodeids i1 i2 [cablecreateblock]

指定将定义该单元的两个节点的 ID 号（i1、i2）。这些节点必须已存在——节点可用 structure node create 创建。节点顺序按下述方式定义梁单元坐标系：正 \(x\) 方向沿从 i1 到 i2 的直线，\(y\) 方向由全局 \(y\) 或 \(x\) 方向投影到单元横截面得到。\(y\) 方向也可用性质 direction-y 修改。

新单元不会附着到网格。若希望附着到网格，则在创建后用 初始化结构节点位置命令（structure node initialize position） 确定其节点位置（该命令会为所有被移入网格单元的节点创建连接并设置适当的附着条件）。

by-ray v1 v2 f [cablecreateblock]

创建一个单元，它位于自 v1 出发、沿 v2 所指定方向延伸 f 距离的直线上。与该单元关联的新节点也会被创建（见 id 关键字）。各新单元的节点连接排序使自 v1 的方向与自起点到终点的方向一致。若这些位置有网格单元，则单元在其节点处与网格单元附着，使平动自由度与网格单元刚性连接、转动自由度自由。若不需要与网格单元附着，则可在创建并定位单元后用 structure link delete 命令删除连接。


structure cable create 关键字块

使用任一个主要关键字创建单元时，可选择性地给出以下关键字：沿线（by-line）、按节点 ID（by-nodeids） 与 按射线（by-ray）。

distinct

取消所创建单元之间的节点共享。每个单元都会新建一组节点，即便它们位于相同空间位置且单元共享相同 ID 号。该选项最常与后续 structure node join 配合，在相同位置节点之间创建连接以实现自定义单元间行为。

group s <slot s >

把所有新建单元赋给组 s。可用可选关键字 slot 指定组槽位；若未指定，则该组被赋给槽位 默认（Default）。组逻辑的用法见 组（Groups）。若未指定，默认组名为 锚索 N（Cable N），其中 N 为赋给该锚索的 ID 号。

group-begin s <slot s >

沿直线所创建单元的第一个节点将被赋予的组名。默认赋给名称为 锚索起点（Cable Begin）。

group-end s <slot s >

沿直线所创建单元的第一个节点将被赋予的组名。默认赋给名称为 锚索终点（Cable End）。

id i

指定将赋给该命令所创建的全部新单元的 ID。若未给出该值，则使用下一个可用 ID。该 ID 按下述方式控制两个单元端节点与已有单元的可能连接：在每个端节点位置都会新建节点，除非同时满足以下条件：1) 已给出 ID；2) 在潜在新节点位置附近找到已有节点；3) 所找到的节点属于 ID 等于 i 的梁。

maximum-length f

把单元分成长度不超过 f 的各段。若同时给出 segments 设置，则按需被该设置覆盖。

segments i

把单元分成 i 个等长段，按需创建新节点。默认值为 1，表示只创建一个单元。

snap <b >

表示所创建单元的首末位置将尝试“吸附”到单元长度一半半径内最近的结构节点（附着于任何单元类型）的位置。若只一端以这种方式吸附，则所创建的整条线将按原位置与吸附位置之差整体偏移。
