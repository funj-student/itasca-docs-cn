structure cable list

语法

structure cable list keyword

主要关键字：

apply    force-axial    节点力（force-node）    分组（group）    grout    information    长度（length）    property    应力（stress）    system-local    yield

列出锚索的信息。

apply

列出所施加的均布荷载

force-axial

节点施加在单元上的轴力

force-node keyword

列出节点力。默认情况下分量按单元局部坐标系显示。这些是节点施加在单元上的力。

local

按单元局部坐标系列出力（默认）

global

按全局坐标系列出力

group <slot s >

列出该单元所属的组。默认列出所有具有组赋值的槽位。若使用 slot 关键字，则只列出该槽位的内容。

grout

浆体中的剪应力

information

列出单元一般信息，包括 id 与 component-id 号、相连节点、形心、表面积、体积以及隐藏与选择状态

length

列出单元长度

property keyword ... <range>
density

密度，\(ρ\)

youngs

杨氏模量，\(E\)

poisson

泊松比 \(ν\)

grout-cohesion

浆体黏聚强度 \(c_g\)

grout-friction

浆体摩擦角 \(φ_g\)

grout-stiffness

浆体刚度 \(k_g\)

grout-perimeter

浆体外露周长 \(p_g\)

plastic-moment

塑性弯矩 \(M^P\)

slide

滑动标志

slide-tolerance

滑动容差

tensile-failure-strain

拉伸破坏应变（无量纲）

thermal-expansion

热膨胀系数 \(α_t\)

cross-sectional-area

横截面积 \(A\)

yield-compression

抗压屈服强度 \(F_c\)

yield-tension

抗拉屈服强度 \(F_t\)

stress

单元中的轴向应力

system-local

单元局部坐标系

yield

单元本身是否已屈服的指示符
