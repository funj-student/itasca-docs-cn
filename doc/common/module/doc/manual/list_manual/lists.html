列表

术语 list 可作为命令词出现。考虑：

列出网格单元数据（zone list）       列出几何对象命令（geometry list）       ball list
列出碎片命令（fragment list）       block list       etc.

该术语也可能是命令中可用的关键字之一。例如见：

zone water       调试FISH函数命令（fish debug）       zone interface node
block fluid       设置流体分析参数命令（model fluid）       etc.

无论在命令中还是作为关键字，功能都相同：使用时 list 把输出返回到 i 控制台（Console） 窗格或 i 列表（Listing） 窗格，取决于要返回的信息长度。

熟悉本程序早期版本的用户会认出该功能即旧的 LIST 命令。不过在 新语法中的通用命令（common commands in the new syntax） 中，并不提供独立的 list 命令。相应地，列表逻辑在需要之处——作为命令词或关键字——出现在提供列表功能的模型对象中。
