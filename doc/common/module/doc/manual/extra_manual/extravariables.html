额外变量

多数模型对象（网格单元、网格点、结构单元等）都有用于存放用户定义变量的 extra 存储空间，可赋值并可视化。例如设想在模拟某一时刻存储各网格单元的最大与最小应力。该信息可存入与各网格单元关联的额外变量中。

fish define setExtra
   loop foreach local z zone.list
       zone.extra(z,1) = zone.stress.min(z)
       zone.extra(z,2) = zone.stress.max(z)
   endloop
end

此时 单元附加变量（zone.extra） FISH 内建函数的第二个参数为相应额外变量的索引。因此每个具备额外变量能力的模型对象可赋予多个额外变量（最多 128 个）。另请注意额外变量可为任何有对应 FISH 类型的类型（即 布尔值（boolean）、整数（integer）、浮动（float）、字符串（string）、vector、矩阵等）。
