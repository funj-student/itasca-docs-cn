值修饰符（add、multiply、gradient 与 vary 关键字）

设置取值时（例如为网格单元或面赋予性质、初始条件或施加力），既可作简单赋值，也可对现有值作算术调整（add、multiply），还可给出空间上的线性分布（梯度（gradient）、应用线性变化（vary））。设置取值的命令不一定支持每种修饰方式。但当这些修饰符可用时，其作用方式如此处所述。

加法

add 关键字最简单。它把所给值加到现有值上。若使用 gradient 或 vary 关键字，则它们作用于所加的值。

乘法

multiply 关键字把现有值乘以该关键字所给因子。若使用 gradient 或 vary 关键字，则它们作用于该因子。

Gradient

gradient 关键字提供指定取值线性变化的方法。其形式为：

gradient v <origin v>

考虑以下命令。

zone apply force-y 1.0 gradient (2,4,3) origin (1,2,3) range pos-y 1 10

对范围内 y=1 到 y=10 的每个网格单元，按下述方式对网格单元中的 y 向力施加梯度：取基准值（1.0）并加上如下取值：

网格单元 \(x\) 分量的 2 倍减 1 加上
网格单元 \(y\) 分量的 4 倍减 2 加上
网格单元 \(z\) 分量的 3 倍减 3。

该值按以下关系变化：

\[\textrm{modified\_value} = \textrm{value} + v\cdot (p - o)\]

使用 gradient 时，\(value\) 在 gradient 关键字之前给出（即为该命令提供的“未修饰”值）；\(p\) 为对象位置；\(o\) 为计算原点；\(v\) 为梯度因子。

origin 关键字为可选，默认为 (0,0,0)。

梯度误差

若把向量 gradient 关键字施加于向量值（例如 displacement 1 3 5 gradient 2 4 3），将产生错误。

Vary

vary 关键字提供指定线性变化的方法。这会在所选范围的 \(x\)、\(y\) 与 \(z\) 范围上改变某分量值。考虑以下命令。

zone apply force-y 1.0 vary (2,4,3) range pos-y 1 10

对形心位于 y=1 到 y=10 范围内的网格单元，按下述方式改变作用于其上的 \(y\) 向力：取基准值（1.0），并加上一个在范围 \(x\) 方向上自 0 变到 2、在 \(y\) 方向上自 0 变到 4、在 \(z\) 方向上自 0 变到 3 的取值。

该值按以下关系变化

\[\textrm{modified\_value} = \textrm{value} + \left((p-l)\over(u-l)\right)v\]

其中 \(l\) 为范围（extent）的向量下界，\(u\) 为范围的向量上界，\(v\) 为 vary 向量，\(p\) 为对象的向量位置。

变化误差

若把向量 vary 关键字施加于向量值（例如 displacement 1 3 5 vary 2 4 3），将产生错误。
