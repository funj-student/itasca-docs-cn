范围短语中的逻辑运算

范围短语通过指定一个或多个范围元素（命令中 range 关键字之后的关键字）来定位一组对象。若指定多个范围元素，则范围短语最终返回的对象集合默认是各范围元素的交集。

union
可在范围短语内任意位置指定 union 关键字，以返回现有范围元素并集的取值范围。
not
可在特定范围元素末尾使用 not 关键字，以返回该元素所指定对象的补集。not 关键字必须出现在范围元素说明的末尾（例如 range position-x 0 100 not position-y 0 100 not）。
extent
在范围短语中使用 extent 关键字时，用对象范围（而非对象形心）检验对象是否位于该范围内。该关键字只适用于几何范围元素（例如 球体（sphere））。
or sub-keyword
用 分组（group） 关键字与 测量面（surface） 关键字构造的范围元素具有 or 子关键字，以便在单个范围元素中连接多个组或面。

逻辑运算与命名范围

使用 named-range 关键字可把现有命名范围插入范围短语，并在其中作为范围元素处理。上述逻辑运算均适用（例如 ... range named-range 'fred' not 将返回不在命名范围 'fred' 中的所有对象）。更多信息见下一主题 命名范围（Named Ranges）。
