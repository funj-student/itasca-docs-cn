命名范围

创建命名范围为后续使用该范围提供便捷途径。命名范围用 设置命名范围命令（model range） 命令创建。例如：

model range create 'fred' position-x 5 500 id 100 200 group 'external' not

创建后，后续命令在范围短语中用 命名范围（named-range） 关键字施加该命名范围：

geometry group edge 'mainedges' range named-range 'fred'

这等价于：

geometry group edge 'mainedges' range position-x 5 500 ...
                                      id 100 200 group 'external' not

由于第二条命令中定义并命名的组 'mainedges' 使用 'fred' 作为其定义，看起来二者似指同一事物。然而：

zone cmodel assign 'mohr' range named-range 'fred'   ; 能够正常运行
zone cmodel assign 'elastic' range group 'mainedges' ; 会失败

后一条命令失败，因为 'mainedges' 是几何面的组，把它用于影响网格单元的命令毫无意义（错误）。若组 'mainedges' 由网格单元组成，则该用法可以接受。进一步讨论见下文。

命名范围与组的比较

组与命名范围有相似之处：二者都提供为某个特定“选择”命名并复用的便利机制——考虑到某些范围短语极为冗长，这并非小事。二者均可用于定义对方（即用组可借一个或多个命名范围定义，反之亦然）。

然而存在关键差异。命名范围是存储的范围短语：一组用于选取模型对象的准则。它在不同时刻可能返回不同结果，取决于模型行为与范围定义。此外命名范围可应用于不同类型的对象。而组始终是特定类型的特定对象集合，只有当组成员被显式添加、移动或删除时才会改变。
