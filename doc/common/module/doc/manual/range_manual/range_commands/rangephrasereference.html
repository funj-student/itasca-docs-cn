范围短语关键字参考

range keyword ...

主要关键字：

union    use-hidden    selected    deselected    按（by）    not    extent    环形（annulus）    长宽比（aspect-ratio）    圆（circle）    cmodel    集合（collection）    分量 ID（component-id）    分量 ID 列表（component-id-list）    ID 列出命令（id-list）    凹角检查（concave）    圆柱（cylinder）    可变形（deformable）    dfn    3DEC 离散裂隙网络（dfn-3dec）    displacement    边长（edge-length）    ellipse    已开挖（excavated）    extra    附加变量列出命令（extra-list）    面面积（face-area）    FISH函数（fish）    裂隙 ID（fracture-id）    几何距离（geometry-distance）    几何空间（geometry-space）    分组（group）    分组相交（group-intersection）    ID 标识（id）    ID 列出命令（id-list）    索引列出命令（index-list）    接触面（interface）    joint-set    命名范围（named-range）    方位（orientation）    平面（plane）    多边形（polygon）    position    position-x    position-y    position-z    投影范围命令（project-range）    矩形（rectangle）    种子（seed）    set    球体（sphere）    状态（state）    结构类型命令（structure-type）    测量面（surface）    velocity    volume    墙体（wall）

创建范围短语。范围短语（常简称“range”）由一个或多个所给范围元素（关键字）组成。注意该短语可含多个范围元素，包括同一范围元素的多个实例（例如 分组（group） 关键字）。存在多个元素时，默认作用于所有范围元素交集中的对象。

若命令未附带范围短语，则受该命令影响类型的所有对象都受影响。

有些关键字可指定改变整个范围行为的方式。它们可出现在范围内的任意位置，只要位于范围元素之间而非其内部。它们是：

union

把范围设为所给范围元素的并集（默认情况下范围选取所有范围元素的交集）。采用该关键字后，只要对象被任一范围元素选中，它就被该范围选中，无论是否被其他元素选中。

use-hidden

包含隐藏对象。默认情况下，被隐藏的对象绝不会被范围包含。若指定该关键字，则隐藏对象也被考虑。[通用问题] 见 ref-selecthide-。

selected

包含已被选中的对象。这使范围只考虑被选中的对象。[通用问题] 见 ref-selecthide-。

deselected

包含未被选中的对象。这使范围只考虑未被选中的对象。[通用问题] 见 ref-selecthide-。

范围元素还有若干标准修饰符。这些关键字必须在范围元素完整描述之后给出，用于改变该范围元素的行为。可用的范围元素修饰符为：

by keyword

许多范围元素会沿对象层次结构查找以判定该对象是否应被选中。例如网格单元网格点会检查其所附着的任一面是否会被选中，或其所附着的任一网格单元是否会被选中。有时需要指定出于该目的应考虑的对象类型。网格单元数据类型可指定 zone-face、zone-gridpoint 或 zone。结构单元数据类型可指定 structure-node、structure-link 或 structure-element。几何数据类型可指定 geometry-node、geometry-edge、geometry-polygon 或 geometry-set。离散裂隙网络数据类型可指定 dfn、dfn-fracture、dfn-intersection 或 dfn-intersection-set

not

反转该范围元素的选择。原本会被选中的对象不再被选中，反之亦然。例如要选择除 \(x\) 位置介于 1.0 与 2.0 之间的对象之外的所有对象，请使用范围元素 position-x 1.0 2.0 not。

extent

要求对象整体范围位于该范围元素内。这影响依据位置选择对象的几何范围元素（如 sphere、position 等）。若未指定，则只需形心位置位于范围元素内即认为该对象在范围内。并非所有几何范围元素都支持该关键字。

以下关键字描述可加入范围的各范围元素。

annulus keyword ...

选择球形环区域内的对象。该区域由中心 v、内半径 f1 与外半径 f2 定义。该几何元素支持 extent 关键字。

center v

定义环带的中心。若未指定则默认为原点 (0,0,0)

radius f1 f2

定义环带的内半径（f1）与外半径（f2）。若未指定，二者默认均为 0.0。若 f1 > f2，则不存在可选体积。

aspect-ratio 浮点值下限（fl ）浮点值上限（fu ）(3DEC-specific)

选择最大长宽比介于所给上下限之间的块体。长宽比定义为最大边长除以体积的立方根。若其他对象与符合该准则的块体相关联，则也会被选中。

circle keyword ... (2D ONLY)

选择圆形区域内的对象。

center f

圆形区域的中心。

radius f

圆形区域的半径。

cmodel s

选择模型名与 s 匹配的网格单元。关键字名称见 zone cmodel 命令。若网格点或面附着于模型名匹配的网格单元，则也被选中。所有其他对象类型不被选中。

collection 索引长度（il ）<iu > (3DEC-specific)

选择具有所给集合 ID 的结构单元（梁、锚索、衬砌、加筋）。区间（索引长度（il），内部单元（iu））为闭区间——若未指定 内部单元（iu），则把 内部单元（iu） 设为等于 索引长度（il）。

component-id i1 <i2 >

对多数对象而言，这与 id 范围元素相同。它依据对象创建时内部赋予的 ID 号选择对象。对结构单元，ID 号指标识一组单元的用户定义编号；此时 component-id 范围元素指单个对象的内部唯一 ID 号。

component-id-list i1 ...

对多数对象而言，这与 id-list 范围元素相同。它依据对象创建时内部赋予的 ID 号选择对象。对结构单元，ID 号指标识一组单元的用户定义编号；此时 component-id-list 范围元素指单个对象的内部唯一 ID 号。

id-list i1 ...

选择 ID 号与所给 ID 号列表匹配的对象。这些 ID 号不必连续。即使所给 ID 号数量很大，该范围元素也针对高效搜索做了优化。

concave (3DEC-specific)

选择凹形块体。若其他对象与符合该准则的块体相关联，则也会被选中。

cylinder keyword ...

选择圆柱内的对象。该圆柱（或圆柱环）的中心轴起于 v1、止于 v2，半径为 摩擦比 1（fr1）。该几何元素支持 extent 关键字。

end-1 v1

指定圆柱中心轴的起点。若未指定则默认为 (0,0,0)。

end-2 v2

指定圆柱中心轴的终点。若未指定则默认为 (0,0,0)。

radius 摩擦比 1（fr1 ）<fr2 >

指定圆柱的半径。若指定 摩擦比 2（fr2），则范围为从 摩擦比 1（fr1） 到 摩擦比 2（fr2） 的圆柱环。

deformable (3DEC-specific)

选择可变形（已划分网格）的块体。若其他对象与符合该准则的块体相关联，则也会被选中。

dfn s keyword ...

依据对象到名为 s 的离散裂隙网络的距离选择对象。可用 name 关键字把更多裂隙网络加入同一元素。该元素可与 extent 关键字一起使用，任何实际与范围相交或位于其内部的裂隙视为距离 0.0。

aperture b

在距离计算中使用开度。距离计算时裂隙沿法向两侧各扩展 1/2 开度。

distance f

指定到所指定裂隙中任一裂隙的距离，落在此距离内的对象将被选中。

name s

指定距离测试时要包含的附加 DFN。

orientation b <f >

仅当对象方位在距裂隙 f 以内时才选择该对象，其中 f 为角度（度）。若未给出，则 f 默认为 2 度。

dfn-3dec s keyword ... (3DEC-specific)

选择由名为 s 的离散裂隙网络生成的面、接触或子接触。只有位于 DFN 裂隙上的对象才会被选中。其他对象将依据其关联的接触或子接触被选中。

displacement 浮点值下限（fl ）浮点值上限（fu ）(3DEC-specific)

选择顶点最大速度介于所给上下限之间的块体、面、顶点或网格单元。若其他对象与符合该准则的块体相关联，则也会被选中。

edge-length 浮点值下限（fl ）浮点值上限（fu ）(3DEC-specific)

选择最小边长介于所给上下限之间的块体。若其他对象与符合该准则的块体相关联，则也会被选中。

ellipse

选择椭圆柱内的对象。四个向量定义空间中的一个平面矩形，椭圆内接于该矩形。

origin v

若给出该关键字，则生成截断椭圆锥，其中 v 为锥顶点，椭圆内接于 vertices 所给矩形所构成的曲面。

vertices v1 v1 v1 v1

这些向量应按逆时针绕向描述空间中的一个平面矩形。一个垂直于该平面无限延伸的椭圆柱内接于该矩形。

excavated (3DEC-specific)

选择已被开挖的块体。若其他对象与符合该准则的块体相关联，则也会被选中。

extra i f1 <keyword>

依据赋给对象的额外变量中索引 i 处的取值过滤。该值假定为数值类型（整数或实数）。若未给出附加关键字，则当取值落在 1.19e-7 乘以 f1 之内时被选中；若 f1 为 0.0，则落在 1.19e-7 之内时被选中。

f2

若指定第二个值，则该元素选择介于 f1 与 f2 之间（含端点）的所有值。

tolerance f

若给出该关键字，则该元素选择 f1 容差内的所有值。所给容差为 f 乘以 f1，若 f1 为 0.0 则仅为 f。

extra-list i i1 ...

依据赋予对象的额外变量中索引 i 处的取值过滤。该值假定为整数类型。其后可跟任意数目的整数，不必连续。即使所给数字数量很大，该范围元素也针对高效搜索做了优化。

face-area 浮点值下限（fl ）浮点值上限（fu ）(3DEC-specific)

选择最小面积介于所给上下限之间的块体。若其他对象与符合该准则的块体相关联，则也会被选中。

fish s

调用由 FISH 函数 s 实现的用户定义范围元素，该函数必须声明为接受两个参数的函数。对每个被查询是否纳入范围的对象都会调用 s。第一个参数为对象的向量位置，第二个参数为对象本身的指针。对象类型可用 FISH 内建函数 指针类型名称（type.pointer） 或 指针名称（type.pointer.name） 判定。若对象不在范围内，则应在函数内把 s 设为 假值（false）；若未设置，每次调用该函数时 s 默认为 真值（true）。

由于使用该范围元素会调用 FISH 并可能对模型状态产生副作用，因此不允许在绘图窗口中包含它。

fracture-id 索引长度（il ）<iu > (3DEC-specific)

选择具有所给裂隙 ID 的接触、子接触或面。裂隙 ID 对应用于创建该对象的 DFN 裂隙 ID。若网格单元、块体或顶点的某个面符合准则，则它们将被选中。若流平面顶点关联的子接触符合准则，则该顶点被选中。区间（索引长度（il），内部单元（iu））为闭区间——若未指定 内部单元（iu），则把 内部单元（iu） 设为等于 索引长度（il）。

geometry-distance s keyword

选择落在名为 s 的几何集合所定义的点、边与多边形一定距离内的对象。该几何元素接受 extra 关键字。若使用 extent 关键字，则实际与该几何集合中元素相交的对象视为距离 0.0。可用以下关键字。

gap f

定义对象被选中所需的到该集合的最大距离。若未指定，则使用 0.0。

set s

把名为 s 的附加几何集合加入待检查集合列表。

geometry-space s keyword ...

依据对象相对名为 s 的几何集合中多边形的位置选择对象。指定一个方向向量，从对象位置沿该方向发出射线，统计射线与几何多边形的相交次数。可选择具有给定交点计数的对象。

若某集合中的多边形构成拓扑封闭体（或在此目的上足够接近），则奇数计数位于体内、偶数计数位于体外。几何逻辑会检测拓扑封闭体的生成，并允许对该数据使用 inside 与 outside 关键字。若并非完全封闭，可用 count odd 或 count even 近似。

注意几何数据可能在同一空间位置包含多个独立多边形，若存在这种情况会改变交点计数过程。

count keyword

按交点数选择位置。按计数有三种可能选项：

i

选择交点计数恰为该值的对象。这可用于在复杂曲面集合中选取特定区域，无论这些曲面是否封闭或相交。

even

选择交点计数为偶数的对象。若多边形构成完全封闭的体积（或在此意义上等效），则会选中该体积外部的对象。

odd

选择交点计数为奇数的对象。若多边形构成完全封闭的体积（或在此意义上等效），则会选中该体积内部的对象。

direction v

指定自被检查位置投射射线的方向。默认该方向为 (0,0,1)。

inside

选择拓扑封闭体内部的对象。

outside

选择拓扑封闭体之外的对象。

set s

把名为 s 的附加几何集合加入待检查集合列表。

group s keyword ...

选择与组 s 关联的对象。组逻辑的用法见 组（Groups） 一节。[通用问题] 见 ref-flac3dcommandconstructs-。

组与槽位都可编码进单个字符串 s。为此请使用 槽位名=分组名（'slotname=groupname'） 构造，其中等号左侧名称为槽位，右侧名称为组。

and s

允许增加一个附加组。对象必须同时含两个组（在不同槽位中）才被视为该范围的一部分。该关键字不能与 or 关键字或 slot 关键字组合。注意此处可使用 槽位名=分组名（'slotname=groupname'） 构造。任意数目的 and 关键字均可组合。

by keyword

对参与层次结构的对象（例如与面相连、面又与网格单元相连的网格点），可能有多个对象匹配组指定。默认只要有一个匹配就认为该对象被选中。该关键字可把参与匹配的对象类型限定为特定类型，而与被选择的对象类型无关。例如可用 by zone 只选择与属于某组的网格单元相连的网格点，而不管这些网格点本身是否属于该组。

虽然可用关键字更多，但以下清单是一般只需用到的。

dfn

按 DFN 过滤。

geometry-edge

按几何边过滤。

geometry-polygon

按几何多边形过滤。

geometry-set

按几何集合过滤。

structure-element

按结构单元过滤。

structure-node

按结构节点过滤。

zone

按网格单元过滤。

zone-face

按网格单元面过滤。

matches i

对参与层次结构的对象（例如与面相连、面又与网格单元相连的网格点），可能有多个对象匹配组指定。默认只要有一个匹配就认为该对象被选中。该关键字可用于要求必须有多个对象匹配。

only

表示对象必须恰好匹配所指定的组列表、不含其他组才会被选中。例如若指定为 group 'fred' and 'george' only，则属于组 示例函数名 fred（fred） 与 示例函数 george（george） 的对象只有在未再被赋予附加组时才被选中。

or s

允许增加一个附加组。只要对象匹配所给组中任一个即被选中。该关键字不能与 and 关键字或 only 关键字组合使用。注意此处可使用 槽位名=分组名（'slotname=groupname'） 构造。

slot s

指定将搜索对象上的哪个组槽位。该值会被在字符串中编码了槽位名的组名所覆盖。若未指定槽位，则在对象所含的所有槽位中检查该组。

group-intersection s1 s2 <slot s3 > (3DEC-specific)

选择块体在槽位 \(s3\) 中同时属于组 s1 与 s2 的交集处的对象。若未指定槽位，则在对象所含的所有槽位中检查该组。

这可用于选择位于具有不同组名的块体之间的接触或面（例如在开挖前识别隧洞表面）。

id 索引长度（il ）<iu >

选择具有所给 ID 号的对象。区间（索引长度（il），内部单元（iu））为闭区间——若未指定 内部单元（iu），则把 内部单元（iu） 设为等于 索引长度（il）。

注意对结构单元，该元素按创建时所赋的组 ID 号选择。要选择单个单元、节点或连接，请使用 component-id 范围元素。

id-list i1 ...

选择 ID 号与所给 ID 号列表匹配的对象。这些 ID 号不必连续。即使所给 ID 号数量很大，该范围元素也针对高效搜索做了优化。

注意对结构单元，该元素按创建时所赋的组 ID 号选择。要选择单个单元、节点或连接，请使用 component-id-list 范围元素。

index-list i1 ... (3DEC-specific)

选择索引（偏移）与所给索引号列表匹配的对象。这些索引号不必连续。即便所给索引号数量很大，该范围元素也针对高效搜索做了优化。

interface s1 ...

选择与名称匹配的界面关联的对象。可指定任意数目的界面名称，只要对象与其中任一个关联，该元素即返回匹配。

这可用于选择界面、界面节点与界面单元。

它还可用于选择附着或连接到该界面的网格单元、网格单元面与网格单元网格点。若界面已创建但尚未用 求解模型（model solve） 或 执行计算时步（model cycle） 命令循环过，则尚未执行接触检测，目标侧的对象不会被选中。

joint-set i ... (3DEC-specific)

选择与所指定节理集 ID 关联的对象。可指定任意数目的 ID，只要对象与其中任一个关联，该元素即返回匹配。

这可直接选择块体接触、子接触与面。若某个宿主块体具有匹配的接触，则块体、网格单元、顶点将被选中。类似地，若流平面接触匹配，则流平面、流平面网格单元与流平面顶点将被选中。

named-range s

把命名范围 s 用作当前范围短语中的一个元素。见命令 创建模型范围命令（model range create）。

orientation keyword ...

选择方位或空间方向匹配的对象。方位可用 dip 与 dip-direction 指定，或用 normal 向量指定。

目前该元素只能用于网格单元、网格单元面或网格单元网格点对象。网格单元面按面法向向量选取。只要网格单元的任一面被选中，该网格单元即被选中。而网格单元网格点只要其相连的任一面被选中即被选中。

dip f

以度为单位指定方位倾角——方位定义为具有该 dip 的平面法向向量。

dip-direction f

以度为单位指定方位倾向——方位定义为具有该 dip-direction 的平面法向向量。

normal v

以向量指定方位。

tolerance f

指定方位容差。若对象方位落在所给方位 f 度以内，则被选中。默认值为 2.0 度。

plane keyword ...

按无限平面周围的区域选择。平面由 origin 与 dip 和 dip-direction 定义，或用 normal 定义。平面周围区域由 above、below 或 distance 定义。该几何元素接受 extra 关键字。

above

平面之上的半空间

below

平面之下的半空间

dip-direction f

倾向角 [度]，在全局 xy 平面中自正 y 轴顺时针量测

dip f

倾角 [度]，从全局 xy 平面沿负 z 方向量测

distance f

距平面 f 以内的区域

normal v

平面的单位法向向量

origin v

平面上一点

polygon keyword

选择多边形柱体内部的对象。一组向量定义空间中的一个平面多边形，选取体积即把该多边形沿平面法向向两侧无限拉伸所形成的多边形柱体。

origin v

若给出该关键字，则生成截断多边形锥，其中 v 为锥顶点，多边形由 vertices 中的向量描述。

vertices v1 ...

这些向量应描述空间中的一个平面多边形。一个垂直于该平面无限延伸的多边形柱体被选中。

position 矢量长度（vl ）<keyword>

选择坐标落在由下界点 矢量长度（vl） 与上界点 vu 所定义盒体内的对象。该几何元素接受 extent 范围元素修饰符。

若未指定 vu，则容差把下界点定义为 矢量长度（vl） - (f,f,f)，上界点定义为 矢量长度（vl） + (f,f,f) * 矢量长度（vl）。注意只有在未指定 vu 时才应指定容差。

vu

表示若对象位置落在 矢量长度（vl） 与 vu 所定义的盒体内，则该对象被选中。

tolerance f

表示若对象位置落在由 矢量长度（vl） +/- (f,f,f) \(\cdot\) 矢量长度（vl） 所定义的盒体内，则该对象被选中

position-x 浮点值下限（fl ）<keyword>

按对象位置的 \(x\) 分量选择对象。若未给出附加关键字，则当取值落在 1.19e-7 乘以 f1 之内时被选中；若 f1 为 0.0 则落在 1.19e-7 之内时被选中。该几何元素接受 extent 范围元素修饰符。

f2

指定一个端点。若指定，则该元素选择介于 f1 与 f2 之间（含端点）的所有值。

tolerance f

指定容差。若指定，则该元素选择 f1 容差内的所有值。所给容差为 f 乘以 f1，若 f1 为 0.0 则仅为 f。

position-y 浮点值下限（fl ）<keyword>

按对象位置的 \(y\) 分量选择对象。若未给出附加关键字，则当取值落在 1.19e-7 乘以 f1 之内时被选中；若 f1 为 0.0 则落在 1.19e-7 之内时被选中。该几何元素接受 extent 范围元素修饰符。

f2

指定一个端点。若指定，则该元素选择介于 f1 与 f2 之间（含端点）的所有值。

tolerance f

指定容差。若指定，则该元素选择 f1 容差内的所有值。所给容差为 f 乘以 f1，若 f1 为 0.0 则仅为 f。

position-z 浮点值下限（fl ）<keyword>

按对象位置的 \(z\) 分量选择对象。若未给出附加关键字，则当取值落在 1.19e-7 乘以 f1 之内时被选中；若 f1 为 0.0 则落在 1.19e-7 之内时被选中。该几何元素接受 extent 范围元素修饰符。

f2

指定一个端点。若指定，则该元素选择介于 f1 与 f2 之间（含端点）的所有值。

tolerance f

指定容差。若指定，则该元素选择 f1 容差内的所有值。所给容差为 f 乘以 f1，若 f1 为 0.0 则仅为 f。

project-range s

把项目命名范围 s 作为元素插入当前范围短语。项目命名范围可在用户界面中创建，且仅能在绘图命令中有效使用；在其他情形下会产生错误。

rectangle keyword

选择矩形柱体内的对象。一组四个向量定义空间中的一个平面矩形，选取体积即把该矩形沿平面法向向两侧无限拉伸所形成的矩形柱体。

origin v

若给出该关键字，则生成截断矩形锥，其中 v 为锥顶点，矩形由 vertices 中的向量描述。

vertices v1 ...

这些向量应描述空间中的一个平面矩形。一个垂直于该平面无限延伸的矩形柱体被选中。

seed 矢量源（vsource ）v 方向（vdir ）keyword

按种子网格单元面选择。种子面通过从 矢量源（vsource） 出发、沿 v 方向（vdir） 方向延伸的射线确定。种子面是射线相交的第一个可见网格单元面。按所给关键字，用该面的性质确定范围内对象的选择准则。例如若使用 group 关键字，且首先击中的面在槽位 默认（Default） 中具有组赋值 示例函数名 fred（fred），则所有含该组赋值（且不含其他组赋值）的对象都将被选中。

cmodel

依据该面所属网格单元所赋的力学本构模型选择。

group <slot s >

依据赋给该面的组选择。若使用可选 slot 关键字指定槽位，则只匹配该槽位的内容。组逻辑的用法见 组（Groups）。

uniform

选择所有对象。

set keyword ...

依据父子关系选择。

id i

用于过滤的集合 ID。

name s

用于过滤的集合名称。

typename s

用于过滤的集合类型名。该参数可与嵌套层次一起使用。

sphere <keyword ...>

选择球形区域内的对象。该几何元素接受 extent 范围元素修饰符。

center v

指定球心。默认该值为 (0,0,0)。

radius f

指定球半径。默认该值为 0.0。

state s

依据网格单元本构模型的状态指示符选择对象。s 与本构模型返回的任何状态名匹配。报告该状态的网格单元将被该元素选中。

若网格单元网格点或网格单元面所附着的任一网格单元被选中，则它们也被选中。

以下关键字依据各网格单元内部四面体 overlay 分别保留的状态，改变网格单元状态的报告方式。

any

只要网格单元内部四面体中任一具有该状态，就认为该网格单元具有此状态。

average

只有当至少 50%（按体积）的四面体具有该状态时，才认为该网格单元具有此状态。这是默认设置。

structure-type keyword

选择特定类型的结构单元。可用类型关键字为 beam、cable、geogrid、liner、pile、shell，以及特殊关键字 any（表示任何单元类型均可接受）。

若结构节点或连接所连的任一单元被选中，则它们也被选中。

surface keyword

若网格单元面落在模型“表面”上则选择它。表定义为只有一个网格单元与之相连的面，或只有一个有效非空网格单元与之相连的面。

默认只用力学模型判定网格单元是否为空。以下关键字可控制为此目的如何判定空网格单元。注意若给出任何关键字，则不再假定默认的 mechanical 设置，必须显式给出。

fluid

用流体模型判定是否为空。

mechanical

用力学模型判定是否为空。

or

默认情况下，若指定多个准则，则这些准则须全部为空才把网格单元整体视为空。若使用该关键字，则只要其中任一为空即视为空网格单元。

thermal

用热学模型判定是否为空。

velocity 浮点值下限（fl ）浮点值上限（fu ）(3DEC-specific)

选择顶点最大速度介于所给上下限之间的块体、面、顶点或网格单元。若其他对象与符合该准则的块体相关联，则也会被选中。

volume 浮点值下限（fl ）浮点值上限（fu ）(3DEC-specific)

选择体积介于所给上下限之间的块体。若其他对象与符合该准则的块体相关联，则也会被选中。

wall (3DEC-specific)

选择作为墙的块体。若其他对象与符合该准则的块体相关联，则也会被选中。
