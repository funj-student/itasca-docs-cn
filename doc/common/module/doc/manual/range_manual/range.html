范围

命令将作用于该命令所有可能的目标对象（例如网格单元、球、块体、网格点、结构单元等）。

范围（range） 施加于命令时，提供把该命令的作用限制到目标对象子集的手段。该子集由范围元素定义，即命令中 范围（range） 关键字之后的关键字（及其取值）。术语 范围短语（range phrase） 指 范围（range） 关键字与一个或多个后续范围元素的组合。范围元素参考清单（reference list of range elements）可通过点击文档中任意 范围（range） 链接访问。

使用时，范围短语（range phrase） 必须始终出现在命令末尾。 多数情况下范围为可选，但有些情形下为必需。整份文档中，命令末尾出现 <范围（range）> 或 范围（range） 表示范围短语可选接受或必需（分别如此）。例如 zone apply 命令的签名：

zone apply keyword ... <range>

最常见的情形是如上所述把范围作为命令末尾出现的关键字使用。但确实存在 设置命名范围命令（model range） 命令。该命令的用途是创建（或删除）命名范围。不过所得命名范围在被作为范围短语中的 命名范围（named-range） 元素使用之前，并不施加于任何对象。更多细节见 命名范围（Named Ranges） 主题。

注意

除非对命令使用范围短语，否则任何命令的作用都施加于该命令所有可能的目标对象。
