group.slot 命令

语法

group slot keyword
create s

创建槽位。槽位被赋予名称 s。创建时没有任何对象或组使用该槽位。不过它会出现在用户界面的可用槽位列表中。

rename 实体（sold ）新字符串（snew ）

查找名为 实体（sold） 的槽位并改名为 新字符串（snew）。引用该槽位的所有对象与组保持不变，只是此后归属于 新字符串（snew）。
