命令

对组名与槽位列表进行操作的命令。

程序维护所有组名（全部槽位中）与所有已创建槽位的全局列表。可查看（列出分组命令（group list））与重命名（重命名分组命令（group rename））这些项。

组赋值用 group 关键字对特定对象类型（如 zone group、几何多边形分组命令（geometry polygon group）、extrude edge group 等）操作来完成。
