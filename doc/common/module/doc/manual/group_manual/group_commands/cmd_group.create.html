group.create 命令

语法

group create s

创建组。组被赋予名称 s。不过该组没有任何对象。

该命令用于不常见但可能出现的情形：为脚本（FISH 或 Python）目的而预先定义组名可避免报错，即便该组本身没有成员。

为创建模型对象组的目的，应优先采用专门用于该目的的命令。完整信息见 组（Groups）。
