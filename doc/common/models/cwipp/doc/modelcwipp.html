WIPP 碎盐模型

FLAC3D/3DEC 实现了碎盐本构模型，用于模拟体积蠕变压密及偏量蠕变压密行为。该模型是WIPP 模型（WIPP model）的一种变体，以 Sjaardema 和 Krieg（1987）的模型为基础，并加入 Callahan 和 DeVries（1991）提出的偏量分量。

公式

在碎盐本构模型中，材料密度 \(\rho\) 随压缩体积应变 \(\epsilon_v\) 演化，从碎盐初始填筑密度 \({\rho}_i\) 逐渐达到完整盐岩的最终密度 \({\rho}_f\)。用于 FLAC3D/3DEC 增量拉格朗日公式的体积应变变化率与密度变化率之间的关系，可按下述方式推导。请注意，按约定，压缩时的应力和应变均取负。

考虑质量为 \(m\) 的给定材料区域，其在时刻 \(t\) 的体积为 \(V_{\circ}\)、密度为 \({\rho}_{\circ}\)。设时间间隔 \(\Delta t\) 内的体积应变增量 \(\Delta \epsilon_v\) 对应体积变化 \(\Delta V\)，以及密度由 \(\rho_{\circ}\) 变为 \(\rho\)。根据质量守恒，有

(1)\[\rho_{\circ} V_{\circ} = \rho (V_{\circ} + \Delta V)\]

根据体积应变的定义，可得

(2)\[\rho = {{\rho_{\circ}}\over{1 + \Delta \epsilon_v}}\]

此外，从连续体观点出发，可以写成

(3)\[\rho = {{m}\over{V}}\]

给定质量对应的密度变化率为

(4)\[\dot{\rho} = -{{m}\over{V^2}} \dot{V}\]

结合 \(\dot{\epsilon_v} = \dot{V} / V\) 与式 (3)，经过整理得到

(5)\[\dot{\epsilon_v} = -{{\dot{\rho}}\over{\rho}}\]

碎盐压密程度以密度比 \(F_d\) 度量，定义为实际盐岩密度与最终盐岩密度之比：

(6)\[F_d = {{\rho}\over{\rho_f}}\]

模型实现假定，蠕变压密机制不可逆，即密度只能增加而不能降低，并且存在上限，即达到完整盐岩密度后不再继续压密。

本构方程

在碎盐模型中，弹性应力率与弹性应变率通过胡克定律的增量形式关联：

(7)\[\dot{\sigma}_{ij} = 2G \left[\dot{\epsilon}_{ij}^e -{{\dot{\epsilon}_{kk}^e}\over{3}} \delta_{ij} \right] + K \dot{\epsilon}_{kk}^e \delta_{ij}\]

其中，\({\delta}_{ij}\) 为 Kronecker δ。

在此表达式中，体积模量 \(K\) 和剪切模量 \(G\) 按以下非线性经验规律与密度关联：

(8)\[K = K_f e^{K_1(\rho - \rho_f)}\]
(9)\[G = G_f e^{G_1(\rho - \rho_f)}\]

其中，\(\rho_f\)、\(K_f\) 和 \(G_f\) 为完整盐岩的属性；\(K_1\) 和 \(G_1\) 为两个常数，由体积模量和剪切模量在初始密度下必须取各自初始值这一条件确定。

假定密度低于完整盐岩密度时，总应变率 \(\dot\epsilon_{ij}\) 可以表示为三个部分之和：非线性弹性部分 \(\dot\epsilon_{ij}^e\)、黏性压密部分 \(\dot\epsilon_{ij}^c\) 和黏性剪切部分 \(\dot\epsilon_{ij}^v\)。弹性应变率的形式为

(10)\[\dot\epsilon_{ij}^e = \dot\epsilon_{ij} - \dot\epsilon_{ij}^c - \dot\epsilon_{ij}^v\]

黏性压密项基于以下形式的试验压密率规律：

(11)\[\dot{\rho}^c = -B_0 \left[ 1 - e^{-B_1 \sigma} \right] e^{B_2 \rho}\]

其中，\(\sigma = \sigma_{kk} / 3\) 为平均应力，\(B_0\)、\(B_1\) 和 \(B_2\) 为根据各向同性压密试验结果确定的常数。

将式 (11) 代替式 (5) 中的 \(\dot{\rho}\)，可推导体积压密应变率 \(\dot\epsilon_v^c\)：

(12)\[\dot{\epsilon_v^c} = {{1}\over{\rho}} B_0 \left[ 1 - e^{-B_1 \sigma} \right] e^{B_2 \rho}\]

本实现假定，只有平均应力为压应力时才会发生体积压密。此外，为前述表达式设置上限，使密度达到完整盐岩密度后不再继续压密。

黏性压密

总压密应变率的表达式为

(13)\[\dot\epsilon_{ij}^c = \dot\epsilon_v^c \left[ {{\delta_{ij}}\over{3}} - \beta {{{\sigma_{ik}^d}{\delta_{kj}}}\over{\bar{\sigma}}} \right]\]

其中，\(\sigma_{ij}^d\) 为偏应力张量，\(\bar\sigma = \sqrt{3J_2}\) 为 von Mises 应力，另有 \(J_2 = \sigma_{ij}^d\sigma_{ij}^d / 2\)。该式中的参数 \(\beta\) 为常数，取值为 1，从而使单轴压缩试验中的侧向压密应变率分量为零。

黏性剪切

黏性剪切应变率与WIPP 模型（WIPP model）相对应。初期蠕变应变率与WIPP 模型（WIPP model）给出的形式相同，但次级蠕变应变率中的偏应力大小 \(\bar\sigma\) 需除以式 (6) 定义的密度比。其形式为

(14)\[\dot\epsilon_s=D\,{\left( {{\bar\sigma}\over{F_d}} \right)}^n e^{(-Q/RT)}\]

其中，各参数的定义与前文相同。

材料接近完全压密时，密度比趋近于 1。由于设置了上限，使达到完整盐岩密度后不再发生蠕变压密，黏性剪切行为会逐渐趋近于完整盐岩。请注意，在 WIPP 模型框架中，完整盐岩的蠕变行为由偏应力触发，而体积行为为弹性。

实现

在碎盐模型的本实现中，总应力和应变率分解为体积部分与偏量部分。先将控制体积行为的增量方程线性化，并显式求解平均应力增量；随后推导蠕变压密应变率，并将其用于偏量行为表达式。偏量部分的其他实现步骤与WIPP 模型（WIPP model）基本一致。最后，根据更新后的体积分量和偏量分量，计算本步总应力。

注意事项

  • 定义弹性性质时，只需提供以下两种组合中的一种：体积模量 \(K\) 与剪切模量 \(G\)，或杨氏模量 \(E\) 与泊松比 \(v\)。
  • 蠕变行为由偏应力触发，而体积变形不考虑蠕变。
  • 两个密度属性 density-salt \(ρ\) 和 density-final \(ρ_f\)，仅应视为本构层面计算的内部变量，不应与真实材料密度混淆。
