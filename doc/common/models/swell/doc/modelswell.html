Swell 模型*

注意

*本模型仅在 FLAC3D 中提供。

该模型基于 Mohr-Coulomb 模型（Mohr-Coulomb model），采用非关联剪切与关联拉伸流动法则。不同之处在于：通过把湿化应变与湿化前的模型状态耦合来计入湿化引起的变形。模型应用与建模流程见 Noorany 等（1999）、Pathak 等（2003）以及 Pathak 等（2010）。屈服函数与势函数、塑性流动法则以及应力修正均与 Mohr-Coulomb 模型相同。

湿化应变与应力修正

湿化引起的应变可表示为主膨胀方向上总压应力 \(\sigma_{z'z'}\)（经大气压 \(p_a\) 归一化）的如下对数或线性函数：

  • 对数函数
(1)\[\begin{split} \begin{matrix} \varepsilon_{z'z'} = c_1 \log [a_1 (-\sigma_{z'z'}/p_a)] \mbox{ , } \sigma_{z'z'} < 0 \\ \\ \varepsilon_{x'x'} = \varepsilon_{y'y'} = c_3 \log [a_3 (-\sigma_{z'z'}/p_a)] \mbox{ , } \sigma_{z'z'} < 0 \end{matrix}\end{split}\]
  • 线性函数
(2)\[\begin{split} \begin{matrix} \varepsilon_{z'z'} = c_1 - a_1 \sigma_{z'z'}/p_a \mbox{ , } \sigma_{z'z'} < 0 \\ \\ \varepsilon_{x'x'} = \varepsilon_{y'y'} = c_3 - a_3 \sigma_{z'z'}/p_a \mbox{ , } \sigma_{z'z'} < 0 \end{matrix}\end{split}\]

上述方程中，\(a_1\)、\(c_1\)、\(a_3\) 与 \(c_3\) 为由室内试验确定的非负湿化性质；按约定压应力与压应变均为负。注意假定湿化应变在横向为各向同性（\(\varepsilon_{x'x'} = \varepsilon_{y'y'}\)）。应力 \(\sigma_{z'z'}\) 为湿化前平衡状态下局部轴中的总竖向应力分量，计算过程中不在公式 (1) 与 (2) 中修改。

随后依据虎克定律的增量形式计算主膨胀方向（由 \(x', y', z'\) 定义）上的相应湿化应力：

(3)\[\begin{split} \begin{matrix} \varepsilon_{x'x'} = \alpha_1 \varepsilon_{x'x'} + \alpha_2 (\varepsilon_{y'y'} + \varepsilon_{z'z'}) \\ \\ \varepsilon_{y'y'} = \alpha_1 \varepsilon_{y'y'} + \alpha_2 (\varepsilon_{z'z'} + \varepsilon_{x'x'}) \\ \\ \varepsilon_{z'z'} = \alpha_1 \varepsilon_{z'z'} + \alpha_2 (\varepsilon_{x'x'} + \varepsilon_{y'y'}) \end{matrix}\end{split}\]

其中 \(\alpha_1 = K + 4G/3\)、\(\alpha_2 = K - 2G/3\)、\(K\) 与 \(G\) 分别为体积模量与剪切模量。

最后，把主膨胀方向的局部应力分解到全局轴，得到全局膨胀应力。随后在指定步数 \(N_s\) 内把全局膨胀应力（按增量）加到全局应力分量上。每一步都依据 Mohr-Coulomb 破坏准则检验所得应力分量是否破坏。注意走完 \(N_s\) 步后应循环至平衡。

实现步骤

在 Swell 模型的实现中，先按 Mohr-Coulomb 模型所述分析该步弹性试探对应的应力。用公式 (3) 计算局部轴（主膨胀方向）中的相应膨胀应力，再分解到全局轴。全局轴中的膨胀应力在指定步数 \(N_s\) 内累加。随后依据 Mohr-Coulomb 破坏准则检验所得应力是否破坏。

按零竖向应力下量测的膨胀量，为膨胀面内与垂直于膨胀面方向的膨胀应变设定上界。程序每步检查湿化应变，一旦超过限值即取上界值。

注意事项

  • 局部膨胀面是一个平面，其定义使膨胀在该平面内为各向同性。
  • 定义弹性性质时，只需提供以下两种组合中的一种：体积模量 \(K\) 与剪切模量 \(G\)，或杨氏模量 \(E\) 与泊松比 \(\nu\)。采用后一种组合时，必须先赋予杨氏模量 \(E\)，再赋予泊松比 \(\nu\)。
  • 抗拉截断为 \({\sigma}^t = min({\sigma}^t, c/\tan \phi)\)。
