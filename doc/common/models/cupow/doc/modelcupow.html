幂律—遍布节理模型

本模型模拟遍布节理岩体的黏弹塑性力学行为，其中岩石基质的蠕变与双分量黏塑性幂律模型（power model）相似。它结合了 FLAC3D/3DEC 中的两个现有模型：双分量黏塑性幂律模型（power model）与弹塑性遍布节理模型（ubiquitous-joint model）。

与双分量黏塑性幂律模型（power model）相比，该模型考虑了一个弱化方向，即弱面。因此，屈服可以发生在实体材料中，也可以沿弱面发生，或在两者中同时发生，具体取决于应力状态、弱面方向，以及实体和弱面的材料属性。

一般破坏修正

在模型公式中，偏应力率为黏弹塑性，表示为：

(1)\[ \dot{S}_{ij} = 2G (\dot{e}_{ij} - \dot{e}^c_{ij} - \dot{e}^p_{ij})\]

其中，\(S_{ij}\) 和 \(e_{ij}\) 为应力张量和应变率张量的偏量部分；\(\dot{S}_{ij}\) 和 \(\dot{e}_{ij}\) 分别为蠕变应变分量和塑性应变分量；\(G\) 为切线剪切模量。

根据 Norton 幂律，利用 von Mises 应力 \(q=\sqrt{3J_2}\) 推导蠕变应变率 \(\dot{e}^c_{ij}\)，其中 \(J_2\) 为偏应力张量的第二不变量：

(2)\[ \dot{e}^c_{ij} = \dot{e}_{cr} {\partial q \over \partial S_{ij}}\]

其中，蠕变强度 \(\dot{e}_{cr}\) 按定义具有两个分量，原文编辑提示：下述章节尚未建立链接，参见第 1.2.2 节；\(\partial q / \partial S_{ij}\) 为蠕变流动方向，由 \(q\) 的定义推导：

(3)\[ {\partial q \over \partial S_{ij}} = {3 \over 2} {S_{ij} \over q}\]

塑性应变率 \(\dot{e}^p_{ij}\) 采用 Mohr-Coulomb 流动法则定义：

(4)\[ \dot{e}^p_{ij} = \dot{e}_p {\partial g \over \partial \sigma_{ij}} - {1 \over 3} \dot{e}^p_{vol} \delta_{ij}\]

其中，塑性体积应变率 \(\dot{e}^p_{vol}\) 为

(5)\[ \dot{e}^p_{vol} = \left[ {\partial g \over \partial \sigma_{11}} + {\partial g \over \partial \sigma_{22}} + {\partial g \over \partial \sigma_{33}} \right]\]

塑性流动率强度 \(\dot{e}_p\) 根据 Mohr-Coulomb 屈服准则推导，\(\partial g / \partial \sigma_{ij}\) 采用 Mohr-Coulomb 势函数 \(g^s\) 表示，见Mohr-Coulomb 模型（Mohr-Coulomb model）。

体积应力率为弹塑性，形式为：

(6)\[ \dot{\sigma}_o = K (\dot{e}_{vol} - \dot{e}^p_{vol})\]

其中，\(\dot{\sigma}_o = (\dot{\sigma}_{11} + \dot{\sigma}_{22} + \dot{\sigma}_{33})/3\)、\(\dot{e}_{vol} = \dot{e}_{11} + \dot{e}_{22} + \dot{e}_{33}\)，且 \(K\) 为切线体积模量。

最终应力张量为偏量部分与各向同性部分之和：

(7)\[ \sigma_{ij} = S_{ij} + \sigma_o \delta_{ij}\]

在主轴形式下，检查 Mohr-Coulomb 屈服准则，并施加相应的塑性处理。原文编辑批注：这里施加的具体是什么塑性量？请注意，在弱面，即遍布节理，不起作用的极限情况下，模型的行为与双分量黏塑性幂律模型（power model）相同。

弱面修正

检查前一步计算所得的应力，以判断弱面是否破坏。将施加塑性修正后得到的全局应力分量 \(\sigma_{ij}\) 转换为局部分量，见遍布节理模型（ubiquitous-joint model）中关于全局与局部坐标系转换的部分。

平面上的破坏准则采用带抗拉截断的局部 Mohr-Coulomb 屈服准则。先在局部坐标轴中修正应力，再转换到全局坐标轴。

请注意，在禁用模型黏塑性响应的极限情况下，其行为与遍布节理模型（ubiquitous-joint model）相同。

模型的实现严格遵循双分量黏塑性幂律模型（power model）和弹塑性遍布节理模型（ubiquitous-joint model）的处理步骤。首先计算岩体的蠕变响应；随后按照遍布节理模型（ubiquitous-joint model）的实现步骤，用黏弹性响应替代“弹性试算值”；最后应用遍布节理模型（ubiquitous-joint model）中的弱面逻辑。

在大应变模式下，会调整弱面方向以计入体转动，方式与遍布节理模型（ubiquitous-joint model）相同。

注意事项

  • 定义弹性性质时，只需提供以下两种组合中的一种：体积模量 \(K\) 与剪切模量 \(G\)，或杨氏模量 \(E\) 与泊松比 \(v\)。
  • 定义弱面方向时，只需提供以下三种形式中的一种：倾角和倾向；法向量（\(n_x\)，\(n_y\)，\(n_z\)）；或三个法向分量 \(n_x\)、\(n_y\) 和 \(n_z\)。
  • 抗拉截断为 \(σ^t\) = min (\(σ^t\), \(c\)/tan\(ϕ\))。
  • 蠕变行为由偏应力触发，而体积变形不考虑蠕变。
