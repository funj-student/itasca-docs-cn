FLAC3D Theory and Background • Constitutive Models

简化帽盖屈服（CHSoil）模型*

注意

*本模型仅在 FLAC3D 中提供。

如CYSoil 模型（CYSoil model）部分所述，土体承受偏应力加载时，通常会出现刚度降低，并伴随不可逆变形。著名的 Duncan–Chang 模型（1970）常用于模拟这种双曲线应力—应变行为，且相对容易使用。但正如CYSoil 模型（CYSoil model）部分指出的，该模型有若干缺点。此外，基于非线性弹性的双曲线关系还存在明显局限（Duncan 等，1980）：1）这些关系适用于破坏前，但在破坏时及破坏后可能给出不真实的土体行为；2）它们不包含剪应力变化引起的体积变化，隐含的剪胀依赖泊松比，因此可能无法准确预测剪胀土体的变形，例如低围压下的密砂；3）这些关系预测 \(\pi\) 平面中的行为为各向同性，而这并不总是符合实际，因为土体的三轴压缩强度与三轴伸长强度通常不同。

CYSoil 模型的简化版本称为 CHSoil 模型，可替代 Duncan–Chang 模型，并避免后者的缺点。CHSoil 模型源自 CYSoil 模型相同的应变硬化/软化逻辑，因此能够给出较为真实的破坏及破坏后应力—应变关系。CHSoil 模型提供内置功能，但不包含体积帽盖。

CHSoil 模型具有三个特定功能：

  1. 内置摩擦硬化规律，直接采用双曲线模型参数作为输入；
  2. 摩擦型 Mohr-Coulomb 剪切包络线；以及
  3. 两种内置剪胀规律：一种基于 Rowe 应力—剪胀理论（Rowe，1962），另一种为用户自定义的剪胀硬化/软化规律。

CHSoil 模型的卸载行为为弹性。再加载时，在达到此前最外侧屈服包络线之前，也保持弹性。请注意，当前形式的 CHSoil 模型并非用于模拟循环加载。

公式

增量弹性定律

CHSoil 模型的弹性行为采用胡克定律表示。用主应力和主应变表示的增量形式为

(1)\[\begin{split}\begin{matrix} \Delta \sigma^{\prime}_1 &= \alpha_1 \Delta e_1^e + \alpha_2 (\Delta e_2^e + \Delta e_3^e) \\ \\ \Delta \sigma^{\prime}_2 &= \alpha_1 \Delta e_2^e + \alpha_2 (\Delta e_1^e + \Delta e_3^e) \\ \\ \Delta \sigma^{\prime}_3 &= \alpha_1 \Delta e_3^e + \alpha_2 (\Delta e_1^e + \Delta e_2^e) \end{matrix}\end{split}\]

其中，\(\alpha_1 = K^e + 4G^e / 3\)、\(\alpha_2 = K^e - 2G^e / 3\)，以及 \(K^e\) 和 \(G^e\) 分别为切线弹性体积模量和剪切模量。

在 CHSoil 模型中，弹性剪切模量取决于平均有效应力的初始值 \(p^{\prime}_m\)。平均有效应力由用户指定，例如可以使用以下表达式：

(2)\[ p^{\prime}_m = - {{\sigma^{\prime}_1+\sigma^{\prime}_2+ \sigma^{\prime}_3}\over 3}\]

\(G^e\) 随 \(p^{\prime}_m\) 的变化可由以下方程表示，例如参见 Byrne 等（2003）：

(3)\[ G^e = G_{ref} p_{ref} \Bigl( {p^{\prime}_m \over p_{ref}}\Bigr)^n\]

参数 \(p_{ref}\) 为参考压力，\(G_{ref}\) 为剪切模量数，其中 \(G_{ref} \times p_{ref}\) 为参考压力下的切线弹性剪切模量。\(n\) 为恒定的模量指数（\(n \le 1\)）。切线弹性体积模量也由以下关系描述：

(4)\[ K^e = K_{ref} p_{ref} \Bigl( {p^{\prime}_m \over p_{ref}}\Bigr)^m\]

参数 \(K_{ref}\) 为体积模量数，乘积 \(K_{ref} \times p_{ref}\) 为参考压力下的切线弹性体积模量；\(m\) 为恒定的模量指数（\(m \le 1\)）。

下面列出 \(K_{ref}\)、\(G_{ref}\)、杨氏模量数 \(E_{ref}\) 及参考压力下泊松比 \(\nu_{ref}\) 之间的一些有用关系，供参考：

(5)\[ K_{ref} = {E_{ref} \over {3 (1 - 2\nu_{ref})}} \qquad G_{ref} = {E_{ref} \over {2 (1 + \nu_{ref})}}\]
(6)\[ {K_{ref} \over G_{ref}} = {{2(1 + \nu_{ref})} \over {3 (1 - 2\nu_{ref})}}\]

用户可以输入 \(E_{ref}\) 与 \(\nu_{ref}\)，也可以输入 \(K_{ref}\) 与 \(G_{ref}\) 作为模型属性。如果指定了 \(E_{ref}\) 和 \(\nu_{ref}\)，则程序根据式 (5) 在内部计算 \(K_{ref}\) 和 \(G_{ref}\)，并将所得值用于式 (3) 和 (4)。泊松比仅允许取小于 0.49 的正值。因此，程序在内部为 \(K^e\) 指定以下上下限：

(7)\[ {2 G^e \over 3} < K^e < 49.66 G^e\]

如上所述，必须将初始平均有效压力 \(p^{\prime}_m\) 作为模型的输入属性。可以使用 FISH 计算该值，并将其存入对应网格单元属性的偏移位置。程序根据式 (3) 和 (4)，利用 \(p^{\prime}_m\) 计算切线弹性剪切模量和体积模量。在本实现中，\(G^e\) 和 \(K^e\) 保持恒定；模量不会随平均有效压力自动更新。

剪切屈服准则与流动法则

剪切屈服采用 Mohr-Coulomb 准则定义，屈服包络线表示为

(8)\[ f^s = \sigma^{\prime}_1 - \sigma^{\prime}_3 N_{\phi_m} +2 c \sqrt{N_{\phi_m}}\]

其中，\(c\) 为黏聚力，\(\phi_m\) 为动员摩擦角；按定义，有

(9)\[ N_{\phi_m}\ =\ {1 + \sin \phi_m \over {1 - \sin \phi_m}}\]

势函数为非关联形式，表示为

(10)\[ g = \sigma^{\prime}_1 - \sigma^{\prime}_3 N_{\psi_m}\]

其中

(11)\[ N_{\psi_m}\ =\ {1 + \sin \psi_m \over {1 - \sin \psi_m}}\]

其中，\(\psi_m\) 为动员剪胀角。文献中有多种不同规律可用于表征 \(\psi_m\)。

默认情况下，可以通过用户自定义的 \(\psi_m\)—\(\gamma^p\) 关系表，将 \(\psi_m\) 定义为塑性剪应变的函数。剪切屈服的演化参数 \(\gamma^p\) 采用以下增量定义：

(12)\[ \Delta \gamma^p = \Delta \epsilon^{ps} = \sqrt{{(\Delta \varepsilon^{dp}_1)^2} + {(\Delta \varepsilon^{dp}_2)^2} + {(\Delta \varepsilon^{dp}_3)^2} } / \sqrt{2}\]

其中，\(\Delta \varepsilon^{dp}_i, i\) = 1,3 为主方向上的偏塑性剪应变增量。

必须将模型参数 flag-dilation 设为零，才能启用此选项。如果 flag-dilation = 0 且未提供表，则假定剪胀角等于通过 dilation 设置的极限剪胀角输入值。请注意，提供剪胀表时，不再使用 dilation。

还提供两种内置剪胀规律。当 flag-dilation = 1 时，采用基于 Rowe（1962）剪胀理论的规律，这是默认设置。另一种选择是简单的阶跃函数：在 \(\phi_m < \phi_{cv}\) 条件下，\(\psi_m\) 为零，其中 \(\phi_{cv}\) 为用户指定的常数；当动员摩擦角大于 \(\psi_{cv}\) 时，\(\psi_m\) 等于通过 dilation 设置的极限剪胀值 \(\psi_f\)。必须将模型属性 flag-dilation 设为 2，才能启用此选项。程序还会在内部强制施加 \(\psi_m\) 不得超过 \(\phi_m\) 的额外约束，以防止产生非预期的能量。

拉伸屈服准则与流动法则

拉伸屈服函数与 CYSoil 模型采用的函数相同，形式为

(13)\[ f^t = \sigma^t - \sigma_3\]

抗拉强度 \(\sigma^t\) 表示为塑性拉应变度量 \(e^{pt}\) 的函数，通过用户自定义表输入。如果未提供表，则假定抗拉强度恒定，等于抗拉强度属性的输入值。

拉伸屈服的演化参数为塑性拉应变的模 \(e^{pt}\)。塑性拉应变增量定义为

(14)\[ \Delta \epsilon^{pt} = \Delta \epsilon^{pt}_3\]

其中，\(\Delta \epsilon_3^{pt}\) 为最大主应力方向的塑性拉应变增量；请注意，拉应力取正。

摩擦硬化

对于大多数土体，排水三轴试验得到的偏应力—轴向应变关系可以用双曲线近似。CHSoil 模型引入摩擦应变硬化规律来描述这种行为。该公式通过以下微分规律，将动员摩擦角 \(\phi_m\) 表示为塑性剪应变度量 \(\gamma^p\) 的函数；此规律类似于 Byrne 等（2003）在 UBCSAND 液化模型中采用的形式：

(15)\[ d(\sin{\phi_m}) = {G^p \over p^{\prime}_m} d(\gamma^p)\]

其中，塑性剪切模量 \(G^p\) 为

(16)\[ \phi_m \le \phi_f : G^p = G^e \Bigl(1 - {\sin{\phi_m} \over \sin{\phi_f}} R_f \Bigr)^2\]

式中，\(G^e\) 为弹性切线剪切模量，\(\phi_f\) 为极限摩擦角，\(R_f\) 为破坏比，是小于 1 的常数，通常取 0.9，用于给定 \(G^p\) 的下限。

根据式 (14)，弹性切线剪切模量是 \(p^{\prime}_m\) 的函数：

(17)\[ G^e = G_{ref} p_{ref} \biggl({p^{\prime}_m \over p_{ref}} \biggr)^n\]

将式 (17) 代入式 (16)，再将所得表达式代入式 (15)，整理后得到

(18)\[ d(\gamma^p) = {p^{\prime}_m \over G^e} {d(\sin{\phi_m}) \over \Bigl(1 - {\sin{\phi_m} \over \sin{\phi_f}} R_f \Bigr)^2}\]

利用 \(\gamma^p\) = 0 时 \(\phi_m\) = 0 的条件，对该方程积分得到

(19)\[ \gamma^p = {p^{\prime}_m \over G^e} {\sin{\phi_f} \over R_f} \Bigl( {1 \over {1 - {\sin{\phi_m} \over \sin{\phi_f}} R_f}} - 1 \Bigr)\]
\[\]

求解 \(\sin{\phi_m}\)，得到

(20)\[ \sin{\phi_m} = {\sin{\phi_f} \over R_f} \Bigl( 1 - {1 \over {1 + \gamma^p {G^e \over p^{\prime}_m} {R_f \over \sin{\phi_f}}}} \Bigr)\]

CHSoil 模型使用该表达式，按塑性剪应变标定动员摩擦角。用这一硬化规律模拟三轴试验的初次加载，可以得到双曲线型的偏应力—轴向应变曲线。

超固结

通过指定摩擦角属性的初始值，可以设定正常固结土或超固结土的初始状态；该值应等于或大于正常固结对应的值 \(\phi_{nc}\)。对于正常固结状态，由式 (15) 和 (19) 得到

(21)\[ \phi_{nc} = \arcsin{ {\sigma^{\prime}_1 - \sigma^{\prime}_3} \over {\sigma^{\prime}_1 + \sigma^{\prime}_3 }}\]

应力点位于当前屈服包络线以内时，材料行为视为弹性。

摩擦角的初始值必须小于极限值 \(\phi_f\)，模型会自动将其上限设为 \(\phi_f\)。程序还会自动给演化参数 \(\gamma^p\) 赋予与所指定初始动员摩擦角相容的初始值。

剪切引起的压密与剪胀

土体剪切预计会引起一定量的不可恢复体积应变 \(\epsilon^p\)。在较小的单调剪应变下，颗粒重排使土骨架倾向于收缩；剪应变较大时，如果土体密实，颗粒相互爬升则可能使土骨架剪胀。模型中引入剪胀应变硬化规律来模拟这一行为。

CHSoil 模型中实现的剪切硬化流动法则形式为

(22)\[ \Delta \epsilon^p = \Delta \gamma^p \sin{\psi_m}\]

其中，\(\Delta \epsilon^p\) 为塑性体积应变增量，\(\Delta \gamma^p\) 为塑性剪应变增量，\(\psi_m\) 为动员剪胀角。

表征 \(\psi_m\) 的一种方法，是采用基于 Rowe 应力—剪胀理论的方程（Rowe，1962）。该理论认为，存在一个等体积摩擦角 \(\phi_{cv}\)：低于该值时，即 \(\phi_m \le \phi_{cv}\) 条件下，材料收缩；应力比更高时，即 \(\phi_m > \phi_{cv}\) 条件下，材料剪胀。方程形式为

(23)\[ \sin{\psi_m} = {{\sin{\phi_m} - \sin{\phi_{cv}} \over {1 - \sin{\phi_m}\sin{\phi_{cv}}}}}\]

其中

(24)\[ \sin{\phi_{cv}} = {{\sin{\phi_f} - \sin{\psi_f} \over {1 - \sin{\phi_f}\sin{\psi_f}}}}\]

其中，\(\phi_f\) 和 \(\psi_f\) 分别为已知的极限摩擦角与极限剪胀角。

根据前两个方程，以及式 (19) 中假定的 \(\phi_m\) 与 \(\gamma^p\) 之间的关系，可按塑性剪应变计算剪胀。将材料属性 flag-dilation 设为 1，即默认值，可选择 Rowe 剪胀规律。还可以采用一种简单剪胀规律：在 \(\phi_m < \phi_{cv}\) 时，\(\psi_m\) = 0；在 \(\phi_m \ge \phi_{cv}\) 时，其值为 \(\psi_m = \psi_{f}\)。将 flag-dilation 设为 2 可启用这一选项。最后，用户还可通过创建剪胀值—塑性剪应变输入表，自定义其他剪胀规律。必须将模型属性 flag-dilation 设为零，才能启用该选项。

根据 Nevada 砂三轴试验结果进行标定

以平均有效应力 \(p^{\prime}\) 恒定条件下 Nevada 砂的排水三轴压缩试验结果为例，说明 CHSoil 模型属性的标定方法。试验结果列于数据文件“40-40.txt”“40-80.txt”和“40-160.txt”中，分别对应 40 kPa、80 kPa 和 160 kPa 的平均应力。试验所用砂的相对密度为 40%。这些试验结果包括以下三组数据，更多细节见排水三轴压缩试验（drained triaxial compression tests）：

  1. 偏应力与平均有效应力的关系；
  2. 偏应力与轴向应变的关系，轴向应变最大为 25%；以及
  3. 体积应变与轴向应变的关系，轴向应变最大为 25%。

本次标定只考虑不超过 5% 的轴向应变，因为对于预定的静力排水应用，预计不会出现更大的应变。Nevada 砂表现为纯摩擦性材料。试验数据有两个主要特点：一是偏应力—轴向应变关系呈双曲线特征；二是体积应变—轴向应变关系呈双线性剪胀特征。使用 CHSoil 模型的摩擦硬化和可变剪胀功能来模拟这些特点。

弹性切线剪切模量和体积模量按式 (3) 至 (5)，取为初始平均有效应力的函数。摩擦硬化使用内置规律，即式 (19)。剪胀规律为双线性形式：应力比低于 \(\phi=\phi_{cv}\) 时，其值为零；高于该值时，取常数 \(\psi_f\)：

(25)\[\begin{split}\begin{matrix} \psi &= 0 \qquad \ \ \ \phi < \phi_{cv} \\ \\ \psi &= \psi_f \qquad \phi \ge \phi_{cv} \end{matrix}\end{split}\]

本次标定中，破坏比 \(R_f\) 取 0.99。需要定义以下八项属性：

\[E_{ref}, \nu, p_{ref}, \phi_f, \psi_f, \phi_{cv}, m, n\]

模型属性标定分两步进行。首先，根据理论分析及文献中的数值，得到属性值的初步估计；然后，对三轴试验进行数值模拟，并与室内试验结果对比拟合，以改进这些估计值。

初步估计——将室内试验所得的偏应力 \(q\) 与平均有效应力 \(p^{\prime}\) 关系进行线性拟合，可以确定极限摩擦角。对给定 \(p^{\prime}\) 下的最大 \(q\) 进行线性拟合，可得到最大应力比 \(a\)：

(26)\[ a = {q \over p^{\prime}}\]

根据纯摩擦型 Mohr-Coulomb 准则的定义，可得到以下关系：

(27)\[ \sin{\phi_f} = {3a \over 6 + a}\]

由此可以推导极限摩擦角 \(\phi_f\)。对于 \(D_r\) = 40% 的砂，估计值为 \(\phi_f\) = 34°。

极限剪胀角由室内负体积应变—轴向应变曲线的线性拟合斜率 \(b\) 推导。为建立 \(b\) 与 \(\psi_f\) 的关系，首先采用 Vermeer 和 de Borst（1984）给出的三轴应力结果双线性理想化表达式进行近似：

(28)\[ b = {2 \sin{\psi_f} \over 1 - \sin{\psi_f}}\]

对于 \(D_r\) = 40% 的砂，\(\psi_f\) 的初步估计值为 8.2°。

为估计给定 \(D_r\) 时的参数 \(\phi_{cv}\)，首先根据该 \(p^{\prime}\) 条件下的室内体积应变—轴向应变曲线，确定体积应变变化可忽略时的最大轴向应变 \(\varepsilon^*_a\)。已知轴向应变 \(\varepsilon^*_a\) 后，再由相应 \(p^{\prime}\) 条件下的室内偏应力—轴向应变曲线估计 \(q\)，进而求出比值 \(q/p^{\prime}\)。每个 \(p^{\prime}\) 对应一个比值，共有三个比值。使用 \(q/p^{\prime}\) 的平均值，并按式 (27) 计算相应摩擦角；此时将 \(\phi_f\) 替换为 \(\phi_{cv}\)，将 \(a\) 替换为平均值 \(q/p^{\prime}\)，见式 (26)。对 \(D_r\) = 40% 的砂，估计得到 \(\phi_{cv}\) = 27.7°。

对于 \(D_r\) = 40% 的砂，在大气压力下，将 \(E_{ref}\) 的初始估计值取为 1200；该值与采用帽盖屈服（CYSoil）模型的密砂三轴数值试验（triaxial numerical experiment for dense sand）中使用的值相同。

本例将 \(\nu\) 任意选为 0.35，并取 \(n = m = 0.5\)。弹性常数 \(E_{ref}\) 通过拟合数值试验和室内试验所得的 \(q\)—轴向应变曲线初始斜率来估计；这两类三轴试验采用相同的恒定平均应力条件。这些估计可能不十分准确；通过小幅卸载—再加载的室内试验结果，可以更可靠地估计弹性常数，但本例未获得此类结果。

= 1（默认）：动员剪胀角 \(\psi_m\) 由 Rowe 应力—剪胀理论确定。

= 2：动员剪胀角在 \(\phi_m\) < \(\phi_{cv}\) 时为 \(\psi_m\) = 0；在 \(\phi_m \ge \phi_{cv}\) 时为 \(\psi_m\) = \(\psi_f\)。

exponent-bulk f (a)

体积模量指数，\(m\)。默认值为 0.5。

exponent-shear f (a)

剪切模量指数，\(n\)。默认值为 0.5。

friction-0 f (a)

与零塑性剪应变对应的初始发挥摩擦角 \(\phi_0\)。默认情况下若 strain-shear-plastic 初始化为 0，则 \(\phi_0\) = \(\phi_m\)；否则若未指定则 \(\phi_0\) = 0。

friction-critical f (a)

剪胀法则中所用常数（flag-dilation = 1 或 2），\(\phi_{cv}\)

strain-shear-plastic f (a)

累计塑性剪应变，\(\epsilon^{ps}\)。默认在程序内部初始化。

strain-tensile-plastic f (a)

累计塑性拉应变，\(\epsilon^{pt}\)。默认初始值为 0。

failure-ratio f (a)

破坏比，\(R_f\)。默认值为 0.9。

table-cohesion s (a)

用于关联黏聚力 \(c\) 与塑性剪应变的表名

用于关联动员剪胀角与塑性剪应变的表名

table-tension s (a)

用于关联动员抗拉强度与塑性拉应变的表名

bulk f (r)

当前弹性体积模量，\(K^e\)

shear f (r)

当前弹性剪切模量，\(G^e\)

young f (r)

当前弹性杨氏模量，\(E\)

注意事项

  • 定义弹性性质时，只需提供以下两种组合中的一种：1）\(K_{ref}\) 和 \(G_{ref}\)；2）\(E_{ref}\) 和 \(\nu\)。采用后一种组合时，必须先赋予 \(E_{ref}\)，再赋予 \(\nu\)。
  • 抗拉截断为 \({\sigma}^t = min({\sigma}^t, c/\tan \phi)\)。
  • 拉伸表与 flag-brittle 不应同时处于活动状态。
