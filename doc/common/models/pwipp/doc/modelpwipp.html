WIPP-Drucker 模型

FLAC3D 或 3DEC 中还通过把黏弹性 WIPP 模型（WIPP model） 与弹塑性 Drucker-Prager 模型（Drucker-Prager model） 组合来模拟黏塑性。在当前 FLAC3D/3DEC 所包含的塑性模型中，Drucker-Prager 模型（Drucker-Prager model） 与 WIPP 模型（WIPP model） 最为兼容，因为两者都以偏应力张量的第二不变量表述。在 \(\pi\) 平面中观察时，两者的响应都只取决于到等向应力轨迹的径向距离。相比之下，Mohr-Coulomb 模型（Mohr-Coulomb model） 的响应不是各向同性的，因为其中主应力不参与表述。

以下推导与 Drucker-Prager 模型（Drucker-Prager model） 中所述略有不同，用以说明 Drucker-Prager 表述与 WIPP 参考蠕变模型（WIPP-reference creep model） 中蠕变表述的兼容性。

Drucker-Prager 模型的剪切屈服函数为

(1)\[f^s=\tau+q_{\phi}\sigma_\circ-k_\phi\]

其中屈服时 \(f^s\) = 0，\(\sigma_\circ=\sigma_{kk}/3\)，且 \(\tau=\sqrt{J_2}\)，其中 \(J_2\) 为偏应力张量的第二不变量。参数 \(q_\phi\) 与 \(k_\phi\) 为材料性质。

Because

(2)\[J_2=\sigma_{ij}^d\sigma_{ij}^d/2\]

（例如见 Malvern 1969，第 93 页）\(\tau\) 可与应力大小 \(\bar\sigma\) 建立关系，后者由 \(\bar\sigma=\sqrt{3\sigma^d_{ij}\sigma^d_{ij}/2}\) 定义：

(3)\[\bar\sigma=\sqrt{3}\,\tau\]

剪切塑性势函数 \(g^s\) 与屈服函数相似，只是把 \(q_\psi\) 代换为 \(q_\phi\)，作为控制剪胀的材料性质（类似 Drucker-Prager 模型（Drucker-Prager model））。

(4)\[g^s=\tau+q_\psi\sigma_\circ\]

若满足屈服条件（\(f^s\) = 0），则适用以下流动法则：

(5)\[\dot\epsilon_{ij}^{dp}=\lambda{\partial g^s\over\partial\sigma_{ij}^d}\]
(6)\[\dot\epsilon_\circ^p=\lambda{\partial g^s\over\partial\sigma_\circ}\]

其中 \(\lambda\) 为乘子（非材料性质），由“最终应力张量必须满足屈服条件”这一要求确定。上标 \(p\) 表示“塑性”，\(d\) 表示“偏量”。对公式 (2) 与 (6) 求导，可得

(7)\[\dot\epsilon_{ij}^{dp}=\lambda{\sigma_{ij}^d\over2\tau}\]
(8)\[\dot\epsilon_\circ^p=\lambda q_\psi\]

在该弹塑性表述中，这些方程与条件 \(f^s\) = 0 以及“弹性应变率与塑性应变率之和必须等于所施应变率”的条件联立求解。

该 Drucker-Prager 模型实现中还包含一个拉伸屈服面，并在剪切与拉伸屈服函数交汇处附近采用复合判别函数。拉伸屈服面为

(9)\[f^t=\sigma_\circ-\sigma^t\]

其中 \(\sigma^t\) 为拉伸屈服强度。关联塑性势函数为

(10)\[g^t=\sigma_\circ\]

采用与剪切屈服类似的方法，拉伸屈服的应变率为

(11)\[\dot\epsilon_{ij}^{dp}=0\]
(12)\[\dot\epsilon_\circ^p=\lambda\]

其中 \(\lambda\) 由 \(f^t\) = 0 的条件确定。注意抗拉强度不能大于使 \(f^s\) 变为零处的平均应力值（即 \(\sigma^t<k_\phi/q_\phi\)）。

当蠕变与塑性流动同时发生时，假定相应应变率“串联”作用：

(13)\[\dot\epsilon_{ij}^d =\dot\epsilon_{ij}^{de}+\dot\epsilon_{ij}^{dv} +\dot\epsilon_{ij}^{dp}\]

其中各项分别表示弹性、黏性与塑性应变率。先处理剪切屈服情形，\(f^s\) > 0。扩展公式 (13)，可得

(14)\[\dot\epsilon_{ij}^d={\dot\sigma_{ij}^d\over2G}+{\sigma_{ij}^d\over2\bar\sigma}\Bigl\{ 3\dot\epsilon + \sqrt{3}\lambda\Bigr\}\]

与纯蠕变模型不同，除非 \(q_\psi\) = 0，黏塑性模型的体积响应并不与偏量行为解耦，因此

(15)\[\dot\epsilon_{kk} = {3\dot\epsilon_\circ} = {\dot\sigma_{kk}\over3K}+\lambda q_\psi\]

蠕变求解方案中的迭代过程可扩展以纳入塑性应变增量。有

(16)\[\sigma_{ij}^{d'}=\sigma_{ij}^{d^\circ}+2G\Delta t \left[\dot\epsilon_{ij}^d -{\sigma_{ij}^d\over2\bar\sigma} \bigl(3\dot\epsilon+\sqrt{3}\lambda\bigr) \right]\]

则公式 (15) 变为

(17)\[\sigma'_\circ=\sigma_\circ^\circ+(\dot\epsilon_{kk} -\lambda q_\psi)K\Delta t\]

每次迭代中可调整 \(\lambda\) 的值，使解收敛到 \(f^s\) = 0。用牛顿求根法，

(18)\[\lambda'=\lambda^\circ-{f^s\over({\partial f^s\over\partial\lambda})}\]

注意 \(f^s\) 是用“新”应力分量 \(\sigma_{ij}^{d'}\) 计算的。公式 (18) 中的导数可计算为：

(19)\[{\partial f^s \over \partial\lambda} ={\partial f^s \over \partial\sigma_{ij}^{d'}} {\partial\sigma_{ij}^{d'} \over \partial\lambda} +{\partial f^s \over \partial\sigma'_\circ} {\partial\sigma'_\circ \over \partial\lambda}\]

因此，

(20)\[{\partial f^s \over \partial\lambda} = -G\Delta t -Kq_\phi q_\psi\Delta t\]

假定平均应力分量（\(\sigma_{ij}^d\) 与 \(\bar\sigma\)）为常数。

对拉伸屈服，\(\sigma_\circ>\sigma^t\)。此外若剪应力非零，则用以下函数判定发生剪切屈服还是拉伸屈服：

\[h=\tau-\tau_p-\alpha_p(\sigma_\circ-\sigma^t)\]

其中

\[\tau_p=k_\phi-q_\phi\sigma^t\]
\[\alpha_p=\sqrt{1+{q_\phi}^2}-q_\phi\]

若 \(h\) < 0 则判定拉伸屈服；否则发生剪切屈服。前一种情形下公式 (13) 的最后一项（塑性项）为零，且 \(\lambda\) 的取值使公式 (17) 化为

\[\sigma'_\circ=\sigma^t\]

为计入软化行为，基于偏应变增量张量的第二不变量计算累积塑性应变 \(\epsilon^{dp}\) 如下：

(21)\[\epsilon^{dp}:=\epsilon^{dp} +\Delta t\sqrt{\dot\epsilon_{ij}^{dp}\dot\epsilon_{ij}^{dp}/2}\]

没有内建的软化表格支持，但可编写一个 FISH 函数，每隔若干步扫描网格并依据 \(\epsilon^{dp}\) 的当前值重算性质（该技术的示例见 WIPP-Drucker 模型：显示局部化的压缩试验（WIPP-Drucker Model: Compression Test Showing Localization））。
