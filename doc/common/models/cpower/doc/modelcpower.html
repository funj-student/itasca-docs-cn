幂律—Mohr 模型

黏塑性模型 cpower 结合了双分量黏弹性幂律模型（power model）与弹塑性Mohr-Coulomb 模型（Mohr-Coulomb model）的行为。在模型公式中，总应变率 \(\dot{\epsilon_{ij}}\) 分解为弹性分量 \(\dot{\epsilon}_{ij}^e\)、黏性分量 \(\dot{\epsilon}_{ij}^c\) 和塑性分量 \(\dot{\epsilon}_{ij}^p\)：

(1)\[\dot{\epsilon}_{ij} = \dot{\epsilon}_{ij}^e + \dot{\epsilon}_{ij}^c + \dot{\epsilon}_{ij}^p\]

只有弹性应变率 \(\dot{\epsilon}_{ij}^e\) 对应力率有贡献；偏量行为为黏弹塑性，表示为

(2)\[\dot{S}_{ij} = 2G \left( \dot{e}_{ij} - \dot{e}_{ij}^c - \dot{e}_{ij}^p\right)\]

其中，\(\dot{S}_{ij}\) 和 \(\dot{e}_{ij}\) 为应力张量和应变率张量的偏量部分，\(\dot{\sigma}_{ij}\) 和 \(\dot{\epsilon}_{ij}\) 为相应张量，\(G\) 为切线剪切模量。本节所用记号约定见Burgers 模型（Burgers model）。

体积行为为弹塑性，形式为

(3)\[\dot{\sigma}_0 = K (\dot{e}_{vol}^e - \dot{e}_{vol}^p)\]

其中，\(\dot{\sigma}_0 = (\dot{\sigma}_{11} + \dot{\sigma}_{22} + \dot{\sigma}_{33} ) / 3\)、\(\dot{e}_{vol} = \dot{e}_{11} + \dot{e}_{22} + \dot{e}_{33}\)，且 \(K\) 为切线体积模量。

蠕变由 von Mises 应力 \(q=\sqrt{3J_2}\) 按 Norton 幂律激活，其中 \(J_2 = 1/2 S_{ij} S_{ij}\) 为偏应力张量的第二不变量。蠕变率为

(4)\[\dot{e}_{ij}^c = \dot{e}_{cr} {{\partial q} \over {\partial S_{ij}}}\]

蠕变流动方向根据 \(q\) 的定义推导：

(5)\[{{\partial q} \over {\partial S_{ij}}} = {{3} \over {2}} {{S_{ij}} \over {q}}\]

按定义，蠕变强度包含两个分量，见幂律模型（power model）：

(6)\[\dot{e}_{cr} = \dot{e}_{cr}^1 + \dot{e}_{cr}^2\]

其中

\[\begin{split}\dot{e}^1_{cr} = \begin{cases} A_1 q^{n_1} & q \ge \sigma^{ref}_1 \\ 0 & q < \sigma^{ref}_1 \\ \end{cases}\end{split}\]
\[\begin{split}\dot{e}^2_{cr} = \begin{cases} A_2 q^{n_2} & q \le \sigma^{ref}_2 \\ 0 & q > \sigma^{ref}_2 \\ \end{cases}\end{split}\]

其中，\(\sigma_1^{ref}\) 和 \(\sigma_2^{ref}\) 为两个模型参数。

塑性应变率采用 Mohr-Coulomb 流动法则定义：

(7)\[\dot{e}_{ij}^p = \dot{e}_{p} {{\partial g} \over {\partial {\sigma}_{ij}}} - {{1} \over {3}} \dot{e}_{vol}^p {\delta}_{ij}\]

其中

(8)\[\dot{e}_{vol}^p = \dot{e}_{p} \left[ {{\partial g} \over {\partial {\sigma}_{11}}} + {{\partial g} \over {\partial {\sigma}_{22}}} + {{\partial g} \over {\partial {\sigma}_{33}}} \right]\]

塑性流动方向 \({\partial g} / {\partial {\sigma}_{ij}}\) 采用 Mohr-Coulomb 势函数 \(g\) 的定义表示，塑性流动率强度 \(\dot{e}_{p}\) 根据 Mohr-Coulomb 屈服准则 \(f\) = 0 推导，见Mohr-Coulomb 模型（Mohr-Coulomb model）。在主轴形式下，剪切屈服的屈服函数和势函数为

(9)\[f=\sigma_1-\sigma_3N_{\phi} +2C\sqrt{N_{\phi} }\]
(10)\[g=\sigma_1-\sigma_3N_{\psi}\]

对于拉伸屈服，相应函数为

(11)\[f=\sigma ^t-\sigma_3\]
(12)\[g=-\sigma_3\]

其中，\(\sigma_1\) 和 \(\sigma_3\) 分别为最小和最大主应力，压应力取负；\(C\) 为材料黏聚力，\(\phi\) 为摩擦角，\(\psi\) 为材料剪胀角，\(\sigma ^t\) 为抗拉强度，另有 \(N_{\phi}=(1+\sin \phi )/(1-\sin \phi )\) 和 \(N_{\psi} =(1+\sin \psi )/(1-\sin \psi )\)。

模型的实现严格遵循手册中幂律模型（power model）和Mohr-Coulomb 模型（Mohr-Coulomb model）的处理步骤。首先计算时间步 \(\Delta t\) 内的黏弹性响应，求出主应力和主方向，并检查屈服准则。若不满足准则，则添加本步塑性应变增量，并计算增量强度 \(\lambda = \dot{e}_p \Delta t\)，使其满足屈服条件 \(f\) = 0。该过程与 Mohr-Coulomb 模型的实现步骤相同，只是用黏弹性响应替代本步的“弹性试算值”。

注意事项

  • 定义弹性性质时，只需提供以下两种组合中的一种：体积模量 \(K\) 与剪切模量 \(G\)，或杨氏模量 \(E\) 与泊松比 \(v\)。
  • 蠕变行为由偏应力触发，而体积变形不考虑蠕变。
  • 抗拉截断为 \(σ^t\) = min (\(σ^t\), \(c\)/tan\(ϕ\))。
