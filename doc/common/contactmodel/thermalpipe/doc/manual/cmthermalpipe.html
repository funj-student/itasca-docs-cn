热管接触模型

引言

热管接触模型模拟每单位长度热阻为 \(\eta\) 的一维管道。

公式

热管模型中的热功率按如下方式更新

(1)\[Q = -{\Delta T \over \eta L}\]

其中 \(\Delta T\) 是管道两端（即两个相互接触的热学片体）两个热库之间的温差，\(L\) 是热学接触的长度。

活动准则

若宿主力学接触模型处于活动状态，则热管接触模型处于活动状态。

模型参数

属性

表 1：热管模型属性
关键字 说明 符号 类型 范围 默认 可修改 可继承
thermalpipe 模型名称
thres 热阻 \(\eta\) FLT \([0.0,+\infty)\) 0.0 YES YES
thexp 热膨胀系数 \(\alpha\) FLT \([0.0,+\infty)\) 0.0 YES NO
temperature 温度 \(T\) FLT \(\mathbb{R}\) 0.0 YES NO

属性继承

热阻可从相互接触的热学片体继承，即：

(2)\[\eta = \eta^{(1)} + \eta^{(2)}\]

其中 \((1)\) 和 \((2)\) 分别表示片体 1 和 2 的属性。 该属性的继承标志必须设为真，且至少一个 相互接触片体必须具有该名称的属性。若其中一个片体不具有该属性， 则接触热阻取另一个片体所设的值。

方法

热管接触模型不定义任何方法。

能量

热管接触模型不定义任何能量。

回调事件

热管接触模型不定义任何回调事件。
