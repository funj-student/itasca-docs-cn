空模型

空模型保持广义内力为零（\(\mathbf{F_c} \equiv \mathbf{M_c} \equiv 0\)）。 除非在 接触模型赋值表（CMAT）（Contact Model Assignment Table (CMAT)） 中指定了其他接触模型，否则新建接触都赋予该接触模型。该模型在命令和 FISH 中称为 null。
