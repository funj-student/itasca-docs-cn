滞回模型

引言

PFC 中的滞回接触模型由“Hertz 模型（Hertz Model）”一节所述的 Hertz 模型弹性部分， 与法向方向上一个由非线性黏弹性单元组成的替代阻尼器组合而成。 该模型在命令和 FISH 中称为 hysteretic。

注意

版本 28 包含以下附加修改：

由接触块体的参数推导接触模型弹性参数的属性继承机制已改为遵循 [Mindlin1953]， 并遵循下文（below）的公式。 在此修改之前，接触的有效剪切模量和泊松比分别取为 接触块体剪切模量和泊松比的平均值。请注意，此更改可能会改变 对 hysteretic 模型使用属性继承机制的模型的输出。 更多信息请参阅“Hertz 模型（Hertz Model）”的文档。

行为概要

该公式基于 [Machado2012] 的文献综述。共提供三种不同的阻尼器模式， 它们分别对应阻尼器力计算的三种不同表达式。

活动-删除准则

滞回模型定义的激活距离为 0.0。接触的激活状态按如下方式更新：

(1)\[\begin{split}\begin{cases} g_c \leq 0.0 & \Rightarrow \mbox{contact active} \\ g_c > 0.0 & \Rightarrow \mbox{contact inactive} \end{cases}\end{split}\]

如“接触识别（Contact Resolution）”一节所述，对未激活的接触会跳过力-位移计算。

力-位移定律

与 赫兹（Hertz） 模型类似，滞回模型传递力而不传递力矩。该力包含一个非线性弹性分量 \(\mathbf{F^{h}}\) 和 一个黏性分量 \(\mathbf{F^{d}}\)

(2)\[\mathbf{F_{c}} =\mathbf{F^{h}} +\mathbf{F^{d}} \mbox{, } \mathbf{M_{c}} \equiv 0\]

非线性 Hertz 力可分解为法向贡献和剪切贡献：

(3)\[\mathbf{F^{h}} = -F_{n}^{h} {\kern 1pt} \hat{\mathbf{n}}_\mathbf{c} +\mathbf{F_{s}^{h}}\]

其公式与赫兹接触模型（Hertz contact model）中描述的非线性 Hertz 力等价。

阻尼器力只有法向分量：

(4)\[\mathbf{F^{d}} =-F_{n}^{d} {\kern 1pt} \hat{\mathbf{n}}_\mathbf{c}\]

其中 \(F_{n}^{d}\) 的表达式可用滞回阻尼因子 \(\chi\) 表示为：

(5)\[F_{n}^{d} = \chi \delta_{n}^{\alpha} \dot{\delta}_n\]

其中 \(\delta_{n} = -g_c\) 表示实际重叠量，\(\dot{\delta}_n = \mathbf{\dot{\delta}} {\kern 1pt} \hat{\mathbf{n}}_\mathbf{c}\) 是相对平动速度的法向分量，滞回阻尼因子 \(\chi\) 取决于阻尼器模式 \(M_d\)、 目标恢复系数 \(e_n\)、Hertz 法向力系数 \(h_n\)（见此处（here））以及法向撞击速度 \(\dot{\delta}^{(-)}_n\)，其关系为：

(6)\[\begin{split}\chi = \begin{cases} \dfrac{1-e_n^2}{e_n} \frac{h_n}{\dot{\delta}^{(-)}_n} & \mbox{, } M_d = 0 \\ \dfrac{3\left(1-e_n^2\right)}{4} \frac{h_n}{\dot{\delta}^{(-)}_n} & \mbox{, } M_d = 1 \\ \dfrac{3\left(1-e_n^2\right)e^{2\left(1-e_n\right)}}{4} \frac{h_n}{\dot{\delta}^{(-)}_n} & \mbox{, } M_d = 2 \end{cases}\end{split}\]

注意，对于 \(M_d=1\) 的情况，上式中所用的目标恢复系数取 \(e_n\) 与最小值 \(e^*_n\) 之间的较大者。

能量分区

滞回模型定义三个能量分区：

  • 储存在弹簧中的应变能 \(E_{k}\)；
  • 滑动功 \(E_{\mu}\)，定义为摩擦滑动耗散的总能量；以及
  • 阻尼功 \(E_{\beta}\)，定义为阻尼器耗散的总能量。

若激活能量跟踪，这些能量分区按如下方式更新。

  1. 更新应变能：

    (7)\[E_{k} = \frac{\alpha}{(\alpha+1)} \left(\frac{\left(F^{h}_n\right)^2}{k_n}\right) + \frac{1}{2} \frac{\|\mathbf{F^{h}_s)}\|^2}{k_s}\]

  2. 更新滑动能量：

    (8)\[\begin{split}\begin{array}{l} {E_{\mu } :=E_{\mu } - {\tfrac{1}{2}} \left(\left(\mathbf{F_{s}^{h}} \right)_{o} +\mathbf{F_{s}^{h}} \right)\cdot \Delta \pmb{δ}_\mathbf{s}^{\mu } } \\ {{\rm with}\qquad \Delta \pmb{δ}_\mathbf{s}^{\mu } =\Delta \pmb{δ}_\mathbf{s} -\Delta \pmb{δ}_\mathbf{s}^{k} =\Delta \pmb{δ}_\mathbf{s} -\left(\frac{\mathbf{F_{s}^{h}} -\left(\mathbf{F_{s}^{h}} \right)_{o} }{k_{s} } \right)} \end{array}\end{split}\]

    其中 \(\left(\mathbf{F_{s}^{h}} \right)_{o}\) 是时间步开始时的剪切力，“接触解析（Contact Resolution）”一节中 该（this） 公式的 相对剪切位移增量已被分解为弹性 \(\left(\Delta \pmb{δ}_\mathbf{s}^{k} \right)\) 和 滑动 \(\left(\Delta \pmb{δ}_\mathbf{s}^{\mu } \right)\) 分量。滑动分量与时间步内平均剪切力的 点积给出滑动能量的增量。

  3. 更新阻尼器能量：

    (9)\[E_{\beta } :=E_{\beta } - \mathbf{F^{d}} \cdot \left(\dot{\pmb{δ} }{\kern 1pt} {\kern 1pt} \Delta t\right)\]

    其中 \(\dot{\pmb{δ} }\) 是“接触解析（Contact Resolution）”一节中 该（this） 公式的相对平动 速度。

属性继承

剪切模量 \(G\)、泊松比 \(\nu\) 和摩擦系数 \(\mu\) 可以从接触块体继承。继承逻辑 与此处（here）描述的 hertz 接触模型类似。

方法

滞回模型未定义任何方法。
