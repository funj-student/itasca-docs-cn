Hertz 模型

Hertz 接触模型包含一个基于对 Mindlin 和 Deresiewicz 理论近似 [Mindlin1953] 的非线性公式。该模型可安装在 球-球和球-面片接触上，在命令和 FISH 中 名称为 hertz。

引言

Hertz 接触模型基于对摩擦接触中光滑弹性球体变形的理论分析， 同时产生法向力和剪切力。在涉及撞击的模拟中，可以添加黏性阻尼器 以进一步耗散能量。这两个组件都只传递力。

行为概要

Hertz 接触模型包含一个非线性 Hertz 分量，它基于对 Mindlin 和 Deresiewicz 理论的近似 [Mindlin1953]。如 [Cundall1988a] 所述，当前实现并不再现剪切方向的连续非线性。取而代之的是使用初始剪切模量，但它取决于法向力。该公式假定有限大小的接触面积相对于相互接触片体的曲率半径很小。界面不抵抗相对转动，即接触力矩为零（\(\mathbf{M_{c}} \equiv 0\)）。接触力被分解为 Hertz 分量和阻尼分量（\(\mathbf{F_{c}} =\mathbf{F^{h}} +\mathbf{F^{d}}\)）。定义表面间隙 \(g_{s}\) 为接触间隙 \(g_{c}\) 与参考间隙 \(g_{r}\) 之差，因此当参考间隙为零时，名义表面与片体表面重合。当且仅当表面间隙小于或等于零时接触才是活动的；对非活动接触会跳过力-位移定律。

注意

Hertz 模型的实现相对 PFC 4.0 有如下变化：

  1. 球-面片接触的处理：在 PFC 4.0 中，球-墙接触中的墙在概念上被替换为 一个关于墙位置对称放置的相同球体，从而使力-位移律中使用的 重叠量被设为实际球-墙重叠量的两倍。 在 PFC 5.0 和 PFC 6.0 中，球-面片接触的力采用面片曲率为 0（或者， 面片半径为 \(\infty\)）来求解。这意味着球-面片接触处的法向力 是 PFC 4.0 中计算值的一半。
  2. 二维公式：PFC 中 Hertz 模型的理论背景仅适用于 三维球-球和球-面片接触的情形。但用户可以在 PFC2D 中使用 Hertz 接触模型， 并选择幂律指数 \(\alpha_h\) 的取值（见下文）。
  3. 幂律指数 \(\alpha_h\)（见下文说明）可由其默认值 3/2 修改。例如，[Hunt1975] 建议同轴圆柱之间接触的取值范围为 [1.0,1.5]。
  4. 新模式（\(M_s\)）允许在法向卸载时减小剪切力， 以防止出现虚假的能量生成（细节见 [Ellata1996] 或 [Agnolin2007a]）。

注意

版本 28 包含以下附加修改：

  1. 从相互接触片体参数导出接触模型弹性参数的属性继承机制已改为符合 [Mindlin1953]，采用 下面的方程 below。 在此修改之前，接触有效剪切模量和泊松比分别取相互接触片体剪切模量和泊松比的 平均值。注意，此更改可能会改变使用 hertz 模型属性继承机制 的模型的输出。 有关如何覆盖属性继承机制以再现先前行为的示例，请参见下文“使用与验证示例（Usage and Verification Examples）”一节。
  2. 新增一个属性 \(\alpha_d\)，使阻尼力与 当前表面间隙的 \(\alpha_d\) 次幂成正比。为向后兼容，该参数默认为 0.0，但可设为 非零值。按照 [Ramírez1999] 的量纲分析，应选择 \(\alpha_d = (\alpha_h-1) / 2\) 以 在低冲击速度下获得恒定的恢复系数。当前模型在 \(\alpha_h = 3/2\) 和 \(\alpha_d = 1/4\) 时 满足该条件，并与 [Tsuji1992] 的模型一致。
  3. 新增一个属性 \(g_r\)，允许用户指定非零参考间隙。

活动-删除准则

采用 Hertz 模型的接触当且仅当表面间隙（\(g_{s} =g_{c} -g_{r}\)）小于或等于 0 时才是激活的。 如“接触识别（Contact Resolution）”一节所述，对未激活的接触会跳过力-位移计算。

力-位移定律

Hertz 模型的力-位移定律更新接触力和力矩：

(1)\[\mathbf{F_{c}} =\mathbf{F^{h}} +\mathbf{F^{d}} ,\quad \mathbf{M_{c}} \equiv 0\]

其中 \(\mathbf{F^{h}}\) 是非线性 Hertz 力，\(\mathbf{F^{d}}\) 是阻尼力。 两种力都被分解为法向力和剪切力：

(2)\[\mathbf{F^{h}} =-F_{n}^{h} {\kern 1pt} \hat{\mathbf{n}}_\mathbf{c} +\mathbf{F_{s}^{h}} ,\quad \mathbf{F^{d}} =-F_{n}^{d} {\kern 1pt} \hat{\mathbf{n}}_\mathbf{c} +\mathbf{F_{s}^{d}}.\]

其中 \(F_{n}^{\left\{h,d\right\}} >0\) 表示受拉。两个剪切力都位于接触平面内， Hertz 剪切力在接触平面坐标系中表示为：

(3)\[\mathbf{F_{s}^{h}} =F_{ss}^{h} {\kern 1pt} \hat{\mathbf{s}}_\mathbf{c} +F_{st}^{h} {\kern 1pt} \hat{\mathbf{t}}_\mathbf{c} \; \; \left({\rm 2D\; model:\; }F_{ss}^{h} \equiv 0\right).\]

Hertz 模型的力-位移定律由以下步骤组成：

  1. 更新 Hertz 法向力：

    (4)\[\begin{split}F^{h}_n = \begin{cases} - h_n {|g_c|}^{\alpha_h} & \mbox{,} g_c < 0.0 \\ 0.0 & \mbox{, otherwise} \end{cases}\end{split}\]

    系数 \(h_n\) 取决于相互接触片体的几何和力学性质，即

    (5)\[h_n = \frac{2 G \sqrt{2\bar{R}}}{3(1-\nu)}\]

    其中 \(G\)、\(\nu\) 和 \(\bar{R}\) 分别是有效剪切模量、泊松比 和接触半径。有效剪切模量和泊松比可直接输入，也可按 下文（below） 所述 从相互接触片体继承。

    接触的有效半径通过相互接触片体表面的半径计算（其中面片的半径为 \(\infty\)），即

    (6)\[\frac{1}{\bar{R}} = \frac{1}{2}\left(\frac{1}{R^{(1)}} + \frac{1}{R^{(2)}}\right)\]

  2. 按如下方式更新 Hertz 模型的剪切力。计算试验剪切力：

    (7)\[\mathbf{F^{*}_s} = \mathbf{({F}^{h}_s)_0} + k_s \Delta \pmb{θ}_\mathbf{s}\]

    其中 \(\mathbf{({F}^{h}_s)_0}\) 是时间步开始时的 Hertz 剪切力，\(\Delta \pmb{θ}_\mathbf{s}\) 是“接触解析（Contact Resolution）”一节中 该（this） 公式的相对剪切 增量。在上式中，\(k_s\) 是初始切线剪切刚度，它 取决于当前法向力，即

    (8)\[k_s = \frac{2(1-\nu)}{2-\nu} \alpha_h \left(h_n\right)^{1/\alpha_h} \left(F^{h}_n\right)^{(\alpha_h-1)/\alpha_h}\]

    \(\mathbf{({F}^{h}_s)_0}\) 的取值取决于缩放模式（\(M_s\)）：

    (9)\[\begin{split}\mathbf{({F}^{h}_s)_0} = \begin{cases} \frac{k_s}{(k_s)_0} \mathbf{(F^{h}_s)_0} & \mbox{, if } M_s = 1 \mbox{ and } F^{h}_n < (F^{h}_n)_0 \\ \\ \mathbf{(F^{h}_s)_0} & \mbox{, otherwise} \end{cases}\end{split}\]

    其中 \((F^{h}_n)_0\)、\(\mathbf{(F^{h}_s)_0}\) 和 \((k_s)_0\) 分别是时间步开始时计算的 法向力、剪切力和切线剪切刚度。计算抗剪强度：

    (10)\[F^{\mu}_s = \mu F^{h}_n.\]

    更新 Hertz 剪切力：

    (11)\[\begin{split}\mathbf{F_{s}^{h}} = \begin{cases} \mathbf{F_{s}^{*}} & \mbox {, } \left\| \mathbf{F_{s}^{*}} \right\| \le F_{s}^{\mu} \\ F_{s}^{\mu} \left(\mathbf{F_{s}^{*}} / \left\| F_{s}^{*} \right\| \right) & \mbox {, otherwise.} \end{cases}\end{split}\]

    更新滑动状态：

    (12)\[\begin{split}s= \begin{cases} {\rm true} &\mbox{, } \left\| \mathbf{F_{s}^{h}} \right\| =F_{s}^{\mu } \\ {\rm false} & \mbox{, otherwise.} \end{cases}\end{split}\]

    若滑移状态为真，则该接触正在滑动。每当滑移状态改变时，都会发生 slip_change 回调事件。

  3. 按阻尼器行为模式更新阻尼器法向力：

    (13)\[\begin{split}\begin{array}{l} {F_{n}^{d} = \left\{\begin{array}{l} {\qquad F^{*} ,\qquad M_{d} =\left\{0,2\right\}{\rm \; (full\; normal)}} \\ {\qquad \min \left(F^{*} ,-F_{n}^{l} \right), \qquad M_{d} =\left\{1,3\right\}{\rm \; (no-tension\; normal)}} \end{array} \right. } \\ {{\rm with}\qquad F^{*} =\left(2\beta _{n} \sqrt{m_{c} k_{n} } \right) {|g_c|}^{\alpha_d} \dot{\delta }_{n} } \\ {\qquad k_{n} = {\qquad \alpha_h h_n \delta_n^{\alpha_h-1}}} \\ {\qquad m_{c} =\left\{\begin{array}{l} {\qquad \frac{m^{\left(1\right)} m^{\left(2\right)} }{m^{\left(1\right)} +m^{\left(2\right)} } ,\qquad {\rm ball-ball}} \\ {\qquad m^{\left(1\right)} {\rm ,}\qquad {\rm ball-facet}} \end{array}\right. } \end{array}\end{split}\]

    其中 \(k_{n}\) 是法向切线刚度，\(m^{\left(b\right)}\) 是体（\(b\)）的质量，\(\alpha_d\) 是无量纲指数，\(\dot{\delta }_{n}\) 是“接触解析（Contact Resolution）”一节中 该（this） 公式的相对 法向平动速度。 对无拉伸的阻尼器法向行为模式，对 \(F_{n}^{d}\) 施加限制以确保总法向力（\(F_{n}^{l} +F_{n}^{d}\)）不会 变为拉伸。

  4. 按阻尼器行为模式更新阻尼器剪切力：

    (14)\[\begin{split}\begin{array}{l} {\mathbf{F_{s}^{d}} =\left\{\begin{array}{l} {\qquad \left(2\beta _{s} \sqrt{m_{c} k_{s} } \right) {|g_c|}^{\alpha_d} \dot{\pmb{δ}}_\mathbf{s} ,\qquad s={\rm false\; \; or}\qquad M_{d} =\left\{0,1\right\}{\rm \; (full\; shear)}} \\ {\qquad 0,\qquad s={\rm true\; \; and}\qquad M_{d} =\left\{2,3\right\}{\rm \; (slip-cut)}} \end{array}\right. } \\ {{\rm with}\qquad m_{c} =\left\{\begin{array}{l} {\qquad \frac{m^{\left(1\right)} m^{\left(2\right)} }{m^{\left(1\right)} +m^{\left(2\right)} } ,\qquad {\rm ball-ball}} \\ {\qquad m^{\left(1\right)} {\rm ,}\qquad {\rm ball-facet}} \end{array}\right. } \end{array}\end{split}\]

    其中 \(\dot{\pmb{δ}}_\mathbf{s}\) 是“接触识别（Contact Resolution）”一节中该（this）公式的相对剪切平动速度。 对于滑移-截断的阻尼器剪切行为模式，若线性弹簧正在滑动（\(s\) = true），则 \(\mathbf{F_{s}^{d}}\) 设为零。

能量分区

Hertz 模型定义三个能量分区：

  • 储存在弹簧中的应变能 \(E_{k}\)；
  • 滑动功 \(E_{\mu}\)，定义为摩擦滑动耗散的总能量；以及
  • 阻尼功 \(E_{\beta}\)，定义为阻尼器耗散的总能量。

若激活能量跟踪，这些能量分区按如下方式更新。

  1. 更新应变能：

    (15)\[E_{k} = \frac{\alpha_h}{(\alpha_h+1)} \left(\frac{\left(F^{h}_n\right)^2}{k_n}\right) + \frac{1}{2} \frac{\|\mathbf{F^{h}_s)}\|^2}{k_s}\]

  2. 更新滑动能量：

    (16)\[\begin{split}\begin{array}{l} {E_{\mu } :=E_{\mu } - {\tfrac{1}{2}} \left(\left(\mathbf{F_{s}^{h}} \right)_{o} +\mathbf{F_{s}^{h}} \right)\cdot \Delta \pmb{δ}_\mathbf{s}^{\mu } } \\ {{\rm with}\qquad \Delta \pmb{δ}_\mathbf{s}^{\mu } =\Delta \pmb{δ}_\mathbf{s} -\Delta \pmb{δ}_\mathbf{s}^{k} =\Delta \pmb{δ}_\mathbf{s} -\left(\frac{\mathbf{F_{s}^{h}} -\left(\mathbf{F_{s}^{h}} \right)_{o} }{k_{s} } \right)} \end{array}\end{split}\]

    其中 \(\left(\mathbf{F_{s}^{h}} \right)_{o}\) 是时间步开始时的剪切力，“接触解析（Contact Resolution）”一节中 该（this） 公式的 相对剪切位移增量已被分解为弹性 \(\left(\Delta \pmb{δ}_\mathbf{s}^{k} \right)\) 和 滑动 \(\left(\Delta \pmb{δ}_\mathbf{s}^{\mu } \right)\) 分量。滑动分量与时间步内平均剪切力的 点积给出滑动能量的增量。

  3. 更新阻尼器能量：

    (17)\[E_{\beta } :=E_{\beta } - \mathbf{F^{d}} \cdot \left(\dot{\pmb{δ} }{\kern 1pt} {\kern 1pt} \Delta t\right)\]

    其中 \(\dot{\pmb{δ} }\) 是“接触解析（Contact Resolution）”一节中 该（this） 公式的相对平动 速度。

表面属性继承

剪切模量 \(G\)、泊松比 \(\nu\) 和摩擦系数 \(\mu\) 可从 相互接触片体继承。请记住，属性要被继承，该属性的继承标志必须 设为真（默认），且两个相互接触片体都必须具有名称完全相同的属性。

剪切模量和泊松比通过取相互接触片体取值的平均值来继承：

(18)\[\begin{split}\nu &= \frac{4 G^* - E^*}{2 G^* - E^*} \\ G &= 2 G^* (2 - \nu)\end{split}\]

其中：

(19)\[\begin{split}E^* &= \left( \frac{1-\nu^{(1)}}{2G^{(1)}} + \frac{1-\nu^{(2)}}{2G^{(2)}} \right)^{-1} \\ G^* &= \left( \frac{2-\nu^{(1)}}{G^{(1)}} + \frac{2-\nu^{(2)}}{G^{(2)}} \right)^{-1}\end{split}\]

其中 (1) 和 (2) 分别表示块体 1 和块体 2 的属性。

摩擦系数采用最小摩擦系数来继承：

(20)\[\mu = \min(\mu^{(1)},\mu^{(2)})\]

方法

Hertz 模型未定义任何方法。

使用与验证示例

验证问题“Hertz 接触模型：复杂加载路径（Hertz Contact Model: Complex Loading Paths）”检验 Hertz 接触模型。

修订版 28 修改了用于从片体属性导出 \(G\) 和 \(\nu\) 的公式。建议用户 使用更新后的逻辑。但下面的示例演示了如何在需要时覆盖默认继承机制，以确保与 先前模型的再现性。

model new
model domain extent -1 1
contact cmat default model hertz 
ball create id 1 rad 0.1 position-x -0.1
ball create id 2 rad 0.1 position-x  0.1
ball attribute density 2000.0
ball property 'hz_shear' 1.0e9 'hz_poiss' 0.3 'fric' 0.0 range id 1
ball property 'hz_shear' 2.0e9 'hz_poiss' 0.2 'fric' 0.5 range id 2
model clean
contact list property
model save 'default'
model new
model domain extent -1 1
contact cmat default model hertz inheritance hz_shear off hz_poiss off   
ball create id 1 rad 0.1 position-x -0.1
ball create id 2 rad 0.1 position-x  0.1
ball attribute density 2000.0
ball property 'hz_shear' 1.0e9 'hz_poiss' 0.3 'fric' 0.0 range id 1
ball property 'hz_shear' 2.0e9 'hz_poiss' 0.2 'fric' 0.5 range id 2

fish define catch_contact(c)
  local b1 = contact.end1(c)
  local b2 = contact.end2(c)
  contact.prop(c,'hz_shear') = 0.5*(ball.prop(b1,'hz_shear') + ...
                                   ball.prop(b2,'hz_shear'))
  contact.prop(c,'hz_poiss') = 0.5*(ball.prop(b1,'hz_poiss') + ...
                                   ball.prop(b2,'hz_poiss')) 
end
fish callback add catch_contact event contact_create
model clean
contact list property
model save 'overriden'
program return

在本例中，接触模型赋值表（contact model assignement table） 中对 \(G\) 和 \(\nu\) 停用了继承机制，并把一个 FISH 函数注册为 contact_create 事件的回调。因此，每当模型中创建新接触时 都会执行该函数，并由它设置接触模型属性（见 接触回调事件（Contact Callback Events））。
