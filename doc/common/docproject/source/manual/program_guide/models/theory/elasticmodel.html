弹性模型组

本组模型的特点是卸载时变形可恢复；其应力-应变规律是线性的且与路径无关。弹性模型包括各向同性和各向异性弹性模型。可提供两种各向异性弹性模型，它们对应两种弹性对称情形：正交各向异性模型和横观各向同性模型。关于各向异性公式的更多信息，参见 Lekhnitskii (1981)。

  • 各向同性弹性模型（Isotropic Elastic Model）
  • 各向异性（横观各向同性）弹性模型（Anisotropic (Transversely) Elastic Model）
  • 正交各向异性弹性模型（Orthotropic Elastic Model）
