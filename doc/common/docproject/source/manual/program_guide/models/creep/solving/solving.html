求解蠕变问题

在 FLAC3D 或 3DEC 中，蠕变与其他本构模型的主要区别在于模拟中的问题时间概念。对于蠕变计算，问题时间和时间步代表真实时间；而对于其他本构模型的静力分析，时间步是一个人为量，仅用作推进到稳态条件的手段。

蠕变时间步

对于蠕变这类与时间相关的现象，FLAC3D 或 3DEC 允许用户定义时间步。该时间步的默认值为零，此时程序视情况将材料按线弹性（黏弹性模型）或弹塑性（黏塑性模型）处理。（命令 设置蠕变计算激活状态（model creep active） 关闭（off） 也可用于停止蠕变计算。）这可用于在开始蠕变模拟前达到平衡。蠕变本构定律在其方程中使用时间步，因此时间步可能影响响应。

尽管用户可以设置时间步，但它并非任意取值。为使系统始终处于准静态力学平衡（如蠕变模拟中那样），本构定律产生的随时间变化的应力变化相对于与应变相关的应力变化而言不能过大。否则，不平衡力会很大，惯性效应（理论上并不存在）可能影响解。

蠕变过程受偏应力状态控制。为数值精度考虑，最大蠕变时间步的估计值可表示为材料黏度与剪切模量之比，

(1)\[\Delta t^{cr}_{max} = {\eta \over G}\]

对于幂型蠕变模型，黏度可估计为应力大小 \(\bar\sigma\) 与蠕变速率 \(\dot\epsilon_{cr}\) 之比。使用 该方程（this equation）（如同在 幂模型（power model） 中那样），最大蠕变时间步为

(2)\[\Delta t^{cr}_{max} = {\bar\sigma^{1-n} \over {A G}}\]

对于 WIPP 类模型，黏度可估计为 \(\bar\sigma\) 与二次蠕变速率 \(\dot\epsilon_s\) 之比；使用 该方程（this equation）（如同在 WIPP 模型（WIPP model） 中那样），最大蠕变时间步为

(3)\[\Delta t^{cr}_{max} = {e^{Q/RT} \over {G \ D \ \bar\sigma^{n-1}}}\]

对于 Burgers 类模型，方程 (1) 必须理解为

(4)\[\Delta t_{\max }^{cr}=\min \left( {{\eta^K} \over {G^K}}, {{\eta^M} \over {G^M}} \right)\]

其中上标 \(.^K\) 和 \(.^M\) 分别表示 Kelvin 和 Maxwell 性质。

蠕变压实的时步限制（例如 WIPP-Salt 模型（WIPP-salt model））涉及系统的体积响应，按黏度与体积模量之比估计。该黏度可表示为 \(\bar\sigma\) 与体积蠕变压实速率 \(\dot\epsilon^c_v\) 之比。使用 该方程（this equation）（如同在 WIPP-Salt 模型（WIPP-salt model） 中那样），蠕变压实的最大蠕变时间步为

(5)\[\Delta t^{cr}_{max} = {\vert\sigma\vert \rho \over {K B_0 \left[e^{B_1 \vert\sigma\vert } - 1 \right] e^{B_2 \rho}}}\]

建议使用 FLAC3D 或 3DEC 进行蠕变分析时，初始蠕变时间步取比由上述相应公式算得的 \(\Delta t^{cr}_{max}\) 小约两到三个数量级。通过调用 设置蠕变时步自动控制（model creep timestep automatic） 开启（on），即可利用 自动时间步调整（automatic timestep adjustment）。通常，时间步的最大值（设置蠕变最大时步（model creep timestep maximum））不应超过为 \(\Delta t^{cr}_{max}\) 推导出的值。示例应用见 验证与示例问题（Verifications and Example Problems）。

用于计算 \(\Delta t^{cr}_{max}\) 的应力大小 \(\bar\sigma\)，可由蠕变过程开始前的初始应力状态确定。\(\bar\sigma\)（也称为 von Mises 应力不变量）可通过 FISH 函数计算。应使用 FLAC3D 模型中最大的 \(\bar\sigma\) 来计算 \(\Delta t^{cr}_{max}\)。

;  计算管道中的最大 von Mises 应力
fish define mises
    local max = 0.0
    loop foreach local elem struct.list
        if struct.pos.y(elem) < 2.0 then
            local j2  = tensor.j2(struct.shell.stress(elem,0))
            local sr_vmstr  = math.sqrt(3.0*j2)
            max = math.max(max,sr_vmstr)
        endif
    endloop
    mises = max
end

蠕变时间步的自动调整

时间步可由用户设为常数，也可由 FLAC3D 或 3DEC 控制而自动变化。若时间步自动变化，则当最大不平衡力超过某一阈值时可将其减小，而当其低于另一水平时又可增大。该阈值定义为最大不平衡力与平均网格点力的比值。

所求问题的典型不平衡力判据，可通过观察问题初始阶段仅存在弹性效应时接近平衡状态出现的不平衡力来确定。许多情况下，采用时间步的逐渐增大或减小（例如使用默认比值 lower-multiplier = 1.01 和 upper-multiplier = 0.90）可获得良好性能。

在某些情况下，最好避免连续调整时间步，因为连续调整可能产生“噪声”。为此，在时间步发生变化后，存在一个用户定义的“延迟期”（例如 100 步），在此期间不再进行进一步调整，以便系统稳定下来。通常，时间步从较小值开始，以适应开挖等瞬态过程，然后随模拟推进而增大。若引入了新的瞬态过程，可先手动减小时间步，然后让其再次自动增大。

设置蠕变时步控制（model creep timestep） 命令用于设置时间步以及使时间步可自动变化所需的参数。命令中列出了各关键字。

温度相关性

对于 WIPP 模型，蠕变速率与温度相关。向 WIPP 类模型提供温度有两种方式：可作为 WIPP 类模型的属性指定；也可利用程序的热学选项计算。采用第一种方式时，温度用 设置网格单元属性（zone property）（FLAC3D）或 设置块体网格单元属性（block zone property）（3DEC）命令赋值，并且在计算期间不发生变化。采用第二种方式时，必须先给出 配置热力计算模式（model configure thermal） 命令，并可用 初始化网格点温度（zone gridpoint initialize temperature）（FLAC3D）或 初始化块体网格点温度（block gridpoint initialize temperature）（3DEC）命令初始化温度。在后一种情况下，温度可在循环过程中变化。两种方式均可指定温度梯度。
