3DEC 与 FLAC3D 中的蠕变本构模型

引言

蠕变模拟功能内置于 3DEC 中，并在 FLAC3D 中作为可选项提供。这些功能用于模拟表现出蠕变的材料行为（即随时间变化的材料行为）。已实现以下蠕变模型：

  1. Maxwell 模型（Maxwell model）——一种称为 Maxwell 体的经典黏弹性模型。
  2. Burgers 模型（Burgers model）——一种称为 Burgers 体的经典黏弹性模型，由 Kelvin 模型和一个 Maxwell 模型（Maxwell model） 组成。
  3. 幂模型（Power model）——一种用于采矿应用（例如岩盐或钾盐开采）的双分量幂律模型。
  4. WIPP 模型（WIPP model）——一种参考蠕变模型，常用于与盐层中核废料地下隔离研究相关的热力学分析。
  5. Burgers-Mohr 模型（Burgers-Mohr model）——结合 Burgers 模型（Burgers model） 与 摩尔-库仑模型（Mohr-Coulomb model） 的黏塑性模型。
  6. Power-Mohr 模型（Power-Mohr model）——结合双分量 幂模型（power model） 与 摩尔-库仑模型（Mohr-Coulomb model） 的黏塑性模型。
  7. Power-Ubiquitous 模型（Power-Ubiquitous model）——结合双分量 幂模型（power model） 与 遍布节理模型（ubiquitous-joint model） 的黏塑性模型。
  8. WIPP-Drucker 模型（WIPP-Drucker model）——结合 WIPP 模型（WIPP model） 与 Drucker-Prager 模型（Drucker-Prager model） 的黏塑性模型。
  9. Soft-Soil-Creep 模型（Soft-Soil-Creep model）——考虑随时间变化的次固结的软土模型（仅 FLAC3D）。
  10. WIPP-Salt 模型（WIPP-Salt model）——由 WIPP 模型（WIPP model） 修改而来的黏塑性模型；包含适用于类盐材料的体积压实与偏量压实行为。

这些模型按复杂度递增的顺序介绍。

此外，用户还可使用 编写新的本构模型（Writing New Constitutive Models） 中所述的 DLL 用户自定义模型选项编写自己的蠕变本构模型。
