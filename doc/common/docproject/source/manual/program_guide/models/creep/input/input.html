蠕变模拟的输入说明

蠕变命令

以下命令用于运行蠕变问题。命令 配置蠕变计算模式（model configure creep） 必须 作为第一个蠕变命令给出，之后才能调用任何其他蠕变命令。配置蠕变计算模式（model configure creep） 可在分析的任何阶段指定。

表 1：蠕变命令
配置蠕变计算模式（model configure creep）
设置蠕变历程输出项（model history creep）
设置蠕变结果输出间隔（model results interval creep）
设置蠕变求解限制（model solve creep）
设置蠕变分析参数（model creep）
FLAC3D专用蠕变命令
设置网格单元蠕变参数（zone creep）
指定网格单元本构模型（zone cmodel assign）
设置网格单元属性（zone property）
设置开挖松弛蠕变表（zone relax excavate table creep）
设置松弛修改蠕变表（zone relax modify table creep）
3DEC专用蠕变命令
指定块体网格单元本构模型（block zone cmodel assign）
设置块体网格单元属性（block zone property）

蠕变 FISH 变量

在 FLAC3D FISH 函数中可使用以下标量变量，以辅助蠕变分析。

表 2：蠕变 FLAC3D FISH 函数
网格单元蠕变累计时间（zone.creep.time.total）
网格单元蠕变时步（zone.creep.timestep）
