安装

PFC 通过 Microsoft 软件安装程序（.msi）文件进行安装。安装通常通过 USB 驱动器提供（购买标准许可证或网络许可证时），但在某些情况下也可通过下载获取。PFC 设计为在 Microsoft Windows 系统上运行（目前支持 Windows XP、Windows Vista、Windows 7 和 Windows 8）。

默认安装将安装程序、其示例文件以及完整文档。本套文档包含完整的程序文档，可通过程序中的 帮助 —> 帮助 菜单选项访问。

运行安装程序

PFC 通过 USB 驱动器、DVD 或下载提供的软件安装程序进行安装。要使用 USB 驱动器或 DVD 安装，请将安装介质插入计算机。插入后，将出现 自动播放 对话框。如果使用闪存驱动器，请选择“打开文件夹以查看文件”，然后打开文件“start.exe”。如果使用 DVD，请选择“运行 start.exe”。如果 自动播放 对话框未出现，请转到介质根目录并运行“start.exe”。在提供的选项中单击 PFC 按钮以开始 PFC 安装。安装向导将引导您完成整个过程。该向导包含四个屏幕（欢迎、最终用户许可协议、目标文件夹 和 准备安装）。在大多数情况下，用户可以接受这些屏幕中呈现的默认选项（单击 下一步）。

安装软件后，请拔出安装用 USB 驱动器。将安全密钥插入可用的 USB 端口。首次执行此操作时，操作系统将查找随 PFC 安装提供的驱动程序，并安装它以配合安全密钥使用。

卸载

卸载最好使用 Windows 控制面板 中的 Windows 程序和功能 功能完成。要访问该功能，在 Windows 7 及更早版本上选择 开始 —> 控制面板 —> 卸载程序。在 Windows 8 及更高版本上，右键单击 PFC 程序磁贴，然后单击屏幕底部菜单中出现的“卸载”选项，直接转到“程序和功能”功能。
