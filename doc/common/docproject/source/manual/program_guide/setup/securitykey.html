安全

本程序通过密钥（也称为“硬件锁”或“加密狗”）进行安全保护。必须插有该密钥，程序才能进行计算循环（cycle）。如果没有密钥，代码将在“演示模式”下运行（见下文）。本程序提供标准许可证或网络许可证。在这些不同的许可证类型下，程序的行为存在差异；它们也需要不同的密钥。

为蓝色。

标准许可证

标准许可证专为单用户使用程序而设计，安全密钥应插在安装程序的同一台计算机上。如许可协议（License Agreement）中所述，标准许可证最多允许同时有两个程序实例进行计算循环。但是，可启动的实例数量没有限制。密钥可根据需要在计算机之间移动。

网络许可证

网络许可证允许一个密钥提供 n 个程序实例的访问权限，其中 n 是随许可证购买的席位数。在此配置中，密钥以及运行许可管理软件所需的服务器软件安装在一台计算机（服务器）上。然后在将访问服务器可用许可证席位的计算机（客户端）上安装本程序。本程序可安装在所需数量的客户端计算机上。当正在使用的许可证少于 n 个时，启动程序的客户端将正常启动，并从服务器获取其许可证。如果已有 n 个许可证在使用中，则启动程序的客户端将收到 未检测到硬件锁！（Hardware Lock Not Detected!） 警告。

演示模式

如果在没有标准许可证或网络许可证密钥的情况下启动程序，将出现 未检测到硬件锁（Hardware Lock Not Detected） 错误对话框。当没有密钥时，该对话框提供通过选择 继续 按钮以“演示模式”启动程序的选项。该模式在各方面功能完整，只是程序只能对特定模型尺寸限制内的模型进行计算循环。限制为 1000 个球体、1000 个刚性团簇和 10 条裂隙。 CS：需要弄清如何标明这些限制 尝试对更大的模型进行计算循环将产生错误信息，表明模型尺寸超出了可在“演示模式”下进行计算循环的范围。
