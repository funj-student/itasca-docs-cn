更新密钥

当用户购买程序升级、预购下一版本程序或在现有许可证上添加新选项时，通常 安全密钥（security key） 将通过直接在 PFC 中执行的密钥重配置过程进行更新。对当前许可证的任何单项更改都使用一个密码文件执行；同时对许可证进行多项更改则使用多个密码文件。步骤如下。

  1. Itasca 将发送用于对许可证进行更改的密码文件。请准备好这些文件。
  2. 确保要更新的密钥已连接到计算机。
  3. 启动PFC。
  4. 转到更新密钥对话框；依次选择菜单工具 —> 更新密钥…。
  1. 使用对话框控件选择更新密钥所需的密码文件。可以对手头的每个密码文件逐一执行这些步骤来完成该过程；但是，同时指定所有密码文件更简单快捷（按住 Ctrl 键的同时单击所需的每个文件，这要求所有文件都位于同一文件夹中）。
  2. 该过程成功完成会在消息对话框中显示。未成功完成将以错误终止。如果出现错误，请立即联系提供密码文件的代码销售办事处或代理商以解决问题。
