获取程序修订历史

Itasca 将更正任何代码错误或问题作为最高优先事项，并以逐个修复的方式向程序提供更正。这样，用户就无需等待补丁或中间版本即可获得对所遇到问题的必要更正。因此，鼓励用户熟悉程序的修订历史。代码的每次更新都会分配一个子版本号、注明日期，并记录在保存在 Itasca 网站上的修订历史中。该历史可随时从程序内部访问（前提是用户有可用的互联网连接）。要访问它，请使用菜单序列 工具 —> 检查修改…。这会将修订历史加载到新的浏览器窗口中。

提示

修订历史列表顶部还包含一个指向 Itasca 网站上该程序主更新页面的链接。使用该链接将把用户带到可下载程序更新的位置。
