PFC 版本号

获取版本号

查找版本号的方法有多种。

  1. 查看程序标题栏。版本号显示在那里。
  2. 选择菜单序列 帮助 —> 关于 —> 关于 PFC。显示的对话框在第一行列出版本号。
  3. 在控制台中输入 列出程序信息（program list） version。控制台 窗格输出的第一行表示版本号。

版本号说明

PFC 的版本号采用简单的编号体系，用于标识程序中的更新级别。版本号中有三个数字标识符，即，

Version I.JK

其中：

I 是从 1 开始的整数，表示代码的一个主发行版本；

J 是一个整数，当为 PFC 的补充升级发行而对代码结构进行需要重大更改的修改时，该整数即递增；以及

K 是一个整数，当次要修改作为当前版本的更新正式发布时，该整数递增。

子版本号

您所使用的程序的准确版本由子版本号确定，该号是出现在上述第三位数字（K）之后的点（.）之后的一个数字。较小的子版本号表示比更大的子版本号更早的版本。子版本号用于标识自正式版本发布以来对 PFC 所作的次要更改。程序可自动检测是否有新的子版本可用（更多信息请参阅更新提醒对话框（Update Alert dialog）主题）。

注意

子版本号大于正式发行版本的 PFC 应谨慎使用，因为并非所有功能都已充分测试。
