文档

所有程序文档均提供在本套文档中。这些文档是 HTML 页面，可在浏览器中或直接在程序内加载。

通用功能

文档集中的每个页面都包含以下元素。

  • 页面顶部标示代码名称的徽标同时也是指向首页的链接
  • 右上角的简易搜索栏对所输入的所有词进行逻辑“或”搜索（注意，不支持使用引号的短语搜索）
  • 每个页面左侧边距上的菜单按钮 ( ) 将收起左侧的导航栏
  • 如果页面宽度小于最小宽度，导航栏将自动收起
  • 每个页面底部的“本页是否有帮助……”链接可用于提交用户反馈
  • 每个页面的页脚包含当前页面在文档树中的路径，以及指向文档集中下一主题和上一主题的链接。
  • 页脚中的代码名称也是指向 Itasca 网站上该代码主页的链接
  • 命令相关帮助（Help With Commands）
