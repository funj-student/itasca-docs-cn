工具菜单

图 1：工具菜单。

选项
打开选项对话框（Options dialog）。
禁用工具提示
关闭当鼠标悬停在界面工具（例如工具栏上的按钮、对话框控件等）上时出现的提示显示
打包
打开一个包含“打包…”和“解包…”选项的飞出菜单。前者允许将当前项目打包并保存为打包文件；后者调用一个对话框，允许用户选择要解包的打包文件并在PFC中打开。有关此功能的更多信息，请参见“项目打包文件（Project Bundle Files）”主题。
复制应用程序数据…
打开一个对话框（a dialog），允许用户为随PFC提供的所有示例及其他辅助材料创建一个用户可访问的文件夹（这些材料会从安装程序时最初写入的系统保护区复制到用户指定的位置）。
检查修改…
打开一个访问 Itasca 网站的浏览器窗口，以显示该程序的最新修改。
插件…
打开一个对话框，显示当前在PFC中加载的插件。
更新密钥…
打开一个对话框（a dialog），当购买升级、选项或其他程序附加内容导致许可发生变化、且该变化必须由密钥识别时，允许用户更新其硬件锁（安全 USB 密钥）。此操作要求用户拥有有效的密码文件（由 Itasca 在修改许可时提供），以便完成密钥更新过程。

注意

Earlier versions of the Tools menu included an Update Key… item that was used to facilitate making changes (upgrade, add option, etc.) to the license security key. This functionality and other license-related facilities may now be found on the c Help menu (see the License ▸ flyout on that menu).
