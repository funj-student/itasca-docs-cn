工具栏

图 1：i 编辑（Edit）窗格处于活动状态时的主工具栏。

工具栏是动态的：其上显示的工具会随活动的窗格类型（pane type）而变化。主工具栏在其左侧显示当前活动窗格的工具；在其右侧，控制面板的工具集中分组显示。主工具栏可以浮动，但不能从显示中移除。它只能停靠在主菜单旁边。

工具栏上可供每种窗格类型使用的具体工具在各窗格类型的文档章节中介绍：此处放置各窗格类型工具栏的链接集。

执行/停止切换按钮

对上述内容有一个重要的说明：无论活动窗格的类型如何，工具栏始终在其左端提供执行/停止切换按钮作为第一个按钮。该切换按钮的可能状态如下。

执行（禁用）
如果当前窗格不包含数据文件并且代码当前未在执行计算循环，则显示此按钮。此时无法处理命令。
执行（启用）
如果当前窗格包含数据文件并且代码当前未在执行计算循环，则显示此按钮。按下该按钮将处理活动窗格中的命令。
停止
如果代码当前正在执行计算循环，则显示此按钮。按下它将停止命令处理。

控制面板工具

工具栏始终在其右端提供控制面板显示/隐藏和控制集按钮。

控制面板显示/隐藏
此按钮切换控制面板的显示状态（可见/隐藏）。
控制集
此按钮是一个下拉菜单，列出当前活动窗格在控制面板中可用的控制集。列出的每个控制集都是一个切换项。如果控制集可见，则处于勾选状态。选择已勾选的控制集将隐藏它；选择未勾选的控制集将显示它。
