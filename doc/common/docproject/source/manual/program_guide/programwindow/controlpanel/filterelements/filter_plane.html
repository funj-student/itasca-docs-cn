平面

交互使用

设置过滤器 A：当“类型”属性设置为“距离”时，将鼠标置于任一平面的控制柄点（ ）上，直到光标指示定位模式已就绪（ ）。按住左键并拖动可设置两平面之间的距离。将光标置于中心控制柄点上，然后单击并拖动可定位原点。单击两平面之间的红线并拖动，可更改平面的方位（法向或倾角/倾向）。

设置过滤器 B：将“类型”属性设置为“上方”或“下方”，将鼠标置于平面的控制柄点（ ）上，直到光标指示定位模式已就绪（ ）。按住左键并拖动可定位平面的原点。将鼠标置于红色方位线上，然后单击并拖动可更改方位（法向或倾角/倾向）。


属性

非：反转过滤元素的选择。

范围：若勾选，则仅当项的整个范围都位于该过滤元素的定义范围内时才包含该项。若未勾选，则使用项的形心来确定项的位置以及它是否位于过滤元素的定义范围内。

原点：指定平面原点的 x、y 和 z 坐标。

法向：以法向量形式指定平面的方位。

倾角/倾向：以倾角和倾向（单位：度）的形式指定平面的方位。

类型：指定相对于平面进行何种过滤。选项为“上方”（沿法向量方向）、“下方”（与法向量方向相反）和“距离”（距平面两侧各一段距离）。

距离：指定平面两侧要包含在范围内的距离。
