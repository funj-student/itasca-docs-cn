移除

用法

此过滤元素可用于移除绘图项的某些部分，既可以通过交互方式，也可以使用属性表单。

交互操作

将鼠标置于所关注区域内的绘图项上。当光标指示移除模式已就绪（ ）时，单击要移除的对象。根据需要重复此操作。注意，每次执行移除单击都会将一个项（以 ID 标识）添加到“添加”属性中。以此方式添加的项无法被移除，但可以取消勾选其名称旁的复选框，从而在过滤器中“取消包含”它们。

属性

非：反转过滤元素的选择。

范围：若勾选，则仅当项的整个范围都位于该过滤元素的定义范围内时才包含该项。若未勾选，则使用项的形心来确定项的位置以及它是否位于过滤元素的定义范围内。

添加：显示绘图项已移除部分的列表。要移除的对象处于勾选状态；取消勾选某个项将使其被排除在过滤元素的作用之外。
