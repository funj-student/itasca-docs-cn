多边形

交互使用

创建过滤器：在光标指示创建模式已激活（ ）的情况下，围绕要由过滤元素包含的区域绘制多边形（单击左键为多边形指定点，拖动以移动到下一位置，Ctrl + 单击左键完成）。使用后，光标将切换到重置模式。


注意

实际上，它指定的是一个拉伸多边形：该多边形在平行（parallel）模式下无限延伸，在透视（perspective）模式下延伸至灭点。初次创建时，仅显示表示所绘范围的红色线条。若移动当前视图设置，该拉伸会以透明方式渲染；红色线条表示该对象在原始视图平面上的位置。灭点（在透视模式下）表示绘制多边形时的原始视点位置。

重置过滤器：当光标指示重置模式（ ）时，按住 Shift 键并在视图窗格中的任意位置单击左键，即可清除现有的过滤元素。使用后，光标将切换为指示创建模式已激活。不按住 Shift 键时单击左键将不会执行任何操作。


属性

非：反转过滤元素的选择。

范围：若勾选，则仅当项的整个范围都位于该过滤元素的定义范围内时才包含该项。若未勾选，则使用项的形心来确定项的位置以及它是否位于过滤元素的定义范围内。
