ID 列表

用法

此过滤元素可用于按 ID 过滤项列表。默认情况下，它会以设置“非”属性的状态出现。此过滤元素与移除过滤元素类似。不过，移除过滤元素旨在“减去一些、保留大部分”，而此过滤元素更适合“减去大部分、保留一些”。进一步的讨论见下文。

交互操作

将鼠标置于所关注的绘图项对象上。当光标指示移除模式已就绪（ ）时，单击要移除的对象。根据需要重复此操作。注意，每次执行移除单击都会将一个项（以 ID 标识）添加到“添加”属性中。添加到“添加”列表中的项无法被移除，但可以取消勾选其名称旁的复选框，从而在过滤器中“取消包含”它们。假设用户希望过滤绘图项以便仅显示所选的项，则使用此元素的最后一步是取消勾选“非”属性。

属性

非：反转过滤元素的选择。

范围：若勾选，则仅当项的整个范围都位于该过滤元素的定义范围内时才包含该项。若未勾选，则使用项的形心来确定项的位置以及它是否位于过滤元素的定义范围内。

添加：指定要包含在过滤器中的 ID 编号列表。可将数值输入到“添加”标签旁的字段中，然后按 Enter 将其添加到列表。可使用每个已添加对象 ID 旁的复选框来使该对象包含（勾选）在过滤器作用范围内或排除（取消勾选）在外。

移除与 ID 列表的对比：进一步讨论

为说明这两种过滤元素之间的差异，设想一个由 100 个球组成的集合。若用户想从集合中移除 10 个球，则移除过滤元素是最高效的选择。若要移除 90 个球而留下 10 个，可以使用勾选了“非”属性的移除元素，但这要求用户单击或输入全部 90 个待移除的球来创建过滤器。在这种情况下，ID 列表过滤器要高效得多。不过，若要使用ID 列表来指定所涉及的 10 个球，则必须从设置“非”属性开始。否则，在特定视图模式下显示会呈半透明（这会使拾取变得含糊且困难）；在普通视图模式下绘图项将不可见（这会使拾取无法进行）！
