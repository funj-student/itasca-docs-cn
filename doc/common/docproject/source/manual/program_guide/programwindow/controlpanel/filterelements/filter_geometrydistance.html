几何距离

用法

此过滤元素基于绘图项到所选几何对象的距离来定义过滤器。使用时，从“几何集”属性提供的列表中指定所需的几何对象（若模型中不存在几何集，则该列表为空；参见 导入几何对象（geometry import） 命令）。“距离”属性基于绘图项各部分到几何对象的距离，指定要包含的绘图项部分。此判定使用到几何上最近点的距离。


属性

非：反转过滤元素的选择。

范围：若勾选，则仅当项的整个范围都位于该过滤元素的定义范围内时才包含该项。若未勾选，则使用项的形心来确定项的位置以及它是否位于过滤元素的定义范围内。

距离：指定用作容差的距离；位于该容差内的对象将被选中。

几何集：从所列内容中选择要使用的一个或多个几何集。
