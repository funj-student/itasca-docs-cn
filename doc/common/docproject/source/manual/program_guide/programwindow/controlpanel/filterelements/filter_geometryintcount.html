几何相交计数

用法

此过滤元素按从对象形心引出的射线与某个几何集相交的次数来过滤绘图项对象。若在“计数”属性（见下文）中设置奇数个交点，则满足该过滤元素条件的对象很可能位于几何集内部——前提是该几何集为封闭体积。


属性

非：反转过滤元素的选择。

范围：若勾选，则仅当项的整个范围都位于该过滤元素的定义范围内时才包含该项。若未勾选，则使用项的形心来确定项的位置以及它是否位于过滤元素的定义范围内。

计数：设置射线的交点数。若将其设置为“奇数”（单击微调框控件，直到达到“-1”位置），则将选中穿过指定几何集的交点数为奇数的任何对象。

射线方向：设置射线的方向（x、y、z）。默认值为 0, 0, 1。

几何集：从所列内容中选择要使用的一个或多个几何集。若此属性为空，则表示模型中不包含任何几何集；参见 导入几何对象（geometry import） 命令。
