显示与打开

如果已隐藏（已打开但不可见）：

  • 使用文档菜单取消隐藏该窗格（如果它是视图或编辑器窗格；使用窗格菜单显示所有其他窗格。
  • 包含数据文件的隐藏窗格也可以使用i 项目（Project）窗格来显示。

使隐藏窗格可见也会使该窗格成为当前活动窗格。

有关窗格可能的视图状态（打开且可见、已关闭、已隐藏）的说明，请参见关于隐藏与关闭（Hiding and Closing）窗格的主题。

文档窗格会根据所请求的项在需要时创建：打开数据文件（data file is opened）时、创建绘图时，或命令产生列表输出时。创建的窗格在创建时即成为活动窗格。CS：上述每一项都应是所述操作的链接。

注意

在程序中不能通过任何工具栏或按钮打开已有的窗格。只有菜单可以做到这一点，因为它们是界面中唯一保证始终可用的组件——请记住，主工具栏虽然始终存在，但其内容会变化，并取决于活动窗格。
