启动对话框

启动对话框在程序首次打开时传递状态通知，并提供与项目有关的操作选项。

通知

这些消息附带链接，以提供关于该通知的更多信息。如果该链接被访问一次，“不再显示”复选框即被激活，用户可以勾选该项，以阻止其在以后启动时显示。[1]

选项

最近项目
这将打开上方“最近项目”下拉列表中显示的项目。使用该下拉列表可访问最近项目列表，以便按需更改选择。
新建项目…和打开项目…
这两者中的任何一个都会打开 File → Open 对话框，以执行所选的选项。
无项目
此选项在未指定项目的情况下打开程序（见下面的提示）。使用对话框的关闭按钮（×）具有选择此选项的效果。

提示

关于无项目工作：程序始终表现得如同已加载项目一样，即使在启动选项中选择了无项目。选择“无项目”时会创建一个“temp”项目；它会跟踪所有项目项（数据文件、模型状态（SAV）文件等）。使用文件 —> 保存菜单命令将保存此项目。

尾注

[1]已关闭的通知消息可以使用选项对话框中的启动选项（Start-up Options）恢复。
