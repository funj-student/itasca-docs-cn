隐藏与关闭

窗格只能通过其标题栏上的控件来隐藏或关闭（从文档和窗格菜单中只能打开窗格，而不能关闭它们）。窗格可能的关闭状态由标题栏上呈现的按钮决定。具体如下。

关闭窗口

隐藏窗口

如果窗格的标题栏上没有某个按钮，则无法对该窗格执行该按钮所代表的操作。

隐藏与关闭的区别

隐藏的窗格仍然存在但不可见。它在隐藏期间仍执行其各种操作并占用其所需的资源。相比之下，关闭的窗格不仅是不可见，而是不再存在（因而不再消耗计算机资源）。如果只关心（不）可见性，这一区别并不重要。不过，在某些情况下，一些窗格即使在隐藏时内部活动也足够密集——例如i 状态记录（State Record）窗格——以至于可能影响计算速度，此时建议关闭该窗口而不是隐藏它。

警告

请记住，绘图与数据文件不同，它不能脱离项目单独存在。绘图存储在项目文件（project file）中。因此，关闭包含绘图的i 视图（View）窗格会永久删除该绘图——没有任何机制可以恢复或重新打开它。
