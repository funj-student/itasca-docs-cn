窗格菜单

图 1：菜单以勾选标记列出打开的项；带“x”标记的项已关闭；不显示图标的项已隐藏。

此菜单上的每个窗格都是唯一的：每种类型始终只有一个实例。其中大多数窗格可以隐藏或关闭（hide or close）。

与“文档”菜单一样，从此菜单中选择一项会使程序按需打开或取消隐藏该项，并使其成为活动窗格。此外

该菜单完成两项任务：

  • 指示每个项的隐藏或关闭状态（hidden or closed state）（勾选 = 可见；带 x 标记 = 已关闭；无图标 = 已隐藏）
  • 导航到从菜单中选中的项，并根据需要取消隐藏

已关闭的项不会从菜单中移除。

注意

不能从此菜单关闭项。项旁边的复选框是可见性的指示器。选中已勾选的项不会“取消勾选”它（即不会“关闭”它），但会使程序将该窗格设为程序中的活动窗格。请使用窗格标题栏上的关闭按钮（ ）关闭窗格。

提示

此菜单上列出的键盘快捷键是全局的。在程序的任何上下文中，使用这些快捷键都会使所请求的窗格按需显示/取消隐藏，并成为当前窗格。

注意

模型、挤出和构建块窗格是FLAC3D专有的。
