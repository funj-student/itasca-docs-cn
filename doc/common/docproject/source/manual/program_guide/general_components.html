通用模型对象

本节介绍的模型对象并非特定于某一程序，而是以下各 Itasca 程序普遍可用的：PFC2D、PFC3D、FLAC3D 和 3DEC——因此称为“通用”。这意味着这些程序之间有大量知识可以迁移。例如，掌握分组（groups）在 PFC 中的工作方式，就足以理解它们在 FLAC3D 中的工作方式。在这些程序中，此处所述对象实现相同类型的用途、具有相同的基本逻辑，并在相同的假设下运行。

因此，本套文档采用如下划分：所有程序共有的内容放在程序指南（Program Guide）一节中，而特定程序特有的内容放在其后的各节中（即 FLAC3D、PFC 和 3DEC）。这种划分有助于容易地区分程序特有对象与 Itasca 软件范围内通用的建模构造。关于分别特定于 PFC、FLAC3D 和 3DEC 的命令和 FISH，参见 PFC 模型对象（PFC Model Objects）、FLAC3D 命令与 FISH（FLAC3D Commands and FISH） 以及 3DEC 命令与 FISH（3DEC Commands and FISH）。
