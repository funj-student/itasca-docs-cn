保存文件处理

创建/保存

  • 在 命令提示符（command prompt） 处或在数据文件中使用 保存模型（model save） 命令
  • 当 i 控制台（Console） 窗格处于活动状态时，按工具栏上的 保存（）
  • 当 i 控制台（Console） 窗格处于活动状态时，使用菜单中的 File –> [item] –> Save（如果当前模型状态与现有保存文件关联，则 [item] 将是该保存文件的名称；如果当前模型状态未与现有保存文件关联，则 [item] 将显示“–”）

注意

如果当前模型状态与现有保存文件关联，则可使用上述步骤一次性保存该状态（任何新数据都会添加到现有文件中）。如果当前模型状态未与先前的保存文件关联，则上述步骤将打开 File –> Save 对话框，用于为新保存文件指定文件夹名称和文件名。默认情况下，该对话框最初会在包含当前 项目文件（project file） 的文件夹中打开。

恢复

  • 在 命令提示符（command prompt） 处或在数据文件中使用 恢复模型（model restore） 命令
  • 在 i 项目（Project） 窗格的“已保存状态”列表中双击某个保存文件（以 表示），或右键单击列表中的某个项目项并从菜单中选择 Restore

删除

  • 在 i 项目（Project） 窗格中，选中该项并按工具栏上的“删除”，或右键单击并从菜单中选择 Delete

添加到项目

使用上述任何方法创建的保存文件都会自动添加到项目中。在当前上下文中，“添加”指的是将“外部”现有的保存文件纳入项目。

  • 使用 File –> Open... 对话框选择并“打开”（在这种情况下是添加到项目而不是恢复）一个保存文件

从项目中移除

“移除”是一个很少需要的选项，它会切断项目与某个保存文件的连接，但不会删除该文件。

存储

项目完成时，是否存储保存文件是时间与存储空间之间的权衡。如果所有项目文件都齐备，可以使用打包（bundle）文件作为归档，以便在需要时重新运行整个项目。这种方式在存储空间上很高效，因为它不保留保存文件，因此可能相对较小。不过，如果模型和/或项目很大，则应考虑重新生成保存文件可能需要的时间。
