状态记录 窗格中的工具

工具栏

当 状态记录 窗格处于活动状态时，工具栏如下所示。

表 1：状态记录 窗格工具栏上可用的工具
图标 命令 说明/注释
以记录格式复制 以记录格式复制当前选择内容（包含所有显示的文本）。
以数据格式复制 以数据文件格式复制当前选择内容（仅包含所显示的输入行）。
全选 选择窗格中的所有文本。
选择剩余部分 选择自上次复制命令以来所创建的输入记录行。
另存为记录 将窗格内容以记录格式保存到文件（包含所有显示的文本）。所创建的文件将在 PFC 的编辑器窗格中打开。
另存为数据文件 将窗格内容以数据文件格式保存到文件（仅包含所显示的输入行）。所创建的文件将在 PFC 的编辑器窗格中打开。
显示/隐藏 控制面板 切换 控制面板 的显示状态。
显示/隐藏控件组 此按钮是一个下拉按钮，列出此窗格类型可用的控件组。选择未勾选的条目可将其显示在控制面板中；选择已勾选的条目可将其隐藏。

控制面板

当 i 状态记录（State Record） 窗格处于活动状态时，控制面板 中可以使用以下控件组：

  • FISH 全局符号控件组（FISH Global Symbols Control Set）

使用工具栏上的 显示/隐藏控件组 按钮（）来访问此控件组。
