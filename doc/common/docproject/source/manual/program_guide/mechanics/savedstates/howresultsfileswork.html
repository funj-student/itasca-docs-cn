结果文件的工作方式

由于结果文件在某种意义上是一种“精简”的保存文件，因此它们的行为与保存文件有一些共同之处。

  • 它们表示特定计算循环数时的模型状态，尽管所包含的模型数据要少得多
  • 恢复后，结果文件即为当前模型状态（注意 恢复模型（model restore） 命令对保存文件和结果文件都有效）
  • 结果可以以二进制或文本格式存储；后者更大，但更适合用其他工具进行数据提取操作

另一方面，保存模型（model save） 命令会创建保存文件，而其对应的 设置结果文件（model results） 命令并不用于创建结果文件，而是用于指定创建一组结果文件的标准。

保存文件是显式且逐个创建的（大多数情况下如此——在 FISH 循环中保存会是一个例外）。结果文件则根据构造结果输出请求时所指定的interval值自动、隐式地创建。

也许最重要的是，尽管恢复的结果文件会被程序视为当前模型状态，但无法从该状态进行循环计算。

结果文件在创建时绝不会成为活动模型状态。只能通过 i 项目（Project） 窗格或使用 恢复模型（model restore） 命令使其成为活动状态。

结果文件剖析

在构成上，结果文件与保存文件类似（comparable to save files），但有以下差异。

  • 文本文件头仅包含程序数据；不包含任何命令。
  • 文件二进制部分所包含的数据仅限于用户为结果文件请求的数据。
