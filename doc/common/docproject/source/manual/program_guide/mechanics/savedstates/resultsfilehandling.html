结果文件处理

创建

  • 在 命令提示符（command prompt） 处或在数据文件中使用 设置结果文件（model results） 命令
  • 使用 i 选项（Options） 对话框的 i 结果（Results） 页面（但 仍在权衡中（under advisement））
  • 要包含在结果文件中的数据需使用数据对象上的 results 关键字逐项添加（设置历史结果输出（history results） 将添加history数据，设置球体结果输出（ball results） 将添加球体数据，设置网格单元结果输出（zone results） 将添加网格单元数据，依此类推）

恢复

  • 在 命令提示符（command prompt） 处或在数据文件中使用 导入结果文件（model results import） 命令
  • 在 i 项目（Project） 窗格的“结果文件”列表中双击某个结果文件（以 表示），或右键单击列表中的某个项目项并从菜单中选择 Import

添加到项目

使用上文“创建”中所示方法创建的结果文件会自动添加到项目中。在当前上下文中，“添加”指的是将“外部”现有的保存文件纳入项目。

  • 使用 File –> Open... 对话框选择并“打开”（在这种情况下是添加到项目而不是恢复）一个保存文件

删除

  • 在 i 项目（Project） 窗格中，选中该项并按工具栏上的“删除”，或右键单击并从菜单中选择 Delete
