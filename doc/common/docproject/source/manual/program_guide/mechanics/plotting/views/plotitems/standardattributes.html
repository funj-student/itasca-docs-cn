标准属性控件

许多绘图项属性（绘图项中控制其渲染的各个方面）在 控制面板 中的 绘图项 控件组内都采用标准控件。这意味着它们在一个绘图项上的使用方式与在其他绘图项上的使用方式完全相同。此处索引了绘图项属性中最常遇到的控件。

名称 说明
颜色（Color） 选择一种颜色
颜色列表（Color-List） 控制颜色列表的外观
颜色选项（ColorOpt） 设置着色选项
等值线（Contour） 控制等值线外观
切割线（Cutline） 设置切割线粗细
变形系数（Def-fac） 设置变形系数
字体（Font） 指定字体设置
图例（Legend） 控制图例中标示该项的哪些方面
线（Line） 选择线型
映射（Map） 将绘图项映射到新的模型坐标
多边形（Polygons） 设置绘图项面片的显示特性
比例（Scale） 缩放该项
形状（Shape） 选择和定义项的形状
透明度（Transparency） 设置项的透明度
