通用绘图项

以下绘图项可用于 任何 Itasca 数值建模代码。

名称 说明
坐标轴（Axes） 指示绘图当前方向的参考坐标轴。
裂隙（Fracture） 按属性或特性着色的裂隙。
裂隙交线（Fracture Intersections） 按属性或特性着色的裂隙交线。
裂隙玫瑰图（Fracture Rosette） 裂隙玫瑰图图表。
裂隙赤平投影网（Fracture Stereonet） 赤平投影网的极点方向。
几何（Geometry） 几何数据。
历史图表（History Chart） 二维图表，用于显示模型执行期间记录的一个或多个历史。
历史位置（History Locations） 当前正在采集的历史的位置——前提是该历史具有关联的位置。
标签（Labels） 使用 设置历史标签（label） 命令创建的一个或多个用户自定义标签。
颗粒轨迹（Particle Trace） 被追踪颗粒所经过的路径；还可以按其速度大小对路径绘制等值线。
标量（Scalars） 用户定义的标量数据。
比例框（ScaleBox） 用于帮助显示模型范围和比例的框。
数据表图表（Table Chart） 一个或多个数据表的二维图表。
张量（Tensors） 用户定义的张量数据。
矢量（Vectors） 用户定义的矢量数据。
