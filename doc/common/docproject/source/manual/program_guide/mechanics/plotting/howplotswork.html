绘图的工作原理

本主题介绍对绘图执行的外部操作。有关绘图内部的操作（即为模型可视化目的而构建绘图），请参见 i 绘图（Plot） 窗格一节。浏览 i 绘图（plot） 命令也很有用。

创建绘图

创建绘图有多种可用方法。下面前两种方法在任何程序环境中都可用；后两种方法仅在特定环境中可用，具体如下。

  • 从文件菜单执行 文件 -> 新建绘图… 命令。
  • 通过键盘按 Ctrl + Shift + N。
  • 在 i 控制台（Console） 窗格的 命令提示符（command prompt） 处输入 创建绘图（plot create）。
  • 当某个现有的 i 绘图（Plot） 窗格处于活动状态时，单击工具栏上的 新建绘图 按钮（ ）。

隐藏和显示绘图

隐藏绘图会将其从视图中移除而不删除它（关闭绘图则会删除它，见下文）。要隐藏特定绘图，请按其标题栏上的 隐藏 按钮（ ）。这是隐藏绘图的唯一方式。要使隐藏的绘图重新显示，请从 i 文档（Documents） 菜单中选择它。绘图在菜单中按其绘图名称列出。这是显示隐藏绘图的唯一方式。

命名和重命名绘图

绘图的初始名称取决于创建它所使用的方式。如果使用 文件 -> 新建绘图… 命令，绘图将被自动命名（“Plot#”，其中 # 是考虑到现有绘图名称后的下一个可用索引编号）。如果使用 创建绘图（plot create） 命令，可以选择提供一个字符串 字符串名称（sname） 为其指定特定名称；如果省略该关键字，则将使用默认的自动命名系统。

可以按如下方式重命名绘图。

  • 文件 -> [绘图名] -> 重命名…（其中 i 文件（File） 菜单中的 [绘图名] 是该绘图的名称，显示在该绘图的标题栏上）。
  • 在 i 绘图（Plot） 窗格的任意位置右键单击，然后选择 绘图 -> 重命名…。
  • 如果绘图的窗格属于某个选项卡组，请右键单击选项卡标签并选择 重命名…。
  • 使用命令 重命名绘图（plot rename） s 重命名当前绘图；或使用 plot s rename 新名称字符串（sNew） 重命名任意绘图。

在前三种情况下，将显示一个对话框，允许用户为绘图指定新名称。

关闭绘图

要关闭绘图，请按其标题栏上的 关闭 按钮（ ）。警告：关闭绘图会将其完全删除，无法恢复或重新显示。如果只是想让 i 绘图（Plot） 窗格从视图中消失，请使用 隐藏（见上文）。

保存绘图

程序中任何已打开或已隐藏的绘图都会随项目一起保存，并在程序中打开该项目时随项目一起恢复。没有专门用于保存文件的操作，不过它们可以导出。

导出绘图

  • 右键单击绘图，选择 导出 ‣ 数据文件 …
  • 从主菜单中选择 文件 ‣ [绘图名] ‣ 导出 ‣ 数据文件…
  • 使用 i 绘图（Plot） 窗格工具栏上的“导出绘图”按钮（ ——选择“数据文件…”）

绘图可以导出为图形文件（位图）或数据文件。如果导出为数据文件，该文件包含与在用户界面中交互式设置的开关相关联的所有关键字。请注意，导出后，生成的数据文件会自动在 i 编辑器（Editor） 窗格中打开以供查看，并自动包含在项目中。
