安全系数绘图项

说明

在绘图图例中显示最近一次计算得到的安全系数。

属性

图例（Legend）

图例

设置绘图图例中该项目的标签。详情请参见标准的 图例（legend） 控件说明。

在 标题 下方，安全系数 绘图项还在 图例 中提供用于 值 和 可用性 的控制项。

后两项都可以勾选，但它们是互斥的：要么存在最近一次计算得到的值，并在图例中显示；要么不存在，此时将显示“FOS 不可用”消息。
