刚性簇模板

说明

按属性或特性着色的刚性簇模板。

此绘图项的控制方式与 刚性簇（Clump） 绘图项完全相同。它们之间的区别在于 形状 属性上可用的选项较少，仅限于“刚性簇”和“表面”，并且新增了一个 显示 属性，详见下文。

属性

形状（Shape） 按…着色（Color By） 颜色选项（Color Opt） 显示（Display） 映射（Map） 透明度（Transparency） 图例（Legend）

形状

仅有“刚性簇”和“表面”可用。另请参见 刚性簇（clump） 绘图项的 形状 说明。

按…着色

参见 刚性簇（clump） 绘图项的说明。

颜色选项

参见 刚性簇（clump） 绘图项的说明。

显示

按刚性簇模板设置刚性簇显示的关闭/开启。

显示：这是可用刚性簇模板列表的容器。

[item]：在绘图中显示此项（勾选时）。

映射

参见 刚性簇（clump） 绘图项的说明。

透明度

参见 刚性簇（clump） 绘图项的说明。

图例

参见 刚性簇（clump） 绘图项的说明。
