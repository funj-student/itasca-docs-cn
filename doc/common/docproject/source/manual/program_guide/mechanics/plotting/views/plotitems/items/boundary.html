边界绘图项

说明

模型边界信息。

属性

分组（Groups） 槽位（Slot） 颜色列表（Color-List） 隐藏空单元（Hide-Null） 多边形（Polygons） 切割线（Cut-Line） 线（Line） 映射（Map） 变形系数（Def-fac） 透明度（Transparency） 图例（Legend）

分组

显示分组轮廓。

分组：指定项目显示应包含项目分组归属的区分（勾选时）。

槽位

指定用于分组显示的槽位。

槽位：选择槽位；若 分组 属性未勾选，则此设置无效。

颜色列表

设置用于项目颜色列表的线的属性。详情请参见标准的 颜色列表（color-list） 控件说明。

隐藏空单元

控制空单元的显示。

隐藏空单元：指定（勾选）空单元不应显示。该字段包含不同网格单元类型的列表。

[item]：隐藏类型为 [item] 的空单元（勾选时）。

隐藏空单元

控制绘图中空单元的显示。

隐藏空单元：指定（勾选）空单元不应显示。该字段包含不同网格单元类型的列表。

[项]：隐藏（勾选）[项]类型的空单元。

多边形

设置项目面片的属性。详情请参见标准的 多边形（polygons） 控件说明。

切割线

设置用于项目切线的线的属性。详情请参见标准的 切割线（cut-line） 控件说明。

线

设置用于项目轮廓的线的属性。详情请参见标准的 线（line） 控件说明。

映射

将该项映射到新的模型坐标。详情请参见标准的 映射（map） 控件说明。

变形系数

设置变形系数。详情请参见标准的 变形系数（def-fac） 控件说明。

透明度

设置绘图项的透明度。详情请参见标准的 透明度（transparency） 控件说明。

图例

设置绘图图例中该项目的标签。详情请参见标准的 图例（legend） 控件说明。

在 标题 下方，边界 绘图项还在 图例 中提供用于 颜色列表、计数、映射 和 变形系数 的控制项。
