绘图项

另见

有关绘图 命令，请参见 绘图（Plot），并参见 命令驱动的绘图工作流程（Command-Driven Plotting Workflow），以了解在数据文件或 FISH 文件中使用命令来构建和操作绘图的指导。

下表按字母顺序列出所有绘图项。单击项名称即可访问在用户界面中使用该绘图项的参考信息。

每种代码都提供了用于渲染其特定模型对象的特定概念方法；详情请参阅 可视化 PFC 模型对象（Visualizing PFC Model Objects） 和 可视化 FLAC3D 模型对象（Visualizing FLAC3D Model Objects） 两个主题。

绘图项索引

名称 说明 用于
连接条件（Attach Conditions） 当前连接条件的摘要。 FLAC3D
坐标轴（Axes） 指示绘图当前方向的参考坐标轴。 通用
球体（Ball） 按属性或特性着色的球体。 PFC
CFD 球体（Ball CFD） 按属性或特性着色的 CFD 球体（仅 PFC3D）。 PFC
球体热学（Ball Thermal） 按属性或特性着色的热学球体。 PFC
梁（Beam） 按标签或数值显示的梁信息 FLAC3D
边界（Boundary） 模型边界信息 FLAC3D
锚索（Cable） 按标签或数值显示的锚索信息 FLAC3D
刚性簇（Clump） 按属性或特性着色的刚性簇。 PFC
CFD 刚性簇（Clump CFD） 按属性或特性着色的 CFD 刚性簇（仅 PFC3D）。 PFC
刚性簇模板（Clump Template） 按属性或特性着色的刚性簇模板。 PFC
刚性簇热学（Clump Thermal） 按属性或特性着色的热学刚性簇。 PFC
接触（Contact） 按属性或特性着色的接触。 PFC
接触热学（Contact Thermal） 按属性或特性着色的热学接触。 PFC
DFN 裂隙等值线（DFN Fracture Contour） 在 DFN 裂隙上绘制力学接触数据的等值线。 PFC
域（Domain） 域几何。 PFC
单元 CFD（Element CFD） 按属性或特性着色的 CFD 单元（仅 PFC3D）。 PFC
面（Face） 网格单元面（全部） FLAC3D
安全系数（Factor of Safety） 在绘图图例中显示最近一次计算的安全系数 FLAC3D
裂隙（Fracture） 按属性或特性着色的裂隙。 通用
裂隙交线（Fracture Intersections） 按属性或特性着色的裂隙交线。 通用
裂隙玫瑰图（Fracture Rosette） 裂隙玫瑰图图表。 通用
裂隙赤平投影网（Fracture Stereonet） 赤平投影网的极点方向。 通用
土工格栅（Geogrid） 按标签或数值显示的土工格栅信息 FLAC3D
几何（Geometry） DXF、STL、GEOM 或其他几何数据。 通用
网格点固定（Gp Fixity） 网格点固定条件，按已固定的方向渲染为线 FLAC3D
历史图表（History Chart） 二维图表，用于显示模型执行期间记录的一个或多个历史。 通用
历史位置（History Locations） 当前正在采集的历史的位置——前提是该历史具有关联的位置。 通用
接触面（Interface） 接触面的位置、数值或标签信息 FLAC3D
等值面（IsoSurface） 以等值面显示的网格单元数值数据 FLAC3D
标签（Labels） 使用 设置历史标签（label） 命令创建的一个或多个用户自定义标签。 通用
衬砌（Liner） 按标签或数值显示的衬砌信息 FLAC3D
测量（Measure） 绘制按属性着色的测量区域。 PFC
桩（Pile） 按标签或数值显示的桩信息 FLAC3D
颗粒轨迹（Particle Trace） 被追踪颗粒所经过的路径；还可以按其速度大小对路径绘制等值线。 通用
剖面（Profile） 沿空间中定义的一条线绘制网格属性的图表 FLAC3D
刚性块体（Rigid Block） 按属性或特性着色的刚性块体。 PFC
刚性块体模板（Rigid Block Template） 按属性或特性着色的刚性块体模板 PFC
标量（Scalars） 用户定义的标量数据。 通用
比例框（ScaleBox） 用于帮助显示模型范围和比例的框。 通用
壳（Shell） 按标签或数值显示的壳信息 FLAC3D
数据表图表（Table Chart） 一个或多个数据表的二维图表。 通用
张量（Tensors） 用户定义的张量数据。 通用
张量（网格单元）（Tensors (Zone)） 应力或应变的网格单元张量数据 FLAC3D
追踪颗粒（Tracked Particles） 释放到流体流场中的颗粒的路径 FLAC3D
矢量（Vectors） 用户定义的矢量数据。 通用
矢量（结构单元）（Vectors (Structural Elements)） 所选结构单元类型的矢量数据 FLAC3D
矢量（网格单元）（Vectors (Zone)） 所选数值的网格单元矢量 FLAC3D
墙（Wall） 按属性或特性着色的墙。 PFC
墙热学（Wall Thermal） 对应于热学墙矢量属性或特性的箭头。 PFC
地下水位（Water Table） 用于计算孔隙压力的地下水位位置 FLAC3D
网格单元（Zone） 按标签或数值显示的网格单元信息 FLAC3D
网格单元分组曲面（Zone Group Surfaces） 按分组的网格单元曲面 FLAC3D
