信息控件组

信息控件组报告有关光标在活动窗格中当前位置的只读数据（活动窗格可以是 绘图 窗格，也可以是 模型、拉伸 或 基本块 窗格——后三者专属于 FLAC3D）。当光标不在模型对象上时，控件组中不显示任何信息。

此控件组中报告的这类信息也可以通过查询鼠标模式（mouse mode）获取。

控件组中显示的信息是动态的，会随鼠标位置变化而变化。所显示的数据字段将根据光标当前所在模型对象的类型而改变。
