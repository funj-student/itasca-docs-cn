Python

程序随附一套专为与 Itasca 软件配合使用而配置的 Python 3.6 发行版。与 FISH 不同（FISH 旨在与 Itasca 程序集成并互操作，因而可以与从 控制台（console） 运行的程序命令互换处理），Python 需要一组与 PFC 模型对象绑定的接口，才能使 Python 编程可以使用这些对象，并且需要一个用于执行 Python 命令/程序的 shell。

有关 FISH 和 Python 的更多介绍，请参见 脚本编写（Scripting） 主页面。两种脚本语言各有优点和长处，脚本编写主页上的说明（note）对此进行了有益的对比。

熟悉 Python 并希望直接学习如何将其融入模型的用户，可能更愿意从 Python 简介（Python Introduction） 开始。
