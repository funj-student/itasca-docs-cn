选项对话框

选项对话框是控制程序大量用户指定设置的地方。该对话框按功能逻辑区域分节。每一节及其中的控件都在各自的主题中介绍。

这些页面包括：

  • 常规选项（General Options）
  • FISH 选项（FISH Options）
  • 电子邮件选项（Email Options）
  • 启动选项（Start-up Options）
  • 编辑器选项（Editor Options）
  • 绘图选项（Plots Options）
  • 动画选项（Movie Options）
  • 控制台选项（Console Options）
  • 列表输出选项（Listings Options）
  • 结果选项（Results Options）
