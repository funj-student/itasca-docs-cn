列表输出选项

分页
勾选后，发送到控制台的输出将分页，并可能创建 列表 窗格；否则，发送到控制台的输出不分页，也不会创建 列表 窗格。
将列表移至单独窗口
勾选且分页已开启时，超过一定行数（在下一个控件中指定）的控制台输出将被发送到 列表 窗格。未勾选时，所有控制台命令输出都显示在控制台中。
移动列表的最小行数
设置自动为该输出生成新窗格所需的列表输出最小行数（例如 列出网格单元数据（zone list））（参见上一个控件）。
修改字体（按钮）
调用标准字体对话框，用户可在其中指定列表中所显示文本使用的字体、样式和大小。
文本颜色
此按钮调用颜色色板网格，用户可在其中指定列表中所显示文本使用的颜色。
背景颜色
此按钮调用颜色色板网格，用户可在其中指定列表背景使用的颜色。
