FISH 选项

命令解释器中的安全转换（需要 @）
勾选后，将作为命令行一部分传递给命令处理器的所有 FISH 变量都必须以特殊字符 @ 为前缀。该特殊字符可以明确地将这些变量标识为 FISH 符号。取消勾选时，这些特殊字符会被忽略。
自动创建全局符号
勾选后，如果在解析 FISH 函数时遇到未识别的名称，将自动创建一个全局符号。如果取消勾选，则必须使用 FISH 关键字 global 显式声明全局符号。
允许将整数转换为索引
勾选后，允许将 int 类型自动转换为索引。
