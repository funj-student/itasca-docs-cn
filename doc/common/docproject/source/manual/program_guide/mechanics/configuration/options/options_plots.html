绘图选项

默认视图设置

关于这些设置

这些控件为新创建的绘图设置默认值。通过 绘图项 控件组工具栏上的 视图设置 按钮（）也可访问相同的控件。不过，使用那些控件时，它们将局部应用于当前绘图，以根据需要覆盖此处设置的默认值。

活动
勾选后，每个绘图项在创建时即为活动状态；否则，每个绘图项在创建时为非活动状态。
自动更新
勾选后，绘图将按给定间隔自动更新（该间隔使用下方 全局设置 部分中的 更新间隔 控件指定）。若未勾选，则必须使用工具栏上可用的 重新生成当前绘图 工具手动更新绘图。
背景
使用指示色板上弹出的颜色选择器来指示/设置绘图的默认背景。
轮廓
指示/设置所显示（若勾选）绘图区域轮廓的颜色和大小，其中绘图区域是视图中不包括图例的矩形部分。
任务标题
指示/设置任务标题所显示文本（若勾选）的颜色、大小、字体和样式。显示时，任务标题出现在绘图区域顶部的带轮廓矩形中，其中绘图区域是视图中不包括图例的矩形部分。任务标题文本在 选项 对话框的 常规 部分中设置。
视图标题
指示/设置所显示视图标题（若勾选）的颜色、大小、字体、样式和文本。显示时，视图标题出现在绘图区域顶部的带轮廓矩形中，其中绘图区域是视图中不包括图例的矩形部分。如果任务标题也设置为显示，则视图标题将出现在任务标题下方。
目标
指示/设置是否在绘图中显示目标视图方框。无论视图窗口的宽高比如何，目标视图方框中的所有图形对象都将被渲染。
动画
勾选后，每个新视图都将成为输出动画的源，并使用指定的起始索引（用于命名后续的动画输出位图）。
图例
提供子控件，可用于配置图例的默认外观和位置，并指定图例中包括/不包括哪些项目项（时间、计算步、客户、标题、视图信息等）。

全局设置

这些设置始终应用于所有视图。此处所做的更改将影响所有绘图，无论之前或局部的设置如何。

顶点数组
指定/指示在 OpenGL 中绘制对象时是否使用顶点数组。默认开启。关闭此选项有时可改善较旧 OpenGL 显示驱动程序上的图像。请注意，关闭此项意味着顶点缓冲对象也随之关闭。
顶点缓冲对象
指定/指示是否使用顶点缓冲对象这一 OpenGL 扩展（若可用）。默认开启。对于报告存在该扩展但未正确支持它的驱动程序，关闭此选项可改善图像质量。
交互1
指示/设置高亮轮廓的颜色和粗细，该高亮轮廓用于勾勒绘图中出现、且在操纵鼠标模式激活时被选中的任何交互对象（绘图项、交互范围、图例等）。
交互2
指示/设置手柄点的颜色和粗细，这些手柄点出现在绘图中出现、且在操纵鼠标模式激活时被选中的任何交互对象（绘图项、交互范围、图例等）的高亮轮廓上。
拾取
激活/停用拾取，拾取允许与屏幕上所渲染的单元进行交互。由于拾取可能降低绘图渲染速度，在某些情况下关闭拾取是合适的。
草图模式
激活/停用草图模式，这是一种简化渲染方法，比完整渲染更快。包含极大量待渲染项目项的绘图在草图模式下可以更快地绘制和操作。
更新间隔
指示/设置视图重新生成的间隔（计算循环或计算步数）。请注意，无论更新间隔如何，视图总是在任何 执行计算时步（model cycle） 命令结束时重新生成。
打印尺寸
指定/指示发送到打印机的位图输出的默认尺寸（x 和 y 维，分别以像素为单位）。
DXF 警告
指定/指示将绘图导出为 DXF 文件时是否显示警告对话框；该警告提醒用户注意 DXF 导出功能的局限性。
动画
指定/指示动画帧捕获的间隔、位图帧的格式类型、位图大小，以及用于命名文件的文件名前缀（与索引编号配合使用）。请注意，这些设置是全局的，任何已标记为在计算循环期间生成动画位图的视图都将使用这些设置。
