常规选项

客户标题
此处输入的文本行将显示在所有绘图上，具体取决于本对话框 视图（Views） 部分中所设置的用户首选项。
任务标题
此处输入的文本可根据本对话框 视图（Views） 部分中设置的用户首选项，设为显示在所有绘图上。
回显输入
勾选后，将已输入的命令（通过命令提示符或通过数据文件输入）作为控制台输出的一部分包含在内。
日志输出
勾选后，开启将输出记录到文本文件的日志功能。用户可使用 … 按钮指定日志的名称及其位置。文件当前名称显示在复选框旁边（上图中的 “pfc3d.log”）。
撤销警告时限（秒）
若某撤销命令所需时间长于此处指定的秒数，则会弹出警告对话框。该对话框给出完成该撤销命令的预计时间，并让用户有机会取消该命令。
销毁按钮置于标题栏左侧
勾选后，程序中所有窗格的 关闭 按钮（）将出现在该窗格标题栏的左上角；默认情况下（未勾选），它们出现在右侧角上。
使用系统标题颜色
勾选后，PFC 中活动窗格的标题栏将使用计算机上的系统基础颜色。默认情况下，此设置未勾选，PFC 使用此行下方色板所示的颜色来渲染活动窗格的标题栏。用户也可更改这些色板上所选的颜色。
不显示程序更新通知
勾选后，当有可用的程序更新时，程序启动过程中不会出现 更新提醒 对话框。
默认使用确定性模式
勾选后，程序以 确定性 模式启动。更多信息请参阅相关主题。
历史步间隔
此处提供的值设置历史采样的步间隔。默认值为 10。该值应用于所有历史；不能为不同历史指定不同的历史间隔。
轨迹步间隔
此处提供的值设置颗粒轨迹采样的步间隔。默认值为 10。该值用于所有轨迹；不能为不同轨迹指定不同的轨迹间隔。
