启动选项

OpenGL 模式

使用选择器指定在程序中渲染加速 3D 图形时使用四种模式中的哪一种。

动态
选择此选项时，程序将根据程序启动时检测到的渲染能力自动选择 OpenGL 模式，并按优先顺序选择：1）本机桌面 2）ANGLE 3）软件模拟。尽管默认首选本机桌面模式，但如果程序在远程桌面协议下运行（即处于 Windows 远程桌面会话中），则会自动拒绝该模式。
本机桌面
此选项使用显卡驱动程序提供的 OpenGL 驱动。最低要求 OpenGL 版本 2.1 或更高。请注意，绘图窗口中的 3D 渲染要求 OpenGL 版本 3.3 或更高，因此如果可用的实现版本位于此范围内，则可能需要选择 ANGLE（见下一项）。另请注意，如果该软件程序在远程桌面协议（Windows 远程桌面）下运行，它将自动切换到动态模式。
角度（DirectX）
使用此选项时，渲染通过 OpenGL → DirectX 转换层（ANGLE）在 DirectX 中执行。
软件模拟
选择此选项时，将使用提供 OpenGL 模拟层的软件来执行渲染。此选项最不受推荐，因为它比其它选项明显更慢。
启动画面
勾选后，在启动时显示程序启动画面。
已抑制的通知
若勾选，所指示的通知在程序启动时不会显示在启动对话框中。

自动加载的插件

本构模型
若勾选，放置在 pluginscmodel 目录中的本构模型插件将在启动时自动加载。
节理模型
若勾选，放置在 pluginsjmodel 目录中的节理模型插件将在启动时自动加载。
接触模型
若勾选，放置在 pluginscontactmodelmechanical 目录中的接触模型插件将在启动时自动加载。
绘图项
若勾选，放置在 pluginsplotitem 目录中的绘图项插件将在启动时自动加载。绘图项插件可以为软件添加新的绘图项类型。这些插件目前不提供独立开发。
模块
若勾选，放置在 pluginsmodule 目录中的模块插件将在启动时自动加载。模块插件为软件引擎增加新的能力。这些插件目前不提供独立开发。
