生成动画帧

此对话框有助于生成一系列动画帧，以展示模型运行过程中绘图状态的演变。

当运行包含绘图的模型时，可以在特定时点创建保存文件或结果文件。模型完成后，打开此对话框并选择要据以生成动画帧的保存文件或结果文件。您可以选择为哪些绘图生成帧。单击“生成”按钮后，保存文件/结果文件将被逐个加载，并为每个文件保存其绘图的图像。
