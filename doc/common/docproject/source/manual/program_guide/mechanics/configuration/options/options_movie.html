动画选项

关于动画设置

程序中的任何已打开绘图都可用于生成动画的源文件（动画输出位图）。本节提供当前所有可用绘图的一站式列表（例如左侧图像显示了程序中当前打开的五个绘图，它们可被制作成动画）。每个单独的绘图在其视图设置中都有“动画”设置（使用 绘图项 控件组上的 视图设置 按钮（）可访问这些设置），该设置也可设置。请注意，此 动画 组的前五个设置是全局设置；对这些值中任何一个的更改都将应用于所有设置为生成动画输出的绘图。

动画间隔
设置每次捕获帧之前应经过的计算步数。
位图类型
设置捕获时要使用的位图文件格式。
图像尺寸 X（和 Y）
以像素为单位指定捕获图像的尺寸（x = 宽度；y = 高度）。
前缀
指定将添加到每个捕获文件文件名前面的字符串。
显示
列出所有可用绘图。通过各自的复选框选择要制作成动画的单个绘图；索引 字段用于指定捕获帧文件编号的起始点。所有捕获的位图文件都放在当前项目目录中。
