编辑器选项

字体和大小
选择编辑器中使用的字体和文本大小。
默认背景和错误指示
指定编辑器的背景色以及用于高亮代码中错误的颜色。
语法设置
使用选择框选择要设置格式的 语法类型。选定后，使用颜色色板设置该语法类型显示的前景色和背景色，并使用 粗体、斜体 和 下划线 复选框进一步按要求设置文本格式。
制表符大小
设置制表符的大小（以空格字符数计）。
编辑新文件页眉
调用一个对话框，用于指定在创建的每个新文件顶部自动插入的文本。
显示行号（及以下各项）
有关本项及随后四个“可勾选”选项，请参见 本地选项（Local Options） 主题。每种情况下，勾选即“开启”相应选项。
剪切或复制光标所在行
勾选此框后，按键命令 Ctrl + C 将复制光标所在的整行，Ctrl + X 将剪切整行。
菜单命令
选择框中可用的 编辑器 窗格命令可以使用其下方显示的 快捷键 控件分配新的快捷键。
在“替换”对话框中…
勾选此项后，如果在调用 替换 对话框时高亮文本部分包含反斜杠（\），则该对话框的“替换为”字段将自动填入一个建议的替换内容，将反斜杠改为正斜杠。
应用按钮
按 应用 将实施已做出的任何选项更改，而不退出对话框。
帮助按钮
按 帮助 按钮将打开 PFC 帮助 文件并定位到本主题。
