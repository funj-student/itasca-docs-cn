控制台选项

行数
指定控制台输出中要存储的行数。一旦输出超过该行数，多余的行将按先进先出原则被“丢弃”。
换行
指定控制台中的文本输出应采用以下哪种方式：“换行”（由控制台窗格的当前宽度决定）；“不换行”（此时提供水平滚动条，便于查看超出 控制台窗格 末端的文本）；或“固定列宽”（此时相邻输入框被激活，允许用户指定固定列宽）。
信息消息
勾选后，归类为“信息”类型的输出消息将包含在控制台输出中。
警告消息
勾选后，归类为“警告”类型的输出消息将包含在控制台输出中。
警告时弹出对话框
勾选后，出现警告消息时将显示 警告列表（List of Warnings） 对话框。
警告级别
设置将调用 警告列表（List of Warnings） 对话框的警告级别，范围为 0（最紧急）到 8（最不紧急）。
错误时弹出对话框
每当程序中发生错误状况时，控制台中会显示一条错误消息。如果勾选此框，错误消息还会显示在主程序窗口中央的对话框中。
背景
显示/设置控制台的背景。单击时，颜色指示器会弹出色板菜单，可从中选择新颜色。所选颜色显示在下方的 示例输出 框中。
输出类型
此选择器与其下方的控件配合使用，用于设置选择器所指示输出类型（“常规”“信息”“警告”和“错误”）的字体、字体外观（样式、大小等）和字体颜色。请注意，字体 按钮左侧的标签与选择器中设置的输出类型一致。
[标签] 字体
使用 字体 按钮调用标准的 字体 对话框以指定字体属性（字体、样式、大小等），并使用相邻的颜色选择器调出色板菜单以指定颜色。受影响的控制台文本类型由上方的 输出类型 选择器指定，并由本控件的 [标签] 部分指示。所做的设置显示在下方的 示例输出 框中。
示例输出
预览使用上方控件所做的设置。此区域为只读预览区域，不能用于提供配置设置。
