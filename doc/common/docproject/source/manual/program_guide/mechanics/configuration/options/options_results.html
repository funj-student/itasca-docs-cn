结果选项

配置设置

自动导出
勾选后，设置为在计算循环期间创建结果文件。结果文件导出没有“手动”方法；不勾选此框即“关闭”结果文件的创建。
间隔
指定结果文件将按何种间隔创建，该间隔可由以下方式控制：时间步、模型时间或时钟时间。
计算步/时间/时钟
此设置的标签将反映在上一个设置中所选的选项。该设置用于指示两次创建结果文件之间应经过的计算步数、模型时间量或时钟时间量。
前缀
设置将用于结果文件文件名开头的文本。若省略，默认文本将与所用的软件代码相对应（对于 FLAC3D，前缀 = “flac3d”；对于 PFC2D，前缀 = “pfc2d”，依此类推）。文件保存到包含当前工作目录的文件夹中（除非用户通过命令明确更改，否则这将是包含当前 项目文件（project file） 的文件夹）。
索引
指定追加到前缀后面的编号，用于对结果文件排序。默认值为“1”，这将在生成的第一个文件的名称中添加“0001”。下一个文件将使用“2”和“0002”，依此类推。

内容设置

页面下半部分列出可添加到结果文件的对象数据。此处显示的名录将与当前使用的程序相对应（例如，若使用 PFC，则只有在加载了 FLAC3D 时，与 FLAC3D 相关的数据对象（网格单元、结构单元）才会显示在该对话框中）。

执行

按下 确定 或 应用 后，将发出命令以反映对话框中的设置。例如，以下命令就是上图中所示设置所产生的结果。

model results interval active true
model results interval clock 5 minutes
model results prefix "tunnel_project"
history results active on
fish results active on
struct results active off

每个软件代码对此对话框都有默认设置。对于 FLAC3D，首次使用时“结构”和“网格单元”对象处于勾选状态。上图中的状态表明：用户勾选了“历史”和“FISH”，取消了“结构”的勾选，并让“网格单元”保持其初始（勾选）状态。因此，上面发出并显示的命令反映了两次添加（history 和 fish）、一次移除（struct），而对 zone 没有出现任何方向的声明，因为它默认就是 active 的。

警告

从此对话框发出命令后，这些设置即成为 模型状态（model state） 的一部分。当使用 新建模型（model new） 命令时，这些设置将被清除。如果在从数据文件运行项目之前尝试使用此对话框，就应牢记这一点：任何数据文件调用栈中下游的任何 新建模型（model new） 都将实际上抹去此对话框的初始设置，并使结果文件的创建失效。
