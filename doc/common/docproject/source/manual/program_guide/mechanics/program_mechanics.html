软件操作

本节介绍构建和运行数值建模项目所需的主要操作，具体如下。

命令
命令的基础知识、i 控制台（Console） 窗格，以及作为操作程序基础的命令讨论（discussion）。
项目
项目的定义和说明、i 项目（Project） 窗格、项目项管理、打包文件，以及 FISH 全局符号控件组。
数据文件
数据文件的说明、对数据（以及 FISH 和其他文本）文件的基本操作、i 编辑器（Editor） 窗格。
其他输入
对建模项目中可用于生成模型对象（DFN、几何等）的其他输入文件的概述，并包含相关文件格式的说明和/或规范。
列表
列出模型信息的简要介绍，以及 i 列表（Listing） 窗格的概述。
绘图
对 i 绘图（Plot） 窗格中模型处理与可视化核心内容的全面参考，并包含可用的大量工具的使用信息。
求解
对程序中计算循环/求解过程的说明，以及程序在计算循环期间报告的内容和此时可执行操作的概述。
保存
对正确设计项目保存顺序所起关键作用的概述，以及对 i 状态记录（State Record） 窗格所提供实用功能的说明。
Python
对于使用 Python 的用户，i IPython窗格（iPython） 窗格提供对 iPython 控制台的程序内部访问，该控制台是一个用于……的工具。

用户界面的大部分内容都已在上面的主题领域中说明和列举。其后还紧跟一个额外的主题领域，用于描述程序的一般方面。

程序布局与配置（Program Layout & Configuration）
窗口与窗格的布局、尺寸调整等，以及用户首选项和选项（Options）对话框。

界面中为程序特定功能提供操作能力的窗格（例如 FLAC3D 中的 i 构建块（Building Blocks）、i 拉伸（Extrusion） 或 i 模型（Model） 窗格）的用法，在介绍这些窗格中所创建命令的文档处进行说明。
