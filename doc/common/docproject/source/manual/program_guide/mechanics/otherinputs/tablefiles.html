数据表文件

数据表逻辑（table logic）支持数据表的创建和操作，数据表是浮点数对的索引数组。

c 表格插值取值（table） 命令中包含一个 导入表格数据（table import） 命令，它允许从符合既定数据表格式（table format）的现有数据表数据中纳入数据表。
