其他输入

数据文件和 FISH 文件是程序的主要输入，构成建模项目中的核心操作。不过，项目中还可以包含若干由文件描述的其他输入。它们服务于多种目的。

  • 几何
  • 离散裂隙网络（DFN）
  • 用户数据（标签、标量、矢量、张量）
  • 数据表
  • 绘图
  • 网格（仅 FLAC3D）
  • 基本块集（仅 FLAC3D）
  • 拉伸集（仅 FLAC3D）
  • 刚性簇模板（仅 PFC）
  • 砖块模板（仅 PFC）
  • CFD 网格（仅 PFC）

这些输入大多不像数据文件那样放在专用的窗格（pane）中。在某些情况下，项目系统会跟踪文件来源；但在大多数情况下，数据只是成为模型的一部分。对各种输入的绘图、复用、导出及其他操作因类型而异。它们所起的作用包括：增强模型可视化；分组；对象构建；辅助对象构建；作为对象构建的模板；作为可由对象数据访问或与对象数据配合使用的数据，等等。
