Itasca 几何文件格式

以下格式规范采用 Itasca 给出的定义——它相对于其他格式的特别优势在于能够使用/存储分组名称和额外变量信息。该格式可以文本或二进制形式指定。下面分别给出两种形式。

格式

文本格式

ITASCA GEOMETRY3D
; 上一行是文本模式文件头标识，
; 必须存在，才能将该文件识别为标量数据文本文件。
; 注释字段，分号后的任何文字均被忽略。空行
; 也被忽略。
; 下列首个
; 所有数据均以逗号和空格分隔。
GROUP s name  ; 后续所有对象都被赋予分组名称 name，归入
             ; 槽位 s。
             ; GROUP 语句也可在文件后续位置添加，
             ; 用于追加或替换先前的 GROUP 赋值。
EXTRA i val    ; 后续所有对象都被赋予附加数据 val，存于第 i 个
             ; 索引位置。
             ; EXTRA 语句也可在文件后续位置
             ; 添加，用于追加或替换先前的 EXTRA
             ; 赋值。
NODES  ; 后续各行视为节点。注意，所有 ID 都仅在本文件
       ; 内部有效，不一定与程序所分配的 ID
       ; 编号相对应。
           ; 还应注意，GROUP 和 EXTRA 语句可插入
           ; 节点列表中。
id x y z EXTRA i val  ... GROUP s name  ...
id x y z EXTRA i val  ... GROUP s name  ...
id x y z EXTRA i val  ... GROUP s name  ...
; 每行表示一个节点。ID 编号不必连续，但在同一个文件中，
; 对于每种对象类型必须唯一。EXTRA 和 GROUP
; 关键字为可选项。
; 每个 EXTRA 和 GROUP 关键字（每行可有多个）后面都可以
; 后面可接任意数量的索引和值配对，指明数值应赋予的
; 槽位索引。
; 分组名称为字符串，包含空格时用双引号括起。
; EXTRA 数据可以是字符串、整数或实数。
EDGES ; 后续各行视为边
id node1 node2 EXTRA i val  ... GROUP s name ...
id node1 node2 EXTRA i val ... GROUP s name ...
id POINT x y z x y z EXTRA i val  ... GROUP s name ...
POLYS  ; 后续各行视为多边形，其定义
  formats are available:
id edge1 edge2 edge3 ... EXTRA i val  ...
  GROUP s name ...
id edge1 edge2 edge3  ... EXTRA i val ...
  GROUP s name ...
id NODE node1 node2 node3  ... EXTRA i val  ...
  GROUP s name  ...
id NODE node1 node2 node3  ... EXTRA i val  ...
  GROUP s name  ...
id POINT x y z  x y z  x y z ... EXTRA i val  ...
  GROUP s name  ...
id POINT x y z  x y z  x y z ... EXTRA i val  ...
  GROUP s name  ...
; 注意，采用 NODE 格式时，无需指定
; 边
; 采用 POINT 格式时，无需指定边或
; 节点。

二进制格式

0x03714714 (unsigned 32 bit integer indicating it is binary geometry data)
; 重复对象
quint8 code indicating type of object (0=node, 1=edge, 2=polygon).
Node: uint64 as id
    x y z as double precision
uint32 as number of extra, followed by that many extra
uint32 as number of group names, followed by that many strings
Edge: uint64 as id
uint64 as node 1 id
uint64 as node 2 id
uint32 as number of extra, followed by that many extra
uint32 as number of group names, followed by that many strings
Poly: uint64 as id
     series of uint64 as edge id, with a value of 0 indicating no more edges
     uint32 as number of extra, followed by that many extra
uint32 as number of group names, followed by that many strings
extra: uint8 as type code (0= 64 bit signed int, 1 = 64 bit double
  precision, 2 = string).
string: uint16 as string length, that many uint16 as string contents.
