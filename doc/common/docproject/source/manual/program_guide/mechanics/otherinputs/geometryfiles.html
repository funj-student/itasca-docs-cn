几何文件

在程序内部，几何（geometry） 系统允许用户创建、导入和导出几何数据。

用途

在各类辅助输入中，几何数据的应用范围大概是最广的。它们可用于：

  • 便于模型可视化，
  • 构建模型范围和/或绘图范围，
  • 作为构建拉伸体或基本块（在 FLAC3D 中）的“跟踪”参考，或
  • 描述一个拓扑表面，并据此通过拉伸构建一组网格单元。

可以为几何数据指定 FISH 额外变量和分组名称。FISH 可用于创建和操作几何数据。几何数据组织为几何集，几何集是节点、边和多边形的命名集合。

几何对象在创建时不需要域，因为它们不是模型组件。

纳入模型

几何数据可以通过多种方式引入模型：

  • 在命令中（参见 导入几何对象（geometry import） 命令）；
  • 使用 c 文件 —> 打开（File —> Open） 对话框；或，
  • 在绘图项中（参见 几何（geometry） 绘图项的“集合（Sets）”属性）。

注意

通过 导入几何对象（geometry import） 命令或 File —> Open 对话框引入程序的几何数据可供 几何（geometry） 绘图项使用；然而，为可视化目的而添加到 几何（geometry） 绘图项的几何集随后并不能被命令访问——它在任何意义上都不是模型的“一部分”，而只是添加它的那个绘图中的一个可视对象。

格式

程序支持以绘图交换（DXF）、立体光刻（STL）或 Itasca 几何（Itasca geometry）（GEOM）格式纳入几何数据。

操作

程序提供了大量 c 几何（geometry） 命令和 FISH 函数（functions）用于处理导入的几何数据（注意，也可以使用命令来创建几何集）。
