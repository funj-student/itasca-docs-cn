网格文件

网格文件仅在 FLAC3D 中使用，用于从一个输入文件一次性构建网格单元。

纳入模型

将网格文件纳入模型有三种主要方法。

  • 使用 导入网格（zone import） 命令
  • 通过 c 文件 —> 打开（File —> Open） 对话框
  • 通过 File —> Grid▸ 菜单命令

注意

在 PFC 中工作时，只有在加载 FLAC3D 后（Tools —> Load FLAC3D），这些方法才可用。

格式

程序支持从 itasca（.f3grid）、ansys（.lis）或 abaqus（.inp）格式导入网格。Itasca 网格（Itasca grid）格式能够存储分组信息。
