DFN 文件

离散裂隙网络（DFN）作为模型中的对象，在 离散裂隙网络（DFN）（Discrete Fracture Network (DFN)） 主题中有详细说明。

纳入模型

DFN 可以使用 c 裂隙（fracture） 命令创建，也可以使用 导入裂隙（fracture import） 命令导入，该命令接受文件或几何作为在模型中创建新 DFN 的基础。

格式

程序支持从 itasca、fishlab 或 fracman 格式导入 DFN。默认使用 itasca 格式，该格式在 DFN 相关文件格式（DFN-Related File Formats） 中描述。
