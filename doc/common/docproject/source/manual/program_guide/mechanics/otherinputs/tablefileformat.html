数据表文件格式

数据表是浮点数对的索引数组（为方便起见记为 \(x\) 和 \(y\)）。每个数据表条目（或 (\(x,y\)) 对）也带有索引（范围 [1, 2, … , \(N\)] 内的整数，其中 \(N\) 是数据表中的项数）。

每个数据表都有唯一的 ID 编号。此外，每个数据表还有一个表示数据表名称的字符串标签，对于大多数用于操作数据表的命令，可以用该标签代替数据表 ID。

数据表文件的第一行保留给数据表名称。第二行用于标识数据表上的点数以及点之间的 \(x\) 间隔。最常见的情况是将其设为 0.0，此时第三行及后续各行应包含 (\(x,y\)) 对。但是，如果提供非零值，则只提供一列 \(y\) 值，其中第一个条目（第 3 行）的 \(x\) 值假定为 0，后续每个 \(x\) 值都会将 \(x\) 间隔的值加到前一个 \(x\) 值上。
