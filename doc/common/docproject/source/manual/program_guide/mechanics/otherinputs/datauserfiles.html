数据文件（标签、标量、张量、矢量）

用户可以输入自定义的标签、标量、矢量和张量数据，并将其与模型结果进行比较。这些数据还可以用于存储由模型计算得出的数据以供可视化。

当从文件创建时，数据可以采用文本或二进制格式，但每种数据类型都有如下定义的特定文件格式。用户数据创建后，可通过 FISH 进行查询或变换，并可在当前模型的绘图中可视化，因为每种数据类型都有关联的绘图项（参见 c 标签项（labels）、c 标量项（scalars）、c 张量项（tensors） 和 c 矢量项（vectors） 绘图项）。
