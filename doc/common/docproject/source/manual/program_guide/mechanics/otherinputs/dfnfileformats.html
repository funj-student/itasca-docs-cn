DFN 相关文件格式

自举分布文件格式

1 行标题行

x 行用于定义离散分布。每行包含一个 ID，随后是该分布的 n 个值（1D 分布为 1 个值，2D 分布为 2 个值，依此类推）。最后一列是可选的，用于定义这些值所对应的数量。如果未给出，则所有值具有相同的概率。分隔符可以是空格、制表符、逗号或分号。

文件结尾由任意空行表示。

示例：

; 裂隙方位的自助重采样分布：id dip dipdir quant
1;242;87;43.33;2
2;241;84;51.94;2
3;84;64;22.01;2
4;153;84;25.99;1
5;151;82;27.91;1
6;158;75;37.95;1
7;150;83;27.41;1
8;166;82;24.43;1
9;77;83;37.22;2
10;182;87;19.41;1
11;138;81;39.22;3
12;45;4;11.42;4

裂隙模板文件格式

1 行标题行

以 <info> 开头并以 <info> 结尾的分组，用于定义模板信息。每个 info 都按 info_name info_value 的格式写成单独一行。

以 <stats> 开头并以 <stats> 结尾的分组，用于定义统计分布。该分组必须包含 <size> … <size> 分组、<orientation> … <orientation> 分组和 <position> … <position> 分组。对于每个分布，参数按 param_name param_values 的格式给出（每行一个）。这些参数包括：

  • 分布的维度，由 dim 定义（例如 dim 1）
  • 分布的类型，由 type 定义（例如 type 1）。1 表示均匀分布，2 表示高斯分布，3 表示幂律分布，4 表示自举分布，5 表示 FISH 函数。
  • 分布的参数，由 parameters 定义，需与类型一致（例如对于高斯分布为 parameters 1.0 0.5）
  • 可接受值的范围，由 bound 定义（例如对于 1D 方向为 bounds 20 50）

示例：

;ITASCA DFN Template File
<info>
name example
<\info>
<stats>
      <size>
            dim 1
            type 2
            parameters 4.0
            bounds 1.0 +inf
      <\size>
      <orientation>
            dim 2
            type 1
            parameters
            bounds 0 0 180 360
      <\orientation>
      <position>
            dim 3
            type 1
            parameters
            bounds -5 -5 -5 5 5 5
      <\position>
<\stats>

Itasca 文件格式

文件头

  • 1 行标题行（注释）
  • 1 行，给出裂隙数量

裂隙列表

  • 每条裂隙由第一行定义，该行包含三个数字：裂隙编号、特性编号（与特性文件相关联）以及顶点数量。
  • 裂隙定义的其余部分形式各异，取决于所给的顶点数量以及维数。
  • 在 3D 中，顶点数可以为 1，此时裂隙为圆盘形。在这种情况下，第二行包含位置、倾角（以度为单位）、倾向（以度为单位）和裂隙直径，
  • 否则，裂隙顶点将在后续各行中输入，其中顶点之后的最后一行列出倾角和倾向，或者，
  • 在 2D 中，顶点数只能为 2，随后的两行即为顶点位置。

裂隙特性文件格式

1 行标题行

1 行，包含各特性的字符串名称

1 行，给出特性数量

x 行，以空格分隔的列表形式给出特性

示例：

;ITASCA DFN Property File 
jks jkn jcohesion 
2
5.0000000000e+09 5.0000000000e+10 5.0000000000e+01 
1.0000000000e+09 1.0000000000e+10 2.0000000000e+01
