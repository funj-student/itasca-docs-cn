求解

一系列计算循环（cycles）最常通过 求解模型（model solve） 命令执行。[1]该命令允许循环持续进行，直到满足一个或多个求解限制。也可以指定 执行计算时步（model cycle），仅执行指定数量的计算循环。

这两条命令中的任何一条都必须从程序中的两个位置之一发出：i 控制台（Console） 窗格中，或在数据文件内。

开始循环计算

要开始循环计算：

  • 在包含要运行的 求解模型（model solve） 或 执行计算时步（model cycle） 命令的数据文件所在的活动编辑器窗格工具栏上，按执行按钮（），或者
  • 在 i 控制台（Console） 窗格中的 命令提示符（command prompt） 处输入 求解模型（model solve） 或 执行计算时步（model cycle） 命令。

循环计算期间

模型循环计算期间，可以进行非命令处理操作（绘图、编辑数据文件、使用某些工具等）。但无法在 控制台 中发出命令，也无法执行发出命令的操作（例如，在 FLAC3D 的 拉伸 窗格中构建拉伸）。

在循环计算期间，程序将在三个特定位置发出有关程序状态和循环计算结果的信息：

  • 控制台 窗格，它回显输入命令并在处理命令时显示其输出
  • i 计算循环（Cycling） 对话框，以及
  • （如有需要）警告（warnings） 对话框。

i 计算循环（Cycling） 对话框在循环计算时始终存在；警告（warnings） 对话框则在出现需要时显示（即，在命令处理期间发出了错误或警告时）。两者都在单独的主题中说明。

停止循环计算

要停止循环计算：

  • 按工具栏上的停止按钮（）。在循环计算期间，程序中的每个窗格工具栏上都可以使用该按钮。
  • 按 i 计算循环（Cycling） 对话框中的 中断 按钮。
  • 按一次 Shift + Esc 键，请求在当前计算循环结束时停止循环计算（这允许在循环计算停止后按需保存模型状态数据），或者
  • 按两次 Shift + Esc 键以立即停止循环计算——这将导致当前计算循环的数据丢失。

尾注

[1]“求解”和“循环计算”这两个术语只能部分互换，因为使用这两个词的命令（求解模型（model solve） 和 执行计算时步（model cycle））有所不同。“求解”始终意味着循环计算到预先确定的终止点（求解限制）。“循环计算”则更为抽象。它要么进行给定的步数，要么在命令未给出数量时无限进行。因此，循环计算与“步进”更为近义（参见 时间步（Timestep））。因此，尽管求解在建模过程中通常更为核心，但在本文档中泛泛指代通过时间步进行迭代时，会更常遇到循环计算这一术语。
