打开打包文件

  1. 使用菜单序列 工具 → 打包 → 解包…。
  2. 使用随后出现的 文件打开 对话框打开所需的打包文件。
  3. 打开后，查看 打包报告（Bundle Report） 对话框中显示的信息。记下解包后可能需要处理的任何警告/错误。
  4. 要继续，请按 解包… 按钮。
  5. 使用 保存 对话框指定打包文件应解包到的位置。按 选择 完成该操作。

有关如何解读其中所报告结果的更多细节，请参见 打包报告（Bundle Report） 对话框的主题。
