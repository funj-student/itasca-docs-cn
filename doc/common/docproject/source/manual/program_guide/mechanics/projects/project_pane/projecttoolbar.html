项目窗格 工具栏

当 项目 窗格处于活动状态时，工具栏如下所示。


表 1：项目 窗格工具栏上可用的工具
图标 命令 说明/注释
执行/停止切换按钮 执行或停止计算循环；更多信息请参见“工具栏（Toolbar）”主题。
  在编辑器中打开 打开当前选定的输入（数据、FISH 等）文件。
关闭 关闭当前选定的输入（数据、FISH 等）文件。
调用 在编辑器窗格中打开当前选定的文件（如果尚未打开），并执行其中的命令。
恢复 激活当前选定的结果（SAV）文件。
从项目中移除 将选定文件从项目中移除，这将永久切断该文件与项目之间的连接。如果所选项目项当前在程序中打开，该命令还会将其关闭。
在 Windows 资源管理器中显示 在 Windows 资源管理器中显示（导航到）选定文件（注意，无论是否已有程序实例打开，这都会打开一个新的 Windows 资源管理器窗口）。
显示/隐藏 控制面板 切换 控制面板 的显示状态。
显示/隐藏控件组 此按钮是一个下拉按钮，列出此窗格类型可用的控件组。选择未勾选的条目可将其显示在控制面板中；选择已勾选的条目可将其隐藏。
