创建打包文件

  1. 使用菜单序列 工具 → 打包 → 打包…。
  2. 查看 打包报告 对话框中的信息。注意，打包报告提供有关将包含在打包文件中的文件的信息，以及创建该打包文件的程序的完整版本。报告还会给出警告（例如，将包含的文件存在未保存的修改）或错误（例如，项目中报告存在的文件无法找到）。总而言之，这些信息使用户能够完整预览打包操作及其预期结果。
  3. 要完成操作，请按 打包报告（Bundle Report）对话框中的 打包 按钮。
  4. 使用随后出现的 保存文件 对话框为打包文件命名并保存。
