与项目相关的键盘命令

下表汇总了 PFC 中可用的与项目和项目项相关的命令的按键命令。如果命令标签后出现省略号（…），表示使用该命令时会弹出一个对话框。所有这些命令都是全局命令。它们可从 PFC 中的任何窗格访问，而不仅限于 项目 窗格。


表 1：与项目相关的按键命令
按键 命令 说明/注释
Ctrl + O 打开项目项… 打开现有的项目项（调用 打开项目项…（Open Item…） 对话框）。
Ctrl + Shift + S 保存所有项目项… 保存所有打开的项目项（注意，这不会保存当前未在 PFC 中打开的项目项）。
Ctrl + S 保存 [项目项名称] 保存当前活动窗格中的项目项。
Ctrl + Alt + S 另存为 [项目项名称]… 将当前活动窗口/窗格中的项目项副本保存到新文件。
Ctrl + W 关闭 [项目项名称] 关闭当前活动窗口/窗格中的项目项。
Ctrl + P 打印 [项目项名称]… 打印当前活动窗口/窗格中的项目项。
Ctrl + 3 显示 项目 窗格 显示和/或激活 项目 窗格；此命令可在 窗格 菜单上使用。它不会隐藏该窗格；要隐藏它，请使用窗格标题栏中的 隐藏 按钮（）。
