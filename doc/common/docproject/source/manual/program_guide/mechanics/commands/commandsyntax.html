命令语法

程序中的所有命令都是由一个主词（名词/对象）和一个第一关键字（动词/动作）组成的词。在此基础之上，还可以附加选项和修饰词（副词）以及范围（介词短语）。换言之，命令在语法上模仿自然语言。

后几类成分（选项、修饰词和范围）在所有命令中的处理方式一致，而且通常是可选的。这些部分通常还需要用户提供的值才能补全。

该语法模式表示为

名词 - 动词 - 选项 - 修饰词 - 范围

请注意，该顺序在所有命令中都是一致且强制要求的。话虽如此，中间部分如果可选则可以省略（也就是说，在选项和修饰词成分可选的命令中——大多数命令都是如此——名词 - 动词 - 范围这一模式是有效的）。

语法模式示例

名词-动词

program quit
model new

这是最简单的命令模式。在这些行中，program 和 model 是名词成分；quit 和 new 是动词成分。第一条命令退出程序。第二条命令清除当前模型状态。参见 退出程序（program quit） 和 新建模型（model new）。

名词-动词-选项，带与不带 范围

名词-动词-修饰词，带与不带 范围

名词-动词-选项-修饰词，带与不带 范围

概括而言，一条命令至少总是包含一个名词和一个动词。视命令而定，这两者之后可以跟：零个、一个或多个选项；零个、一个或多个修饰词（用于改变命令的作用效果）；以及零个或一个范围（用于限制命令的作用效果）。
