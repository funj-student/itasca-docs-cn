在 控制台 窗格中输入命令

命令可直接在命令提示符处逐字键入。

在此处放置命令提示符的图像

输入之后，命令产生的输出（如有）显示在命令提示符上方的控制台区域中。

缩写

命令可以缩短为其前几个字母。在本文档中，命令签名中带下划线的字符（例如参见 列出网格单元数据（zone list））表示正确识别该命令所需键入的最少字符数。请注意，带连字符的命令既需要最少字符也需要连字符（例如，移除网格单元条件（zone apply-remove） 可以缩短为 z a-r）。

单行输入（包括注释）可以包含任意数量的字符。命令没有字符数限制（仅受计算机内存限制）。在数据文件中，只要使用续行符将多行文本连接成一条命令行，命令就可以写在多行文本上。不过，长命令难以阅读（也可能难以输入）。请参阅 命令书写方式（Command Shaping）。
