文档中的命令与 FISH 参考记号

在本文档中，每条命令和每个 FISH 函数都按若干约定呈现。命令或 FISH 函数中的选项用 < > 表示。关键字（命令）或参数（FISH）（可选或必需）后面跟省略号，表示其后可以跟任意数量的此类参数。省略号记法在命令中很常见，但在 FISH 中较为少见。另请注意，它与将省略号用作命令或 FISH 行的续行机制完全不同（参见“命令书写方式”主题中的 续行（Continuation））。

命令

命令“签名”会首先显示命令最基本的形式，随后是各可用关键字和其他选项。例如：

wall import keyword ... <范围（range）>

回顾几条命令（可尝试 导入墙体（wall import）、设置网格单元动力分析参数（zone dynamic）、新建模型（model new） 和 删除几何边（geometry edge delete）），以便快速熟悉本文档中命令的呈现方式。

在命令参考文档中，缩进用于表示关键字层级。许多命令都遵循 command keyword <range> 这一基本模式。然而，在第一关键字层级上，可能会发现本身还可接受关键字的选项。例如，从主命令缩进一级的位置可能会出现： l1keyword1 keyword ... 和 l1keyword2 <keyword>。按照该记法，第一级关键字 l1keyword1 接受任意数量的附加关键字，而第一级关键字 l1keyword2 接受一个可选关键字。这些子关键字的每个选项都会出现在其父关键字下方缩进一级的位置。

FISH

FISH 函数的“签名”会显示该函数所需的确切参数和返回值。函数可以是只读、只写或可读可写。例如：

（读取）v = domain.max(<i>)
（写入）domain.max(<i>) = v

该函数的记号（域上角点（domain.max））表明此函数可读/可写。第一行是读取版本，展示如何获取计算域上角点的矢量或分量（如果指定了 <i>），并将其存入矢量 v。第二行是写入版本，将计算域上角点的矢量或分量设置为 v 的值。读取（或获取）函数总是把赋值变量写在等号左侧。写入（或设置）函数总是把函数写在等号左侧。

在签名下方，FISH 参考页面会给出所有函数参数和返回值的类型与说明。

视觉参考

在命令和 FISH 中，各种类型的值均以类型名称的首字母表示。在大多数情况下，单个字母就足够了。当提供多个值时，它们往往会被编号（i1、i2、i3 等）。矢量通常用 v 表示，其维数（二维或三维）可由上下文明确。有时情况可能并非如此，此时就分别使用 v2 和 v3 来明确指定二维或三维矢量。正如数字的这种用法同样适用于矢量，当表示多个矢量时，会用字母加以区分（v_a、v_b 等，或 v2_a、v2_b 等）。
