命令书写方式

在基本命令语法中，提供了一些操作方式，以便于提高命令的可读性和/或输入便利性。

缩写

命令可以缩短为其前几个字母。在本文档中，命令签名中带下划线的字符（例如参见 列出网格单元数据（zone list））表示正确识别该命令所需键入的最少字符数。请注意，带连字符的命令既需要最少字符也需要连字符（例如，移除网格单元条件（zone apply-remove） 可以缩短为 z a-r）。

续行

命令的长度没有限制；单条命令在一行内可以包含任意数量的字符。不过，在实践中，最好用多行来拆分长命令。可以在输入行末尾给出与号（&）或省略号（...），以表示下一行是该行的续行。两者均有效且可以互换。请注意，空白字符会被忽略（见下文“分隔符”）。

zone create brick size 20 1 20 point 0 (3.0,0.0,0.0) ...
                               point 1 (20.0,0.0,0.0) &
                               point 3 (3.0,0.0,10.0) ...
                               ratio 1.08 1.0 0.97

值

许多关键字后面跟有一个值或一系列值，用于提供该关键字所需的输入（这些输入可以是数值、布尔值、字符串、矢量或其他输入，包括 FISH 函数的名称）。

对于数值输入，所需的实数值可以省略小数点，但整数值中不得出现小数点。

此外，关于命令在程序中以及在本文档中的呈现方式，还请分别参见 程序中命令与 FISH 的高亮显示（Command and FISH Highlighting in the Program） 和 文档中的命令与 FISH 参考记号（Command and FISH Reference Notation in the Documents） 主题。

分隔符

命令、关键字和数值之间可以用任意数量的空格分隔，也可以用以下任一分隔符分隔：

( ) , =

注释

可以用分号（ ; ）引出注释；输入行中分号之后的所有内容都会被忽略。在数据文件中加入注释很有用，并且强烈建议这样做。这样不仅以这种方式为输入提供了说明文档，而且注释还会回显到输出中，从而为分析的质量保证提供了机会。
