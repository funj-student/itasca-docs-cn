控制台窗格工具栏

当 控制台 窗格处于活动状态时，工具栏如下所示。

表 1：控制台窗格工具栏上可用的工具
图标 命令 说明/注释
执行/停止切换按钮 执行或停止计算循环；更多信息请参见“工具栏（Toolbar）”主题。
调用 打开一个对话框，用户可通过它选择要 调用数据文件（program call） 到 PFC 中的文件。
保存状态 打开一个对话框以保存模型状态（创建 SAV 文件），前提是此前尚未保存；如果此前已保存，则将当前模型状态保存到现有文件中。
另存为 如果当前模型状态与某个现有 SAV 文件相关联，则打开一个对话框，将当前模型状态保存到一个不同的新文件；否则其行为与“保存状态”完全相同。
恢复 打开一个现有的 SAV 文件，并将其设为当前模型状态。
选项 打开 选项 对话框的 控制台 部分。
命令帮助 打开 帮助，定位到命令行上当前命令的页面。
显示/隐藏 控制面板 切换 控制面板 的显示状态。
显示/隐藏控件组 此按钮是一个下拉菜单，列出该窗格类型可用的控件组；选择未勾选的项可在控制面板中显示它，选择已勾选的项可将其隐藏。
