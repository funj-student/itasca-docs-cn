命令

程序的核心是其命令。这一点无论怎么强调都不为过：这是命令驱动的软件。用户界面中可以执行的任何操作，最终都只是发出程序某条命令的一种方式——无论该操作是在模型的屏幕视图上进行的、通过菜单进行的、用鼠标单击工具栏进行的，还是通过任何其他类型的可视化交互输入操作进行的。然而，也应当记住，用户界面只向窗口化的程序空间暴露了命令集的一部分。要完整掌握该软件，至少必须对整个命令集有基本的熟悉。

控制台窗格

i 控制台（Console） 窗格（将在后续主题中介绍）是程序的核心。该窗格始终提供命令（以及 FISH 或 Python 脚本）处理产生的输出。它也可用于命令（以及 FISH 或 Python 脚本）的输入。在通常做法中，用户会向控制台输入内容，以执行简单操作、对模型进行“抽查”式查询，或者将其作为比程序菜单或工具栏更快速的替代方式。在完整规模的模型运行中，项目的大部分内容都将写入输入文件并从中处理——数据文件、FISH 或 Python 脚本文件以及其他输入文件。要处理这些文件，请参阅 编辑器窗格（The Editor Pane） 的讨论。

……位于何处？

本节仅将命令作为一个主题来介绍，并概括地说明在程序中使用命令的方法，尤其是在 控制台 窗格中的使用。关于所有通用命令、PFC 命令和 FLAC3D 命令的完整参考信息，以及关于 FISH 和 Python 脚本编写的全部信息，均在文档集的其他部分给出。

通用

  • 索引：通用命令（Index: Common Commands），用于所有 Itasca 软件共有的命令（c 调用命令（call）、c 恢复模型（restore）、c 几何（geometry）、c 裂隙（fracture）、c 模型（model）、c 程序（program）、c 表格插值取值（table） 等）
  • 索引：通用 FISH（Index: Common FISH），用于与通用命令关联的所有 FISH 函数。

PFC

  • 索引：PFC 命令（Index: PFC Commands），用于 PFC 命令（c 球体（ball）、c 墙体（wall）、c 颗粒簇（clump） 等）
  • 索引：PFC FISH 函数（Index: PFC FISH Functions），用于 PFC FISH 函数。

FLAC

  • FLAC3D 命令索引（FLAC3D Commands Index），用于 FLAC3D 命令（c 网格单元（zone）、c 结构单元（structure）、c 拉伸块体（extrude block） 等）
  • FLAC3D FISH 索引（FLAC3D FISH Index），用于所有 FLAC3D FISH 函数。

脚本编程

  • FISH 脚本参考（FISH Scripting Reference），用于 FISH 的一般参考；
  • FISH 函数（FISH Functions），用于直接内建于 FISH 语言的所有函数的索引（这些函数不属于通用命令所对应的函数集（见上文））。
  • Python 脚本编程（Python Scripting），用于 Itasca 软件中 Python 的一般参考。

注意

可以把控制台看作程序中“最古老”的部分。在最初版本中，Itasca 代码除了控制台窗口之外别无他物。这些代码本质上由命令驱动，其明证就是：即使在今天，程序已经为绘图、网格生成、项目管理等添加了许多功能和内置工具，仅凭 控制台 也仍然可以完成整个模型运行。
