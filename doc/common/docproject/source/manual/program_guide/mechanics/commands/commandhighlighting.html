程序中命令与 FISH 的高亮显示

在本文档中，作为示例或以缩进列表形式呈现的命令与 FISH 函数将与程序的默认语法高亮一致（假设使用的是默认设置——用户可以在 选项对话框（Options dialog） 中自定义语法高亮）。

当命令和 FISH 出现在参考章节、正文（无论是纯文本形式，还是最常见的情况——超链接形式）或其他位置时，其呈现方式会有所简化。命令词和关键字以黑色文本显示；随关键字或参数提供的值，无论其类型如何，都以蓝色文本显示。

举例来说，正文中像这样的引用——施加网格单元面条件（zone face apply）——是指向该命令参考信息的基本超链接。这种情况非常常见。同样地，“填写完整”的命令的内联示例也很常见，外观大致如下：zone face apply stress-xy 110.23 system dip-direction 47.4。

然而，如果将其偏移显示在正文之外，无论是作为简单的“片段”式示例（如此处），还是作为完整数据文件列表中的一行，它都会显示成如下样子：

zone face apply stress-xy 110.23 system dip-direction 47.4 ...
                                 range position-x 22.7 1.19e-1
表 1：程序及文档示例中命令与 FISH 语法高亮的可视化指南
字体样式/字符 用于
command 命令中的第一个词
keyword 命令关键字
fishword FISH 函数名或语句
fishvar FISH 变量
flt 或 int 浮点型或整型的数值
str 或 bool 字符串值或布尔值
comment 注释
stop stop、pause、return、quit（停止类词）
solve solve、cycle（执行类词）
& 或 … 续行字符
