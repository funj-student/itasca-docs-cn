命令及其理由

此时，已经学习过前面内容的用户应当对程序命令以及如何使用 控制台 窗格来发出命令有了良好的实际理解。然而，程序最初为什么要以这种方式利用命令来设计，可能还不完全清楚。以下讨论旨在阐明这一问题。

为什么采用命令驱动界面？

无论是通过交互方式还是手动方式生成，任何 FLAC3D 模型的基本描述都是一个数据文件。数据文件是一种标准文本文件，其中的命令完整地指定了一个 FLAC3D 模型，从模型创建到开展物理模拟所需的后续顺序操作都包含在内。

初次接触时，FLAC3D 使用数据文件来描述模型这一事实可能显得过时，或许是 1970 年代程序设计遗留下来的做法。恰恰相反，这种模型描述方式已被证明非常有价值，并被认为是使 FLAC3D 以及一般意义上的 Itasca 代码成为强大建模工具的一个不可或缺的组成部分。随着我们的用户界面设计日趋成熟，我们的目标不是移除命令驱动界面，而是简化其使用，使模拟更易于开展，同时保留该设计所体现的灵活性。

下面列出使用数据文件描述模型的几点优势。

  • 表示紧凑

    即使是最复杂的模型，也可以由一组通常不超过几百行的数据文件创建出来。事实上，绝大多数模型要小得多。这意味着，您的 FLAC3D 模型的完整描述保存在一个仅有几 KB 的文本文件中。因此，与他人共享模型、通过电子邮件将其发送给 Itasca 寻求支持、将模型归档以备将来参考，以及使用版本管理软件跟踪更改，都变得轻而易举。

  • 可重复性

    Itasca 竭力确保同一版本的代码和同一数据文件始终产生相同的结果，精确到机器精度。这意味着，当您把数据文件发送给 Itasca、同事或客户时，您可以确信结果将保持不变。因此，无需归档建模工作的完整结果（可能包含许多 GB 的保存文件和结果文件），只需保留数据文件及用于执行该文件的代码版本即可。

  • 历史与路径依赖性

    除了使用最简单材料的最简单模型之外，达到解所经过的 路径 是模型描述中非常重要的一部分。数据文件能够清晰而灵活地描述事件序列。许多程序可能提供开挖顺序选项，但数据文件允许在必要时构造 任意 事件序列。这包括边界条件的变化、材料特性的变化、流体相互作用的变化等，以及开挖顺序的变化。如果设计一个图形用户界面来包含通过数据文件可用的全部选项列表，其结果将十分复杂，需要使用笨拙的工具来编辑和修改。

  • 灵活性

    数据文件使用户在如何创建和处理模型方面拥有最大的灵活性，包括各项内容的指定顺序。虽然对于简单模型有一套推荐的模拟步骤标准顺序（例如，几何创建、区域命名、材料与特性指定、边界条件、初始条件、求解、开挖、求解等），但每个模型都不相同。复杂模型往往需要对标准模拟流程进行修改。Itasca 致力于不把用户局限于少量模拟选项，而是为用户提供以自己认为合适的方式开展物理模拟的能力和工具。

  • 脚本编程

    在 FLAC3D 中将模型创建命令与脚本结合起来的能力极其强大。例如，只需在数据文件中简单地更改一组初始参数，就可以研究一整类模型。复杂序列、几何形状、特性分布等的应用可以通过脚本实现自动化，这种方式在传统图形用户界面中会非常耗时且难以复现。此外，还可以通过用户在计算循环期间执行的脚本，引入深入的模型查询以及 FLAC3D 中未包含的新物理现象。

这种命令驱动界面的缺点在于，它可能让新用户望而生畏，这些用户可能觉得必须掌握大量复杂命令才能开展最简单的建模工作。实际上，与面对包含众多窗格、按钮繁多、工具林立的复杂图形用户界面（这是我们都经历过的）相比，学习曲线反而更快。这些命令有意采用描述性强且一致的术语来构造，因此阅读数据文件并理解其调用的操作变得很容易。此外，在 FLAC3D 内创建和编辑数据文件时，还可以使用交互式命令文档，这大大简化了过程。

为了使数据文件的创建和编辑尽可能简单，FLAC3D 包含以下功能：

  • 功能强大、支持语法高亮的内置编辑器（A powerful, built-in editor with syntax highlighting support）。
  • 更新的命令语法，使表达更清晰（Updated command syntax, leading to increased clarity）。
  • CTRL-SPACE 交互式内联帮助系统（CTRL-SPACE interactive inline help system）。
  • F1 上下文相关帮助。

为什么使用 FISH？

引言

FISH 是一种内置脚本语言，让 FLAC3D 用户能够强有力地控制程序操作的几乎每一个方面。FISH 是 “FLAC-ISH”（即 FLAC 的语言）的简称，最初就是在该代码中开发的。如今，除 FLAC 和 FLAC3D 之外，FISH 也已集成到所有 Itasca 商业程序中。

FISH 深度嵌入 FLAC3D 几乎每一个层面。它可用于对数据文件进行参数化处理，从而将多个不同的工况构建到同一基础模型中。构成 FLAC3D 模型的每一种数据类型也都可以由 FISH 直接操纵——无论是在求解之前、之后还是求解过程中。这意味着，FISH 不仅可以用于创建自定义的复杂模型和定制结果，还可以用于为求解过程添加标准软件包中不具备的自定义物理机制。

FISH 包含将 FLAC3D 命令嵌入 FISH 函数中的构造（参见 运行控制（Run Control） 一节所示示例中的 command – end command 块）。（此处的括号说明显得别扭，不确定应如何编辑？）

FISH 是一种半编译语言，变量采用动态类型——其语法和用法与 Python 类似（但不完全相同）。它被设计成对小需求非常简单，但必要时也提供支持大型复杂程序所需的结构和数据类型。

以下示例仅用于说明 FISH 的强大能力。更完整的信息请参阅 教程：使用 FISH（Tutorial: Working with FISH） 和 FISH 脚本参考（FISH Scripting Reference） 章节。下面给出的示例代表了五个一般应用领域：

  • 模型创建（Model Creation）
  • 参数化（Parameterization）
  • 自定义可视化（Custom Visualization）
  • 物理扩展（Physics Extension）
  • 运行控制（Run Control）

模型创建：属性初始化

以下 FISH 例程将体积模量指定为各网格单元中当前力学压力的函数。

fish define iniBulk(a,b)
    loop foreach zone zone.list
        local stress = zone.stress.effective(zone)
        local pressure = tensor.trace(stress)/3
        local bulk = a + b*math.sqrt(pressure)
        zone.prop(zone,'bulk') = bulk
    end_loop
end
[iniBulk(1e7,1e6)]

这是一个特别简单的示例，仅用于说明目的。

参数化：改变模型几何形状

在本示例中，我们使用 二维拉伸工具（2D extrusion tool） 交互式地创建一个简单的隧道模型。该工具的数据以及生成的网格单元如下所示。请注意，用于隧道的点以绿色标记，属于名为 分组名（Tunnel） 的分组。

自定义可视化：设定软弱面

或许 FISH 最常见的用途是定制模型结果。提供这一能力正是将其引入 Itasca 软件的初衷。FISH 允许用户绘制模型中任何感兴趣的物理量，而无需在某个菜单树中增加大量五花八门、鲜少使用的选项。下面是一个脚本示例，它针对整个模型计算某一特定平面方位上的法向应力和剪切应力分量。它还创建一个标志（破坏标志变量（fail），第 9 行），用于指示在给定特定摩擦角（临界切应力变量（tauCrit），第 8 行）的情况下，该平面上是否会发生破坏。

fish automatic-create off
fish define shearNormal(dip,dd,fric)
    local norm = math.normal.from.dip.ddir(dip*math.degrad,dd*math.degrad)
    loop foreach local zone zone.list
        local stress = zone.stress(zone)
        local traction = stress*norm
        local normalStress = math.dot(traction,norm)
        local shear = math.mag(traction - (norm*normalStress))
        local tauCrit = -normalStress*math.tan(fric*math.degrad)
        local fail = shear > tauCrit
        
        zone.extra(zone,1) = fail
        zone.extra(zone,2) = normalStress
        zone.extra(zone,3) = shear
    endloop
end
[shearNormal(45,90,20)]

在 FLAC3D 中，压应力为负值（注意第 8 行对 临界切应力变量（tauCrit） 的定义）。下面是由 相交隧道中的矿柱荷载（Pillar Loads At Intersecting Tunnels） 算例得到的绘图结果，观察的是相同方位的剖切面。请注意，可以自定义 FLAC3D 图例条目，使绘图内容更加清晰——在本例中，fail 取值为布尔值（真值（true）、假值（false）），但在绘图图例中它们被重新标记为 失败图例标签（Failed） 和 稳定图例标签（Stable）。

物理扩展：地层冻结

FISH 函数可以在计算循环/求解过程中被调用来推进求解。在每个计算循环中，可以在任意时点调用 FISH，以覆盖模型中的物理过程或为其添加额外的物理过程。每个计算循环是显式求解格式中各步骤的一次迭代；FISH 在该序列中的位置可以通过命令指定。

下面是一个 FISH 算子 地层冻结变量（groundFreezing） 的简单示例，它可用于在热力耦合分析中模拟地层冻结。算子是一类特殊的 FISH 函数，它可以（在解析时施加的限制条件下）利用系统可用的全部线程来执行。

program call 'freezezone'
fish operator groundFreezing(zone)
    ; 跳过已经冻结的网格单元
    if zone.group(zone,'state') == 'frozen' then exit
    if zone.temp(zone) > 0.0 then exit
    freezeZone(zone)
end

这里调用了 FISH 算子 冻结区域变量（freezeZone）（定义见下文），它实际改变网格单元的应力和刚度，并将其标记为已冻结。

fish operator freezeZone(zone)
    local porosity = zone.fluid.prop(zone,'porosity') 
    ; 注意：假定完全饱和
    local expansion = porosity * 0.09 * 1.0
    ;  孔隙率乘水的膨胀率再乘饱和度
    local bulk = zone.prop(zone,'bulk')
    local stress_inc = bulk * expansion  
    ; 应力增量
    local bulk_inc = (8.96/2.16) * porosity 
    ; 冰与水体积模量之比乘孔隙率
    zone.prop(zone,'bulk') += bulk_inc
    ; 压应力为负！
    zone.stress(zone) -= tensor(stress_inc,stress_inc,stress_inc)
    zone.group(zone,'state') = 'frozen'
end

可以通过类似下面的命令将冻结过程加入到求解处理中。

fish callback add groundFreezing([::zone.list]) -100 interval 10

向 地层冻结变量（groundFreezing） 算子传入的是要作用的网格单元列表。:: 前缀表示应将网格单元列表拆分，使用全部线程对列表中的每个网格单元分别调用。interval 关键字用于表示该算子应仅每 10 个计算步执行一次（以进一步限制对求解时间的影响）。同样的事情也可以作为 求解模型（model solve） 命令的一部分来完成，如下例所示。像下面这样的命令将求解至 1 年的热学时间，并且每 10 个计算循环进行一次地层冻结检查。

model solve time-total [360*24*60*60] ...      ; 加热一年，按 360 天计。
      mechanical ratio 1e-3 ...    ; 稍微放宽求解要求以加快计算。
      fish-call -100 groundFreezing([::zone.list]) interval 10 
                                               ; 通过 program call 调用地层冻结。

上面两种写法之间的区别在于：前者是全局性的，对之后任何 求解模型（model solve） 命令都会生效；后者则只针对该次特定的 model solve 调用指定执行 FISH。

下图显示了在修改后的 无限介质中的无限线热源（Infinite Line Heat Source in an Infinite Medium） 算例上运行所得的结果。

model new
model large-strain off
model configure thermal fluid
; --- 模型几何形状
zone create cylinder point 1 (500,0,0) ...
                     point 2 (0,1,0)  ...
                     point 3 (0,0,500) ...
                     size (48,1,24) rat 1.1 1 1
zone face skin slot 'uniform' ; 标记模型边界
zone group 'unfrozen' slot 'state' ; 初始化状态标记
; --- 力学模型
zone cmodel assign elastic
zone property bulk 5e10 shear 3e10 density 2e3
zone gridpoint fix velocity-x 0 range group 'West' ; 边界条件
zone gridpoint fix velocity-y 0 range group 'North' or 'South'
zone gridpoint fix velocity-z 0 range group 'Bottom'
; --- 热学模型
zone thermal cmodel isotropic
zone thermal property conductivity 4 expansion 5e-6 specific-heat 1e3
zone gridpoint initialize temperature 50
zone gridpoint fix source -200 range pos-x 0 pos-z 0 ; 施加冷源
; --- 流体模型
zone fluid cmodel assign isotropic
zone fluid property porosity 0.3
; --- 设置
zone fluid active off ; 本算例不考虑流体耦合
zone thermal implicit on 
model thermal timestep fix 6.48e3
model save 'line-year0'
; --- 添加地层冻结
program call 'groundfreezing'
; --- 耦合分析
model mechanical slave on
; excerpt-solve-start
model solve time-total [360*24*60*60] ...      ; 加热一年，按 360 天计。
      mechanical ratio 1e-3 ...    ; 稍微放宽求解要求以加快计算。
      fish-call -100 groundFreezing([::zone.list]) interval 10 
                                               ; 通过 program call 调用地层冻结。
; excerpt-solve-end
model save 'line-year1'

fish callback add groundFreezing([::zone.list]) -100 interval 10

这个示例非常简单，但仍然可能有用。根据模型的需要，还可以提高精度。例如，可以修改更多的特性，可以将本构模型改为支持蠕变的本构模型，还可以考虑水变成冰所需的熔化热。

运行控制：多个节理角度下的屈服

以下内容是 节理材料试样的单轴抗压强度（Uniaxial Compressive Strength of a Jointed Material Sample） 的简化版本。在 FISH 控制下共运行 18 次模型，以绘制破坏应力随节理角度变化的曲线（节理角度从 0 开始，每次运行增加 5 度）。所需的完整数据文件如下所示：

model new
model large-strain off
zone ratio convergence  ; 采用更保守的收敛准则
program call 'cylinder' ; 载入描述模型几何的拉伸器数据
program call 'measure'  ; 定义 'measureStress'，用于测量
                        ; 表面应力并存入数据表
fish define triaxSolver
    loop local beta (0,90,5)
        command
            zone delete                      ; 销毁全部网格单元
            zone generate from-extruder      ; 创建新网格单元
            zone cmodel ubiquitous-joint     ; 指定本构模型
            zone property bulk 1e8 shear 7e7 cohesion 2e3 ; 指定参数
            zone property friction 40 dilation 0 tension 2400
            zone property dip [beta] dip-direction 0
            zone property joint-cohesion 1e3 joint-friction 30
            zone property joint-dilation 0 joint-tension 2000
            ; 指定边界条件，并以准静态方式逐渐增大
            zone face apply velocity-y  1e-7 range position-y 0.0 
            zone face apply velocity-y -1e-7 range position-y 4.0 
model cycle 6000                 ; 运行计算循环，以获取破坏应力
        endcommand
        measureStress(beta)
    endloop
end
[triaxSolver]
model save 'triax1'

请注意，在实际的验证算例中，施加的边界条件使用 FISH 伺服控制来优化收敛精度，并将结果与通过 FISH 计算得到的解析解进行比较。

fish define measureStress(angle)
    ; 利用拆分和筛选查找 y==0 处的网格点列表
    local gplist = gp.list(gp.pos(::gp.list)->y == 0)
    ; 获取这些网格点 y 方向的不平衡力，即反力
    local force = -list.sum(gp.force.unbal(::gplist)->y)
    ; 将力转换为应力，底部面积并非精确的单位圆面积，
    ;    这是由边缘线性化造成的。
    local stress = force / 3.06147
    ; 将结果存入数据表，以供后续参考或绘图
    table('result',angle) = stress
end
