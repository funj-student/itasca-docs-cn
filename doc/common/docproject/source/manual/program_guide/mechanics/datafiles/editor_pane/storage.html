文件存储与 编辑器 窗格

创建新文件时（使用 文件 —> 添加新数据文件… 菜单命令、工具栏上的 新建数据文件 按钮（）或键盘命令 Ctrl + N），会提供一个对话框，用于命名新文件并选择其应存储的文件夹。对话框中提供的初始文件夹位置将是包含当前项目文件的文件夹。数据文件创建后，用户可以使用 文件 —> [文件名] —> 重命名 [文件名] 菜单命令对其重命名。以这种方式重命名也会重命名硬盘上的文件。

习惯在其它文本编辑器中处理数据文件的用户需要注意 PFC 的项目系统，如“项目：进一步说明（Projects: Further Description）”主题所述。需要牢记的主要一点是：当某个数据文件同时在 PFC 和另一个编辑器中打开时，在任一侧所做的更改不会反映到另一侧。此外，PFC 中的“保存”命令与外部编辑器中的保存命令相互独立；无论此前是哪个程序保存的，任一方都将覆盖该文件最后保存的版本。在保存项目时应牢记这一点，因为保存项目会自动保存所有已打开的项目项。
