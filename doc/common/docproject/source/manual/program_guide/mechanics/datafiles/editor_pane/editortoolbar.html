编辑器窗格工具栏

当 编辑器 窗格处于活动状态时，工具栏如下所示。

表 1：编辑器窗格工具栏上可用的工具
图标 命令 说明/注释
执行/停止切换按钮 执行或停止计算循环；更多信息请参见“工具栏（Toolbar）”主题。
新建… 在新 编辑器 窗格中打开新的数据文件。
打开… 调用对话框，让用户指定要打开的数据文件。
保存… 保存活动数据文件。
关闭 关闭活动数据文件。
撤销 撤销上一次操作。
重做 再次执行上一次操作。
查找… 打开 查找 对话框，让用户指定要在当前文件中搜索的文本。
查找所选内容 查找当前所选文本的下一个实例。
再次查找 搜索最近一次在 查找 对话框中指定的文本的下一个实例。
替换… 打开 替换 对话框，让用户指定全局替换操作（即查找 A 的所有实例并替换为 B）。
转到… 打开对话框，让用户指定在当前文件中要转到的行号。
注释所选内容 注释所选文本（如果选择了多行，则逐行注释）。
取消注释所选内容 取消注释所选文本（如果选择了多行，则逐行取消注释）。
运行所选内容 仅执行当前所选内容。
编辑器选项… 将 选项 对话框打开到 编辑器页面（Editor page）。
局部选项 下拉菜单，用于关闭/开启 局部选项（Local Options）：行号、代码折叠、缩进参考线、语法高亮和自动换行。详情请参阅关于局部选项的 主题（topic）。
命令帮助… 将 帮助 打开到当前行上命令的定义。
显示/隐藏控制面板 切换 控制面板 的显示；请参阅“工具栏（Toolbar）”主题。
控件组 选择要显示/隐藏的控件组；请参阅“工具栏（Toolbar）”主题。

编辑器窗格中的右键菜单

窗格中的弹出上下文菜单提供以下命令。这些命令会根据当前上下文（即是否选中了文本、撤销/重做栈中是否存有命令等）适当地启用/禁用。

撤销 - 撤销上一次操作。
重做 - 再次执行最近一次被“撤销”的操作。
剪切 - 删除所选文本并将其放到剪贴板。
复制 - 将所选文本复制到剪贴板。
粘贴 - 将剪贴板上的文本插入到当前光标位置。
删除 - 删除所选文本。
全选 - 选择窗格中的所有文本。
查找… - 打开 查找 对话框。
查找所选内容 - 查找当前所选文本的下一个实例。
查找下一个 - 查找在 查找 对话框中输入的文本的下一个实例。
替换… - 打开 替换 对话框。
转到行… - 打开 转到行 对话框；输入编号以转到该行。
转到标记… - 打开 转到标记 对话框；输入编号以转到当前行中该位置处的标记。
块注释 - 注释所选文本（如果选择了多行，则逐行注释）。
块取消注释 - 取消注释所选文本（如果选择了多行，则逐行取消注释）。
帮助（F1）- 将 帮助 文件打开到当前行上命令的定义。
运行所选内容 - 仅执行当前所选内容。
执行 - 此命令与工具栏上的 “执行/停止”命令开关（“Execute/Stop” command toggle） 相同。用它来开始或停止执行当前整个文件。
