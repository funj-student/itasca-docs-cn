数据文件处理

此处描述的主题定义以文件形式对数据文件执行的操作。用命令编写完整数据文件的过程在 i 编辑器（Editor） 窗格一节中介绍——该窗格正是为此目的而设计。

创建

使用菜单命令 文件 ‣ 添加新数据文件（或其键盘快捷键 Ctrl + N）。这将打开 添加新数据文件 对话框，并定位到当前项目文件所在的文件夹。指定文件名，然后按此对话框中的 打开 按钮，即可在 i 编辑器（Editor） 窗格中打开新建的文件。

打开或调用

不在项目中的文件

使用菜单命令 文件 ‣ 打开到项目中（或其键盘快捷键 Ctrl + O）。在随后出现的 i 打开到项目中（Open Into Project） 对话框中，定位并选择所需文件。使用右侧的选项按钮指示所选数据文件应被打开（仅加载到 编辑器 窗格）还是被调用（加载并执行）。如果使用该对话框的默认选项“按扩展名确定”，则数据文件将被打开（而不是被调用）。以这种方式打开的数据文件会添加到项目中。

项目中的文件

上述方法对已在项目中的文件同样适用。不过，打开项目中数据文件更简单的方法是使用 i 项目（Project） 窗格。在“数据文件”列表中双击该数据文件即可打开；右键单击并选择“调用”，即可打开并执行。

另请参阅命令 调用数据文件（program call），它可用于在 控制台的 命令提示符（command prompt） 处调用数据文件。

重命名

  • 在包含该数据文件的窗格处于活动状态时，使用菜单命令 文件 ‣ [filename] ‣ 重命名（[filename] 是该文件的名称，将显示在菜单上）。
  • 如果该文件属于某个选项卡组，则右键单击该文件的选项卡，并从上下文菜单中选择 重命名。

用任一种方法这样重命名，都可确保该文件保持与项目的连接。如果在程序外部重命名（例如在系统的默认文件浏览器中），则项目与该文件的链接将断开。

创建副本

  • 在包含该数据文件的窗格处于活动状态时，使用菜单命令 文件 ‣ [filename] ‣ 另存为（[filename] 是该文件的名称，将显示在菜单上）。

关闭

  • 在包含该数据文件的窗格处于活动状态时，使用菜单命令 文件 ‣ [filename] ‣ 关闭（[filename] 是该文件的名称，将显示在菜单上）。
  • 如果该文件属于某个选项卡组，则右键单击该文件的选项卡，并从上下文菜单中选择 关闭。
  • 在项目窗格中，右键单击“数据文件”列表中的该文件，并选择 在编辑器中关闭
  • 在包含该数据文件的窗格处于活动状态时，按下工具栏上的“关闭”按钮（||）。

打印

  • 在包含该数据文件的窗格处于活动状态时，使用菜单命令 文件 ‣ [filename] ‣ 打印（[filename] 是该文件的名称，将显示在菜单上）。

取消隐藏

  • 转到 文档 窗口并选择该项（该项目项将处于未勾选状态）以将其显示。
