编辑器窗格中的选择

在编辑器中选定文本有多种方式，描述如下。在以下所有情况下，所述操作均使用鼠标左键。

选择任意长度的文本（向上或向下方向）：
  • 从起点单击并拖动到终点，到达终点时松开鼠标按钮；或
  • 单击将光标置于起点，按住 Shift 键，将鼠标放在所需的终点处，然后单击。
选择单个字符：
  • 按住 Shift 键不放，按右方向键或左方向键，分别选择光标右侧或左侧的下一个字符。连续按方向键将选择后续字符。按相反方向的方向键可一次从选择中移除一个字符。
选择单个单词：
  • 双击该单词；或
  • 将光标置于该单词的开头，按 Ctrl 和 Shift 键，然后按右方向键。再次按右方向键将选择下一个单词，向右方向移动。使用左方向键则可在相反方向上执行此操作。
选择单行：
  • 单击该行的左侧边距（这也会将文本光标置于下一行的开头）；或
  • 在该行内同一位置三击；或
  • 将光标置于该行开头，按住 Shift 键不放，然后按向下方向键（向下方向选择；按向上方向键则向上选择）。连续按键将沿方向键方向选择后续行。
全选：
  • 指向任意行的左侧边距，按 Ctrl，然后单击。
选择列：
  • 按 Alt 键，然后从该列的起点单击并拖动到终点；或
  • 在所需的起点处单击，按住 Alt + Shift 键，然后在所需的终点处单击；或
  • 在所需的起点处单击，然后按 Alt + Shift 键。接着使用左右方向键加宽选择，或使用上下方向键加长选择。
