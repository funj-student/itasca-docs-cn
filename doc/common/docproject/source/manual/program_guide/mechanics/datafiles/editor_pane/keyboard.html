键盘

下表汇总了 PFC 中可用于与 编辑器 窗格相关的命令的按键。命令末尾出现省略号（…）表示使用该命令时将出现对话框。所有命令都是上下文相关的。它们会根据当前上下文（例如编辑器中当前是否选中了文本）适当地启用或禁用。请注意，当相关命令出现在 编辑 菜单中时，这些按键命令列在该菜单的右侧。

在某些选择操作中也会使用键盘。这些操作在各自的主题（in their own topic）中描述。

表 1：与 编辑器 相关的按键命令
按键 命令 说明/注释
Ctrl + Z 撤销 撤销上一次操作。
Ctrl + Y 重做 再次执行上一次操作。
Ctrl + X 剪切 删除所选文本并将其放到剪贴板。
Ctrl + C 复制 将所选文本复制到剪贴板。
Ctrl + V 粘贴 将剪贴板上的文本插入到当前光标位置。
Ctrl + A 全选 选择窗格中的所有文本。
Ctrl + F 查找… 打开 查找 对话框，让用户指定要在当前文件中搜索的文本[†]。
Ctrl + Shift + F 查找所选内容 查找当前所选文本的下一个实例[†]。
Ctrl + L 查找下一个 搜索最近一次在 查找 对话框中指定的文本的下一个实例[†]。
Ctrl + H 替换… 打开 替换 对话框，让用户指定全局替换操作（即查找 A 的所有实例并替换为 B）[†]。
Ctrl + G 转到行… 打开对话框，让用户指定在当前文件中要转到的行号[†]。
Ctrl + Shift + G 转到标记… 打开对话框，让用户指定在当前文件中要转到的行号[†]。
Ctrl + K 块注释 注释所选文本（如果选择了多行，则逐行注释）。
Ctrl + Shift + K 块取消注释 取消注释所选文本（如果选择了多行，则逐行取消注释）。
Ctrl + Shift + E 运行所选内容 仅执行当前所选内容。
Ctrl + E 执行 执行或停止计算循环；更多信息请参阅 工具栏主题（Toolbar topic）。

[†] 此命令的按键可以用 i 选项（Options） 对话框中的 i 编辑器（Editor） 选项进行自定义。
