选择

在模型窗格中选择对象有多种方式。

单击

最简单的方式是单击某个对象，此时该颜色的所有相关对象都会被选中。所使用的颜色方案决定哪些对象会被选中。对象（Objects） 控件组提供了用于更改颜色方案的控件。

显示网格单元时，可以选择按分组、按统一颜色或按模型着色。按分组着色时，所选的槽位会影响着色结果。

显示网格单元面时，显示、按…着色和槽位（或表皮槽位）属性的组合将决定面的着色。

Alt+单击

如果在单击时按住 Alt 键，则无论采用何种颜色方案，只会选中被单击的那一个对象。

Control+单击、Control+Alt+单击

单击时按住 Control 键，将使被单击对象的选择状态反转。

Control+Alt+Shift+单击

在单击对象时按住 Control、Alt 和 Shift 键，将弹出消歧器。可以使用 消歧器（disambiguator） 对话框按分组选择对象。

消歧器

工具栏中的消歧器工具（）会使鼠标进入一种模式：在对象上单击鼠标将显示一个对话框，其中列出该对象的所有槽位与分组分配。可以选择要按分组选择的哪些对象。

还可以将鼠标悬停在对象上并按“D”键来显示 消歧器（disambiguator）。

上下文菜单

上下文菜单中有一个“选择…”命令，用于选择右键单击的对象。

范围

可以通过范围控件组以及上下文菜单中的“使用范围…”命令打开范围对话框。可以使用范围来选择对象和取消选择对象。

按平面选择面

可以使用工具栏选择网格单元面，在工具栏中可以设置折角来定义平面。工具按钮（）会使鼠标进入一种模式：单击某个面即可选择同一平面内所有相邻的面。按住 Control 单击将反转此类选择。

还可以将鼠标悬停在对象上，按“S”键或 Control+S 来选择对象或反转其选择状态。
