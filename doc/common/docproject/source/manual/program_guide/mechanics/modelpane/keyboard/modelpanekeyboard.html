键盘参考

选择模式下的鼠标单击组合键：
  • Shift：按颜色隐藏。
  • Control：按颜色反转选择状态。
  • Alt：选择单个对象。
  • Shift+Alt：隐藏单个对象。
  • Control+Alt：反转单个对象的选择状态。
  • Control+Alt+Shift：使用消歧器按分组选择或隐藏。

Shift+拖动：创建矩形以隐藏对象。

Control+右键单击：显示上下文菜单以更改所显示的数据类型。

Alt+鼠标滚轮：第一人称导航模式。

键盘操作：

按键 功能
Backspace 清除当前选择。
删除 删除当前选择。
Esc 取消当前模式。
A 显示全部。
D 使用消歧器按颜色选择或隐藏鼠标指针悬停处的对象。
G 显示范围对话框。
H 按颜色隐藏。
Control+K 为模型生成蒙皮。
L 针对当前选择：Shift+L = 隐藏所选内容；Control+Shift+L = 仅显示所选内容；Control+Alt+L = 缩放到所选内容（视图平移控件组中的按钮）。
O 使鼠标进入选择模式。
Alt+O 显示工具栏中的下拉菜单。
Shift+O 执行默认操作。
S 按共面性选择鼠标悬停面所在平面上的面。
Control+S 切换按共面性对鼠标所在面进行的面选择。
Shift+S 按共面性隐藏鼠标所在面平面上的面。
