消歧器

模型窗格中的对象可以有一个或多个分组指定。当指定了多个分组、而您想按分组选择或隐藏对象时，消歧器可让您挑选使用哪个分组。

例如，单个网格单元可能被指定了分组 X、Y 和 Z，以及一个 Building Block ID。当您显示该网格单元的消歧器时，会在列表中看到全部四种槽位+分组组合。您可以逐个单击列表中的每个条目，让模型窗格显示每个槽位+分组中的对象。在列表中选择槽位和分组后，可以单击“选择”或“隐藏”按钮对该分组执行操作。
