基于几何的选择

在模型上单击鼠标将找到一个初始对象，并根据在 对象（Objects） 控件组中所选的颜色方案，找到要包含在选择范围内的一系列对象。系统将生成一条命令来指定要选择的对象范围。

初始对象可以在单击鼠标时确定，也可以在命令执行时确定。

默认情况下，“基于几何的选择”处于关闭状态，此时初始对象由单击鼠标确定，且用于选择对象的指定范围保持固定。

当“基于几何的选择”处于开启状态时，鼠标单击的坐标会被写入命令，并在命令执行时用于查找要包含在选择范围内的初始对象及相关范围。如果模型的位置发生偏移，则下次执行该命令时可能会选中不同的对象范围。

修饰键改变鼠标光标

此设置决定在按住 Shift、Control 和/或 Alt 键时鼠标光标是否随之改变。

显示工具按钮

此设置决定工具栏中是否显示某些工具按钮。

“按平面性隐藏面”设置仅在模型窗格中显示面时可用。
