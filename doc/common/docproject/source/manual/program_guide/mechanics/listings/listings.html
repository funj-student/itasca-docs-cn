列表

列表是使用 list 关键字的命令（此类命令有很多）所产生的打印输出。

当输出的长度低于输出行数阈值（该阈值在 i 选项（Options） 对话框的“列表”页面中设置）时，输出显示在 控制台（console） 中。当输出超过该阈值时，它会被放入其自己的 i 列表（Listing） 窗格中。窗格中的输出是静态的——不会因任何后续程序操作而更新或改变。列表 窗格提供处理输出的工具，包括复制文本和导出为文件输出。可以打开的列表窗格数量没有限制。

使用 list 的命令

program list security
program list cycle-sequence

list 关键字出现在许多命令中（例如 列出循环序列（program list cycle-sequence）、列出网格单元应力（zone list stress）、列出球体属性（ball list property））。它用于获取关于使用它的对象的基于文本的信息，后面跟随的关键字用于确定需要该对象的哪个方面。与所有命令一样，其输出预期在 i 控制台（Console） 窗格中处理。但是，当 list 类型命令的输出超过一定行数时，会在自动生成的 i 列表（Listing） 窗格中创建列表。

用于创建 列表 窗格的行数阈值可在 i 选项（Options） 对话框的 i 列表（Listings） 页面中指定。

作为对比，在 控制台 窗格的 命令提示符（command prompt） 处输入上面显示的两条命令。假设 i 选项（Options） 对话框中的列表阈值设为约 10 或更小，则第一条命令的输出显示在 控制台 窗格中。第二条命令的输出则进入 列表 窗格。

注意

如其它地方所述，所有 c 程序（program） 命令都可以省略开头的词 program。上面显示的命令可输入为 list security 和 list cycle-sequence。
