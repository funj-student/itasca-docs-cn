键盘

下表汇总了 PFC 中与处理列表或 列表 窗格处于活动状态时相关的按键命令。如果命令标签后出现省略号（…），表示使用该命令时将出现对话框。这些命令是上下文相关的，意味着如果活动的窗格不是 列表 窗格，它们将产生不同的结果。


表 1：列表窗格按键命令
按键 命令 说明/注释
Ctrl+Alt+S 将 [列表名称] 另存为… 将活动窗格中的列表保存到文件。
Ctrl + W 关闭 [列表名称] 关闭活动窗格中的列表。除非此前已保存，否则列表中的信息将丢失。
Ctrl + C 复制 将列表中选定的文本复制到剪贴板。
