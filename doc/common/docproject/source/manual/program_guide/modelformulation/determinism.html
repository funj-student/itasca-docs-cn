确定性

在多个 CPU 或核心上并行执行计算时，特定计算发生的顺序可能改变，而且确实会改变。

这会使舍入误差以不同方式累积。

对许多模型而言，这些差异的最终结果几乎无法察觉。但对一大类模型来说，这些差异会被放大，导致每次运行同一模型都会得到不同的结果。<br>需要强调的是，所有这些结果同样有效，因为它们都处于有限精度浮点误差的范围之内。

确定性模式会牺牲效率和内存，以强制并行计算每次都得到相同结果，无论计算使用多少个 CPU、各 CPU 的相对速度如何。

默认情况下，程序以确定性模式运行。可在数据文件中使用 ‘model deterministic off’ 命令更改。也可以取消勾选用户界面中“工具/选项/常规”下的“默认确定性”复选框来更改默认设置。

关闭确定性的后果

  • 模型运行速度会更快。
    加快的幅度取决于具体程序和模型。FLAC3D 忽略确定性标志，始终为确定性。3DEC 约快 10%。PFC3D 约快 15%。
  • 结果将不可重复。
    在某些小变化会传播放大的情况下，每次运行模型都会得到非常不同的结果。
  • 数据文件（及项目包）将无法再可靠地复现结果。
    为便于归档，应将生成的保存文件与输入数据一起保存。
  • 若遇到需要技术支持的问题，Itasca 可能无法复现该问题。
    这种情况下，应开启确定性重新运行模型。若问题不再出现，我们可能几乎无法为您提供帮助。
