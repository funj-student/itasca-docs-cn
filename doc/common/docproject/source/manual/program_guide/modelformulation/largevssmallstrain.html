大应变/小应变

FLAC3D 的默认计算模式是小应变，而 PFC 和 3DEC 的默认计算模式是大应变。在小应变模式下：网格点或颗粒的位置不发生变化——应力和应变计算均基于网格单元的原始形状进行。若变形后的形状与原形状的差异在百分之几以内，这是可接受的近似。在大应变模式下，位置会被频繁更新，从而可能得到更精确的解。大应变模型还执行接触检测计算，因此当各单元相对运动时，接触可能被创建或删除。在小应变模式下，接触配置不发生变化。

大应变模拟能更准确地反映真实情况，但代价是计算量增加。用户可通过指定位置和接触更新的频率来权衡精度与计算成本。默认的更新间隔和命令因程序而异。

除位置和接触更新外，大应变模式下还执行以下计算：

  • 对网格单元中的应力增量施加旋转修正
  • 对于指定了软弱面的本构模型（例如遍布节理模型），软弱面的方位随网格单元一起旋转
  • 由面力或应力边界条件产生的施加力会重新计算，以计及面的旋转

另请注意，在大应变连续体模型中，网格单元可能经历极端变形，以致在几何上变得不可接受（例如体积为 0）。这种情况下，程序计算无法继续。

选择大应变还是小应变取决于预期的模型行为。若存在接触（PFC 中总是存在，FLAC3D 中位于接触面上，3DEC 中位于节理上），且各部分预计会相对移动较大距离（即超过一个网格单元的尺寸），那么大应变可能确有必要，以允许接触更新。同样，在连续体模型中，若网格单元之间的相对运动量级与单元尺寸相当（例如剪切带两侧），大应变可能是正确选择。注意，大位移不一定等于大应变——若位移均匀分布于整个模型，则小应变假定可能仍然有效。
