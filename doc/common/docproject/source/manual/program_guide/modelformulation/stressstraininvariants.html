应力/应变不变量

在 FLAC3D 中，设 \(s_{ij}\) 为应力张量 \(\sigma_{ij}\) 的偏量部分、\(e_{ij}\) 为应变张量 \(\varepsilon_{ij}\) 的偏量部分，FLAC3D 中的应力/应变不变量按 表 1（Table 1） 定义并汇总。

例如，在三轴压缩试验中，\(xy\) 平面内的室压为 100，\(z\) 方向上的竖向压缩压力为 400，则试样中的应力张量为

\[\sigma_{ij} = \{\sigma_{xx}, \sigma_{yy}, \sigma_{zz}, \sigma_{xy}, \sigma_{yz}, \sigma_{xz} \} = \{-100,-100,-400,0,0,0\}\]

根据 表 1（Table 1） 中的公式，可得


\(I_1 = -600\),
\(I_2 = 9e4\),
\(I_3 = -4e6\)
\(\sigma_v = -600\),
\(\sigma_m = -200\),
\(e_{ij} = \{s_{xx}, s_{yy}, s_{zz}, s_{xy}, s_{yz}, s_{xz} \} = \{100,100,-200,0,0,0\}\),
\(J_1 = 0\),
\(J_2 = 3e4\),
\(J_3 = -2e6\),
\(\theta_{\sigma} = \pi/6\),
\(\sigma_1 = -400\),
\(\sigma_2 = \sigma_3 = -100\),
\(\sigma_{eq} = q = 300\),
\(\sigma_{oct} = 100\sqrt{2}\),
\(\tau_{max} = 100\),
\(\sigma_{norm} = 300\sqrt{2}\)，以及
\(\sigma_{tm} = 300\sqrt{2}\).

表 1：应力/应变不变量
应力不变量 定义 应变不变量 定义
第 1 应力不变量 \(I_1 = \sigma_{kk}\) 第 1 应变不变量 \(I'_1 = \varepsilon_{kk}\)
第 2 应力不变量 \(I_2 = (\sigma_{xx}\sigma_{yy}+\sigma_{yy}\sigma_{zz}+\sigma_{zz}\sigma_{xx}) \\- (\sigma_{xy}\sigma_{yz}+\sigma_{yz}\sigma_{zx}+\sigma_{zx}\sigma_{xy})\) 第 2 应变不变量 \(I'_2 = (\varepsilon_{xx}\varepsilon_{yy}+\varepsilon_{yy}\varepsilon_{zz}+\varepsilon_{zz}\varepsilon_{xx}) \\- (\varepsilon_{xy}\varepsilon_{yz}+\varepsilon_{yz}\varepsilon_{zx}+\varepsilon_{zx}\varepsilon_{xy})\)
第 3 应力不变量 \(I_3 = |\sigma_{ij}|\) 第 3 应变不变量 \(I'_3 = |\varepsilon_{ij}|\)
体积应力 \(\sigma_v = \sigma_{kk}\) 体积应变 \(\varepsilon_{v} = \varepsilon_{kk}\)
平均应力 \(\sigma_m = \sigma_{kk}/3\) 平均应变 \(\varepsilon_{m} = \varepsilon_{kk}/3\)
第 1 偏应力不变量 \(J_1 \equiv 0\) 第 1 偏应变不变量 \(J'_1 \equiv 0\)
第 2 偏应力不变量 \(J_2 = (s_{ij}s_{ij})/2\) 第 2 偏应变不变量 \(J'_2 = (e_{ij}e_{ij})/2\)
第 3 偏应力不变量 \(J_3 = (s_{ij}s_{ik}{s_{ki}})/3\) 第 3 偏应变不变量 \(J'_3 = (e_{ij}e_{ik}{e_{ki}})/3\)
应力 Lode 角 \(\theta_{\sigma} = {{1} \over {3}} \arcsin{\left( -{{3\sqrt{3}} \over {2}} {{J_3} \over {J^{1.5}_2}} \right)}\) 应变 Lode 角 \(\theta_{\varepsilon} = {{1} \over {3}} \arcsin{\left(- {{3\sqrt{3}} \over {2}} {{J'_3} \over {J'^{1.5}_2}} \right)}\)
最小主应力 \(\sigma_1 = {2\over{\sqrt{3}}}\sqrt{J_2}\sin{(\theta_{\sigma} - {2\over{3}}\pi)} + \sigma_m\) 最小主应变 \(\varepsilon_1 = {2\over{\sqrt{3}}}\sqrt{J'_2}\sin{(\theta_{\varepsilon} - {2\over{3}}\pi)} + \varepsilon_m\)
中间主应力 \(\sigma_2 = {2\over{\sqrt{3}}}\sqrt{J_2}\sin{(\theta_{\sigma})} + \sigma_m\) 中间主应变 \(\varepsilon_2 = {2\over{\sqrt{3}}}\sqrt{J'_2}\sin{(\theta_{\varepsilon})} + \varepsilon_m\)
最大主应力 \(\sigma_3 = {2\over{\sqrt{3}}}\sqrt{J_2}\sin{(\theta_{\sigma} + {2\over{3}}\pi)} + \sigma_m\) 最大主应变 \(\varepsilon_3 = {2\over{\sqrt{3}}}\sqrt{J'_2}\sin{(\theta_{\varepsilon} + {2\over{3}}\pi)} + \varepsilon_m\)
von Mises 等效应力 \(\sigma_{eq} = \sqrt{3 J_2}\) von Mises 等效应变 \(\varepsilon_{eq} = \sqrt{{{4}\over{3}}J'_2}\)
等效偏应力 \(q = \sqrt{3 J_2}\) 等效（工程）剪应变 \(\gamma = \sqrt{4 J'_2}\)
八面体应力 \(\sigma_{oct} = \sqrt{{{2}\over{3}}J_2}\) 八面体应变 \(\varepsilon_{oct} = \sqrt{{{8}\over{3}}J'_2}\)
最大剪应力 \(\tau_{max} = (\sigma_3 - \sigma_1)/2\) 最大剪应变 \(\gamma_{max} = \varepsilon_3 - \epsilon_1\)
应力范数 \(\sigma_{norm} = \sqrt{\sigma_{ij}\sigma_{ij}}\) 应变范数 \(\varepsilon_{norm} = \sqrt{\varepsilon_{ij}\varepsilon_{ij}}\)
应力总量度 \(\sigma_{tm} = \sqrt{\sigma_1^2+\sigma_2^2+\sigma_3^2} = \sqrt{I_1^2/3+2J_2}\) 应变总量度 \(\varepsilon_{tm} = \sqrt{\varepsilon_1^2+\varepsilon_2^2+\varepsilon_3^2} = \sqrt{I_1^{'2}/3+2J'_2}\)
