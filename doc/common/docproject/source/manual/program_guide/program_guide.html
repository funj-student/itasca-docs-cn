程序指南

所有 Itasca 软件都建立在每个程序基础层的一组共同要素之上，无论所采用的数值方法或程序使用的单元类型如何。因此，无论是使用 3DEC 或 PFC 这类离散元软件，还是使用 FLAC3D 这类连续介质软件，都会有大量逻辑、过程、工具和功能是它们所共有的。

本节全部内容聚焦于这些通用机制，它们渗透于软件的每一个方面，从建模方法学到命令的实现，到计算格式，到用户界面设计，再到模型设计、处理和输出的技术，乃至更多。下文列出的各小节分别涵盖这些领域：

建模方法学（Modeling Methodology）
本节提供数值建模的高层指南，给出推荐的处理方法，并讨论可能影响模型设计和程序性能的具体考虑事项。
基础概念与约定（Underpinnings）
本节概述程序的科学背景。其中列举了有关符号表示、命令语法高亮、正负号约定、单位制、精度限制的约定。还介绍了计算循环、模型中作用的物理力（能量、应力和应变），并对用于创建模型的组成部分（网格单元、球体或刚性簇、结构单元、块体等）作了入门性介绍。
程序机制（Program Mechanics）
本节介绍程序所提供的大部分数值模型开发环境。首先介绍命令——它是程序的核心。然后按照建模过程的顺序介绍：项目创建、数据文件与命令处理、绘图、求解以及结果存储。本节可视为程序的通用用户指南。
本构模型（Constitutive Models）
FLAC3D 和 3DEC 中可用的力学本构模型从线弹性模型到高度非线性的塑性模型。本节介绍基本本构模型。每个模型的说明都包括理论背景的简要讨论和简单的示例测试。
结构单元（Structural Elements）
本节提供 FLAC3D 和 3DEC 中提供的六种结构单元的说明、构成它们的组件、结构单元公式的理论与背景，以及演示结构单元在模型中应用的示例。
通用命令与 FISH（Common Commands and FISH）
本节是所有 Itasca 数值建模程序中普遍可用的全部命令和 FISH 函数的参考。分别特定于 PFC、FLAC3D 和 3DEC 的命令集参见 PFC 模型对象（PFC Model Objects）、FLAC3D 命令与 FISH（FLAC3D Commands and FISH） 和 3DEC 命令与 FISH（3DEC Commands and FISH）。

命令与 FISH 参考

通用

  • 索引：通用命令（Index: Common Commands），用于所有 Itasca 软件共有的命令（c 调用命令（call）、c 恢复模型（restore）、c 几何（geometry）、c 裂隙（fracture）、c 模型（model）、c 程序（program）、c 表格插值取值（table） 等）
  • 索引：通用 FISH（Index: Common FISH），用于与通用命令关联的所有 FISH 函数。

  • 索引：PFC 命令（Index: PFC Commands），用于 PFC 命令（c 球体（ball）、c 墙体（wall）、c 颗粒簇（clump） 等）

FLAC

  • FLAC3D 命令索引（FLAC3D Commands Index），用于 FLAC3D 命令（c 网格单元（zone）、c 结构单元（structure）、c 拉伸块体（extrude block） 等）
