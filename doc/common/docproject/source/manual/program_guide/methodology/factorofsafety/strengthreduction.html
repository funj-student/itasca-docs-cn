FLAC3D Theory and Background • Factor of Safety

在 FLAC3D 和 3DEC 中的强度折减流程

强度折减法基本上可应用于任何材料破坏模型，以根据指定强度属性或属性组的折减来评估安全系数。该方法已在摩尔-库仑材料的背景下广泛使用，并且主要体现为同时折减黏聚力和摩擦强度。从 FLAC3D 5.0 版本起，除摩尔-库仑强度属性（用 指定Mohr-Coulomb本构模型（zone cmodel assign mohr-coulomb） 指定）外，当给出 设置安全系数分析参数（model factor-of-safety） 命令时，该方法还会自动应用于遍布节理强度属性（用 指定遍布节理本构模型（zone cmodel assign ubiquitous-joint） 指定）和 Hoek-Brown 强度属性（用 指定Hoek-Brown本构模型（zone cmodel assign hoek-brown） 指定）。

当在 FLAC3D 中针对接触面黏聚力和摩擦（通过 设置接触面节点属性（zone interface node property） 指定）、或在 3DEC 中针对节理黏聚力和摩擦（通过 设置块体接触属性（block contact property） 指定）执行 设置安全系数分析参数（model factor-of-safety） 时，也可以应用强度折减法。

通过 设置安全系数分析参数（model factor-of-safety） 命令实施强度折减技术的步骤如下。

首先，程序确定一个“特征响应时间”，即表征系统响应时间的一个代表性步数（记为 \(N_r\)）。\(N_r\) 的求法是：把材料强度（对摩尔-库仑材料为黏聚力和抗拉强度）设为一个很大的值，使内部应力发生很大变化（默认对应力状态施加扰动因子 2），然后确定系统恢复到平衡所需的步数。

默认情况下，\(N_r\) 的最大限值为 50,000。如果模型在 50,000 步内未达到平衡，计算将停止，安全系数解无法完成。此时用户应检查为模型选择的参数。例如，如果用户选用了杨氏模量很高的结构支护，这可能会影响解的收敛时间。

也可以通过 characteristic-steps 关键字手动设置 \(N_r\) 的值来指定 \(N_r\)。或者，使用 perturbation 关键字指定不同的扰动因子，以改变内部应力的初始扰动。注意，这些手动控制应谨慎使用。

在 \(N_r\) 确定之后，对于给定的强度折减系数 \(F\)，执行 \(N_r\) 个计算步。如果在 \(N_r\) 步之后不平衡力比 [1] 小于 10-5，则系统处于平衡状态。如果不平衡力比大于 10-5，则再执行 \(N_r\) 步；如果此时力比小于 10-5，则退出循环。将当前 \(N_r\) 步跨度结束时力比的值与前一个 \(N_r\) 步结束时力比的值进行比较。如果差值小于 10%，则认为系统处于非平衡状态，并以新的非平衡状态 \(F\) 退出循环。如果上述差值大于 10%，则继续执行由 \(N_r\) 步组成的块，直至：(1) 差值小于 10%；或 (2) 已执行 6 个这样的块；或 (3) 力比小于 10-5。情形 (1) 的理由是：平均力比正在收敛到一个大于平衡所对应值的稳定值，因此系统必定处于持续运动状态。

求解过程中会显示以下信息：

  1. 当前正在执行的操作；
  2. 为确定给定 \(F\) 值而完成的计算步数；
  3. 两倍特征响应时间 \(N_r\)（注意，不平衡力比的变化首先在两倍 \(N_r\) 时检查）；
  4. 不平衡力比；
  5. 已完成的求解阶段数（即平衡或非平衡检验次数）；以及
  6. \(F\) 的当前区间值。

当上、下区间值之差小于平均值的 0.005 倍时，安全系数求解停止。（该分辨率限值可通过 设置安全系数分析参数（model factor-of-safety） 命令的可选关键字 resolution 更改。）

使用 设置安全系数分析参数（model factor-of-safety） 命令调用的区间求解方法，在确定安全系数之前可能需要进行大量（稳定与不稳定）求解。如果已知安全系数的近似范围，则可通过指定起始区间值来减少求解次数（以及总求解时间）。这可以通过 bracket v1 v2 实现，该短语是 设置安全系数分析参数（model factor-of-safety） 命令的可选短语。如果计算得到的安全系数超出指定区间，将发出警告消息。此外，还可以通过设置 bracket v1 v2 来检验指定安全系数是高于还是低于实际安全系数。

使用 设置安全系数分析参数（model factor-of-safety） 时应注意以下情况。

  1. 在执行 设置安全系数分析参数（model factor-of-safety） 计算之前，必须保存模型状态。
  2. 对于 设置安全系数分析参数（model factor-of-safety） 计算，初始应力状态可以是零应力状态，也可以是应力平衡状态。如果模型处于零应力状态，则仅施加重力荷载来确定 \(N_r\)。
  3. 发出 设置安全系数分析参数（model factor-of-safety） 时，安全系数计算在小应变计算模式下进行。
  4. 如果对流体流动-力学耦合模型（已指定 配置流体计算模式（model configure fluid））进行安全系数计算，则在发出 设置安全系数分析参数（model factor-of-safety） 时，流体流动计算将被关闭，流体体积模量将被设为零。
  5. 安全系数计算假定为 设置安全系数分析参数（model factor-of-safety） 的非关联塑性流动。可添加关键字 associated 进行关联塑性流动计算。

在 设置安全系数分析参数（model factor-of-safety） 计算期间会保存三个文件：初始条件状态、最近一次稳定的安全系数计算以及最近一次不稳定的安全系数计算。默认情况下，初始状态保存到名为“FOS-Init.sav”的文件，稳定状态保存到名为“FOS-Stable.sav”的文件，不稳定状态保存到“FOS-Unstable.sav”文件。每个安全系数计算阶段都从“FOS-Init.sav”状态开始。

可以为这三个文件分别指定不同的文件名（参见 设置安全系数分析文件名（model factor-of-safety filename） 命令）。

强度折减属性

使用 设置安全系数分析参数（model factor-of-safety） 时可折减的强度属性在以下各节中描述。

摩尔-库仑材料

如果指定了摩尔-库仑模型（Mohr-Coulomb model）破坏准则，则执行 设置安全系数分析参数（model factor-of-safety） 时，黏聚力 \(c\) 和内摩擦角 \(\phi\) 默认被选入安全系数计算。这些属性的折减方程为

(1)\[c^{\rm trial}\ =\ {1 \over {F^{\rm trial}}}\ c\]
(2)\[\phi^{\rm trial}\ =\ \arctan\biggl({1 \over {F^{\rm trial}}}\tan\phi\biggr)\]

这些强度可与强度折减过程（strength reduction procedure）配合使用。可通过关键字短语 exclude cohesion 或 exclude friction 选择将这些强度从 设置安全系数分析参数（model factor-of-safety） 计算中排除。

抗拉强度 \(\sigma^t\) 也可以通过可选短语 include tension 纳入。抗拉强度的试算属性按与材料摩擦和黏聚力类似的方式计算。抗拉强度的折减方程为

(3)\[\sigma^{t (trial)}\ =\ {1 \over {F^{trial}}}\ \sigma^t\]

遍布节理材料

如果使用遍布节理模型（ubiquitous-joint model），完整材料的强度值 \(c\) 和 \(\phi\)、以及遍布节理的强度值 \(c_j\) 和 \(\phi_j\) 默认被包括在 设置安全系数分析参数（model factor-of-safety） 计算中。抗拉强度 \(\sigma^t\) 和 \(\sigma^t_j\) 也可以通过分别添加关键字短语 include tension 和 include joint-tension 而被选入折减。完整材料的折减方程与公式 (1) 至 (3) 相同，而遍布节理的折减方程为

(4)\[c_j^{trial}\ =\ {1 \over {F^{trial}}}\ c_j\]
(5)\[\phi_j^{trial}\ =\ \arctan\biggl({1 \over {F^{trial}}}\tan\phi_j\biggr)\]
(6)\[\sigma_j^{t (trial)}\ =\ {1 \over {F^{trial}}}\ \sigma_j^t\]

遍布节理黏聚力和摩擦可通过分别为 包含节理黏聚力选项（include joint-cohesion） 和 排除节理摩擦选项（exclude joint-friction） 从安全系数计算中排除。

Hoek-Brown 材料

Hoek-Brown 模型（Hoek-Brown model）支持使用 设置安全系数分析参数（model factor-of-safety） 进行安全系数计算。强度折减是相对于抗剪强度进行的（flag-fos = 0）。

注意，虽然 Hoek-Brown 模型的软化/硬化功能可以在执行安全系数计算之前激活，但在强度折减过程中应将其禁用（通过移除表格属性赋值），因为此时演化参数的值定义不明确。

关于抗剪强度的安全系数， \(\tau\)

Hoek-Brown 准则可以在局部用摩尔-库仑准则近似：

(7)\[\tau = \sigma^{\prime} \tan{\phi_c} + c_c\]

其中表观黏聚力和摩擦角由 \(\sigma_3\) 的局部值表示为

(8)\[\phi_c\ =\ 2 \tan^{-1} \sqrt{N_{\phi_c}}\ -\ 90^\circ\]
(9)\[c_c\ =\ {\sigma^{ucs}_c \over {2\sqrt{N_{\phi_c}}}}\]

其中（压应力为正）若 \(\sigma_3 \ge 0\)：

(10)\[N_{\phi_c}\ =\ 1 + am_b {\Bigl(m_b {\sigma_3 \over \sigma_{ci}} + s \Bigr)}^{a-1}\]
(11)\[\sigma^{ucs}_c =\ \sigma_3 (1 - N_{\phi_c}) + \sigma_{ci} {\Bigl(m_b {\sigma_3 \over \sigma_{ci}} + s \Bigr)}^a\]

并且，若 \(\sigma_3 < 0\)：

(12)\[N_{\phi_c}\ =\ 1 + am_b (s)^{a-1}\]
(13)\[\sigma^{ucs}_c =\ \sigma_{ci} (s)^a\]

采用一种基于强度折减技术的实用方法来评估边坡安全系数：将局部黏聚力 \(c_c\) 和摩擦系数 \(\tan{\phi}_c\) 除以一个系数，直至检测到边坡发生主动破坏。该系数直接适用于最大允许剪应力 \(\tau_{max}\)（见公式 (7)）。边坡临近破坏时的折减系数被定义为基于所提出的（局部强度折减）技术的安全系数。

理论上可以找到与折减后包络线最佳拟合的 Hoek-Brown 型方程（例如参见 Hammah 等 2005），但本模型的特定实现不要求这一步，因为其逻辑依赖于直接使用包络线切线（既然切线已经可用，就无需先定义曲线再求切线——见上文）。此外，所提出的局部强度折减技术提供了一种量化剪切应力破坏容许量的手段，正如人们所预期的那样。在这种情况下，折减系数并不直接作用于模型参数（也没有绝对理由要直接作用）。

关于无侧限抗压强度的安全系数， \(\sigma_{ci}\)

Hoek-Brown 模型（Hoek-Brown model）支持使用 设置安全系数分析参数（model factor-of-safety） 进行另一种安全系数计算；通过设置 flag-fos = 1，折减是相对于无侧限抗压强度进行的。完整无侧限抗压强度被折减系数折减，直至检测到主动破坏，以便与 Li 等（2008）用极限分析得到的简单边坡稳定图进行比较。

接触面（FLAC3D）

通过将 interface include 属性名（propname） 添加到 设置安全系数分析参数（model factor-of-safety），可将接触面强度计入安全系数计算。对于接触面强度值 \(c_i\) 和 \(\phi_i\)，方程为

(14)\[c_i^{trial}\ =\ {1 \over {F^{trial}}}\ c_i\]
(15)\[\phi_i^{trial}\ =\ \arctan\biggl({1 \over {F^{trial}}}\tan\phi_i\biggr)\]

库仑节理（3DEC）

通过用 block contact jmodel assign mohr 指定库仑节理材料，可将节理强度计入安全系数计算。默认情况下，执行 model factor-of-safety 时会包括节理黏聚力和摩擦角。这些属性的强度折减方程为

\[c_i^{trial}\ =\ {1 \over {F^{trial}}}\ c_i\]
\[\phi_i^{trial}\ =\ \arctan\biggl({1 \over {F^{trial}}}\tan\phi_i\biggr)\]

节理强度属性可通过关键字 include/exclude cohesion、friction 包含或排除。

尾注

[1]不平衡力是作用在一个网格点上的净力。该力与周围各网格单元所施加力的绝对平均值之比，称为不平衡力比。不平衡力比的限值可通过 设置安全系数分析参数（model factor-of-safety） 命令的可选关键字 ratio 更改。
