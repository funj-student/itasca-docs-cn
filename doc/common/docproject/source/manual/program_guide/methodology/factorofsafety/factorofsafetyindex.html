安全系数的定义

可对任何相关的问题参数定义“安全系数”指标，方法是取给定条件下该参数的计算值与不可接受结果开始显现时的参数临界值之比。相关的问题参数可以是控制所研究问题的无量纲量（例如稳定数）。边坡稳定的（有量纲）参数示例包括边坡高度、水位、施加荷载和强度属性。

不可接受的结果与“安全”相关（通常取为剪切破坏），但也可以考虑其他情形，例如位移超过给定阈值、收敛超过可接受水平（如隧道开挖中）、倾倒破坏、边坡剥落（循环冻融、风化）等。

按惯例，安全系数指标大于 1 表示稳定状态。因此，如果参数值高于临界值是可接受的（例如材料黏聚力），则安全系数指标取实际值与临界值之比；否则取该比值的倒数（例如边坡高度）。注意，除简单情形外，计算得到的安全系数指标一般不会与其所定义的问题参数呈线性关系。此外，对同一问题采用不同的度量会给出不同的安全系数值。安全系数指标在使用相同指标定义的分析中作比较时最有价值（例如，使用该指标可能得出如下结论：平台更宽的边坡比平台更高的边坡具有更高的指标）。

计算安全系数指标的工作（在定义确定之后）包括确定实际参数值和临界参数值。在最一般的情况下，实际参数值通过直接求解控制问题的场方程和本构方程来评估，这通常用数值方法完成。另一方面，需要求解反边界值问题来估计参数的临界值。原则上，这可以通过试错技术实现，即对一系列参数值进行数值模拟，直至找到临界值。我们把这种一般方法称为“参数折减技术”。任何合适的岩土力学软件（例如有限体积法、有限元法和离散元法软件）均可用于完成涉及各种复杂程度（例如几何形状、材料本构模型、离散裂隙网络、边坡加固、支护系统、力学结构等）的问题。
