数据受限系统的建模

在岩土力学这样数据并不总是可获得的领域，数值建模所使用的方法学应不同于机械工程等领域所用的方法学。[Starfield1988] 提出了一种适用于数据受限系统的建模方法建议。在尝试用 PFC、FLAC3D 或 3DEC 这类数值建模程序进行任何严肃建模之前，应查阅该论文。本质上，该方法承认现场数据（如地应力、材料属性和地质特征）永远不可能被完全了解。当输入数据存在巨大不确定性时，期望模型提供设计数据（如预期位移）是徒劳的。然而，数值模型在提供可能发生于特定物理系统中的机制图景方面仍然有用。模型通过提供一系列因果示例，起到培养设计工程师直觉的作用。模型可以是简单的，其假定数据与已知现场数据和工程判断相一致。构建一个非常庞大而复杂的模型、而它可能与实际情况一样难以理解，是白费力气。

当然，如果有大量的现场数据，这些数据可以纳入一个能够直接给出设计信息的综合模型。然而，更常见的情况是，数据受限模型并不直接产生此类信息，而是提供对可能发生的机制的洞察。然后，设计者可基于这些机制进行简单计算，以估计所关注的参数或稳定性条件。

在某些情况下，可以通过执行一个或多个校准步骤（模拟现有条件并调整模型参数以匹配观测结果），以更具预测性的方式使用数值模型。然后，可以在一定程度上置信地将校准后的模型用于对拟议的未来情景做出预测。
