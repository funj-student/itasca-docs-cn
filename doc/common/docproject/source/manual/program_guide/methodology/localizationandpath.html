局部化、物理失稳与路径依赖

在许多可以用 PFC、3DEC 或 FLAC3D 这类数值建模程序模拟的系统中，解可能沿多条路径之一发展，取决于初始条件相当小的变化。这种现象称为分岔。例如，弹塑性材料的剪切试验可能均匀变形，也可能出现剪切带，即剪应变发生局部化而不是均匀分布。看来，如果数值模型具有足够的自由度（即足够的单元），就应当预期出现局部化。事实上，关于分岔过程的理论工作（例如 [Rudnicki1975] 和 [Vardoulakis1980]）表明，只要剪胀角低于摩擦角，即使材料不发生应变软化，也会形成剪切带。“简单的”摩尔-库仑材料只要有足够的单元来分辨一条或多条局部化带，就总会表现出局部化。应变软化材料更容易产生条带。

有些计算机程序似乎无法再现条带的形成，尽管这种现象在物理上是预期会发生的。然而，Itasca 程序能够让条带在模型中发展和演化，部分原因是它们使用动态运动方程（即，伴随条带形成的动能以符合物理实际的方式释放和耗散）。已有若干论文记录了使用 Itasca 程序 FLAC 模拟剪切带形成（[Cundall1989]、[Cundall1990] 和 [Cundall1991]），可查阅这些文献以了解求解过程的细节。FLAC 处理得不够好的一个方面是剪切带的厚度。实际上，条带厚度由材料的内部特征（如颗粒尺寸）决定，而这些特征并未内置于 FLAC 所用的本构模型中。这个问题在 PFC 中不是主要问题，因为该程序用于在颗粒层面上模拟行为。关于完整材料内软化和局部化效应建模的更多讨论，应查阅 FLAC 手册（[Itasca2008]）。

因此，这里需要一些重要帮助来协调 PFC 版本和 FLAC3D 版本。

涉及混沌、物理失稳和分岔的一个主题是路径依赖。在大多数非线性非弹性系统中，存在无穷多个满足平衡、协调和本构关系的解。除非指定路径，否则物理问题没有“正确”的解。如果不指定路径，则所有可能的解都是正确的。这种情况可能引起建模者和用户之间无休止的争论，特别是当求解过程中某个看似无关的参数（例如阻尼）被认为会影响最终结果时。所有这些解在数值上都是有效的。例如，用低阻尼模拟矿山开挖可能表现出很大的过冲，从而产生很大的最终位移；而高阻尼会消除过冲并给出较小的最终位移。哪一个更符合实际？这取决于路径。如果开挖是通过爆破（即突然）完成的，那么带过冲的解可能是合适的；如果开挖是用镐和铲（即逐渐）完成的，那么第二种情况可能更合适。对于路径依赖起作用的工况，建模应以模仿系统物理演化过程的方式进行。
