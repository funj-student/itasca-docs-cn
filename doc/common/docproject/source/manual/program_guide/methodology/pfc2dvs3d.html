PFC 中的二维模型与三维模型

PFC2D 的“世界”本质上是二维的（即，PFC2D 模型中只存在两个力分量和一个力矩分量，而三维颗粒集合体中存在三个力分量和三个力矩分量）。运动方程或力-位移定律完全不考虑面外力分量和两个面内力矩分量。PFC2D 模型可视为对单位厚度的变半径圆柱体集合体进行模拟。

在二维中建模的优点以及先进行二维建模的建议，在“二维模型与三维模型（2D vs. 3D Models）”主题中讨论。

堆积与孔隙率

PFC2D 计算的孔隙率是基于面积的计算（总空隙面积与总面积之比），而定义三维孔隙率使用的是基于体积的计算（总空隙体积与总体积之比）。对于球形颗粒的任意集合体，二维孔隙率值与三维孔隙率值之间没有明确关系。然而，由于孔隙率是颗粒堆积的一种度量，以下关于二维和三维颗粒堆积的信息突出并解释了某些差异。Deresiewicz（1958）表明，三维中均匀球体所有规则堆积中最密堆积的孔隙率为 0.2595，而二维中均匀圆盘所有规则堆积中最密堆积的孔隙率为 0.0931。在没有压实力作用于集合体的情况下，这些是在不发生颗粒相互贯入时理论上可达到的最低孔隙率值。一般而言，三维集合体中残留的空隙空间比二维集合体多。在真实材料中，孔隙率会更高，因为颗粒在达到这种最优堆积之前就会发生“锁固”。如果已知真实材料中会发生颗粒成拱，那么三维集合体中形成拱的机会比二维集合体多得多。此外，PFC2D 模型假定所有颗粒的形心都对齐在一个平面上——这在三维集合体中不太可能发生。

颗粒集合体的配位数 \(C_n\)（每个颗粒的平均接触数）也是堆积的一个重要特征。在 [Agnolin2007b] 中，作者表明，在刚性颗粒极限下，决定密实、各向同性、摩擦颗粒集合体小应变力学响应的是配位数，而不是孔隙率。[Radjaï2004] 提出，此类集合体的接触网络组构是描述塑性区硬化的一种相关状态变量。[Roux2000] 证明了密实刚性摩擦颗粒集合体配位数的上界（在无超静定性的情况下），一般情形为 \(C_n \leq d(d+1)\)，球形颗粒情形为 \(C_n \leq 2d\)，其中 \(d\) 表示维数。对于无摩擦颗粒，这些不等式变为等式。

二维与三维集合体之间的另一个差异涉及渗透。小颗粒可以容易地透过由较大颗粒构成的三维集合体，但无论颗粒相对尺寸如何，它们永远无法透过密实堆积的 PFC2D 模型。

对于颗粒堆积对行为有显著影响的情况，可能需要使用 PFC3D 程序进行少量三维模拟，以确定获得实测物理响应所需的相关参数，然后在使用 PFC2D 程序进行大量参数研究时使用这些参数。

应力与应变

应力与应变作为连续变量，并不存在于颗粒集合体的每一点上，因为介质是不连续的。因此，采用平均化过程来计算用户定义测量圆内的平均应力和应变率张量。应力的平均化过程（在此处（here）描述）将作用在测量圆内每个颗粒上的两个面内力分量与单位颗粒边界长度上的力联系起来，然后必须将其除以厚度值才能得到应力量。PFC2D 中报告的应力值采用单位厚度。

应变率的平均化过程不涉及关于面外厚度的任何假设。然而，由于二维和三维系统的孔隙率和组构不同，二维集合体的体积应变不同于三维情形。[Hazzard2003] 强调了面外第三维在颗粒材料直剪模拟中的重要性，其中报告三维模型表现出比二维模型更大的宏观内摩擦角。比较二维和三维侧限压缩试验时也观察到类似的趋势（[David2007]）。

大多数基于连续介质的二维程序通过应力与应变之间的本构关系，强制施加平面应力或平面应变条件，以确定三维弹性响应。然而，PFC2D 模型不强制这两种条件中的任何一种。如上所述，面外力分量以及应力和应变根本不在运动方程或力-位移定律中考虑。因此，不存在强制平面应变状态所需的面外约束。

质量属性

PFC2D 中每个球体的质量通过将颗粒视为单位厚度圆柱体来确定。质量根据球体的密度和半径赋予。颗粒质量既影响运动计算（因为圆盘和球体的惯性属性不同），也影响施加到每个颗粒上的重力。
