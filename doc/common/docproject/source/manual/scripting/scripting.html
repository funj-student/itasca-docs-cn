脚本编程

尽管大多数常见操作可通过命令执行，脚本仍是程序的重要方面，使用户能够执行针对特定问题的操作。FLAC3D、PFC 和 3DEC 都通过 FISH 语言提供脚本能力，PFC 和 FLAC3D 还通过 Python 语言提供脚本能力。本节对两者都作了说明。

FISH 是 Itasca 软件专用的嵌入式编程语言，面向非程序员设计。FISH 多年来不断扩充，已成为在 Itasca 软件中进行自定义脚本编写的成熟实用工具。借助 FISH，用户可在建模过程的任意时刻访问模型数据。FISH 在 PFC 中一直广泛用于实现高级算法。

Python 编程语言自 PFC 5.00.20 发布起即嵌入 PFC；在 FLAC3D 中首次引入是在 FLAC3D 6.00。当前 3DEC 实现中未嵌入。Python 是一种开源、面向对象、解释型、交互式的高级编程语言。本程序包含一套科学 Python 发行版，并作了扩展，使用户可从 Python 访问程序模型数据。此外，用户界面中嵌入了 IPython 控制台，提供交互式 Python 控制台。

注意

Python 与 FISH 都可用于与 PFC、3DEC 和 FLAC3D 交互。二者主要区别可概括如下：

  • 与 FISH 不同，Python 采用面向对象的编程风格与模型组件交互。例如在 FISH 中，通过以球指针调用函数（例如 球体半径（ball.radius(bp)），其中 球体指针（bp） 为球指针）来访问球数据。而在 Python 中，球由 Ball 类表示，该类定义了与球交互的方法。例如上述操作在 Python 中写为 b.radius()，其中 b 为 Ball 对象（即 Ball 类的实例）。
  • 与 FISH 不同，Python 全局命名空间不与模型状态关联。给出 new、save 或 restore 命令时，FISH 编程状态被清除、保存或恢复；但 Python 命名空间的状态不因这些操作而改变。这虽可视为 Python 使用上的限制，但也带来了可用一连串保存与恢复操作自动完成批量处理的优势。
  • Python 的优势是易于使用，且本程序随附的科学 Python 环境包含大量功能。自 20 世纪 80 年代问世以来，Python 已成为世界上使用最广泛的编程语言。此外，Python 可通过全球庞大用户社区提供的大量模块进行扩展。
