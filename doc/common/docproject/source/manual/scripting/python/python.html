Python 脚本

Python 编程语言嵌入在 PFC、FLAC3D 和 3DEC 内部。Python 是一种通用编程语言，对科学计算与数值编程有良好支持。Python 已作扩展，使模型可从 Python 程序进行操作。

注意

  • FISH 编程环境仍然可用。
  • Python 的优势在于更快、易于使用，并且具有附加功能。
  • Python 与 FISH 编程环境的一个重要区别是：Python 状态不与模型状态关联，也不保存在存档文件中。给出 新建模型（model new） 或 恢复模型（model restore） 命令时，FISH 编程状态被清除或恢复。Python 状态不受 新建模型（model new） 或 恢复模型（model restore） 命令影响，也不保存在存档文件中。
  • 给出命令 python-reset-state false 可改变该行为，使 Python 状态不被 model new 或 model restore 命令清除。此处的教程和示例都假定已给出该命令，且 Python 状态在调用 model new 或 model restore 命令后仍然保留。
