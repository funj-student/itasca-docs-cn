裂隙

class itasca.dfn.fracture.Fracture
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
aperture() → float.

获取裂隙开度。

area() → float.

获取裂隙面积。

contact_count(all=False, type=None) → int.

获取与该裂隙关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。可选 type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若可选关键字参数 all 为 True，则计数包含虚拟接触。

contacts(all=False, type=None) → Contact 对象的元组。

获取与该裂隙关联的接触元组。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

delete() → None.

删除此裂隙。

dfn() → DFN 对象。

获取该裂隙所属的 dfn。

diameter() → float.

获取裂隙直径。

dip() → float.

获取裂隙倾角。

dipdir() → float.

获取裂隙倾向。

extra(slot: int) → any.

获取给定槽位中的裂隙额外数据。

group([slot: str]) → str.

获取给定槽位中的裂隙组名。

group_remove(group_name: str) → bool.

从该裂隙的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该裂隙属于哪些组的字典。字典的键为槽位名，值为组名。

has_prop(property_name: str) → bool.

若该裂隙具有给定表面性质则返回 True。

id() → int.

获取裂隙 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该裂隙是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

intersections(DFN object) → Intersection 对象的元组。

获取与该裂隙的交线。可指定可选 DFN 对象，以把交线限于属于该 dfn 的裂隙。

intersects(Fracture object) → 布尔值。

获取表示该裂隙与给定裂隙是否相交的布尔值。

isdisk() → bool.

获取裂隙圆盘状态。

normal() → vec.

获取裂隙法向（向量）。

normal_x() → float.

获取裂隙法向的 x 分量。

normal_y() → float.

获取裂隙法向的 y 分量。

normal_z() → float.

获取裂隙法向的 z 分量。

point_near(value: vec) → vec.

获取裂隙上距给定点最近的点（向量）。

pos() → vec.

获取裂隙位置（向量）。

pos_x() → float.

获取裂隙位置的 x 分量。

pos_y() → float.

获取裂隙位置的 y 分量。

pos_z() → float.

获取裂隙位置的 z 分量。

prop(property_name: str) → any.

获取该裂隙某个表面性质的取值。

props() → dict {str: any}.

获取该裂隙所有表面性质的字典。

set_aperture(value: float) → None.

设置裂隙开度。

set_area(value: float) → None.

设置裂隙面积。

set_diameter(value: float) → None.

设置裂隙直径。

set_dip(value: float) → None.

设置裂隙倾角。

set_dipdir(value: float) → None.

设置裂隙倾向。

set_extra(slot: int, value: any) → None.

设置给定槽位中的裂隙额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的裂隙组名。

set_normal(value: vec) → None.

设置裂隙法向（向量）。

set_normal_x(value: float) → None.

设置裂隙法向的 x 分量。

set_normal_y(value: float) → None.

设置裂隙法向的 y 分量。

set_normal_z(value: float) → None.

设置裂隙法向的 z 分量。

set_pos(value: vec) → None.

设置裂隙位置（向量）。

set_pos_x(value: float) → None.

设置裂隙位置的 x 分量。

set_pos_y(value: float) → None.

设置裂隙位置的 y 分量。

set_pos_z(value: float) → None.

设置裂隙位置的 z 分量。

set_prop(property_name: str, value: any) → None.

设置该裂隙的一个表面性质。

valid() → bool.

若该裂隙为活动对象则返回 True。

vertices() → Vertex 对象的元组。

获取该裂隙的顶点。
