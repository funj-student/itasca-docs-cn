不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。

group([slot: str]) → str.

获取给定槽位中的子接触组名。

group_remove(group_name: str) → bool.

从该子接触的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该子接触属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取子接触 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该子接触是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取该子接触的索引（偏移）。

is_excavated() → bool.

pos_z() → float.

pp() → float.

prop(str) → float.
