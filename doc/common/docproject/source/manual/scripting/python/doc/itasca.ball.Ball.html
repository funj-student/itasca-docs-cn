球体

class itasca.ball.Ball
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
contact_count(all=False, type=None) → int.

获取与该球关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。可选 type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若可选关键字参数 all 为 True，则计数包含虚拟接触。

contacts([piece: ball, ]all=False, type=None) → Contact 对象的元组。

获取与该球关联的接触元组。可包含一个可选参数，即片体对象（Ball、Pebble 或 Facet）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。
