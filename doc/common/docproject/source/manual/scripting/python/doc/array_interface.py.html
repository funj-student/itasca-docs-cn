使用 PFC 与 NumPy 的数组式编程

还提供了另一种基于 NumPy 数组的 PFC 接口。

数组接口不是逐个处理 Ball 对象，而是同时处理所有球的属性与性质。

注意

NumPy 是 Python 的一个扩展，定义了强大的数组对象和许多有用的数值运算。使用 NumPy 和数组式编程比在 Python 中直接用循环快得多。其编程风格不同于面向对象接口所定义的风格。

关于 NumPy 的更多信息见：NumPy 官网（http://numpy.org）

import itasca as it

it.command ("python-reset-state false")

from itasca import ballarray as ba

import numpy as np

首先，我们导入 itasca、ballarray 和 numpy 模块。注意 ballarray 模块是 itasca 模块的子模块。为减少输入量，我们以简写名导入这些模块。

接下来，我们像前面一样创建一个简单模型，

dim = 2.5e-2

rad = dim / 20.0

it.command("""

model new

model large-strain on

model domain extent -5e-2 6e-2 -6e-2 5e-2 -5e-2 5e-2

contact cmat default model linear property kn 1e1 dp_nratio 0.2

ball generate cubic box -{xdim} {xdim} -{ydim} {ydim} -{xdim} {xdim} rad {rad}

ball attribute dens 2600

""".format(xdim=dim-rad, ydim=2*dim-rad, rad=rad))

标量数组

现在我们调用 ballarray 模块中定义的 radius 函数。

radii = ba.radius()

radii
output:
[ 0.00125  0.00125  0.00125 ...,  0.00125  0.00125  0.00125]

注意

在终端中打印大数组时，只显示数组的开头和结尾。省略号表示中间的间隔。

变量 radii 是所有球半径组成的数组。接下来我们检验它确实是数组，并检查其形状是否正确。

assert type(radii) is np.ndarray

print (radii.shape)

print (it.ball.count(),)
output:
(16000,)
16000

我们把球半径缩小 75% 并更新半径值。

  • 数组接口中以 set_ 开头的方法用于把数值发回 PFC。
  • 仅仅修改 radius 数组只会改变我们的数据副本。
  • 用于设置模型数值的数组必须具有正确的形状。此处的数组必须是一维数组，其长度等于球的数量。
radii *= 0.75

ba.set_radius(radii)

radii = ba.radius()

radii
output:
[ 0.0009375  0.0009375  0.0009375 ...,  0.0009375  0.0009375  0.0009375]

多维数组

这里我们定义一个变量 positions，其中包含球位置的多维数组。

positions = ba.pos()

positions
output:
[[-0.02375 -0.04875 -0.02375]
 [-0.02125 -0.04875 -0.02375]
 [-0.01875 -0.04875 -0.02375]
 ...,
 [ 0.01875  0.04875  0.02375]
 [ 0.02125  0.04875  0.02375]
 [ 0.02375  0.04875  0.02375]]

作为示例，我们对每个球施加 5e-3 N 的力，方向指向原点。原点位于模型中部，因此力向量指向内部。首先定义一个新数组 force

force = -5e-3 * (positions.T/np.linalg.norm(positions,axis=1)).T

force
output:
[[ 0.0020059   0.00411737  0.0020059 ]
 [ 0.00182427  0.00418509  0.00203889]
 [ 0.00163391  0.00424817  0.00206962]
 ...,
 [-0.00163391 -0.00424817 -0.00206962]
 [-0.00182427 -0.00418509 -0.00203889]
 [-0.0020059  -0.00411737 -0.0020059 ]]

然后使用 ballarray 接口把它设为施加到每个球上的力。

ba.set_force_app(force)

下图显示该力沿指向原点的方向施加到每个颗粒上。

获取每个分量方向各自的（一维）数组通常很有用。

x, y, z = positions.T

y
output:
[-0.04875 -0.04875 -0.04875 ...,  0.04875  0.04875  0.04875]

注意

由 x、y 和 z 引用的数组是 数组视图，即它们是对 positions 变量中数据的引用。修改 x 会改变变量 positions. 中的取值。这是一种避免复制的优化，但可能造成混淆。

NumPy 数组支持比较运算符，其返回 掩码数组，

y>0
output:
[False False False ...,  True  True  True]

它们是 True 或 False 值组成的数组。

掩码数组可用于赋值。在下例中，我们把正 y 半空间中所有球的半径恢复为原始尺寸。

radii[y>0] /= 0.75

ba.set_radius(radii)

下图显示更新后的球半径。


球的创建

ballarray 模块还提供一个 create 方法，可用于在模型中快速创建球。该方法以标量的一维数组作为第一个参数指定半径，以标量的{二维（二维中）；三维（三维中）}数组作为第二个参数指定位置。该函数还接受可选参数，用于为所创建的球指定属性与性质。这些可选参数接受标量或维数一致的数组。

例如，以下各行创建 10 万个半径随机、位置随机的球

from vec import vec



nballs = 100000

rmin = 8.0e-4

rmax = 1.2e-3

dom_lo = vec((-5e-2,-6e-2,-5e-2))

dom_hi = vec(( 6e-2, 5e-2, 5e-2))



brad = rmin + np.random.rand(nballs) *(rmax-rmin)

bpos = dom_lo + np.random.rand(nballs,3) *(dom_hi-dom_lo)



ba.create(brad,bpos)

注意，create 方法只是使用输入的半径和位置，并不检查球是否重叠。

以下各行演示如何同时指定可选参数，此处为密度和局部阻尼系数。

it.command("ball delete")

ba.create(brad,bpos,density=1000.0,damp=0.7)

上一行中，密度和阻尼都以常数标量值指定。也可使用形状一致的数组，如下文所示：密度以一维数组指定。

bdens = np.full_like(brad,1000.0)

x,y,z = bpos.T

bdens[x<0] *= 2.0

it.command("ball delete")

ba.create(brad,bpos,density=bdens,damp=0.7)

性质也可通过 props 可选参数指定，该参数要求一个字典结构，如下文所示。

it.command("ball delete")

ba.create(brad,bpos,density=bdens,damp=0.7,props={'kn':1e4,'ks':1e4})



it.command("ball delete")

kn = np.full_like(brad,1.0e4)

kn[z<0] = 2e4

ba.create(brad,bpos,density=bdens,damp=0.7,props={'kn':kn,'ks':1e4,'myprop':'george'})
