DFN

class itasca.dfn.DFN
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
center_density(lower=domain lower bound, upper=domain upper bound) → 浮点数。

获取裂隙中心密度。裂隙中心密度定义为在指定区域内测得的{二维中 P20 值；三维中 P30 值}。{二维中 P20；三维中 P30} 是单位面积（体积）内指定区域中的裂隙中心数量。

clone_fracture(Fracture object) → 裂隙对象。

克隆该裂隙，在 dfn 中创建一条新裂隙。该裂隙可来自任意 dfn。

contacts(all=False, type=None) → Contact 对象的元组。

获取与该 dfn 中裂隙关联的接触元组。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

create_fracture(pos=origin, size=0, dip=0, dipdir=0 (3D ONLY), id=0, vertices=array) → 裂隙对象。

创建一条裂隙并将其添加到该 dfn。三维中可创建圆盘状裂隙，其中 size 为裂隙直径，pos 为裂隙中心，dip/dipdir 分别为倾角和倾向（度）。二维中可创建线段裂隙，其中 size 为裂隙长度，pos 为中心，dip 为裂隙倾角（度）。否则可指定若干顶点（二维中 2 个；三维中 3 个或更多）来勾勒裂隙顶点。

delete() → None.

删除此 DFN。

density(lower=domain lower bound, upper=domain upper bound) → 浮点数。

获取裂隙质量密度。裂隙质量密度定义为在指定区域内测得的{二维中 P21 值；三维中 P32 值}。{二维中 P21；三维中 P32} 是单位面积（体积）内指定区域中的累积裂隙长度（表面积）。

dominance() → int.

获取 DFN 主导值。

fracture_count() → int.

获取该 DFN 中的裂隙数量。

fracture_near(point: vec, radius=0.0) → 裂隙对象。

查找距某点最近的裂隙。若可选关键字参数 radius 非零，则只在该半径内搜索。

fractures() → 裂隙迭代器对象。

获取裂隙迭代器对象。

fractures_inbox(lower_bound: vec, upper_bound: vec, intersect=True) → 裂隙对象的元组。

获取包围盒与某盒体相交的裂隙元组。包围盒是该裂隙的轴对齐包围盒。若可选关键字参数 intersect 为 False，则只返回完全落在盒内的裂隙。只搜索属于该 DFN 的裂隙。

id() → int.

获取 dfn ID。

name() → string.

获取 dfn 名称。

p10(pt1=origin, pt2=origin) → float.

获取沿从 pt1 到 pt2 的直线的 P10，即单位长度裂隙密度。

percolation(lower=domain lower bound, upper=domain upper bound) → 浮点数。

获取裂隙渗流。裂隙渗流在区域内测量，定义为{二维中单位面积内裂隙长度平方之和；三维中单位体积内 pi^2 (area/pi)^(1.5) 之和，其中 area 为裂隙面积}。

set_dominance(value: int) → None.

设置 DFN 主导值。

set_prop(property_name: str, value: any) → None.

为该 dfn 的所有裂隙设置某个表面性质。

template() → DFN 模板对象。

获取用于创建该 DFN 的模板。

valid() → bool.

若该 dfn 为活动对象则返回 True。
