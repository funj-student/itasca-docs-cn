itasca.clump

用于处理 Itasca 刚性簇的函数与类。

Functions

itasca.clump.count() → int.

获取刚性簇数量。

itasca.clump.energies() → dict {str: float}.

以字符串键、浮点值的字典形式获取刚性簇总能量贡献。

itasca.clump.energy(energy_name: str) → float.

获取刚性簇的总能量贡献。这是所有刚性簇中名为 energy_name 的能量之和（见 set energy 命令）。可用的能量有：“energy-body”、“energy-damp”和“energy-kinetic”。

itasca.clump.find(id: int) → Clump 对象。

获取具有给定 ID 号的 Clump 对象。

itasca.clump.inbox(lower_bound: vec, upper_bound: vec, intersect=True) → Clump 对象的元组。

获取包围盒与某盒体相交的刚性簇元组。包围盒是该刚性簇的轴对齐包围盒。若可选关键字参数 intersect 为 False，则只返回位置落在盒内的刚性簇。

itasca.clump.list() → Clump 对象迭代器。

获取刚性簇迭代器对象。

itasca.clump.maxid() → int.

获取最大刚性簇 ID。

itasca.clump.near(point: vec, radius=0.0) → Clump 对象。

查找距某点最近的刚性簇。若可选关键字参数 radius 非零，则只在该半径内搜索。
