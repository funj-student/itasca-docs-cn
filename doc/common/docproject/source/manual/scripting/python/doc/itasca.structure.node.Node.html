节点

class itasca.structure.node.Node
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
acc_global() → (translational: vec3, rotational: vec3).

获取以全局坐标系表示的结构节点加速度。

acc_local() → (translational: vec3, rotational: vec3).

获取以局部坐标系表示的结构节点加速度。

apply() → (translational: vec3, rotational: vec3).

获取以全局坐标系表示的结构节点平动与转动施加力。

apply_local() → bool.

获取表示广义施加力的坐标系是否为局部系。

component_id() → int.

获取节点组件 ID。

convergence() → float.

返回网格点收敛值，定义为当前局部力比（由 \(ratio\) 方法给出）与目标力比（\(ratio.target\)）之比。因此，1 或更小的值视为“收敛”。

damp_local() → float.

获取结构的局部阻尼因子。

disp_global() → (translational: vec3, rotational: vec3).

获取以全局系表示的结构节点位移。

disp_local() → (translational: vec3, rotational: vec3).

获取以局部系表示的结构节点位移。

extra(slot: int) → any.

获取给定槽位中的节点额外数据。

fix() → 整数的元组。

获取以节点局部系表示的速度约束标志。返回值 {1, 2, 3} 分别表示自由、固定或从属于目标速度。从属条件由刚性连接条件产生；从属的自由度不能被固定。

fix_local() → bool.

获取局部坐标系约束的布尔标志。True 表示固定节点局部系，False 表示自由节点局部系。

force_unbal_global() → (translational: vec3, rotational: vec3).

获取以全局系表示的结构节点不平衡力。

force_unbal_local() → (translational: vec3, rotational: vec3).

获取以局部系表示的结构节点不平衡力。

group([slot: str]) → str.

获取给定槽位中的节点组名。

group_remove(group_name: str) → bool.

从节点的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该节点属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取节点结构单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该节点是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

links() → Link 对象的元组。

获取与该节点关联的连接对象。每侧返回一个连接。若未找到连接则返回 None。

local_system() → tens3.

获取结构节点的局部坐标系。

mark() → bool.

获取标记标志。注意，结构单元逻辑可能在命令处理、循环和绘图过程中修改该标志。

mass_added() → (translational: vec3, rotational: vec3).

获取节点局部系中各自由度除惯性质量外的附加质量。

mass_local() → (translational: vec3, rotational: vec3).

获取节点局部系中各自由度的质量。

pos() → vec3.

获取该结构单元节点的当前位置。

pos_reference() → vec3.

获取该结构单元节点的参考位置。

ratio() → float.

获取局部网格点力学收敛比，即不平衡力与施加到该节点的力之比。

ratio_target() → float.

获取节点中的目标力学力比。默认值为 1e-4。低于该值的局部力比（见 \(ratio\) 方法）视为收敛。另见 \(convergence\) 方法。

resultant() → 浮点数元组（Mx、My、Mxy、Nx、Ny、Nxy）。

获取与该节点相连单元最后计算的应力合力。注意，\(Q_x\) 和 \(Q_{y1}\) 项在节点处无效，因为它们在单元上为常数。应力合力在节点表面系中表示；见 恢复壳单元表面命令（structure shell recover surface）、恢复土工格栅单元表面命令（structure geogrid recover surface） 和 恢复衬砌单元表面命令（structure liner recover surface） 命令。

set_apply(comp: int, force: float) → None.

设置以全局坐标系表示的结构节点平动与转动施加力的某个分量。分量 0、1、2 为平动，3、4、5 为转动。

set_damp_local(float) → None.

设置结构的局部阻尼因子。

set_extra(slot: int, value: any) → None.

设置给定槽位中的节点额外数据。

set_fix_local(bool) → None.

设置局部坐标系约束的布尔标志。True 表示固定节点局部系，False 表示自由节点局部系。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的节点组名。

set_mark(bool) → None.

设置标记标志。注意，结构单元逻辑可能在命令处理、循环和绘图过程中修改该标志。

set_mass_added(comp: int, mass: float) → (translational: vec3, rotational: vec3).

获取节点局部系中各自由度除惯性质量外的附加质量。

set_ratio_target(ratio: float) → None.

设置节点中的目标力学力比。默认值为 1e-4。低于该值的局部力比（见 \(ratio\) 方法）视为收敛。另见 \(convergence\) 方法。

set_surface_xdir(orientation: vec3) → bool.

设置表面体系的方位，使 x 方向与表面向量 v 在法向平面（由 z 方向定义）上的投影对齐。该操作只能对具有有效表面体系的节点执行（以确保 z 方向始终与至少一个使用该节点的壳类结构单元的平均法向一致）。返回 \(True\) 表示成功，\(False\) 表示失败。

set_temp_increment(dtemp: float) → None.

设置下一个时步将施加到结构节点的温度增量，使与其相连的单元因热膨胀而产生应力变化。施加热膨胀应力后，每个时步结束时该值被清零。

stiff_local() → 浮点数的元组。

获取以局部系表示的结构节点刚度。返回长度为 6 的元组，先给出平动刚度，随后给出转动刚度。

surface_system() → tens3.

获取结构节点的表面坐标系。

surface_valid() → bool.

获取表面体系有效性的布尔标志；\(True\) 表示有效，\(False\) 表示无效。可通过执行结构恢复命令使表面体系有效。

temp_increment() → float.

获取下一个时步将施加到结构节点的温度增量，使与其相连的单元因热膨胀而产生应力变化。施加热膨胀应力后，每个时步结束时该值被清零。

valid() → bool.

若该节点为活动对象则返回 True。

vel_global() → (translational: vec3, rotational: vec3).

获取以全局系表示的结构节点速度。

vel_local() → (translational: vec3, rotational: vec3).

获取以局部系表示的结构节点速度。
