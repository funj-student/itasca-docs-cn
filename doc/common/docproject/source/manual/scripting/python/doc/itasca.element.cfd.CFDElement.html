CFDElement

class itasca.element.cfd.CFDElement
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
adjacent_to_face(index) → CFD 单元对象。

获取与标识符为 index 的面相邻的单元。

density() → float.

获取 CFD 单元流体密度。

drag_force() → vec.

获取 CFD 单元流体阻力（向量）。

drag_force_x() → float.

获取 CFD 单元流体阻力的 x 分量。

drag_force_y() → float.

获取 CFD 单元流体阻力的 y 分量。

drag_force_z() → float.

获取 CFD 单元流体阻力的 z 分量。

extra(slot: int) → any.

获取给定槽位中的 CFD 单元额外数据。

group([slot: str]) → str.

获取给定槽位中的 CFD 单元组名。

group_remove(group_name: str) → bool.

从 CFD 单元的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该 CFD 单元属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取 CFD 单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该 CFD 单元是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

node_pos(index) → vec.

获取标识符为 index 的节点位置（向量）。

node_pos_x(index) → float.

获取标识符为 index 的节点位置的 x 分量。

node_pos_y(index) → float.

获取标识符为 index 的节点位置的 y 分量。

node_pos_z(index) → float.

获取标识符为 index 的节点位置的 z 分量。

porosity() → float.

获取 CFD 单元流体孔隙率。

pos() → vec.

获取 CFD 单元位置（向量）。

pos_x() → float.

获取 CFD 单元位置的 x 分量。

pos_y() → float.

获取 CFD 单元位置的 y 分量。

pos_z() → float.

获取 CFD 单元位置的 z 分量。

pres_grad() → vec.

获取 CFD 单元流体压力梯度（向量）。

pres_grad_x() → float.

获取 CFD 单元流体压力梯度的 x 分量。

pres_grad_y() → float.

获取 CFD 单元流体压力梯度的 y 分量。

pres_grad_z() → float.

获取 CFD 单元流体压力梯度的 z 分量。

pressure() → float.

获取 CFD 单元的流体压力。

set_density(value: float) → None.

设置 CFD 单元流体密度。

set_drag_force(value: vec) → None.

设置 CFD 单元流体阻力（向量）。

set_drag_force_x(value: float) → None.

设置 CFD 单元流体阻力的 x 分量。

set_drag_force_y(value: float) → None.

设置 CFD 单元流体阻力的 y 分量。

set_drag_force_z(value: float) → None.

设置 CFD 单元流体阻力的 z 分量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的 CFD 单元额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的 CFD 单元组名。

set_porosity(value: float) → None.

设置 CFD 单元流体孔隙率。

set_pres_grad(value: vec) → None.

设置 CFD 单元流体压力梯度（向量）。

set_pres_grad_x(value: float) → None.

设置 CFD 单元流体压力梯度的 x 分量。

set_pres_grad_y(value: float) → None.

设置 CFD 单元流体压力梯度的 y 分量。

set_pres_grad_z(value: float) → None.

设置 CFD 单元流体压力梯度的 z 分量。

set_pressure(value: float) → None.

设置 CFD 单元的流体压力。

set_vel(value: vec) → None.

设置 CFD 单元流体速度（向量）。

set_vel_x(value: float) → None.

设置 CFD 单元流体速度的 x 分量。

set_vel_y(value: float) → None.

设置 CFD 单元流体速度的 y 分量。

set_vel_z(value: float) → None.

设置 CFD 单元流体速度的 z 分量。

set_viscosity(value: float) → None.

设置 CFD 单元流体黏度。

share_a_face() → CFD 单元对象的元组。

获取与该单元共面的所有单元。

share_a_node() → CFD 单元对象的元组。

获取与该单元共节点的所有单元。

share_an_edge() → CFD 单元对象的元组。

获取与该单元共边的所有单元。

valid() → bool.

若该 CFD 单元为活动对象则返回 True。

vel() → vec.

获取 CFD 单元流体速度（向量）。

vel_x() → float.

获取 CFD 单元流体速度的 x 分量。

vel_y() → float.

获取 CFD 单元流体速度的 y 分量。

vel_z() → float.

获取 CFD 单元流体速度的 z 分量。

viscosity() → float.

获取 CFD 单元流体黏度。

vol() → float.

获取 CFD 单元体积。
