在 3DEC 中使用 Python

本节给出用 Python 程序与 3DEC 交互的示例。本例中我们创建一个简单 3DEC 模型，并用 Python 施加边界条件、考察模型响应。

首先我们用 import 语句导入 c itasca 模块。itasca 模块定义 Python 与 3DEC 之间的交互。我们以简写名 it 导入 itasca 模块。

import itasca as it
it.command("python-reset-state false")

我们将创建一些块体以展示 Python 脚本的特性。用 itasca.command 函数发出一系列 3DEC 命令。在 Python 程序开头应始终给出命令 python-reset-state false。若未给出该命令，则当通过 新建模型（model new） 或 恢复模型（model restore） 命令重置 3DEC 模型状态时，Python 变量与函数会被删除。

这些命令创建一个块体，然后把它细分为小块体。三引号用于定义多行字符串。

it.command("""
model new
model large-strain off
block create brick 0 10
block densify segment 5
block cut joint-set o 5 5 5 dip 20 d-d 90
""")

处理 3DEC 块体

可用 itasca.block.count 函数获取块体数量。把以下表达式输入 IPython 终端，屏幕上会打印出数字 160。

it.block.count()

output:

160

itasca 模块定义了用于与 3DEC 模型交互的函数和类。其中一些函数返回对象，

b = it.block.find(1)
print(b)

output:

<itasca.block.Block object at 0x000001BB82260288, ID : 1>

此处 itasca.block.find(1) 返回 id 为 1 的块体的 Block 对象。该对象被赋给 Python 变量 b。多数 3DEC 模型项都是这样的对象（类的实例）。Block 对象有许多方法，例如

b.pos()

output:

vec3(( 9.000000e+00, 9.000000e+00, 9.000000e+00 ))

变量 b 是一个 Block 对象，表示单个 3DEC 块体。pos（区块位置（itasca.block.Block.pos））是该对象的一个方法，返回块体形心。

注意

区块位置（itasca.block.Block.pos） 方法返回以 vec3 对象表示的长度为 3 的向量。关于 vec3 对象以及用 Python 处理向量的更多信息，见 c vec 模块。

print("block", b.id(), "at", b.pos())

Python 中用 for 语句遍历事物的序列，

volume_sum = 0.0
for b in it.block.list():
    volume_sum += b.vol()

在本例中，用 for 语句遍历所有 3DEC 块体。每次循环中变量 b 是另一个 Block 对象。最后，我们检验各块体体积之和是否符合预期。

print(volume_sum)
assert abs(volume_sum - 1000.0)<1e-9

output:

999.9999999999998

我们来查找靠近模型中心的块体

b = it.block.near((5,5,5))

并用 pos 方法确认其位置。

b.pos()

output:

vec3(( 5.121323e+00, 5.000000e+00, 5.477921e+00 ))

处理 3DEC 网格单元

我们在块体内生成网格单元，并在可变形块体之间生成子接触。随后为网格单元和子接触设置本构模型与若干性质。最后在模型中初始化地应力。

it.command("""
block zone generate edgelength 1.0
block zone cmodel assign elastic
block zone property density 2950 young 12e9 poisson 0.25
""")

props 方法（区块单元属性列表（itasca.block.zone.Zone.props））以 Python 字典对象返回网格单元本构模型性质。字典的键为性质名，值为性质取值。

z = it.block.zone.find(1)
print(z)
z.props()

output:

<itasca.block.zone.Zone object at 0x000001BB82260288, ID : 1>

要访问字典的各个部分，需用 [ ] 括号配合字符串键，

z.props()['bulk']

output:

8000000000.0

或可使用 prop 方法（区块单元属性（itasca.block.zone.Zone.prop））。

z.prop('shear')

output:

4800000000.0

网格单元性质可用 set_prop 方法（设置区块单元属性（itasca.block.zone.Zone.set_prop））设置。

z.set_prop('bulk', 8.5e9)
print(z.prop('bulk'))

output:

8500000000.0

Python 与 3DEC 网格单元有两处交互：

  1. 属于 c itasca.block.zone Python 模块的函数，以及
  2. 单个 c 网格单元（Zone） 对象的方法。

用 Python 术语说，c itasca.block.zone 是 c itasca.block 模块的子模块，而 c 网格单元（Zone） 是定义在 c itasca.block.zone 模块中的类。为简洁起见，我们常用简写名 it 导入 itasca 模块。上文中，itasca.block.zone.count、itasca.block.zone.list 和 itasca.block.zone.find 是定义在 c itasca.block.zone 模块中的函数，而 区块单元 z 向位置（itasca.block.zone.Zone.pos_z） 和 itasca.block.zone.Zone.vol_z 是 c 网格单元（Zone） 对象的方法调用。

  • c itasca 给出 itasca 模块函数与类的完整列表。
  • c itasca.block.zone 给出 itasca.block.zone 模块函数的完整列表。
  • c 网格单元（Zone） 给出 Zone 对象方法的完整列表。

处理 3DEC 顶点

类似地，Python 可以通过以下方式与 3DEC 网格点交互

  • c itasca.block.gridpoint 模块函数以及
  • c 网格点（Gridpoint） 对象的方法。
gp = it.block.gridpoint.near((2,2,2))
print(gp.pos())

output:

vec3(( 2.000000e+00, 2.000000e+00, 2.000000e+00 ))

与块体和网格单元一样，我们可以用 Python 的 for 语句遍历所有 3DEC 网格点。

gp_mass = 0
for gp in it.block.gridpoint.list():
    gp_mass += gp.mass()

z_mass = 0
for z in it.block.zone.list():
    z_mass += z.mass()
print(gp_mass, z_mass)

output:

0.0 0.0

处理接触与子接触

it.command("""
block contact gen-sub
block contact jmodel assign mohr
block contact property stiffness-normal 1e9 stiffness-shear 1e9 coh 1e20 fric 35
""")


"""
Similarly, the :py:func:`it.block.contact.find()
<pyapi_itasca_block_contact_find>` and :py:func:`it.block.contact.near()
<pyapi_itasca_block_contact_near>` functions can be used to get specific
contact.

"""

c1 = it.block.contact.find(1)
c2 = it.block.contact.near((0,2,2))

print(c1)
print(c2)

output:

<itasca.block.contact.Contact object at 0x000001BB832B47B0, ID : 1>
<itasca.block.contact.Contact object at 0x000001BB822603A8, ID : 475>

我们获取与某个接触关联的所有子接触的列表

for cx in c1.subcontacts():
     print("subcontact ",cx.id(), "at", cx.pos())

额外变量

3DEC 的块体、网格单元、网格点及其他 Itasca 模型对象都有额外变量，从而可把某些数据关联到模型对象。Python 程序可用所有对象类型都定义的 extra 和 set_extra 方法读写额外变量。

b.set_extra(1, 1.23)
b.set_extra(2, "a text string")

print(b.extra(1))
print(b.extra(2))

output:

1.23
a text string

z.set_extra(1, z.vol())
z.set_extra(2, z.model())

print(z.extra(1))
print(z.extra(2))

output:

0.19669147144483143
Isotropic Elastic

gp.set_extra(1, gp.pos())
gp.set_extra(2, 86856527)

print(gp.extra(1))
print(gp.extra(2))

output:

vec3(( 6.826550e+00, 6.560625e+00, 2.581529e+00 ))
86856527

Python 中索引通常从 0 开始。额外变量的索引是例外，以便 Python 与 Itasca 软件 GUI 良好配合。额外变量保存在模型存档文件中，这是把 Python 数据关联到 Itasca 模型状态的一种方式。

使用 3DEC 组

组用于创建 3DEC 模型对象的列表。这常用于设置边界条件或对模型的特定部分施加材料性质。此处我们用 3DEC 命令创建两组块体，分别表示模型的上部和下部。

it.command("""
block group "lower" range plane o 5 5 5 dip 20 d-d 90 above
block group "upper" range plane o 5 5 5 dip 20 d-d 90 below
block join range group "lower"
block join range group "upper"
""")

可用 Block.group 方法（区块分组（itasca.block.Block.group））查询块体是否属于某个组。

lower_blocks, upper_blocks = 0, 0

for b in it.block.list():
    if b.group("default") == "lower":
        lower_blocks += 1
    elif b.group("default") == "upper":
        upper_blocks += 1

print(lower_blocks, upper_blocks)

output:

80 80

接下来我们对模型进行循环计算，并考察模型对该荷载的响应。

it.command("""
model gravity 0 0 -10
block face apply stress-zz -1e6 range position-x 10
block gridpoint apply velocity (0.,0.,0.) range position-z 0
model save "before_cycling"
model solve
""")


gp_top_middle = it.block.gridpoint.near((5,5,10))
gp_middle = it.block.gridpoint.near((5,5,5))
print(gp_top_middle.disp())
print(gp_middle.disp())

output:

vec3(( 4.449410e-05, 7.152149e-08, -2.622171e-04 ))
vec3(( -7.172716e-07, 1.519721e-07, -2.311518e-04 ))

central_zone = it.block.zone.near((5,5,5))
stress = central_zone.stress()
strain = central_zone.strain_inc()

print(stress)
print()
print(strain)

output:

stens3([[ -7.954626e+03, -1.565704e+02, 3.726855e+03 ],
        [               -5.499364e+03, 4.192065e+03 ],
        [ sym.                        -1.854032e+05 ]])

stens3([[ 3.314251e-06, -1.630942e-08, 3.882140e-07 ],
        [               3.570008e-06, 4.366735e-07 ],
        [ sym.                        -1.516998e-05 ]])

注意

stress（区块单元应力（itasca.block.zone.Zone.stress））和 strain（区块单元应变增量（itasca.block.zone.Zone.strain_inc））这两个网格单元方法以 stens3 对象返回对称张量。关于对称张量对象以及用 Python 处理张量的更多信息，见 stens3 类型（vec 模块 stens3 类型（vec.stens3））。

进行参数研究

Python 程序及其变量与 3DEC 模型状态无关（前提是已给出命令 python-reset-state false）。这便于以程序化方式开展参数研究。下例用 4 个不同的杨氏模量运行同一模型，并打印模型顶部中心的竖向位移。

for modulus in [6e9, 8e9, 10e9, 12e9]:
    it.command("""
    model restore 'before_cycling'
    block zone prop young {}
    model solve
    """.format(modulus))
    vertical_disp = it.block.gridpoint.near((5,5,10)).disp_z()
    result = "Modulus: {:.01e} Pa, vertical displacement: {:.03e}"
    print(result.format(modulus, vertical_disp))

output:

Modulus: 6.0e+09 Pa, vertical displacement: -3.846e-04
Modulus: 8.0e+09 Pa, vertical displacement: -3.235e-04
Modulus: 1.0e+10 Pa, vertical displacement: -2.867e-04
Modulus: 1.2e+10 Pa, vertical displacement: -2.622e-04

处理 3DEC 错误

借助 Python，可用内置的异常处理机制捕获并处理错误。Python 中的运行时错误称为异常。可用 try、except 块捕获并处理异常。

try:
    it.command("""
    block zone prop young 0
    model solve
    """)
except Exception as data:
    print("an error occurred", data)

print("Python program execution continues...")

it.command("block zone prop young 8e9")  # 修正该问题

output:

an error occurred moduli have not been set - cannot cycle
    While processing line 1 of source Python interpreter.
Python program execution continues...

Python 回调函数

Python 函数可在 3DEC 计算序列的特定位置运行。itasca.set_callback 函数注册在循环期间调用的 Python 函数，而 itasca.remove_callback 移除这些函数回调。

i=0
def my_callback(*args):
    global i
    i += 1
    print("in Python callback function.")

it.set_callback("my_callback", -1)
it.command("cycle 5")
print("The Python callback function was called {} times".format(i))

it.remove_callback("my_callback",-1)
i=0
it.command("cycle 5")
print("The Python callback function was called {} times".format(i))

output:

in Python callback function.
in Python callback function.
in Python callback function.
in Python callback function.
in Python callback function.
The Python callback function was called 5 times
The Python callback function was called 0 times

注意

给出 新建模型（model new） 或 恢复模型（model restore） 命令时，回调函数注册会被清除。请注意不要把同一 Python 函数重复注册为每个循环调用多次。可用 fish list 回调（fish list callbacks） 命令查看已注册的函数。

有三个回调事件在 Python 中具有特殊行为。给出 新建模型（model new） 或 恢复模型（model restore） 命令时，“save”、“restore” 和 “new” 回调事件不会被重置。这些回调允许 Python 程序手动保存或读取与模型状态关联的数据。itasca.state_callbacks 函数可用于查看在这些特殊回调事件处定义了哪些 Python 函数。
