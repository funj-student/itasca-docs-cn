Liner

class itasca.sel.liner.Liner
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取衬砌的面积。

extra(slot: int) → any.

获取给定槽位中的衬砌额外数据。

face() → face_ptr.

获取所连接的面。

fiber_max() → float.

获取最大外缘纤维应力。

fiber_min() → float.

获取最小外缘纤维应力。

group([slot: str]) → str.

获取给定槽位中的衬砌组名。

group_remove(group_name: str) → bool.

从衬砌的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该衬砌属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取衬砌 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该衬砌是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取衬砌单元的索引（偏移）。

matnum() → float.

获取赋给衬砌的材料编号。

membrane_max() → float.

获取最大膜应力。

membrane_min() → float.

获取最小膜应力。

moment() → vec.

获取衬砌力矩（向量）。

moment_max() → float.

获取最大弯矩。

moment_min() → float.

获取最小弯矩。

moment_x() → float.

获取衬砌力矩的 x 分量。

moment_y() → float.

获取衬砌力矩的 y 分量。

moment_z() → float.

获取衬砌力矩的 z 分量。

node(int) → node_ptr.

获取衬砌面的一个节点（输入 {0, 1, 2} 分别表示该面的第一、第二或第三个节点）。

normal() → vec.

获取衬砌法向（向量）。

normal_stiffness() → float.

获取衬砌单元与岩/土之间界面的法向刚度（力/位移）。

normal_strength() → float.

获取衬砌单元与岩/土之间界面的法向（抗拉）强度。

normal_x() → float.

获取衬砌法向的 x 分量。

normal_y() → float.

获取衬砌法向的 y 分量。

normal_z() → float.

获取衬砌法向的 z 分量。

poiss() → float.

获取泊松比。

pos() → vec.

获取衬砌位置（向量）。

pos_x() → float.

获取衬砌位置的 x 分量。

pos_y() → float.

获取衬砌位置的 y 分量。

pos_z() → float.

获取衬砌位置的 z 分量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的衬砌额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的衬砌组名。

shear_cohesion() → float.

获取衬砌单元与岩/土界面的黏聚力。

shear_friction() → float.

获取衬砌单元与土/岩界面的摩擦角（度）。

shear_stiffness() → float.

获取衬砌单元与岩/土之间界面的剪切刚度（力/位移）。

stress() → vec.

获取衬砌应力（向量）。

stress_x() → float.

获取衬砌应力的 x 分量。

stress_y() → float.

获取衬砌应力的 y 分量。

stress_z() → float.

获取衬砌应力的 z 分量。

thermalexp() → float.

获取热膨胀系数。

thickness() → float.

获取衬砌厚度。

valid() → bool.

若该衬砌为活动对象则返回 True。

young() → float.

获取杨氏模量。
