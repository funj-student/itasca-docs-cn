CFDBall

class itasca.ball.cfd.CFDBall
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
ball() → Ball 对象。

获取与该 CFD 球对应的球。

elements() → CFD 单元对象的元组。

获取与某个 CFD 球关联的 CFD 单元元组。

extra(slot: int) → any.

获取给定槽位中的 CFD 球额外数据。

force() → vec.

获取 CFD 球流体力（向量）。

force_x() → float.

获取 CFD 球流体力的 x 分量。

force_y() → float.

获取 CFD 球流体力的 y 分量。

force_z() → float.

获取 CFD 球流体力的 z 分量。

group([slot: int]) → str.

获取给定槽位中的 CFD 球组名。

group_remove(group_name: str) → int.

从 CFD 球中移除给定组。需要一个字符串类型的参数给出组名。返回值为整数：找到该组名的第一个槽位；若未找到则为 -1。

groups() → 字符串的元组。

获取赋给该 CFD 球的组名元组。

id() → int.

获取 CFD 球 ID。

in_group(group_name: str) → bool.

检验该 CFD 球是否属于给定组。搜索所有组槽位。

overlaps() → 浮点数的元组。

获取该球与各 CFD 单元重叠体积的元组。返回的体积与 elements 方法返回的单元相对应。

pos() → vec.

获取 CFD 球位置（向量）。

pos_x() → float.

获取 CFD 球位置的 x 分量。

pos_y() → float.

获取 CFD 球位置的 y 分量。

pos_z() → float.

获取 CFD 球位置的 z 分量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的 CFD 球额外数据。

set_force(value: vec) → None.

设置 CFD 球流体力（向量）。

set_force_x(value: float) → None.

设置 CFD 球流体力的 x 分量。

set_force_y(value: float) → None.

设置 CFD 球流体力的 y 分量。

set_force_z(value: float) → None.

设置 CFD 球流体力的 z 分量。

set_group([group_name: str[, slot: int]]) → None.

设置给定槽位中的 CFD 球组名。

set_pos(value: vec) → None.

设置 CFD 球位置（向量）。

set_pos_x(value: float) → None.

设置 CFD 球位置的 x 分量。

set_pos_y(value: float) → None.

设置 CFD 球位置的 y 分量。

set_pos_z(value: float) → None.

设置 CFD 球位置的 z 分量。

valid() → bool.

若该 CFD 球为活动对象则返回 True。
