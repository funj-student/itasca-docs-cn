面

class itasca.block.face.Face
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取面的面积。

extra(slot: int) → any.

获取给定槽位中的面额外数据。

fblock() → blockptr.

获取与该面关联的块体面。

fid() → int.

获取该面的 DFN 裂隙 ID。

flowplane() → flowplanptr.

获取与该面相关的流体流动平面。

gp(int) → gridpointptr.

获取面第 n 个顶点（整数）的索引。

gridpoints() → 网格点列表。

获取构成该面的网格点列表。

group([slot: str]) → str.

获取给定槽位中的面组名。

group_remove(group_name: str) → bool.

从该面的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该面属于哪些组的字典。字典的键为槽位名，值为组名。

hostblock() → blockptr.

获取面所属的块体。

id() → int.

获取面 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该面是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取该面的索引（偏移）。

is_excavated() → bool.

获取宿主块体的开挖状态。

is_hidden() → bool.

获取宿主块体的隐藏状态。

is_original() → bool.

获取原始块体面指示符。

is_planar() → bool.

获取该面的平面标志。

jset() → int.

获取该面的节理集 ID。

ngp() → int.

获取面上的顶点（网格点）数目。

normal() → vec.

获取面法向向量（向量）。

normal_x() → float.

获取面法向向量的 x 分量。

normal_y() → float.

获取面法向向量的 y 分量。

normal_z() → float.

获取面法向向量的 z 分量。

pos() → vec.

获取面位置（向量）。

pos_x() → float.

获取面位置的 x 分量。

pos_y() → float.

获取面位置的 y 分量。

pos_z() → float.

获取面位置的 z 分量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的面额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的面组名。

valid() → bool.

若该面为活动面则返回 True。

zone() → zoneptr.

获取包含该面的网格单元的索引。
