itasca.clump.thermal

用于处理 Itasca 热学刚性簇的函数与类。

Functions

itasca.clump.thermal.count() → int.

获取热学刚性簇数量。

itasca.clump.thermal.find(id: int) → 热学刚性簇对象。

获取具有给定 ID 号的热学刚性簇对象。

itasca.clump.thermal.inbox(lower_bound: vec, upper_bound: vec, intersect=True) → 热学刚性簇对象的元组。

获取包围盒与某盒体相交的热学刚性簇元组。包围盒是该刚性簇的轴对齐包围盒。若可选关键字参数 intersect 为 False，则只返回位置落在盒内的热学刚性簇。

itasca.clump.thermal.list() → 热学刚性簇迭代器对象。

获取热学刚性簇迭代器对象。

itasca.clump.thermal.maxid() → int.

获取热学刚性簇的最大 ID。

itasca.clump.thermal.near(point: vec, radius=0.0) → 热学刚性簇对象。

查找距某点最近的热学刚性簇。若可选关键字参数 radius 非零，则只在该半径内搜索。
