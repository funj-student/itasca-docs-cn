块体

class itasca.block.Block
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取块体的表面积。

contacts() → Contact 对象的元组。

获取块体的接触列表。

density() → float.

获取块体密度。

dsf() → float.

获取块体密度缩放系数。

extra(slot: int) → any.

获取给定槽位中的块体额外数据。

faces(bool) → 面的元组。

获取块体的面列表。

force_app() → vec.

获取块体所受施加力（向量）。

force_app_x() → float.

获取块体所受施加力的 x 分量。

force_app_y() → float.

获取块体所受施加力的 y 分量。

force_app_z() → float.

获取块体所受施加力的 z 分量。

force_unbal() → vec.

获取块体不平衡力（向量）。

force_unbal_x() → float.

获取块体不平衡力的 x 分量。

force_unbal_y() → float.

获取块体不平衡力的 y 分量。

force_unbal_z() → float.

获取块体不平衡力的 z 分量。

gridpoints() → Gridpoint 对象的元组。

获取属于该块体的网格点对象元组。

group([slot: str]) → str.

获取给定槽位中的块体组名。

group_remove(group_name: str) → bool.

从块体的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该块体属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取块体 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该块体是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取块体索引。

is_excavated() → bool.

检查块体是否已被开挖。

is_fix() → bool.

检查块体是否被约束。

is_hidden() → bool.

获取块体的隐藏标志。

is_rigid() → bool.

获取块体的刚体标志。

mass() → float.

获取块体质量。

master_slave() → int.

获取块体的 master_slave 标志。

moi() → vec.

获取块体惯性（向量）。

moi_x() → float.

获取块体惯性的 x 分量。

moi_y() → float.

获取块体惯性的 y 分量。

moi_z() → float.

获取块体惯性的 z 分量。

moment() → vec.

获取块体力矩（向量）。

moment_x() → float.

获取块体力矩的 x 分量。

moment_y() → float.

获取块体力矩的 y 分量。

moment_z() → float.

获取块体力矩的 z 分量。

pos() → vec.

获取块体位置（向量）。

pos_x() → float.

获取块体位置的 x 分量。

pos_y() → float.

获取块体位置的 y 分量。

pos_z() → float.

获取块体位置的 z 分量。

rvel() → vec.

获取块体转动速度（向量）。

rvel_x() → float.

获取块体转动速度的 x 分量。

rvel_y() → float.

获取块体转动速度的 y 分量。

rvel_z() → float.

获取块体转动速度的 z 分量。

set_density(float) → float.

设置块体密度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的块体额外数据。

set_fix(bool) → bool.

设置块体。

set_force_app(value: vec) → None.

设置块体所受施加力（向量）。

set_force_app_x(value: float) → None.

设置块体所受施加力的 x 分量。

set_force_app_y(value: float) → None.

设置块体所受施加力的 y 分量。

set_force_app_z(value: float) → None.

设置块体所受施加力的 z 分量。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的块体组名。

set_hidden(bool) → bool.

设置块体的隐藏标志。

set_rvel(value: vec) → None.

设置块体转动速度（向量）。

set_rvel_x(value: float) → None.

设置块体转动速度的 x 分量。

set_rvel_y(value: float) → None.

设置块体转动速度的 y 分量。

set_rvel_z(value: float) → None.

设置块体转动速度的 z 分量。

set_velocity(value: vec) → None.

设置块体速度（向量）。

set_velocity_x(value: float) → None.

设置块体速度的 x 分量。

set_velocity_y(value: float) → None.

设置块体速度的 y 分量。

set_velocity_z(value: float) → None.

设置块体速度的 z 分量。

valid() → bool.

若该块体为活动块体则返回 True。

velocity() → vec.

获取块体速度（向量）。

velocity_x() → float.

获取块体速度的 x 分量。

velocity_y() → float.

获取块体速度的 y 分量。

velocity_z() → float.

获取块体速度的 z 分量。

vol() → float.

获取块体的体积。

zones() → 块体网格单元的元组。

获取块体的网格单元列表。
