在 FLAC3D 中使用 Python

本节给出用 Python 程序与 FLAC3D 交互的示例。本例中我们创建一个简单 FLAC3D 模型，并用 Python 施加边界条件、考察模型响应。

首先我们用 import 语句导入 itasca 模块。itasca 模块定义 Python 与 FLAC3D 之间的交互。我们以简写名 it 导入 itasca 模块。

import itasca as it
it.command("python-reset-state false")
it.command("""
program load module 'zone'
program load guimodule 'zone'
program load module 'body'
program load guimodule 'body'
program load module 'extruder'
program load guimodule 'extruder'
program load module 'sel'
program load module 'zonesel'
program load module 'selpython'
program load module 'wallsel'
program load guimodule 'sel'
program load module 'pfcsel'
program load module 'rblocksel'
program load module 'dfnzone'
program load module 'ballzone'
program load module 'zonepython'
program load module 'wallzone'
""")

我们将创建一些网格单元以展示 Python 脚本的特性。用 it.command（itasca.command）函数发出一系列 FLAC3D 命令。始终在 Python 程序开头给出命令 python-reset-state false。若不给出该命令，则当 FLAC3D 模型状态通过 model new 或 model restore 命令重置时，Python 变量与函数会被删除。

这些命令创建网格单元并设置若干性质。三引号用于定义多行字符串。

it.command("""
model new
model large-strain off
zone create brick size 10 10 10
zone cmodel assign elastic
zone property density 2950 young 12e9 poisson 0.25
cycle 1
""")

处理 FLAC3D 网格单元

可用 it.zone.count（itasca.zone.count）函数确认创建了 1000 个网格单元。在 IPython 终端中键入以下表达式会向屏幕输出数字 1000。

it.zone.count()
output:
1000

itasca 模块定义了用于与 FLAC3D 模型交互的函数和类。其中一些函数返回对象，

z = it.zone.find(1)
print(z)
output:
<itasca.zone.Zone object at 0x000001A830FC12D0, ID : 1>

此处 it.zone.find(1)（itasca.zone.find）返回 id 为 1 的网格单元的 Zone 对象。该对象被赋给 Python 变量 z。多数 FLAC3D 模型项都是这样的对象（类的实例）。Zone 对象有许多方法，例如

z.pos()
output:
vec3(( 5.000000e-01, 5.000000e-01, 5.000000e-01 ))

变量 z 是一个 Zone 对象，表示单个 FLAC3D 网格单元。pos（单元位置（itasca.zone.Zone.pos））是该对象的一个方法，返回网格单元形心。

注意

单元位置（itasca.zone.Zone.pos） 方法返回以 vec3 对象表示的长度为 3 的向量。关于 vec3 对象以及用 Python 处理向量的更多信息，见 vec 模块（vec module）。

print("zone", z.id(), "with model", z.model(), "at", z.pos())

Python 中用 for 语句遍历事物的序列，

volume_sum = 0.0
for z in it.zone.list():
    volume_sum += z.vol()

在本例中，用 for 语句遍历所有 FLAC3D 网格单元。每次循环中变量 z 是另一个 Zone 对象。最后，我们检验各网格单元体积之和是否符合预期。

print(volume_sum)
print(z.vol() * it.zone.count())
assert volume_sum == z.vol() * it.zone.count()
output:
1000.0
1000.0

我们来查找靠近模型中心的网格单元

z = it.zone.near((5,5,5))

并用 \(pos\) 方法确认其位置。

z.pos()
output:
vec3(( 4.500000e+00, 4.500000e+00, 4.500000e+00 ))

处理 FLAC3D 网格单元性质

props（单元属性列表（itasca.zone.Zone.props））方法以 Python 字典对象返回网格单元本构模型性质。字典的键为性质名，值为性质取值。

z.props()
output:
{'bulk': 8000000000.0, 'shear': 4800000000.0, 'young': 12000000000.0, 'poisson': 0.25}

要访问字典的各个部分，需用 [] 括号配合字符串键，

z.props()['bulk']
output:
8000000000.0

或可使用 prop 的 itasca.zone.zone.prop 方法。

z.prop('shear')
output:
4800000000.0

网格单元性质可用 set_prop（设置单元属性（itasca.zone.Zone.set_prop））方法设置。

z.set_prop('bulk', 8.5e9)
print(z.prop('bulk'))
output:
8500000000.0

Python 与 FLAC3D 网格单元有两处交互：(i) 属于 itasca.zone Python 模块的函数；(ii) 单个 itasca.zone.Zone object 的方法。按 Python 术语，itasca.zone 是 itasca 模块的子模块，Zone 是 itasca.zone 模块中定义的类。为简洁起见，我们常以缩写名 it 导入 itasca 模块。上文中 it.zone.count()（itasca.zone.count）、it.zone.list()（itasca.zone.list）与 it.zone.find()（itasca.zone.find）是 itasca.zone 模块中定义的函数。z.pos()（单元位置（itasca.zone.Zone.pos））与 z.vol()（单元体积（itasca.zone.Zone.vol））是 Zone 对象的方法调用。

  • itasca 给出 itasca 模块函数与类的完整列表。
  • itasca.zone 给出 itasca.zone 模块函数的完整列表。
  • 网格单元（Zone） 给出 Zone 对象方法的完整列表。

处理 FLAC3D 网格点

类似地，Python 可以通过以下方式与 FLAC3D 网格点交互

  • itasca.gridpoint 模块函数以及
  • 网格点（Gridpoint） 对象的方法。
gp = it.gridpoint.near((2,2,2))
print(gp.pos())
output:
vec3(( 2.000000e+00, 2.000000e+00, 2.000000e+00 ))

与网格单元一样，我们可以用 Python 的 for 语句遍历所有 FLAC3D 网格点。

total_mass = 0
for gp in it.gridpoint.list():
    total_mass += gp.mass_gravity()

print(total_mass, z.vol()*1000*z.density())
output:
2949999.9999999995 2950000.0

处理结构单元

Python 可通过 itasca.structure 模块与结构单元交互。为演示从 Python 访问结构单元，用以下命令添加结构。

it.command("""
struct cable create by-line (0.0, 5, 5) (10, 5, 5) id=1 segments=4
zone mechanical damping combined
struct cable property cross-sectional-area=2e-3 young=200e9 ...
                      yield-tension=1.1e20 grout-stiffness=1e10 ...
                      grout-cohesion=1e20 grout-friction=0.123
struct beam create by-line (0.0, 2, 2) (10, 2, 2) id=2 segments=4
struct beam property young=1.234e9 poisson=0.223 plastic-moment=23.4e4 ...
                     cross-sectional-area=1.234 moi-y=55.66 moi-z=3458.33
""")

所有类型的结构单元都存储在单个列表中，可通过 it.structure.list()（itasca.structure.list）函数访问。与 Itasca Python 接口中的其他迭代器不同，该迭代器返回特定类型的对象。共有六种结构单元类型：

  • 锚索（Cable）
  • 梁（Beam）
  • 桩（Pile）
  • 壳（Shell）
  • 土工格栅（Geogrid）
  • 衬砌（Liner）
for s in it.structure.list():
    if type(s) is it.structure.Cable:
        print("Cable element with id: {} and component id: {}"
              .format(s.id(), s.component_id()))
    elif type(s) is it.structure.Beam:
        print("Beam element with Young's modulus: {}".format(s.young()))
output:
Cable element with id: 1 and component id: 1
Cable element with id: 1 and component id: 2
Cable element with id: 1 and component id: 3
Cable element with id: 1 and component id: 4
Beam element with Young's modulus: 1234000000.0
Beam element with Young's modulus: 1234000000.0
Beam element with Young's modulus: 1234000000.0
Beam element with Young's modulus: 1234000000.0

类似地，可用 it.structure.find()（itasca.structure.find）与 it.structure.near()（itasca.structure.near）函数获取特定的单元。

s1 = it.structure.find(1)
s2 = it.structure.near((0,2,2))

print(s1)
print(s2)
output:
<itasca.structure.Cable object at 0x000001A830FC12D0, ID : 1>
<itasca.structure.Beam object at 0x000001A830FC1168, ID : 5>

结构单元节点与连接可通过以下子模块访问：

  • itasca.structure.node
  • itasca.structure.link
s_node = it.structure.node.find(1)
s_link = s_node.links()[0]
print("SEL node {} is attached to zone {}"
      .format(s_node.id(), s_link.target().id()))

it.command("struct cable delete")
it.command("struct beam delete")
output:
SEL node 1 is attached to zone 551

额外变量

FLAC3D 的网格单元、网格点及其他 Itasca 模型对象都有额外变量，从而可把某些数据关联到模型对象。Python 程序可用所有对象类型都定义的 extra 和 set_extra 方法读写额外变量。

z.set_extra(1, 1.23)
z.set_extra(2, "a text string")

print(z.extra(1))
print(z.extra(2))
output:
1.23
a text string

gp.set_extra(1, gp.pos())
gp.set_extra(2, 86856527)

print(gp.extra(1))
print(gp.extra(2))
output:
vec3(( 1.000000e+01, 1.000000e+01, 1.000000e+01 ))
86856527

Python 中索引通常从 0 开始。额外变量的索引是例外，以便 Python 与 Itasca 软件 GUI 良好配合。额外变量保存在模型存档文件中，这是把 Python 数据关联到 Itasca 模型状态的一种方式。

使用 FLAC3D 的组并施加边界条件

组用于创建 FLAC3D 模型对象的列表。这常用于设置边界条件或对模型的特定部分施加材料性质。此处我们用 FLAC3D 命令创建两组网格单元，分别表示模型的上部和下部。

it.command("""
zone group "lower" range position-z 0 5
zone group "upper" range position-z 5 10
""")

可用 Zone 的 group（单元分组（itasca.zone.Zone.group））方法查询某个网格单元是否属于某个组。

lower_zones, upper_zones = 0, 0

for z in it.zone.list():
    if z.group("default") == "lower":
        lower_zones += 1
        z.set_prop("young", 1.6e10)
    elif z.group("default") == "upper":
        upper_zones += 1

print(lower_zones, upper_zones)
output:
500 500

对象所属的组可用 set_group（设置单元分组（itasca.zone.Zone.set_group））方法设置。

接下来我们固定模型下表面的网格点，并对模型上表面的网格点施加力。

lower_gridpoints, upper_gridpoints = 0, 0

for gp in it.gridpoint.list():
    if gp.pos_z() == 0:
        lower_gridpoints += 1
        gp.set_fix(0, True)
        gp.set_fix(1, True)
        gp.set_fix(2, True)
    if gp.pos_z() == 10:
        upper_gridpoints += 1
        gp.set_force_load((1e6,2e6,1e6))

print(lower_gridpoints, upper_gridpoints)
output:
121 121

it.command("""

print(stress)
print()
print(strain)

stress（单元应力（itasca.zone.Zone.stress））和 strain（单元应变（itasca.zone.Zone.strain））这两个网格单元方法以 stens3 对象返回对称张量。关于对称张量对象以及用 Python 处理张量的更多信息，见 stens3 类型（stens3 type）。

进行参数研究

Python 程序及其变量不依赖于 FLAC3D 模型状态（前提是已给出命令 python-reset-state false）。这便于以程序化方式开展参数研究。下例用 4 个不同的杨氏模量运行同一模型，并打印模型顶部中心的竖向位移。

for modulus in [6e9, 8e9, 10e9, 12e9]:
    it.command("""
    model restore 'before_cycling'
    zone prop young {}
    model solve
    """.format(modulus))
    vertical_disp = it.gridpoint.near((5,5,10)).disp_z()
    print("Modulus: {:.01e} Pa, vertical displacement: {:.03e}"
          .format(modulus, vertical_disp))
output:
Modulus: 6.0e+09 Pa, vertical displacement: 1.771e-03
Modulus: 8.0e+09 Pa, vertical displacement: 1.328e-03
Modulus: 1.0e+10 Pa, vertical displacement: 1.063e-03
Modulus: 1.2e+10 Pa, vertical displacement: 8.856e-04

处理 FLAC3D 错误

借助 Python，可用内置的异常处理机制捕获并处理错误。Python 中的运行时错误称为异常。可用 try、except 块捕获并处理异常。

try:
    it.command("""
    zone prop young 0
    model solve
    """)
except Exception as data:
    print("an error occurred", data)

print("Python program execution continues...")

it.command("zone prop young 8e9")  # 修正该问题
output:
an error occurred Zero stiffness in gridpoint 133.
    While processing line 1 of source Python interpreter.
Python program execution continues...

Python 回调函数

Python 函数可在 FLAC3D 计算序列的特定位置运行。itasca.set_callback 函数注册在循环期间调用的 Python 函数，而 itasca.remove_callback 函数移除这些函数回调。

i=0
def my_callback(*args):
    global i
    i += 1
    print("in Python callback function.")

it.set_callback("my_callback", -1)
it.command("cycle 5")
print("The Python callback function was called {} times".format(i))

it.remove_callback("my_callback",-1)
i=0
it.command("cycle 5")
print("The Python callback function was called {} times".format(i))
output:
in Python callback function.
in Python callback function.
in Python callback function.
in Python callback function.
in Python callback function.
The Python callback function was called 5 times
The Python callback function was called 0 times

注意

给出 model new 或 model restore 命令时，回调函数注册会被清除。请注意不要把同一 Python 函数重复注册为每个循环调用多次。可用 list fish callback 命令查看已注册的函数。

有三个回调事件在 Python 中具有特殊行为。给出 model new 或 model restore 命令时，“save”、“restore” 和 “new” 回调事件不会被重置。这些回调允许 Python 程序手动保存或读取与模型状态关联的数据。itasca.state_callbacks 函数可用于查看在这些特殊回调事件处定义了哪些 Python 函数。
