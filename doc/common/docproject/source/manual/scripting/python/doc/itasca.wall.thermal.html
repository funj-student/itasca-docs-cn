itasca.wall.thermal

用于处理 Itasca 热学墙的函数与类。

Functions

itasca.wall.thermal.count() → int.

获取热学墙数量。

itasca.wall.thermal.find(id: int) → 热学墙对象。

获取具有给定 ID 号的热学墙对象。

itasca.wall.thermal.inbox(lower_bound: vec, upper_bound: vec, intersect=True) → 热学墙对象的元组。

获取包围盒与某盒体相交的热学墙元组。包围盒是该热学墙的轴对齐包围盒。若可选关键字参数 intersect 为 False，则只返回位置落在盒内的热学墙。

itasca.wall.thermal.list() → 热学墙迭代器对象。

获取热学墙迭代器对象。

itasca.wall.thermal.maxid() → int.

获取最大热学墙 ID。

itasca.wall.thermal.near(point: vec, radius=0.0) → 热学墙对象。

查找距某点最近的墙。若可选关键字参数 radius 非零，则只在该半径内搜索。
