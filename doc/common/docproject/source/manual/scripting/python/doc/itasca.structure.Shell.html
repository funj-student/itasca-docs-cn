Shell

class itasca.structure.Shell
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取壳单元的表面积。

beta() → float.

获取壳体系 beta 角。定义为单元局部系 x 轴与材料体系 x 轴之间的夹角，以弧度为单位，从单元局部 x 轴逆时针量得。

component_id() → int.

获取壳组件 ID。

connectivity(component: int) → bool.

获取该单元中组件 ID 为 id 的节点的索引。若该单元中没有匹配的节点，则抛出 ValueError 异常。

delete() → None.

删除此结构单元。

density() → float.

获取该结构单元的密度。

depth_factor() → float.

获取已恢复应力的深度因子。深度等于 Ft/2，其中 t 为壳单元厚度。F 值为 +1.0 或 -1.0 分别对应壳单元的外/内表面。外表面由局部壳单元系的正 z 方向定义。F 值为 0.0 对应壳单元中面。深度因子可用 \(structure Shell recover stress\) 命令修改。

element_type() → str.

获取该壳单元所用有限元类型的名称。壳单元可能的类型为 ‘cst’、‘csth’、‘dkt’、‘dkt-cst’ 和 ‘dkt-csth’。

extra(slot: int) → any.

获取给定槽位中的壳单元额外数据。

force_nodal() → (vec3,vec3, vec3,vec3, vec3,vec3).

获取作用在壳单元各节点上的广义节点力。先给出节点 1 的平动和转动分量。

group([slot: str]) → str.

获取给定槽位中的壳单元组名。

group_remove(group_name: str) → bool.

从壳单元的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该壳单元属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取壳单元结构单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该壳单元是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

local_system() → Tens3.

以 3x3 张量形式获取该单元的局部坐标系。

mark() → bool.

获取结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

nodes() → 结构单元节点对象元组。

获取连接到该单元的结构单元节点元组。

poisson() → float.

获取单元的泊松比。

pos() → vec3.

获取单元的位置向量，定义为单元形心。

pressure() → float.

获取作用在壳单元上的均布压力。正值沿单元局部系的 z 方向作用。

prop_anis() → （膜：浮点数元组，弯曲：浮点数元组）。

获取各向异性材料性质。按该顺序返回膜刚度和弯曲刚度各自的材料刚度系数 c‘11、c‘12、c‘13、c‘22、c‘23、c‘33。若单元不具有各向异性性质，则返回零。

prop_ortho() → （膜：浮点数元组，弯曲：浮点数元组）。

获取正交各向异性材料性质。按该顺序返回膜刚度和弯曲刚度各自的材料刚度系数 c‘11、c‘12、c‘13、c‘22、c‘23、c‘33。若单元不具有正交各向异性性质，则返回零。

prop_type() → str.

获取材料性质类型。可能的返回值为 ‘isotropic’、‘orthotripc’ 和 ‘anisotropic’。

resultant(location: int) → 长度为 8 的浮点数元组。

获取索引 \(location\) 处最后计算的单元应力合力。\(location\) 值为 0 时给出单元形心处的合力；\(location\) 值为 1、2 和 3 时给出节点处的合力。返回值分量为：Mx、My、Mxy、Nx、Ny、Nxy、Qx 和 Qy。注意，必须用 \(structure Shell recover\) 命令计算应力合力。另见 \(resultant_valid\) 方法。

resultant_valid() → bool.

获取应力合力的有效性标志。True 表示应力合力有效；False 表示尚未计算合力，或自上次计算以来发生了变化而使结果失效。

set_density(float) → None.

设置该结构单元的密度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的壳单元额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的壳单元组名。

set_mark(bool) → None.

设置结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

set_pressure(float) → None.

设置作用在壳单元上的均布压力。正值沿单元局部系的 z 方向作用。

set_thermal_expansion(float) → None.

设置该结构单元的热膨胀系数。

set_thickness(float) → None.

设置单元厚度。

stress(location: int) → stens3.

获取当前深度因子处在索引 \(location\) 处的壳单元应力。\(location\) 值为 0 时给出单元形心处的应力；\(location\) 值为 1、2 和 3 时给出节点处的应力。应力在全局系中表示。注意压应力为负。

stress_prin(location: int) → vec3.

获取当前深度因子处在索引 \(location\) 处的分解主应力。\(location\) 值为 0 时给出单元形心处的应力；\(location\) 值为 1、2 和 3 时给出节点处的应力。返回编码为（最小、中间、最大）的向量。注意，在 FLAC3D 中压应力为负。

stress_valid() → bool.

获取单元的应力有效性标志。True 表示按当前深度因子最后计算的应力有效；False 表示尚未计算应力，或发生了使上次计算的应力失效的变化。

thermal_expansion() → float.

获取该结构单元的热膨胀系数。

thickness() → float.

获取单元厚度。

valid() → bool.

若该壳单元为活动对象则返回 True。

volume() → float.

获取单元体积，即表面积乘以厚度。

young() → float.

获取单元的杨氏模量。在循环过程中修改该值可能有风险。
