itasca.dfn

用于处理 Itasca DFN 的函数与类。

Functions

itasca.dfn.center_density(lower=domain lower bound, upper=domain upper bound) → 浮点数。

获取裂隙中心密度。裂隙中心密度定义为在指定区域内测得的{二维中 P20 值；三维中 P30 值}。{二维中 P20；三维中 P30} 是单位面积（体积）内指定区域中的裂隙中心数量。该计算使用所有 dfn 的所有裂隙。

itasca.dfn.count() → int.

获取 dfn 数量。

itasca.dfn.create(dfn_name=Empty) → DFN 对象。

创建空 dfn，可选名称为 dfn_name。

itasca.dfn.density(lower=domain lower bound, upper=domain upper bound) → 浮点数。

获取裂隙质量密度。裂隙质量密度定义为在指定区域内测得的{二维中 P21 值；三维中 P32 值}。{二维中 P21；三维中 P32} 是单位面积（体积）内指定区域中的累积裂隙长度（表面积）。该计算使用所有 dfn 的所有裂隙。

itasca.dfn.find(id: int or name: str) → DFN 对象。

获取具有给定 ID 号或名称的 dfn 对象。

itasca.dfn.list() → DFN 迭代器对象。

获取 dfn 迭代器对象。

itasca.dfn.maxid() → int.

获取最大 dfn ID。

itasca.dfn.p10(pt1=origin, pt2=origin) → float.

获取沿从 pt1 到 pt2 的直线的 P10，即单位长度裂隙密度。该计算使用所有 dfn 的所有裂隙。

itasca.dfn.percolation(lower=domain lower bound, upper=domain upper bound) → 浮点数。

获取裂隙渗流。裂隙渗流在区域内测量，定义为{二维中单位面积内裂隙长度平方之和；三维中单位体积内 pi^2 (area/pi)^(1.5) 之和，其中 area 为裂隙面积}。
