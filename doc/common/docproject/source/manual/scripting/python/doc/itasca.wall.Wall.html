墙

class itasca.wall.Wall
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
closed() → bool.

获取墙的封闭状态。封闭墙是指所有边都共享的墙。

contact_count(all=False, type=None) → int.

获取与该墙关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则计数包含虚拟接触。

contacts([piece: object, ]all=False, type=None) → Contact 对象的元组。

获取与该墙关联的接触元组。可包含一个可选参数，即片体对象（Ball、Pebble 或 wallFacet）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

convex() → bool.

获取凸性状态。墙还必须封闭才是凸的。

cutoff() → float.

获取截断角。截断角用于接触解析，以确定是否传播接触状态信息。

delete() → None.

删除此墙。

disp() → vec.

获取墙位移（向量）。

disp_x() → float.

获取墙位移的 x 分量。

disp_y() → float.

获取墙位移的 y 分量。

disp_z() → float.

获取墙位移的 z 分量。

euler() → vec.

获取墙方位（向量）。

euler_x() → float.

获取墙方位的 x 分量。

euler_y() → float.

获取墙方位的 y 分量。

euler_z() → float.

获取墙方位的 z 分量。

extra(slot: int) → any.

获取给定槽位中的墙额外数据。

facets() → 面片迭代器对象。

获取墙的面片。

force_contact() → vec.

获取墙接触力（向量）。

force_contact_x() → float.

获取墙接触力的 x 分量。

force_contact_y() → float.

获取墙接触力的 y 分量。

force_contact_z() → float.

获取墙接触力的 z 分量。

fragment() → int.

获取墙的破碎块体 ID。

group([slot: str]) → str.

获取给定槽位中的墙组名。

group_remove(group_name: str) → bool.

从墙的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该墙属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取墙 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该墙是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

inside(point: vec) → bool.

检验某点是否在墙内。墙必须封闭。

moment_contact() → vec.

获取墙接触力矩（向量）。

moment_contact_x() → float.

获取墙接触力矩的 x 分量。

moment_contact_y() → float.

获取墙接触力矩的 y 分量。

moment_contact_z() → float.

获取墙接触力矩的 z 分量。

name() → str.

获取墙名称。墙一旦创建，其名称不能更改。

pos() → vec.

获取墙位置（向量）。

pos_x() → float.

获取墙位置的 x 分量。

pos_y() → float.

获取墙位置的 y 分量。

pos_z() → float.

获取墙位置的 z 分量。
