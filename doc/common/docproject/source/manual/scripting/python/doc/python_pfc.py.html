在 PFC 中使用 Python

本节给出通过 Python 程序与 PFC 交互的示例。

首先，从 i Python 菜单中选择 IPython 窗格进入。本例中所有行都可在该窗格的提示符下输入。关于运行本例的更多信息，另见下文 示例文件（Example File）。

首先用 Python 的 import 语句导入 c itasca 模块。import 语句中的 as 把 itasca 模块的名称简写为 it。itasca 模块定义 Python 与 PFC 之间的交互。

import itasca as it

Python 程序应始终以以下行开始。

python-reset-state false 命令设置程序行为，使 Python 状态不会被 新建模型（model new） 或 恢复模型（model restore） 命令清除（默认情况下给出这些命令时会被清除，这是 FISH 脚本环境的常规做法）。

it.command("python-reset-state false")

接下来创建一些 PFC 颗粒。用 it.command 函数（itasca.command）发出一组 PFC 命令，创建由 8000 个球形颗粒构成的三维立方排列。Python 中用三重引号定义多行字符串。

itasca.command("""
model new
model large-strain on
model domain extent -5e-2 6e-2 -6e-2 5e-2 -5e-2 5e-2
contact cmat default model linear property kn 1e1 dp_nratio 0.2
ball generate cubic box -0.02375 0.02375 rad 1.25e-3
ball attr dens 2600
""")

用 it.ball.count（itasca.ball.count）函数确认创建了 8000 个球。

it.ball.count()
output:
8000

c itasca 模块定义了用于与 PFC 模型交互的函数和类。其中一些函数返回对象。

ball = it.ball.find(1)
print(ball)
output:
<itasca.ball.Ball object at 0x000001BB82260738, ID : 1>

此处 it.ball.find(1) 返回 id 为 1 的球的 c 球体（Ball） 对象。多数 PFC 模型项都是这样的对象（类的实例）。c 球体（Ball） 对象有许多方法。

ball.radius()
output:
0.00125

上文中，变量 ball 是前面代码片段中创建的 c 球体（Ball） 对象。radius 是一个返回球半径的球方法。

for 语句用于迭代。

radius_sum = 0.0
for b in it.ball.list():
  radius_sum += b.radius()

上文中，用 for 语句遍历所有 PFC 球。每次循环中变量 b 是另一个 c 球体（Ball） 对象。可检查迭代结果，确认球半径之和符合预期。

print(radius_sum)
print(ball.radius() * it.ball.count())
output:
10.000000000000503
10.0

可与 PFC 球交互的地方有两处：

  1. 属于 c itasca.ball 模块的函数，以及
  2. 单个 c 球体（Ball） 对象的方法。

按 Python 术语，ball 是 itasca 模块的子模块（故其名为 c itasca.ball）。上面的代码片段中，it.ball.count、it.ball.list 与 it.ball.find 是 it.ball 模块（即 c itasca.ball 模块：请注意 it 在开头就定义为 itasca 的简写替代）中定义的函数。另一方面，b.radius 是作为 c 球体（Ball） 类一部分定义的方法。

  • 关于模块函数的完整列表，见 c itasca.ball 模块参考。
  • 关于 Ball 对象方法的完整列表，见 c 球体（Ball） 类的说明。

PFC 接触与 Python 的关联方式与球相同。把 PFC 循环一步以创建接触即可看到。

it.command("model cycle 1")

用 near 查找距原点最近的球，

b = it.ball.near((0,0,0))

并用 pos 方法确认其位置。

b.pos()
output:
vec3(( 1.250000e-03, 1.250000e-03, 1.250000e-03 ))

注意

pos 方法返回以 vec3 对象表示的长度为 3 的向量。关于 vec3 对象以及用 Python 处理向量的更多信息，见 c vec 模块。

用 contacts 方法获取该球接触的数量。

len(b.contacts())
output:
6

Python 中用内置函数 len 确定序列的长度。以下代码遍历球 b 的所有接触，并打印接触 ID 与接触位置。

for c in b.contacts():
    print("contact with id: {} at {}".format(c.id(), c.pos()))
output:
contact with id: 11063 at vec3(( 1.250000e-03, 1.250000e-03, -1.951564e-18 ))
contact with id: 12163 at vec3(( 1.250000e-03, -1.951564e-18, 1.250000e-03 ))
contact with id: 12218 at vec3(( -1.951564e-18, 1.250000e-03, 1.250000e-03 ))
contact with id: 12221 at vec3(( 2.500000e-03, 1.250000e-03, 1.250000e-03 ))
contact with id: 12222 at vec3(( 1.250000e-03, 2.500000e-03, 1.250000e-03 ))
contact with id: 12223 at vec3(( 1.250000e-03, 1.250000e-03, 2.500000e-03 ))

注意

字符串对象的 format 方法用于把数值代入字符串。字符串中的 {} 部分被 format 方法的参数替换——此处用于显示接触 ID 与位置。

对接触对象也可进行类似的查询。

c = b.contacts()[0]

用括号（[ ]）从 contacts 方法返回的元组中取出元素。（注意 Python 索引从 0 开始，因此该调用返回第一个接触。）接触力（在全局系中）用 force_global 获取。

c.force_global()
output:
vec3(( 0.000000e+00, 0.000000e+00, 0.000000e+00 ))

用 props 获取该接触上定义的性质。

c.props()
output:
{'kn': 10.0, 'ks': 0.0, 'fric': 0.0, 'lin_force': vec3(( 0.000000e+00, 0.000000e+00, 0.000000e+00 )), 'lin_slip': False, 'lin_mode': 0, 'rgap': 0.0, 'emod': 5092.958178940651, 'kratio': 0.0, 'dp_nratio': 0.2, 'dp_sratio': 0.0, 'dp_mode': 0, 'dp_force': vec3(( 0.000000e+00, -0.000000e+00, -0.000000e+00 )), 'user_area': 0.0}

props 方法返回 Python 字典对象（Python dictionary object）。要访问字典中的单个部分，需用括号（[ ]）指定所需的键名。

c.props()['fric']
output:
0.0

或者，可使用 prop 方法。

c.prop('fric')
output:
0.0

接触（或球）性质可用 set_prop 方法设置。

c.set_prop('fric', 0.5)
print(c.prop('fric'))
output:
0.5

可用 end1 和 end2 方法访问接触两侧的体。

print(c.end1())
print(c.end2())
output:
<itasca.ball.Ball object at 0x000001BB82260498, ID : 3811>
<itasca.ball.Ball object at 0x000001BB82260498, ID : 4211>

检验接触的哪一端对应 Ball 对象 b。

print(c.end1() == b)
print(c.end2() == b)
output:
False
True

neighbor_list = [c.end1() if c.end2() == b else c.end2() for c in b.contacts()]

print("central ball id: {}, position: {}".format(b.id(), b.pos()))
print
for i, neighbor in enumerate(neighbor_list):

                                                         neighbor.id(),
                                                         neighbor.pos()))

Python 类型系统

在下一个示例中，将在新模型中创建三个球和一面墙，以演示 Python 类型系统。

it.command("""
model new
model large-strain on
model domain extent -1 1 -1 1 -1 1
contact cmat default model linear property kn 1e1 dp_nratio 0.2
""")

from vec import vec

origin = vec((0.0, 0.0, 0.0))
rad = 0.1
eps = 0.001

b1 = it.ball.create(rad, origin)
b2 = it.ball.create(rad, origin + (rad-eps, 0, 0))
# 创建第三个球颗粒，使其距离足够近以生成虚拟接触
b3 = it.ball.create(rad, origin + (rad*3 + eps, 0, 0))

it.command("""
ball attribute density 1200
wall create vertices  ...
   -{rad} -{rad} -{rad} ...
   {rad} -{rad} -{rad} ...
   {rad} {rad} -{rad}
model cycle 1
""".format(rad=rad))

执行该代码并绘制球与墙，结果应如下图所示。

该模型中有三个活动接触和一个非活动接触。默认情况下 it.contact.list 函数只返回活动接触。

for c in it.contact.list():
    print(c)
output:
<itasca.BallBallContact object at 0x000001BB82260858, ID : 1>
<itasca.BallFacetContact object at 0x000001BB832B47B0, ID : 1>
<itasca.BallFacetContact object at 0x000001BB82260858, ID : 2>

通过添加 all=True 关键字参数，可把非活动接触也包含在列表中。

for c in it.contact.list(all=True):
    print(c)
output:
<itasca.BallBallContact object at 0x000001BB832B47B0, ID : 1>
<itasca.BallBallContact object at 0x000001BB82260858, ID : 2>
<itasca.BallFacetContact object at 0x000001BB832B47B0, ID : 1>
<itasca.BallFacetContact object at 0x000001BB82260858, ID : 2>

不同接触类型具有不同的 Python 类型。配合内置函数 type 可确定对象的类型。

c1, c2, c3, c4 = tuple(it.contact.list(all=True))

print(type(c1) is it.BallBallContact)
print(type(c1) is it.BallFacetContact)
print(type(c3) is it.BallFacetContact)
output:
True
False
True

此处 it.BallBallContact 是一个 Python 类型对象。若只需要球-球接触，则把该类型对象传给 it.contact.list 函数。

for c in it.contact.list(type=it.BallBallContact, all=True):
    print(c)
output:
<itasca.BallBallContact object at 0x000001BB82260A38, ID : 1>
<itasca.BallBallContact object at 0x000001BB82260858, ID : 2>

Python 回调函数

Python 函数可在 PFC 计算序列的特定位置运行。itasca.set_callback 函数注册在循环期间调用的 Python 函数，而 itasca.remove_callback 移除这些函数回调。

i=0
def my_callback(*args):
    global i
    i += 1
    print("in Python callback function.")

it.set_callback("my_callback", -1)
it.command("model cycle 5")
print("The Python callback function was called {} times".format(i))

it.remove_callback("my_callback",-1)
i=0
it.command("model cycle 5")
print("The Python callback function was called {} times".format(i))
output:
in Python callback function.
in Python callback function.
in Python callback function.
in Python callback function.
in Python callback function.
The Python callback function was called 5 times
The Python callback function was called 0 times

注意

给出 新建模型（model new） 命令时，回调函数注册会被清除。请注意不要把同一 Python 函数重复注册为每个循环调用多次。可用 fish list callback 命令查看已注册的函数。
