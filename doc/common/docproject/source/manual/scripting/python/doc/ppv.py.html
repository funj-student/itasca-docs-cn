记录峰值质点速度

本教程中运行动力波传播模型，并记录各网格点的峰值质点速度（PPV）。PPV 定义为模型中各点所经历速度向量大小的最大值。

与前面的示例不同，该模型由 FLAC3D 数据文件驱动，而 Python 用于扩展模型行为。FLAC3D 力学循环过程中会调用 Python 回调函数，并更新各网格点的 PPV。

默认情况下，FLAC3D 存档文件中不存储任何 Python 数据。此时使用 save、restore 和 new Python 回调事件，把 PPV 数据保存到 FLAC3D 存档文件并从其中恢复。

创建一个边长 100 米的弹性材料立方体，并移除立方体中心的一块区域。对模型中单个网格单元施加各向同性应力，以产生应力波源。

该数据文件调用 ppv.py，如下所示。

import itasca as it
it.command('python-reset-state false')
import numpy as np
np.set_printoptions(threshold=20)
from itasca import gridpointarray as gpa

ppv = None

def store_ppv(*args):
    global ppv
    if ppv is None:
        ppv = np.zeros(it.gridpoint.count())
    ppv = np.maximum(np.linalg.norm(gpa.vel(), axis=1), ppv)

def ppv_save(*args):
    global ppv
    print("saving PPV")
    if ppv.any():
        gpa.set_extra(1,ppv)

def ppv_restore(*args):
    global ppv
    print("restoring PPV")
    try:
        print(it.zone.count())
        ppv = gpa.extra(1)
        print("max ppv during restore", ppv.max())
    except: pass

def ppv_new(*args):
    global ppv
    print("resetting PPV")
    ppv = None

def transit_time():
    z = it.zone.find(1)
    K, G, rho = z.prop("bulk"), z.prop("shear"), z.density()
    vp = np.sqrt((K + 4.0/3.0*G)/rho)
    d = np.sqrt(3*100**2)
    return d/vp

it.set_callback("store_ppv", 0.1)
it.set_callback("ppv_save", "save")
it.set_callback("ppv_restore", "restore")
it.set_callback("ppv_new", "new")

每个力学循环中都会调用 Python 函数 store_ppv。该函数使用 gridpointarray 模块（gridpointarray module） 获取每个网格点的速度，形式为 numpy 数组。求出每个网格点的速度大小，并把每个网格点经历的最大速度大小存入数组 ppv。

在 FLAC3D 存档文件中保存与恢复 Python 数据

保存 FLAC3D 模型时会调用 Python 函数 ppv_save。在该函数中，PPV 被存入网格点额外变量，随后随 FLAC3D 存档文件一起保存。定义为在“save”回调事件期间调用的 Python 函数在保存操作开始前即被调用。类似地，FLAC3D 恢复操作完成后会调用 Python 函数 ppv_restore。在该函数中，用此前存入网格点额外变量的 PPV 值重新填充 Python 变量 ppv。

当用 model new 或 model restore 命令重置 FLAC3D 模型时会调用 Python 函数 ppv_new。此时 ppv Python 变量的值被重置。

注意

也可以使用 it.fish 文件（it.fish） 函数保存和恢复 Python 变量的值。存为 FISH 变量的值会被写入 FLAC3D 存档文件并从其中读取。大多数常见 Python 值都可转换为 FISH 值。

使用 numpy 和 matplotlib 进行数据分析

load_point = (80.5, 80.5, 80.5)
# 源网格单元至各网格点的距离
distance = np.linalg.norm(gpa.pos()-load_point,axis=1)

gpos = gpa.pos()
gx, gy, gz = gpos.T
top_mask = gz == 100.0
exterior_mask = reduce(np.logical_or, 
                       (gx==0, gz==100, gy==0, gy==100, gz==0, gz==100))
boundary_gridpoint_mask = np.array([len(v)!=8 for v in gpa.zones()])
excavation_surface_mask = np.logical_and(np.logical_not(exterior_mask), 
                                         boundary_gridpoint_mask)
interior_mask = np.logical_not(boundary_gridpoint_mask)

colors = ["#4e79a7", "#f28e2b","#e15759","#76b7b2","#59a14e",
          "#edc949","#b07aa2","#ff9da7","#9c755f","#bab0ac"]

import pylab as plt
plt.loglog(distance[interior_mask], ppv[interior_mask], 
           "o", color=colors[2], markeredgewidth=0)
plt.loglog(distance[excavation_surface_mask], ppv[excavation_surface_mask], 
           "o", color=colors[1], markeredgewidth=0)
plt.loglog(distance[top_mask], ppv[top_mask], 
           "o", color=colors[0], markeredgewidth=0)
plt.legend(("Interior", "Excavation Surface", "Ground Surface"))
plt.xlabel("Distance from Source [m]")
plt.ylabel("PPV [m/s]")
plt.show()

峰值质点速度按距源的距离绘制。数据分为三组绘制：蓝色点对应地表，橙色点对应开挖面，红色点对应模型内部。
