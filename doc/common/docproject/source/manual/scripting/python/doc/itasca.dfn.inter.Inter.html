Inter

class itasca.dfn.inter.Inter
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
end1() → 裂隙对象。

获取 end1 裂隙对象。

end2() → 裂隙对象。

获取 end2 裂隙对象。

extra(slot: int) → any.

获取给定槽位中的交线额外数据。

group([slot: str]) → str.

获取给定槽位中的交线组名。

group_remove(group_name: str) → bool.

从该交线的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该交线属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取交线 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该交线是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

len() → float.

获取交点长度。

polylinept(index) → vec.

获取指定索引处的折线交点（向量）。

polylinept_count() → int.

获取交线的折线点数。

pos1() → vec.

获取交线第一端位置（向量）。

pos1_x() → float.

获取交线第一端位置的 x 分量。

pos1_y() → float.

获取交线第一端位置的 y 分量。

pos1_z() → float.

获取交线第一端位置的 z 分量。

pos2() → vec.

获取交线第二端位置（向量）。

pos2_x() → float.

获取交线第二端位置的 x 分量。

pos2_y() → float.

获取交线第二端位置的 y 分量。

pos2_z() → float.

获取交线第二端位置的 z 分量。

set() → 交点集合对象。

获取该交线所属的交线集。

set_extra(slot: int, value: any) → None.

设置给定槽位中的交线额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的交线组名。

valid() → bool.

若该交线为活动对象则返回 True。
