Gridpoint

class itasca.gridpoint.Gridpoint
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
accel() → vec.

获取网格点加速度（向量）。

accel_x() → float.

获取网格点加速度的 x 分量。

accel_y() → float.

获取网格点加速度的 y 分量。

accel_z() → float.

获取网格点加速度的 z 分量。

biot_modulus() → float.

获取网格点的流体 Biot 模量。

convergence() → float.

获取网格点收敛值，定义为当前局部力比（网格点比值成员）与目标力比（网格点 ratio_target 方法）之比。因此，1 或更小的值视为收敛。

copy_to(destination: gridpoint) → None.

把该网格点的状态信息复制到给定网格点。

disp() → vec.

获取网格点位移（向量）。

disp_small() → vec.

获取网格点小位移向量。仅在小应变模型中，小位移才由速度和时步累积。见 model large 命令。小应变向量场用于界面逻辑计算重叠量（向量）。

disp_small_x() → float.

获取网格点小位移向量的 x 分量。仅在小应变模型中，小位移才由速度和时步累积。见 model large 命令。小应变向量场用于界面逻辑计算重叠量。

disp_small_y() → float.

获取网格点小位移向量的 y 分量。仅在小应变模型中，小位移才由速度和时步累积。见 model large 命令。小应变向量场用于界面逻辑计算重叠量。

disp_small_z() → float.

获取网格点小位移向量的 z 分量。仅在小应变模型中，小位移才由速度和时步累积。见 model large 命令。小应变向量场用于界面逻辑计算重叠量。

disp_x() → float.

获取网格点位移的 x 分量。

disp_y() → float.

获取网格点位移的 y 分量。

disp_z() → float.

获取网格点位移的 z 分量。

dynamic_mul() → float.

获取网格点的动力步进乘子。

extra(slot: int) → any.

获取给定槽位中的网格点额外数据。

fix(component: int) → bool.

获取网格点的约束条件。第一个参数是向量分量。

flow() → float.

获取网格点处的不平衡流量。

fluid_load() → float.

获取网格点的附加流体荷载。

fluid_modulus() → float.

获取网格点的流体体积模量。

fluid_modulus_confined() → float.

获取网格点流体流动受限模量乘以其节点体积。该量用于 fastflow 求解方案。

fluid_tension() → float.

获取网格点的流体抗拉极限。

fluid_unbal() → float.

获取网格点的流体不平衡流量（用于 fastflow 求解方案）。

fluid_vol_inv() → float.

获取网格点流体节点体积的倒数。

flux() → float.

获取网格点处的不平衡热通量。

force_app() → vec.

获取网格点处的总施加力。这包括所有来源，包括重力产生的力（向量）。

force_app_x() → float.

获取网格点处总施加力的 x 分量。这包括所有来源，包括重力产生的力。

force_app_y() → float.

获取网格点处总施加力的 y 分量。这包括所有来源，包括重力产生的力。

force_app_z() → float.

获取网格点处总施加力的 z 分量。这包括所有来源，包括重力产生的力。

force_load() → vec.

获取网格点用户施加载荷（向量）。

force_load_x() → float.

获取网格点用户施加载荷的 x 分量。

force_load_y() → float.

获取网格点用户施加载荷的 y 分量。

force_load_z() → float.

获取网格点用户施加载荷的 z 分量。

force_unbal() → vec.

获取网格点不平衡力（向量）。

force_unbal_x() → float.

获取网格点不平衡力的 x 分量。

force_unbal_y() → float.

获取网格点不平衡力的 y 分量。

force_unbal_z() → float.

获取网格点不平衡力的 z 分量。

group([slot: str]) → str.

获取给定槽位中的网格点组名。

group_remove(group_name: str) → bool.

从该网格点的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该网格点属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取网格点 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该网格点是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

local_small() → bool.

获取网格点的局部小应变选项。

mass_add() → vec.

获取该网格点的附加质量向量。在运动方程中，该质量被加到网格点的惯性质量上（向量）。

mass_add_x() → float.

获取网格点附加质量向量的 x 分量。在运动方程中，该质量被加到网格点的惯性质量上。

mass_add_y() → float.

获取网格点附加质量向量的 y 分量。在运动方程中，该质量被加到网格点的惯性质量上。

mass_add_z() → float.

获取网格点附加质量向量的 z 分量。在运动方程中，该质量被加到网格点的惯性质量上。

mass_gravity() → float.

获取网格点的重力质量。

mass_inertial() → float.

获取网格点的惯性质量。

pos() → vec.

获取网格点形心位置（向量）。

pos_x() → float.

获取网格点形心位置的 x 分量。

pos_y() → float.

获取网格点形心位置的 y 分量。

pos_z() → float.

获取网格点形心位置的 z 分量。

pp() → Float.

获取网格点孔隙压力。

pp_fix() → bool.

获取表示网格点孔隙压力是否固定的网格点标志。

ratio() → float.

获取网格点的局部力学收敛比。

ratio_target() → float.

获取网格点的目标局部力学收敛比。默认值为 1e-4。低于该值的局部力比（网格点比值法）视为收敛。见 convergence Gridpoint 方法。

sat() → float.

获取网格点的流体饱和度。

set_disp_small_x(value: float) → None.

设置网格点小位移向量的 x 分量。仅在小应变模型中，小位移才由速度和时步累积。见 model large 命令。小应变向量场用于界面逻辑计算重叠量。

set_disp_small_y(value: float) → None.

set_disp_small_z(value: float) → None.

set_pp(pp: float, update: bool=false) → None.

设置网格点孔隙压力。若可选第二个参数为 true，则除修改网格点孔隙压力外，该方法还会固定网格点压力，并更新自上次力学步以来累积的孔隙压力增量。必须激活渗流计算才能执行该选项。要获得与 zone gridpoint fix pore-pressure f 命令相同的效果，需同时使用 pp_fix 与 pp 方法。

set_pp_fix(value: bool) → None.

设置表示网格点孔隙压力是否固定的网格点标志。

set_ratio_target(value: float) → None.

设置网格点的目标局部力学收敛比。默认值为 1e-4。低于该值的局部力比（网格点比值法）视为收敛。见 convergence Gridpoint 方法。
