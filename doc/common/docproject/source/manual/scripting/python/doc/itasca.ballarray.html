itasca.ballarray

用于 Itasca 球的数组接口。

Functions

itasca.ballarray.create(radii: array float{ball}, centroids: array float{ball, dim}, **kwds) → array int{ball} 新建球的 ID。

由两个数组创建球。第一个数组必须包含半径，第二个数组包含位置。两个数组必须具有正确的形状。可指定其他关键字参数以设置新建球的属性。关键字参数取值可为标量、vec 或一维、二维数组。关键字参数 props 可用于设置球性质，其值应为 {str: value} 类型的字典。关键字参数 extra 可用于设置额外变量，其值应为 {int: value} 类型的字典。props 或 extra 字典的值可为双精度的一维或二维数组、数值、vec 或字符串。
