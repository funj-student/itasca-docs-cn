Template

class itasca.clump.template.Template
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
add_pebble(pebble_radius: float, pebble_position: vec[, pebble_id: int]) → TemplatePebble 对象。

向刚性簇模板添加一个子颗粒。该操作不影响刚性簇模板的惯性属性。若未指定可选参数 ID，则新建子颗粒的 ID 设为下一个可用编号。

clone(new_template_name: str) → Template 对象。

克隆该刚性簇模板。新模板名为 new_template_name，且没有刚性簇引用该新建模板。

delete() → None.

删除该刚性簇模板。所有引用该模板的刚性簇将不再引用任何刚性簇模板。

delete_pebble(pebble: TemplatePebbel object) → None.

从该刚性簇中删除一个 TemplatePebble。该操作不影响刚性簇模板的惯性属性。该刚性簇不再引用刚性簇模板。若有刚性簇引用该模板，该操作将抛出异常。

id() → int.

获取刚性簇模板 ID。

moi() → tensor.

获取刚性簇模板转动惯量。在二维中使用极转动惯量，因此返回值为浮点数。

moi_prin() → vec.

获取刚性簇模板主转动惯量（向量）。

moi_prin_x() → float.

获取刚性簇模板主转动惯量的 x 分量。

moi_prin_y() → float.

获取刚性簇模板主转动惯量的 y 分量。

moi_prin_z() → float.

获取刚性簇模板主转动惯量的 z 分量。

name() → str.

获取刚性簇模板名称。

orig_pos() → vec.

获取刚性簇模板原始位置（向量）。

orig_pos_x() → float.

获取刚性簇模板原始位置的 x 分量。

orig_pos_y() → float.

获取刚性簇模板原始位置的 y 分量。

orig_pos_z() → float.

获取刚性簇模板原始位置的 z 分量。

pebbles() → TemplatePebble 对象的元组。

获取该刚性簇模板的子颗粒。

set_moi() → tensor.

获取刚性簇模板转动惯量。在二维中使用极转动惯量，因此返回值为浮点数。修改时不会改变其他刚性簇属性（例如子颗粒尺寸、刚性簇体积等）。以这种方式指定转动惯量会使主转动惯量处于固定状态，因此在缩放刚性簇时它们不会自动更新，除非用户改变固定状态（见 Clump moi_fix() 方法）。

set_moi_prin(value: vec) → None.

设置刚性簇模板主转动惯量（向量）。

set_moi_prin_x(value: float) → None.

设置刚性簇模板主转动惯量的 x 分量。

set_moi_prin_y(value: float) → None.

设置刚性簇模板主转动惯量的 y 分量。

set_moi_prin_z(value: float) → None.

设置刚性簇模板主转动惯量的 z 分量。

set_orig_pos(value: vec) → None.

设置刚性簇模板原始位置（向量）。

set_orig_pos_x(value: float) → None.

设置刚性簇模板原始位置的 x 分量。

set_orig_pos_y(value: float) → None.

设置刚性簇模板原始位置的 y 分量。

set_orig_pos_z(value: float) → None.

设置刚性簇模板原始位置的 z 分量。

set_vol(value: float) → None.

设置刚性簇模板体积。在二维中为每单位厚度的体积。

valid() → bool.

若该对象为活动刚性簇模板则返回 True。

vol() → float.

获取刚性簇模板体积。在二维中为每单位厚度的体积。
