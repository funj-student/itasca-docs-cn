常见问题

支持哪些 Python 扩展模块？

Python 环境包含以下扩展模块：

  • numpy 1.13.0 数组运算
  • scipy 1.0.0 科学计算库集合
  • networkx 2.1 图论算法
  • fipy 3.1 有限体积
  • numexpr 2.6.4 快速数组表达式求值器。
  • pyside 5.11.0 通过 Python 的 Qt 绑定进行 GUI 编程

能否把其他 Python 扩展模块用于 PFC、FLAC3D 或 3DEC？

大多数第三方 Python 扩展模块都可用于 Itasca 软件。可用程序随附的 pip 可执行文件安装扩展模块。

安装到程序发行版 site-packages 目录中的扩展模块在升级时会被删除。请通过用户方案安装扩展模块以避免此问题。见：Python 用户级替代安装说明页面（https://docs.python.org/2/install/#alternate-installation-the-user-scheme） 这通常涉及为 pip 或其他安装脚本添加 --user 命令行选项。这会把模块安装到：C:\Users\<username>\AppData\Roaming\Python\Python<##>\site-packages 。

若你另有一个 Python 3.6 的 64 位安装，可修改 sys.path 变量，使其包含该安装中的扩展模块。

Python 是否更快？

在 Python 中执行一项操作比 FISH 中的等效操作约快 10%。把循环写成 numpy 数组运算可获得更大的性能提升。用 Cython 创建的扩展模块可与 Itasca 软件配合工作，并能显著提升性能。有关 Cython 编译器的更多信息见 Cython 官网（http://cython.org/）。

能否在 Itasca 软件中使用 IPython Notebook（或 Jupyter）？

不能。Python 解释器嵌入在程序内部，因此不能作为扩展模块加载到外部 Python 解释器中。若有足够需求，Itasca 可能会考虑开发扩展模块的构建目标。
