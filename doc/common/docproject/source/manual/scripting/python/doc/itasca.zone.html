itasca.zone

用于处理 FLAC3D 网格单元的函数与类。

Functions

itasca.zone.containing(point: vec3, search_start=None) → 网格单元对象或 None。

获取包含该点的网格单元。可给出可选参数 search_start，以先搜索指定网格单元。这可加快检查速度。

itasca.zone.count() → int.

获取网格单元数量。

itasca.zone.create_ratio(ratio: float, index: int, isize: int) → float.

按给定比率、索引和数量，用几何级数计算一个值。该比率与 zone create 逻辑、挤出器和 building-blocks 中所用相同。它把 0.0 到 1.0 的区间分为 size 段，每段是前一段的 ratio 倍。\(ratio\) 为所用几何比率，每个区间比前一个大 ratio 倍。\(index\) 为要计算的级数位置索引（从 0 到 size）。\(isize\) 为涉及的区间总数。返回值为从 0 到 size 的几何级数在给定比率和索引处占 0.0 到 1.0 的分数。

itasca.zone.creep_time_total() → float.

获取累积的网格单元模块总蠕变时间。该值累加网格单元蠕变模块活动的每个循环的时步。

itasca.zone.creep_timestep() → float.

获取网格单元蠕变模块活动时所用的时步。若有其他活动模块需要更小的时步，它可能不是实际使用的时步。

itasca.zone.dynamic_time_total() → float.

获取累积的网格单元模块总动力时间。该值累加网格单元动力模块活动的每个循环的时步。

itasca.zone.dynamic_timestep() → float.

获取累积的网格单元模块总蠕变时间。该值累加网格单元蠕变模块活动的每个循环的时步。

itasca.zone.find(id: int) → Zone 对象。

获取具有给定 ID 号的网格单元对象。

itasca.zone.fluid_ratio() → float.

获取网格单元当前的流体收敛比，定义为总不平衡流量与通过网格单元的总流量之比。

itasca.zone.fluid_stress_normal() → float.

获取模型中任意网格点当前的收敛最大值。见 model.solve.convergence 关键字。

itasca.zone.fluid_time_total() → float.

获取累积的网格单元模块总流体时间。该值累加网格单元流体模块活动的每个循环的时步。

itasca.zone.fluid_timestep() → float.

获取当前流体时步。注意，若有其他模块需要更小的时步，它可能不是循环中实际使用的时步。若自动时步计算处于活动状态，该值可能被其覆盖。固定大于计算临界值的时步会产生错误。

itasca.zone.fluid_unbal_avg() → float.

获取 fastflow 求解方案的平均不平衡流体体积限值。

itasca.zone.fluid_unbal_max() → float.

获取 fastflow 求解方案的最大不平衡流体限值。

itasca.zone.force_update() → None.

为循环逻辑置标志，使下一个循环开始时执行几何更新。通常该更新在循环开始时执行，而在大应变模型中按几何更新间隔执行。密度和刚度变化引起的网格点质量与重力变化，若不执行更新可能不会实际影响计算。

itasca.zone.list() → 网格单元迭代器对象。

获取网格单元迭代器对象。

itasca.zone.maxid() → int.

获取最大网格单元 ID。

itasca.zone.mech_convergence() → float.

获取模型中任意网格点当前的收敛最大值。见 model.solve.convergence 关键字。

itasca.zone.mech_ratio() → float.

获取当前网格单元力学收敛比。见 zone ratio 命令。

itasca.zone.mech_ratio_avg() → float.

获取当前网格单元力学平均收敛比。见 zone ratio 命令。

itasca.zone.mech_ratio_local() → float.

获取当前网格单元力学局部收敛比。见 zone ratio 命令。

itasca.zone.mech_ratio_max() → float.

获取当前网格单元力学局部收敛比。见 zone ratio 命令。

itasca.zone.near(point: vec) → Zone 对象。

查找距某点最近的网格单元。
