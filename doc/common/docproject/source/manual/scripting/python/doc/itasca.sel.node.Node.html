节点

class itasca.sel.node.Node
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
attach() → float.

获取节点的连接状态（true = 已连接到网格）。

bond() → float.

获取单元节点与宿主岩/土之间黏结的状态（1 = 完好，2 = 破坏，3 = 无）。

collection() → float.

获取给定节点所属的节点集合 ID。

dis() → vec.

获取节点位移（向量）。

dis_x() → float.

获取节点位移的 x 分量。

dis_y() → float.

获取节点位移的 y 分量。

dis_z() → float.

获取节点位移的 z 分量。

extra(slot: int) → any.

获取给定槽位中的节点额外数据。

fix() → int.

获取节点的约束指示符（false = 不固定（默认）；true = 固定）。

force() → vec.

获取节点力（向量）。

force_app() → vec.

获取节点所受施加力（向量）。

force_app_x() → float.

获取节点所受施加力的 x 分量。

force_app_y() → float.

获取节点所受施加力的 y 分量。

force_app_z() → float.

获取节点所受施加力的 z 分量。

force_shear() → float.

获取剪力。

force_x() → float.

获取节点力的 x 分量。

force_y() → float.

获取节点力的 y 分量。

force_z() → float.

获取节点力的 z 分量。

group([slot: str]) → str.

获取给定槽位中的节点组名。

group_remove(group_name: str) → bool.

从节点的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该节点属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取节点 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该节点是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → float.

获取节点的索引（偏移）。

length() → float.

获取梁单元或锚索节点关联的长度（所连接单元平均长度的一半）。

mass() → float.

获取节点质量。

matnum() → int.

获取赋给节点的材料编号。

pos() → vec.

获取节点位置（向量）。

pos_x() → float.

获取节点位置的 x 分量。

pos_y() → float.

获取节点位置的 y 分量。

pos_z() → float.

获取节点位置的 z 分量。

set_attach(bool) → None.

设置节点的连接状态（true = 已连接到网格）。

set_bond(float) → None.

设置单元节点与宿主岩/土之间黏结的状态（1 = 完好，2 = 破坏，3 = 无）。

set_extra(slot: int, value: any) → None.

设置给定槽位中的节点额外数据。

set_fix(int) → None.

设置节点的约束指示符（false = 不固定（默认）；true = 固定）。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的节点组名。

set_matnum(int) → None.

设置赋给节点的材料编号。

set_vel(value: vec) → None.

设置节点速度（向量）。

set_vel_x(value: float) → None.

设置节点速度的 x 分量。

set_vel_y(value: float) → None.

设置节点速度的 y 分量。

set_vel_z(value: float) → None.

设置节点速度的 z 分量。

valid() → bool.

若该节点为活动对象则返回 True。

vel() → vec.

获取节点速度（向量）。

vel_x() → float.

获取节点速度的 x 分量。

vel_y() → float.

获取节点速度的 y 分量。

vel_z() → float.

获取节点速度的 z 分量。
