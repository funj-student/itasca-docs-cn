Vertex

class itasca.flowplane.vertex.Vertex
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
aperture_hydraulic() → float.

获取受指定最大值限制的水力开度（流平面性质 aperture-maximum）。

aperture_mech() → float.

获取力学开度。

area() → float.

获取汇聚到该顶点的面积。

extra(slot: int) → any.

获取给定槽位中的流平面顶点额外数据。

flowplane() → 流动面指针。

获取与给定流动平面顶点关联的流动平面。

group([slot: str]) → str.

获取给定槽位中的流平面顶点组名。

group_remove(group_name: str) → bool.

从流平面顶点的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该流平面顶点属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取流平面顶点 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该流平面顶点是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取流平面顶点的索引（偏移）。

knot() → 流动节点指针。

获取与给定流动平面顶点关联的流动节点。

local1() → float.

获取流平面顶点的局部 x 坐标。

local2() → float.

获取流平面顶点的局部 x 坐标。

pos() → vec.

获取流平面顶点位置（向量）。

pos_x() → float.

获取流平面顶点位置的 x 分量。

pos_y() → float.

获取流平面顶点位置的 y 分量。

pos_z() → float.

获取流平面顶点位置的 z 分量。

prop(str) → float.

获取流平面性质。

proppant_mconc() → float.

获取流动平面顶点的支撑剂质量浓度。

proppant_thick() → float.

获取流动平面顶点的支撑剂厚度（体积浓度乘以张开度）。

proppant_vconc() → float.

获取支撑剂体积浓度。

set_aperture_mech(float) → None.

设置力学开度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的流平面顶点额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的流平面顶点组名。

set_prop(str, float) → None.

设置流平面性质。

subcontact1() → 接触指针。

获取用于插值的面-面接触的某个子接触。

subcontact2() → 接触指针。

获取用于插值的面-面接触的某个子接触。

valid() → bool.

若该流平面顶点为活动对象则返回 True。

visc() → float.

获取顶点处流体的黏度（若支撑剂浓度大于 0，黏度将高于全局值）。

weight1() → float.

获取流动平面顶点与子接触 1 关联的插值权重。

weight2() → float.

获取流动平面顶点与子接触 2 关联的插值权重。
