Zone

class itasca.flowplane.zone.Zone
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取流动平面区域的面积。

discharge() → vec.

获取流平面网格单元流量（向量）。

discharge_x() → float.

获取流平面网格单元流量的 x 分量。

discharge_y() → float.

获取流平面网格单元流量的 y 分量。

discharge_z() → float.

获取流平面网格单元流量的 z 分量。

extra(slot: int) → any.

获取给定槽位中的流平面网格单元额外数据。

flowplane() → flowplane 指针。

获取与给定流动平面区域关联的流动平面。

group([slot: str]) → str.

获取给定槽位中的流平面网格单元组名。

group_remove(group_name: str) → bool.

从流平面网格单元的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该流平面网格单元属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取流平面网格单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该流平面网格单元是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取给定流平面网格单元的索引（偏移）。

pos() → vec.

获取流平面网格单元位置（向量）。

pos_x() → float.

获取流平面网格单元位置的 x 分量。

pos_y() → float.

获取流平面网格单元位置的 y 分量。

pos_z() → float.

获取流平面网格单元位置的 z 分量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的流平面网格单元额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的流平面网格单元组名。

valid() → bool.

若该流平面网格单元为活动对象则返回 True。

velocity() → vec.

获取流平面网格单元速度（向量）。

velocity_x() → float.

获取流平面网格单元速度的 x 分量。

velocity_y() → float.

获取流平面网格单元速度的 y 分量。

velocity_z() → float.

获取流平面网格单元速度的 z 分量。

vertex(int) → 顶点指针。

获取流平面网格单元的顶点。
