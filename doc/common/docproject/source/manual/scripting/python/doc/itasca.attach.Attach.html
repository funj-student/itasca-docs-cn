Attach

class itasca.attach.Attach
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
attach_delete() → None.

删除一个附着。

extra(slot: int) → any.

获取给定槽位中的连接额外数据。

group([slot: str]) → str.

获取给定槽位中的连接组名。

group_remove(group_name: str) → bool.

从该连接的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该连接属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取连接 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该连接是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

master() → 网格点对象的元组。

该函数按网格点、边或面连接类型，返回由 1、2 或 4 个网格点对象组成的元组。

master_face() → 整数或 None。

获取与该连接条件关联的面索引（0 到 5）；若不是面连接则返回 None。

master_zone() → 网格单元对象或 None。

获取面连接的主网格单元指针。若连接类型不是面，则该函数返回 None。

pos() → vec3.

获取连接点位置。

set_extra(slot: int, value: any) → None.

设置给定槽位中的连接额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的连接组名。

set_snap(value: bool) → None.

设置连接点的吸附选项。若 snap 为 True，则位于相对连接面上的网格点将保持其位置。snap 默认为 True。

set_weight_edge(weight: float) → None.

设置 0.0 到 1.0 范围内的一个值，用于描述网格点在边连接中的位置。若连接类型不是边，则该函数抛出 ValueError。

set_weight_face(weight: vec3) → None.

用向量值 weight 设置面权分量。各分量必须在 0 到 1.0 范围内，且总和须小于 1.0。该值对应网格点在面内相对于面顶点的位置，适用于面连接。第四个四边形权重可由 1.0 减去向量上三个权重得到。若连接不是面类型，则抛出 ValueError。

slave() → Gridpoint 对象。

获取从属网格点。

snap() → bool.

获取连接点的吸附选项。若 snap 为 True，则位于相对连接面上的网格点将保持其位置。snap 默认为 True。

type() → str.

取决于连接类型，取值为“gridpoint”、“edge”或“face”。

valid() → bool.

若该连接为活动连接则返回 True。

weight_edge() → 浮点数或 None。

获取 0.0 到 1.0 范围内的一个值，用于描述网格点在边连接中的位置。若连接类型不是边，则该函数返回 None。

weight_face() → vec3.

获取一个各分量均在 0 到 1.0 范围内的向量。该值对应网格点在面内相对于面顶点的位置，适用于面连接。第四个四边形权重可由 1.0 减去向量上三个权重得到。若连接不是面类型，则返回 None。
