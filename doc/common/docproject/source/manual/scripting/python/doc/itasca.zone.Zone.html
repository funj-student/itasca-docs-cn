Zone

class itasca.zone.Zone
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
adjacent_zones() → 长度为 6 的 Zone 对象元组或 None。

返回通过拓扑完好的面与本网格单元相邻的网格单元元组。若第 i 个面没有相邻面，则元组第 i 个元素为 None。

aspect() → float.

获取网格单元长宽比的度量。接近零的值表示长宽比很大的网格单元。定义为网格单元相邻边中最小边长与最大边长之比的最小值。

condition() → float.

获取网格单元的条件数。该值总体指示网格单元几何形状的良好程度。1.0 表示完美的立方体网格单元，0.0 表示不可用的网格单元。

copy_to(destination: itasca.zone.Zone) → None.

把该网格单元的状态信息复制到目标网格单元。

create_interface_element(face_index: int, interface_name: str) → int.

创建连接到 face_index 所给面的新界面单元。face_index 从 0 开始。新建界面单元将添加到 interface_name 指定的界面中；若该界面不存在则创建。返回创建的界面单元数量。若该面已有界面，则返回 0。

density() → float.

获取网格单元密度。

extra(slot: int) → any.

获取给定槽位中的网格单元额外数据。

face_areas() → 浮点数的元组。

获取该网格单元各面的面积。

face_extra(face_index: int, extra_index: int) → any.

获取与 face_index 关联、索引为 extra_index 的额外变量取值。face_index 从零开始，extra_index 从 1 开始。

face_find(gp0, gp1, gp2) → 整数或 None。

获取包含网格点 gp0、gp1 和 gp2 的网格单元的面索引。每个网格点可用 itasca.gridpoint.Gridpoint 对象或 ID 号指定。若找到该面，则返回 0 到 5 之间的值；若未找到面，则返回 None。

face_find_normal(normal: vec3) → int.

获取外法向最接近方向 normal 的网格单元的面索引。该函数返回 0 到 5 的值。

face_group(face_index: int, slot='Default') → 字符串或 None。

获取槽位 slot 中由 face_index 标识的面所关联的组名。face_index 从零开始。若给定槽位未赋组，则返回 None。

face_group_remove(face_index: int, group_name: str) → bool.

从所标识的面和 face_index 中移除 group_name。若该组尚未赋给该面，则返回 false。它会从找到该组名的所有槽位中移除该名称。face_index 从零开始。

face_in_group(face_index: int, group_name: str, slot='Default') → bool.

检查 group_name 是否与 face_index 指示的网格单元面关联。默认检查任意槽位中的匹配；若指定可选参数 slot，则只在该槽位中返回匹配。注意，只要与该面相连的任一网格单元包含该组名，或该面本身包含，该函数就返回匹配。face_index 从零开始。

face_normals() → 向量的元组。

获取网格单元所有面的外法向向量。

faces() → Gridpoint 对象元组之元组。

获取包含各面网格点对象的元组之元组。

flow() → vec.

获取网格单元的比流量向量（向量）。

flow_x() → float.

获取网格单元比流量向量的 x 分量。

flow_y() → float.

获取网格单元比流量向量的 y 分量。

flow_z() → float.

获取网格单元比流量向量的 z 分量。

fluid_model() → str.

获取网格单元的渗流本构模型。

fluid_prop(property_name: str) → float.

获取该网格单元的某个流体性质取值。

fluid_props() → dict {str: any}.

返回包含流体性质的字典。

flux() → vec.

获取网格单元平均热流向量（向量）。

flux_x() → float.

获取网格单元平均热流向量的 x 分量。

flux_y() → float.

获取网格单元平均热流向量的 y 分量。

flux_z() → float.

获取网格单元平均热流向量的 z 分量。

geom_test() → bool.

检验网格单元的几何适应性。若网格单元良好则返回 true，若不良则返回 false。

gridpoints() → Gridpoint 对象的元组。

获取属于该网格单元的网格点对象元组。

group([slot: str]) → str.

获取给定槽位中的网格单元组名。

group_remove(group_name: str) → bool.

从该网格单元的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该网格单元属于哪些组的字典。字典的键为槽位名，值为组名。

has_prop(property_name: str) → bool.

若该网格单元具有给定表面性质则返回 True。

hysteretic_props() → dict {string: float}.

以 Python 字典形式获取该网格单元的滞回阻尼性质。

id() → int.

获取网格单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该网格单元是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

live() → bool.

检查网格单元是否为活动状态，即其是否具有非空的力学、热学或流体本构模型。

model() → string.

获取该网格单元的当前力学本构模型。

model_init() → None.

初始化赋给网格单元的所有本构模型（力学、流体与热学）。这会依据当前性质重新计算中间值。若在循环过程中改变了性质值，则可能需要这样做。注意力学本构模型应在性质改变时自动重算中间存储值。该命令不执行依据刚度或密度的取值更新，见 itasca.zone.do_update() 函数。

num_gp() → int.

获取与该类网格单元关联的唯一网格点数量。对四面体网格单元可少至 4，对六面体网格单元可多至 8。

ortho() → float.

获取网格单元正交性的度量。接近零的值表示网格单元严重非正交。

overlays() → int.

获取网格单元可用的 overlay 数量。该数通常为 2。若网格单元变形到使某个 overlay 含零体积或负体积四面体，或在 zone cmodel assign 命令中有意只创建一个 overlay，则该值可能为 1。值为 0 表示该网格单元从未赋予本构模型，因此从未创建内部四面体。

planarity() → float.

获取网格单元四边形面平面性的度量。值为 0 表示所有面完全共面。该数值越大，面越不共面。

plane_traction(vdir: vec3) → (traction: vec, normal_stress: float, max_shear_stress: float, max_shear_stress_direction: vec3).

获取网格单元在垂直于 vdir 的平面上的面力。返回值为元组，包含面力（向量）、法向应力（浮点数）、最大剪应力（浮点数）和最大剪应力方向（向量）。

pos() → vec.

获取网格单元形心位置（向量）。

pos_x() → float.

获取网格单元形心位置的 x 分量。

pos_y() → float.

获取网格单元形心位置的 y 分量。

pos_z() → float.

获取网格单元形心位置的 z 分量。

pp() → float.

获取网格单元平均孔隙压力。

prop(property_name: str) → any.

获取该网格单元的某个性质取值。

props() → dict {str: any}.

返回包含力学性质的字典。

rotation() → stens3.

获取网格单元转动增量张量。该张量用当前位移场计算。

rotation_rate() → stens3.

获取网格单元转动率张量。该张量用当前速度场计算。

set_density(value: float) → None.

设置网格单元密度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的网格单元额外数据。

set_face_extra(face_index: int, extra_index: int, value: any) → None.

设置与 face_index 关联、索引为 extra_index 的额外变量取值。face_index 从零开始。

set_face_group(face_index: int, group_name: str, slot='Default') → None.

设置槽位 slot 中由 face_index 标识的面所关联的组名。face_index 从零开始。

set_fluid_model(model: str) → None.

设置网格单元的渗流本构模型。当前可用的本构模型为 anisotropic、isotropic 和 null。

set_fluid_prop(property_name: str) → float.

设置该网格单元的某个流体性质取值。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的网格单元组名。

set_model(value: string) → None.

设置该网格单元的当前力学本构模型。

set_pp(value: float) → None.

设置网格单元平均孔隙压力。

set_prop(property_name: str, value: any) → None.

设置该网格单元的一个表面性质。

set_state(state: int) → None.

设置该网格单元的当前塑性状态指示符。

set_stress(stress: stens3) → None.

设置网格单元应力张量。

set_temp(value: float) → None.

设置网格单元温度。

set_therm_prop(property_name: str) → float.

设置该网格单元某个热学性质的取值。

set_thermal_model(model: str) → None.

设置网格单元的热流本构模型。当前可用的本构模型为 advection-conduction、anisotropic、hydration、isotropic 和 null。

set_work_elastic_shear(value: float) → None.

设置网格单元剪切弹性功耗散。

set_work_elastic_vol(value: float) → None.

设置网格单元体积弹性功耗散。

set_work_plastic_shear(value: float) → None.

设置网格单元剪切塑性功耗散。

set_work_plastic_vol(value: float) → None.

设置网格单元体积塑性功耗散。

state(average: bool) → int.

获取该网格单元的当前塑性状态指示符。若参数 average 为 true，则当体积平均四面体中 50% 或更多设置了该位时该位被置位；若为 false，则只要网格单元中有任一四面体设置了该位就被置位。

strain() → stens3.

基于当前位移场获取网格单元应变增量。

strain_rate() → stens3.

基于当前速度场获取网格单元应变率。

strain_shear_inc() → float.

获取基于当前位移场的网格单元剪切应变增量，即应变增量偏量的第二不变量平方根。

strain_shear_rate() → float.

获取基于当前速度场的网格单元剪切应变率，即应变率偏量的第二不变量平方根。

strain_vol_inc() → float.

获取基于当前位移场的网格单元体积应变增量，即应变增量张量的迹。

strain_vol_rate() → float.

获取基于当前速度场的网格单元体积应变率，即应变率张量的迹。

stress() → stens3.

获取网格单元应力张量。

stress_effective() → stens3.

获取网格单元有效应力。即四面体应力的体积加权平均值加上网格单元平均孔隙压力。

stress_int() → float.

获取网格单元四面体应力体积加权平均值的中主应力。

stress_max() → float.

获取体积平均四面体应力的最大（最正）主值。注意，在 FLAC3D 中压应力为负。

stress_min() → float.

获取体积平均四面体应力的最小（最负）主值。注意，在 FLAC3D 中压应力为负。

stress_prin() → vec.

获取网格单元主应力，由四面体应力的体积加权平均值计算得到（向量）。

stress_prin_dir() → (vec3, tens3).

返回元组，包含以 vec 表示的主应力大小和以 tens3 表示的主应力方向。

stress_prin_x() → float.

获取网格单元主应力的 x 分量，由四面体应力的体积加权平均值计算得到。

stress_prin_y() → float.

获取网格单元主应力的 y 分量，由四面体应力的体积加权平均值计算得到。

stress_prin_z() → float.

获取网格单元主应力的 z 分量，由四面体应力的体积加权平均值计算得到。

temp() → float.

获取网格单元温度。通常为各网格点温度的平均值。若使用过 zone thermal zone-based-temperature 命令，则温度直接存储于网格单元并从其中读取。

test_quality() → (length_vol: float, skew: float).

获取网格单元质量的度量，即网格单元形状可能如何影响求解精度。第一个值表示体积与边长之比的检验，第二个值表示歪斜的检验。两者均返回所有内部四面体中的最小值。返回 1.0 表示等边四面体。

tet_strain_rates() → 多层 stens3 的元组。

获取所有四面体应变率张量。返回两个张量元组，每个 overlay 一个。

tet_strains() → 多层 stens3 的元组。

获取所有四面体应变张量。返回两个张量元组，每个 overlay 一个。

tet_stresses() → 多层 stens3 的元组。

获取所有四面体应力张量。返回两个张量元组，每个 overlay 一个。

tet_volumes() → 多层浮点数的元组。

获取各四面体的体积。返回两个元组，每个 overlay 一个。任何循环开始前这些值为零。

tets() → itasca 的元组之元组之元组。

gridpoint.Gridpoint 对象。获取构成各四面体的网格点。返回两个元组，每个 overlay 一个。

therm_prop(property_name: str) → float.

获取该网格单元的某个热学性质取值。

therm_props() → dict {str: any}.

返回包含热学性质的字典。

thermal_model() → str.

获取网格单元的热流本构模型。

type() → str.

获取网格单元类型，取以下之一：“brick”、“wedge”、“pyramid”、“dbrick” 或 “tetra”。

valid() → bool.

若该网格单元为活动单元则返回 True。

vol() → float.

获取用网格单元网格点当前位置计算的网格单元体积。

vol_deformed() → float.

使用计入累积网格点位移的网格点位置获取网格单元体积。该方法用于小应变分析中需要变形后网格单元体积的情形。不应在大应变分析中使用该方法（会返回不正确的体积）。大应变模式下请使用网格单元对象的 .vol()。

work_elastic_shear() → float.

获取网格单元剪切弹性功耗散。

work_elastic_total() → float.

获取总弹性功。

work_elastic_vol() → float.

获取网格单元体积弹性功耗散。

work_plastic_shear() → float.

获取网格单元剪切塑性功耗散。

work_plastic_total() → float.

获取耗散的总塑性功。

work_plastic_vol() → float.

获取网格单元体积塑性功耗散。
