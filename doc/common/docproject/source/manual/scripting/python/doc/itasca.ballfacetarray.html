itasca.ballfacetarray

用于 Itasca 球-面片接触的数组接口。

Functions

itasca.ballfacetarray.branch() → array float{contact,3}.

获取全局坐标系中接触分支向量的 numpy 数组。

itasca.ballfacetarray.extra(slot: int) → array float{contact} or float{contact,3}.

以数组形式获取给定槽位中的接触额外数据。通过数组访问的额外变量必须为 float 或 vec 类型。

itasca.ballfacetarray.fill_branch(data: array float{contact, 3}) → None.

用全局坐标系中的接触分支向量填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_force_global(data: array float{contact, 3}) → None.

用全局坐标系中的接触力填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_force_local(data: array float{contact, 3}) → None.

用局部坐标系中的接触力填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_force_normal(data: array float{contact}) → None.

用接触法向力填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_force_shear(data: array float{contact}) → None.

用接触剪切力的大小填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_gap(data: array float{contact}) → None.

用接触间隙填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_moment1_global(data: array float{contact, 3}) → None.

用全局坐标系中作用在 end 1 上的接触力矩填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_moment1_local(data: array float{contact, 3}) → None.

用局部坐标系中作用在 end 1 上的接触力矩填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_moment2_global(data: array float{contact, 3}) → None.

用全局坐标系中作用在 end 2 上的接触力矩填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_moment2_local(data: array float{contact, 3}) → None.

用局部坐标系中作用在 end 2 上的接触力矩填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_normal(data: array float{contact, 3}) → None.

用接触法向填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_offset(data: array float{contact, 3}) → None.

用接触偏移填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.fill_pos(data: array float{contact, 3}) → None.

用接触位置填充已有数组。该数组必须具有正确的形状。

itasca.ballfacetarray.force_global() → array float{contact,3}.

获取全局坐标系中接触力的 numpy 数组。

itasca.ballfacetarray.force_local() → array float{contact,3}.

获取局部坐标系中接触力的 numpy 数组。

itasca.ballfacetarray.force_normal() → array float{contact}.

获取接触法向力的 numpy 数组。

itasca.ballfacetarray.force_shear() → array float{contact}.

获取接触剪切力大小的 numpy 数组。

itasca.ballfacetarray.gap() → array float{contact}.

获取接触间隙的 numpy 数组。

itasca.ballfacetarray.ids() → array int{contact}.

以数组形式获取接触 ID。

itasca.ballfacetarray.in_group(group_name: str, slot=1) → array bool{contact}.

以布尔数组返回接触所属的组。

itasca.ballfacetarray.moment1_global() → array float{contact,3}.

获取全局坐标系中作用在 end 1 上的接触力矩的 numpy 数组。

itasca.ballfacetarray.moment1_local() → array float{contact,3}.

获取局部坐标系中作用在 end 1 上的接触力矩的 numpy 数组。

itasca.ballfacetarray.moment2_global() → array float{contact,3}.

获取全局坐标系中作用在 end 2 上的接触力矩的 numpy 数组。

itasca.ballfacetarray.moment2_local() → array float{contact,3}.

获取局部坐标系中作用在 end 2 上的接触力矩的 numpy 数组。

itasca.ballfacetarray.normal() → array float{contact,3}.

获取接触法向的 numpy 数组。

itasca.ballfacetarray.offset() → array float{contact,3}.

获取接触偏移的 numpy 数组。

itasca.ballfacetarray.pos() → array float{contact,3}.

获取接触位置的 numpy 数组。

itasca.ballfacetarray.set_extra(slot: int, data: array float{contact} or float{contact, 3}) → None.

用数组设置给定槽位中的接触额外数据。通过数组设置的额外变量必须为 float 或 vec 类型。

itasca.ballfacetarray.set_group(membership: array bool{contact}, group_name: str, slot=1) → None.

由数组设置接触组。若成员标志为 True，则把相应接触设为给定槽位中组 group_name 的成员。
