测量

class itasca.measure.Measure
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
coordination() → float.

获取测量对象的协调性。

delete() → None.

删除此量测对象。

id() → int.

获取测量对象 ID。

porosity() → float.

获取测量对象的孔隙率。

pos() → vec.

获取测量对象位置（向量）。

pos_x() → float.

获取测量对象位置的 x 分量。

pos_y() → float.

获取测量对象位置的 y 分量。

pos_z() → float.

获取测量对象位置的 z 分量。

radius() → float.

获取测量对象半径。

set_pos(value: vec) → None.

设置测量对象位置（向量）。

set_pos_x(value: float) → None.

设置测量对象位置的 x 分量。

set_pos_y(value: float) → None.

设置测量对象位置的 y 分量。

set_pos_z(value: float) → None.

设置测量对象位置的 z 分量。

set_radius(value: float) → None.

设置测量对象半径。

size() → array float{nbin,2}.

获取落入该测量对象的累积尺寸分布 numpy 数组，其中 nbin 为尺寸分布计算的箱数（见 MEASURE CREATE 或 MEASURE MODIFY 命令）。

strainrate() → tensor.

获取为该测量对象计算的应变率张量。

strainrate_full() → tensor.

获取为该测量对象计算的全应变率张量。

stress() → tensor.

获取为该测量对象计算的应力张量。

stress_full() → tensor.

获取为该测量对象计算的全应力张量。

valid() → bool.

若该测量对象为活动对象则返回 True。
