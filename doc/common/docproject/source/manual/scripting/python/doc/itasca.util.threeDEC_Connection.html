ThreeDEC_Connection

class itasca.util.ThreeDEC_Connection
启动并连接到 3DEC。
connect() → None.

连接到 Itasca 软件，读取 fishcode 以确认连接。在调用 start 方法启动程序后，调用该函数建立套接字连接。

end() → None.

关闭套接字连接。

receive() → any.

从 Itasca 程序中读取一个数据项。

send(data: any) → None.

向 Itasca 程序发送一个数据项。

shutdown() → None.

关闭正在运行的软件代码。

start(datafile_name: str) → None.

在独立进程中启动 Itasca 软件并打开指定的数据文件。必须在 Itasca 软件中按下绿色执行按钮才会开始计算。
