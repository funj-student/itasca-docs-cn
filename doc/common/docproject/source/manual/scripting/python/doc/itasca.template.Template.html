class itasca.template.Template
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
dipdirmax() → float.

获取模板最大倾向（度）。

dipdirmin() → float.

获取模板最小倾向（度）。

dipmax() → float.

获取模板最大倾角（度）。

dipmin() → float.

获取模板最小倾角（度）。

id() → int.

获取模板 ID。

name() → string.

获取模板名称。

norientparam() → int.

获取模板的方位参数个数。

nposparam() → int.

获取模板的位置参数个数。

nsizeparam() → int.

获取模板的尺寸参数个数。

orientparam(index) → 字符串或浮点数。

获取方位参数。参数个数可用 norientparam 方法获得。

orienttype() → string.

获取模板方位类型名。可接受值为 uniform、gauss、powerlaw、bootstrapped、fish、fisher（仅三维）和 dips（仅三维）。

posparam(index) → 字符串或浮点数。

获取位置参数。参数个数可用 nposparam 方法获得。

postype() → string.

获取模板方位类型名。可接受值为 uniform、gauss、bootstrapped 和 fish。

设置模板最大倾角（度）。

set_dipmin(value: float) → None.

set_orientparam(index, parameter) → None.

set_orienttype(value: string) → None.

设置模板方位类型名。可接受值为 uniform、gauss、powerlaw、bootstrapped、fish、fisher（仅三维）和 dips（仅三维）。

set_posparam(index, parameter) → None.

设置位置参数。该参数可为字符串或浮点数，取决于参数。参数个数可用 nposparam 方法获得。

set_postype(value: string) → None.

设置模板方位类型名。可接受值为 uniform、gauss、bootstrapped 和 fish。

set_sizemax(value: float) → None.

设置模板最大尺寸。裂隙尺寸定义为{二维中裂隙长度；三维中圆盘直径}。

set_sizemin(value: float) → None.

设置模板最小尺寸。裂隙尺寸定义为{二维中裂隙长度；三维中圆盘直径}。

set_sizeparam(index, parameter) → None.

设置尺寸参数。该参数可为字符串或浮点数，取决于参数。参数个数可用 nposparam 方法获得。

set_sizetype(value: string) → None.

设置模板尺寸类型名。可接受值为 uniform、gauss、powerlaw、bootstrapped 和 fish。

sizemax() → float.

获取模板最大尺寸。裂隙尺寸定义为{二维中裂隙长度；三维中圆盘直径}。

sizemin() → float.

获取模板最小尺寸。裂隙尺寸定义为{二维中裂隙长度；三维中圆盘直径}。

sizeparam(index) → 字符串或浮点数。

获取尺寸参数。参数个数可用 nsizeparam 方法获得。

sizetype() → string.

获取模板尺寸类型名。可接受值为 uniform、gauss、powerlaw、bootstrapped 和 fish。
