itasca.deterministic() → bool.

获取确定性模式。在确定性模式下，所有以相同初始条件开始的模型运行都会得到相同解，代价是性能下降 20% 以上。而在非确定性模式下，相同的初始条件可能导致不同的解。这种差异仅由求和顺序造成，所有解在机器精度上同样有效。

itasca.set_callback(function_name: str, call_point: float or str) → None.

注册一个在循环序列中被调用的 Python 函数。第一个参数为函数名字符串，第二个参数可以是浮点数（给出其在循环序列中的位置），也可以是某个预定义回调事件对应的字符串。给定名称的函数应存在于 __main__ Python 命名空间中，且应能以任意数目的参数调用。

itasca.set_deterministic(value: bool) → None.

设置确定性模式。在确定性模式下，所有以相同初始条件开始的模型运行都会得到相同解，代价是性能下降 20% 以上。而在非确定性模式下，相同的初始条件可能导致不同的解。这种差异仅由求和顺序造成，所有解在机器精度上同样有效。

itasca.set_domain_condition(direction: string, condition: string) → None.

设置给定域方向的域条件。域方向的可接受值为{二维中的 ‘x’ 或 ‘y’；三维中的 ‘x’、‘y’ 或 ‘z’}。可接受的条件为 ‘destroy’、‘periodic’、‘reflect’ 和 ‘stop’。
