itasca.attach

用于处理 FLAC3D 网格点连接的函数与类。

Functions

itasca.attach.count() → int.

获取连接数量。

itasca.attach.create(slave: Gridpoint object, a1: Zone or Gridpoint object, a2=None: Gridpoint object or face index (0-5)) → 整数。

创建新的 attach（附着）。第一个参数为从属网格点。后续参数的数目与类型取决于所创建的附着类型。若只给出一个 Gridpoint 对象，则创建网格点附着；若给出两个 Gridpoint 对象，则创建边附着；若给出一个 Zone 对象与一个面索引（0 到 5），则创建面附着。若无法创建附着，则函数返回 None。附着权重依据当前几何自动确定，但可用 weight_edge 或 weight_face 方法覆盖。

itasca.attach.find(id: int) → Attach 对象。

获取具有给定 ID 号的连接对象。

itasca.attach.list() → 附着迭代器对象。

获取连接迭代器对象。

itasca.attach.maxid() → int.

获取最大连接 ID。
