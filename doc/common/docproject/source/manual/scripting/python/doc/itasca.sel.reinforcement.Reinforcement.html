Reinforcement

class itasca.sel.reinforcement.Reinforcement
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
b1() → float.

获取加筋单元的块段 1。

b2() → float.

获取加筋单元的块段 2。

collection() → int.

获取一组加筋单元的集合 ID。

dir() → vec.

获取加固单元方向（向量）。

dir_x() → float.

获取加固单元方向的 x 分量。

dir_y() → float.

获取加固单元方向的 y 分量。

dir_z() → float.

获取加固单元方向的 z 分量。

disp_axial() → float.

获取加筋单元中的轴向位移。

disp_shear() → vec.

获取加固单元剪切位移（向量）。

disp_shear_x() → float.

获取加固单元剪切位移的 x 分量。

disp_shear_y() → float.

获取加固单元剪切位移的 y 分量。

disp_shear_z() → float.

获取加固单元剪切位移的 z 分量。

extra(slot: int) → any.

获取给定槽位中的加固单元额外数据。

face1() → float.

获取加筋单元所附着的第一个块体面。

face2() → float.

获取加固单元所连接的第二个块体面。

force_axial() → float.

获取加筋单元中的轴力。

force_shear() → vec.

获取加固单元剪切力（向量）。

force_shear_x() → float.

获取加固单元剪切力的 x 分量。

force_shear_y() → float.

获取加固单元剪切力的 y 分量。

force_shear_z() → float.

获取加固单元剪切力的 z 分量。

group([slot: str]) → str.

获取给定槽位中的加固单元组名。

group_remove(group_name: str) → bool.

从加固单元的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该加固单元属于哪些组的字典。字典的键为槽位名，值为组名。

halflength() → float.

获取加筋单元的半长。

id() → int.

获取加固单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该加固单元是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → float.

获取给定加筋单元在加筋单元列表中的索引。

matnum() → float.

获取赋给加固单元的材料编号。

pos() → vec.

获取加固单元位置（向量）。

pos_x() → float.

获取加固单元位置的 x 分量。

pos_y() → float.

获取加固单元位置的 y 分量。

pos_z() → float.

获取加固单元位置的 z 分量。

rupture_shear() → float.

获取加固单元的极限剪切应变。

rupture_tension() → float.

获取加固单元的极限拉伸应变。

set_extra(slot: int, value: any) → None.

设置给定槽位中的加固单元额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的加固单元组名。

state() → str.

获取加固单元的状态指示符。

stiffness_axial() → float.

获取加固单元的轴向刚度（单位：力/位移）。

stiffness_shear() → float.

获取加筋单元的剪切刚度（单位为力/位移）。

strain_axial() → float.

获取加筋单元的轴向应变。

strain_shear() → float.

获取加筋单元的剪切应变。

valid() → bool.

若该加固单元为活动对象则返回 True。

yield_shear() → float.

获取加筋单元的剪切屈服强度（单位为力）。

yield_tension() → float.

获取加筋单元的拉伸屈服强度（单位为力）。
