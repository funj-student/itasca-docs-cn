ThermalFacet

class itasca.wall.thermal.facet.ThermalFacet
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
contact_count(all=False, type=None) → int.

获取与该热学子颗粒关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。可选 type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallThermalContact、itasca.BallPebbleThermalContact、itasca.PebblePebbleThermalContact、itasca.BallFacetThermalContact 或 itasca.PebbleFacetThermalContact 之一）。若可选关键字参数 all 为 True，则计数包含虚拟接触。

contacts([piece, ]all=False, type=None) → Contact 对象的元组。

获取与该热学子颗粒关联的接触元组。可包含一个可选参数，即片体对象（热学球、热学子颗粒或热学面片）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallThermalContact、itasca.BallPebbleThermalContact、itasca.PebblePebbleThermalContact、itasca.BallFacetThermalContact 或 itasca.PebbleFacetThermalContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

extra(slot: int) → any.

获取给定槽位中的热学面片额外数据。

facet() → 子颗粒对象。

获取与该热学子颗粒对应的子颗粒。

group([slot: int]) → str.

获取给定槽位中的热学面片组名。

group_remove(group_name: str) → int.

从热学面片移除给定组。需要一个字符串类型的参数给出组名。返回值为整数：找到该组名的第一个槽位；若未找到则为 -1。

groups() → 字符串的元组。

获取赋给该热学面片的组名元组。

has_prop(property_name: str) → bool.

若该热学面片具有给定表面性质则返回 True。

id() → int.

获取热学面片 ID。

in_group(group_name: str) → bool.

检验该热学面片是否属于给定组。搜索所有组槽位。

pos() → vec.

获取热学面片位置（向量）。

pos_x() → float.

获取热学面片位置的 x 分量。

pos_y() → float.

获取热学面片位置的 y 分量。

pos_z() → float.

获取热学面片位置的 z 分量。

prop(property_name: str) → any.

获取该热学面片某个表面性质的取值。

props() → dict {str: any}.

获取该热学面片所有表面性质的字典。

set_extra(slot: int, value: any) → None.

设置给定槽位中的热学面片额外数据。

set_group([group_name: str[, slot: int]]) → None.

设置给定槽位中的热学面片组名。

set_prop(property_name: str, value: any) → None.

设置该热学面片的一个表面性质。

set_temp(value: float) → None.

设置热学面片温度。

temp() → float.

获取热学面片温度。

valid() → bool.

若该热学面片为活动对象则返回 True。

wall() → 热学刚性簇对象。

获取与该子颗粒对应的热学刚性簇。
