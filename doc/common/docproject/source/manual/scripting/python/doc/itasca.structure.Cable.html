Cable

class itasca.structure.Cable
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取锚索单元的横截面积。

component_id() → int.

获取锚索组件 ID。

connectivity(component: int) → bool.

获取该单元中组件 ID 为 id 的节点的索引。若该单元中没有匹配的节点，则抛出 ValueError 异常。

delete() → None.

删除此结构单元。

density() → float.

获取该结构单元的密度。

extra(slot: int) → any.

获取给定槽位中的锚索额外数据。

force_axial() → float.

获取单元的平均轴力（正为拉力，负为压力）。

force_nodal() → (vec3, vec3, vec3, vec3).

获取作用在各端的广义节点力。先给出节点 1 的平动和转动分量。

group([slot: str]) → str.

获取给定槽位中的锚索组名。

group_remove(group_name: str) → bool.

从锚索的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该锚索属于哪些组的字典。字典的键为槽位名，值为组名。

grout_cohesion() → float.

获取注浆体的黏聚力。

grout_confining() → (float, float).

获取作用在各端浆体上的围压。负值表示压缩。该应力作用在垂直于锚索轴线的平面内；有效围压为该平面内主应力的平均值。

grout_dir() → (vec3, vec3).

获取各端耦合弹簧对锚索施加载荷的方向向量。

grout_disp() → (vec3, vec3).

获取各端浆体（剪切耦合弹簧）中的位移；相对锚索平均轴向方向为正或负。

grout_friction() → float.

获取浆体内摩擦角。

grout_perimeter() → float.

获取注浆体的外露周长。

grout_slip() → (int, int).

获取各端浆体（剪切耦合弹簧）的滑动状态。返回值 {0, 1, 2} 分别表示从未滑动、正在滑动或曾经滑动。

grout_stiffness() → float.

获取浆体刚度。

grout_stress() → (float, float).

获取各端浆体（剪切耦合弹簧）中的应力；相对锚索平均轴向方向为正或负。

id() → int.

获取锚索结构单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该锚索是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

length() → float.

获取锚索单元的长度。

local_system() → Tens3.

以 3x3 张量形式获取该单元的局部坐标系。

mark() → bool.

获取结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

nodes() → 结构单元节点对象元组。

获取连接到该单元的结构单元节点元组。

pos() → vec3.

获取单元的位置向量，定义为单元形心。

set_area(float) → None.

设置锚索单元的横截面积。

set_density(float) → None.

设置该结构单元的密度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的锚索额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的锚索组名。

set_grout_cohesion(float) → None.

设置浆体黏聚力。

set_grout_friction(float) → None.

设置浆体内摩擦角。

set_grout_perimeter(perimeter: float) → None.

设置浆体外露周长。

set_grout_stiffness(float) → None.

设置浆体刚度。

set_mark(bool) → None.

设置结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

set_slide(bool) → None.

设置大应变滑动的布尔标志。若为 True 则启用滑动；若为 False 则关闭滑动。

set_slide_tol(bool) → None.

设置锚索单元的大应变滑动容差。

set_thermal_expansion(float) → None.

设置该结构单元的热膨胀系数。

set_yield_compression(float) → float.

设置锚索单元的压缩屈服强度。

set_yield_tension(float) → None.

设置锚索单元的拉伸屈服强度。

set_young(float) → None.

设置锚索单元的杨氏模量。

slide() → bool.

获取大应变滑动的布尔标志。若为 True 则启用滑动；若为 False 则关闭滑动。

slide_tol() → float.

获取锚索单元的大应变滑动容差。

state_compression() → int.

获取锚索单元的压缩屈服状态。返回值 {0, 1, 2} 分别表示未屈服、正在屈服或曾经屈服。

state_tension() → int.

获取锚索单元的拉伸屈服状态。返回值 {0, 1, 2} 分别表示未屈服、正在屈服或曾经屈服。

stress_axial() → float.

获取锚索单元的平均轴向应力（正为拉力，负为压力）。

thermal_expansion() → float.

获取该结构单元的热膨胀系数。

valid() → bool.

若该锚索为活动对象则返回 True。

volume() → float.

获取锚索单元体积，即横截面积乘以长度。

yield_compression() → float.

获取锚索单元的压缩屈服强度。

yield_tension() → float.

获取锚索单元的拉伸屈服强度。

young() → float.

获取锚索单元的杨氏模量。
