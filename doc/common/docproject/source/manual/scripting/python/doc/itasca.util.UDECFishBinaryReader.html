UDECFishBinaryReader

class itasca.util.UDECFishBinaryReader
用于读取 UDEC 生成文件的 FishBinarReader 专用版本。
asarray() → numpy 数组。

以 numpy 数组返回 FISH 文件内容。各元素类型必须一致。

aslist() → [any].

以 Python 列表返回 FISH 文件内容。

next() → any.

从 FISH 二进制文件中获取下一个数据项。

read() → any.

从 .fish 二进制文件中读取并返回一个值（转换为 Python 类型）。
