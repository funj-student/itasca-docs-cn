Facet

class itasca.wall.facet.Facet
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
active() → int.

获取面片活动代码。适用以下代码：0 - 两侧均活动；1 - 顶侧（例如沿面片法向方向）活动；-1 - 面片底侧活动；2 - 面片两侧均不活动。

contact_count(all=False, type=None) → int.

获取与该面片关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则计数包含虚拟接触。

contacts([piece: object, ]all=False, type=None) → Contact 对象的元组。

获取与该面片关联的接触元组。可包含一个可选参数，即片体对象（Ball、Pebble 或 Facet）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

conveyor() → vec.

获取面片传送带速度（向量）。

conveyor_x() → float.

获取面片传送带速度的 x 分量。

conveyor_y() → float.

获取面片传送带速度的 y 分量。

conveyor_z() → float.

获取面片传送带速度的 z 分量。

delete() → None.

删除一个面片。墙位置会自动更新。

edge_neighbors() → Facet 对象的元组。

获取相邻面片。相邻面片是指共享{二维中顶点；三维中边}的面片。元组长度在三维中为 3、二维中为 2。元组中每个位置包含一个 Facet 对象；若该边（二维中为点）没有相邻面片则为 None。

extra(slot: int) → any.

获取给定槽位中的面片额外数据。

group([slot: str]) → str.

获取给定槽位中的面片组名。

group_remove(group_name: str) → bool.

从面片的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该面片属于哪些组的字典。字典的键为槽位名，值为组名。

has_prop(property_name: str) → bool.

若该面片具有给定表面性质则返回 True。

id() → int.

获取面片 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该面片是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

normal() → vec.

获取面片法向方向（向量）。

normal_x() → float.

获取面片法向方向的 x 分量。

normal_y() → float.

获取面片法向方向的 y 分量。

normal_z() → float.

获取面片法向方向的 z 分量。

point_near(point: vec) → vec.

获取面片上距另一点最近的点。

pos() → vec.

获取面片位置（向量）。

pos_x() → float.

获取面片位置的 x 分量。

pos_y() → float.

获取面片位置的 y 分量。

pos_z() → float.

获取面片位置的 z 分量。

prop(property_name: str) → any.

获取该面片某个表面性质的取值。

props() → dict {str: any}.

获取该面片所有表面性质的字典。

set_active(activity_code: int) → None.

适用以下代码：0 - 两侧均活动；1 - 顶侧（例如沿面片法向方向）活动；-1 - 面片底侧活动；2 - 面片两侧均不活动。

set_conveyor(value: vec) → None.

设置面片传送带速度（向量）。

set_conveyor_x(value: float) → None.

设置面片传送带速度的 x 分量。

set_conveyor_y(value: float) → None.

设置面片传送带速度的 y 分量。

set_conveyor_z(value: float) → None.

设置面片传送带速度的 z 分量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的面片额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的面片组名。

set_prop(property_name: str, value: any) → None.

设置该面片的一个表面性质。

valid() → bool.

若该面片为活动对象则返回 True。

vertices() → WallVertex 对象的元组。

获取面片的顶点。

wall() → Wall 对象。

获取面片所属的墙。
