Pebble

class itasca.clump.pebble.Pebble
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
clump() → Clump 对象。

获取该子颗粒所属的刚性簇对象。

contacts([piece: object, ]all=False, type=None) → Contact 对象的元组。

获取与该球关联的接触元组。可包含一个可选参数，即片体对象（Ball、Pebble 或 Facet）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

delete() → None.

删除此子颗粒。

extra(slot: int) → any.

获取给定槽位中的子颗粒额外数据。

group([slot: str]) → str.

获取给定槽位中的子颗粒组名。

group_remove(group_name: str) → bool.

从该子颗粒的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该子颗粒属于哪些组的字典。字典的键为槽位名，值为组名。

has_prop(property_name: str) → bool.

若该子颗粒具有给定表面性质则返回 True。

id() → int.

获取子颗粒 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该子颗粒是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

pos() → vec.

获取子颗粒位置（向量）。

pos_x() → float.

获取子颗粒位置的 x 分量。

pos_y() → float.

获取子颗粒位置的 y 分量。

pos_z() → float.

获取子颗粒位置的 z 分量。

prop(property_name: str) → any.

获取该子颗粒某个表面性质的取值。

props() → dict {str: any}.

获取该子颗粒所有表面性质的字典。

radius() → float.

获取子颗粒半径。

set_extra(slot: int, value: any) → None.

设置给定槽位中的子颗粒额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的子颗粒组名。

set_pos(value: vec) → None.

设置子颗粒位置。（向量）。

set_pos_x(value: float) → None.

设置子颗粒位置的 x 分量。

set_pos_y(value: float) → None.

设置子颗粒位置的 y 分量。

set_pos_z(value: float) → None.

设置子颗粒位置的 z 分量。

set_prop(property_name: str, value: any) → None.

设置该子颗粒的一个表面性质。

set_radius(value: float) → None.

设置子颗粒半径。

template() → 模板对象。

获取该子颗粒所属的刚性簇模板。

valid() → bool.

若该子颗粒为活动对象则返回 True。

vel() → vec.

获取子颗粒速度（向量）。

vel_x() → float.

获取子颗粒速度的 x 分量。

vel_y() → float.

获取子颗粒速度的 y 分量。

vel_z() → float.

获取子颗粒速度的 z 分量。
