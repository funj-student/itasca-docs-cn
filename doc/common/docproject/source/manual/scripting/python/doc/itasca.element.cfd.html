itasca.element.cfd

用于处理 Itasca CFD 单元的函数与类。

Functions

itasca.element.cfd.age() → float.

获取流体耦合时间。

itasca.element.cfd.count() → int.

获取 CFD 单元数量。

itasca.element.cfd.face_count() → int.

获取每个 CFD 单元的面数。

itasca.element.cfd.find(id: int) → CFD 单元对象。

获取具有给定 ID 号的 CFD 单元对象。

itasca.element.cfd.inbox(lower_bound: vec, upper_bound: vec, intersect=True) → CFD 单元对象的元组。

获取包围盒与某盒体相交的 CFD 单元元组。包围盒是该 CFD 单元的轴对齐包围盒。若可选关键字参数 intersect 为 False，则只返回位置落在盒内的 CFD 单元。

itasca.element.cfd.list() → CFD 单元迭代器对象。

获取 CFD 单元迭代器对象。

itasca.element.cfd.maxid() → int.

获取最大 CFD 单元 ID。

itasca.element.cfd.near(point: vec, radius=0.0) → CFD 单元对象。

查找距某点最近的 CFD 单元。若可选关键字参数 radius 非零，则只在该半径内搜索。

itasca.element.cfd.node_count() → int.

获取每个 CFD 单元的节点数。
