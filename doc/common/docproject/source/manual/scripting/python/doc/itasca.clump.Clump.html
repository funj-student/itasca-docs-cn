刚性簇

class itasca.clump.Clump
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
add_pebble(pebble_radius: float, pebble_centroid: vec[, id: int]) → 子颗粒对象。

向刚性簇添加一个子颗粒。该操作不影响刚性簇的惯性属性。该刚性簇不再引用刚性簇模板。子颗粒必须落在模型域内。

calculate(error_percentage=0.01) → None.

计算刚性簇的惯性属性。可选参数 error_percentage 应在 0.0005 < x < 1 范围内。计算使用当前子颗粒分布，采用体素化方法在指定误差内计算惯性属性。更多细节见 clump template 命令。子颗粒不会被平移，但刚性簇形心位置可能被修改。此操作后，转动惯量会随体积或密度的变化而改变。

contact_count(all=False, type=None) → int.

获取与该刚性簇关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则计数包含虚拟接触。

contacts([piece: object, ]all=False, type=None) → Contact 对象的元组。

获取与该刚性簇关联的接触元组。可包含一个可选参数，即片体对象（Ball、Pebble 或 Facet）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallContact、itasca.BallPebbleContact、itasca.PebblePebbleContact、itasca.BallFacetContact 或 itasca.PebbleFacetContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

获取刚性簇的约束条件。整数自由度按以下顺序对应：三维中 0) x 速度，1) y 速度，2) z 速度，3) x 角速度，4) y 角速度，5) z 角速度；二维中 0) x 速度，1) y 速度，2) 角速度。自由时返回值为 false，固定时为 true。

moi() → tensor.

获取刚性簇转动惯量。在二维中使用极转动惯量，因此返回值为浮点数。

moi_fix() → bool.

获取转动惯量的固定状态。激活后，当刚性簇被缩放、体积改变或密度改变时，其转动惯量不会自动更新。当通过 clump attribute 命令或通过 Clump 对象的 vol()、moi_real() 或 moi_prinreal() 方法手动设置体积或转动惯量时，该状态会自动激活。

moi_prin() → vec.

获取刚性簇主转动惯量（向量）。

moi_prin_real() → vec.

获取刚性簇真实主转动惯量。修改时不会改变其他刚性簇属性（例如子颗粒尺寸、刚性簇体积等）。以这种方式指定转动惯量会使主转动惯量处于固定状态，因此在缩放刚性簇时它们不会自动更新，除非用户改变固定状态（见 Clump moi_fix() 方法）（向量）。

moi_prin_real_x() → float.

获取刚性簇真实主转动惯量的 x 分量。修改时不会改变其他刚性簇属性（例如子颗粒尺寸、刚性簇体积等）。以这种方式指定转动惯量会使主转动惯量处于固定状态，因此在缩放刚性簇时它们不会自动更新，除非用户改变固定状态（见 Clump moi_fix() 方法）。

scale_sphere(diameter: float) → None.

把刚性簇缩放到等效球。缩放使刚性簇的{二维为面积；三维为体积}与给定直径的{二维为圆；三维为球}相同。各子颗粒被缩放，其位置被修改，体积被更新。缩放后刚性簇的所有子颗粒必须落在模型域内，操作才能成功。若用户此前已通过刚性簇属性或 Clump 对象方法（vol()、moi_prin_real() 或 moi_real()）指定体积或转动惯量，则主转动惯量处于固定状态，不会被缩放。详见 Clump 对象的 moi_fix() 方法。

scale_vol(volume: float) → None.

缩放刚性簇。缩放使刚性簇的{二维为单位厚度体积；三维为体积}等于指定值。各子颗粒被缩放，其位置被修改，体积被更新。缩放后刚性簇的所有子颗粒必须落在模型域内，操作才能成功。若用户此前已通过刚性簇属性或 Clump 对象方法（vol()、moi_prin_real() 或 moi_real()）指定体积或转动惯量，则主转动惯量处于固定状态，不会被缩放。详见 Clump 对象的 moi_fix() 方法。
