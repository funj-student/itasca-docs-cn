itasca.rblock

用于处理 Itasca 刚体块的函数与类。

Functions

itasca.rblock.count() → int.

获取刚体块数量。

itasca.rblock.energies() → dict {str: float}.

以字符串键、浮点值的字典形式获取刚体块总能量贡献。

itasca.rblock.energy(energy_name: str) → float.

获取刚体块的总能量贡献。这是所有刚体块中名为 energy_name 的能量之和（见 set energy 命令）。可用的能量有：“energy-body”、“energy-damp”和“energy-kinetic”。

itasca.rblock.find(id: int) → RBlock 对象。

获取具有给定 ID 号的 RBlock 对象。

itasca.rblock.inbox(lower_bound: vec, upper_bound: vec, intersect=True) → RBlock 对象的元组。

获取包围盒与某盒体相交的刚体块元组。包围盒是该刚体块的轴对齐包围盒。若可选关键字参数 intersect 为 False，则只返回位置落在盒内的刚体块。

itasca.rblock.list() → RBlock 对象迭代器。

获取刚体块迭代器对象。

itasca.rblock.maxid() → int.

获取最大刚体块 ID。

itasca.rblock.near(point: vec, radius=0.0) → RBlock 对象。

查找距某点最近的刚体块。若可选关键字参数 radius 非零，则只在该半径内搜索。
