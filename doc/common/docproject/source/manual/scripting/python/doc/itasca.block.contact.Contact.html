接触

class itasca.block.contact.Contact
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取接触的表面积。

b1() → blockptr.

获取接触处的块体 1。

b2() → blockptr.

获取接触处的块体 2。

energy_fric() → float.

获取接触处耗散的摩擦能。

energy_strain_comp() → float.

获取该接触的压缩应变能。

energy_strain_shear() → float.

获取接触处的剪切应变能。

energy_strain_tensile() → float.

获取接触处的拉伸应变能。

energy_strain_total() → float.

获取接触处的总应变能。

extra(slot: int) → any.

获取给定槽位中的接触额外数据。

fb1() → blockptr.

获取与该接触关联的面块体 1。

fb2() → blockptr.

获取与该接触关联的面块体 2。

fid() → int.

获取接触处的 DFN 裂隙 ID 号。

flowplane() → flowplaneptr.

获取与接触相关的流动平面。

group([slot: str]) → str.

获取给定槽位中的接触组名。

group_remove(group_name: str) → bool.

从该接触的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该接触属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取接触的 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该接触是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取该块体接触的索引（偏移）。

is_excavated() → bool.

获取接触的开挖标志。

is_hidden() → bool.

获取接触的隐藏标志。

jset() → int.

获取该接触的节理集 ID。

normal() → vec.

获取接触法向向量（向量）。

normal_x() → float.

获取接触法向向量的 x 分量。

normal_y() → float.

获取接触法向向量的 y 分量。

normal_z() → float.

获取接触法向向量的 z 分量。

pos() → vec.

获取接触位置（向量）。

pos_x() → float.

获取接触位置的 x 分量。

pos_y() → float.

获取接触位置的 y 分量。

pos_z() → float.

获取接触位置的 z 分量。

set_extra(slot: int, value: any) → None.

在给定槽位中设置接触额外数据。

set_group(group_name: str[, slot: str]) → None.

在给定槽位中设置接触组名。

subcontacts() → 子接触的元组。

获取块体的子接触列表。

type() → int.

获取接触类型。

valid() → bool.

若该接触为活动接触则返回 True。
