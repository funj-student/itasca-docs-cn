Cable

class itasca.sel.cable.Cable
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取锚索的横截面积。

collection() → float.

获取该锚索单元的集合 ID。

dir() → vec.

获取锚索方向（向量）。

dir_x() → float.

获取锚索方向的 x 分量。

dir_y() → float.

获取锚索方向的 y 分量。

dir_z() → float.

获取锚索方向的 z 分量。

extra(slot: int) → any.

获取给定槽位中的锚索额外数据。

force_axial() → float.

获取锚索单元中的轴力（拉力为负）。

force_thermal() → float.

获取锚索单元中的轴向热学力（拉力为负）。

group([slot: str]) → str.

获取给定槽位中的锚索组名。

group_remove(group_name: str) → bool.

从锚索的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该锚索属于哪些组的字典。字典的键为槽位名，值为组名。

grout_cohesion() → float.

获取注浆体的黏聚力。

grout_friction() → float.

获取注浆体的内摩擦角（单位为度）。

grout_perimeter() → float.

获取注浆体的外露周长。

grout_stiffness() → float.

获取注浆体刚度（单位为力/位移）。

id() → int.

获取锚索 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该锚索是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取锚索单元的索引（偏移）。

length() → float.

获取锚索单元的长度。

matnum() → int.

获取该锚索单元的材料属性编号。

node(int) → nodeptr.

获取锚索的节点，给定节点编号（1 为第一个节点；2 为第二个节点）。

pos() → vec.

获取锚索位置（向量）。

pos_x() → float.

获取锚索位置的 x 分量。

pos_y() → float.

获取锚索位置的 y 分量。

pos_z() → float.

获取锚索位置的 z 分量。

rupture_tension() → float.

获取受拉断裂的极限轴向应变。

set_extra(slot: int, value: any) → None.

设置给定槽位中的锚索额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的锚索组名。

state() → string.

获取锚索单元的破坏状态指示符（0 = 弹性，1 = 拉伸屈服，2 = 压缩屈服，3 = 轴向断裂）。

strain_axial() → float.

获取锚索单元的轴向应变（正为拉力，负为压力）。

stress_axial() → float.

获取锚索单元的轴向应力（正为拉力，负为压力）。

valid() → bool.

若该锚索为活动对象则返回 True。

yield_compression() → float.

获取锚索单元的压缩屈服强度。

yield_tension() → float.

设置锚索的拉伸屈服强度（力单位）。

young() → float.

获取锚索的杨氏模量。
