vec

快速二维和三维向量。

vec 模块提供四个类 vec2、vec3、tens3 和 stens3，它们是表示向量和张量的专用快速类型。语句 from vec import vec 在 PFC2D 和 PFC3D 中分别导入二维或三维版本。

vec、tens 和 stens 对象可与 NumPy 互操作。itasca 模块的许多 API 函数接受或返回这些对象。创建该模块是因为 NumPy 对小数组相对较慢。

Examples:

>>> from vec import vec3
>>> a = vec3((1, 1, 1))
>>> b = vec3((2, 2, 2))
>>> print a
vec3((1.000000e+00, 1.000000e+00, 1.000000e+00))

定义了常用运算：

>>> a+b
vec3((3.000000e+00, 3.000000e+00, 3.000000e+00))

>>> b / (a + 0.1)
vec3((1.818182e+00, 1.818182e+00, 1.818182e+00))

以及若干向量专用的运算

>>> b.mag()
3.4641016151377544

>>> a.norm()
vec3((5.773503e-01, 5.773503e-01, 5.773503e-01))

>>> a.dot(b)
6.0
