itasca.pebblearray

用于 Itasca 子颗粒的数组接口。

Functions

itasca.pebblearray.extra(slot: int) → array float{pebble} or float{pebble,3}.

以数组形式获取给定槽位中的子颗粒额外数据。通过数组访问的额外变量必须为 float 或 vec 类型。

itasca.pebblearray.fill_pos(data: array float{pebble, 3}) → None.

用子颗粒位置填充已有数组。该数组必须具有正确的形状。

itasca.pebblearray.fill_radius(data: array float{ball}) → None.

用子颗粒半径填充已有数组。该数组必须具有正确的形状。

itasca.pebblearray.fill_vel(data: array float{pebble, 3}) → None.

用子颗粒速度填充已有数组。该数组必须具有正确的形状。

itasca.pebblearray.ids() → array int{pebble}.

以数组形式获取子颗粒 ID。

itasca.pebblearray.in_group(group_name: str, slot=1) → array bool{pebble}.

以布尔数组返回子颗粒所属的组。

itasca.pebblearray.pos() → array float{pebble,3}.

获取子颗粒位置的 numpy 数组。

itasca.pebblearray.radius() → array float{ball}.

获取子颗粒半径的 numpy 数组。

itasca.pebblearray.set_extra(slot: int, data: array float{pebble} or float{pebble, 3}) → None.

用数组设置给定槽位中的子颗粒额外数据。通过数组设置的额外变量必须为 float 或 vec 类型。

itasca.pebblearray.set_group(membership: array bool{pebble}, group_name: str, slot=1) → None.

由数组设置子颗粒组。若成员标志为 True，则把相应子颗粒设为给定槽位中组 group_name 的成员。

itasca.pebblearray.set_pos(data: array float{pebble, 3}) → None.

由数组设置子颗粒位置。

itasca.pebblearray.set_radius(data: array float{ball}) → None.

由数组设置子颗粒半径。

itasca.pebblearray.vel() → array float{pebble,3}.

获取子颗粒速度的 numpy 数组。
