Zone

class itasca.block.zone.Zone
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
extra(slot: int) → any.

获取给定槽位中的网格单元额外数据。

gp(int) → gpptr.

获取网格单元网格点整数（1、2、3 或 4），表示四个相邻网格点。

group([slot: str]) → str.

获取给定槽位中的网格单元组名。

group_remove(group_name: str) → bool.

从该网格单元的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该网格单元属于哪些组的字典。字典的键为槽位名，值为组名。

hostblock() → float.

获取网格单元所属的块体。

id() → int.

获取网格单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该网格单元是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取该网格单元的索引（偏移）。

is_excavated() → bool.

获取该网格单元的开挖状态。

is_hidden() → bool.

获取该网格单元的隐藏状态。

mass() → float.

获取网格单元质量。

model() → float.

以字符串形式获取网格单元材料模型。

pos() → vec.

获取网格单元位置（向量）。

pos_x() → float.

获取网格单元位置的 x 分量。

pos_y() → float.

获取网格单元位置的 y 分量。

pos_z() → float.

获取网格单元位置的 z 分量。

pp() → float.

获取网格单元孔隙压力（各网格点孔隙压力的平均值）。

prop(str) → float.

获取一个性质。

prop_fluid(str) → float.

获取网格单元的某个流体性质。

prop_thermal(str) → float.

获取网格单元的某个热学性质。

props() → dict {str: any}.

获取所有性质的列表。

set_extra(slot: int, value: any) → None.

设置给定槽位中的网格单元额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的网格单元组名。

set_model(str) → None.

以字符串形式设置网格单元材料模型。

set_prop(str, float) → None.

设置某个性质。

set_prop_fluid(str, float) → float.

设置网格单元的某个热学性质。

set_prop_thermal(str, float) → None.

设置网格单元的某个热学性质。

set_state(string) → None.

设置塑性状态指示符（整数值之和）。

set_stress(stens3) → None.

设置网格单元应力张量。

state() → float.

获取塑性状态指示符（整数值之和）。

strain_inc() → stens3.

基于当前位移场获取网格单元应变增量。

strain_rate() → stens3.

基于当前速度场获取网格单元应变率。

strain_rotation_inc() → stens3.

基于当前位移场获取网格单元旋转增量张量。

strain_rotation_rate() → stens3.

基于当前速度场获取网格单元旋转率张量。

strain_shear_int() → float.

获取基于当前位移场的网格单元剪切应变增量。

strain_shear_rate() → float.

获取基于当前速度场的网格单元剪切应变率。

strain_total() → float.

获取某个网格单元的冯·米塞斯应变值。

strain_vol_int() → float.

获取基于当前位移场的网格单元体积应变增量。

strain_vol_rate() → float.

获取基于当前速度场的网格单元体积应变率。

stress() → stens3.

获取网格单元应力张量。

stress_effective() → stens3.

获取网格单元有效应力。

stress_int() → float.

获取中间主应力。

stress_max() → float.

获取最大（最正）主应力。

stress_min() → float.

获取最小（最负）主应力。

stress_prin_dir() → [vec3,sten3].

获取网格单元主应力方向。

valid() → bool.

若该网格单元为活动单元则返回 True。

vol() → float.

获取网格单元体积。
