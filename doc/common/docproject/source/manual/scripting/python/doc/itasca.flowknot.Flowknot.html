Flowknot

class itasca.flowknot.Flowknot
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取该节点对应的面积。

bulk() → float.

获取该流节点所用的流体体积模量。

extra(slot: int) → any.

获取给定槽位中的流节点额外数据。

fix_fluid() → int.

获取孔隙压力变化的指示符。

fix_proppant() → bool.

获取支撑剂变化的标志（true = 自由；false = 恒定体积分数）。

fix_thermal() → int.

获取热学条件码（0 = 自由；1 = 恒定温度；2 = 恒定通量）。

flux_fluid_app() → float.

获取附加通量源的值。

flux_thermal() → float.

获取热流总和。

flux_thermal_app() → float.

获取边界上的热通量。

flux_thermal_unbal() → float.

获取不平衡热通量。

group([slot: str]) → str.

获取给定槽位中的流节点组名。

group_remove(group_name: str) → bool.

从流节点的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该流节点属于哪些组的字典。字典的键为槽位名，值为组名。

htc() → float.

获取传热系数。

id() → int.

获取流节点 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该流节点是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取给定流节点的索引（偏移）。

is_hidden() → bool.

获取该网格单元的隐藏状态。

pos() → vec.

获取流节点位置（向量）。

pos_x() → float.

获取流节点位置的 x 分量。

pos_y() → float.

获取流节点位置的 y 分量。

pos_z() → float.

获取流节点位置的 z 分量。

pp() → float.

获取流节点孔隙压力。

propin_vol() → float.

获取注入流体中的支撑剂体积浓度。

set_bulk(float) → None.

设置该流节点所用的流体体积模量。

set_extra(slot: int, value: any) → None.

设置给定槽位中的流节点额外数据。

set_fix_fluid(int) → None.

设置孔隙压力变化的指示符。

set_fix_proppant(bool) → None.

设置支撑剂变化的标志（true = 自由；false = 恒定体积分数）。

set_fix_thermal(int) → None.

设置热学条件码（0 = 自由；1 = 恒定温度；2 = 恒定通量）。

set_flux_fluid_app(float) → None.

设置附加通量源的值。

set_flux_thermal_app(float) → None.

设置边界上的热通量。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的流节点组名。

set_htc(float) → None.

设置传热系数。

set_pp(float) → None.

设置流节点孔隙压力。

set_propin_vol(float) → None.

设置注入流体中的支撑剂体积浓度。

set_temp(float) → None.

设置流节点温度。

stiffness() → float.

获取该节点对应的流体刚度。

temp() → float.

获取流节点温度。

timestep() → float.

获取该节点对应的流体流动时步。

trans() → float.

获取与该节点相连单元的总导流系数。

valid() → bool.

若该流节点为活动对象则返回 True。

vertexlist() → 顶点列表。

获取该流节点的顶点列表。

vol() → float.

获取与该节点对应的体积。

vol_unbal() → float.

获取当前循环计算的不平衡流动体积。

vol_unbal_max() → float.

获取模拟过程中的最大不平衡体积。
