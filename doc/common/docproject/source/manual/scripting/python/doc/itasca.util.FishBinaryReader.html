FishBinaryReader

class itasca.util.FishBinaryReader

读取结构化 FISH 二进制文件。

用结构化 FISH 文件名调用构造函数，并调用 read() 读取各个值。该类也支持迭代。返回值被转换为 Python 类型。支持 int、float、string、bool、v2 与 v3。

>>> fish_file = FishBinaryReader('my_fish_data.fish')
>>> for val in fish_file:
...    print val
42
"this is a string"
[1.0,2.0,3.0]
asarray() → numpy 数组。

以 numpy 数组返回 FISH 文件内容。各元素类型必须一致。

aslist() → [any].

以 Python 列表返回 FISH 文件内容。

next() → any.

从 FISH 二进制文件中获取下一个数据项。

read() → any.

从 .fish 二进制文件中读取并返回一个值（转换为 Python 类型）。
