Link

class itasca.structure.link.Link
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
attach() → 整数的元组。

获取连接在各自由度所用的连接条件。返回值为整数，取以下三值之一：1 = 自由；2 = 刚性；3 = 可变形。若条件为可变形，详见 \(model\) 方法（及相关方法）。

component_id() → int.

获取连接组件 ID。

delete() → None.

删除此结构连接。

extra(slot: int) → any.

获取给定槽位中的连接额外数据。

group([slot: str]) → str.

获取给定槽位中的连接组名。

group_remove(group_name: str) → bool.

从连接的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该连接属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取连接结构单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该连接是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

model() → 字符串的元组。

获取各自由度所用一维力-位移模型的名称。若连接条件为自由或刚性，则该函数返回 None（见 \(attach\) 方法）。当前可用的模型为 \(linear\)、\(normal-yield\)、\(shear-yield\) 和 \(pile-yield\)。

model_area() → 浮点数的元组。

获取力-位移模型中所有自由度对应的面积。

model_compression() → 浮点数的元组。

获取所有自由度对应力-位移模型的压缩屈服力。

model_disp() → (translational: vec3, rotational: vec3).

获取各一维力-位移模型所用的节点与目标之间的相对位移。注意，位移相对于节点局部坐标系。相对位移定义为连接目标的位移减去连接宿主节点在节点局部坐标系中的位移。

model_force() → (translational: vec3, rotational: vec3).

获取各一维力-位移模型中的当前力。该力由一维力-位移模型根据连接目标与宿主节点（目标减节点）的相对位移增量以增量方式计算。见 \(model_disp\) 方法。

model_gap() → 布尔值的元组。

获取表示各自由度一维力-位移模型中间隙计算是否启用的标志。见 \(gap_neg\) 和 \(gap_pos\) 方法。

model_gap_neg() → 浮点数的元组。

获取各自由度对应各一维力-位移模型的负（压缩）间隙分量。

model_gap_pos() → 浮点数的元组。

获取各自由度对应各一维力-位移模型的正（拉伸）间隙分量。仅当间隙启用标志开启时该值才影响力的计算；见 \(model_gap\) 方法。相对位移定义为连接目标的位移减去连接宿主节点在节点局部坐标系中的位移。见 \(model_disp\) 方法。

model_stiffness() → .

获取各自由度所用各一维力-位移模型的刚度。

model_tension() → 浮点数的元组。

获取各自由度对应力-位移模型的拉伸屈服力。拉伸屈服力是连接中力可达到的正值上限。注意，拉伸是相对节点局部坐标系定义的，因此视所用坐标系而定，压缩与拉伸的定义可能与宿主节点所连单元的定义不一致。见 \(model_force\) 方法。

model_yield() → 整数的元组。

获取各自由度一维力-位移模型的屈服状态指示符。以整数返回：0 = 从未屈服，1 = 正在屈服，2 = 曾经屈服。

node() → Node 对象。

获取承载该结构连接的节点。

set_extra(slot: int, value: any) → None.

设置给定槽位中的连接额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的连接组名。

set_model_area(comp: int, area: value) → None.

设置某个自由度分量对应的面积。整数分量从零开始，先给出平动分量。

set_model_compression(comp: int, force: value) → None.

设置单一自由度对应力-位移模型的压缩屈服力。整数分量从零开始，先给出平动分量。

set_model_gap(comp: int, flag: bool) → None.

设置单一自由度的一维力-位移模型中间隙计算是否启用的标志。见 \(gap_neg\) 和 \(gap_pos\) 方法。

set_model_stiffness(comp: int, force: float) → None.

设置各自由度所用各一维力-位移模型的刚度。

set_model_tension(comp: int, force: float) → None.

设置单一自由度对应的力-位移模型的拉伸屈服力。拉伸屈服力是连接中力可达到的正值上限。注意，拉伸是相对节点局部坐标系定义的，因此视所用坐标系而定，压缩与拉伸的定义可能与宿主节点所连单元的定义不一致。见 \(model_force\) 方法。整数分量从零开始，先给出平动分量。

set_slide(flag: bool) → None.

设置连接的大应变滑动标志。该函数仅适用于节点-网格单元连接；对节点-节点连接无意义。

set_slide_tol(flag: bool) → None.

获取连接的大应变滑动容差。该函数仅适用于节点-网格单元连接；对节点-节点连接无意义。

side() → int.

获取连接的侧面编号。除非连接的宿主节点连接到嵌入式衬砌，否则始终返回 1。若宿主节点属于嵌入式衬砌，则可能返回 2，表示该连接用于衬砌的侧面 2。

slide() → bool.

获取连接的大应变滑动标志。该函数仅适用于节点-网格单元连接；对节点-节点连接无意义。

slide_tol() → bool.

获取连接的大应变滑动容差。该函数仅适用于节点-网格单元连接；对节点-节点连接无意义。

target() → 网格单元或节点对象。

获取该连接的目标。节点-节点连接返回 Node 对象，节点-网格单元连接返回 Zone 对象。

type() → str.

获取连接目标类型的名称。节点-节点连接返回 \(itasca.structure.node.Node\) 对象。节点-网格单元连接返回 \(itasca.zone.Zone\) 对象。

used_by() → str.

获取该连接所关联的结构单元类型名称。仅适用于节点-网格单元连接，否则返回空字符串。类型字符串为 \(beam\)、\(cable\)、\(pile\)、\(shell\)、\(geogrid\) 或 \(liner\) 之一。若赋给该连接的条件与模型与这些单元不兼容（通常是因为它们已被修改），则返回空字符串。

valid() → bool.

若该连接为活动对象则返回 True。
