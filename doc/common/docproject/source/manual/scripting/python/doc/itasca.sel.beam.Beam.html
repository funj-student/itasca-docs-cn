Beam

class itasca.sel.beam.Beam
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取梁的横截面积。

collection() → int.

获取给定梁的集合 ID。

dir() → vec.

获取梁方向（向量）。

dir_x() → float.

获取梁方向的 x 分量。

dir_y() → float.

获取梁方向的 y 分量。

dir_z() → float.

获取梁方向的 z 分量。

extra(slot: int) → any.

获取给定槽位中的梁额外数据。

force_axial() → float.

获取梁上的轴力。

force_thermal() → float.

获取梁上的热学力。

group([slot: str]) → str.

获取给定槽位中的梁组名。

group_remove(group_name: str) → bool.

从梁的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该梁属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取梁 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该梁是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

index() → int.

获取梁的索引（偏移）。

length() → float.

获取梁单元的长度。

matnum() → int.

获取梁单元的材料编号。

node(int) → node_ptr.

获取梁单元的一个节点。

normal_stiffness() → float.

获取梁单元与岩/土之间界面的法向刚度（力/位移）。

normal_strength() → float.

获取梁单元与岩/土之间界面的法向（抗拉）强度。单位为力。

pos() → vec.

获取梁位置（向量）。

pos_x() → float.

获取梁位置的 x 分量。

pos_y() → float.

获取梁位置的 y 分量。

pos_z() → float.

获取梁位置的 z 分量。

set_area(float) → None.

设置梁的横截面积。

set_extra(slot: int, value: any) → None.

设置给定槽位中的梁额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的梁组名。

shear_cohesion() → float.

获取梁单元与岩/土界面的黏聚力。

shear_friction() → float.

获取梁单元与土/岩界面的摩擦角（度）。

shear_stiffness() → float.

获取梁单元与岩/土之间界面的剪切刚度（力/位移）。

state() → string.

获取梁单元的状态指示符。

strain_axial() → float.

获取梁上的轴向应变。

stress_axial() → float.

获取梁上的轴向应力。

thermalexp() → float.

获取梁单元的热膨胀系数。

valid() → bool.

若该梁为活动对象则返回 True。

young() → float.

获取梁单元的杨氏模量。
