Pile

class itasca.structure.Pile
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → float.

获取桩单元的横截面积。

axial_yield() → float.

获取桩单元的轴向拉伸屈服强度（力单位）。

component_id() → int.

获取桩组件 ID。

connectivity(component: int) → bool.

获取该单元中组件 ID 为 id 的节点的索引。若该单元中没有匹配的节点，则抛出 ValueError 异常。

delete() → None.

删除此结构单元。

density() → float.

获取该结构单元的密度。

extra(slot: int) → any.

获取给定槽位中的桩额外数据。

force() → (vec3, vec3).

获取单元局部系中桩各端的力。

force_nodal() → (vec3, vec3, vec3, vec3).

获取全局系中作用在各端的广义节点力。先给出端 1 的平动和转动分量。

gap() → ((float, float, float, float), (float, float, float, float)).

获取桩单元各端法向弹簧中的间隙分量。间隙在桩横截面平面内形成矩形，该平面由桩单元节点的局部 yz 轴定义。间隙由四个值组成，分别表示正 y、负 y、正 z 和负 z 方向的间隙大小。间隙始终被跟踪，但只有在启用法向耦合弹簧间隙标志时才影响行为。先给出端 1 的间隙值。

group([slot: str]) → str.

获取给定槽位中的桩组名。

group_remove(group_name: str) → bool.

从桩的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该桩属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取桩结构单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该桩是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

length() → float.

获取桩单元的长度。

load() -> None. () → vec3.

获取作用在桩单元上、沿局部 y 和 z 方向的均布施加荷载。返回值的 x 分量始终为 0.0。

local_system() → Tens3.

以 3x3 张量形式获取该单元的局部坐标系。

mark() → bool.

获取结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

moi() → vec3.

获取桩的转动惯量。定义为关于 x、y、z 轴的二阶转动惯量。

moment() → (vec3, vec3).

获取单元局部系中桩各端的力矩。

moment_plastic() → float.

获取桩的塑性弯矩承载力。

moment_plastic_y() → float.

获取桩在 Y 方向的塑性弯矩承载力。

moment_plastic_z() → float.

获取桩在 Z 方向的塑性弯矩承载力。

nodes() → 结构单元节点对象元组。

获取连接到该单元的结构单元节点元组。

normal_cohesion() → float.

获取桩单元法向耦合弹簧的黏聚强度。

normal_dir() → (vec3, vec3).

获取各端耦合法向弹簧对桩单元施加载荷的全局方向。

normal_disp() → (float, float).

获取桩单元各端耦合法向弹簧中的位移。法向弹簧的符号约定为正值/负值，分别表示分离/重叠。

normal_friction() → float.

获取桩单元法向耦合弹簧的摩擦角。

normal_gap() → bool.

获取法向耦合弹簧的间隙启用标志。True 表示启用间隙，False 表示关闭间隙。

normal_state() → (int, int).

获取桩单元各端耦合法向弹簧的屈服状态。返回值 0、1 和 2 分别表示从未屈服、正在屈服或曾经屈服。

normal_stiffness() → float.

获取桩单元法向耦合弹簧的刚度。

normal_stress() → (float, float).

获取桩单元各端耦合法向弹簧中的应力。法向弹簧的符号约定为正值/负值，分别表示分离/重叠。

perimeter() → float.

获取桩单元的外露周长。

poisson() → float.

获取桩单元的泊松比。

pos() → vec3.

获取单元的位置向量，定义为单元形心。

rockbolt() → bool.

获取锚杆的布尔标志。True 表示锚杆标志开启，False 表示关闭。

set_area(float) → None.

设置桩单元的横截面积。

set_axial_yield(float) → None.

设置桩单元的轴向拉伸屈服强度（力单位）。

set_density(float) → None.

设置该结构单元的密度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的桩额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的桩组名。

set_load(vec3) → None.

设置作用在桩单元上、沿局部 y 和 z 方向的均布施加荷载。赋值时忽略 x 分量。

set_mark(bool) → None.

设置结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

set_moi(vec3) → None.

设置桩的转动惯量。定义为关于 x、y、z 轴的二阶转动惯量。

set_moment_plastic(float) → None.

设置桩的塑性弯矩承载力。

set_moment_plastic_y(float) → None.

设置桩在 Y 方向的塑性弯矩承载力。

set_moment_plastic_z(float) → None.

设置桩在 Z 方向的塑性弯矩承载力。

set_normal_cohesion(float) → None.

设置桩单元法向耦合弹簧的黏聚强度。

set_normal_friction(float) → None.

设置桩单元法向耦合弹簧的摩擦角。

set_normal_gap(bool) → None.

设置法向耦合弹簧的间隙启用标志。True 表示启用间隙，False 表示关闭间隙。

set_normal_stiffness(float) → None.

设置桩单元法向耦合弹簧的刚度。

set_perimeter(float) → None.

设置桩单元的外露周长。

set_poisson(float) → None.

设置桩单元的泊松比。

set_rockbolt(bool) → None.

设置锚杆的布尔标志。True 表示锚杆标志开启，False 表示关闭。

set_shear_cohesion(float) → None.

设置桩单元剪切耦合弹簧的黏聚强度。

set_shear_flag(bool) → None.

设置剪切方向增量围压标志。True 表示该标志开启，False 表示关闭。

set_shear_friction(float) → None.

设置桩单元剪切耦合弹簧的摩擦角。

set_shear_stiffness(float) → None.

设置桩单元剪切耦合弹簧的刚度。

set_slide(bool) → None.

设置滑动的布尔标志。True 表示滑动标志开启，False 表示关闭。

set_slide_tol() → float.

设置桩单元的大应变滑动容差。

set_strain_failure(float) → None.

设置桩单元的拉伸破坏应变（无量纲）。

set_table_cohesion(str) → None.

设置桩单元剪切方向黏聚强度表的名称。

set_table_factor(str) → None.

设置桩单元剪切方向摩擦表的名称。

set_table_friction(str) → None.

设置桩单元剪切方向增量围压系数表的名称。

set_thermal_expansion(float) → None.

设置该结构单元的热膨胀系数。

set_young(float) → None.

设置桩单元的杨氏模量。

shear_cohesion() → float.

获取桩单元剪切耦合弹簧的黏聚强度。

shear_dir() → (vec3, vec3).

获取各端耦合剪切弹簧对桩单元施加载荷的全局方向。

shear_flag() → bool.

获取剪切方向增量围压标志。True 表示该标志开启，False 表示关闭。

shear_friction() → float.

获取桩单元剪切耦合弹簧的摩擦角。

shear_state() → None.

获取桩单元各端耦合剪切弹簧的屈服状态。返回值 0、1 和 2 分别表示从未屈服、正在屈服或曾经屈服。

shear_stiffness() → float.

获取桩单元剪切耦合弹簧的刚度。

shear_stress() → (float, float).

获取桩单元各端耦合剪切弹簧中的应力。剪切弹簧的符号约定为相对桩平均轴向方向的正/负。

slide() → bool.

strain_failure() → float.

stress_confining() → (float, float).

获取桩单元各端的围压。（负值表示压缩。）应力作用在垂直于桩轴线的平面内；围压为该平面内主应力的平均值。

table_cohesion() → str.

valid() → bool.

volume() → float.
