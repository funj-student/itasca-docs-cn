ThermalBall

class itasca.ball.thermal.ThermalBall
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
ball() → Ball 对象。

获取与该热学球对应的球。

contact_count(all=False, type=None) → int.

获取与该热学球关联的接触数量。若给出可选关键字参数 type，则计数限于所指定的接触类型。可选 type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallThermalContact、itasca.BallPebbleThermalContact、itasca.PebblePebbleThermalContact、itasca.BallFacetThermalContact 或 itasca.PebbleFacetThermalContact 之一）。若可选关键字参数 all 为 True，则计数包含虚拟接触。

contacts([piece, ]all=False, type=None) → Contact 对象的元组。

获取与该热学球关联的接触元组。可包含一个可选参数，即片体对象（热学球、热学子颗粒或热学面片）。若给出可选关键字参数 type，则返回列表限于所指定的接触类型。type 关键字参数应为 Python 类型对象（取值为 itasca.BallBallThermalContact、itasca.BallPebbleThermalContact、itasca.PebblePebbleThermalContact、itasca.BallFacetThermalContact 或 itasca.PebbleFacetThermalContact 之一）。若（可选）关键字参数 all 为 True，则返回列表包含虚拟接触。

del_temp() → float.

获取热学球的温度增量。

expansion() → float.

获取热学球的膨胀系数。

extra(slot: int) → any.

获取给定槽位中的热学球额外数据。

fix() → bool.

获取热学球的约束条件。

group([slot: int]) → str.

获取给定槽位中的热学球组名。

group_remove(group_name: str) → int.

从热学球中移除给定组。需要一个字符串类型的参数给出组名。返回值为整数：找到该组名的第一个槽位；若未找到则为 -1。

groups() → 字符串的元组。

获取赋给该热学球的组名元组。

has_prop(property_name: str) → bool.

若该热学球具有给定表面性质则返回 True。

id() → int.

获取热学球 ID。

in_group(group_name: str) → bool.

检验该热学球是否属于给定组。搜索所有组槽位。

pos() → vec.

获取热学球位置（向量）。

pos_x() → float.

获取热学球位置的 x 分量。

pos_y() → float.

获取热学球位置的 y 分量。

pos_z() → float.

获取热学球位置的 z 分量。

power_app() → float.

获取热学球所施加的热功率。

power_unbal() → float.

获取热学球的不平衡热功率。

prop(property_name: str) → any.

获取该热学球某个表面性质的取值。

props() → dict {str: any}.

获取该热学球所有表面性质的字典。

set_del_temp(value: float) → None.

设置热学球的温度增量。

set_expansion(value: float) → None.

设置热学球的膨胀系数。

set_extra(slot: int, value: any) → None.

设置给定槽位中的热学球额外数据。

set_fix(value: bool) → None.

设置热学球的约束条件。

set_group([group_name: str[, slot: int]]) → None.

设置给定槽位中的热学球组名。

set_pos(value: vec) → None.

设置热学球位置（向量）。

set_pos_x(value: float) → None.

设置热学球位置的 x 分量。

set_pos_y(value: float) → None.

设置热学球位置的 y 分量。

set_pos_z(value: float) → None.

设置热学球位置的 z 分量。

set_power_app(value: float) → None.

设置热学球所施加的热功率。

set_prop(property_name: str, value: any) → None.

设置该热学球的一个表面性质。

set_specific_heat(value: float) → None.

设置热学球的比热。

set_temp(value: float) → None.

specific_heat() → float.

temp() → float.
