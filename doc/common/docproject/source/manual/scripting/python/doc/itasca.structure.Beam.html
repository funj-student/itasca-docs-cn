Beam

class itasca.structure.Beam
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
area() → Float.

获取单元的横截面积。

component_id() → int.

获取梁组件 ID。

connectivity(component: int) → bool.

获取该单元中组件 ID 为 id 的节点的索引。若该单元中没有匹配的节点，则抛出 ValueError 异常。

delete() → None.

删除此结构单元。

density() → float.

获取该结构单元的密度。

extra(slot: int) → any.

获取给定槽位中的梁额外数据。

force() → (vec3, vec3).

获取单元局部系中梁各端的力。

force_nodal() → (vec3, vec3, vec3, vec3).

获取全局系中作用在各端的广义节点力。先给出端 1 的平动和转动分量。

group([slot: str]) → str.

获取给定槽位中的梁组名。

group_remove(group_name: str) → bool.

从梁的所有组槽位中移除给定组。需要一个字符串类型的参数给出组名。返回值为布尔值：若该组已从任一槽位移除则为 True，否则为 False。

groups() → {slot: group_name}.

获取描述该梁属于哪些组的字典。字典的键为槽位名，值为组名。

id() → int.

获取梁结构单元 ID。

in_group(group_name: str[, slot: str]) → bool.

检验该梁是否属于给定组。若给出可选参数 slot，则只搜索该槽位；否则搜索所有组槽位。

length() → float.

获取梁单元的长度。

load() → vec3.

获取作用在梁单元上、沿局部 y 和 z 方向的均布施加荷载。返回值的 x 分量始终为 0.0。

local_system() → Tens3.

以 3x3 张量形式获取该单元的局部坐标系。

mark() → bool.

获取结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

moi() → vec3.

获取梁的转动惯量。定义为关于 x、y、z 轴的二阶转动惯量。

moment() → (vec3, vec3).

获取单元局部系中梁各端的力矩。

moment_plastic() → float.

获取梁的塑性弯矩承载力。

moment_plastic_y() → float.

获取梁在 Y 方向的塑性弯矩承载力。

moment_plastic_z() → float.

获取梁在 Z 方向的塑性弯矩承载力。

nodes() → 结构单元节点对象元组。

获取连接到该单元的结构单元节点元组。

poisson() → float.

获取梁单元的泊松比。

pos() → vec3.

获取单元的位置向量，定义为单元形心。

set_area(float) → None.

设置单元的横截面积。

set_density(float) → None.

设置该结构单元的密度。

set_extra(slot: int, value: any) → None.

设置给定槽位中的梁额外数据。

set_group(group_name: str[, slot: str]) → None.

设置给定槽位中的梁组名。

set_load(vec3) → None.

设置作用在梁单元上、沿局部 y 和 z 方向的均布施加荷载。赋值时忽略 x 分量。

set_mark(bool) → None.

设置结构单元上的标记标志。结构单元逻辑可能在命令处理和循环过程中修改该标志。

set_moi(vec3) → None.

设置梁的转动惯量。定义为关于 x、y、z 轴的二阶转动惯量。

set_moment_plastic(float) → None.

设置梁的塑性弯矩承载力。

set_moment_plastic_y(float) → None.

设置梁在 Y 方向的塑性弯矩承载力。

set_moment_plastic_z(float) → None.

设置梁在 Z 方向的塑性弯矩承载力。

set_poisson(float) → None.

设置梁单元的泊松比。

set_thermal_expansion(float) → None.

设置该结构单元的热膨胀系数。

set_young(float) → None.

设置梁单元的杨氏模量。

thermal_expansion() → float.

获取该结构单元的热膨胀系数。

valid() → bool.

若该梁为活动对象则返回 True。

volume() → None.

获取梁单元体积，等于横截面积乘以长度。

ydir() → vec3.

获取梁单元局部系的 y 轴。

young() → float.

获取梁单元的杨氏模量。
