Vertex

class itasca.wall.vertex.Vertex
不应在 Python 中直接创建（实例化）该类型的对象。请使用返回该类型实例的模块函数。
delete() → None.

删除该顶点。共享该顶点的所有面片都会被删除，墙位置也随之更新。

facets() → 面片对象的元组。

获取共享该顶点的面片。

id() → int.

获取顶点 ID。

pos() → vec.

获取顶点位置（向量）。

pos_x() → float.

获取顶点位置的 x 分量。

pos_y() → float.

获取顶点位置的 y 分量。

pos_z() → float.

获取顶点位置的 z 分量。

set_pos(value: vec) → None.

设置顶点位置（向量）。

set_pos_x(value: float) → None.

设置顶点位置的 x 分量。

set_pos_y(value: float) → None.

设置顶点位置的 y 分量。

set_pos_z(value: float) → None.

设置顶点位置的 z 分量。

set_vel(value: vec) → None.

设置顶点速度（向量）。

set_vel_x(value: float) → None.

设置顶点速度的 x 分量。

set_vel_y(value: float) → None.

设置顶点速度的 y 分量。

set_vel_z(value: float) → None.

设置顶点速度的 z 分量。

valid() → bool.

若该对象为活动顶点则返回 True。

vel() → vec.

获取顶点速度（向量）。

vel_x() → float.

获取顶点速度的 x 分量。

vel_y() → float.

获取顶点速度的 y 分量。

vel_z() → float.

获取顶点速度的 z 分量。
