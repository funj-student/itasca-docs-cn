分支选择：Caseof - Case - Endcase

caseof 表达式（expr）

            …

case n

            …

endcase

这些控制语句的作用类似于 FORTRAN 的计算型 GOTO 语句或 C 语言的 SWITCH 语句。它们根据索引值，将控制权迅速转移到多个代码段中的某一段。以下示例说明这些关键字的用法：

caseof expr
    ; ................. 此处为默认分支代码
    case i1
    ; ................. 此处为 case i1 的代码
    case i2
    ; ................. 此处为 case i2 的代码
    case i3
    ; ................. 此处为 case i3 的代码
endcase

caseof 后面的对象 表达式（expr） 可以是任意有效的代数表达式；i1、i2、i3 等项可以是整数或字符串，但必须在解析函数时为常量。如果 表达式（expr） 的值等于 i1，对于字符串则比较时不区分大小写，控制权就跳转到 case i1 语句后面的语句，并持续执行到下一个 case 语句；随后跳转到 endcase 后面的代码，不会像 C 语言那样贯穿执行后续分支。如果 表达式（expr） 的值等于 i2、i3 等，也会进行类似跳转。如果 表达式（expr） 的值不等于任何 case 语句所关联的数值，就执行紧跟在 caseof 语句之后的代码，并在遇到第一个 case 时跳转到 endcase。如果 表达式（expr） 的值小于零，或大于所有 case 所关联数值中的最大值，则报告执行错误并停止处理。数值 n，例如 i1、i2、i3，不必按顺序排列，也不必连续，但不允许重复。

caseof … endcase 代码段可以嵌套任意层数，不同嵌套层级的 case 编号不会冲突。例如，可以多次出现 case 5，只要它们分别属于不同的嵌套层级即可。使用 case 语句可以快速进行分支判断，速度远高于一系列 if … endif 语句（if … endif） 语句。
