循环：Loop - EndLoop

四种有效的 loop 结构如下：

  • 索引循环

    loop <local> 变量 (expr1, expr2, <expr3>)（<local> var (expr1, expr2, <expr3>)）

    …

    endloop

  • While 条件循环

    loop while 测试表达式（exprtest）

    …

    endloop

  • For 循环

    loop for (初始化、测试、修改表达式（exprinit, exprtest, exprmodify)）

    …

    endloop

  • ForEach 遍历循环

    loop foreach <local> 变量 expr1（<local> var expr1）

    …

    endloop

loop 与 endloop 之间的 FISH 代码行会重复执行，直到满足特定条件。下面分别说明各个 loop 选项的具体细节：

循环可以嵌套任意层数。

索引循环

loop <local> 变量 (expr1, expr2, <expr3>)（<local> var (expr1, expr2, <expr3>)）

…

endloop

第一种形式使用数值计数器：循环变量 var（var） 的初始值为 表达式 1（expr1），每次循环结束时增加 表达式 3（expr3），直到其值大于 表达式 2（expr2）。若未给出 表达式 3（expr3），默认增量为 1。

可以选择在 循环变量 var（var） 前使用 local 语句，将 循环变量 var（var） 创建为函数的局部变量。

请注意，表达式 1（expr1）、表达式 2（expr2） 和 表达式 3（expr3） 可以是任意表达式，但它们都在循环开始时求值。在循环内部重新定义这些表达式涉及的变量，不会改变循环执行次数。

另请注意，循环变量 var（var） 与 表达式 2（expr2） 结果的比较在循环结束时进行，因此无论这些值如何，循环体都至少执行一次。

循环变量 var（var） 是一个一般的 FISH 变量，可以用于循环内部的表达式；如果它是全局变量，还可以用于循环中调用的函数内，甚至可以重新定义。按 表达式 3（expr3） 指定的值增加时，使用一般的 FISH + 运算符；与 expr2 比较时，使用 < 运算符。因此，可以采用与这些运算符相容的任意类型，最常用的是整数或实数。

以下代码片段展示这种形式的基本用法，用于累加小于指定值的所有整数。

fish define sum(n)
    local s = 0
    loop local i (1,n)
        s += i  
    endloop
    sum = s
end
[s = sum(10)]
fish list [s]

fish define sum_even(n)
    local s = 0
    loop local i (0,n,2)
        s += i
    endloop
    sum_even = s
end
[s2 = sum_even(10)]
fish list [s2]

当 n 赋值为 10（n`=:lint:`10） 时，函数的最终结果为 s = 55，以及 s2 = 30。请注意，循环变量可以是整数或实数；若 表达式 3（expr3） 取负值，就可以从较大值递减到较小值。

While 条件循环

loop while 测试表达式（exprtest）

…

endloop

第二种 loop 结构在测试表达式求值为真时执行循环体；否则将控制权转移到 endloop 语句之后的下一行。

表达式既可以包含浮点变量，也可以包含整数；在满足与 if 语句相同的条件时，还可以使用布尔值、字符串和指针。

以下代码片段展示这种形式的基本用法，用于累加小于指定值的所有偶数。

fish define sum_even(n)
    local s = 0
    local i = 0
    loop while i <= n
        s += i
        i +=2
    endloop
    sum_even = s
end
[s2 = sum_even(10)]
fish list [s2]

当 n = 10 时，求和的最终结果为 30。

For 循环

loop for (初始化、测试、修改表达式（exprinit, exprtest, exprmodify)）

…

endloop

第三种 loop 结构的主要作用，是在 test 表达式为真时重复执行循环体，与 loop while 形式类似。此外，loop for 结构还提供专门的位置，用于写入 initialize 初始化字段和 modify 修改字段。因此，这种循环特别适合使用计数器执行重复操作，计数器在开始时初始化，并在每次迭代中修改。其工作过程如下。

  1. 执行初始化操作，通常是为局部或全局计数器变量设置初始值。此操作仅执行一次。
  2. 检查条件。如果条件为真，则继续循环；否则结束循环，不再执行循环体。
  3. 执行循环体。
  4. 最后，执行 modify 字段中指定的内容，然后返回第 2 步。

以下代码片段展示这种形式的基本用法，用于累加小于指定值的所有奇数。

fish define sum_odd(n)
    local s= 0
    loop for (local i=1, i <=n, i+=2)
        s += i  
    endloop
    sum_odd = s
end
[s_odd = sum_odd(10)]
fish list [s_odd]

当 n = 10 时，求和的最终结果为 25。

loop 语句的前三种形式可以相互比较。第一种在循环末尾进行判断，因此至少执行一遍循环；第二种和第三种在循环开始处判断，因此初始判断为假时会跳过整个循环。

ForEach 遍历循环

loop foreach <local> 变量 expr1（<local> var expr1）

…

endloop

第四种 loop 语句形式采用专用语法，用于遍历给定可迭代对象中的所有对象。此时，表达式 1（expr1） 必须求值为可迭代对象，最常见的是容器指针或列表。例如，FISH 内置函数 user.scalar.list 返回用户自定义标量列表中的所有标量对象。

与第一种 loop 形式相同，可以在 循环变量 var（var） 前面加上 local 语句，表示创建局部变量，而不是全局变量。循环变量 var（var） 会依次被赋予可迭代对象中的各个值。

如果遍历的对象是指向容器的指针，并且在处理 loop 循环时删除了 循环变量 var（var） 所指对象，只要在本次循环中删除之后不再引用 循环变量 var（var），循环仍可正常继续。如果删除了容器中的其他项，例如调用了删除容器内容的函数，则循环可能提前退出。

fish define scalar_location
    loop foreach local pnt data.scalar.list
        io.out(data.scalar.pos(pnt))
    endloop
end

循环控制语句

在循环内部，可以使用 exit loop 语句跳出循环，并从 endloop 语句之后继续执行。

此外，可以使用 continue 语句停止当前这次循环迭代，并直接进入下一次迭代，不再执行它与 endloop 语句之间的代码。
