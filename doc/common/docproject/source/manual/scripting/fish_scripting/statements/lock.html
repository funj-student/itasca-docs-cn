锁定（Lock）

lock 名称（name） = <expression>

lock 关键字只能在 FISH 运算子中使用，不能用于普通 FISH 函数。在 FISH 运算子内部，该语句锁定一个全局符号，允许通过一般表达式以线程安全且确定的方式对其赋值。

lock 语句后的第一个词项必须是全局符号的名称。

全局符号名后面只有四种有效的语法形式，分别是：

  • lock 名称（name） = 最大值函数（math.max） (名称（name） ,<expression>)

    求出最大值并赋给该符号。最大值函数（math.max） 只能接受两个参数。

  • lock 名称（name） = 最小值（math.min） (名称（name） ,<expression>)

    求出最小值并赋给该符号。最大值函数（math.max） 只能接受两个参数。

  • lock 名称（name） = <expression>

    直接设置该符号的值。代码保证：在触发多线程执行的拆分顺序中，最后一次调用的结果具有优先权。

  • lock 名称（name） += <expression>

    将数值累加到该符号中。符号值必须为整数或实数类型，表达式的结果也必须属于这两种类型。

使用 lock 语句时需要遵守以下规则：

  • 在某个给定运算子中，同一个符号只能用于这四种类型中的一种 lock 语句。可以对同一个符号使用多条相同类型的 lock 语句。
  • 如果前面的任何代码已经读取过某个符号，就不能再将该符号作为 lock 语句的写入目标。

以下示例展示如何在运算子中使用 lock 语句，安全地写入全局 FISH 符号：

lock maxval = math.max(maxval,thisval)
lock myval = a*b*c

一个常见需求是，在取得最大值的同时，保留与它相关的另一个值。例如，希望找到 FLAC3D 中位移最大的网格点。此时，可以使用 lock sym = math.max(sym,val) 语法，但让符号保存结构。结构比较会按顺序逐个比较成员，因此可将第一个成员设为实数，即位移大小，第二个成员设为网格点指针。以下 FLAC3D 示例展示这一用法：

fish struct mystruct(disp,gp)

[global maxgp = struct mystruct(0.0,null)]

fish operator findmax(gp)
    local dispmag = math.mag(gp.disp(gp))
    lock maxgp = math.max(maxgp,struct mystruct(dispmag,gp))
end
[findmax(::gp.list)]
