命令段：Command - EndCommand

command <suppress>

            …

endcommand

在这一对 FISH 语句之间可以插入 FLAC3D 命令，这些命令在 FISH 函数执行时进行解释。command - endcommand 之间的各行只是由 FISH 存储为字符串列表，不作任何检查，因此必须执行该函数后才能发现其中的错误。

将 FLAC3D 命令嵌入 FISH 函数时有若干限制。不能从 FISH 函数内部调用 新建模型（model new） 和 恢复模型（model restore） 命令，因为这会覆盖当前模型状态，其中也包括正在执行的 FISH 函数。

导入结果文件（model results import） 命令应使用 skip-fish 关键字，表明需要保留 FISH 上下文。不过，如果代码检测到导入操作发生于 FISH 函数执行期间，通常应自动保留该上下文。

FISH 函数定义可以放在 command - endcommand 之间，其自身又可以包含 command 语句，如此递归嵌套。由此可以编写 FISH 代码，在运行时根据实际情况创建新的 FISH 函数。位于 command - endcommand 之间的 FISH 定义，不应重新定义当前正在执行的 FISH 函数。

与回调事件关联的函数可以包含 command 语句。不过，这种写法应谨慎使用，并尽可能避免，因为它更容易产生意外副作用，执行速度也更可能较慢。特别是，在循环计算期间执行的函数，不允许执行会启动循环计算的命令。

以分号 ; 开始的注释行被视为 FLAC3D 注释，而非 FISH 注释。可以利用这一点，在函数中加入说明消息，使其在调用函数时输出。如果回显模式关闭，即 设置回显命令（program echo） 关闭（off），则函数发出的任何 FLAC3D 命令都不会显示在屏幕上，也不会记录到日志文件中。

可以在 command 语句后添加可选关键字 suppress。这表示该命令序列中的所有命令均按已给出 设置回显命令（program echo） 关闭（off） 的状态执行，执行完毕后再恢复之前的 echo 状态。
