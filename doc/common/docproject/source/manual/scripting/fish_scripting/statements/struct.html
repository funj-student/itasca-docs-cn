结构：Struct - Structure

struct 或 structure 语句用于定义或创建结构类型（structure types）；在 FISH 中，这两个关键字互为同义词。

如果放在输入行的开头，struct 语句就用于定义新结构：

struct fred(mem1,mem2,mem3)

struct 后面的名称是新结构的名称，后续参数是结构成员的名称。结构名和成员名都必须遵守命名规则（rules for names），但它们可以与全局符号同名。

请注意，该结构定义在解析 FISH 函数时生效，而不是在执行函数时生效。

如果同名结构已经存在，且与原有定义并不完全一致，则会引发错误。

定义结构的另一种方式是使用 定义FISH结构命令（fish structure） 命令。

结构定义属于模型状态的一部分。这意味着，它们会随模型一起保存和恢复，并会在执行 新建模型（model new） 时移除。


如果用于表达式，struct 关键字就用于创建结构类型。此时，后面的参数为可选项，用于按照结构定义中的声明顺序初始化各个结构成员。

以下示例展示 struct 关键字的用法：

local a = struct fred(1,'a',list.range(1,10))
my_function_call(struct fred(5,7.8,'monkey'))
