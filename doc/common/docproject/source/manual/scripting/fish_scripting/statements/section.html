代码段：Section - EndSection

section

            …

endsection

FISH 语言没有“GOTO”语句。section 结构允许以受控的方式向前跳转。

section … endsection 语句可以包围任意数量的 FISH 代码行，本身不影响程序运行。不过，在这样定义的代码段范围内使用 exit section 语句，会将控制权直接转移到该段末尾。

代码段内可以包含任意数量的这种跳转。endsection 语句起到标签的作用，类似于 C 或 FORTRAN 中 GOTO 语句的目标位置。不过，这种逻辑更清晰，因为控制权不能跳转到所定义代码段以外的位置，而且程序流始终向后推进。
