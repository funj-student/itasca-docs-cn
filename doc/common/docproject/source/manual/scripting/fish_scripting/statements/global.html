全局声明（Global）

global 名称（name） <=expression> <, 名称 2（name2） <=expression>> …

如果全局符号名尚不存在，则显式创建它。默认情况下，FISH 在赋值时遇到无法识别的名称，会自动执行此操作。如果使用了 设置FISH变量自动创建命令（fish automatic-create） 关闭（off），则必须通过 global 显式创建全局符号。编写大型、复杂的 FISH 代码时，强烈建议设置 设置FISH变量自动创建命令（fish automatic-create） 关闭（off）。

可以选择使用表达式给出的值初始化该符号。

如果符号已经存在，不会产生错误。如果给出了初始化表达式，则将新值赋给现有符号。

在 global 语句后，可以创建并初始化任意数量的符号，各符号之间用逗号分隔。

以下是 FISH 全局变量声明语句的示例：

global fred
global george = 2.0
global mary = math.pi, sue = 3.0, freya
