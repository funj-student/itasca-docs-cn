矩阵

FISH 支持由浮点数值组成的二维矩阵。

支持对尺寸相容的矩阵进行加法和乘法运算。

可以使用圆括号 ()，按照先行后列的顺序访问矩阵分量。如果矩阵只有一行或一列，则仅需一个索引。

可以使用四个索引指定较大矩阵中的一个子矩阵：前两个索引是起始行和起始列，后两个是结束行和结束列。这种写法既可用于从大矩阵中提取子矩阵，也可在赋值时更新大矩阵的一部分。

以下示例说明如何使用圆括号访问矩阵分量：

    global m3 = matrix(3,3,   ...
                       1,2,3, ...
                       4,5,6, ...
                       7,8,9)
    global m1 = matrix(1,3,1,2,3)
	
    global a = m3(2,3)  ; a = 6.0
    m3(2,3) = 6.5       ; m3 = ((1,2,3) (4,5,6.5) (7,8,9))
    global b = m1(3)    ; b = 3.0
    m1(3) = 3.5
    global c = m3(2,1,2,3)  ; 从 m3 中提取的 1x3 行矢量 (4,5,6.5)
    m3(3,1,3,3) = matrix(1,3,10,11,12) ; m3 = ((1,2,3) (4,5,6.5) (10,11,12))

可以使用库函数 矩阵（matrix） 创建矩阵类型。该函数还可以将列表、张量或数组转换为矩阵。

可以使用库函数 list、张量（tensor） 或 数组（array），分别将矩阵转换为列表、张量或数组。

矩阵还支持多种其他操作，详见矩阵工具（Matrix Utilities）部分。其中包括矩阵转置、求逆、计算行列式和 LU 分解等。外积（math.outer.product） 可计算两个向量的外积，并返回矩阵。


矩阵属于可迭代类型。这意味着，可以将矩阵用作 loop foreach 语句的遍历对象，见ForEach 循环（Loop ForEach），也可以对矩阵进行拆分，见拆分（Splitting）。矩阵元素按行顺序遍历，即先访问第 1 行第 1 列 (1,1)，再访问第 1 行第 2 列 (1,2)，然后是第 1 行第 3 列 (1,3)，依此类推。


与大多数聚合类型相同，列出矩阵的值时，仅显示其类型为 Matrix，以及矩阵大小。要查看矩阵内容，请使用 fish list 内容（fish list contents） 命令。


以下示例展示一些简单的矩阵操作。

model new
; 矩阵功能测试
fish define setup
    alan = matrix(4,4)
    alan(1,3) = 6
    alan(2,1) = 2.2
    alan(3,4) = 6.6
    alan(4,2) = math.pi
end
[setup]
[alan(4,2)]
[alan = matrix.transpose(alan)]
[alan(2,4)]


fish define sum_tests
    herp = matrix(2,2, 6,-1,-3,2)
    derp = matrix(2,2, 4, 3,-7,0)
   
    klerp = herp + derp
    werp = herp - derp
    serp = herp * derp
end
[sum_tests]
[klerp(1,1)] 
[werp(1,1)] 
[serp(1,1)] 
 
fish define test
    local first = vector(2,4,3)
    local second = vector(8,1,5)
    local prod = math.outer.product(first, second)
    output = list(prod)
end
[test]
fish list contents [output]
