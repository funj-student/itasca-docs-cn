数据类型

FISH 变量可以具有多种类型，包括：

  1. 整数：范围为 -9,223,372,036,854,775,807 至 +9,223,372,036,854,775,807 的精确数值。
  2. 浮点数：近似数，精度约为十四位十进制数字，取值范围约为 \(10^{-308}\) 至 \(10^{308}\)。
  3. 布尔值：取值为 真值（true） 或 假值（false）。
  4. 字符串：任意可打印字符组成的序列。序列长度不限，但输出时可能被截断。在 FISH 和 FLAC3D 中，字符串表示为用单引号或双引号括起的字符序列，例如 字符串 'Have a nice day'（'Have a nice day'） 或 字符串 "Have a nice day"（"Have a nice day"）。更多说明见字符串（Strings）。字符串可迭代。
  5. 指针：在遍历列表及标记对象引用时使用的机器地址。除空指针外，指针具有与其所指对象关联的类型。更多说明见指针（Pointers）。通常，列出指针值时会显示指针的类型名称，以及其所指对象的 ID。指向容器的指针是可迭代的。
  6. 向量：由浮点分量组成的二维或三维向量。更多说明见向量（Vectors）。向量可迭代。
  7. 张量：对称张量。更多说明见张量（Tensors）。张量可迭代。
  8. 矩阵：由数值组成的二维矩阵。更多说明见矩阵（Matrices）。矩阵可迭代。
  9. 列表：用于存储一般 FISH 值的线性容器。更多说明见列表（Lists）。列表可迭代。
  10. 映射：由键值对组成的关联数组。更多说明见映射（Maps）。映射可迭代。
  11. 结构：用户可以定义结构，其中包含多个具有名称的 FISH 变量。更多说明见结构（Structures）。
  12. 数组：具有指定维数的一组 FISH 变量。数组与列表有两点不同：数组可以具有多个维度，而且按引用传递而非按值传递。更多说明见数组（Arrays）。数组可迭代。

FISH 变量可以根据赋给它的表达式类型，动态改变自身类型。为说明这一点，请考虑以下赋值语句：

var1 = var2

如果 var1 和 var2 类型不同，则执行两步操作：首先，将 var1 的类型转换为 var2 的类型；然后，将 var2 的数据传给 var1。在 FORTRAN 或 C 等其他语言中，虽然也会转换数据，但 var1 的类型不会改变。默认情况下，FISH 中所有变量最初都是值为 0 的整数；但是，以下语句：

var1 = 3.4

执行时使 var1 变为浮点变量。可使用 列出FISH变量命令（fish list） 命令查看所有变量的当前类型。

FISH 的动态类型机制旨在让没有编程经验的用户也更容易编程。在 BASIC 等语言中，数值以浮点格式存储；例如，当循环计数器需要整数时，这可能造成不便。在 FISH 中，变量类型会自然地适应使用它的上下文。例如，在以下代码片段中：

n  = n + 2
xx = xx + 3.5

变量 n 将是整数，其值每次精确增加 2；变量 xx 将是浮点数，会受到通常的截断误差影响，但能表示大得多的动态范围。算术运算中的类型转换规则见算术：表达式与类型转换（Arithmetic: Expressions and Type Conversions）。变量的类型由所用运算符的类型优先规则决定；通常会提升为满足需要的最灵活类型。


显式赋入常量值时，遵循以下规则：

  1. 赋入整数值时，即仅包含数字 0–9，变量将变为整数：

    var1 = 334

  2. 如果赋入的数值含有小数点，或含有由“e”或“E”表示的指数，变量将变为浮点数：

    var1 = 3e5
var2 = -1.2

  3. 如果赋值内容用单引号或双引号括起，变量将变为字符串，其“值”为引号内的字符序列：

    var1 = 'Have a nice day'

  4. 如果赋值内容用圆括号括起，且内部包含一个或两个逗号，变量将变为二维或三维向量：

    var3 = (0.3,1,2)
var2 = (0.1,0.2)
