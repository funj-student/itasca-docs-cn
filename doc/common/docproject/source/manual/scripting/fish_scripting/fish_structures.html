结构

结构可以在一个值中包含多个具有名称的 FISH 变量。这是一种程序数据结构，可用于将 FISH 变量分组组织。

可用方法见结构工具（Structure Utilities）。

可以使用 定义FISH结构命令（fish structure） 命令定义结构，也可以在一行 FISH 输入的开头使用 struct 或 structure 语句定义结构。

在表达式中的任何位置，都可以使用 struct 或 structure 关键字，后接结构名称，来创建结构实例；还可将用于初始化结构成员的值作为可选参数传入。未初始化时，结构成员采用默认的 FISH 值 0。

结构成员可以保存任意有效的 FISH 值，包括列表或其他结构。

在访问运算符 -> 后面加上成员名称，即可访问结构成员。与旧版 FISH 相比，结构成员访问的效率大幅提高，仅略慢于直接访问变量。

结构类型可以通过 ==、<、> 等运算符相互比较。如果结构的类型名称相同，则按顺序比较各个成员。

以下示例说明结构的用法。

fish structure fred(one,two,three) ;; 定义结构类型 fred
                                   ;; 包含三个成员：
                                   ;;   'one', 'two', 'three'
fish define test
   struct george(val1,val2,val3) ;; 定义结构类型 george
                                 ;; 包含三个成员：
                                 ;;   'val1', 'val2', 'val3'
   fred = struct george(1,2,3) ;; 创建并初始化 george 结构
   mary = struct fred          ;; 创建 fred 结构
   test = fred->val1
   mary->two = 'monkey'
end
[test]

与大多数聚合类型相同，列出结构的值时，仅显示其类型为 Structure，以及结构名称。要查看结构内容，请使用 fish list 内容（fish list contents） 命令。
