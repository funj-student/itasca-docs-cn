矢量

FISH 内置五个通用函数，辅助创建和操作向量。

向量类型可以是二维或三维的。

可以使用内置函数 vector，传入两个或三个参数，创建向量类型；也可以使用 (x,y) 或 (x,y,z) 语法创建。

分量访问

可以使用圆括号和单个参数 1、2 或 3，读取或设置向量分量。

还可以通过 c -> 运算符以及访问器 x、y 或 z，读取或赋值向量的单个分量。

    local a = vector(1.0,2.1,3.0)
    local b = (4.5,6.7)
    local c = a(2)  ; c = 2.1
    local d = b->y  ; d = 6.7
    a(3) = 2.5      ; a = (1.0,2.1,2.5)
    a->x = 1.5      ; a = (1.5,2.1,2.5)

有关如何获取 FISH 函数返回的向量类型的分量，见成员访问运算符（Member Access Operator）。

数学运算

同类型的两个向量之间可以使用数学运算符 /、*、+ 和 -。这些运算均逐分量进行。例如，v1 * v2 返回向量 (v1.x * v2.x, v1.y * v2.y, v1.z * v2.z)。向量与数值，即整数或浮点数，之间也可以使用 * 运算符；向量与数值之间还可以使用 / 运算符。

运算符支持情况的完整表格见算术（Arithmetic）。

一些有用的向量库函数包括 叉积（math.cross）、点积（math.dot）、矢量模函数（math.mag）、矢量模平方（math.mag2） 和 单位矢量（math.unit）。

这些函数列于数学工具（Math Utilities）部分；vector 则列于构造函数（Constructors）部分。

迭代

向量属于可迭代类型。这意味着，可以将向量用作 loop foreach 语句的遍历对象，见ForEach 循环（Loop ForEach），也可以对向量进行拆分，见拆分（Splitting）。各个分量会按顺序逐一遍历。
