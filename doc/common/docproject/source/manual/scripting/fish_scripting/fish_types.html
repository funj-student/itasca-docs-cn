FISH 类型索引

FLAC3D 文档中的 FISH 函数签名使用这些类型说明符。

ANY
任意类型
ARR
数组
BOOL
布尔值
FLT
浮点数
INDEX
一般索引
INT
整数
LIST
指向对象列表或对象容器的指针。
MAP
映射（关联容器）
MAT
矩阵
NULL
空指针
NUM
浮点数或整数
PNT
一般指针
STR
字符串
TEN
张量
V2
二维向量
V2+
二维向量，可以作为一个向量参数输入，也可以作为两个 NUM 参数输入。
V3
三维向量
V3+
三维向量，可以作为一个向量参数输入，也可以作为三个 NUM 参数输入。
VEC
二维或三维向量
VEC+
二维或三维向量，可以作为一个向量参数输入，也可以作为两个或三个 NUM 参数输入。
