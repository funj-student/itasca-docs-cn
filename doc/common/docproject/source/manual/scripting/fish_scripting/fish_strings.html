字符串

字符串由可打印字符组成。代码中的字符串值可以用单引号或双引号括起，但结束引号必须与开始引号匹配。

字符串变量唯一支持的算术运算是加法，其作用是将两个字符串连接起来。

反斜杠字符 \ 用作特殊转义符，用于表示不可打印的特殊字符。下表列出了可跟在反斜杠后面的字符及其含义。


表 1：字符串操作字符
‘ 在字符串中插入单引号
“ 在字符串中插入双引号
b 退格
t 制表符
r 回车
n 回车/换行（CR/LF）
\ 单个反斜杠

算术运算不能只有一个操作数是字符串变量。如果要将数值包含在字符串变量中，必须使用内置函数 字符串构造函数（string()），见上例中的变量 xx。另请注意用于识别参数类型的内置函数 类型函数（type()） 的用法。


可以使用圆括号 () 访问字符串的内容。

单个参数必须是非零整数，表示字符在字符串中的位置；返回值是长度为一个字符的字符串。

可以使用负值从字符串末尾开始索引：-1 表示最后一个字符，-2 表示其左侧的字符，依此类推。

同样的规则也适用于两个参数的访问，此时返回从第一个索引到第二个索引之间的子字符串。如果第二个索引小于第一个索引，则返回空字符串。

读取时，如果引用的位置超出字符串范围，则返回空字符串。

可以使用单个索引或两个索引赋入任意长度的字符串；相应的单个字符或子字符串会被新字符串替换。如果赋值时第二个索引小于第一个索引，则会隐式颠倒索引的顺序。

示例如下：

    local a = "Frederick"
    local b = a(2)    ; b = "r"
    local c = a(-3)   ; c = "i"
    local d = a(2,4)  ; d = "red"
    local e = a(2,-2) ; e = "rederic"
    a(3) = "upper"    ; a = "Frupperderick"
    a(3,-7) = "lower" ; a = "Frlowerderick"

在 FISH 函数中，字符串的常见用途是控制交互式输入和输出。以下示例展示用户如何输入杨氏模量和泊松比这两个参数。


model new

fish define in_def(msg,default)
  local xx = io.in(msg+'('+'default:'+string(default)+'):')
  if type(xx) = 3
    in_def = default
  else
    in_def = xx
  endif
end

def moduli_data
  global y_mod = in_def(1.0e9,'Input Young`s modulus ')
  global p_ratio = in_def(0.25,'Input Poisson`s ratio ')
  if p_ratio = 0.5 then
    io.out(' Bulk mod is undefined at Poisson`s ratio = 0.5')
    io.out(' Select a different value --')
    p_ratio = in_def
  endif
  global s_mod = y_mod / (2.0 * (1.0 + p_ratio))
  global b_mod = y_mod / (3.0 * (1.0 - 2.0 * p_ratio))
end
[moduli_data]
[y_mod]
[p_ratio]
[s_mod]
[b_mod]

所有处理字符串的 FISH 函数都已在 FISH 参考手册中建立索引（indexed）。


字符串属于可迭代类型。这意味着，可以将字符串用作 loop foreach 语句的遍历对象，见ForEach 循环（Loop ForEach），也可以对字符串进行拆分，见拆分（Splitting）。各个字符会按顺序遍历，每次得到一个长度为 1 的字符串。
