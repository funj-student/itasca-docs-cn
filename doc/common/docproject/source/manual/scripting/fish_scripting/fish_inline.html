执行 FISH：内联 FISH 或 FISH 代码片段

通常，FLAC3D 与 FISH 作为两个独立系统运行；不能将 FISH 语句直接作为 FLAC3D 命令执行，FLAC3D 命令也不能直接作为 FISH 程序中的语句。不过，两个系统有多种交互方式，下面列出其中较常用的几种。

  1. 直接使用函数——用户可以在输入行中给出用方括号括起的函数名，按需执行 FISH 函数：

    [myfunc]

    典型用途包括生成几何形状、设置特定的材料属性分布，以及以某种方式初始化应力。

  2. 用作历史变量——当 FISH 函数用作 history 命令的参数时，在整个模拟过程中，每逢按固定间隔保存历史数据，都会执行该函数。

  3. 步进计算时自动执行——如果 FISH 函数使用通用回调（callback）功能，就可以在 FLAC3D 的每个计算循环中自动执行，或在特定事件发生时执行。有关回调事件的说明，见 设置FISH回调命令（fish callback）。

  4. 使用函数控制计算——FISH 函数可以通过 命令（command） 语句或 执行命令字符串（system.command） 函数发出 FLAC3D 命令，因此可用于“驱动”FLAC3D，其方式类似于使用数据文件控制计算。不过，使用 FISH 函数控制程序要强大得多，因为函数可以改变传给命令的参数。

命令处理时的一般规则是：

  1. 如果要直接执行一行 FISH 代码或一个 FISH 函数，则必须将代码用 [] 括起。
  2. 如果在命令行中用 FISH 替代某个数值，则必须将该 FISH 表达式用 [] 括起。
  3. 如果命令语法明确要求后面是 FISH 符号，就可以直接给出符号名，无需用字符串定界符或 [] 括起。

基本原则是：如果命令行中某个位置是否需要 FISH 存在歧义，就必须使用 [] 括起相应内容，以明确其含义。

在普通命令处理过程中，即在 定义FISH函数命令（fish define） 或 定义FISH运算符命令（fish operator） 命令之外，遇到的用 [] 括起的 FISH 代码，称为内联 FISH 或 FISH 代码片段。

从 FLAC3D 执行 FISH 函数的主要方式，是给出一行包含函数名、并用 [] 括起的 FISH 代码。例如，在命令行中遇到以下代码时，就会执行 FISH 函数 fred：

[fred]

还可以直接执行 FISH 代码片段，作为一种方便的单行简写形式，无需显式创建函数：

[global fred = math.cos(4.5)]

FISH 与 FLAC3D 之间还有一种重要联系：在 FLAC3D 命令中，凡是需要输入值的位置，都可以用 FISH 符号，即变量名或函数名，进行替代。这是一项非常强大的功能，因为数据文件可以使用符号来编写，而不必写入实际数值。

model new
[global fred=1]
data scalar create ([fred  ],0,0) val 0.5
data scalar create ([fred+1],0,0) val 0.5
data scalar create ([fred+2],0,0) val 0.5
data scalar create ([fred+3],0,0) val 0.5
data scalar create ([fred+4],0,0) val 0.5

在本例中，生成的所有标量对象的 x 坐标都由 FISH 符号 fred 的初始设置控制。这是一个极其简单的参数化示例，展示了该语言与描述模型的数据文件结合使用时的强大功能。它使用户能够快速、方便地创建参数空间内不同取值对应的模型。通常会在建模开始时，对材料属性、特征尺寸、结构加固量等进行参数化，以便研究这些重要参数的变化所产生的影响。

使用 FISH 函数的另一种重要方式，是控制一次 FLAC3D 计算或一系列 FLAC3D 操作。将 FLAC3D 命令放在函数内部的 command - endcommand 代码段中即可。整个代码段可以放在循环内部，并且可将局部或全局参数传递给 FLAC3D 命令。

验证算例含节理材料试样的单轴抗压强度（Uniaxial Compressive Strength of a Jointed Material Sample）中给出了一个相对简单的示例。

请注意，每次尝试求出该词项的值时，都会重新解析并执行内联 FISH。如果命令接受多种词项类型，并需要逐一检查，那么在处理整个命令期间，这种求值可能发生多次。[CS：此处最好加入一个具体示例来说明] 因此需要注意可能产生的副作用及效率问题。
