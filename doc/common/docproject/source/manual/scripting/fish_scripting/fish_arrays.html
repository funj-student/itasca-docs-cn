数组

数组是 FISH 变量的容器，其中的元素通过整数索引进行赋值和读取。数组可以是多维的。可用方法见数组工具（Array Utilities）。

数组的灵活性和性能不如列表（Lists）或映射（Maps）。若需要以多维形式存储海量数据，数组类型可能是最佳选择；其他情况下，建议尽可能将旧版 FISH 代码中的数组替换为列表（Lists）。

可以使用库函数 array.create 创建数组。传给该函数的参数个数决定数组的维数，各参数的值决定相应维度的大小。除内存容量外，数组的维数和各维度的大小没有其他限制。

可以使用内置函数 删除数组（array.delete） 销毁数组对象。不过，这并非必需操作：不再被任何 FISH 值引用的数组对象会自动销毁，其内存也会被回收。

数组成员是 FISH 变量，只是没有与之关联的名称，因此遵循与符号值相同的规则。如果某个 FISH 符号指向数组，可以通过在圆括号列表中指定索引来访问数组元素。例如：

var1 = abc(3, nn + 3, math.max(5, 6))

在 FISH 符号 abc（abc） 当前指向三维数组时，是一条有效语句。数组可以出现在赋值语句的两侧，也可以用作其他数组的索引。

请注意，如果 FISH 符号 abc（abc） 当前指向一个数组，则以下语句：

abc = 0

将使 FISH 符号 abc（abc） 变为值为零的整数。如果没有其他符号指向该数组，就会失去对该数组的全部访问途径，数组也会被自动删除。

model random 10001
fish define afill          ; 用随机数填充矩阵
    ;; 方法一，采用 array.create 和循环
    var = array.create(4,3)
    loop local m (1,array.size(var,1))
        loop local n (1,array.size(var,2))
            var(m,n) = math.random.uniform
        end_loop
    end_loop
    ;; 方法二，采用列表
    var2 = array(math.random.uniform(4*3),4,3)
end
fish define ashow(v)          ; 显示矩阵内容
    loop local m (1,array.size(v,1))
        local hed = '   '
        local msg = '  '+string(m)
        loop local n (1,array.size(v,2))
            hed = hed + '               '+string(n)
            msg = msg + '  '+string(v(m,n),8,' ',8,'e')
        end_loop
        if m = 1
            io.out(hed)
        end_if
        io.out(msg)
    end_loop
end
[afill]
[ashow(var)]
[ashow(var2)]

数组可以通过 ==、<、> 等运算符相互比较。如果结构的类型名称相同，则按顺序比较各个成员。


数组属于可迭代类型。这意味着，可以将数组用作 loop foreach 语句的遍历对象，见ForEach 循环（Loop ForEach），也可以对数组进行拆分，见拆分（Splitting）。遍历数组各项时，最左侧索引最先变化，最右侧索引最后变化。


与大多数聚合类型相同，列出数组的值时，仅显示其类型为 Array、数组大小以及分配给它的唯一 ID。要查看数组内容，请使用 fish list 内容（fish list contents） 命令。请注意，对于大型多维数组，输出的数据量可能十分庞大。
