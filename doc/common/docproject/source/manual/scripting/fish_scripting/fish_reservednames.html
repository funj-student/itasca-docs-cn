函数和变量的保留名称

变量名或函数名必须以非数字字符开始，且不得包含以下任何符号：

.   ,   *   /   +   -   ^   =   <   >   #   (   )   [   ]  { }  @   ;   ’   ” ! % ~ :

变量名和函数名不区分大小写。用户定义的名称长度不限，但由于行长限制，在输出和绘图说明中可能被截断。通常可以任意选择名称，但不能与 FISH 语句、预定义变量或函数同名。例如，不能将 FISH 变量命名为 comp，因为这是用于获取或设置向量或张量分量的内置函数。

用户自定义变量可以表示布尔值、单个数值、字符串、列表、矩阵、映射、张量、结构、向量、指针或数组。数据类型列表见数据类型（Data Types）。这些类型所支持的方法列于FISH 函数索引（FISH Function Index）。
