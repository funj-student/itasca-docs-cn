变量作用域

默认情况下，变量名和函数名在全局范围内可见，与 BASIC 语言类似。一旦某个名称出现在有效的 FISH 语句中，此后便可在所有 FISH 代码和 FLAC3D 命令中全局使用，例如以内联 FISH（inline FISH） 形式替代数值。执行 fish list 符号（fish list symbols） 命令时，该变量还会出现在变量列表中，也会显示在用户界面的 FISH Global Symbols（FISH 全局符号）控件组中。

若用 local 标识符声明变量，则该变量被视为该函数的局部变量，函数执行完毕后即不可用。局部变量在函数中优先于全局变量。

如果禁用了 FISH 变量自动创建选项，见 设置FISH变量自动创建命令（fish automatic-create） 命令，则所有全局变量都必须使用 global 关键字声明。可以在一个 FISH 函数中为全局变量赋值，再在另一个函数或 FLAC3D 命令中使用它。在被修改之前，该值始终保留。所有全局变量的值也会通过 save 命令保存，并通过 restore 命令恢复。

强烈建议用户在熟悉 FISH、并开始编写具有一定复杂度的函数后，将所有数据文件中的 设置FISH变量自动创建命令（fish automatic-create） 设置为 关闭（off）。变量名的拼写错误可能意外创建一个默认值为 0 的新全局 FISH 符号，从而产生隐蔽且难以发现的错误。

以下简短示例展示了如何在 FISH 中声明 global 符号和 local 变量：

fish define test
    ;; 声明两个全局符号
    global aa = 0, bb = 'a'
    ;; 声明两个局部变量
    local cc = 3, dd = 'test'
end
[test]
fish define test
!    test = aa + bc ; 这是一个错误，bc 尚未声明
