映射

在使用方式上，映射类似于列表（Lists），二者都可存储数量可变的元素，并通过某个值访问这些元素。

但二者有若干不同之处。映射类型用于从一个值，即键，查找到另一个值。作为键的值不局限于整数，也不必连续。键和值可以采用任意有效的 FISH 类型。与列表一样，映射按值传递。此外，映射的大小可以动态变化。

用于创建和操作映射类型的可用方法，见映射工具（Map Utilities）。

映射类型可以使用内置函数 映射（map） 创建，如下所示。

map1 = map

向内置函数 映射（map） 提供键值对，可以在创建映射时直接添加条目。

map1 = map(10,1.0,   'fred',4.0,   3.4,6.0)

上面一行创建了包含三个键值对的映射：整数 10 对应值 1.0，字符串 示例函数名 fred（fred） 对应值 4.0，实数 3.4 对应值 6.0。

与数组相同，给定键后，可以使用 () 运算符访问对应的值。

v = map1('fred')

上面一行返回分配给键 示例函数名 fred（fred） 的值 4.0。映射使用通用的有序红黑树容器实现，以优化查找时间。

可用 loop foreach 语句遍历映射的所有值。这会把循环变量依次赋给映射的每个值。

loop foreach local v map1
   io.out(v)
endloop

也可以使用内置函数 映射键（map.keys） 遍历映射的键：

loop foreach local v map.keys(map1)
   io.out(string(v) + ' = ' + string(map1(v)))
endloop

由于映射按值传递，将映射赋给另一个符号时，会创建该映射的副本，而不是让两个符号引用同一数组。例如：

local a = map(1,'fred',    5,'george')
local b = a
b(5) = 'mary'
io.out(a(5))
io.out(b(5))

将先输出“george”，然后输出“mary”。

以下数据文件给出了在 FISH 中使用映射的更多示例。

fish define testBreak
    loop local i (1,2)
        testmap = map('first',1,  'second',2,  'third',3)
        sum = 0
        loop foreach local v testmap
            sum = sum + v
        endloop
    endloop        
end
[testBreak]
[sum]

fish define test1
    local temp = map('hello',1,'world',2)
    test1 = temp('hello') + temp('world')
end
[test1]

fish define test2
    testmap = map('first',1,'second',2,'third',3)
    map.remove(testmap,'first')
    map.add(testmap,'fourth',4)
    testmap('second')=8
    ; 当前数值为 fourth->4、second->8、third->3
    local output = 0
    loop foreach n testmap
        output = output + n
    endloop
    test2 = output
end
[test2]

fish define test3
    ; 测试各键
    testmap = map('yet',1,'another',4,'test',9,'m',16)
    testkeys = map.keys(testmap)
    test3 = testkeys(3)
    
    ; 检查是否包含
    if (map.has(testmap,'wrongkey'))
      hascheck = 909
    else if (map.has(testmap,'another'))
      hascheck = testmap('another')
    endif
end
[test3]
[hascheck]

映射属于可迭代类型。这意味着，可以将映射用作 loop foreach 语句的遍历对象，见ForEach 循环（Loop ForEach），也可以对映射进行拆分，见拆分（Splitting）。遍历时会按顺序访问映射中的每个值。


与大多数聚合类型相同，列出映射的值时，仅显示其类型为 Map，以及条目数量。要查看映射内容，请使用 fish list 内容（fish list contents） 命令。
