二元运算符始终按照给定的优先级顺序执行。可以使用任意层数的括号来明确求值顺序；括号内的表达式优先于括号外的表达式求值，内层括号优先于外层括号。例如，FISH 将变量 xx 的值计算为 133：

xx = 6/3*4^3+5

该表达式等价于：

xx = ( (6/3) * (4^3) ) + 5

如果对算术运算符的执行顺序存在疑问，应使用括号明确运算顺序。

如果算术运算的两个操作数中有任意一个为浮点类型，则结果为浮点类型。如果两个操作数均为整数，则结果为整数，但除法运算符除外，它始终将类型提升为浮点类型。张量也会按照同样的规则自动提升为矩阵。

除法运算符始终将类型提升为浮点类型。

向下取整除法运算符定义为 floor(i/j)，因此 -1//3 的返回值为 -1。

成员访问运算符

最后一种可用运算符是成员访问运算符（->），用于访问向量、张量和结构类型的分量或成员。

结构类型允许用户自行定义访问符号，即结构成员的名称。

成员访问运算符可以出现在赋值语句的左侧或右侧，便于访问向量或张量的各个分量。它可以直接用于符号或局部值，也可以作为更长表达式的一部分使用。

local a = vector(1,2,3)
local b = a->x
a->y = 4
gp.pos(pnt)->x = 3.0
local c = zone.strain.rate(pnt)->zz
