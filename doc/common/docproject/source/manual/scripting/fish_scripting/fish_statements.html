FISH 语句

caseof - case - endcase 根据条件将控制权传递给某个代码块。
command - endcommand 开始或结束一个 FLAC3D 命令段。
define - end 函数定义的开始和结束。
exit 退出函数。
全局函数（global） 创建全局变量。
if - else if - else - endif 条件语句。
local 创建局部变量。
lock 允许在 FISH 运算子中安全地写入全局符号。
loop - endloop - exit loop - continue 循环执行代码，共有四种形式。
return 退出函数并返回一个值。
section - endsection - exit section 开始或结束一个已定义的独立代码段。
struct - structure 定义或创建结构类型。
