张量

FISH 支持 3×3 对称张量，用于表示应力和应变状态。

还可以从矩阵或列表创建张量，见库函数 张量（tensor）。

分量访问

可以使用圆括号访问张量分量：单参数索引的范围为 1 至 6，分量顺序为 xx、yy、zz、xy、xz、yz；也可以使用两个参数，两个参数的范围均为 1 至 3。

也可以通过 c -> 运算符以及 xx、yy、zz、xy、xz、yz、yx、zx、zy 访问器来访问张量分量。

以下示例展示访问张量各个分量的不同方法。

    local a = tensor(2,3,4,1,6,5)
    local b = tensor(8,8,3,7,3,5)
	
    local c = a(5)   ; c = 6.0
    local d = a(1,3) ; d = 6.0
    local e = a->xz  ; e = 6.0
	
    a(5) = 6.0    ; 这些形式均等价
    a(1,3) = 6.0
    a->xz = 6.0

数学运算

张量可以进行加法和乘法运算。

张量可以与向量（vector）相乘，得到另一个向量。

请注意，张量相乘的结果是矩阵（matrix）。

运算符支持情况的完整表格见算术（Arithmetic）。

可用方法见张量工具（Tensor Utilities）。

迭代

张量属于可迭代类型。这意味着，可以将张量用作 loop foreach 语句的遍历对象，见ForEach 循环（Loop ForEach），也可以对张量进行拆分，见拆分（Splitting）。各分量按 xx、yy、zz、xy、xz、yz 的顺序遍历。

与大多数聚合类型相同，列出张量的值时，仅显示 张量（Tensor）。要查看张量内容，请使用 fish list 内容（fish list contents） 命令。
