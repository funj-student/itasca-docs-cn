函数：结构、求值和调用方式

在 FISH 语言中，用户创建的对象只有两种可以执行：函数和运算子（operators）。函数名位于 定义FISH函数命令（fish define） 命令之后，其后可带有可选的参数列表，函数作用域以 end 语句结束。函数执行时，end 语句也用于将控制权交还调用者。请注意，exit 语句可以在执行到 end 语句之前交还控制权。以下示例展示函数的创建和使用方法。


fish define xxx
    aa  = 2 * 3
    bb  = 0
    xxx = aa + bb
end

函数执行时会改变 xxx 的值。变量 aa 在局部计算，而计算 xxx 时使用的是 bb 的现有值。若未明确为变量赋值，其默认值为零，类型为整数。函数并不一定要为与其名称对应的变量赋值。

返回值的另一种方式是使用 return 语句，如下例所示：


fish define yyy
    aa  = 2 * 3
    return aa + bb
end

在这种情况下，每次调用 yyy 时都会返回 aa+bb 的值，但与 yyy 关联的实际 FISH 参数值不会改变。


调用函数的方式有多种，包括：

  1. 作为 FISH 函数中的单个词 xxx；

  2. 作为 FISH 公式中的变量 xxx，例如：

    new_var = (math.sqrt(xxx) / 5.6)^4;

  3. 作为用方括号括起的单个词 [xxx]，具体说明见此处（here）；

  4. 作为 FLAC3D 输入行中数值的符号替代；或者

  5. 作为接受 FISH 函数作为选项的命令的参数，例如 fish history 。在这种情况下，函数通常会在稍后作为回调被调用。

  6. 作为第（5）种情况的特例，可以使用 设置FISH回调命令（fish callback） 命令，或使用 求解模型（model solve） 命令的 fish-call 关键字，使函数在循环计算过程中执行。不过，在这种情况下，出于运行效率考虑，建议使用运算子（operators）。


FISH 函数还可以接受任意数量的参数。定义函数时，将这些参数写入函数定义中即可。例如：


fish define george(one,two)
    george = one * two
end

一个函数可以在定义之前被另一个函数引用：FISH 编译器在首次遇到该名称时建立一个符号；随后，通过 定义FISH函数命令（fish define） 命令定义该函数时，编译器会链接所有对它的引用。函数不能被删除，但可以重新定义。

函数调用可以嵌套到任意层次，即函数可以调用其他函数，后者又可以继续调用其他函数。但实际强制限制调用嵌套层数为 64。函数调用可以是递归的，即执行某个函数时可以再次调用它自身。下例展示一种不受限的递归函数调用，这是不允许的，因为在定义函数时以某种方式使用了函数自身的名称，导致它试图无限地调用自身。该示例在执行时会产生错误：

;; 错误的递归
data scalar create (0,0,0)
data scalar create (0,0,1)
data scalar create (1,0,0)
fish define pos_sum
    pos_sum = (0,0,0)
    loop foreach local scalar data.scalar.list
        pos_sum = pos_sum + data.scalar.pos(scalar)
    end_loop
end
![pos_sum]

通常的原则是，函数应避免读取其自身的值。同一个函数应按以下方式编写：


;; 无递归
fish define pos_sum
    pos_sum = (0,0,0)
    loop foreach local scalar data.scalar.list
        pos_sum += data.scalar.pos(scalar)
    end_loop
end
[pos_sum]

变量与函数的区别在于，只要提及函数名，就一定会执行该函数；变量则仅提供自身的当前值。但是，执行函数也可能导致对其他变量进行求值，而非仅对函数求值。例如，在需要记录多个 FISH 变量的历史时，这一特性十分有用：只需一个函数就能计算多个量，如下所示：


model new
fish define h_var_1
    global bp22 ; 指向 ID = 22 的网格点的指针，在创建时设置……
    global bp45 ; 指向 ID = 45 的网格点的指针，在创建时设置……
    local xx = gp.pos.x(bp45)
    h_var_1 = xx
    h_var_2 = gp.pos.x(bp22)
    h_var_3 = math.abs(h_var_2 - xx)  ; 此处使用 xx 可避免递归
    h_var_4 = gp.vel.x(bp45)
    h_var_5 = gp.vel.x(bp22)
    h_var_6 = math.abs(h_var_5 - h_var_4)
end

用于请求记录历史（histories）的 FLAC3D 命令可以是：

fish history h_var_1
fish history h_var_2
fish history h_var_3
fish history h_var_4
fish history h_var_5
fish history h_var_6

FLAC3D 的历史（history）逻辑会按照指定间隔执行函数 h_var_1。与此同时，h_var_2 至 h_var_6 的值也会随之更新。
