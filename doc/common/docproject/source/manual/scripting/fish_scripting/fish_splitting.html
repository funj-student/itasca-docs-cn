拆分：针对类型中的各项内容自动执行函数

FISH 拆分允许对聚合类型，例如列表、数组或对象容器中的每个元素，重复执行函数、运算子或库函数调用。如果拆分用于读取操作，结果将是一个列表，按顺序包含各次执行的结果。

拆分可作为 loop 语句的替代方案，以非常清晰简洁的方式对许多对象执行操作。

要进行拆分调用，可以在函数、运算子或库函数调用的一个或多个参数前添加拆分运算符前缀“::”。未拆分的参数在每次执行时都保持相同值。如果拆分多个参数，这些参数必须包含相同数量的元素。

例如，要建立包含所有数据标量对象 x 坐标的列表，可以这样写：

    local a = data.scalar.pos(::data.scalar.list)->x

这会对 标量数据列表（data.scalar.list） 返回值所指容器中的所有数据标量对象进行拆分，并对列表中的每一项调用一次内置函数 标量数据位置（data.scalar.pos）。任何可迭代的 FISH 类型都可以拆分。FISH 的可迭代类型包括指向容器的指针、字符串、向量、张量、矩阵、列表、映射和数组。最常见的拆分对象是列表，或指向网格点、球、块体等模型对象容器的指针。

列表筛选

将拆分与布尔列表筛选结合使用，可以快速找出满足特定条件的对象子列表。例如，以下代码会找出所有标记为“surface”组的数据标量对象。

    local allpts = list(data.scalar.list) ; 指向标量的指针列表
    local check = data.scalar.isgroup(::data.scalar.list,'surface') 
                                                 ; 布尔值列表
    global pts = allpts(check) ; 'surface' 中的标量列表

这可以用下面一行 FISH 代码完成：

    global pts = ...
    list(data.scalar.list)(data.scalar.isgroup(::data.scalar.list,'surface'))

赋值时拆分

向库函数赋值时也可以进行拆分。此时，用户必须明确赋值语句右侧，即等号后面的内容是否也要拆分。如果不拆分右侧，就会在对函数进行的每次拆分赋值中赋入相同的值；如果拆分右侧，则将右侧列表中的元素依次赋给各次函数调用。

在赋值运算符 =、+=、-=、*= 或 /= 后面添加拆分运算符 ::，即可表示对右侧进行拆分，分别写作 =::、+=::、-=::、*=:: 和 /=::。

例如，以下一行 FISH 代码会为模型中每个数据标量对象的 x 坐标增加一个介于 0.0 和 1.0 之间的随机值。

    data.scalar.pos(::data.scalar.list)->x ...
                      +=:: math.random.uniform(data.scalar.num)

拆分与多线程

如果拆分调用的是运算子或标记为线程安全的库函数，就会自动在所有可用线程上执行。如果文档说明中的“=”号前面带有“:”，就表示该库函数是线程安全的。其他情况下，仍会执行拆分操作，但仅在单个线程上顺序执行。

总结与提示

结合布尔列表筛选、作用于列表元素的运算符以及拆分功能，可以用较少的代码实现复杂算法，而无需使用 loop 语句。

要有效使用拆分，需要在传统顺序编程的思路和方法上作出一定调整。不过，熟悉之后，就能用较少的代码，以很快且相对高效的方式处理大量数据。

请注意，拆分虽然非常方便，但在多线程环境中，通常不如使用一次拆分、并对每个对象同时完成多项计算的 FISH 运算子高效。如果运行速度十分重要，例如函数在循环计算期间执行时通常如此，则一般值得编写运算子，而不是对现有内置函数反复执行多次拆分。
