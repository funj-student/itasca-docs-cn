运算子：支持多线程的函数

FISH 运算子是一类特殊函数，专门用于在多线程环境中执行。

通过拆分（splitting）重复调用函数时，如果该符号声明为运算子，各次独立执行就会分配到所有可用线程上，见 设置线程数命令（program threads） 命令。对于典型的现代多核计算机和大型数据集，这可以大幅提高运行速度。

这些函数需要在多个线程同时运行时保证安全，因此必须在受限环境中执行。以下规则使运算子与普通函数有所不同：

  1. 运算子必须始终接受至少一个参数。
  2. 运算子不能调用普通 FISH 函数，但可以调用其他运算子。
  3. 运算子只能调用标记为线程安全的 FISH 库函数。如果文档说明中的“=”号前面带有“:”，就表示该库函数是线程安全的。
  4. 运算子只有在使用 lock 语句时，才可以写入全局符号。
  5. 运算子不能修改通过参数传入的值。
  6. 运算子不能在赋值时，即在等号左侧调用库函数，并向其传递对象指针，除非该对象本身就是作为参数传入的。
  7. 运算子不能调用其他运算子并向其传递对象指针，除非该对象本身就是作为参数传入的。

请注意，对全局符号的读取或写入，必须在所有同时运行的执行线程之间进行同步，因此可能严重影响整体性能。建议尽可能只使用局部变量。

运算子通过 定义FISH运算符命令（fish operator） 命令创建，参数写在后面，方式与 定义FISH函数命令（fish define） 相同。定义中的 FISH 代码行与普通函数相同，但必须遵守上述限制。

为演示运算子的使用，先生成一组待处理数据。以下 FISH 函数将在 10×10×10 的立方体内随机生成 100,000 个数据标量对象，并为其赋予 0.0 至 10.0 之间的随机值。

model random 12000
fish define generate(n)
    local x = math.random.uniform(n) * 10.0
    local y = math.random.uniform(n) * 10.0
    local z = math.random.uniform(n) * 10.0
    local scalars = data.scalar.create(::vector(::x,::y,::z))
    data.scalar.value(::scalars) =:: math.random.uniform(n) * 10.0
end
[generate(100000)]

以下示例运算子判断某个标量对象的 x 坐标是否位于给定范围内。如果是，就将该对象加入槽位 标记（mark） 中的组 inside，并返回 真值（true）；否则，将它加入组 outside，并返回 假值（false）。

fish operator labeldata(data,low,high)
    local x = data.scalar.pos(data)->x
    if math.in.range(low,x,high) then
        data.scalar.group(data,'mark') = 'inside'
        return true
    endif
    data.scalar.group(data,'mark') = 'outside'
    return false
end

要执行运算子，可像调用普通 FISH 符号一样调用它，并传入一个拆分（split）参数。由于它是运算子，这些重复调用将在所有可用线程上执行。

[labeldata(::data.scalar.list,4.0,6.0)]

请注意运算子中 return 语句的用法。运算子与函数一样，本身也是一个全局符号；若直接为它赋值，就需要使用 lock 语句，并产生明显的同步开销。因此，运算子应始终使用 return 语句返回操作结果。与所有拆分操作一样，各次调用的返回值会汇总为一个列表。


某些情况下，对全局符号的读取和/或写入不可避免。此时，需要在运算子内部使用 fwd 语句，以允许写入全局符号。以下示例使用 FISH 运算子扫描标量数据，查找位于给定笛卡尔坐标范围所定义的长方体内部的值，并将其中的最大值、最小值、累计值和最后找到的值返回到全局符号中。

[global maxval = 0.0]
[global minval = 1e30]
[global accval = 0.0]
[global setval = 0.0]
fish operator maxdata(data,low,high)
    local p = data.scalar.pos(data)
    if math.in.range(low,p,high) then
        lock maxval = math.max(maxval,data.scalar.val(data)) ; 最大值
        lock minval = math.min(minval,data.scalar.val(data)) ; 最小值
        lock accval += data.scalar.val(data)         ; 累计值
        lock setval = data.scalar.val(data)   ; 设置的值，应为
                                              ; 列表中的最后一个值
    endif
end
[maxdata(::data.scalar.list,(4,4,4),(6,6,6))]

最后，FISH 运算子最常见、最重要的用途之一，是在循环计算过程中使用；这实际上也是开发运算子的主要原因。否则，一个检查或修改模型中所有对象的单线程 FISH 函数，很容易占据系统运行时间的主要部分。

要指定某个运算子在循环计算期间执行，可以使用 设置FISH回调命令（fish callback） 命令，或 求解模型（model solve） 命令的 fish-call 关键字。先指定运算子名称，再给出每次执行时传入的参数。

通常，用来指定待遍历对象列表的参数由 FISH 库函数提供，命令处理器不能直接识别，因此必须使用内联 FISH（inline fish）。与通常的拆分调用一样，必须添加前缀 ::，表示要对该参数进行拆分，见拆分（Splitting）。请注意，这些值在处理命令时求出并保存，供循环计算期间执行时使用。

下面给出一个示例：

;; 持续生效的 FISH 调用项
fish callback add my_function([::data.scalar.list]) -100
;; 仅添加到单条 solve 命令的 FISH 调用
model solve fish-call -100 my_function([::data.scalar.list])
