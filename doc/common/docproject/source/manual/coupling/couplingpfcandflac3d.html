PFC 与 FLAC3D 的耦合

FLAC3D 和 PFC 的计算引擎及绘图引擎均设计为插件，共用同一套图形用户界面和循环计算系统。因此，可以在同一个图形用户界面中同时加载并运行 FLAC3D 和 PFC，使连续体模型组件与离散元模型组件同时存在于同一个 FLAC3D 实例中。若耦合模型超过演示版的规模限制，运行计算时必须同时具备有效的 PFC 和 FLAC3D 许可证。在 FLAC3D 图形用户界面中，可以通过 Tools ‣ Load PFC 菜单项加载 PFC；同样，也可以在 PFC 图形用户界面中通过 Tools ‣ Load FLAC3D 菜单项加载 FLAC3D。此外，还可以使用 加载插件命令（program load） 命令加载各个模块。工程文件会记录已加载的模块。请注意，若加载保存文件时缺少所需模块，程序会发出警告，且该模型状态很可能无法正常使用。上述许可证要求适用于 PFC-FLAC3D 耦合模型。

为了使 PFC 模型组件（球体、刚性簇和刚性块体）能够与 FLAC3D 网格单元相互作用，专门开发了独立的耦合模块。这些模块独立于 PFC 和 FLAC3D 的计算模块及绘图模块，连接 FLAC3D 与 PFC。目前共有四个耦合模块，分别对应以下三种耦合方案：

  • 将 PFC 模型组件与一维结构单元耦合的方案。
  • 将 PFC 模型组件与 FLAC3D 壳类结构单元和/或 FLAC3D 网格单元面耦合的方案。
  • 将 PFC 球与 FLAC3D 网格单元耦合的方案。

所有采用 PFC-FLAC3D 耦合的应用示例均可在此处（here）找到。

以下各节分别介绍这三种方案：

  • 一维结构单元耦合（1D Structural Element Coupling）
  • 墙-网格单元耦合（Wall-Zone Coupling）
  • 球体-网格单元耦合（Ball-Zone Coupling）
