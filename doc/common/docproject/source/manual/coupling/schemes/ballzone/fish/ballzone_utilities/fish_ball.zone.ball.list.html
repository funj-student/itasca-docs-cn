ball.zone.ball.list

语法

l = ball.zone.ball.list

获取参与球—网格单元耦合的球的全局列表。可使用 循环遍历（loop foreach） 结构遍历该列表。

返回值：l - 球列表

用法示例

以下示例说明如何使用 循环遍历（loop foreach） 语句 ball.zone.ball.list 遍历系统中参与球—网格单元耦合的球的列表。

model solve calm 500 time 1.0

fish define ball_loop
  ; 遍历球颗粒
  global nballs = 0
  loop foreach local b ball.list
    nballs = nballs + 1
  endloop
