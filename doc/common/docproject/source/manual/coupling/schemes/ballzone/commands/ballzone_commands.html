命令

创建球—网格单元耦合数据结构。该耦合可对相互重叠的球和网格单元进行运动学修正。

注意

  • 要使 PFC 以耦合方式进行循环计算，必须将 FLAC3D 配置为动力计算，并采用大应变模式。这两项设置分别通过 设置大变形模式命令（model large-strain） 和 模型配置动力分析命令（model configure dynamic） 命令完成。
  • 必须通过 Tools ‣ Plugins 菜单项或 加载模块命令（program load module） 命令加载接触插件、PFC 插件和球—网格单元耦合插件。若要显示 PFC 模型组件，还必须加载 PFC 图形界面插件，此时使用 加载 GUI 模块命令（program load guimodule） 命令。
