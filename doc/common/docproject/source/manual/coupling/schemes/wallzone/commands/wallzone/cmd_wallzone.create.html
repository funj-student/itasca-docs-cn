wall-zone create 命令

语法

wall-zone create ... <range>

主要关键字：

角度（angle）    face    fill    分组（group）    internal    名称（name）    merge    skip-errors    起始单元（starting-zone）

使用 PFC 墙包裹 FLAC3D 网格单元。按定义，PFC 墙是通过边相连的一组三角面片，不包含面片相互穿透、多于两个面片共用一条边等非流形情况。给定的 range 作用于 FLAC3D 网格单元，用于筛选需要包裹的网格单元。默认情况下，仅使用墙面片包裹被视为表面的网格单元面。这里的表面可以是外部网格单元面，即仅与一个网格单元相邻的面，也可以是一侧为空模型网格单元、另一侧为非空模型网格单元的面。

angle f

仅考虑法线方向与初始网格单元面的法线方向夹角不超过 f 度的面。初始网格单元面由 starting-zone 和 face 关键字指定。

face i <restrict-to-face>

此关键字将要添加到墙上的初始网格单元面设置为 i。通常将它与 starting-zone 关键字配合使用，以指定开始包裹时的网格单元和面。可选的 restict-to-face 关键字指定仅考虑具有该面编号的网格单元面进行耦合。

fill

指定使用所有可能的网格单元面片构建墙。这意味着，对于每组非流形的网格单元面，都将创建新的墙。

group s <keyword>

将组名 s 添加到通过 PFC 墙面片进行耦合的网格单元面。分组逻辑的用法见分组（Groups）。

remove

从网格单元面中移除组名 s。若未指定槽位，则从所有包含该组名的槽位中移除它。

slot s

将组分配到名为 s 的槽位。默认槽位名称为 默认（Default）。

internal b

指定是否可以包裹内部面。例如，当相邻面上的网格点位置不一致的网格单元之间未设置附着连接条件时，可能出现内部面。默认情况下，不包裹内部面。

name s

将墙的名称设置为 s。若已存在该名称的耦合墙，则将与网格单元面对应的新面片添加到这面墙上；若不存在，则创建一面新的耦合墙。若未指定名称，则墙的名称设为 默认墙体名称（wallzoneXX），其中 XX 向（XX） 为下一个可用的墙 ID。

merge b

默认情况下，若在与现有耦合条目相同的位置创建新的耦合条目，则将这些条目合并为一个耦合条目。

skip-errors

将网格单元面转换成的墙面片拼接起来时，忽略发生的错误。例如，尺寸不同且未进行附着连接的相邻网格单元面可能构成非流形几何形状。在这种情况下，无法形成通过边相连的流形几何形状的墙面片将被忽略。

starting-zone i

选择第一个要添加的网格单元。可以再使用 face 关键字指定初始面。这可能十分重要，因为墙面片从一个种子面片开始添加，且新增面片必须通过边相连。该网格单元应位于模型域内，参见 设置模型域命令（model domain） 命令。
