命令

使用 PFC 墙包裹网格单元和壳类结构单元。该耦合使球体和刚性簇能够直接与网格单元及壳类结构单元相互作用。

注意

  • 要使 PFC 以耦合方式进行循环计算，FLAC3D 必须采用大应变模式。这项设置通过 设置大变形模式命令（model large-strain） 命令完成。
  • 必须通过 Tools ‣ Plugins 菜单项或 加载模块命令（program load module） 命令加载接触插件、PFC 插件和墙—网格单元耦合插件。若要显示 PFC 模型组件，还必须加载 PFC 图形界面插件，此时使用 加载 GUI 模块命令（program load guimodule） 命令。

墙-网格单元命令

wall-zone compute-stiffness
wall-zone create
wall-zone full-computation
wall-zone stiffness-factor
wall-zone update-tolerance

墙-结构命令

wall-structure compute-stiffness
wall-structure create
wall-structure full-computation
wall-structure stiffness-factor
wall-structure update-tolerance
