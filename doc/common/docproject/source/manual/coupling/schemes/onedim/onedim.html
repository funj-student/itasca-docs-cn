一维结构单元耦合方案

梁（beams）、锚索（cables）、桩（piles）和土工格栅（geogrids）等一维结构单元由结构单元节点（structural element nodes）组成。现在，可以通过结构单元连接（structural element links）将节点连接到目标对象，目标可以是球、刚性团簇中的子颗粒、刚体块、网格单元或结构单元。创建一维结构单元时，会自动创建连接。与结构单元或网格单元之间的连接不同，当连接的另一端是球、刚性团簇中的子颗粒或刚体块时，程序不会自动指定连接模型的属性，用户必须直接指定。连接模型需要计算节点位置处的应力。对于球、簇和刚体块等刚性对象，应力根据接触力和分支向量计算，采用的方法与测量逻辑相同。有关公式的进一步说明，请参阅测量逻辑（measurement logic）说明中的相关部分（here）。
