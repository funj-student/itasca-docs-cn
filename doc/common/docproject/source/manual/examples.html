示例类型

此处列举的示例分为三个不同类别。

  • Tutorials 面向新手用户，是其入门的第一站；它们演示程序功能与原理。
  • Verification Problems 用于表明程序结果相对于基础理论的正确性；它们不一定是“真实世界”的示例。
  • Example Applications 是这些程序部分可能用途的全尺寸演示。
