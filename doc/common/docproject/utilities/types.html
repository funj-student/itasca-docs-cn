Types

基本变量类型有以下若干种，列于下表。命令或函数中变量类型总是由命令/函数签名中给出的名称提示：该名称或为类型名首字母（例如布尔类型为 b），或以类型名首字母开头（例如浮点类型为 浮点 x 向位置（fposx））。命令签名或 FISH 函数中同一类型的多个实例通常加编号（i1 i2 i3 …… 依此类推）。[1]

any

用于表示此处所示除 sym 之外其他任意类型（a）的统称。命令中的多个实例按顺序编号（a1 a2 a3 等）。当可接受某一特定类型组合时（例如常见情形：可给出字符串 s 或整数 i），也用该类型表示。此时，具体的可接受类型在说明正文中给出。

bool

布尔值（b），有六种有效表达：on off true false yes no。若未给出取值，则布尔值视为 true。不给值、on、true 与 yes 均等价。off、false 与 no 均等价。命令中的多个实例按顺序编号（b1 b2 b3 等）。

flt

实数（f），可正可负。可用科学计数法（e 记法）书写。命令中的多个实例按顺序编号（f1 f2 f3 等）。

ind

索引（ind），正整数。命令中的多个实例按顺序编号（索引 1（ind1） 索引 2（ind2） 索引 3（ind3） 等）。

int

整数（i），可正可负。整数不能包含小数。命令中的多个实例按顺序编号（i1 i2 i3 等）。

list

列表（l），即可变的有序元素序列。列表元素按索引访问。更多信息见 列表（Lists）。

list

可通过整数索引访问的 FISH 值列表。

map

键值对映射（m）容器。更多信息见 映射（Maps）。

num

数值（n），flt 或 int 均可。命令中的多个实例按顺序编号（n1 n2 n3 等）。

str

由字母数字字符组成的字符串（s）。命令中的多个实例按顺序编号（s1 s2 s3 等）。更多信息见 字符串（Strings）。

sym

FISH 符号（名称（name））——其中 名称（name） 为 FISH 变量或 FISH 函数的名称。

vec

向量（v 或 v2 或 v3），以单行矩阵表示。v2 和 v3 分别表示要求二维或三维向量。单纯的 “v” 表示要求与该程序维数相同的向量，即三维程序要求三维向量、二维程序要求二维向量。在 FLAC3D 中，v 始终表示三维向量。当命令中需要多个同类型向量时，用附加下划线的字母区分（v2_a v2_b 或 v_a v_b 等）。更多信息见 向量（Vectors）。

vec2

A 2D vector.

尾注

[1]有些情形下，若区分能增强可读性，单条命令中同一类型的多个实例可用不同方式标识（例如 x 向尺寸（fx） y 向尺寸（fy） z 向尺寸（fz））。另一些情形下可给它们“名称”（最大索引（imax）、浮点半径（fradius） 等），因为它们作为某个关键字的参数出现，却可能在另一个关键字的说明文字中被引用（例如可参阅 生成几何圆锥体命令（geometry generate cone） 命令）。这些情形下基本类型总由首字母表示——“i”表示 int，“f”表示 flt，依此类推。
