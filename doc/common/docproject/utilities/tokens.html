Tokens

当出现在命令中时，color、text、line 和 range 这些标记是代码块的简写名称，这些代码块有多种可为命令提供所需关键字/取值信息的有效方式。


color Token

color 标记的命令参考信息如下。

color keyword

注意 color 出现在 line 与 text（下文描述）中作为选项。color 的每种写法都以“color”开头（与之对比，text 不必在各关键字前加“text”）。color 标记可接受的命令写法如下。

s

其中 s 为有效的颜色名称（见下表）。此外还可使用 SVG 颜色关键字名称列表（在线见 SVG 颜色关键字参考（http://www.w3.org/TR/SVG/types.html#ColorKeywords））中定义的任何关键字。

sCOLRRGGBB

在 RGB 空间中指定颜色，其中 红色分量（RR）、绿色分量（GG） 与 蓝色分量（BB） 为两位十六进制码（例如 白色（colFFFFFF） 为白色，黑色（col000000） 为黑色）。

rgb 整数返回值（ir ）绿色强度分量（ig ）蓝色强度分量（ib ）

在 RGB 空间指定颜色，其中 红、绿、蓝强度分量（ir ig ib） 为 0 到 255 的整数（例如 rgb 0 0 0 为黑色，rgb 255 255 255 为白色）。

hsv 变量 ih（ih ）变量 is（is ）变量 iv（iv ）

在 HSV 空间指定颜色，其中 变量 ih（ih） 为 0 到 359 的整数，变量 is（is） 与 变量 iv（iv） 为 0 到 255 的整数（例如 hsv 0 0 0 为黑色，hsv 0 0 255 为白色）。

line Token

line 标记的命令参考信息如下。

line keyword

在所有情形下 line 标记都由 PLOT 命令使用。

color color

用 color 标记指定线的颜色（见上文）。

active b

打开或关闭线渲染（开启（on） 或 关闭（off））。

style keyword

指定线型。有效选项为：none solid dash dot dashdot dashdotdot。

width i

指定线的宽度。该值必须在 0 到 10 之间。值为 0 表示最细的线（1 像素）。


text Token

text 关键字的命令参考信息如下。

text keyword

text 标记接受多个关键字。提供 text 标记时，可给出其中一个或多个关键字。但并非所有关键字在所有上下文中都可用。

color color

用 color 标记指定文字的颜色（见上文）。

family s

指定字体族名称（例如 “Arial” 或 “Times New Roman”）。（注意名称中必须用下划线代替空格。）

active :lbool:`b`

打开或关闭文本渲染（开启（on） 或 关闭（off））。

size i

指定所用文本字体的高度。该值取决于上下文。

style keyword

指定字体样式。有效选项为：normal bold italic bolditalic。

text s

指定要使用的文字（替代默认值）。
