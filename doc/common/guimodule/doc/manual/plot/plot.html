Plot

可使用 i 绘图（Plot） 窗格中的控件交互式可视化模型。与大多数操作一样，也可通过命令创建、删除、修改绘图等。不过，只要快速浏览任一绘图的控件就会发现，修改任何具体绘图都可能涉及大量关键字。

概略地说，c 绘图（plot） 命令分为三组。

  • 对整幅图进行操作的命令（创建绘图（plot create）、设置当前绘图命令（plot current）、删除绘图命令（plot delete）、设置绘图自动更新命令（plot update） 等）
  • 控制绘图当前视图的命令（设置视图命令（plot view））

前两者在此处有完整说明。

  • 操作图的 内容，即图中 显示什么的命令（管理绘图项命令（plot item）、清除绘图命令（plot clear）、设置绘图标题命令（plot title） 等）

这些命令在此也有说明，但 管理绘图项命令（plot item） 命令仅部分描述。用于设置或修改项外观的关键字因数量过多而省略。要获得通过命令控制绘图项外观所需的关键字，请参考命令驱动绘图工作流（workflow）主题。

关于交互式控制绘图与绘图操作的全部信息，见 i 绘图（Plot） 窗格的文档。
