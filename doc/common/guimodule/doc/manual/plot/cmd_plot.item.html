plot item 命令

语法

plot <s > item keyword

创建、销毁或修改与该绘图关联的绘图项。若未指定绘图名 s，则假定为当前视图。

可用关键字为：

create keyword ...

向与该绘图关联的列表添加新绘图项。下面按字母顺序列出与 Build Plot 对话框（Build Plot dialog） 中可用项对应的关键字。注意插件可在任何时候向系统添加更多绘图项。

delete i

销毁与当前绘图关联的列表中的第 i 个绘图项。注意这会重排该位置之后的绘图项编号。

modify i keyword ...

允许修改与当前绘图关联的列表中第 i 个位置的现有绘图项。

警告

下列绘图项可通过多种关键字配置，这些关键字控制项外观的各个方面。此处不记录这些关键字，其语法可通过查看绘图导出为数据文件的结果获得（见 命令驱动绘图工作流（Command-Driven Plotting Workflow））。

表 1：按关键字排序的绘图项（用于 创建绘图项（plot item create））
关键字 Build Plot 对话框（Build Plot dialog） 标签 说明
axes Axes 笛卡尔坐标轴表示，用于辨识视图方位与位置。
chart-history 历史记录图表 历史记录曲线内容图。见 历史（History） 命令。
chart-table 数据表图表 表格曲线图。见 表格（Table） 命令。
data-disk   表示用户定义数据的圆盘。见 data vector 命令。此处需确认：“data vector”命令究竟是什么？？？
data-label 标签 用户定义标签。见 数据（Data） 命令。
data-scalar 标量 用户定义标量数据。见 数据（Data） 命令。
data-tensor 张量 用户定义张量数据。见 数据（Data） 命令。
data-vector 矢量 绘制用户定义向量数据。见 数据（Data） 命令。
fos 安全系数 最后计算的安全系数，仅在图例中显示为一项。见 设置安全系数分析参数（model factor-of-safety） 命令。
fracture 裂隙 由离散裂隙网络系统生成的裂隙。见 DFN 命令（DFN Commands）。
geometry 几何 通过 几何（Geometry） 命令创建或导入的几何数据。
gridpoint-fix 网格点固定状态 方向与颜色表示网格点约束条件及方向的线段。
history-locations 历史位置 历史记录曲线的位置（适用时）。见 历史（History）。
particle-trace 颗粒轨迹 颗粒追踪记录所走过的路径。见 追踪（Trace）。
scalebox Scalebox 用于尺寸参照的背景三维比例框。
structure-beam Beam 结构梁单元。见 beam 命令。
structure-cable Cable 结构锚索单元。见 cable 命令。
structure-geogrid Geogrid 结构土工格栅单元。见 geogrid 命令。
structure-liner Liner 结构衬砌单元。见 衬砌（liner） 命令。
structure-pile Pile 结构桩单元。见 pile 命令。
structure-shell Shell 结构壳单元。见 shell 命令。
structure-vector 矢量 结构节点处各值的向量（如速度、位移等）。
zone Zone 范围内网格单元的表面。
zone-attach 附着条件 把网格点与网格点、边和面相连的接触条件。见 zone attach 命令。
zone-boundary Boundary 模型表面边界，而非全部网格单元面。
zone-face 面 落在范围内的网格单元面。
zone-group 网格单元组面 组名发生变化的边界处网格单元面（透明显示）。
zone-interface Interface 网格单元界面单元与节点。[CS：需确定如何实现：见 :cmd:-zone.interface- 命令。]
zone-isosurface IsoSurface 网格单元场值的等值面。
zone-profile Profile 沿空间某条直线的网格单元场值剖面。
zone-stereonet Stereonet 与网格单元相关的有向值（如最小主应力方向）的施密特网投影。
zone-tensor 张量 网格单元的张量值，如应力、应变率等。
zone-track 被跟踪颗粒 由网格单元流体颗粒追踪记录的路径。见 单元流体追踪（zone fluid track） 命令。
zone-vector 矢量 基于向量的网格单元值，如速度、位移等。
zone-water 水位面 最近指定的、用于在网格点中设置孔隙压力的水位面。
