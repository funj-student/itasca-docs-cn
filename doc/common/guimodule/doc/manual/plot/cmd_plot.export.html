plot export 命令

语法

plot <s > export keyword

主要关键字：

位图（bitmap）    csv    数据文件（datafile）    dxf    PDF 格式（pdf）    PostScript 格式（postscript）    print    SVG 格式（svg）

把名为 s 的绘图内容导出到文件。若未指定绘图名，则假定为当前视图。

该命令可用于生成绘图图像的硬拷贝、以其他文件格式生成绘图版本，或生成可在命令处理器中读取以重建绘图的数据文件。

若未明确指定，所创建的文件都命名为 “flac3d_name”，其中 “name” 为被导出绘图的名称。默认文件扩展名取决于导出文件类型。

以下关键字用于指定导出格式：

bitmap <keyword ...>

把图渲染为位图文件。可用以下关键字控制所创建位图的格式与大小：

dpi i

设置结果文件中的每英寸点数（若适用）。默认值基于当前视频显示。

dpm i

设置结果文件中的每米点数（若适用）。默认值基于当前视频显示。

filename s

设置目标文件名。若未指定则自动赋予一个。扩展名决定格式；若未指定扩展名则默认使用 PNG。支持 PNG、BMP、PPM、XBM 和 XPM 格式。

size 位图宽度（ix ）网格单元 y 向索引（iy ）

指定位图大小（像素）。默认为 1024 x 768。

csv <filename s >

创建 CSV（逗号分隔值）格式的数据文本文件，数据来自所有支持该转换的绘图项（例如图表、表格等）。数据以表格形式组织。该文件可方便地导入 Excel 之类电子表格程序进一步处理。

可用 filename 关键字指定文件输出，默认扩展名为 CSV。

datafile <filename s >

该命令导出数据文件；若用 调用数据文件（program call） 命令读取，应能完全重建该绘图的内容。

可用 filename 关键字指定文件输出，默认扩展名为 F3DAT。

dxf <filename s >

该命令尝试把绘图的几何内容导出为 DXF 文件。注意：DXF 格式不支持生成绘图所用的全部特性，结果可能与屏幕上的绘图有较大差异。

可用 filename 关键字指定文件输出，默认扩展名为 DXF。

pdf <keyword ...>

创建绘图的 PDF 文件。

filename s

设置目标文件名。默认扩展名为 PDF。

landscape

指定使用横向版面。默认为纵向。

margin x 向下限（fx1 ）x 向上限（fx2 ）y 向下限（fy1 ）y 向上限（fy2 ）<inches, millimeters>

指定布局中页面边缘留白量（英寸或毫米）。默认为 0.25, 0.25, 0.25, 0.25 英寸。

paper x 向尺寸（fx ）y 向尺寸（fy ）<inches, millimeters>

指定布局中使用的纸张尺寸（英寸或毫米）。默认为 11.0, 8.5 英寸。

size 位图宽度（ix ）网格单元 y 向索引（iy ）

确定用于渲染三维图像的位图大小。默认使用当前打印图像尺寸设置。见 PLOT 全局设置对话框中的 PRINT SIZE 属性以及 设置打印尺寸命令（plot print-size） 命令。

postscript <keyword ...>

创建绘图的 Postscript 文件。

filename s

设置目标文件名。默认扩展名为 PS。

landscape

指定使用横向版面。默认为纵向。

margin x 向下限（fx1 ）x 向上限（fx2 ）y 向下限（fy1 ）y 向上限（fy2 ）<inches, millimeters>

指定布局中页面边缘留白量（英寸或毫米）。默认为 0.25, 0.25, 0.25, 0.25 英寸。

paper x 向尺寸（fx ）y 向尺寸（fy ）<inches, millimeters>

指定布局中使用的纸张尺寸（英寸或毫米）。默认为 11.0, 8.5 英寸。

size 位图宽度（ix ）网格单元 y 向索引（iy ）

确定用于渲染三维图像的位图大小。默认使用当前打印图像尺寸设置。见 PLOT 全局设置对话框中的 PRINT SIZE 属性以及 设置打印尺寸命令（plot print-size） 命令。

print

把绘图发送到操作系统的打印系统。若处于交互模式，则打开打印对话框。若作为数据文件的一部分运行，则把绘图发送到默认 Windows 打印机。

svg <keyword ...>

生成该图的可缩放矢量图形（SVG）文件。可用以下关键字：

filename s

指定 SVG 文件所用的文件与路径。默认扩展名为 SVG。

size 位图宽度（ix ）网格单元 y 向索引（iy ）

指定图中位图部分的大小（像素）。默认使用当前打印图像尺寸设置。见 PLOT 全局设置对话框中的 PRINT SIZE 属性与 设置打印尺寸命令（plot print-size） 命令。
