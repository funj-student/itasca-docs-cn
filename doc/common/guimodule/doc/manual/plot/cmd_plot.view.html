plot view 命令

语法

plot <s > view keyword ...

主要关键字：

center    后裁剪面距离（clip-back）    前裁剪面距离（clip-front）    倾角（dip）    倾向（dip-direction）    distance    视点位置（eye）    放大倍数（magnification）    投影方式（projection）    翻滚角（roll）

控制绘图的相机视图。若未指定绘图名 s，则假定为当前视图。

可用关键字为：

center v

视图中心。相机始终从视点位置指向视图中心。在模型模式（默认）下，旋转视图时视点绕视图中心旋转。

clip-back f

到后裁剪面的限制距离。默认设为 1e10 因而不构成约束。若默认视图深度设置导致很远的物体降低深度缓冲分辨率，可调整该参数将其前移。

clip-front f

到后裁剪面的限制距离。默认设为 -1e10 因而不构成约束。若默认视图深度设置导致很近的物体降低深度缓冲分辨率，可调整该参数将其后移。

dip f

以度为单位设置视图平面的方位。保持当前视图中心与距离不变，视点绕中心旋转，直至从视点到视图中心的向量垂直于具有该倾角的平面。

dip-direction f

以度为单位设置视图平面的方位。保持当前视图中心与距离不变，视点绕中心旋转，直至从视点到视图中心的向量垂直于具有该倾向的平面。

distance f

设置从视点到视图中心的距离。保持从视点位置到视图中心的当前向量方向不变，但移动视点使两者距离等于该值。

eye v

设置当前视点位置。观察方向始终由视点位置指向视图中心。“向上”方向由当前 roll 确定，该值保持不变。

magnification f

设置当前视图放大倍数。默认值为 1.0，表示视场角 45 度。增大放大倍数会减小视场角。

projection keyword

设置视图是否包含透视畸变，或为正交（平行）投影。可用关键字为：

parallel

把视图设为正交或平行投影。对象不会因距离变远而变小。distance 参数对视图没有直接影响，只会改变交互控制的结果。

perspective

把视图设为基于当前视点位置的透视视图，视场由当前 magnification 确定。这是默认值。

roll f

设置当前滚转角（度）。滚转角定义屏幕顶部的朝向。

相机始终从视点位置朝向视图中心。滚转角定义为指向屏幕顶部的向量与投影到屏幕上的全局 z 方向之间的夹角。若视图完全沿 z 轴方向、因而没有投影，则使用全局 x 方向。
