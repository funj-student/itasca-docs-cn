plot load 命令

语法

plot load keyword

主要关键字：

automatic    占位参数（adummy）

尝试加载一个或多个用户定义绘图项 DLL。若成功，这些绘图项将在 GUI 中可用于绘图。

可用以下选项：

automatic

将自动尝试加载安装目录下 exe64pluginsplotitem3d 目录（及其子目录）中找到的所有兼容 DLL。这些 DLL 必须遵循命名约定 “plotitem3dname005.dll”，其中 “name” 为该绘图项的唯一名称。

s

将尝试加载名为 s 的 plotitem DLL。若不是完全限定路径名，程序将搜索插件目录 exe64pluginsplotitem3d、当前目录和项目目录。

DLL 文件名必须遵循 “plotitem3dname005.dll” 约定。可给出完整文件名，也可只给 “name”，程序会自动扩展为标准约定。
