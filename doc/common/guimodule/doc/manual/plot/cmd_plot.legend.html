plot legend 命令

语法

plot <s > legend keyword ...

主要关键字：

活动（active）    版权信息（copyright）    掘进方向（heading）    放置位置（placement）    position    size    步（step）    模型时间（time-model）    实际时间（time-real）    用户标题（title-customer）    视图倾角（view-dip）    视图信息（view-info）

设置绘图图例的属性。若未指定绘图名 s，则假定为当前视图。

可用关键字为：

active b

打开或关闭图例（开启（on） 与 关闭（off），默认为 开启（on））。

copyright :tok:`text`

用于显示 Itasca 版权与程序限制信息（若有）的字体。注意只能修改颜色。

heading text

用于绘制标题（即 “FLACD 6.0”）的字体。注意只能修改颜色。

placement keyword

图例在图中的位置。可用选项为：

floating

图例以任意位置浮动于绘图之上

left

图例位于图左侧（默认）

right

图例位于绘图右侧

position 位图宽度（ix ）网格单元 y 向索引（iy ）

图例浮动时的位置。取值为 0 到 100，表示显示尺寸的百分比。

size 图例宽度百分比（iw ）变量 ih（ih ）

图例大小，以屏幕宽度的百分比（图例宽度百分比（iw））与高度百分比（变量 ih（ih））表示。若图例位置为 left 或 right，则只使用 图例宽度百分比（iw）。图例宽度百分比（iw） 可在 5 到 50 之间变化；变量 ih（ih） 可在 5 到 100 之间变化。

step text

用于绘制步数的字体

time-model text

用于绘制当前模型中任何活动过程总时间的字体。

time-real text

用于绘制当前日期与时间的字体

title-customer text

用于在图例底部绘制自定义标题的字体（若有空间）

view-dip b

若设为 开启（on），则图例 view-info 部分输出的方位以倾角、倾向、滚转角和距离表示；否则方位由视点位置与滚转角给出。默认为 关闭（off）。

view-info text

用于绘制当前相机视图信息的字体。
