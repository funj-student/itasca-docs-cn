命令驱动的绘图流程

若要把命令驱动绘图纳入建模运行，建议采用以下步骤构建所需命令。

  1. 按需要构建含绘图项与视图调整的绘图。
  2. 导出绘图（Export the plot） 为数据文件。

此时请检查所导出的数据文件，并把其部分或全部内容纳入正在构建的命令序列。若绘图序列需要发生变化（例如作为动画的一部分需要平移模型视图、改变放大倍数、改变颜色等），建议先以交互方式完成所需改动，再导出第二个数据文件。通过比较所导出的数据文件，可以相对容易地识别与所做改动相关的关键字及取值。

上图说明了该过程。第一幅图显示一个典型绘图（该应力合力图来自 嵌入式挡土墙（embedded retaining wall） 示例）。第二幅图显示选中 “Zone Uniform” 项时绘图的 Control Panel 状态。其旁为从该绘图导出的数据文件中包含 创建绘图项（plot item create） 命令的部分，该命令负责创建 “Zone Uniform” 绘图项（必要时可点击图像放大到全分辨率）。命令中的关键字与 Control Panel 中的 “Attribute” 标签高度对应。以这种方式获取绘图的命令开关——如同绘图本身——比试图直接从命令参考信息构建绘图要快得多。

绘图数据文件结构

导出的绘图数据文件遵循统一结构。

  1. 影响整幅图的命令写作（创建绘图（plot create）、清除绘图命令（plot clear） 等）。
  2. 接着出现控制视图的 设置视图命令（plot view） 命令（可能有多条）。
  3. 最后，给出“填充”绘图的 管理绘图项命令（plot item） 命令。

对开关使用缩进有助于辨识绘图的命令结构。查看任何导出的绘图即可看到，控制绘图项外观的开关数量庞大。不过，用户操纵绘图的目标通常只与少数绘图项开关相关。

常用开关选项（颜色、线型等）清单另见 开关/关键字选项（Switch/Keyword Options）。
