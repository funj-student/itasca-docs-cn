type

语法

i := type(a)

获取类型。类型名称（type.name） 是另一种方式，返回表示类型的字符串（即 integer、double、string、Boolean 等）。此处返回的整数取下列值之一。

1: integer

2: float

3: string

4: pointer

5: array

6: 2D vector

7: 3D vector

8: index

9: Boolean

11: Matrix

12: Tensor

13: Structure

14: Map

15: List

16: Memory

返回值：i - 整数类型
