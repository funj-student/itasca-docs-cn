vector

语法

v := vector(n1<,n2><,n3>)

创建向量类型。

类型的创建与初始化方式取决于所给参数的数目与类型：
  • 若给出数值（整数或浮点数），则其后必须再跟一个或两个数值参数，以创建二维或三维向量类型。
  • 列表长度必须为 2 或 3，且每个元素必须为 float 类型，才能转换为向量。
  • 字符串必须采用 “(x,y)” 或 “(x,y,z)” 格式（含圆括号与逗号）才能转换为向量。
  • 矩阵必须只有一行或一列，且另一维大小为 2 或 3，才能转换为向量。
  • 数组必须为一维且长度为 2 或 3，才能转换为向量。
返回值：

v - 向量
参数：

n1 - 数值、数组、矩阵列表或字符串

n2 - 二维/三维向量的可选数值

n3 - 三维向量的可选数值
