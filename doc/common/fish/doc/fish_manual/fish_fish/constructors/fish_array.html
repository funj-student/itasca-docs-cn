array

语法

a := array(i<,i>...)

创建并返回新的数组类型。

数组的大小与内容取决于参数的类型和数量。
  • 若给出一个或多个整数，则数组的维数由整数个数给出，各维大小由相应整数值给出。数组初值均为 0。
  • 若给出列表，且其后无其他参数，则数组为一维，长度与列表相同，元素一一对应。若其后跟整数参数，则数组维数等于整数个数，各维大小由相应整数指定。此时数组总大小必须等于或小于第一个参数中列表的大小。数组内容由列表内容填充。
  • 若给出向量，则数组为长度 2 或 3 的一维数组，其浮点值与向量各分量一致。
  • 若给出矩阵，则数组为二维，大小与矩阵一致，所有元素均为 double 类型，取值与矩阵元素一致。
  • 若给出张量，则数组创建为长度 6 的一维数组，包含该张量的各分量。
返回值：a - 新建的数组类型。
参数：i - 可用于创建数组的六种类型之一。i2 - 可选的更多整数，用于指定数组的维数和大小。
