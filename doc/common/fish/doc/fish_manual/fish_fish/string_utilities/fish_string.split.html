string.split

语法

l := string.split(source<,sep>)

把字符串按 分隔符（sep） 的内容拆分为子字符串，并以列表返回这些字符串。

默认情况下，分隔符（sep） 与命令处理器相同的字符匹配。这包括圆括号、等号、空格、制表符和逗号。

返回值：l - 子字符串列表。
参数：source - 要拆分为标记的原字符串 分隔符（sep） - 用作分隔符的字符串，默认使用正则表达式 [ \s \t(),=]。
