string.build

语法

结果字符串（sr） := string.build(s<,a1><,a2>...)

用标记替换构造字符串。以字符串 s 为基础。标记 %1、%2、%3 等用于指示后续参数 a1、a2 等将放置的位置。后续参数在必要时会被自动转换为字符串。若无法转换，则产生错误。

返回值：结果字符串（sr） - 拼接后的字符串
参数：s - 要拼接的字符串

用法示例

下例说明 构建字符串（string.build） 的用法，结果将是字符串 v1 = 12, v2 = 3.456。

local v1 = 12
local v2 = 3.456
local a = string.build("v1 = %1,  v2 = %2.",v1,v2)
io.out(a)
