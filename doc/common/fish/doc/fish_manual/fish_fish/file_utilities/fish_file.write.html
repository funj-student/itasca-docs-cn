file.write

语法

b = file.write(a<,l>)
file.write(<f>) = l

把列表写入文件。

若未提供文件指针，则写入最后打开的文件。

若在取值时调用，则必须以参数提供列表（位于可选文件指针之后）。该列表的所有条目被写入文件，并返回 表示固定的真值（btrue）。

若在赋值时调用，则假定赋值内容为要写入文件的列表。

返回值：b - 真值（true）（布尔值取真）
接受：l - 要写入文件的列表
参数：a - 可选的文件指针，指明要写入的文件。l - 仅在取值调用时给出的列表参数，用于写入文件。
