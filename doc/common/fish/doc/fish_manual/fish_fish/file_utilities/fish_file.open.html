file.open

语法

f = file.open(sname<,smode><,stype>)

打开文件以读取/写入。

打开模式（smode） 表示打开模式。它是一个字符串，必须（作为命令关键字）匹配以下取值之一：
  • read：以只读方式打开。这是默认值。
  • write： 以只写方式打开。
  • append：以写入方式打开，但保留文件当前内容并从末尾开始写入。
  • both： 以读写方式打开。
  • 读写（rw）： 以读写方式打开。
  • 读写模式（readwrite）： 以读写方式打开。
stype 为文件类型。默认文件类型为 保存（save）。当前可用的文件类型为：
  • 保存（save）：默认值。与保存文件和结果文件所用格式相同。
  • text：文本文件，文件中每一行读作一个字符串。写入时把列表中每一项转换为字符串（若需要）并写为一行。
  • JSON 格式（json）： 采用 JSON 格式组织的文本文件。
  • FISH函数（fish）：采用 FISH 专用传统格式的文件。与旧版本兼容，并已扩展以支持部分较新的类型。
  • binary：二进制格式文件。列表中的每一项被当作 0 到 255 的整数，在文件中作为一个独立字节读写。

保存（save） 与 JSON 格式（json） 格式允许除指针外的所有 FISH 类型，并保留层次化数据结构（列表的列表、映射等）。text 类型在写入时把所有条目转换为文本字符串，如同使用了 字符串（string） 内建函数。FISH函数（fish） 类型限于 bool、integer、float、string、vector 和 tensor 类型。

返回值：f - 已打开文件的指针。
参数：字符串名称（sname） - 文件名 打开模式（smode） - 文件打开模式，默认为 read。stype - 文件类型，默认为 保存（save）。
