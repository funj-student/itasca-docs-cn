memory

语法

a := memory(m)
memory(m) := a

获取/设置内存类型中的某个值。第一个值只需提供 m 即可设置。后续值通过偏移 m 获取/设置（即把 m + 2 作为参数将获取或设置第三个 FISH 变量）。

返回值：a - 内存中的值
接受：a - 要赋给内存的值
参数：m - 指向内存类型的内存指针。
