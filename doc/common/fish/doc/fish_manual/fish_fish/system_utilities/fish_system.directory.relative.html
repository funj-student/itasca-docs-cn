system.directory.relative

语法

相对路径（srel） := system.directory.relative(sdir<,sdirbase>)

返回路径/目录 目录（sdir） 相对目录 基准目录（sdirbase） 的形式。若未提供 基准目录（sdirbase），则使用当前目录。

返回值：相对路径（srel） - 目录 目录（sdir） 相对目录 基准目录（sdirbase） 的形式
参数：目录（sdir） - 原目录条目。基准目录（sdirbase） - 用于换算 目录（sdir） 的参考目录。
