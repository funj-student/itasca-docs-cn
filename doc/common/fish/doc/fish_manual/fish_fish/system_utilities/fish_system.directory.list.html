system.directory.list

语法

l := system.directory.list(<sdir><,brecurse><,bdir>)

返回某目录中所有文件条目的列表。

目录（sdir） 为目录名称；若未提供则使用当前目录。

递归标志（brecurse） 表示列表是否应递归进入子目录。默认值为 假值（false）。

目录标志（bdir） 表示列表中给出的是文件名还是目录名。其值为 假值（false），表示应返回文件名并跳过目录名。

返回值：l - 给定目录中的名称列表。
参数：目录（sdir） - 要扫描的目录，默认为当前目录。递归标志（brecurse） - 若为 真值（true），则扫描应递归进入子目录。默认值为 假值（false）。目录标志（bdir） - 若为 真值（true），则列表应返回子目录名而非文件名。默认值为 假值（false）。
