domain.strain.rate

语法

向量访问

v = domain.strain.rate(<i>)
domain.strain.rate(<i>) = v

获取/设置域应变率。

返回值：v - 域应变率向量或分量
接受：v - 域应变率向量或分量
参数：i - 可选的向量分量

分量访问

f = domain.strain.rate.x()
domain.strain.rate.x() = f

获取/设置域应变率的 \(x\) 分量。

返回值：f - 域应变率向量的 \(x\) 分量
接受：f - 域应变率向量的 \(x\) 分量
f = domain.strain.rate.y()
domain.strain.rate.y() = f

获取/设置域应变率的 \(y\) 分量。

返回值：f - 域应变率向量的 \(y\) 分量
接受：f - 域应变率向量的 \(y\) 分量
f = domain.strain.rate.z() (3D only)
domain.strain.rate.z() = f (3D only)

获取/设置域应变率的 \(z\) 分量。

返回值：f - 域应变率向量的 \(z\) 分量
接受：f - 域应变率向量的 \(z\) 分量

另见：设置域应变率命令（domain strain-rate）
