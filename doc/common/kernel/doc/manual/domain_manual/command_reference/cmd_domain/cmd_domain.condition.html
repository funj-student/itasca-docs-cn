domain.condition 命令

语法

domain condition x 向条件（sx ）<sy sz > (z 向条件（sz ）is 3D only)

设置域边界条件。

注意

域主要与 PFC 相关。在 FLAC3D 模型中，只有 离散裂隙网络（DFN）（discrete fracture networks (DFNs)） 会受域影响。

每个域条件作用于与该方向垂直的两个盒侧（例如 x 向条件（sx） 作用于与 x 方向垂直的两个侧）。若只指定 x 向条件（sx），则该条件作用于所有边界；否则必须指定{二维按 x,y 顺序的两个字符串；三维按 x,y,z 顺序的三个字符串}。默认 condition 为 stop 条件。

可接受的边界条件为 stop、reflect、destroy 和 periodic。

stop 条件施加如下约束：当物体形心落到模型域之外时，该物体的速度与自转置零。对于墙，一旦某个面片形心落到模型域之外，其速度与自转即置零，包括所有顶点速度。

reflect 条件在物体形心落到模型域之外时赋予相反符号的速度，自转保持不变。不建议把该条件用作接触规则，因为它可能引起不稳定。reflect 条件与穿过模型域的墙不兼容。

destroy 条件删除其各自范围（即紧密包围该对象的轴对齐包围盒）落到模型域之外的球、刚性团簇和墙面片。

periodic 条件施加周期性边界条件。当球或刚性团簇形心落到模型域之外时，将其平移回模型的相对一侧。为使接触按模型连续的方式创建，引入了“鬼”球与鬼刚性团簇。periodic 条件与穿过模型域的墙不兼容。
