data scalar create 命令

语法

data scalar create v <keyword ...>

主要关键字：

extra    分组（group）    value

创建标量数据项。标量是内部维护的用户定义对象列表，这些对象关联着位置 v 与取值 f（通过 value 关键字赋值）。标量在创建时还可被赋予组与额外变量。

标量场可通过用户界面可视化。标量可用于跟踪模型中的事件，或把模型结果与外部数据比较。

extra i a

可选地把额外变量 a 赋给索引 i。

group s <slot s2 >

可选地把组名 s 赋给槽位 s2。默认 s2 = 默认（Default）。组逻辑的用法见 组（Groups） 主题。

value f

把与标量关联的值赋为 f。
