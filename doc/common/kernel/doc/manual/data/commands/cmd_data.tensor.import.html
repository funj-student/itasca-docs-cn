data tensor import 命令

语法

data tensor import s <group s <slot s >>

从文件 s 导入张量。若未给出扩展名，则添加 张量（tensor）。文件格式（文本或二进制）通过打开文件并查找相应文件头确定。若未找到正确的文件头，则提示错误且不导入任何数据。

若指定 group 关键字，则导入的张量被赋予所指定的组名。该组赋值优先于导入文件中的赋值。相关文件格式详见 张量文本文件格式（Tensor Text File Format） 与 张量二进制文件格式（Tensor Binary File Format）。
