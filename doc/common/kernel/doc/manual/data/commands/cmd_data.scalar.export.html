data scalar export 命令

语法

data scalar export s <binary> <range>

把标量导出到名为 s 的文件。若未指定扩展名，则自动添加 标量（scalar）。除非指定 binary 关键字，否则创建 ASCII 文本文件。任何已有文件都会被删除。相关文件格式详见 标量文本文件格式（Scalar Text File Format） 与 标量二进制文件格式（Scalar Binary File Format）。
