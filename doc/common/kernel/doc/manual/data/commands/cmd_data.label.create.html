data label create 命令

语法

data label create keyword ...

在空间某点创建用户定义标签。这些标签可用绘图逻辑可视化，标识关注区域。

默认情况下，标签是位于原点的空字符串，没有箭头或线段。可用以下关键字为所创建的标签赋值。

arrow b

指定连接 v1 与 v2 的线段是否以箭头结尾。仅在已指定 end 时适用。

end v2

若指定 end 与 v1 不同，则标签将包含一条从 v1 指向 v2 的线段。

name s

为标签赋予唯一名称以便后续引用。若未指定，则基于内部赋予的 ID 号生成名称。

position v1

指定标签的原点位置。

text s

把标签文本设为 s。该文本将在 v1 所定义的位置输出到屏幕。
