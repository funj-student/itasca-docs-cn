命令

创建、修改和删除用于存储用户定义数据的数据类型，这些数据对模型没有直接影响。可用的数据类型为 scalar、vector、tensor 和 label。这些类型可用于可视化、跟踪以及与来自其他来源的数据比较。

数据命令

创建数据标签命令（data label create）
删除数据标签命令（data label delete）
列出数据标签命令（data label list）
修改数据标签命令（data label modify）
设置数据标签结果输出命令（data label results）

删除标量数据命令（data scalar delete）
导出标量数据命令（data scalar export）

导入标量数据命令（data scalar import）
列出标量数据命令（data scalar list）
设置标量数据结果输出命令（data scalar results）

删除张量数据命令（data tensor delete）

设置张量数据结果输出命令（data tensor results）
