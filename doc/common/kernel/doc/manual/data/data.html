Data

用户定义的标签、标量、向量和张量数据可输入，并用于与模型结果比较。也可用于存储由模型计算得到的数据以供可视化。

标签是用户定义数据的内部列表，各数据关联一个位置、一个字符串以及可选的结束位置。

标量是用户定义数据的内部列表，各数据关联一个位置和一个取值。

张量是用户定义数据的内部列表，各数据关联一个位置和一个对称张量。

向量是用户定义数据的内部列表，各数据关联一个位置、一个方向和一个大小。

标量、张量和向量可赋予组和 FISH 额外值。

此外，这些数据类型都可通过 import 关键字从文件创建。文件数据可为文本或二进制格式，但每种数据类型都有其专属文件格式（如下定义）。创建用户数据后，可通过 FISH 查询或变换，并可在当前模型的绘图中可视化。

用户定义的数据文件格式

  • 标量文本格式（Scalar text format）
  • 标量二进制格式（Scalar binary format）
  • 张量文本格式（Tensor text format）
  • 张量二进制格式（Tensor binary format）
  • 向量文本格式（Vector text format）
  • 向量二进制格式（Vector binary format）
  • 命令（Commands）
  • FISH 函数（FISH Functions）
