命令

对颗粒迹线进行操作。

每条迹线在模型推进过程中记录并存储颗粒的位置与速度。其间隔由 设置追踪采样间隔命令（trace interval） 命令控制。迹线通过在特定数据类型上使用 trace 关键字创建（例如 zone trace 或 ball trace）。

模型打开期间迹数据存储在临时文件中，保存模型时该数据被转入存档文件。

迹命令

删除追踪命令（trace delete）
导出追踪命令（trace export）
设置追踪采样间隔命令（trace interval）
列出追踪命令（trace list）
设置追踪标签（trace name label）
清除追踪命令（trace purge）
设置追踪结果输出命令（trace results）
