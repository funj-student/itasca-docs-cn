Trace

迹是模型运行期间用于跟踪某些对象位置与速度的粒子。迹在空间中经过的路径可被绘制。每条 trace 命令只能跟踪一个对象。迹可在任何时候添加。可用 清除追踪命令（trace purge） 关键字清除所有迹的内容，并用 删除追踪命令（trace delete） 删除所有迹。使用 列出追踪命令（trace list） 可获取所有迹的摘要。迹的采样率由 设置追踪采样间隔命令（trace interval） 命令控制；所有迹都使用该采样率。
