model configure 命令

语法

model configure keyword ...

配置额外的计算模式。该命令允许用户指明模型使用了需要额外资源或受许可证信息限制的计算模式。model.configure 命令可在分析的任何阶段给出，但必须在调用相应计算模式（求解模型（model solve） 或 执行计算时步（model cycle））之前给出。

适用以下关键字。

cfd

PFC CFD 分析

creep

蠕变材料分析*

dynamic

完全动力分析*

energy

3DEC 中的能量跟踪

feblock

3DEC 中的有限元块体

fluid

流体流动分析

imass

Itasca 高级应变软化模型*

matrixflow

3DEC 中的基质流动

plugins

C++ 用户定义模型和/或 FISH 内建插件。* 无需该配置即可加载 FISH 插件（但循环被禁用）。

thermal

热学分析


注意

*只有在程序许可中包含相应程序选项时，这些分析模式才可用。
