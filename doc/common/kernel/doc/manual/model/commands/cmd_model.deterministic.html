model deterministic 命令

语法

model deterministic <default> b

设置确定性模式。每次给出 新建模型（model new） 命令时，确定性模式都会重置为默认设置。可选 default 关键字用于把默认设置设为 b。未使用 default 时只设置当前确定性模式。安装时（即任何用户改动之前）程序的默认确定性设置为 开启（on）。默认设置也可通过 选项对话框（Options Dialog） 中的 “Determinism by default” 复选框更改。

当在多个 CPU 或核心上并行执行计算时，特定计算发生的顺序会改变。这会导致舍入误差以不同方式累积。对许多模型而言，这些差异的最终结果几乎无法察觉。但对一大类模型，这些差异可能被放大，导致每次运行给定模型都得到不同的结果。

需要强调的是，所有这些结果同样有效，因为都处于有限精度浮点误差范围内。确定性模式牺牲效率与内存，以强制并行计算每次都得到相同答案，无论所用 CPU 数量或其相对速度如何。

把确定性设为 关闭（off） 的影响如下。

  • 模型会运行得更快，快多少取决于程序和模型。FLAC3D 始终是确定性的；用该命令把确定性设为 off 会被忽略。3DEC 约快 10%。PFC 约快 15%。
  • 结果将不可重复。在某些小变化会传播的情形中，每次运行同一模型都会得到差别很大的结果。
  • 数据文件（及项目包）将不再能可靠地重现结果。为存档目的，用户应把所得保存文件与输入数据一并保存。
  • 对于需要技术支持的问题，Itasca 可能无法复现该问题。此时应在确定性设为 开启（on） 的情况下重新运行模型。若问题不再出现，则可能几乎无法做进一步处理。
