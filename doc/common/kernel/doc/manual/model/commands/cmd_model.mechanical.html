model mechanical 命令

语法

model mechanical <b > keyword

主要关键字：

活动（active）    dynamic    list    time-total    从块列表（slave）    子时步（substep）    timestep

设置力学分析的参数。可通过给出 b 直接指定是否活动。

active b

力学过程默认为 开启（on）。指定 active 关闭（off） 可抑制力学计算。

dynamic b

指定 3DEC 中动力模型的状态。

list

显示力学计算模式信息。

time-total f

f 为模型的累积力学时间。可重置为任意值，之后将在循环中继续累积。

slave b

指定把力学模式视为从属过程，并在每个主步之后循环至平衡。

substep i

指定用 slave 开启（on） 求解时力学过程所走的最大步数。

timestep
automatic

稳定时步根据系统中所有对象的当前刚度与质量计算。这是默认设置。在静态力学 FLAC3D 分析中时步是任意的，默认设为 1.0。

fix f

把时步设为固定值 f。所有时步计算都被跳过，从而提高性能。在 FLAC3D 静态力学分析中，时步可设为任意值，惯性质量会被缩放以保证稳定性。质量缩放的讨论见 ref-Mechanical Timestep Determination for Numerical Stability <mechtimestepdetermination>- 一节。CS：通用文档有问题

increment f

设置 automatic 模式下时步允许从一次循环到下一次循环增加的最大增量。默认 f = 1.05。为保证稳定性，时步可任意减小。

maximum f

设置允许的最大时步。默认情况下时步最大值没有限制。

safety-factor f

设置时步安全系数，即与 auto 模式计算出的稳定时步相乘的系数。FLAC3D 中默认 f = 1.0。若加载了 PFC 模块，则默认值为 f = 0.8。该值不用于静态力学 FLAC3D 分析。

scale f

在 PFC 中启用时步缩放。时步缩放用于尽快达到静态构型，而不论所经历的应力路径。各物体的惯性质量依据刚度缩放，使稳定时步为 f（若未指定 f 则为 1.0）。此外，速度按旧惯性质量与新惯性质量之比缩放。这样所有自由度具有相同的时间响应，从而加快收敛，但时间尺度失去物理意义。该值不用于 FLAC3D 力学时步计算。

update i

设置 PFC 或 3DEC 中时步计算之间的循环数。PFC 中默认 i = 1（即时步每个循环都更新）。3DEC 的默认值为 i=100。该值不用于 FLAC3D 力学时步计算。
