model creep 命令

语法

model creep <b > keyword

主要关键字：

活动（active）    time-total    list    从块列表（slave）    子时步（substep）    timestep

设置蠕变材料分析的参数。可通过给出 b 直接指定是否活动。仅当已指定 配置蠕变计算模式（model configure creep） 时才能进行与时间相关的蠕变材料分析。该功能仅在蠕变模型选项下可用——详见 蠕变模型选项 此处应为链接。[CS：这又是一个通用文档、多程序的问题]

active b

给出 配置蠕变计算模式（model configure creep） 命令时，蠕变过程默认为 开启（on）。指定 active 关闭（off） 可抑制蠕变计算。

time-total f

f 为模型的累积蠕变时间。可重置为任意值，之后将在循环中继续累积。

list

显示蠕变计算模式信息。

slave b

指定把蠕变模式视为从属过程，并在每个主步之后循环至平衡。该选项为完整性而提供，但在蠕变计算中很少有用。

substep i

指定用 slave 开启（on） 求解时蠕变过程所走的最大步数。

timestep

蠕变计算的时步控制。注意大多数蠕变模型没有稳定时步的解析解，因此自动模式下的时步由与不平衡力比挂钩的伺服控制。[CS：目前在 PFC 上暂时移除；通用文档问题] 见蠕变一节中的 ref-automaticadjustmentofthecreeptimestep- 主题。 可用以下关键字。

automatic b

若为 开启（on），则按下面设置的时步伺服确定稳定时步。若为 关闭（off），则必须用 fix 关键字手动设置时步。

fix f

把时步设为固定值 f。所有时步计算都被跳过。

警告

若 f 超过稳定时步限值，使用 fix 关键字可能导致模型不稳定。使用时需极为谨慎。

increment f

设置 automatic 模式下时步允许从一次循环到下一次循环增加的最大增量。默认 f = 1.05。为保证稳定性，时步可任意减小。

latency i

设置伺服控制时步时，改变时步前必须经过的最小步数。使用该关键字会隐含设置 servo 开启（on）。默认 :latency: 为 1。

lower-bound f

若当前收敛比低于 f，则把 lower-multiplier 施加到时步上以增大时步。使用该关键字会隐含设置 servo 开启（on）。默认 :lower-bound: 为 1e-3。

lower-multiplier f

当收敛比低于 lower-bound 时施加到当前时步的取值。该值应大于 1.0。默认情况下 lower-multiplier 为 1.01。

maximum f

允许的最大时步。伺服不会把时步提高到该值以上。时步最大值没有默认限制。

minimum f

允许的最小时步。伺服不会把时步降低到该值以下。时步最小值没有默认限制。

servo b

启用或停用时步伺服控制。若时步已设为 automatic 开启（on） 且 servo 关闭（off），则继续使用最后计算得到的伺服值。

starting f

指定时步处于伺服控制下时，蠕变计算开始阶段所用的时步。此后伺服会在每一步调整时步。开始蠕变计算前必须给出起始时步。

unbalanced b

表示时步伺服改用最大不平衡力而非收敛比。lower-bound 与 upper-bound 现在与最大不平衡力比较。注意 lower-bound 与 upper-bound 的默认值在此情形下很可能不再有效。

upper-bound f

若当前收敛比高于 f，则把 upper-multiplier 施加到时步上以增大时步。使用该关键字会隐含设置 servo 开启（on）。默认 :upper-bound: 为 5e-3。

upper-multiplier f

当收敛比高于 upper-bound 时施加到当前时步的取值。该值应小于 1.0。默认情况下 lower-multiplier 为 0.9。
