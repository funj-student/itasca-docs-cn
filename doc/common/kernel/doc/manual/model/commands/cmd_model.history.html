model history 命令

语法

model history <name s > keyword

主要关键字：

creep    damping    dynamic    energy    fluid    力学（mechanical）    thermal    timestep

创建模型量的历史记录。这些量大多与某个过程相关。

name 关键字可用于为该历史记录赋予唯一标识以便后续引用。若未指定 name，则将基于内部赋予的 ID 号自动生成名称。

适用以下关键字：

creep keyword

与蠕变过程相关的取值。

cycles-total

该过程处于活动状态期间累积的循环总数。

time-total

该过程处于活动状态时的总累积时间。

damping

全局阻尼参数取值（3DEC）

dynamic keyword

与动力过程相关的取值。

cycles-total

该过程处于活动状态期间累积的循环总数。

time-total

该过程处于活动状态时的总累积时间。

energy keyword

3DEC 中与能量量相关的取值。

block-kinetic

3DEC 中的动能值。

block-potential

3DEC 中的势能值。

block-strain

3DEC 中的块体应变。

block-strain-excavated

3DEC 中的已开挖块体应变。

block-strain-fill

3DEC 中的充填应变值。

block-strain-plastic

3DEC 中的塑性应变值。

block-volume-excavated

3DEC 中的已开挖块体体积。

boundary-load

3DEC 中的边界荷载。

boundary-viscous

3DEC 中的边界黏性力。

damp-mass

3DEC 中的质量阻尼值。

joint-friction

3DEC 中的节理摩擦值。

joint-strain

3DEC 中的节理应变值。

joint-strain-compressive

3DEC 中的节理压缩应变值。

joint-strain-excavated

3DEC 中的节理应变开挖值。

joint-strain-shear

3DEC 中的节理应变的剪切值。

joint-strain-tensile

3DEC 中的节理应变拉伸值。

strain-excavated

3DEC 中的已开挖应变值。

strain-total

3DEC 中的总应变值（节理 + 网格单元）。

total-released

3DEC 中的总释放能量值。

total-stored

3DEC 中的储存能量值。

fluid keyword

与流体过程相关的取值。

cycles-total

该过程处于活动状态期间累积的循环总数。

time-total

该过程处于活动状态时的总累积时间。

mechanical keyword

与力学过程相关的取值。

convergence

当前的力学收敛值（见 模型力学收敛求解（model solve mechanical convergence））。

cycle

力学循环总数。（已弃用；请使用 cycles-total。）

cycles

该过程在本次 求解模型（model solve） 命令中所走的循环数。

cycles-total

该过程处于活动状态期间累积的循环总数。

energy keyword

PFC 中某能量分量的取值。

energy-adhesive

接触中储存的黏附能。

energy-body

基于物体的功-能。

energy-boundary

基于墙的功-能。

energy-damp

物体局部阻尼能。

energy-dashpot

接触中存储的黏性阻尼器能。

energy-kinetic

物体的动能。

energy-pbstrain

接触中存储的平行黏结应变能。

energy-rrslip

接触中存储的滚动阻力滑移能。

energy-rrstrain

接触中存储的滚动阻力应变能。

energy-slip

接触中存储的滑移能。

energy-strain

接触中存储的应变能。

ratio

当前所用比值的取值。比值的定义见 ref-equilibrium-。此项及后三项需在临近发布时与 DR 核对！！！！

ratio-average

平均力比的取值。比值的定义见 ref-equilibrium-。

ratio-local

局部力比的取值。比值的定义见 ref-equilibrium-。

ratio-maximum

最大力比的取值。比值的定义见 ref-equilibrium-。

time

该过程在本次 求解模型（model solve） 命令中累积的时间。

time-total

该过程处于活动状态时的总累积时间。

unbalanced-average

所有对象上的平均不平衡力。

unbalanced-maximum

任意对象中的最大不平衡力。

thermal

与热学过程相关的取值。

cycles-total

该过程处于活动状态期间累积的循环总数。

time-total

该过程处于活动状态时的总累积时间。

timestep

活动时步。
