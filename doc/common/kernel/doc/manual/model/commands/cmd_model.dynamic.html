model dynamic 命令

语法

model dynamic keyword

主要关键字：

活动（active）    list    time-total    从块列表（slave）    子时步（substep）    timestep

设置动力材料分析的参数。仅当已指定 模型配置动力分析命令（model configure dynamic） 且存在动力选项时该命令才可用。更多信息见 dynamicREF 主题 [CS：此处需要通用求解说明]。

active b

给出 模型配置动力分析命令（model configure dynamic） 命令时，动力过程默认为 开启（on）。指定 active 关闭（off） 可抑制动力计算。

list

显示动力计算模式信息。

time-total f

f 为模型的累积动力时间。可重置为任意值，之后将在循环中继续累积。

slave b

指定把动力模式视为从属过程，并在每个主步之后循环至平衡。该选项为完整性而提供，但在动力计算中很少有用。

substep i

指定用 slave 开启（on） 求解时动力过程所走的最大步数。

timestep
automatic

稳定时步根据系统中所有对象的当前刚度与质量计算。这是默认设置。

fix f

把时步设为固定值 f。所有时步计算都被跳过。设置大于计算临界时步的值将导致错误。

increment f

设置 auto 模式下时步允许从一次循环到下一次循环增加的最大增量。默认 f = 1.05。为保证稳定性，时步可任意减小。

maximum f

设置允许的最大时步。默认情况下时步最大值没有限制。

safety-factor f

设置时步安全系数，即与 automatic 模式计算出的稳定时步相乘的系数。默认 f = 1.0。
