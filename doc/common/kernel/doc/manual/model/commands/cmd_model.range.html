model range 命令

语法

model range keyword

主要关键字：

创建（create）    delete

创建/删除命名范围。创建命名范围即“预定义”一个范围，此后可在命令的 范围短语（range phrase） 中用 命名范围（named-range） 关键字高效地引用它（例如 [command] range named-range s）。若底层范围定义很冗长，这尤其有用。

create s [range element ...]

若尚不存在名为 s 的命名范围则创建它。其后必须跟一个或多个 范围元素（range elements），即上文所示的 [range element] ...（实际上就是一个开头不含 range 一词的 范围短语（range phrase））。

delete s

删除名为 s 的范围。

另见 命名范围（Named Ranges） 的讨论，其中比较和对比了命名范围与组。

用法示例

下例说明 设置命名范围命令（model range） 的用法。该例还用到逻辑运算——见 范围短语中的逻辑运算（Logical Operations in a Range Phrase） 主题。

;创建命名范围 1
model range create 'walls' group 'West' or 'East' or 'North' or 'South'
;使用命名范围 1
zone face apply velocity-normal 0 range named-range 'walls'

;创建命名范围 2 和 3
model range create 'sw corner' position-x 0 1 ...
                               position-y 0 1 ...
                               position-z 0 10
model range create 'nw corner' position (9,0,0)(10,1,10)
;使用命名范围 2 和 3
zone cmodel assign mohr-coulomb range union named-range 'sw corner' ...
                                            named-range 'nw corner'
zone cmodel assign elastic range named-range 'sw corner' not ...
                                 named-range 'nw corner' not
