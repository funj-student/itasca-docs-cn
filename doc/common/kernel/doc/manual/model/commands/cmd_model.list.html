model list 命令

语法

model list keyword

主要关键字：

域（domain）    information    范围（range）    记录（record）    requirements

列出与模型相关的量。适用以下关键字：

domain

列出域范围与条件。

information

列出当前模型状态的一般信息。

range <s>

此处需修正；此处把 RAnge 用作关键字似乎妨碍了按需正确使用 :str:s 列出作为该模型一部分创建的所有命名范围。若给出 s，则列出匹配命名范围的内容。

record <keyword>

列出当前模型记录的信息。该记录为对模型的全部命令与输入。见 i 状态记录（State Record） 窗格的说明。

commands

列出交互式给出的所有命令，包括由交互工具发出的命令。注意作为数据文件一部分输入的命令不会被记录，数据文件改在 Files 部分跟踪。

该列表可发送给 回放记录文件（program playback） 命令。创建项目包时（见用户界面中的 Tools Bundle Pack… 菜单项），会为项目中的每个模型存档状态创建一个 .record 文件。理论上可用其重建该模型状态。

files

可能影响模型状态的所有输入文件的列表，包括数据文件。记录文件名称、大小以及最后修改的时间与日期。

information

单行显示记录中存储的命令行数与文件条目数。未指定关键字时这是默认选项。

requirements

当前模型状态的安全要求的完整列表。注意若不存在模型，或现有模型小于演示版限值，此处需要是某处描述演示版的节的链接 则可能不列出任何内容。
