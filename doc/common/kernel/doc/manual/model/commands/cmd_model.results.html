model results 命令

语法

model results keyword

主要关键字：

clear-map    导出（export）    导入（import）    index    间隔（interval）    list    映射（map）    prefix    覆盖警告（warn）

对结果文件执行文件操作。结果文件是保存文件的轻量版本。导入结果文件将完全覆盖模型状态（与 恢复模型（model restore） 相同），但只包含完整模型中预先确定的一小部分。一般而言，结果文件约为完整保存文件大小的 5%，取决于所含信息量。从结果文件导入的状态不能再继续循环。

用户通过许多模型对象都提供的 results 关键字控制结果文件中包含哪些信息。例如在 FLAC3D 中见 设置网格单元结果输出（zone results） 命令。

可随时用 导出模型结果（model results export） 命令显式导出结果文件。也可用 模型结果间隔（model results interval） 命令在循环期间按固定间隔自动导出。

结果文件常用于按固定间隔导出模型状态——既便于后续生成动画，也便于在求解过程中检查模型进度。可用 i 工具（Tools） 菜单中的 Generate Movie Frames… 向导创建动画文件。选项对话框（Options Dialog） 的 “Results” 部分也可用于指定输出间隔并控制导出哪些取值。

结果文件设置属于模型状态，随模型保存和恢复。给出 新建模型（model new） 命令后这些设置被重置。

循环期间自动生成的结果文件按 prefix 与 index 取值顺序命名。若未指定 prefix，则默认为 flac3d；index 默认为 1。所用格式为 结果文件名模板（prefixXXXX.result），其中 四位数字序号（XXXX） 为按需补前导零的四位数字 index 值。每个文件导出后 index 会自动递增。

clear-map

清除当前的表格结果列表。

export s <text>

把结果文件导出到文件 s。FLAC3D 中默认扩展名为 FLAC3D 结果文件扩展名（f3result），{PFC2D 结果文件扩展名（p2result）（PFC2D 中）；PFC3D 结果文件扩展名（p3result）（PFC3D 中）}。默认以二进制格式导出结果。text 关键字选项指定以文本格式导出。

import s | i <skip-fish>

导入结果文件 s 或索引为 i 的结果文件的内容。若给出整数，则依据所指定的 prefix 生成候选文件名。假定默认扩展名在 FLAC3D 中为 FLAC3D 结果文件扩展名（f3result），{PFC2D 结果文件扩展名（p2result）（PFC2D 中）；PFC3D 结果文件扩展名（p3result）（PFC3D 中）}。默认会重置 FISH 状态并导入随结果文件保存的任何 FISH 变量。skip-fish 关键字表示保持当前 FISH 状态不变，不导入结果文件中存储的任何 FISH 变量。

index i

指定下一个待导出结果文件名称所用的数字索引。

interval keyword

控制循环期间导出结果文件的间隔（若导出）。默认设置为 模型结果间隔启用（model results interval active） 关闭（off）。

active b

开启（开启（on））或关闭（关闭（off））结果文件的自动导出。默认设置为 关闭（off）。一般而言，设置导出间隔会自动把导出设为 开启（on）。

clock f keyword

启用按实时间隔导出结果文件。f 指定导出之间的时间量。可用以下关键字定义 f 所用的时间单位。

hours

f 为结果文件导出间隔，单位为小时。

minutes

f 为结果文件导出间隔，单位为分钟。

seconds

f 为结果文件导出间隔，单位为秒。

creep f

每累积 f 单位蠕变时间导出一个结果文件。

dynamic f

每累积 f 单位动力时间导出一个结果文件。

fluid f

每累积 f 单位流体时间导出一个结果文件。

mechanical f

每累积 f 单位力学时间导出一个结果文件。注意这包括静态、蠕变或动力条件下所走的循环。静态循环始终使用时步 1.0。

step i

每 i 个循环导出一个结果文件。注意对弱耦合分析（见 求解模型（model solve） 命令），这些步为“超级循环”，不包含为求解从属过程至平衡所走的步。

thermal f

每累积 f 单位热学时间导出一个结果文件。

list

列出当前结果文件设置。该列表先详细列出所有可包含的可选值及其当前设置，最后给出当前间隔值。

map s | y 向条件（sy ）

把表格结果列表放入 FISH 映射。若 FISH 变量不存在，则必须给出字符串名称；否则符号名可不用引号。键为超循环编号或制表时刻的累积时间，值为结果文件名。

prefix s

指定自动导出结果文件所用的前缀。默认前缀在 FLAC3D 中为 flac3d，{PFC2D 默认前缀（pfc2d）（PFC2D 中）；PFC3D 默认前缀（pfc3d）（PFC3D 中）}。

warn b

指定从控制台启动循环时，若结果文件覆盖已有结果文件是否通知用户。
