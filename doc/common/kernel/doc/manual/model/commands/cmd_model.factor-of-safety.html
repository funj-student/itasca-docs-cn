model factor-of-safety 命令

语法

model factor-of-safety <keyword ...>

设置安全系数分析参数。完整说明见 ref-factorofsafety- 一节。适用以下关键字。

:flag3:[cs：属于通用问题的一部分]

associated

采用关联流动法则。剪胀角设为摩擦角（经安全系数计算过程修正后的值）。（默认采用非关联流动。）注意即便在非关联流动法则中，剪胀角也不允许大于摩擦角。

block-zone keyword (3DEC)

指定分析过程中要改变哪些 3DEC 网格单元性质。用户可从列表中 include（包含）或 exclude（排除）特定的网格单元性质。默认所包含的性质列表为 摩擦（friction）、黏聚力（cohesion）、节理黏聚力（joint-cohesion） 与 joint-friction（后两者指遍布节理强度性质）。

include s

匹配 s 的性质被包含。随目标安全系数改变，其取值在本构模型中被调整。

exclude s

匹配 s 的性质被排除。随目标安全系数改变，其取值在本构模型中保持不变。

bracket f1 f2

设置两个起始区间值。若安全系数落在所指定区间之外，则安全系数计算停止并发出警告消息。若 f1 = f2，则 FLAC3D 只检验一个值的稳定性。

bracket-limit f

设置安全系数区间搜索过程中目标安全系数每次可变动的最大幅度。例如若当前安全系数限值为1（稳定）、2 刚被算出为不稳定，则下一次安全系数试验值为 1.5。但若 bracket-limit 已设为 0.05，则下一次试验安全系数为 1.45——方向与 1.5 相同，但与上一个值的距离最多为 0.05。

若目标是生成安全系数等值线，该关键字很有用，因为它保证区间搜索期间所取各值之间的最大间隔。

characteristic-steps i

设置特征响应步数。若未指定，则用现有扰动方法检验 i。

convergence f

指定用于判定平衡的收敛值。见 ref-equilibrium- 中关于比值选项的讨论。

filename s

设置用于标识安全系数计算过程中所创建存档文件的文件名前缀。过程中将创建三个文件。例如若前缀为 试验（test），则将创建文件 初始算例存盘文件（test-Init.f3sav）、稳定算例存盘文件（test-Stable.f3sav） 和 不稳定算例存盘文件（test-Unstable.f3sav），分别表示初始状态、最后一个稳定状态和最后一个不稳定状态。

interface (FLAC3D)

指定分析过程中改变哪些界面性质。用户可 include 或 exclude 列表中的特定界面性质。注意若存在界面，则不支持大应变模式下的安全系数计算。

include s

匹配 s 的性质被包含。随目标安全系数改变，其取值在本构模型中被调整。

exclude s

匹配 s 的性质被排除。随目标安全系数改变，其取值在本构模型中保持不变。

joint (3DEC)

指定分析过程中改变哪些节理性质。用户可 include 或 exclude 列表中的特定节理性质。默认包含的性质列表为 黏聚力（scohesion） 和 摩擦角（sfriction）。

include s

匹配 s 的性质被包含。随目标安全系数改变，其取值在本构模型中被调整。

exclude s

匹配 s 的性质被排除。随目标安全系数改变，其取值在本构模型中保持不变。

list

显示最近一次安全系数结果。

perturbation f

设置应力扰动系数。该系数用于确定特征响应步数：通过调整应力场并使模型不产生破坏，把模型从其当前（假定的）平衡状态扰动。默认系数为 2.0。

ratio f

指定用于判定平衡的不平衡力比。若未显式设置，则程序使用上一次 求解模型（model solve） 命令所用的当前值。默认值为 1e-5。

ratio-average f

指定用于判定平衡的不平衡力比，且使用平均比值。见 ref-equilibrium- 中关于比值选项的讨论。

ratio-local f

指定用于判定平衡的不平衡力比，且使用局部比值。见 ref-equilibrium- 中关于比值选项的讨论。

ratio-maximum f

指定用于判定平衡的不平衡力比，且使用最大比值。见 ref-equilibrium- 中关于比值选项的讨论。

resolution f

设置比较两个区间（稳定与不稳定）安全系数时的分辨率。默认值为 .005 × 平均值。一旦已知稳定与不稳定安全系数之间的间隙小于该值，安全系数计算即结束。

step-limit i

设置允许的特征步数上限。若特征步数将超过该限值，则停止检查并使用该值。默认值为 200,000。

zone keyword (FLAC3D)

指定分析过程中改变哪些网格单元性质。用户可 include 或 exclude 列表中的特定网格单元性质。默认包含的性质列表为 摩擦（friction）、黏聚力（cohesion）、节理黏聚力（joint-cohesion） 和 joint-friction。

include s

匹配 s 的性质被包含。随目标安全系数改变，其取值在本构模型中被调整。

exclude s

匹配 s 的性质被排除。随目标安全系数改变，其取值在本构模型中保持不变。
