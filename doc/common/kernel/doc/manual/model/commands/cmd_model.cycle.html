model cycle 命令

语法

model cycle i <calm i2 >

执行时步。也可使用同义词 执行计算时步命令（model step）。这等价于以 i 设置 cycles 关键字后调用 求解模型（model solve）。

将执行 i 个时步，除非处理过程因按下 Shift + Esc 而中断——这会终止循环、退出当前数据文件（以及可能用于调用它的所有嵌套层级数据文件），并在当前步完成后把输入返回命令提示符。

可选的 calm 关键字用于力学过程，每 i2 个循环把线速度与角速度重置为零。
