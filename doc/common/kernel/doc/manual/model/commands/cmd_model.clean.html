model clean 命令

语法

model clean <keyword>

清理模型。

注意

FLAC3D 对象（网格单元与结构单元）不受该命令影响。该命令是为支持 PFC 对象（球、墙等）而提供的。更多背景见 ref-pfcplugin-。

[CS：本页两处说明都需要重新考虑，即本页被多个程序共用的问题]

模型创建期间（循环之前），模型并不有效：片体之间尚无接触，片体性质可能尚未设置，片体也可能尚未加入用于高效空间搜索的数据结构。model.clean 命令是全局命令，可在模型创建过程中的任意时刻给出，用于创建模型中所有接触、初始化所有片体性质、确保存在可供空间搜索的数据结构，并根据几何更新接触活动状态。给出 model timestep fix 和 model timestep auto 命令时会调用该命令。

注意

在 PFC 中用 DFN 插入接触时：若在 model clean 命令之前未给出 fracture model 命令，则与裂隙相交的新建接触不会被赋予裂隙 ID。

all

若给出该关键字，则在单元空间中对 PFC 对象重新映射并更新单元范围。
