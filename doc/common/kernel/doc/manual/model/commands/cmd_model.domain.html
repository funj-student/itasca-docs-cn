model domain 命令

语法

model domain keyword

指定域边界与条件。DFN 裂隙只存在于域范围之内。

注意

在 FLAC3D 中，网格单元与结构单元并不感知模型域。

在 PFC 中，墙、刚性簇和球必须位于域内，且会感知域边界条件。

condition keyword <keyword keyword>

设置域边界条件。每个域条件作用于与该方向垂直的两个盒体侧面。

第一个关键字指定 x 方向的条件，第二个指定 y，第三个指定 z。若只指定一个关键字，则 y 与 z 设为与 x 相同的条件。默认 condition 为 stop 条件。

可用以下关键字指定域条件。

stop

stop 条件施加如下约束：若物体形心落到模型域之外，该物体的速度与自转置零。对 PFC 墙，一旦某个面片形心落到模型域之外，其速度与自转即置零，包括所有顶点速度。

reflect

reflect 条件在物体形心落到模型域之外时赋予相反符号的速度，自转保持不变。不建议把该条件用作接触规则，因为它可能引起不稳定。reflect 条件与穿过模型域的墙不兼容。

destroy

destroy 条件会删除其个体范围（即紧密包络该对象的轴对齐包围盒）落于模型域之外的球、刚性簇与墙面片。

periodic

periodic 条件施加周期性边界条件。当球或刚性簇形心落到模型域之外时，将其平移回模型的相对一侧。为使接触按模型连续的方式创建，引入了“鬼”球与鬼刚性簇。periodic 条件与穿过模型域的墙不兼容。

extent 盒体 x 向下限（fxl ）盒体 x 向上限（fxu ）<fyl fyu fzl fzu >

指定域各侧的位置。每组取值作用于该域相应维度的下界与上界。若只指定 盒体 x 向下限（fxl） 和 盒体 x 向上限（fxu），则该域为立方体。
