model new 命令

语法

model new <force>

清除模型状态信息。模型信息被清除，从而可开始新问题。可选关键字 force 抑制模型重置确认对话框（使用 model.new 命令时，若模型自上次保存后已改变，通常会出现该对话框）。

与项目或程序状态相关的取值不受 新建模型（model new） 命令影响。见 新建项目命令（project new） 与 program 命令。

模型状态信息包括已定义的 FISH 函数与变量、历史记录和表格。

整个模型状态可通过 保存模型（model save） 命令写入文件，之后用 恢复模型（model restore） 命令恢复。或者，由 FISH 函数把数据写入文件（见 文件工具（File Utilities）），再由另一个 FISH 函数（在执行 model.new 命令之后创建）读回该数据。

注意

当从被调用文件运行多个不同问题时，必须在每个新问题之前给出 model new 命令。
