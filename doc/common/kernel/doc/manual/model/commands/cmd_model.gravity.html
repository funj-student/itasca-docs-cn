model gravity 命令

语法

model gravity v3 | f

以向量或浮点数设置重力。重力以加速度为单位设置。体积力由重力向量与物体真实质量之积计算。

作为简写，也可只指定单个标量值 f。此时重力被设为 (0,0,-f)。
