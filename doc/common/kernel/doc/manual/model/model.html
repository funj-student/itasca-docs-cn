模型

这是一组影响当前模型状态的命令。因此与多数针对模型组件（即数据标量或几何集合）的命令不同，许多模型命令作用于整个模型。例如整个模型状态用 新建模型（model new） 命令重置，并用 保存模型（model save） 与 恢复模型（model restore） 命令保存/恢复。这些命令不同于 程序（program） 命令：后者的结果不随模型状态保存，而通常存储在计算机注册表中。
