Program

这些命令控制并配置程序执行。与 program 命令关联的数据通常根本不保存，或保存在运行程序的计算机注册表中，以便下次运行程序时可用。不过这些数据不与任何特定项目或模型状态关联。所有 program 命令都可带或不带前导词 program 构成——program.quit 与 quit 两种形式结果相同。这些命令不同于 模型（model） 命令，后者结果通常影响模型状态。
