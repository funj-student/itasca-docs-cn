program call 命令

语法

program call s <keyword ...>

处理指定的数据文件。

注意

与所有 program 命令一样，命令词 program 可省略；program call 与 call 均有效。

若给出的文件名 s 不带扩展名，则程序会同时查找带 “.dat” 扩展名和带程序专用扩展名（FLAC3D 为 “.f3dat”）的字符串。

以相对路径而非显式路径调用的文件，会先在当前正在处理的数据文件所在文件夹中查找，然后在当前目录中查找。[1] [这应当成为某处自己的主题，一旦建立则此处改为指向该主题的链接。]

任何一系列输入指令都可放入数据文件。数据文件又可调用其他文件，嵌套层级不限。但文件之间不得递归调用（例如文件 “ABC” 调用文件 “DEF”，后者又调用文件 “ABC”）。

可用 暂停命令处理命令（program pause） 与 返回程序控制命令（program return） 命令中断数据文件处理；可在控制台命令提示符下给出 继续程序执行命令（program continue） 命令以恢复处理。详见这些命令，特别是关于调用栈的部分。按下 Shift + Esc 会终止来自数据文件的输入并把程序控制权交回命令提示符，无论调用嵌套到哪一层。

call s <keyword ...>

使用两个或更多 call 关键字可在同一行中调用多个文件。被调用文件将按其在命令中出现的顺序处理，从后往前。多文件调用各以 program call 命令词开始——多文件调用实际上是一串独立的调用。每个文件可用的关键字与 program call 命令所允许的相同。

line i

若指定 line 关键字，则数据文件从第 i 行开始读取。若该行超出文件末尾，则文件立即返回，如同已处理到文件末尾。该选项不能与 label 选项一起使用。

label 历程标签名（sl ）

若指定 label 关键字，则数据文件从标签 历程标签名（sl） 处开始读取。要在数据文件中放置标签，请使用语法 “:label”（冒号必须是该行的第一个字符）。数据文件将从标签之后的第一行开始读取。含标签的行被忽略（如同冒号是注释）。若在数据文件中未找到该标签，则提示错误。该选项不能与 line 选项一起使用。

suppress

若在命令中有一处添加了可选关键字 suppress，则命令处理器在处理所调用文件（以及由其调用的任何文件）期间不会把这些文件的内容回显到屏幕。

用法示例

下面的示例文件 “call_use.dat” 展示了若干可能的 program call 命令。它使用两个数据文件 “table_w1.dat” 与 “table_w2.dat”——下文一并列出以供参考。查看该例时需注意：“table_w2.dat” 在其第四行调用了 “table_w1.dat”。

;call_use.dat

;基本调用：
program call 'table_w2.dat'                                 ;(a)    
;call 'table_w2'                                     (b) 
;call 'c:\projects\flac3d\examples\table_w2'         (c)
;call 'c:\\projects/flac3d//examples\table_w2.dat'   (d)   
;call 'folder\table_w2.dat'             -- ERROR!!   (e)

;使用 line 关键字
new
program call 'table_w1' call 'table_w2' line 5                ;(f)
new
program call 'table_w2' line 5                              ;(g)

;使用 suppress 关键字
new
program call 'table_w1' suppress call 'table_w2' line 5       ;(h)

文件中标为 “basic calls” 的部分展示了 program call 的五种用法。前四种是调用文件 “table_w2.dat” 的有效方式，假定 当前目录 为 (c) 和 (d) 所示的路径 “c:\projects\flac3d\examples”。第五种用法 (e) 产生错误，因为所给相对路径不正确。情形 (c) 说明可用 正斜杠 “/”、反斜杠 “\” 或 “//” 互换 地分隔文件路径。

下一组标为 ;using line keyword。用法 (f) 得到与基本调用情形 (a-d) 相同的结果。先处理 “table_w2.dat”（从第 5 行开始，即在其第 4 行对 “table_w1.dat” 的调用之后），然后处理 “table1.dat”。注意处理顺序的差异意味着 “world” 表格先被创建，因此其索引较小，在 “table_w2.dat” 中处理最后的 列出程序信息（program list） table 命令时先被列出。情形 (g) 用 line 关键字跳过 “table_w2.dat” 中对 “table_w1.dat” 的调用，因此该情形下只创建拼出 “world” 的表格。

最后一种用法 (h) 演示了 suppress 关键字。其调用过程与用法 (f) 相同，但该用法下控制台只显示 列出程序信息（program list） 命令的结果。

;table_w1.dat

table letter_h 2,12 2,8 2,10, 4,10 4,12 4,8
table letter_e 7,12 5,12 5,10 7,10 5,10 5,8 7,8
table letter_l1 8,12 8,8 10,8
table letter_l2 11,12 11,8 13,8
table letter_o1 15,12 14,11 14,9 15,8 16,8 17,9 17,11 16,12 15,12

list table

new

table letter_r 11,3 11,7 12,7 13,6 12,5 11,5 13,3
table letter_l3 14,7 14,3 16,3
table letter_d 17,7 17,3 19,3 20,4 20,6 19,7 17,7

list table

尾注

[1]

当前目录 定义如下：

  • 当前项目文件所在文件夹，除非
  • 未使用项目文件，此时它是程序所在文件夹，除非
  • 程序位于受 Windows 保护的文件夹（例如常见的 “program files” 文件夹）中，此时它是应用程序数据复制到（application data was copied）的文件夹，除非
  • 应用程序数据尚未复制，此时它是本机上当前用户配置文件的基文件夹（该文件夹位置各 Windows 版本不同）

使用 设置工作目录命令（program directory） 命令可覆盖上述任何设置，改为命令中所指定的位置。可用 list directory 确定当前目录。
