program list 命令

语法

program list keyword

主要关键字：

cycle-sequence    directory    FISH函数（fish）    information    memory    module    命名范围（named-range）    plugins    principal    version

打印程序信息。

注意

与所有 program 命令一样，命令词 program 可省略；program list 与 list 均有效。

程序信息打印到屏幕。该信息可用 设置日志文件命令（program log-file） 命令捕获到日志文件中。




cycle-sequence

列出表示循环点与循环序列中各循环条目名称的双精度数。该信息在安装 FISH 回调事件（用 设置FISH回调命令（fish callback） 命令）时有用。下表列出保留的循环点：


循环点 循环操作
-10 校验数据结构
0 确定稳定时步
10 运动方程（或热学物体更新）
15 各过程间的物体耦合
20 递增时间
30 更新单元空间
35 创建/删除接触
40 力-位移法则（或热学接触更新）
42 累积确定性量
45 各过程间的接触耦合
60 运动方程的第二遍计算
70 热学计算
80 流体计算


directory

列出当前工作目录与应用程序目录。

fish <keyword> | s ...

列出 FISH 信息。默认列出所有 FISH 符号。也可列出特定 FISH 符号。

arrays

列出所有已创建的 FISH 数组。

basic

所有全局 FISH 符号的基本列表。

callbacks

列出已添加为回调执行的 FISH 函数（即通过 设置FISH回调命令（fish callback） 命令添加的）。

callback-list

列出已注册的回调事件。例如 solve_complete 事件就是一个已注册的回调事件。[CS：事件的基础列表在何处显示？]

code <s >

列出解析 FISH 语法后生成的 FISH 伪代码。若给出特定符号 s，则只列出该特定函数的代码；否则列出所有函数的伪代码。

contents s

对聚合类型（数组、矩阵、结构体、映射等）的 FISH 值，该命令将以结构化方式列出该类型的内容。

intrinsics <s >

列出全部 FISH 内建函数（含内建与用户定义）。若给出字符串 s，则只列出名称中包含 s 的内建函数。

memory-items

列出所有已分配的内存对象。见 FISH 函数 创建内存块（memory.create）。

structures

列出已定义的 FISH 结构体，包括其成员名与取值。

symbols

列出所有 FISH 符号。

information

程序的一般设置与状态，包括客户标题与所用目标线程数。

memory

列出正在活动使用的内存量。

module

列出已加载的模块 DLL。

named-range <s >

列出当前的命名范围。若指定特定命名范围 s，则列出该范围的具体内容。

plugins

列出已加载的插件 DLL。

principal 第一主应力值（fs1 ）第二主应力值（fs2 ）第三主应力值（fs3 ）keyword

这是一个实用工具，可由主值（第一主应力值（fs1） 第二主应力值（fs2） 第三主应力值（fs3））与方向确定应力张量的六个分量。必须给出全部三个主值。需要两个方向：

intermediate f <keyword ...>

指定中间值。可用以下关键字指定中间方向：

azimuth f

该方向以由 azimuth 与 plunge 给出的平面的法向指定，单位为度。

dip f

该方向以由 dip 与 dip-direction 给出的平面的法向指定，单位为度。

dip-direction f

该方向以由 dip 与 dip-direction 给出的平面的法向指定，单位为度。

normal v

以法向向量形式给出的方向。

plunge f

该方向以由 azimuth 与 plunge 给出的平面的法向指定，单位为度。

trend f

azimuth 的同义词

minimum f <keyword ...>

指定最小值。可用以下关键字指定中间方向：

该方向以由 azimuth 与 plunge 给出的平面的法向指定，单位为度。

dip f

该方向以由 dip 与 dip-direction 给出的平面的法向指定，单位为度。

trend f

azimuth 的同义词

指定最大值。可用以下关键字指定中间方向：

dip f

该方向以由 dip 与 dip-direction 给出的平面的法向指定，单位为度。

version

列出完整的程序版本信息。若使用本程序时出现问题，应报告该信息。

用法示例

下例说明 列出程序信息（program list） 的用法。该例演示 principal 关键字的用法，它要求给出全部三个应力分量，且每个分量需给出两个方向关键字。

program list principal 3.3 2.2 1.1 intermediate dip 22.2 dip-direction 80 &
                       minimum normal 1,3,1 &
                       maximum azimuth 80 plunge 22.2
