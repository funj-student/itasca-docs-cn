program load 命令

语法

program load keyword

加载兼容的 DLL。

注意

与所有 program 命令一样，命令词 program 可省略；program load 与 load 均有效。

DLL 可为用户定义 FISH 函数、接触模型、网格单元或结构单元的本构模型、框架模块或框架 GUI 模块。必须用 cmodel、contactmodelmechanical、function、guimodule、module 或 plotitem 关键字之一指定所加载模块的类型。

插件被载入程序后一直可用，直至程序关闭。当前已加载插件的列表可通过执行 列出已加载插件命令（program list plugins） 命令获得。

用户界面的 “Tools/Plugins” 菜单提供通用插件管理器对话框。

cmodel [loadoptions]

加载本构模型 DLL。插件文件前缀为 模型（model）。附加模型会在 FLAC3D 中执行 列出单元本构模型（zone cmodel list） 命令后出现在可用模型列表中。

contactmodelmechanical [loadoptions]

加载力学接触模型 DLL。三维中插件文件前缀为 三维接触模型力学模块（contactmodelmechanical3d），二维中为 二维接触模型力学模块（contanctmodelmechanical2d）。由于这些接触模型作用于球、子颗粒与墙面片之间的接触，必须先加载 PFC 模块（见 module 关键字）。

function [loadoptions]

加载一个或多个 FISH 函数 DLL。插件文件前缀为 FISH函数（fish）。FISH 函数 DLL 可创建一个或多个 FISH 内建函数，这些函数会出现在执行 列出 FISH 内置函数（fish list intrinsics） 命令后所得的列表中。

guimodule [loadoptions]

加载框架 GUI 模块 DLL。三维中插件文件前缀为 三维 GUI 模块（guimodule3d），二维中为 二维 GUI 模块（guimodule2d）。一般而言，每个 GUI 模块都对应一个引擎模块，且必须先在 GUI 模块之前加载引擎模块（见 module 关键字）。

module [loadoptions]

加载框架引擎模块 DLL（[DR：请向 CS 提供该术语的定义；CS：把定义加入术语表]）。插件文件前缀在三维中为 三维模块（module3d），在二维中为 二维模块（module2d）。该模块会出现在执行 列出程序模块（program list module） 命令后所得的列表中。

plotitem [loadoptions]

加载框架绘图项 DLL。插件文件前缀在三维中为 三维绘图项（plotitem3d），在二维中为 二维绘图项（plotitem2d）。


加载的通用选项块

可用以下关键字影响给定类型插件的加载方式。cmodel、接触模型力学模块（contactmodelmechanical）、函数（function）、GUI 模块（guimodule）、module 和 绘图项（plotitem）。

s

加载名为 s 的插件 DLL 文件。可给出完整文件名，或由程序尝试查找匹配 “prefixname005.dll” 模式的名称，其中 s = 名称（name） 且 prefix 匹配插件类型。若未给出完整路径，程序将在可执行文件目录及其所有子目录、当前目录及其所有子目录中查找匹配。

automatic

尝试加载所有匹配 “prefixname005.dll” 的插件，其中 prefix 匹配插件类型，名称（name） 匹配任何可用名称。默认会扫描安装位置的 “exe64/plugins” 目录及其所有子目录。可用 directory 关键字覆盖。

directory 区域条件（sd ）

指定使用 automatic 时要扫描的目录。所有子目录也会被扫描。默认目录为安装位置的 “exe64/plugins” 目录。
