program threads 命令

语法

program threads keyword

设置用于计算与绘图的线程数。

该值是程序状态的一部分。它不随模型或项目保存或恢复。它在当前硬件上的多次代码执行之间持续有效。代码安装后的默认值为 automatic。

注意

与所有 program 命令一样，命令词 program 可省略；program threads 与 threads 均有效。

i

使用 i 个处理器。

automatic

使用操作系统报告的线程数。注意若启用了超线程，该数可能为实际可用处理器与核心数的两倍。
