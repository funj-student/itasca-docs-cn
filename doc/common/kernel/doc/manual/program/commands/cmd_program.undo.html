program undo 命令

语法

program undo <i >

撤销命令。

注意

与所有 program 命令一样，命令词 program 可省略；program undo 与 undo 均有效。

若可能，该命令撤销发送给命令处理器的最后 i 行命令。这些命令可以是在命令提示符下输入的命令，或通过用户界面发出的命令。撤销操作通过“回放”自上次模型重置或保存状态以来记录的交互命令记录来执行，但去掉最后 i 步。i 为可选，省略时默认为 1。

对数据文件的调用被 undo 视为单行（即出于 undo 的目的不会“展开”为其组成命令）。回放期间，此前导致错误的命令不会中止处理，但错误报告仍照常进行。[DR：复核前述描述；若需改进/更正请与 CS 讨论]

若已从某个允许的状态创建模型存档文件，则 undo 会先通过执行 恢复模型（model restore） 恢复该文件。因此不能撤销到该点之前。

注意

undo 并非始终可用。

  • 以不安全方式被中断的命令会阻止撤销回放。
  • 不能撤销到 恢复模型（model restore） 之前。
  • 若执行环境已改变，undo 可能失败或导致模型状态不同。
  • 在不允许使用 新建模型（model new） 命令的状态下所创建的保存状态（例如处理 FISH command/end.command 命令块（command/end.command） 期间）不能用作撤销的起点。
  • 请注意若直接使用该命令（在命令提示符下键入 undo），则不会检查回放将耗时多久。
