program automatic-model-save 命令

语法

program automatic-model-save keyword ...

设置控制循环期间自动创建安全存档文件的取值。这是一项安全措施，用于避免在断电或程序崩溃后不得不重新开始漫长的运行。

若自上次创建存档以来的累积循环时间超过所设间隔，则自动创建模型存档状态（压缩）。该文件被赋予唯一文件名。程序正常关闭时该文件也会被自动删除。创建后，除非当前目录改变，否则每次新建存档都覆盖同一文件；若当前目录改变，则删除旧文件并创建新文件。

这些取值属于程序状态。它们不随模型或项目保存或恢复。它们会在当前硬件上的多次程序运行之间保持。程序安装后的默认值为在当前目录中每 4 小时创建一个存档文件。

这些取值可在用户界面的 Tools/Options/General 中获得。

active b

开启或关闭循环期间的自动模型保存。

interval 自动保存时间间隔（fi ）

设置循环期间自动创建模型存档的时间间隔（小时）。该时间值必须介于 0 与 24 之间。

若该值设为 0，则还会自动把 active 设为 关闭（off）。

若该值设为非零，则还会自动把 active 设为 开启（on）。

directory s

设置自动存档文件所在目录。若为相对路径，则相对当前目录。默认该字符串为空，表示文件保存在当前目录。
