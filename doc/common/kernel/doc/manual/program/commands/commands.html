命令

这些命令影响当前程序状态。这些取值属于设置，既不受模型状态影响，也不受项目影响——因此当模型状态或项目状态改变时（例如恢复模型时）不受影响。

部分 program 命令（在注明处）存储在计算机上的持久位置，并在多次程序执行之间持续有效。其他命令只影响程序的当前实例，程序退出并重启后将重置。

所有 program 命令都可带或不带前导命令词 program 发出。因此，例如 call 等价于 program call。
