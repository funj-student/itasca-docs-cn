program quit 命令

语法

program quit

关闭程序。

注意

与所有 program 命令一样，命令词 program 可省略；program quit 与 quit 均有效。

除非在 program.quit 命令之前给出 保存模型（model save） 命令，否则所有信息都将丢失。这是 停止程序命令（program stop） 与 退出程序命令（program exit） 的同义词。
