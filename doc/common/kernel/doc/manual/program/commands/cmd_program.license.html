program license 命令

语法

program license keyword

主要关键字：

list    位置（location）

获取/设置许可证信息。

注意

与所有 program 命令一样，命令词 program 可省略；program list 与 list 均有效。

可用以下关键字

list keyword

列出许可证信息。可用以下子关键字。

key-information

查找直接连接在本机上的有效 Itasca 安全密钥并报告其全部信息。该密钥不必含有本程序的许可证，可为任意 Itasca 程序的密钥。该操作仅允许一个 Itasca 密钥直接连接在本机上。

security

查找有效许可证（使用当前位置设置），若找到则报告许可证内容。许可证信息将对应当前许可证需求；若无需求则使用最小默认需求。

serial

列出满足当前许可要求的许可证序列号。若当前无要求，则使用最小的默认要求。

location keyword

指定用于获取满足当前需求所需许可证的位置。可用以下许可证位置关键字：

key-local <key-id i >

指定许可证可在通过 USB 端口直接连接到计算机的 SuperPro 硬件密钥上找到。可用可选关键字 key-id 输入密钥序列号以指定使用特定密钥。

key-network <server > <key-id i >

指定许可证可在直接连接 SuperPro 网络硬件密钥的网络服务器上找到。必须紧跟其后给出服务器名称——可为 IP 地址（字符串）、局域网中的计算机名或 URL。若未指定服务器名，则系统使用最近一次为网络密钥许可证所指定的服务器。使用字符串 本机（localhost） 表示网络密钥与服务器就是本机。可选 key-id 关键字可用于通过输入密钥序列号来指定使用特定密钥。

requirements

列出当前模型的许可证要求。组内任一许可证满足其任一条目即满足该组要求。所有组都必须找到满足各自某一项条目的许可证。也可能完全没有要求。

web <sfile >

指定许可证可通过 web 许可证找到。其后的字符串必须给出 .lic 许可证文件的位置，该文件将被加载以指明所用许可证信息。若未指明文件，则系统将使用上一次作为 web 许可证标识给出的内容。
