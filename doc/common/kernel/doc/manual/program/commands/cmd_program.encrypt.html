program encrypt 命令

语法

program encrypt source <starget >

加密源数据文件，使内容对调用者不可见或不可修改。加密文件可像普通文本文件一样与 调用数据文件（program call） 命令一起使用，但其内容已被打乱，并会检查是否被修改。

读入数据文件 source，并创建加密数据文件 \(starget\)。

若未为 source 指定扩展名，则假定为 数据文件扩展名（.dat）。

若未指定 加密输出文件名（starget），则目标文件名与源文件相同但扩展名为 加密数据文件扩展名（.edat）。若未为 加密输出文件名（starget） 指定扩展名，则假定为 加密数据文件扩展名（.edat）。
