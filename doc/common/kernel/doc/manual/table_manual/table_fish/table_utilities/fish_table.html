table

语法

y 向尺寸（fy） = table(t,fx)
table(t,fx) = y 向尺寸（fy）

获取/设置表格条目。

取值表格条目时，查询表格 t，并通过插值求得与给定 x 对应的 y 值。若 x 小于或大于表格中任何 x 值，则返回与最小或最大 x 值关联的 y 值。若表格未按 x 值递增排序，则该函数结果无定义。

设置表项时，把 (x,y) 对插入表 t 中第一个适当位置（即新项插入到 x 值夹住所给 x 值的两个现有项之间）。若所给 x 分别小于最小 x 或大于最大 x，则新项置于表首或追加到表末。执行该语句后表中项数增加一。若表 t 不存在，则创建该表并把所给项作为第一项。若所给 x 与某个 (x,y) 对已存的 x 相同，则更新其 y 值而不插入新对。

注意

若第一个参数给出唯一整数或字符串名称，则创建新表格。

返回值：

y 向尺寸（fy） - y 值
接受：

y 向尺寸（fy） - y 值
参数：

t - 整数名、字符串名或表格指针

x 向尺寸（fx） - x 值
