Table

表格逻辑支持创建和操作表格，表格是以浮点数对（为方便起见记为 x 与 y）为元素的索引数组。每个表格条目（或 (x,y) 对）还有一个序号（整数，范围 [1, 2, … , N]，N 为表格中的项数）。

可通过多条命令定义多个表格。每个表格有唯一 ID 号。此外每个表格还有一个表示表格名称的字符串，对于大多数操作表格的命令，可用它代替表格 ID。

历史记录的内容可通过 导出历程命令（history export） 命令复制到表格。此外，ASCII 文件的内容可通过 history import 命令复制到表格。
