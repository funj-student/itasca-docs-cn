table import 命令

语法

table s import 许可证文件名（sfile ）

把文件 许可证文件名（sfile） 读入表格 s。

文件必须按下述格式编排，默认扩展名为 “.tab”。文件内容被加入任何已有表格数据。

文件 许可证文件名（sfile） 必须按如下格式编排：

第 1 行——该行作为表格标签，长度任意。

第 2 行——给出两个以空白分隔的值，即点的数量，随后是它们之间的假定间隔。若间隔指定为 0.0，则假定其后为间距不均匀的数对。

第 3 行——给出表格 y 值。x 值按第 2 行输入的步长以等间隔时间值计算。若步长指定为 0.0，则假定步长不是常数，其余各行的值按以空白分隔的数对读取。
