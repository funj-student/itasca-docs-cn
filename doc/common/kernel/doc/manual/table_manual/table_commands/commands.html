命令

表本质上是一个带名称的 (x,y) 值对列表。这些值对可任意排序，并按索引查找。更常见的是这些值对按 x 值递增排列，此时可在给定值之间线性插值，从而依据 x 值高效地查找 y 值。

许多本构模型用表格把一般材料性状表示为某个演化参数的函数。表格也可用于存储数据以便后续显示。
