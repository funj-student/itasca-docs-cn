fish callback 命令

语法

fish callback keyword

添加/移除响应回调事件而执行的函数。

回调机制允许 FISH 函数 回调函数（sf） 在循环期间 循环序列（the cycle sequence） 的特定位置执行——在序列中的 f 位置（若给出），或在特定回调事件发生时执行（事件列表见 fish list 回调（fish list callbacks） 命令）。

有三类事件可触发 FISH 函数的执行：1) 模型实体的创建/删除；2) 接触模型事件；[1] 3) 求解终止事件。情形 1) 和 2) 下，若 回调函数（sf） 带参数，则可把值作为参数返回给 回调函数（sf）。

情形 1) 下，传给 回调函数（sf） 的第一个参数是指向被创建或删除实体的指针。情形 2) 下，参数取决于接触模型的实现。[CS：在属实之前删除以下内容] 并在 “nomenclature” 主题中详述

若给出 remove 关键字，则移除 回调函数（sf） 的第一个实例。[CS：在属实之前删除以下内容] 回调用法示例见 :ref:tuto_callbacks。

add sym keyword

把 FISH 符号 sym 加入系统回调。回调位置由以下关键字确定。注意 sym 所需的任何参数都必须在此处以括号括起给出。

f <keyword>

每一步都会在 f 给定的循环序列位置调用 FISH 函数 sym。可用以下关键字降低回调频率。

interval i

若指定，则该函数仅在每 i 步调用一次。

process keyword

若指定，则仅当所指过程在该循环中处于活动状态时才调用该函数。

creep

仅当蠕变与力学过程均处于活动状态时才会执行该回调。

dynamic

仅当动力与力学过程均处于活动状态时才会执行该回调。

fluid

仅当流体过程处于活动状态时才会执行该回调。

mechanical

仅当力学过程处于活动状态时才会执行该回调。

thermal

仅当热学过程处于活动状态时才会执行该回调。

event [evblock]

将响应指定事件而调用 FISH 函数 sym。

remove sym <keyword>

从系统回调列表中移除 sym。若未指定事件名或调用位置，则该符号将从所有出现处移除。可用以下关键字与选项：

f

移除在循环中位置 f 处找到的、对符号 sym 的第一个回调。若该函数被多次登记，则只移除一个条目。

event [evblock]

移除与该事件关联的、对符号 sym 的第一个回调。若该函数被多次登记，则只移除一个条目。

fish callback 关键字块

可用以下关键字指定回调事件。事件（event）。事件（event）。

ball_create

球创建事件。

ball_delete

球删除事件。

ballcfd_create

球 CFD 创建事件。

ballcfd_delete

球 CFD 删除事件。

ballthermal_create

球热学创建事件。

ballthermal_delete

球热学删除事件。

block_create

块体创建事件。

block_delete

块体删除事件。

bond_break

接触黏结断裂事件。

cfd_after_update

在 CFD 孔隙率更新之后

cfd_after_receive

在收到 CFD 速度之后

cfd_before_send

在发送 CFD 信息之前

cfd_before_update

在 CFD 孔隙率更新之前

clump_create

刚性簇创建事件。

clump_delete

刚性簇删除事件。

clumpcfd_create

刚性簇 CFD 创建事件。

clumpcfd_delete

刚性簇 CFD 删除事件。

clumpthermal_create

刚性簇热学创建事件。

clumpthermal_delete

刚性簇热学删除事件。

contact_activated

接触激活事件。

contact_create

接触创建事件。

contact_delete

接触删除事件。

faceblock_create

面块体创建事件。

faceblock_delete

面块体删除事件。

facet_create

墙面片创建事件。

facet_delete

墙面片删除事件。

fos_complete

安全系数求解已完成。检查当前求解准则以判断模型是否收敛。全局安全系数（global.fos） 内建函数将返回当前安全系数。

fos_start

安全系数求解已开始。全局安全系数（global.fos） 内建函数将返回当前安全系数。模型已从初始状态恢复并已施加强度折减。这可用于在给定安全系数下自定义强度折减。

rblock_create

RBlock 创建事件。

rblock_delete

RBlock 删除事件。

rblockthermal_create

RBlock 热学创建事件。

rblockthermal_delete

RBlock 热学删除事件。

slip_change

接触滑移变化事件。

solve_complete

solve 或 cycle 命令已终止。可提供一个字符串参数。若该字符串非空，则表示使循环停止的错误消息。

solve_ending

solve 或 cycle 命令即将终止。循环已停止，清理操作已开始。

solve_master

程序已进入耦合求解的 Master 段。

solve_slave

程序已进入耦合求解的 slave 段。提供一个参数表示该从进程的名称。

solve_start

solve 或 cycle 命令即将开始

struct_eom

在结构单元节点运动方程之前

struct_eom_complete

在结构单元节点运动方程完成之后

struct_internal

在结构单元内力计算之前。

struct_internal_complete

在结构单元内力计算完成之后

struct_link_force

在结构连接力计算之前。

struct_link_force_complete

在结构连接力计算之后。

struct_link_update_complete

在作为更新的一部分由单元性质赋值给结构连接性质之后。

struct_update

在结构几何更新之前。几何更新在循环开始时执行，大应变模式下每个更新间隔执行一次。

struct_update_complete

在结构几何更新之后。几何更新在循环开始时执行，大应变模式下每个更新间隔执行一次。

subcontact_create

子接触创建事件。

subcontact_delete

子接触删除事件。

subcontact_state_change

子接触破坏状态的改变。被调用 fish 函数的参数将为子接触指针与旧状态（整数）。

wall_create

墙创建事件。

wall_delete

墙删除事件。

wallthermal_create

墙热学创建事件。

wallthermal_delete

墙热学删除事件。

zone_eom

在网格单元网格点运动方程求解之前

zone_eom_complete

在网格单元网格点运动方程求解之后

zone_stress

在网格单元应力更新之前。

zone_stress_complete

在网格单元应力更新及其他力施加之后。

zone_update

在网格单元几何更新之前。几何更新在循环开始时执行，大应变模式下每个更新间隔执行一次。

zone_update_complete

在网格单元几何更新之后。几何更新在循环开始时执行，大应变模式下每个更新间隔执行一次。
