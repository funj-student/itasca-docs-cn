fish automatic-create 命令

语法

fish automatic-create b

设置 FISH 符号自动创建状态。若为 true，则在解释 FISH 表达式时遇到无法识别的字符串（且为可能的合法符号名）便创建新的全局变量。否则所有变量都必须用 FISH 中的 local 和 全局函数（global） 关键字声明。默认自动创建为 开启（on）。

若编写大型复杂的 FISH 函数，建议指定 设置FISH变量自动创建命令（fish automatic-create） 关闭（off），以防因变量名拼写错误而产生错误。
