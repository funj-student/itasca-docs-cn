fish operator 命令

语法

fish operator s ...

定义新的 FISH 运算符。运算符是 FISH 函数的特殊类别，设计为在多线程环境中安全使用。

该运算符命名为 s，必须是合法的符号名。其后的标记假定为该函数接受的参数。请参见 FISH 脚本参考（FISH Scripting Reference），特别是 运算符：多线程函数支持（Operators: Multi-threaded function support）。

从此处直到遇到 end 语句，期望的是 FISH 语法而非标准命令处理。FISH 代码被解析为称为伪代码的压缩格式，即由 FISH 运行时执行的格式。编译错误会在处理语句时报告。

伪代码被视为模型状态的一部分，因此在 新建模型（model new） 时被清除、随 保存模型（model save） 保存、用 恢复模型（model restore） 恢复。

若全局符号 s 尚不存在，则创建该符号。若已存在，则将其标记为函数，并在从其取值时执行相应代码。已定义在 s 上的任何函数都将被删除并覆盖。

用法示例

下例说明 定义FISH运算符命令（fish operator） 的用法。

定义返回数据标量指针 x 分量的简单 FISH 运算符 示例函数名 fred（fred）：

fish operator fred(scalar)
    return data.scalar.pos(scalar)->x
end

定义把一个值加到数据标量指针 x 分量上的 FISH 运算符

fish define george(scalar,a)
    data.scalar.pos(scalar)->x += a
end
