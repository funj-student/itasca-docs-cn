命令

这些命令检查或修改一般项目状态。项目状态不同于模型状态（用 新建模型（model new） 命令清除或重置的信息）与程序状态（在本程序实例整个生命周期内保持的信息）。项目信息作为项目文件的一部分被保存与恢复。模型状态的改变不影响项目状态。部分项目设置会被存储并在下次程序执行时继续有效，但会被所恢复的任何已保存项目覆盖。
