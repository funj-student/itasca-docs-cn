命令

对历史记录进行操作。

每条历史记录在循环过程中记录并存储单个标量值。其间隔由 设置历程采样间隔命令（history interval） 命令控制。历史记录通过在特定数据类型上使用 history 关键字创建（例如 zone history 或 ball history）。

请注意历史记录逻辑并非用于采集极大量历史记录。虽然程序不会阻止你每步采集数万条（甚至更多）历史记录，但所存储的数据量会迅速变得难以管理，甚至可能占满硬盘。

模型打开期间，历史数据存储在临时文件中；保存模型时该数据被转入存档文件。

历史命令

删除历程命令（history delete）
导出历程命令（history export）
设置历程采样间隔命令（history interval）
列出历程命令（history list）
设置历程标签（history name label）
清除历程命令（history purge）
设置历程结果输出（history results）
