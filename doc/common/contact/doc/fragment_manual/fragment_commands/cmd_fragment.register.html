fragment register 命令

语法

fragment register <s ...> <ignorebond> <range>

为破碎块体分析注册接触类型。若未指定接触类型（例如 s = ball-ball），则注册所有可用的接触类型。默认情况下，只有黏结的力学接触才被视为纳入破碎块体的判据。若给出 ignorebond 关键字，则考虑所有已有接触（无论是否黏结）。用户可以指定一个可选范围，该范围将作用于所考虑的接触，直到发出 清除碎片信息命令（fragment clear） 命令为止。

给出该命令时，模型中每种相关接触类型至少必须存在一个活动接触。
