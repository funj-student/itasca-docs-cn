fragment activate 命令

语法

fragment activate keyword

主要关键字：

cycles    分组槽位（group-slot）    以便后续操作（time）

激活破碎块体自动计算。必须指定两次破碎块体计算之间的循环步数或时间（分别用 cycles 或 time 关键字）。可选地，可指定把破碎块体 ID 放入指定的组槽位，以便配合范围逻辑使用。 注意，若用户手动移除或解除了接触的黏结，则需要调用 计算碎片命令（fragment compute） 命令，以便破碎块体自动计算逻辑检测到这些变化。

cycles i

指定两次破碎块体计算之间的 i 个循环步。

group-slot s

可选地，指定在更新破碎块体时把破碎块体索引放入组槽位 s。

time f

指定两次破碎块体计算之间的时间量为 f 个时间单位。
