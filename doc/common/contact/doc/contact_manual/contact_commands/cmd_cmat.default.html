cmat default 命令

语法

contact cmat default <type stype > keyword ...

主要关键字：

继承（inheritance）    力学（mechanical）    方法（method）    模型（model）    property    邻近（proximity）    thermal    type

设置 CMAT 的默认槽位。尝试把以下信息赋给 CMAT 的默认槽位。若给出可选关键字 type，则其后必须跟有效的接触类型名，且相应的 CMAT 默认槽位将被修改。若未指定类型，则该命令将尝试修改所有默认槽位。

默认情况下，只考虑力学接触。

inheritance keyword b ...

接触模型属性的继承标志被设为 b。 该属性必须支持继承。

mechanical

适用于力学接触。

method keyword ...

接触模型方法 方法名（sm） 及其特定的参数名与取值对列表（参数名（sa）、a）（如适用） 被注册到选定的默认槽位，并将在创建接触时调用。

model keyword

指定默认模型。若相应的接触类型不能使用指定的接触模型， 则默认槽位不会被修改。

内置力学接触模型的列表见“内置接触模型（Built-in Contact Models）”一节。 用户也可以实现自定义接触模型（更多信息见“用户自定义接触模型（User-Defined Contact Models）”），并将 它们注册到 CMAT 中。

arrlinear

指定 黏附滚动阻力线性模型（Adhesive Rolling Resistance Linear Model） 接触模型。

burger

指定 Burger 模型（Burger’s Model） 接触模型。

fish

指定 FISH 模型（FISH Model） 接触模型。

flatjoint

指定 平节理模型（Flat-Joint Model） 接触模型。

hertz

指定 Hertz 模型（Hertz Model） 接触模型。

hysteretic

指定 滞回模型（Hysteretic Model） 接触模型。

linear

指定 线性模型（Linear Model） 接触模型。

linearcbond

指定 线性接触黏结模型（Linear Contact Bond Model） 接触模型。

linearpbond

指定 线性平行黏结模型（Linear Parallel Bond Model） 接触模型。

null

指定 空模型（Null Model） 接触模型。

rrlinear

指定 滚动阻力线性模型（Rolling Resistance Linear Model） 接触模型。

smoothjoint

指定 光滑节理模型（Smooth-Joint Model） 接触模型。

softbond

指定 软黏结模型（Soft-Bond Model） 接触模型。

property keyword <inheritance b > ...

指定接触模型性质。若给出可选 inheritance，则该性质必须支持继承，且其后必须跟一个布尔值表示其继承标志。

proximity 检测距离（fd ）

检测距离设为 检测距离（fd）。

thermal

适用于热学接触。

type keyword

指定该 CMAT 条目适用于指定类型的接触。这也可以通过接触 范围（range） 元素 实现。

ball-ball

指定该条目为球-球接触的默认 CMAT 条目。

ball-facet

指定该条目为球-面片接触的默认 CMAT 条目。

ball-pebble

指定该条目为球-子颗粒接触的默认 CMAT 条目。

pebble-facet

指定该条目为子颗粒-面片接触的默认 CMAT 条目。

pebble-pebble

指定该条目为子颗粒-子颗粒接触的默认 CMAT 条目。
