cmat add 命令

语法

contact cmat add <i > keyword ... range

主要关键字：

继承（inheritance）    力学（mechanical）    方法（method）    模型（model）    property    邻近（proximity）    thermal

向 CMAT 中添加一个新条目。若未指定 i，或 i 大于 条目总数减一，则新条目添加到 CMAT 末尾；否则，新条目插入到槽位 i（i>0），并按需要递增后续条目的索引。 范围（range） 标记是必需的，且必须最后指定。

默认情况下，只考虑力学接触。

条目中的信息由以下关键字指定。

inheritance s b ...

接触模型属性 s 的继承被 设为 b。

mechanical

适用于力学接触。

method 方法名（sm ）<sa a> ...

接触模型方法 方法名（sm） 及其特定的参数名与取值列表 被注册到该 CMAT 条目，并将在创建接触时调用。

model keyword

指定接触模型。内置力学接触模型的列表见 “内置接触模型（Built-in Contact Models）”一节。用户也可以实现自定义接触模型 （更多信息见“用户自定义接触模型（User-Defined Contact Models）”），并将其注册到 CMAT 中。

arrlinear

指定 黏附滚动阻力线性模型（Adhesive Rolling Resistance Linear Model） 接触模型。

burger

指定 Burger 模型（Burger’s Model） 接触模型。

fish

指定 FISH 模型（FISH Model） 接触模型。

flatjoint

指定 平节理模型（Flat-Joint Model） 接触模型。

hertz

指定 Hertz 模型（Hertz Model） 接触模型。

hysteretic

指定 滞回模型（Hysteretic Model） 接触模型。

linear

指定 线性模型（Linear Model） 接触模型。

linearcbond

指定 线性接触粘结模型（Linear Contact Bond Model） 接触模型。

linearpbond

指定 线性平行粘结模型（Linear Parallel Bond Model） 接触模型。

null

指定 空模型（Null Model） 接触模型。

rrlinear

指定 滚动阻力线性模型（Rolling Resistance Linear Model） 接触模型。

smoothjoint

指定 光滑节理模型（Smooth-Joint Model） 接触模型。

softbond

指定 软粘结模型（Soft-Bond Model） 接触模型。

property s a<inheritance b > ...

名为 s 的接触模型属性被设为 a。若指定了 inheritance 关键字， 则该属性的继承被设为 b。

proximity 检测距离（fd ）

检测距离设为 检测距离（fd）。

thermal

适用于热学接触。
