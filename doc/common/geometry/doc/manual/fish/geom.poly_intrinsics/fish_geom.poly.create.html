geom.poly.create

语法

p = geom.poly.create(g)

创建多边形。新建的多边形没有边，因此处于无效状态。在多边形变为有效状态之前，可用 向多边形添加边（geom.poly.add.edge） 或 通过添加节点添加边（geom.poly.add.node） 添加边。

返回值：p - 多边形指针
参数：g - 几何集合指针
