geom.set.raydist

语法

f := geom.set.raydist(g,vpos,vray)

获取从某点沿射线到该集合的距离。

注意所用算法假定会用同一射线方向计算许多不同位置来优化。每次使用新射线方向都会带来显著开销，量级为集合中多边形的数量。请据此优化 FISH 函数。

返回值：

f - 从 位置矢量（vpos） 沿 射线方向（vray） 到该集合的距离。
参数：

g - 几何集合指针

位置矢量（vpos） - 三维向量位置

射线方向（vray） - 要投射的方向
