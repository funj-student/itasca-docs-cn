geom.edge.create

语法

e = geom.edge.create(g,n1,n2)

创建边。节点可用其 ID 或节点指针指定。节点必须已存在。

返回值：

e - 边指针
参数：

g - 几何集合指针

n1 - 节点 1 的 ID 或节点指针

n2 - 节点 2 的 ID 或节点指针
