geometry refine 命令

语法

geometry refine <i > <set s > <range>

把几何集合中的三角形或四边形多边形细化为更小的版本。

对几何数据执行非常简单的细化。集合中每个三角形通过在各边中点增加新节点而替换为四个更小的三角形。每个四边形通过在各边中点增加新节点并在形心增加一个节点而替换为四个更小的四边形。

可选索引 i 允许指定多级细化。默认级数为 1。若指定多于一级，则递归进行细化。一次最多只能应用 4 级——即便如此也可能很快产生极大量的多边形。

若未给出 set 关键字，则使用当前集合。
