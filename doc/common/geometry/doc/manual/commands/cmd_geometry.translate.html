geometry translate 命令

语法

geometry translate v <keyword ...> <range>

平移节点。节点位置按 v 平移，可选范围作用于节点。若未给出 set 关键字，则使用当前集合。

set s

指定几何集合。

tolerance 英尺（ft ）

<tolerance 英尺（ft）> 选项提供节点合并容差。默认容差为 1.0e-8 乘以该集合中所有节点位置的最大范围尺寸。
