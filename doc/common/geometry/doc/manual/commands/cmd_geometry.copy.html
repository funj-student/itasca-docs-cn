geometry copy 命令

语法

geometry copy <source s1 > <target s2 > keyword ... <range>

主要关键字：

edges    分组（group）    nodes    多边形（polygons）

复制几何数据。源集合 s1（若未指定则为当前默认集合）中的所有几何数据被复制到目标几何集合 s2。若目标集合不存在则创建它。可用可选范围过滤哪些几何对象被包含在复制中。默认复制范围内所有节点、边与多边形，除非用关键字限制要复制的类型。

edges

若指定，则只复制边与从属节点。

group s <keyword>

所有被复制的对象都被赋予组名 s。组逻辑的用法见 组（Groups）。默认情况下组名被加入槽位 默认（Default）。

add

把 s 赋给下一个可用槽位。此处使用槽位 默认（Default）。

slot 槽位（slot ）

把组槽位 槽位（slot） 设为 s。默认使用槽位 默认（Default）。

nodes

若指定，则只复制节点。

polygons

若指定，则只复制多边形及从属边和节点。
