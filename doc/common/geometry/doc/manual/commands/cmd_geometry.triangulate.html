geometry triangulate 命令

语法

geometry triangulate keyword ... <range>

主要关键字：

clean    set    目标集合（to-set）

对平面多边形做三角剖分。当前几何集合中的平面多边形被三角化。这对绘制带凹形的多边形可能有用。默认在当前集合中创建三角形多边形。见 to-set 关键字以把多边形输出到不同几何集合。

clean

删除已完成三角剖分的多边形。

set s

指定几何集合。

to-set s

把所生成的多边形放入名为 s 的集合。若该集合不存在则创建。
