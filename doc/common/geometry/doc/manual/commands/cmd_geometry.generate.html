geometry generate 命令

语法

geometry generate keyword ...

主要关键字：

长方体（box）    圆（circle）    圆锥（cone）    圆柱（cylinder）    圆盘（disk）    由边生成（from-edges）    由面生成（from-faces）    分组（group）    set    球体（sphere）

生成指定形状的对象。多边形在当前几何集合中创建；若指定可选 group 关键字，则组名应用于所生成的多边形。形状包括：box、cone、cylinder、disk 和 sphere。若未给出 set 关键字，则使用当前集合。

注意

group 关键字必须在任何附加关键字之前给出。

box x 向最小值（fxmin ）x 向最大值（fxmax ）y 向最小值（fymin ）y 向最大值（fymax ）z 向最小值（fzmin ）z 向最大值（fzmax ）

生成封闭长方体。若只指定 x 向最小值（fxmin） 和 x 向最大值（fxmax），则该长方体为等边立方体。

circle keyword ... (2D only)

在二维中生成圆。

position v

圆心。

radius f

圆的半径。

resolution f

圆边的分辨率。默认 f = 0.1。

cone keyword ... (3D only)

在三维中生成圆锥。可生成圆锥或截锥（即切去锥尖的圆锥，若无端盖则形似漏斗）。

axis v3

圆锥对称轴的方向，从基点出发指向正 z 方向（默认）。

base v3

圆锥底面（即底端中心）的位置，默认为原点。

cap 底部标志（bbottom ）<btop >

表示端盖的包含状态。若指定一个布尔值，则该状态同时作用于两个端盖。若指定两个布尔值，则第一个作用于底盖，第二个作用于顶盖。默认创建底盖。除非指定 顶面半径（fradtop） 且其非零，否则不创建顶盖。

height 圆锥高度（fheight ）

圆锥高度。即从底面位置到锥尖的距离；若为截锥，则为到顶端中心的距离。默认 圆锥高度（fheight） = 1。

radius 底面半径（fradbot ）<fradtop >

圆锥半径。默认 底面半径（fradbot） = 1.0 且 顶面半径（fradtop） = 0.0，表示创建圆锥。若 顶面半径（fradtop） > 0.0，则创建截锥（即切去锥尖的圆锥）。此时 底面半径（fradbot） 为底面处的底部半径，顶面半径（fradtop） 为截锥顶端在距底面位置沿对称轴 圆锥高度（fheight） 距离处的半径。

resolution 端边分辨率（fres ）

圆锥两端边缘的分辨率。端边数目设定为使边长小于 端边分辨率（fres） * 底面半径（fradbot）。若要生成 顶面半径（fradtop） > 0 的截锥，则端边长度小于 端边分辨率（fres） * min(底面半径（fradbot）, 顶面半径（fradtop）)。默认 端边分辨率（fres） = 0.1。

cylinder keyword ...

在三维中生成圆柱。

axis v3

圆柱对称轴的方向，从基点出发。

base v3

圆柱底面（即底端中心）的位置，默认为原点。

cap 底部标志（bbottom ）<btop >

表示端盖的包含状态。若指定一个布尔值，则该状态同时作用于两个端盖。若指定两个布尔值，则第一个作用于底盖，第二个作用于顶盖。默认创建两个端盖。

height 圆锥高度（fheight ）

圆柱高度。即从底面位置到顶端中心的距离。默认 圆锥高度（fheight） = 1。

radius 搜索半径（frad ）

圆柱半径，即从对称轴到侧面的距离。

resolution 端边分辨率（fres ）

圆柱两端边缘的分辨率。端边数目设定为使边长小于 端边分辨率（fres） * 搜索半径（frad）。默认 端边分辨率（fres） = 0.1。

disk keyword ...

在三维中生成圆盘。

dip Fisher倾角（fdip ）

圆盘倾角，单位为度，取值范围 [0,90]。倾角为自投影到 xy 平面上的倾向方向到圆盘表面、沿负 z 方向量测的角度。默认 Fisher倾角（fdip） = 0。

ddir 裂隙倾向值（fddir ）

圆盘倾向，单位为度，在 [0,360] 范围内自正 y 轴顺时针量测。默认 裂隙倾向值（fddir） = 0。

position v3

圆盘中心位置，默认为原点。

radius 搜索半径（frad ）

圆盘半径，默认为 1.0。

resolution 端边分辨率（fres ）

圆盘边缘的分辨率。圆盘边数设定为使边长小于 端边分辨率（fres） * 搜索半径（frad）。默认 端边分辨率（fres） = 0.1。

from-edges keyword ... <range>

通过拉伸范围内所有边生成多边形。这些边必须位于同一集合。所有匹配所给范围的边都被选中。

可用以下关键字：

extrude v

从给定边拉伸的方向与长度。默认值为 (0,0,1)。

segments i

拉伸方向被划分的段数。默认值为 1。

from-faces keyword ... <range>

由范围内所有网格单元面的列表生成多边形。默认只考虑力学表面。

可用以下关键字：

internal

内部面和外部面都会被考虑。

fluid

指定在确定表面时考虑流体本构模型的空状态。

group s <slot slot >

把组名赋给所创建的所有多边形。

mechanical

指定在确定表面时考虑力学本构模型的空状态。这是默认状态。若指定 thermal 或 fluid，则力学将被移除，除非同时也指定了它。

or

若给出多个 mechanical、thermal 或 fluid 实例，则默认行为要求它们全部为空才视为空网格单元。若给出该关键字，则只要其中任一为空即视为空网格单元。

split-nonplanar b

默认情况下，非平面的四边形面被拆分为两个三角形多边形。把 split-nonplanar 设为 假值（false） 后，多边形将保持为非平面四边形。请注意，非平面多边形在执行几何操作时可能导致错误。

thermal

指定在确定表面时考虑热学本构模型的空状态。

group s keyword ...

指定所创建多边形被赋予组名 s。组逻辑的用法见 组（Groups）。若未指定 slot 关键字，则组名被赋给槽位 默认（Default）。

slot 槽位（slot ）

把组槽位 槽位（slot） 设为 s。默认赋给槽位 默认（Default）。

set s

指定几何集合。

sphere keyword ...

在三维中生成闭合球面。球面通过对二十面体（即由 20 个相同等边三角形构成的球）进行细化生成，使边长小于 resolution 关键字所定义的长度。

position v3

球心位置，默认为原点。

radius 搜索半径（frad ）

球半径，默认为 1.0。

resolution 端边分辨率（fres ）

边的分辨率。边数设定为使边长小于 端边分辨率（fres） * 搜索半径（frad）。默认 端边分辨率（fres） = 0.1。
