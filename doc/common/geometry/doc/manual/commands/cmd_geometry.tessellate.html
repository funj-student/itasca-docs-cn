geometry tessellate 命令

语法

geometry tessellate keyword ... <range>

主要关键字：

convex-hull    delaunay    set    起始集合（start-set）    目标集合（to-set）    voronoi

对节点做镶嵌。用 Qhull（Qhull 官网（http://www.qhull.org））软件包在当前几何集合中对节点做镶嵌。默认在当前集合中创建多边形。见 to-set 与 start-set 关键字以把多边形输出到不同几何集合。若未给出 set 关键字，则使用当前集合。

convex-hull

计算当前几何集合中各节点的凸包。该关键字与 start-set 不兼容。

delaunay

计算当前几何集合各节点的 Delaunay 单纯形。

set s

指定几何集合。

start-set s

每个 Delaunay 单纯形或 Voronoi 区域被放入单独的集合。每个集合名由 s 与该集合 ID 拼接而成（ID 附于 s 之后）。例如，ID = 13 且 s = 示例集合名 con（con） 的集合名为 示例集合名 con13（con13）。该关键字不能与 convexhull 关键字一起使用。

to-set s

把所生成的多边形放入名为 s 的集合。若该集合不存在则创建。

voronoi

计算当前几何集合各节点的 Voronoi 区域。

注意

生成输出时跳过含无穷远点的 Voronoi 区域。
