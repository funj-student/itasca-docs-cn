geometry paint-extra 命令

语法

geometry paint-extra i keyword ... <range>

主要关键字：

acceleration    acceleration-x    acceleration-y    acceleration-z    condition    convergence    density    流体密度（density-fluid）    displacement    displacement-x    displacement-y    displacement-z    extra    流体体积模量（fluid-bulk-modulus）    流体比奥模量（fluid-biot-modulus）    乘数（multiplier）    pore-pressure    property    property-fluid    property-thermal    ratio-local    目标力比（ratio-target）    saturation    set    strain-increment    应变增量 xx 分量（strain-increment-xx）    应变增量 xy 分量（strain-increment-xy）    应变增量 xz 分量（strain-increment-xz）    应变增量 yy 分量（strain-increment-yy）    应变增量 yz 分量（strain-increment-yz）    应变增量 zz 分量（strain-increment-zz）    strain-rate    应变速率 xx 分量（strain-rate-xx）    应变速率 xy 分量（strain-rate-xy）    应变速率 xz 分量（strain-rate-xz）    应变速率 yy 分量（strain-rate-yy）    应变速率 yz 分量（strain-rate-yz）    应变速率 zz 分量（strain-rate-zz）    应力（stress）    stress-xx    stress-xy    stress-xz    stress-yy    yz 向应力（stress-yz）    stress-zz    stress-effective    有效应力 xx 分量（stress-effective-xx）    有效应力 xy 分量（stress-effective-xy）    有效应力 xz 分量（stress-effective-xz）    有效应力 yy 分量（stress-effective-yy）    有效应力 yz 分量（stress-effective-yz）    有效应力 zz 分量（stress-effective-zz）    应力强度比（stress-strength-ratio）    stress-effective    温度（temperature）    timestep-dynamic    unbalanced-force    unbalanced-force-x    unbalanced-force-y    unbalanced-force-z    velocity    velocity-x    velocity-y    velocity-z

从网格单元场“绘制”标量值。该值被绘制到当前几何集合中的节点上。各值被放入每个节点的额外变量索引 i。范围选择几何集合中要绘制的节点。

若取值为基于网格点的量，则用网格单元内的加权函数计算节点位置处的取值。

若取值为基于网格单元的量，则由曲线拟合算法外推到节点位置确定。所用算法可在下列 [zonefieldoptions] 中指定。默认情况下，值在网格单元内视为常数。

注意若“着色”需求是临时的（即仅为可视化），可在绘图时于几何绘图项上完成——这可绕过该命令及其在网格点存储场值所需开销。若未给出 set 关键字，则使用当前集合。CS：此处应链接到描述该做法的主题

acceleration [zonefieldoptions]

在网格点处绘制加速度大小（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用）。

acceleration-x [zonefieldoptions]

在网格点处绘制 x 向加速度（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用）。

acceleration-y [zonefieldoptions]

在网格点处绘制 y 向加速度（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用）。

acceleration-z [zonefieldoptions]

在网格点处绘制 z 向加速度（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用）。

condition [zonefieldoptions]

绘制网格单元变形严重程度的度量。[紧急：CS：此处链接所需内容似乎需要加入文档集：指向命令参考第 1.1.5 节内容所在位置的链接

convergence [zonefieldoptions]

绘制网格单元收敛值。

density [zonefieldoptions]

绘制网格单元的密度。

density-fluid [zonefieldoptions]

绘制流体密度。

displacement [zonefieldoptions]

绘制网格点处的位移大小。

displacement-x [zonefieldoptions]

绘制网格点处的 x 向位移。

displacement-y [zonefieldoptions]

绘制网格点处的 y 向位移。

displacement-z [zonefieldoptions]

绘制网格点处的 z 向位移。

extra [zonefieldoptions]
绘制额外变量取值。所用额外变量索引默认为 1，可用 index 修饰符关键字更改。该值默认取自网格单元额外变量，但可用 source 修饰符关键字指定。该值默认按标量浮点类型处理，但可用 type 修饰符关键字指定。
factor-of-safety [zonehistoryblock]

该网格点所能保持稳定的最大安全系数。仅在完成 设置安全系数分析参数（model factor-of-safety） 计算后可用。velocity-limit 关键字用于指定速度大小，超过该值的网格点在给定安全系数下视为不稳定。

fluid-bulk-modulus [zonefieldoptions]

按流体体积模量绘制网格单元。

fluid-biot-modulus [zonefieldoptions]

按流体 Biot 模量绘制网格单元。

multiplier [zonefieldoptions]

绘制网格单元乘子。

pore-pressure [zonefieldoptions]

绘制网格单元中的孔隙压力。默认显示网格单元平均孔隙压力，但可用 source 修饰关键字指定网格点压力。

property [zonefieldoptions]

绘制网格单元力学本构模型的某个性质。性质名必须用 name 关键字修饰符指定。默认假定该性质为浮点标量，但可用 type 修饰符关键字指定。

property-fluid [zonefieldoptions]

绘制网格单元流体本构模型的某个性质。性质名必须用 name 关键字修饰符指定。默认假定该性质为浮点标量，但可用 type 修饰符关键字指定。

property-thermal [zonefieldoptions]

绘制网格单元热学本构模型的某个性质。性质名必须用 name 关键字修饰符指定。默认假定该性质为浮点标量，但可用 type 修饰符关键字指定。

ratio-local [zonefieldoptions]

在各网格点处绘制局部不平衡力比。与所有结果一样，可用 :lkwd:“log” 关键字修饰符改为显示该值的对数。

ratio-target [zonefieldoptions]

在各网格点处绘制目标不平衡力比。与所有结果一样，可用 :lkwd:“log” 关键字修饰符改为显示该值的对数。

saturation [zonefieldoptions]

在网格点处绘制饱和度（仅在已指定 配置流体计算模式（model configure fluid） 时可用）。

set s

指定几何集合。

strain-increment [zonefieldoptions]

绘制网格单元的应变增量张量，该张量由当前位移场确定。用 quantity 关键字指定从张量中提取哪个标量值。

strain-increment-xx [zonefieldoptions]

绘制 xx 应变增量。

strain-increment-xy [zonefieldoptions]

绘制 xy 应变增量。

strain-increment-xz [zonefieldoptions]

绘制 xz 应变增量。

strain-increment-yy [zonefieldoptions]

绘制 yy 应变增量。

strain-increment-yz [zonefieldoptions]

绘制 yz 应变增量。

strain-increment-zz [zonefieldoptions]

绘制 zz 应变增量。

strain-rate [zonefieldoptions]

绘制网格单元的应变率张量，该张量由当前速度场确定。用 quantity 关键字指定从张量中提取哪个标量值。

strain-rate-xx [zonefieldoptions]

绘制 xx 应变率。

strain-rate-xy [zonefieldoptions]

绘制 xy 应变率。

strain-rate-xz [zonefieldoptions]

绘制 xz 应变率。

strain-rate-yy [zonefieldoptions]

绘制 yy 应变率。

strain-rate-yz [zonefieldoptions]

绘制 yz 应变率。

strain-rate-zz [zonefieldoptions]

绘制 zz 应变率。

stress [zonefieldoptions]

绘制网格单元的应力张量，该张量由子网格单元应力的加权平均确定。用 quantity 关键字指定从张量中提取哪个标量值。

stress-xx [zonefieldoptions]

绘制网格单元的 stress-xx，由子网格单元应力的加权平均值确定。

stress-xy [zonefieldoptions]

绘制网格单元的 stress-xy，由子网格单元应力的加权平均值确定。

stress-xz [zonefieldoptions]

绘制网格单元的 stress-xz，由子网格单元应力的加权平均值确定。

stress-yy [zonefieldoptions]

绘制网格单元的 stress-yy，由子网格单元应力的加权平均值确定。

stress-yz [zonefieldoptions]

绘制网格单元的 stress-yz，由子网格单元应力的加权平均值确定。

stress-zz [zonefieldoptions]

绘制网格单元的 stress-zz，由子网格单元应力的加权平均值确定。

stress-effective [zonefieldoptions]

绘制网格单元的有效应力张量，该张量由子网格单元有效应力的加权平均确定。用 quantity 关键字指定从张量中提取哪个标量值。

stress-effective-xx [zonefieldoptions]

绘制网格单元的有效 stress-xx，由子网格单元应力的加权平均值确定。

stress-effective-xy [zonefieldoptions]

绘制网格单元的有效 stress-xy，由子网格单元应力的加权平均值确定。

stress-effective-xz [zonefieldoptions]

绘制网格单元的有效 stress-xz，由子网格单元有效应力的加权平均值确定。

stress-effective-yy [zonefieldoptions]

绘制网格单元的有效 stress-yy，由子网格单元有效应力的加权平均值确定。

stress-effective-yz [zonefieldoptions]

绘制网格单元的有效 stress-yz，由子网格单元有效应力的加权平均值确定。

stress-effective-zz [zonefieldoptions]

绘制网格单元的有效 stress-zz，由子网格单元有效应力的加权平均值确定。

stress-strength-ratio [zonefieldoptions]

绘制网格单元当前应力与其破坏面之比，破坏面由当前网格单元本构模型确定。并非所有本构模型都支持该计算。若不支持，返回值将为 10。返回值通常以 10 为上限。

stress-effective [zonefieldoptions]

绘制网格单元的有效应力张量，该张量由子网格单元应力加权平均值减去网格单元平均孔隙压力确定。用 quantity 关键字指定从张量中提取哪个标量值。

temperature [zonefieldoptions]

绘制网格点处的温度。可用 source 修饰关键字指定改用基于网格单元的温度。

timestep-dynamic [zonefieldoptions]

绘制该网格点的局部临界动力时步。（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用）。

unbalanced-force [zonefieldoptions]

绘制网格点处的不平衡力大小。

unbalanced-force-x [zonefieldoptions]

绘制网格点处的 x 向不平衡力。

unbalanced-force-y [zonefieldoptions]

绘制网格点处的 y 向不平衡力。

unbalanced-force-z [zonefieldoptions]

绘制网格点处的 z 向不平衡力。

velocity [zonefieldoptions]

绘制网格点处的速度大小。

velocity-x [zonefieldoptions]

绘制网格点处的 x 向速度。

velocity-y [zonefieldoptions]

绘制网格点处的 y 向速度。

velocity-z [zonefieldoptions]

绘制网格点处的 z 向速度。

component keyword

该关键字用于选择从矢量类型的值（如速度或位移）中提取哪个标量分量。若值类型不是矢量，则忽略该设置。可用的选项有：

x

获取向量的 x 分量。

y

获取向量的 y 分量

z

获取向量的 z 分量

magnitude

获取向量的模。

index i

对于需要索引的关键字（最典型的是 extra），此参数指定应使用的索引。默认值为 1。

gravity b

若为 开启（on），则返回的施加力中包含重力。默认值为 关闭（off）。

label s

为历史记录赋予标签（用于打印与绘图）。

log b

若为 开启（on），则返回的数值为原始值绝对值的以 10 为底的对数。默认值为 关闭（off）。

method

该关键字指定用于将基于网格单元的量插值到空间任意位置（包括网格点位置）的计算方法。

constant

假定数值在网格单元内部为常数。这是默认选项。位于网格点处或网格单元边界上的值将选取一个相邻网格单元来计算。

average

该方式使用与该网格点相连的所有网格单元的体积加权平均值。

inverse-distance-weight

该方法使用该点附近至多 32 个网格单元的加权平均值。权重由网格单元形心到指定点的距离的幂次确定。

power f

指定用于加权取值的距离幂次。默认幂次为 3.0。

radius-ratio f

指定所选网格单元到该点的最大距离与用于计算加权值的比率之比。距离超过该值的网格单元被折减。默认值为 0.75。

polynomial <tolerance f >

使用基于该点附近网格单元的多项式函数拟合。检测并剔除退化的自由度。可选 tolerance 标志可用于改变检测退化所用的数值。默认值为 1e-7。

name s

某些关键字（最典型的是 property）需要给出名称值才能完整指定。该名称决定所提取的具体属性名。

null

指定用于忽略网格单元取值的判据。默认忽略 mechanical 空网格单元。

fluid b

若将该选项设为 开启（on），则流体本构模型为空的网格单元也会被忽略。

mechanical b

若将该选项设为 开启（on），则忽略力学本构模型为空的网格单元（这是默认设置）。

thermal b

若将该选项设为 开启（on），则忽略热学本构模型为空的网格单元。

quantity keyword

该关键字用于选择从对称张量类型的值（如应力或应变）中提取哪个标量分量。若值类型不是张量，则忽略该设置。可用的选项有：

intermediate

获取中间主应力。

maximum

获取主应力的最大（最正）值。[CS：需要在文档中补充后才能 PFC 中生效] 注意在 -flac3d- 中 ref-压应力为负 <stresssignconventions>-。

mean

获取平均压力值，定义为张量的迹除以 3。对于应力，这通常称为压力。

minimum

获取主应力的最小（最负）值。[CS：需要在文档中补充后才能 PFC 中生效] 注意在 -flac3d- 中 ref-压应力为负 <stresssignconventions>-。

norm

获取应变率的范数。[CS：同样，需要在 FLAC3D 中提供相应文档才能在 PFC 中生效]；见 ref-sec_zonefielddatanames- 中的公式。

octahedral

获取八面体应力。[CS：同样，需要在 FLAC3D 中提供相应文档才能在 PFC 中生效]；见 ref-sec-zonefielddatanames- 中的公式。

shear-maximum

获取最大剪应力。

total-measure

获取主空间中张量值到原点的距离。

volumetric

获取体积变化量，即迹。

von-mises

获取 Von Mises 度量。[CS：同样，需要在 FLAC3D 中提供相应文档才能在 PFC 中生效]；见 ref-sec_zonefielddatanames- 中的公式。

xx

获取张量的 xx 分量。

xy

获取张量的 xy 分量。

xz

获取张量的 xz 分量。

yy

获取张量的 yy 分量。

yz

获取张量的 yz 分量。

zz

获取张量的 zz 分量。

source keyword

某些关键字（如 extra 和 pore-pressure）既可从网格单元结构、也可从网格点结构提取。默认值为 gridpoint。

gridpoint

数值直接取自网格点。

zone

从网格单元中提取数值。

stress b

少数张量类型的 quantity 选项会根据该值是否被视为应力而具有不同行为。当该值来自 extra 之类的变量时，无法自动判定。此选项允许用户指定传入的张量值应按应力处理。

type keyword

某些情况下无法事先确定值的类型（标量、向量或张量）。例如额外变量可保存全部三种类型的值。该关键字可指定假定其为何种类型。若原值类型不匹配，则返回 0.0。

scalar

把类型设为标量浮点数。这是默认值。

vector

把类型设为 vector。

tensor

把类型设为 tensor。

velocity-limit f

指定用于判定对象在给定 factor-of-safety 值下是否稳定的速度限值。默认值为 1e-4。

注意

此命令仅适用于 FLAC3D and 3DEC.
