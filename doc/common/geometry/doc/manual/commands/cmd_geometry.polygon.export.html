geometry polygon export 命令

语法

geometry polygon export s <keyword ...> <range>

主要关键字：

binary    格式（format）    set

导出几何多边形数据。多边形（若格式支持还包括节点和边）被输出到名为 s 的文件。默认文件类型为 Itasca 几何格式，范围作用于多边形。若未给出 set 关键字，则使用当前集合。

binary

表示导出时应使用该文件格式的二进制版本。该选项对 DXF 导出无效。

format keyword

指定导出所用的文件格式。默认将根据文件扩展名选择。

dxf

AutoCAD DXF 格式，文件扩展名为 “.dxf”。

geometry

Itasca 几何格式，文件扩展名为 “.geom”。这是默认格式，详见 几何文本文件格式（Geometry Text File Format）。

stl

STL 文件格式 “.stl”。

set s

指定几何集合。
