geometry move-to 命令

语法

geometry move-to keyword ... <range>

移动节点。若提供范围，则把 <范围（range）> 内节点的位置分量（\(x\)、\(y\) 或 \(z\)）移动到值 f；若未提供范围则移动所有节点。若某节点的最终位置落在另一节点的某一容差范围内，则二者将被合并。

<tolerance 英尺（ft）> 选项提供节点合并容差。默认容差为 1.0e-8 乘以所有节点位置的最大范围尺寸。

若未给出 set 关键字，则使用当前集合。

set s

指定几何集合。

x f <tolerance ft >

设置该点的 \(x\) 分量。

y f <tolerance ft >

设置该点的 \(y\) 分量。

z f <tolerance ft >

设置该点的 \(z\) 分量。
