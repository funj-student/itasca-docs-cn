geometry assign-groups 命令

语法

geometry assign-groups keyword ... <range>

主要关键字：

数据（data）    结构单元（structure）    网格单元（zone）

该命令根据对象与几何集合的关系为其分配组名。组逻辑的用法见 组（Groups）。所有集合中的所有多边形都被赋予一个表面编号——在拓扑上相连的多边形被赋予相同编号。从每个对象的位置出发，沿 projection 关键字指定的方向投射射线。FLAC3D 将统计射线与各表面相交的次数，并据此分配组名。

例如，若未与任何表面相交，则分配组名 “No Intersections”。每种不同的相交组合被赋予一个大写字母。例如，与表面 2 相交一次、与表面 3 相交两次的对象可能被赋予字母 “D”。组名被分配给范围内的所有对象。

可用以下关键字选择要分配组名的对象类型：

data keyword

按下述方式根据位置为一组用户定义数据分配组名。

scalar [assignoptions]

用 \(Type Block\) 关键字为用户定义标量数据分配组。

tensor [assignoptions]

用 \(Type Block\) 关键字为用户定义张量数据分配组。

vector [assignoptions]

用 \(Type Block\) 关键字为用户定义向量数据分配组。

structure keyword

为结构数据（单元、节点或连接）分配组名。单元在其形心处检查。

beam [assignoptions]

用 \(Type Block\) 关键字为梁分配组。

cable [assignoptions]

用 \(Type Block\) 关键字为锚索分配组。

geogrid [assignoptions]

用 \(Type Block\) 关键字为土工格栅分配组。

liner [assignoptions]

用 \(Type Block\) 关键字为衬砌分配组。

link [assignoptions]

用 \(Type Block\) 关键字为连接分配组。

node [assignoptions]

用 \(Type Block\) 关键字为节点分配组。

pile [assignoptions]

用 \(Type Block\) 关键字为桩分配组。

shell [assignoptions]

用 \(Type Block\) 关键字为壳单元分配组。

zone <grid-point> [assignoptions]

用 \(Type Block\) 关键字把组赋予网格单元（若给出 grid-point 关键字则为网格点）。


组分配的通用选项块

可使用以下关键字来修饰命令：网格单元（zone）。标量（scalar）、张量（tensor） 和 vector。beam、cable、geogrid、衬砌（liner）、link、node、pile 和 shell。

projection v

指定从每个所考虑位置进行投影的方向。默认该方向为 (0,0,1)。

set s

指定要使用的集合名称。可指定多个集合名。默认使用当前几何集合。

slot s

指定组名将被赋入的槽位。若未指定，则槽位名为 ‘Default’。
