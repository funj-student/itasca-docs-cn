fracture.template.sizemin

语法

最大尺寸值（fsize） = fracture.template.sizemin(template)
fracture.template.sizemin(template) = 最大尺寸值（fsize）

获取/设置最小尺寸。裂隙尺寸定义为{二维中裂隙长度；三维中圆盘直径}。

注意

对已用于生成裂隙的模板不提供设置访问。

返回值：最大尺寸值（fsize） - 最小尺寸
接受：最大尺寸值（fsize） - 最小尺寸
参数：template - DFN 模板指针
