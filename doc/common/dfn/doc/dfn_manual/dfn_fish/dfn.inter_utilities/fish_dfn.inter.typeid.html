fracture.intersect.typeid

语法

接触类型ID（itype） = fracture.intersect.typeid

获取裂隙交点类型编号。类型 ID 可用于唯一标识裂隙交点 FISH 指针，并将其与任何其他类型的 FISH 指针区分开。

返回值：接触类型ID（itype） - 类型 ID 值
