fracture attribute 命令

语法

fracture attribute keyword ... <range>

主要关键字：

aperture    面积（area）    倾向（dip-direction）    diameter    倾角（dip）    长度（length）    position    position-x    position-y    position-z

修改裂隙属性。该命令是 初始化裂隙命令（fracture initialize） 命令的同义词。

注意

  • 若修改后的裂隙不能完全落在模型域内，则裂隙几何的修改将失败。
  • 裂隙属性是裂隙的特征（例如位置或尺寸）。它们 不同于裂隙性质（用 设置裂隙属性命令（fracture property） 命令赋值）， 后者是裂隙的表面性质，用于通过 设置裂隙接触模型命令（fracture contact-model） 命令填充接触模型属性。
aperture f

裂隙开度，其中 f ≥ 0。

area f (3D only)

裂隙面积，其中 f > 0。

dip-direction f (3D only)

倾向（度），从 \(y\) 轴正向顺时针量得，其中 f 的范围为 [0,360]。

diameter f (3D only)

圆盘状裂隙的直径，其中 f > 0。

dip f

倾角（度），其中 f 的范围为{二维中 [0,180]；三维中 [0,90]}。在二维中，倾角是 从 \(x\) 轴正向顺时针量得的角。在三维中，倾角是从投影到 \(xy\) 平面上的倾向 到裂隙面、沿 \(z\) 负向量得的角。

length f (2D only)

裂隙总长度，其中 f > 0。

position v

裂隙位置向量。

position-x f

裂隙位置（\(x\) 分量）。

position-y f

裂隙位置（\(y\) 分量）。

position-z f (3D only)

裂隙位置（\(z\) 分量）。

用法示例

下例说明如何使用 修改裂隙属性命令（fracture attribute） 命令 旋转所有裂隙（三维）。最终，中心位于层 \(z\in [-2;2]\) 内的所有裂隙具有相同方位。

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;修改默认模板
fracture template modify-default size-limits 0.5 5
;采用默认模板生成裂隙
fracture generate tolerance-box -4 4 -4 4 -4 4 fracture-count 1000
; 修改部分裂隙属性
fracture attribute aperture 1 dip 25 dip-direction 270 range position-z -2 2
program return
