fracture delete 命令

语法

fracture delete <dfn <s > ><range>

删除裂隙。若给出可选的 dfn 关键字，则删除 仅限于指定的 DFN。空 DFN 会被删除。若给出 dfn 关键字但未 指定字符串名称，则范围作用于 DFN，移除整个 DFN（即删除 DFN 中的所有裂隙）。

用法示例

下例说明如何使用 删除裂隙命令（fracture delete） 命令从裂隙中移除最大裂隙。

model new
model random 10000
model domain extent -5 5 
;范围定义
fish define mylarge(dummy,frac)
	mylarge=0
	if fracture.area(frac)>4
		mylarge = 1
	endif
end
;采用默认模板生成裂隙
fracture generate dfn 'first' fracture-count 400
;采用默认模板生成更多裂隙
fracture generate dfn 'second' fracture-count 200
;在范围中使用 by 关键字，删除第二个 DFN 的全部裂隙
fracture delete range name 'second' by dfn
;删除大裂隙
fracture delete range fish mylarge
program return
