fracture contact-model 命令

语法

fracture contact-model keyword ... <rangeof dfns>

主要关键字：

activate    应用分组（apply-groups）    应用属性（apply-properties）    deactivate    distance    install    模型（model）    type    use-aperture

通过裂隙赋接触模型。该命令仅适用于 PFC。为使 model 关键字指定的接触模型 能使用裂隙几何，该接触模型必须 具有与裂隙倾角对应的属性“dip”（三维中还须有与裂隙 倾向对应的“ddir”）。用 设置裂隙属性命令（fracture property） 命令赋给裂隙的属性 被提供给接触模型。这些属性是固定的，即它们不会 从相互接触片体或先前接触继承，必须由用户直接指定才能改变其值。使用接触模型继承逻辑来指定 裂隙中未指定的接触模型属性。

多条裂隙可能与同一个接触相交。为了唯一确定 合适的接触模型，对 DFN 和裂隙施加优势层级。若多条 裂隙与一个接触相交，则先考察来自 DFN 主导值最低的 DFN 的裂隙。 在这些裂隙中，主导值最低的裂隙被确定为 接触模型/属性赋值的合适裂隙。DFN 主导值通过 创建裂隙命令（fracture create）、生成裂隙命令（fracture generate） 和 导入裂隙（fracture import） 命令指定。

力学接触模型的列表见 PFC Help 中的 Contact Models 一节。在每个接触模型的文档中都有一个 Properties 表。其中包括：linear、线性接触黏结（linear contact bond）、线性平行黏结（linear parallel bond）、hertz、hysteretic、光滑节理（smooth joint） 和 平节理（flat joint） 属性表。

activate

当创建与指定范围内裂隙相交的新接触时，激活接触模型赋值。

apply-groups b

把裂隙组赋给接触。默认情况下 b = false。该关键字仅在安装接触模型时适用。

apply-properties b

对与指定范围内裂隙相交的接触模型应用属性。

deactivate

当创建与指定范围内裂隙相交的新接触时，停用接触模型赋值。这适用于所有先前已激活的实例，无论 所给范围如何。

distance f

把从裂隙上最近点到接触线的距离（用于识别接触模型赋值的接触）设为 f。默认值为 0.0。若指定 use-aperture 关键字，则裂隙开度优先于 f。

install

在范围内与裂隙相交的所有现有接触上安装指定接触模型。与裂隙相交的新接触不会自动被赋予该指定接触模型，除非同时指定 activate 关键字。

model s

命名要使用的接触模型（例如 linear、smoothjoint 等）。

type s

把安装限制在类型为 s 的接触上。

use-aperture

用各裂隙的开度作为距离判据，以确定进行接触模型赋值的接触。开度优先于 distance 关键字所给距离。

用法示例

下例说明如何使用 设置裂隙接触模型命令（fracture contact-model） 命令为所有与裂隙相交的接触安装 smoothjoint 接触模型。我们首先 创建球的立方集合，并用 cmat 命令安装默认接触模型。 随后生成裂隙，并为每条裂隙赋 kn、ks 和黏聚力属性。光滑节理接触模型被赋给每个与裂隙相交的接触。

model new
program warning off
model random 10001
model domain extent -5 5
cmat default model linearpbond property kn 1e5
ball generate cubic
ball attribute density 2500.0 damp 0.7
; 创建接触并指定 linearpbond 接触模型
clean
dfn generate nfrac 1000
fracture aperture log-normal 0.1 10
dfn property sj_kn 1e5 sj_ks 1e-4 sj_coh 0
; 安装 smoothjoint
fracture contact-model model smoothjoint install useaperture
program return
