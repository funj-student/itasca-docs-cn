fracture template modify-default 命令

语法

fracture template modify-default keyword

主要关键字：

倾向上下限（dip-direction-limits）    倾角上下限（dip-limits）    方位（orientation）    position    size    尺寸上下限（size-limits）

修改默认裂隙生成模板。裂隙生成模板是一组 统计参数，用于以 生成裂隙命令（fracture generate） 命令生成裂隙。若未 指定裂隙生成模板，则使用默认模板。执行 新建模型（model new） 时， 默认裂隙生成模板被赋予以下属性：1) 裂隙位置均匀；2) 裂隙方位均匀（二维中倾角 0 到 180 度；三维中倾角 0 到 90 度、倾向 0 到 360 度）；3) 裂隙尺寸服从指数为 4 的负 幂律分布；4) 最小裂隙尺寸为 1.0，最大裂隙 尺寸为 ∞。默认裂隙生成模板随模型状态保存， 且 DFN 不能与默认模板关联。可应用以下关键字：

dip-direction-limits 最小开度（fmin ）最大开度（fmax ）(3D only)

指定裂隙倾向必须落在 [最小开度（fmin）, 最大开度（fmax）] 度范围内。默认情况下，最小开度（fmin） = 0，最大开度（fmax） = 360。

dip-limits 最小开度（fmin ）最大开度（fmax ）

指定裂隙倾角必须落在 [最小开度（fmin）, 最大开度（fmax）] 度范围内。默认情况下， {二维中 最小开度（fmin） = 0 且 最大开度（fmax） = 180；三维中 最小开度（fmin） = 0 且 最大开度（fmax） = 90}。

orientation s a1...an

用参数 \(a_{1}...a_{n}\) 定义裂隙方位的生成规则。 支持 s 的以下选项：

  • 自助重采样（bootstrapped）：倾角{及三维中的倾向}从文件中自举抽取。必须 给出一个参数：保存离散取值分布的文件名。该文件 符合 DFN 相关文件格式（DFN-Related File Formats） 中给出的自举分布文件格式。
  • DIPS文件分布（dips）（仅三维）：倾角和倾向从 DIPS 文件自举抽取。必须给出一个 参数：保存离散取值分布的文件名。该文件 符合 DFN 相关文件格式（DFN-Related File Formats） 中给出的 DIPS 文件格式。
  • FISH函数（fish）：使用 FISH函数（fish） 关键字从用户定义的 FISH 函数获取取值。函数名用 \(a_{1}\) 给出，函数参数（任意 个数）在函数名之后给出。该函数必须返回{二维中浮点值；三维中二维向量}。
  • Fisher分布（fisher）（仅三维）：倾角和倾向从 Fisher 分布中抽取。 需要三个附加参数：倾角、倾向和 \(\kappa\)。
  • gauss：倾角{及三维中的倾向}从高斯分布中抽取。在 二维中，需要两个附加参数，分别指定倾角分布的均值和标准差。 在三维中，需要四个附加参数：倾角分布的 均值和标准差，随后是倾向分布的均值和标准差。
  • 均匀分布（uniform）：倾角{及三维中的倾向}从均匀分布中抽取。 不能给出任何附加参数。

注意

在二维中，倾角是从 \(x\) 轴正向顺时针量得的角（度）。在三维中，倾角是从投影到 \(xy\) 平面上的倾向到裂隙面、沿 \(z\) 负向量得的角。三维中的倾向从 \(y\) 轴正向顺时针量得。

position s a1...an

用参数 定义裂隙位置的生成规则。 s 支持的选项有 均匀分布（uniform）、gauss、自助重采样（bootstrapped） 和 FISH函数（fish）。这些关键字的含义与 orientation 关键字相同，区别在于位置为{二维中二维向量；三维中三维向量}。因此，若指定 自助重采样（bootstrapped），则文件必须包含所需数量的值； 若指定 FISH函数（fish），则 FISH 函数必须返回正确维数的向量。 此外，若指定 gauss 关键字，则均值和标准差必须是向量。

size s a1...an

定义裂隙尺寸的分布。裂隙尺寸定义为{二维中裂隙 长度；三维中圆盘直径}。s 支持的选项有 均匀分布（uniform）、gauss、幂律分布（power-law）、自助重采样（bootstrapped） 和 FISH函数（fish）。 幂律分布（power-law） 说明符定义负幂律分布，需要一个 参数，即分布的指数， > 0。其余 s 选项与 orientation 描述中的规定相同，区别在于 返回值为浮点值。因此，gauss 说明符后只跟两个参数：自助重采样（bootstrapped） 文件必须遵循一维格式； FISH函数（fish） 函数必须返回单个值。

size-limits 最小开度（fmin ）最大开度（fmax ）

裂隙尺寸限值必须落在 [最小开度（fmin）, 最大开度（fmax）] 范围内。默认情况下， 最小开度（fmin） = 1.0，最大开度（fmax） = +∞。裂隙尺寸定义为{二维中 长度；三维中直径}。
