fracture generate 命令

语法

fracture generate keyword ...

主要关键字：

connectivity-threshold    dfn    DFN主导值（dfn-dominance）    FISH 停止函数（fish-stop）    裂隙数量（fracture-count）    生成盒（generation-box）    mass-density    修改（modify）    p10    percolation    template    容差盒（tolerance-box）

按统计描述生成裂隙。生成之前必须先指定模型域。生成{二维中的线段裂隙；三维中的圆盘状裂隙}。若未指定裂隙 生成模板（即用 创建裂隙模板命令（fracture template create） 命令定义的统计描述）， 则使用默认裂隙生成模板。默认裂隙模板 参数可用 修改裂隙模板默认值命令（fracture template modify-default） 命令修改。DFN 可与裂隙生成模板 关联，前提是未给出 modify 关键字且 模板不是默认模板。裂隙持续生成，直至满足指定的停止准则。 这些条件包括：

  • a target fracture number (fracture-count);
  • a target P10 (p10);
  • a target density (P21 in 2D; P32 in 3D) (mass-density);
  • a target percolation volume (percolation);
  • 位于连通性阈值（connectivity-threshold）的 DFN；以及
  • 用户定义判据（fish-stop）。

注意

指定的 DFN 必须不存在或为空。若未指定 DFN，则创建 使用下一个可用 ID 的 DFN，DFN 名称为 新建DFN名称（dfnXX），其中 XX 向（XX） 是 ID。

此外，可在每条裂隙生成后调用用户定义的 FISH 函数，以 修改该裂隙、跳过它，或添加/计算特定量（modify）。随后可用 修改裂隙属性命令（fracture attribute） 命令修改裂隙 特征，并用 设置裂隙属性命令（fracture property） 命令赋属性。

用于接触模型赋值的裂隙主导值（见 设置裂隙接触模型命令（fracture contact-model） 命令）按裂隙生成顺序赋值。

connectivity-threshold

生成在连通阈值处终止（即当可经由裂隙交线遍历空间区域所有维度的瞬间）。

box 盒体 x 向下限（fxl ）盒体 x 向上限（fxu ）盒体 y 向下限（fyl ）盒体 y 向上限（fyu ）盒体 z 向下限（fzl ）盒体 z 向上限（fzu ）(z-components are 3D only)

当可从指定盒体的每条边经由裂隙交线到达其他每条边时，生成立即终止。

geometry s1 <s2 >

当 DFN 连接到几何集 s1 的所有{二维中的边；三维中的多边形}时，生成终止。若给出 s2，则当 DFN 把几何集 s1 的至少一个{二维中的边；三维中的多边形}与几何集 s2 的至少一个{二维中的边；三维中的多边形}连通时，生成终止。

dfn s

指定 DFN 名称。该 DFN 必须为空或不存在。

dfn-dominance i

DFN 的主导值设为 i。当某个接触与来自不同 DFN 的多条裂隙相交时， 接触模型赋值期间会用到 DFN 主导值。DFN 主导值最低的 DFN 中的裂隙 将按其主导值进一步考察，以 赋合适的接触模型属性。

fish-stop s a1...an

若 FISH 函数 s（参数为 \(a_{1}...a_{n}\)） 返回非零整数，则终止生成。

fracture-count i

当生成的裂隙数为 i 时，生成终止。

generation-box x 向最小值（fxmin ）x 向最大值（fxmax ）y 向最小值（fymin ）y 向最大值（fymax ）z 向最小值（fzmin ）z 向最大值（fzmax ）(z-components are 3D only)

生成位置（即中心）位于该矩形生成区域内的裂隙。默认情况下 generation-box 设为模型域范围。

mass-density f

当 tolerance-box 中的裂隙密度{二维中为 P21；三维中为 P32}首次达到或超过 f 时，生成终止。

注意

使用修改函数会阻止 DFN 与底层 DFN 模板建立关联。

modify s a1...an

每生成一条裂隙后都会调用 FISH 函数 s。 s 的第一个参数填入裂隙指针；该 FISH 函数必须至少接受一个 参数。附加参数可按 \(a_{1}...a_{n}\) 指定。该 FISH 函数 可用于访问和/或修改裂隙参数。若该函数返回 字符串“remove”，则删除该裂隙并将其移出生成过程。

p10 f keyword ...

当沿指定扫描线（使用 begin 和 end）或沿若干扫描线（使用 geometry 关键字） 首次测得 P10 时，生成终止。

begin v

指定扫描线起点的位置。不能与 geometry 关键字一起给出。

end v

指定扫描线终点的位置。不能与 geometry 关键字一起给出。

geometry s

指定扫描线来自几何集中的边。当沿该几何集各边定义的扫描线集测得的平均 P10 首次达到或超过 f 时，生成终止。不能与 begin 和 end 关键字同时使用。

percolation 贯通阈值（fval ）

当 tolbox 中的裂隙渗流体积首次达到或超过 贯通阈值（fval） 时，生成终止。

template s

按指定模板生成裂隙。若未提供裂隙生成模板，则使用默认裂隙生成模板。

tolerance-box x 向最小值（fxmin ）x 向最大值（fxmax ）y 向最小值（fymin ）y 向最大值（fymax ）z 向最小值（fzmin ）z 向最大值（fzmax ）(z-components are 3D only)

容差盒用于截断裂隙。该盒可大于或小于生成盒，但不得超过模型域范围。若这些条件之一代表所指定的终止判据，则它用于密度或渗流计算。若未指定容差盒，则使用生成盒（generation-box）（若生成盒超出模型域则用模型域）。

用法示例

下例说明如何使用 生成裂隙命令（fracture generate） 命令生成分层裂隙网络， 其中裂隙密度用不同数据标定。 所有裂隙遵循相同的统计规律（即尺寸从指数为 3、截断于 0.5 和 100 之间的幂律分布中抽取）， 方位均匀、位置均匀。 裂隙位置在比所考虑层更大的体积中生成，以避免有限尺寸效应。

在第一层中，当裂隙密度等于 1 时停止生成。 在第二层中，当沿给定直线的裂隙频率等于 0.5 时停止。 最后，在第三层中，当给定露头上裂隙迹线的二维密度等于 0.5 时停止。

model new
model random 10000
model domain extent -5 5
;创建表示露头的几何集 'that'
geometry set 'outcrop'
geometry polygon create by-positions (-5,-5,3) (-5,5,3) (5,5,3) (5,-5,3)

;定义停止函数
fish define stop
   stop = 0
   outcrop = geom.set.find('outcrop')
   if fracture.geomp21(outcrop,dfn.find('example3'))>0.5
      stop = 1
   endif
end

;创建裂隙模板
fracture template create 'ex_temp' size power-law 3 size-limit 0.5 100
;采用模板生成裂隙，在达到指定裂隙面积密度时停止
fracture generate dfn 'example1' template 'ex_temp' ...
                  generation-box -8 8 -8 8 -8 1 ...
                  tolerance-box -5 5 -5 5 -5 -2 mass-density 1
;采用模板生成裂隙，在达到指定 p10 时停止
fracture generate dfn 'example2' template 'ex_temp' ...
                  generation-box -8 8 -8 8 -5 5 ...
                  tolerance-box -5 5 -5 5 -2 2 p10 0.5 ...
                  begin (-5,0,0) end (5,0,0)
;采用模板生成裂隙，根据 FISH 准则停止
fracture generate dfn 'example3' template 'ex_temp' ...
                  generation-box -8 8 -8 8 -1 8 ...
                  tolerance-box -5 5 -5 5 2 5 fish-stop stop
program return

下例说明如何使用 生成裂隙命令（fracture generate） 命令在连通阈值处生成 DFN，且裂隙不与给定钻孔相交（三维）。 生成过程中，通过使用 modify 关键字和 移除裂隙函数（remove_fracture） FISH 函数移除与钻孔相交的裂隙。这种生成方式可用于 在确定性地添加了与钻孔相交的裂隙之后。

model new
model random 10000
model domain extent -5.01 5.01
;创建表示露头的几何集 'that'
geometry set 'borehole'
geometry edge create by-position (0,0,-4) (0,0,4)
;定义停止函数
fish define remove_fracture(frac)
   remove_fracture = '0'
   borehole = geom.set.find('borehole')
   if fracture.gintersect(frac,borehole) then
      remove_fracture = 'remove'
   endif
end

;创建裂隙模板
fracture template create 'ex_temp' size power-law 3 size-limits 0.5 100
;采用模板生成裂隙，直至达到连通阈值
fracture generate dfn 'example' template 'ex_temp' ...
                  generation-box -8 8 -8 8 -8 8 ...
                  connectivity-threshold box -5 5 -5 5 -5 5 ...
                  modify remove_fracture
program return
