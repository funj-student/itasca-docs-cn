fracture property 命令

语法

fracture property s a<s1 a1...> <range>

赋裂隙表面性质。值 a 被赋给名称为 s 的表面性质。这些性质可与 设置裂隙接触模型命令（fracture contact-model） 命令配合， 用于设置接触模型属性。

注意

裂隙性质是裂隙的表面性质，用于通过 设置裂隙接触模型命令（fracture contact-model） 命令填充 接触模型属性。它们不同于 裂隙属性（用 修改裂隙属性命令（fracture attribute） 命令修改），后者是裂隙的 特征，例如位置或尺寸。

力学接触模型的列表见 PFC Help 中的 Contact Models 一节。在每个接触模型的文档中都有一个 Properties 表。其中包括：linear、线性接触黏结（linear contact bond）、线性平行黏结（linear parallel bond）、hertz、hysteretic、光滑节理（smooth joint） 和 平节理（flat joint） 属性表。

用法示例

下例说明如何使用 设置裂隙属性命令（fracture property） 命令 为倾角小于 45° 和大于 45° 的裂隙赋不同性质。 若这些性质名称与某接触模型的属性一致，则随后可直接按所给属性安装该模型。

model new
model random 10000
model domain extent -5 5
;范围定义
fish define angle(dummy,frac)
	angle=0
	if fracture.dip(frac)>45
		angle = 1
	endif
end
;采用默认模板生成裂隙
fracture generate dfn 'example' fracture-count 500
;指定参数
fracture property 'jcohesion' 0.5 'sj_kn' 100e9 'sj_ks' 10e9 range fish angle
fracture property 'jcohesion' 0.5 'sj_kn' 10e9 'sj_ks' 1e9 range fish angle not
program return
