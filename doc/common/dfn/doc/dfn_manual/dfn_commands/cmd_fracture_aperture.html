fracture aperture 命令

语法

fracture aperture keyword ... <range>

主要关键字：

常数（constant）    dfn    FISH函数（fish）    gauss    limits    对数正态（log-normal）    幂律分布（power-law）    均匀分布（uniform）

为裂隙赋开度。开度可用于接触模型赋值（用 设置裂隙接触模型命令（fracture contact-model） 命令）、连通距离计算（用 计算裂隙连通性命令（fracture connectivity） 命令）以及 DFN 范围元素。

constant f

开度为常数，f>0。

dfn s

只对具有所给名称的 DFN 分配开度。

fish s a1...an

开度通过用户定义的 FISH 函数 s 赋值，参数为 。该函数对每条裂隙调用，必须返回与裂隙开度对应的浮点值。

gauss 开度均值（fm ）开度标准差（fs ）

从均值为 开度均值（fm）、标准差为 开度标准差（fs） 的高斯分布中随机抽取开度。

limits 最小开度（fmin ）最大开度（fmax ）

开度落在 [最小开度（fmin）, 最大开度（fmax）] 范围内，其中 最大开度（fmax） 大于或 等于 最小开度（fmin）。默认情况下，最小开度（fmin） = 0，最大开度（fmax） = +∞。

log-normal 开度均值（fm ）开度标准差（fs ）

从均值为 开度均值（fm）、标准差为 开度标准差（fs） 的对数正态分布中随机抽取开度。

power-law f

从指数为 f 的负幂律分布中随机抽取开度。

uniform

按 limit 关键字所定义的上下限，从均匀分布中随机抽取开度。

用法示例

下例说明如何使用 设置裂隙开度命令（fracture aperture） 命令，为裂隙赋以从多种分布中抽取的开度。

model new
model random 10000
model domain extent -5 5 
;采用默认模板生成裂隙
fracture generate fracture-count 1000
;设置缝宽
fracture aperture log-normal 0.1 10                      
program return
