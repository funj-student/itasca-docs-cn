命令

对离散裂隙网络（DFN）进行操作。DFN 是线段的集合（平面、凸多边形和/或圆盘）， 在二维（三维）中。DFN 中的每个元素称为一条裂隙。裂隙保存性质列表，也可保存额外变量 并属于组。性质可为任意类型，可按需赋值。DFN 作为裂隙集合，可通过 DFN 模板（一组描述裂隙分布的统计参数）生成。裂隙之间的交线 可计算并查询，用于裂隙连通性分析。

注意

  • 所有 DFN 裂隙都必须创建在模型域内，模型域由 设置模型域命令（model domain） 命令指定。
  • 裂隙性质和额外变量在从属性文件导入时被转换为浮点数或整数，尽管导出时按实际格式输出。因此，可以在模型状态（SAV）文件中保存/恢复裂隙的一般性质或额外变量，但不能从属性文件导入这些值。Itasca DFN 数据文件格式在“DFN 相关文件格式（DFN-Related File Formats）”中规定，同时还规定了用于为裂隙赋性质的属性文件格式。
