fracture create 命令

语法

fracture create keyword ...

主要关键字：

dfn    DFN主导值（dfn-dominance）    倾角（dip）    倾向（dip-direction）    优势度（dominance）    分组（group）    intersection-set    position    size    skip-errors

创建一条确定性裂隙。

注意

  • 在添加裂隙之前必须先指定模型域。
  • 若裂隙超出模型域，则会在模型域边界处被裁剪。

若 dfn 关键字指定的 DFN 不存在，则新建一个 DFN。若未指定 DFN，则新建一个 DFN， 使用下一个可用 ID 和名称 新建DFN名称（dfnXX），其中 XX 向（XX） 是 DFN ID。该命令 创建{二维中为线段裂隙；三维中为圆盘裂隙}。该命令与 生成裂隙命令（fracture generate） 命令不同，后者基于裂隙的随机描述生成裂隙。

dfn s

把裂隙添加到名称为 s 的 DFN。

dfn-dominance i

若新建 DFN，则其主导值设为 i，其中 i 大于 1。当某个接触与来自不同 DFN 的多条 裂隙相交时，接触模型赋值期间会用到该主导值。DFN 主导值最低的 DFN 中的裂隙将 按其各自主导值进一步考察，以赋合适的接触 模型属性。若未指定，则使用下一个可用的主导值。详见 设置裂隙接触模型命令（fracture contact-model） 命令。

dip f

裂隙倾角（度），其中 f 的范围为{二维中 [0,180]；三维中 [0,90]}。在二维中，倾角是从 \(x\) 轴正向顺时针量得的角。在三维中，倾角是从投影到 \(xy\) 平面上的倾向到裂隙面、沿 \(z\) 负向量得的角。默认情况下，f = 0。

dip-direction f (3D only)

裂隙倾向（度），从 \(y\) 轴正向顺时针量得，其中 f 的范围为 [0,360]。默认情况下，f 为 0.0。

dominance i

指定裂隙的主导值，其中 i 大于 1。若未指定，则 使用下一个可用的裂隙主导值。若某个接触与来自同一 DFN 的多条裂隙 相交，则使用主导值最低的裂隙来赋 合适的接触模型和属性。详见 设置裂隙接触模型命令（fracture contact-model） 命令。

group s <slot slot >

把组名 s 赋给该裂隙，并可选地把槽位设为 槽位（slot）。

intersection-set s

计算新创建裂隙的裂隙交线，并添加到 名称为 s 的交线集。

position v

裂隙中心位置。除非指定 skip-errors 关键字，否则裂隙位置必须落在模型域内。默认位置为原点。

size f

裂隙尺寸。默认值为 1。尺寸为{二维中裂隙长度；三维中圆盘 直径}。

skip-errors

表示若裂隙创建失败，该命令将返回警告而非错误。给出该关键字时，裂隙位置不要求落在 模型域内。

用法示例

下例说明如何使用 创建裂隙命令（fracture create） 命令 在新的 DFN 中创建单条裂隙（三维）。

model new
model domain extent -5 5 -5 5 -5 5 
;创建确定性裂隙
fracture create                         ...
            position        (1.,1.,1.)  ...
            dip             45.0        ...
            dip-direction   230.0       ...
            size            1.0         ...
            group           '5'         ...
            dfn             'newDFN'
program return
