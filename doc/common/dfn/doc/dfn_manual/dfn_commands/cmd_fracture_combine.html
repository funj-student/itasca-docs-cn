fracture combine 命令

语法

fracture combine keyword ... <range>

主要关键字：

角度（angle）    collapse    distance    merge

简化裂隙。裂隙按尺寸从大到小排序；从最大裂隙（称为参考裂隙）开始， 算法找出满足 以下 2 条判据的较小裂隙：

  • 参考裂隙与裂隙方位的差异小于所给角度（由 angle 关键字提供）。
  • 裂隙之间的距离（由最小裂隙中心与最大裂隙面之间的距离确定）小于所给距离（由 distance 关键字提供）。

注意

  • 使用 merge 关键字可能显著改变裂隙密度。请谨慎使用该关键字。
  • 使用 合并裂隙命令（fracture combine） 命令时，所有交线都会被删除。

满足这些判据时，较小裂隙被旋转到与参考裂隙相同的方位。算法随后把参考裂隙切换为下一个尚未旋转过的最大裂隙并继续。若给出 merge 关键字，则共面的裂隙在会重叠时被平移到参考裂隙面上。若某裂隙完全落在更大裂隙内，则将其移除；否则增大最大裂隙的面，使其等于两个合并裂隙面之和。

angle f

裂隙邻近性识别的角度判据，f ≥ 0。

collapse

把旋转后的裂隙塌缩到参考裂隙平面上。裂隙不合并。

distance f

裂隙邻近性识别的距离判据，f ≥ 0。

merge

合并若塌缩到参考裂隙平面上就会与参考裂隙重叠的裂隙。若某条裂隙完全落在 更大裂隙之内，则将其移除。

用法示例

下例说明如何使用 合并裂隙命令（fracture combine） 命令减少方位相近的 裂隙集中的裂隙数量（三维）。在生成 DFN 之后，分两步进行：

  • 首先，合并方位最接近（两者之间的立体角小于 20°）的裂隙；
  • 其次，按更宽松的方位判据（两者之间的立体角小于 50°）把裂隙投影到同一平面上，但不合并。

初始 DFN 由此被“简化”，裂隙之间不再有小角度，这有助于后续网格划分。

三维示例：

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;创建模板
fracture template create 'example' orientation fisher 50 150 10
;采用模板生成裂隙
fracture generate template 'example' fracture-count 400
;根据角度和距离组合裂隙，采用合并方式 
fracture combine angle 20 distance 0.5 merge
;根据角度和距离组合裂隙，采用塌缩方式
fracture combine angle 50 distance 0.5 collapse
program return
