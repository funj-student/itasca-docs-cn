fracture template create 命令

语法

fracture template create s keyword ...

主要关键字：

倾向上下限（dip-direction-limits）    倾角上下限（dip-limits）    方位（orientation）    position    size    尺寸上下限（size-limits）

创建裂隙生成模板。模板名称为 s。裂隙生成 模板是一组统计 参数，用于以 生成裂隙命令（fracture generate） 命令生成裂隙。这些参数 为尺寸分布、位置分布和方位分布。生成裂隙之后，裂隙生成模板与 所生成裂隙之间可能存在关联。裂隙生成模板也可输出到文件以便导入和 复用（见 导出裂隙命令（fracture export） 和 导入裂隙（fracture import） 命令）。

默认情况下，裂隙生成模板具有以下属性：裂隙位置均匀、 方位均匀（二维中倾角 0 到 180 度；三维中倾角 0 到 90 度、倾向 0 到 360 度），尺寸服从指数为 4、最小（最大）尺寸分别为 1.0（∞）的负幂律分布。

始终存在一个默认裂隙生成模板，其状态随模型状态保存和恢复。当未指定模板时，该默认裂隙生成模板用作生成裂隙（即用 生成裂隙命令（fracture generate） 命令）的基础。关于如何修改默认裂隙 生成模板的细节，见 修改裂隙模板默认值命令（fracture template modify-default） 命令。

dip-direction-limits 最小开度（fmin ）最大开度（fmax ）(3D only)

指定裂隙倾向必须落在 [最小开度（fmin）, 最大开度（fmax）] 度范围内。默认情况下，最小开度（fmin） = 0，最大开度（fmax） = 360。

dip-limits 最小开度（fmin ）最大开度（fmax ）

指定裂隙倾角必须落在 [最小开度（fmin）, 最大开度（fmax）] 度范围内。默认情况下， {二维中 最小开度（fmin） = 0 且 最大开度（fmax） = 180；三维中 最小开度（fmin） = 0 且 最大开度（fmax） = 90}。

orientation keyword

定义裂隙方位的生成规则。

bootstrapped s

倾角{及三维中的倾向}从文件 s 中自举抽取。该文件 必须符合 DFN 相关文件格式（DFN-Related File Formats） 中给出的自举分布文件格式。

dips s (3D only)

倾角和倾向从 DIPS 文件 s 中自举抽取。该文件 必须符合 DFN 相关文件格式（DFN-Related File Formats） 中给出的 DIPS 文件格式。

fish s a1a2...

fish 关键字用于从用户定义的 FISH 函数获取取值。函数 s 后跟函数参数（任意 个数）。该函数必须返回{二维中浮点值；三维中二维向量}。

fisher Fisher倾角（fdip ）Fisher倾向（fdipdir ）κ参数（fk ）(3D only)

倾角和倾向从 Fisher 分布中抽取。 按顺序指定倾角（Fisher倾角（fdip））、倾向（Fisher倾向（fdipdir））和 \(\kappa\)（κ参数（fk））。

gauss f1 f2 ...

倾角{及三维中的倾向}从高斯分布中抽取。在 二维中，需要两个附加参数，分别指定倾角分布的均值和标准差。 在三维中，需要四个附加参数：倾角分布的 均值和标准差，随后是倾向分布的均值和标准差。

uniform

倾角{及三维中的倾向}从均匀分布中抽取。

注意

在二维中，倾角是从 \(x\) 轴正向顺时针量得的角（度）。在三维中，倾角是从投影到 \(xy\) 平面上的倾向到裂隙面、沿 \(z\) 负向量得的角。三维中的倾向从 \(y\) 轴正向顺时针量得。

position keyword

定义裂隙位置的生成规则。

bootstrapped s

位置从文件 s 中自举抽取。对所需维数，该文件 必须符合 DFN 相关文件格式（DFN-Related File Formats） 中给出的自举文件格式。

fish s a1a2...

fish 关键字用于从用户定义的 FISH 函数获取取值。函数 s 后跟函数参数（任意 个数）。该函数必须返回向量。

gauss x 向位置均值（fpx ）x 向位置标准差（fsx ）y 向位置均值（fpy ）y 向位置标准差（fsy ）z 向位置均值（fpz ）z 向位置标准差（fsz ）

位置从高斯分布中抽取。每个均值方向后跟该方向的标准差。在二维中只给出四个值。

uniform

位置从均匀分布中抽取。

size keyword

定义裂隙尺寸的分布。裂隙尺寸定义为{二维中裂隙 长度；三维中圆盘直径}。

bootstrapped s

尺寸从文件 s 中自举抽取。该文件 必须符合 DFN 相关文件格式（DFN-Related File Formats） 中给出的一维自举文件格式。

fish s a1a2...

fish 关键字用于从用户定义的 FISH 函数获取取值。函数 s 后跟函数参数（任意 个数）。该函数必须返回浮点值。

gauss f1 f2

尺寸从均值为 f1、标准差为 f2 的高斯分布中抽取。

power-law f

指数为 f 的负幂律分布。

uniform

尺寸从均匀分布中抽取。

size-limits 最小开度（fmin ）最大开度（fmax ）

裂隙尺寸限值必须落在 [最小开度（fmin）, 最大开度（fmax）] 范围内。默认情况下， 最小开度（fmin） = 1.0，最大开度（fmax） = +∞。裂隙尺寸定义为{二维中 长度；三维中直径}。

用法示例

下例说明如何使用 创建裂隙模板命令（fracture template create） 命令 构建简单模板并生成一个实现。此处模板为裂隙尺寸定义指数为 3.5 的幂律分布、 均匀位置以及 Fisher 方位分布。

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;创建裂隙模板
fracture template create 'example' orientation fisher 60 250 100 ...
                  position uniform size power-law 3.5 size-limits 0.5 10
;采用模板生成裂隙
fracture generate template 'example' dfn 'realization_1' fracture-count 300
;采用该模板生成更多裂隙
fracture generate template 'example' dfn 'realization_2' mass-density 1
program return

下例说明如何使用 创建裂隙模板命令（fracture template create） 命令 构建一个调好的模板并生成一个实现。此处裂隙方位和尺寸 从用户定义的分布中抽取。 方位分布由 fish 函数 二维均匀分布函数（d2uniform） 定义，尺寸 分布由 fish 函数 对数正态分布函数（lognormallaw） 定义。

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;为裂隙尺寸定义对数正态分布
fish define log_normallaw(mean,sigma)
	w=2.0
	v1=0.0
	v2=0.0
	z1=1
	loop while w>=1
		v1 = 2.0*math.random.uniform-1.0
		v2 = 2.0*math.random.uniform-1.0
		w = v1*v1+v2*v2
	endloop
	w=math.sqrt((-2.0*math.log(w))/w)
	z1=v1*w;
	val=mean+z1*sigma
	log_normallaw = math.exp(val)
end
;定义倾角与倾向的二维正态分布
fish define d2uniform(maxdip,maxdipd)
  local dip = math.random.uniform*maxdip
  local dipd = math.random.uniform*maxdipd
  d2uniform=vector(dip,dipd)
end
;利用这些 FISH 函数创建裂隙模板
fracture template create 'example' orientation fish d2uniform(90,360) ...
                          size fish log_normallaw(0,2)
;采用该模板生成裂隙
fracture generate template 'example' mass-density 0.5
program return

同样的二维示例：

model new

model domain extent -5 5 -5 5 
; 定义裂隙尺寸的对数正态分布
fish define lognormallaw(mean,sigma)
	w=2.0
	v1=0.0
	v2=0.0
	z1=1
	loop while w>=1
		v1 = 2.0*math.random.uniform-1.0
		v2 = 2.0*math.random.uniform-1.0
		w = v1*v1+v2*v2
	endloop
	w=math.sqrt((-2.0*math.log(w))/w)
	z1=v1*w;
	val=mean+z1*sigma
	lognormallaw = math.exp(val)
end
; 定义倾角与倾向的二维正态分布
fish define d2uniform(maxdip)
  local dip = math.random.uniform*maxdip
  d2uniform=dip
end
; 定义模板
fracture template create 'example' orientation fish d2uniform(90) ...
                         size fish lognormallaw(0,2)
; 生成一次随机实现
fracture generate template 'example' mass-density 2

program return
