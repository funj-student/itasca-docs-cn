fracture list 命令

语法

fracture list keyword <range>

主要关键字：

显示属性（attribute）    extra    分组（group）    intersection    position    property

列出裂隙属性。默认情况下，列出 DFN 及其关联的 模板（如有）和裂隙数量。

注意

使用 设置列表精度命令（model precision） 命令可更改所列浮点值的精度。

attribute <s >

列出裂隙属性。若未给出 s，则列出可用属性。若指定了 s，则为每条裂隙列出该属性的值。

extra i

列出索引 i 处的裂隙额外变量。

group s

列出槽位 s 处的裂隙组名。

intersection

列出裂隙交线。

position

列出所有裂隙的位置（中心）。

property <s >

列出裂隙性质。若未给出 s，则为 每条裂隙列出可用性质。若指定了 s，则为每条 裂隙列出该性质的取值。

裂隙性质可与 设置裂隙接触模型命令（fracture contact-model） 命令配合，用于设置接触 模型属性。
