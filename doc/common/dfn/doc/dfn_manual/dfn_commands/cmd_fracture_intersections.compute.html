fracture intersections compute 命令

语法

fracture intersections compute keyword ... <range>

主要关键字：

clean    分组槽位（group-slot）    intersection-set    skip-errors    与几何集求交（with-geometry）

计算交线。交线可存在于裂隙之间，以及裂隙 与几何集之间。支持的几何类型为{二维中的边；三维中的多边形/边}。三维中既不支持 凹平面多边形，也不支持非平面多边形。可提供 geometry 关键字 以生成裂隙与几何集之间的交线。交线存储在由 intersection-set 关键字指定的交线集中。指定的 交线集必须尚不存在。交线可在 FISH 中可视化和查询。 此外，交线还用于勾勒裂隙团簇（见 计算裂隙聚类命令（fracture cluster） 命令）和裂隙连通性（见 计算裂隙连通性命令（fracture connectivity） 命令）。

与几何对象的交线在三维中可能产生折线交线。例如，一条 裂隙可能在多处与表示钻孔的圆柱几何相交。那些在几何边处汇合的单个裂隙/多边形交线 被合并为折线交线。

clean

指定在交线操作成功后删除该几何集。

group-slot s

该可选关键字表示把交线集名称放入被判为处于该交线中的所有裂隙的组槽位 s。

intersection-set s

指定交线集。若勾勒交线且未 指定交线集，则交线名称设为 新建交叉集名称（intersectionsXX），其中 XX 向（XX） 是下一个可用的交线集 ID。

skip-errors (3D only)

表示即使几何对象非平面、凹或不是简单多边形，交线判定仍将继续。越界的裂隙会被跳过。

with-geometry s <range>

勾勒裂隙与名称为 s 的几何集之间的交线。可在 with-geometry 关键字之后指定可选的{二维中的边；三维中的多边形}范围，以过滤几何对象。此时 dfn.intersect.end2 FISH 内置函数返回 指向该几何集的指针。

用法示例

下例说明如何使用 计算裂隙交点命令（fracture intersections compute） 命令 计算裂隙之间的交线。

model new
model random 10000
model domain extent -5 5 -5 5
;采用默认模板生成裂隙
fracture generate fracture-count 400
;计算相交对象
fracture intersections compute intersection-set 'all'
program return

下例说明如何使用 计算裂隙交点命令（fracture intersections compute） 命令 计算裂隙与由三个多边形建模的隧道之间的交线（三维）。

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;创建简单隧道的几何形状
geometry set 'tunnel'
geometry polygon create by-positions  (-4,-4,-4) (-4,-4,1) (-4,4,1) (-4,4,-4)
geometry polygon create by-positions  (-4,-4,1) (-4,4,1) (4,4,1) (4,-4,1)
geometry polygon create by-positions  (4,-4,-4) (4,-4,1) (4,4,1) (4,4,-4)
;采用默认模板生成裂隙
fracture generate fracture-count 400
;计算与隧道的相交对象
fracture intersection compute with-geometry 'tunnel' ...
                      intersection-set 'frac_tunnel' 
program return
