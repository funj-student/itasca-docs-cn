fracture verify-file 命令

语法

fracture verify-file keyword

主要关键字：

文件（file）    格式（format）    属性文件（property-file）

校验 DFN 文件。在从 DFN 文件导入裂隙之前，应先使用 校验裂隙文件命令（fracture verify-file） 命令检查文件中所表示裂隙的有效性/特征。 显示以下量：

  • 读取 DFN 文件时的错误信息；
  • 文件中的裂隙数量；
  • 裂隙的最小/最大空间范围；
  • 裂隙{二维中长度；三维中面积}的最小/平均/最大值；以及
  • DFN 中心。

在识别无效裂隙以及确定导入裂隙应使用的适当 偏移/缩放时，该工具非常有用。

file s

指定要校验的 DFN 文件。

format keyword

指定文件格式。若未指定格式，则由 file 关键字所给名称的文件扩展名确定文件格式。假定“.dat”扩展名为 itasca 格式，“.flab”扩展名为 fishlab 格式，“.fab”扩展名为 fracman 格式。

itasca

itasca 格式按 DFN 相关文件格式（DFN-Related File Formats） 中的规定， 且为默认格式。

fishlab (3D ONLY)

fishlab 格式为 FISHLab 所用的 flowplane 格式。

fracman

fracman 格式遵循 FracMan ASCII 输出格式。

property-file s

表示要查询的属性文件。属性文件格式的定义见 DFN 相关文件格式（DFN-Related File Formats）。

用法示例

下例说明如何使用 校验裂隙文件命令（fracture verify-file） 命令 预解析 DFN 文件。它将输出 DFN 文件中有用的裂隙统计量，包括：

  • 性质数量，
  • 裂隙数量，
  • 包含域在 \(x\)、\(y\) 和 \(z\) 方向上的尺寸，
  • 裂隙面积的范围（可换算为等效直径），以及
  • 裂隙中心。

文件由 导出裂隙命令（fracture export） 命令的示例生成。

model new
model domain extent -4 4
;检查文件中的裂隙，相关信息见控制台
fracture verify-file 'example.dat' format itasca ...
         property-file 'example_prop.dat'
program return

另见：导出裂隙命令（fracture export） | 导入裂隙（fracture import）
