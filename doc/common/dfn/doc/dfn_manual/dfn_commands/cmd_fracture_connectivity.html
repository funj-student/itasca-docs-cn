fracture connectivity 命令

语法

fracture connectivity keyword ... <range>

主要关键字：

aperture    cubic    distance    附加变量索引（extra-index）    起始裂隙（starting-fracture）    起始几何集合（starting-geometry）    intersection-set

计算裂隙与指定结构之间的连通性。初始结构可以是裂隙，也可以是几何集。默认情况下，为每条裂隙计算整数连通级别（即连通级别 n 表示该裂隙通过 n 个裂隙交线与该结构相连），并根据距离赋额外变量。该行为可用 aperture、cubic 和 distance 关键字修改。若未指定交线集，或指定的交线集不存在，则新建一个交线集并勾勒出裂隙之间的所有交线；所得交线集用作连通性计算的基础。

aperture

连通性被赋给由 extra-index 关键字指定的索引处的额外变量。连通性为距离（按 distance 关键字的说明定义）除以裂隙开度。

cubic

连通性被赋给由 extra-index 关键字指定的索引处的额外变量。连通性为距离（按 distance 关键字的说明定义）除以裂隙开度的立方（即类似于透水率）。

distance

把连通性赋给 extra-index 关键字所指定索引处的额外变量。连通性以结构到裂隙的物理距离给出，沿穿过各交点的路径计算。

extra-index i

计算连通性，该关键字指定用于赋值的额外变量索引。若未指定该关键字，则使用额外变量索引 1。

starting-fracture i

起始结构设为 ID 为 i 的裂隙。该关键字不能 与 starting-geometry 关键字同时指定。

starting-geometry s

起始结构设为名称为 s 的几何集。该关键字不能 与 starting-fracture 关键字同时指定。

intersection-set s

指定用于连通性计算的交线集名称。若未指定交线集， 则新建一个名为 新建交叉集名称（intersectionsXX） 的交线集，其中 XX 向（XX） 是下一个可用的交线集 ID。

用法示例

下例说明如何使用 计算裂隙连通性命令（fracture connectivity） 命令计算从 钻孔出发的连通级别，以及从某条裂隙出发的连通距离。它首先计算从先前定义的钻孔出发的连通 级别，并把该级别保存到额外变量 1 中。连通级别为 0 的裂隙与 钻孔直接相连，级别为 1 的裂隙与级别 0 的裂隙相连，依此类推。连通级别为负 （-1）的裂隙是不连通的。随后，它计算所有裂隙到 ID 为 1 的裂隙的距离， 并保存到额外变量 2 中。该距离后续可用于分析目的，或用于简化 DFN （例如移除距给定结构过远的裂隙）。

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;创建钻孔几何对象
geometry set 'borehole'
geometry edge create by-position (-5,0,0) (5,0,0)
;采用默认模板生成裂隙
fracture generate percolation 5
;以钻孔为起点计算连通性
fracture connectivity starting-geometry 'borehole' extra-index 1
;以裂隙 1 为起点计算连通性
fracture connectivity starting-fracture 1 extra-index 2 distance
program return
