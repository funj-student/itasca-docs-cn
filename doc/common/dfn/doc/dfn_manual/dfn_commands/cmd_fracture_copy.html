fracture copy 命令

语法

fracture copy keyword <range>

主要关键字：

源DFN名称（from-dfn）    目标DFN名称（to-dfn）

复制裂隙。落在指定范围内的裂隙从 from-dfn 关键字指定的 DFN 复制到 to-dfn 关键字指定的 DFN。 若后一个 DFN 不存在，则创建它。

from-dfn s

指定从其复制裂隙的 DFN 名称。若未指定 DFN，则在裂隙落在指定范围内时 可从所有 DFN 复制裂隙。

to-dfn s

指定裂隙将被复制到的 DFN 名称。若未指定 DFN， 则新建一个名为 复制生成的DFN名称（copyOfDfnXX） 的 DFN，其中 XX 向（XX） 是复制裂隙来源的 DFN 的 ID。

用法示例

下面的三维示例说明如何使用 复制裂隙命令（fracture copy） 命令把 DFN 分成两个：一个含最小裂隙，一个含最大裂隙。

model new
model random 10000
model domain extent -5 5 
; 范围定义
fish define mylarge(dummy,frac)
	mylarge=0
	if fracture.area(frac)>4
		mylarge = 1
	endif
end
;采用默认模板生成裂隙
fracture generate dfn 'first' fracture-count 400
;将裂隙复制到新的 DFN
fracture copy from-dfn 'first' to-dfn 'second' range fish mylarge
;从第一个 DFN 中删除大裂隙
fracture delete dfn 'first' range fish mylarge
program return

另见：删除裂隙命令（fracture delete）
