fracture intersections scanline 命令

语法

fracture intersections scanline keyword <range> (3D only)

主要关键字：

intersection-set    扫描线几何集（lines）    测量面（surface）

创建与扫描线映射对应的交线。扫描线映射在由 surface 关键字指定的平面 表面上进行。测量表面必须是 平面、凸多边形。与该表面相交、同时也与指定扫描线集中的某条扫描线（见 scanlines 关键字）相交的所有裂隙交线 都被添加到指定的 交线集中。

intersection-set s

设置包含扫描线迹线的结果交线集名称。指定的 交线集必须尚不存在。

lines s

几何集 s 中的边被视为扫描线集合。与该表面相交、同时也与某条扫描线相交的所有裂隙 交线都保留在指定的 交线集中。

surface s

几何集 s 被视为定义测量平面。

用法示例

下例说明如何使用 裂隙交点测线分析命令（fracture intersections scanline） 命令 在名为“plane”的平面上沿名为“line”的直线计算扫描线，并把 映射的迹线保存到交线集中。

model new
model random 10000
model domain extent -5 5 -5 5 -5 5 
;采用默认模板生成裂隙
fracture generate fracture-count 1000
;定义测线所在平面
geometry set 'plane'
geometry polygon create by-positions  (-4,-4,0) (-4,4,0) (4,4,0) (4,-4,0)
geometry set 'line'
geometry edge create by-position (-4,0,0) (4,0,0)
;计算测线迹线，即裂隙与平面的交线
fracture intersections scanline intersection-set 'scan' ...
                       lines 'line' surface 'plane'
program return
