fracture prune 命令

语法

fracture prune keyword ...

主要关键字：

临界裂隙数（critical-number）    intersection-set

剪除孤立裂隙。作为该操作基础的交线集由 intersection-set 关键字 指定。尺寸小于或等于 critical-number 关键字所指定 裂隙数的裂隙团簇会被删除。 该交线集必须存在。若尚未计算团簇，则在剪除孤立裂隙之前先计算。

critical-number i

团簇中标记为待移除的裂隙临界数（默认 i = 1）。

intersection-set s

指定交线集名称，作为剪除操作的基础。

用法示例

下例说明如何使用 修剪裂隙命令（fracture prune） 命令从 DFN 中移除所有位于裂隙数不超过两条的团簇中的裂隙。若尺寸设为 1，则只移除孤立裂隙（即不与其他任何裂隙相连的裂隙）。

model new
model random 10000
model domain extent -5 5
;采用默认模板生成裂隙
fracture generate fracture-count 400
;计算相交对象
fracture intersection compute intersection-set 'all'
;计算裂隙簇
fracture cluster intersection-set 'all' group-slot 'cluster'
;剔除，即删除近乎孤立的裂隙
fracture prune intersection-set 'all' critical-number 2
program return
