fracture export 命令

语法

fracture export keyword ... <range>

主要关键字：

文件（file）    与平面相交（intersect-with-plane）    属性文件（property-file）    模板文件（template-file）

把裂隙导出到文件。默认情况下，裂隙以 Itasca DFN 数据文件格式导出 （见 DFN 相关文件格式（DFN-Related File Formats）），若文件名缺少扩展名， 则添加“.dat”扩展名。也支持 FISHLab 和 FracMan 格式。 相关的裂隙生成模板（若唯一）可导出到裂隙生成模板文件，裂隙属性可导出到属性文件（见 DFN 相关文件格式（DFN-Related File Formats））。这些文件可用 导入裂隙（fracture import） 命令导入。

file s keyword

裂隙导出到名称为 s 的文件。若未提供扩展名，则添加相应的扩展名。

format keyword

指定输出格式。默认使用 Itasca 格式。

itasca

itasca 格式按 DFN 相关文件格式（DFN-Related File Formats） 中的规定。

fishlab (3D ONLY)

fishlab 格式为 FISHLab 所用的 flowplane 格式，文件扩展名为 ‘.flab’。

fracman (3D ONLY)

fracman 格式遵循 FracMan ASCII 输出格式，文件扩展名为 ‘.fab’。

intersect-with-plane <keyword ...> (3D only)

指定输出与某一平面相交对应的二维裂隙迹线集。不勾勒面积交线。所得二维 DFN 必须在二维 Itasca 程序（即 PFC2D）中打开。采用 Itasca DFN 数据文件格式（见 DFN 相关文件格式（DFN-Related File Formats））。

注意

输出交点以 origin 关键字所指定的位置为中心。交点的 \(x\) 分量沿平面走向，\(y\) 分量沿平面下倾方向。

dip f

指定交线平面的倾角。

dip-direction f

指定交线平面的倾向。

origin v

指定交线平面的原点。

property-file s

裂隙属性集导出到名称为 s 的文件。若不导出属性文件， 则导出文件中所有含裂隙的裂隙的相应属性集编号 都设为 1。属性文件格式在 DFN相关文件格式（DFN-Related File Formats） 中规定。

template-file s

相应的裂隙生成模板（若唯一）导出到名称为 s 的文件，若未给出扩展名， 则文件名追加“.idt”扩展名。模板文件格式在 DFN 相关文件格式（DFN-Related File Formats） 中规定。注意，使用 intersect 关键字时 不会导出模板文件。

用法示例

下例说明如何使用 导出裂隙命令（fracture export） 命令：首先，由单个模板但两套不同属性集生成 DFN；其次，导出 DFN 几何、属性和模板。共生成 3 个文件：

  • 含裂隙几何的 example.dat；
  • 含裂隙属性的 example_prop.dat；以及
  • 含用于生成该裂隙的模板描述的 example_temp.idt。
model new
model random 10000
model domain extent -5 5
;范围定义
fish define mylarge(dummy,frac)
   mylarge=0
   if fracture.area(frac)>4
      mylarge = 1
   endif
end
;创建裂隙模板
fracture template create 'ex_temp' size power-law 3 size-limit 0.5 100
;采用模板生成裂隙
fracture generate dfn 'example' template 'ex_temp' fracture-count 500
;指定参数
fracture property 'jcohesion' 50 'jkn' 50e9 'jks' 5e9 range fish mylarge
fracture property 'jcohesion' 20 'jkn' 10e9 'jks' 1e9 range fish mylarge not
;将裂隙、参数和模板导出到文件
fracture export file 'example.dat' ...
         property-file 'example_prop.dat' ...
         template-file 'example_temp'
program return

下例仅适用于三维，说明如何使用 导出裂隙命令（fracture export） 命令 导出三维 DFN 的二维切面，以便在二维程序中进一步分析。此处 example.dat 将包含 三维 DFN 在以 (1,0,0) 为中心、倾角 90°、倾向 50° 的平面上的迹线。

model new

model domain extent -5 5
;范围定义
fish define mylarge(dummy,frac)
   mylarge=0
   if fracture.area(frac)>1
      mylarge = 1
   endif
end
;创建裂隙生成模板
fracture template create 'ex_temp' size power-law 3 size-limits 0.5 100
;采用模板生成裂隙
fracture generate dfn 'example' template 'ex_temp' fracture-count 500
;指定参数
fracture property 'jcohesion' 50 'jkn' 50e9 'jks' 5e9 range fish mylarge
fracture property 'jcohesion' 20 'jkn' 10e9 'jks' 1e9 range fish mylarge not
;导出与平面的相交对象 
fracture export file 'example' ...
                property-file 'example_prop' ...
                intersect-with-plane dip 90 dip-direction 50 origin (1,0,0)
program return
