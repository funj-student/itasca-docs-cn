fracture group 命令

语法

fracture group s keyword <range>

主要关键字：

remove    槽位（slot）

指定裂隙组名。组逻辑的用法见 分组（Groups）。默认情况下，s 被赋给默认槽位 默认（Default）。使用 remove 关键字从所有槽位中移除 s。

remove

将 s 从所有槽位中移除。

slot 槽位（slot ）

把组 s 赋给名为 槽位（slot） 的槽位。默认使用槽位 默认（Default）。

用法示例

下面的三维示例说明如何使用 裂隙分组命令（fracture group） 命令 把裂隙分成两组：大裂隙和小裂隙。

model new
model random 10000
model domain extent -5 5 
;定义范围
fish define mylarge(dummy,frac)
	mylarge=0
	if fracture.area(frac)>4
		mylarge = 1
	endif
end
;采用默认模板生成裂隙
fracture generate fracture-count 400
;为裂隙指定分组
fracture group 'large' slot 'size' range fish mylarge
fracture group 'small' slot 'size' range fish mylarge not
;为 DFN 指定分组 'to'
fracture dfn-group 'my_dfn'
program return
