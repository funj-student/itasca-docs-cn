fracture cluster 命令

语法

fracture cluster keyword ...

主要关键字：

分组槽位（group-slot）    intersection-set

计算裂隙团簇。团簇定义为通过交线相连的 裂隙集合。这些裂隙集合被编号，并根据编号赋组名。交线通过 计算裂隙交点命令（fracture intersections compute） 命令创建。若未指定交线集，或 指定的交线集不存在，则新建一个交线集并勾勒出裂隙之间的 所有交线；所得交线集用作 团簇计算的基础。

group-slot s

在槽位 s 中赋组名。组逻辑的用法见 分组（Groups） 专题。组名基于交线集名称。 组名设为 分组名称（cnameXX），其中 交叉集名称（cname） 是交线集名称， XX 向（XX） 是团簇索引。默认情况下，s = 默认（Default）。

intersection-set s

指定用于团簇计算的交线集名称。若未指定交线集， 则新建一个名为 新建交叉集名称（intersectionsXX） 的交线集，其中 XX 向（XX） 是下一个可用的交线集 ID。随后计算所有交线。

用法示例

下面的三维示例说明如何使用 计算裂隙聚类命令（fracture cluster） 命令 计算裂隙团簇并为可视化赋组。在该例中，裂隙在渗流阈值处生成（即当某个团簇 连通所有系统边界时）。随后计算团簇，并赋给名为 簇分组名称（allXX） 的组，其中 XX 向（XX） 是团簇索引。注意，被赋予组 簇 0 分组名称（all0） 的裂隙是孤立的，即它们不与任何其他裂隙相交。

model new
model random 10000
model domain extent -5 5
;采用默认模板生成裂隙
fracture generate generation-box -8 8 -8 8 -8 8 ...
                  connectivity-threshold box -5 5 -5 5 -5 5
;计算相交对象
fracture intersection compute intersection-set 'all'
;根据相交关系计算裂隙簇
fracture cluster intersection-set 'all' group-slot 'cluster'
program return
