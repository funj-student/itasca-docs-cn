fracture compute 命令

语法

fracture compute keyword <range>

主要关键字：

平均迹线长度（average-trace-length）    center-density    mass-density    p10    trace-center-density    trace-mass-density    percolation

计算裂隙统计量。可计算按范围过滤的多种 裂隙密度度量。

average-trace-length s (3D only)

返回平均迹线长度，其中迹线是裂隙与 名称为 s 的平面几何集的交线。

center-density

返回裂隙中心密度（即二维中的 P20、三维中的 P30）。

mass-density

返回裂隙质量密度（即二维中的 P21、三维中的 P32）。

p10 keyword

返回沿由 begin 和 end 定义的直线、或沿用 geometry 关键字 定义的几何边测得的 P10。

geometry s

P10 沿名为 s 的几何集各边测量。不能与 begin 或 end 关键字一起给出。

begin v

定义测量 P10 的参考线起点。不能与 geometry 关键字一起给出。

end v

定义量测 P10 的参考线终点。不能与 geometry 关键字一起给出。

trace-center-density s (3D only)

返回迹线中心密度（即 P20），其中迹线是裂隙与名称为 s 的平面几何集的交线。

trace-mass-density s (3D only)

返回迹线质量密度（即 P21），其中迹线是裂隙与 名称为 s 的平面几何集的交线。

percolation

返回渗流参数。

用法示例

下例说明如何使用 计算裂隙统计量命令（fracture compute） 命令 输出裂隙统计量（三维）。

model new
model random 10000
model domain extent -5 5
;采用默认模板生成裂隙
fracture generate fracture-count 100
;创建用于计算 p10 的直线
geometry set 'p10line'
geometry edge create by-position (-5,0,0) (5,0,0)
;列出部分信息
fracture compute mass-density
fracture compute center-density
;分别利用直线及所指定端点列出 p10
fracture compute p10 begin (-5,0,0) end (5,0,0)
fracture compute p10 geometry 'p10line'
