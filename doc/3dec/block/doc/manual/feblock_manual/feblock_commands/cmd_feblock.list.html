feblock list 命令

语法

feblock list <keyword> <range...>

主要关键字：

displacements    elements    faces    failed    gauss    loads    最大值（maximum）    nodes    principal    stresses

将有限元块体的相关信息输出到屏幕。若指定了范围，则输出限于落在该范围内的块体。

displacements

节点位移

elements

单元节点列表

faces

面节点列表

failed

已失效的高斯点列表

gauss

高斯点位置

loads

重力节点载荷

maximum

有限元块体统计信息

nodes

节点坐标

principal

高斯点上的主应力

stresses

高斯点应力
