block vtk 命令

语法

block vtk keyword <range>

主要关键字：

displacements    导出单元附加变量（zone-extra）    导出网格点附加变量（gridpoint-extra）    forces    groups    导出流体模型属性（model-fluid）    导出力学模型属性（model-mechanical）    导出热模型属性（model-thermal）    pore-pressure    stresses    导出温度（temperatures）    导出速度（velocities）    文件名（filename）

控制是否从块体网格单元向 VTK 文件导出数值以及导出哪些数值。默认导出的量为 stresses、groups 和 displacements。

displacements b

网格点处的位移矢量

zone-extra b <index i >

网格单元处索引为 i 的额外变量

gridpoint-extra b

网格点处索引为 i 的额外变量

forces b

网格点处的不平衡力信息，包括最近一次的局部力比率。

groups b <slot s >

在 vtk 文件中包含赋给网格单元的槽位 s 中的组

model-fluid b <prop s >

在 vtk 文件中包含流体属性 s

model-mechanical b <prop s >

在 vtk 文件中包含力学性质 s

model-thermal b <prop s >

在 vtk 文件中包含热学性质 s

pore-pressure b

网格点处的孔隙压力值

stresses b

各网格单元中的平均应力。请注意，内部四面体的应力从不导出。

temperatures b

网格点处的温度值

velocities b

网格点处的速度矢量

filename s

指定 vtk 文件的名称
