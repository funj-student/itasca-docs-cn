block fluid 命令

语法

block fluid keyword ... <range>

主要关键字：

裂缝流动（crack-flow）    水头基准高程（datum）    快速流动（fast-flow）    气体（gas）    节理流体子步数（jointflow-substep）    list    基质流动（matrix-flow）    property    proppant    同步力学与流体时步（sync-mech）    timestep    时步更新间隔（timestep-update）

指定流动计算的配置。

crack-flow b

确保流动仅发生在流动面中相关联子接触已破坏的部分内。当裂隙流动为 关闭（off） 时，流动将在所有面中发生。默认值为 关闭（off）。

datum f

指定用于水头图绘制的 \(z\) 值。

fast-flow keyword ...

指定快速流动计算的设置。

active b

开启/关闭不可压缩流体流动的快速流动计算（开启（on）/关闭（off））。（对于可压缩流体流动，默认值为 关闭（off）。）对于仅计算流体流动的情况，不要将快速流动设为 开启（on）。（默认值为 关闭（off）。）（另请参见接下来的三个关键字：relaxation、unbalanced-average 和 unbalanced-maximum。）

relaxation f

设置快速流动计算中使用的松弛参数。relaxation < 1 时应能给出稳定解。默认值为 0.1。

gas keyword ...

指定气体流动计算的设置。

active b

开启/关闭气体流动逻辑的控制（开启（on）/关闭（off））。

alpha f

定义气体流动的“a”因子。

bulk-minumum f

指定气体流动的最小体积模量。

constant f

指定气体流动的气体常数。

density-minimum f

指定气体流动的最小密度。

jointflow-substep i

设置两次基质流动计算之间节理流体步的最大数目（默认值 = 10）。当力学计算处于激活状态时，jointflow-substep = 1。

list

列出流体信息。

matrix-flow b

开启或关闭基质流动计算（开启（on）/关闭（off））。若基质流动为 关闭（off），块体网格单元中流体体积模量的力学效应仍会被计入，从而减小力学时步（仅当 configure fluid 为 开启（on） 时）。

property keyword ...

指定用于流体流动计算的流体属性。

bulk f

设置节理和基质中流体的体积模量。

bulk-matrix f

设置基质中流体的体积模量。

cohesion f

设置非牛顿流动时流体的黏聚力。

density f

设置流体的密度。

f-factor f

设置用于乘以力学张开度以得到水力张开度的因子。默认值为 1。

heat-transfer-coefficient f

设置流体传热系数。

specific-heat f

设置流体比热。

thermal-conductivity f

设置流体热传导系数。

viscosity f

设置流体黏度。

proppant keyword ...

设置属性并配置支撑剂计算。

active b

设置支撑剂计算的 开启（on）/关闭（off）。使用当前的体积分数和节理张开度来初始化支撑剂状态。

settling b

开启/关闭支撑剂沉降计算（开启（on）/关闭（off））（默认值 = 关闭（off））。

concentration-limit-volume f

设置支撑剂的浓度限值（0-1），超过该限值后支撑剂承担荷载。

concentration-limit-mass f

设置支撑剂的质量浓度限值（质量/体积），超过该限值后支撑剂承担荷载

density f

设置流体的密度。

grain-size f

设置支撑剂颗粒的粒径（直径）。

grain-size-factor f

设置支撑剂运移的（与颗粒尺寸相关的）节理张开度允许值。若张开度小于该因子乘以支撑剂颗粒尺寸，则支撑剂留在原处。默认值为 1。相关联流动区的渗透率被设为内禀渗透率的 支撑剂渗透率系数（block fluid proppant permeability-factor） 倍。

list

列出支撑剂的信息。

modulus f

设置支撑剂充填层承担荷载时的体积模量（体积分数高于限值时）。

permeability f <table s >

设置支撑剂充填层承担荷载时的渗透率（内禀渗透率除以流体黏度）。

permeability-factor f

当一个或多个顶点的张开度小于 支撑剂粒径（block fluid proppant grain-size） 乘以 支撑剂粒径系数（block fluid proppant grain-size-factor） 时，计算流动区的渗透率。该值乘以内禀渗透率即得到“封堵”渗透率。默认值为 0。

sync-mech b

将 \(b\) 设为 \(on\) 可使力学时间与流体时间保持同步。将采用流体与力学时步中的最小者。若 \(b\) 为 \(on\)，则流体与力学子步自动设为 1。默认值为 \(off\)。

timestep f
指定流体流动计算所需的时步（仅节理流动）。每个流动节点的流体体积模量会被调整，以产生所需的时步。
警告：设置过高的值会产生体积模量较低的体积，从而对结果产生不利影响。执行该命令时，屏幕上会打印受影响的节点总数和节点总体积。用户须自行确保受影响的体积不要过大。
timestep-update 在（in ）

指定重新计算流体时步的间隔。默认情况下 \(n\) = 1，因此每个流体步都会重新计算时步。
