block merge-start 命令

语法

block merge-start <slot s > <exclude s1 <s2 <...> >>

执行该命令后，随后创建的所有四面体块体都将转换为网格单元；若它们具有相同的组名，则合并为一个块体。组槽位名可通过 s1 指定。若未给出槽位，则使用默认槽位。若块体未在指定槽位中被赋予组名，则不会被合并。 可使用关键字 Exclude 并给出组名（s1 s2 …），将一个或多个组排除在合并之外。
