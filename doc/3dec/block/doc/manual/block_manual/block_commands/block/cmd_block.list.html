block list 命令

语法

block list keyword <range>

主要关键字：

apply    在（at）    砖块（brick）    cell    凹角检查（concave）    contacts    energy    extra    缺陷（flaw）    分组（group）    information    limits    master    memory    moment    多面体文件导出（polyhedra）    position    剖面（profile）    从块列表（slave）    unbalanced-force    velocity    墙体（wall）    water-table

列出块体信息。若指定了范围，则输出仅限于位于该范围内的块体。

apply

列出施加了速度或热学条件的块体的信息。

at v

输出最靠近指定位置的网格单元应力、顶点位移和速度。

brick

该命令提供了 LIST boundary reactions 命令之外的另一种选择。当需要把整体模型内部的应力作为边界条件传递到较小的模型时，可使用该命令。较小模型必须定义为砖块形状的多面体。该命令生成一个文件，其中包含 BOUNDARY point、BOUNDARY xload、BOUNDARY yload 和 BOUNDARY zload，它们在较小模型的数据文件中作为输入使用。与 LIST boundary reactions 命令不同，整体模型无需具备与较小模型边界相对应的节理。各力通过对砖块面上规则网格中的应力进行采样来计算。网格尺寸可由用户定义。力经过修正，使合力与砖块区域内部的重力相平衡。这里假定砖块内部不存在空洞。默认文件名为“BRICK.PRN”。默认网格间距为砖块最大尺寸的 0.1 倍。

cell

列出单元空间数据。

concave <angle f >

列出面对面夹角为 180◦ 或更大的块体棱边。面对面夹角大于 180◦ 即为凹角，在划分网格或滑动时可能引发问题。若面对面夹角大于给定值（默认值 = 210◦），则输出块体信息。

contacts

列出块体接触清单数据。

energy

列出应变能计算的汇总信息。

extra i

列出范围内块体的额外变量 i 的内容。

flaw <keyword ...>

列出假设平面上的法向和剪切面力，该平面由 dip、倾向（dip-direction）和原点坐标指定。输出区域可通过 radius 关键字限定。此功能用于评估不同方位下的滑动可能性。

dip f

指定倾角。

dip-direction f

指定倾向。

file s

指定将输出发送到文本文件 s。

origin v

若使用半径，则指定球体的原点。

radius f

指定输出仅限于半径为 f 的球体范围内。

screen

指定将输出发送到屏幕而不是文件。

group

列出块体组名。

information

列出块体的一般信息，包括 ID、材料号、本构号、区域、类型以及主从状态（这是默认设置）。

limits

列出模型中位置、位移和速度的最大值与最小值。

master

列出主块体。

memory

列出 3DEC 当前正在使用的内存量。

moment

列出块体的惯性矩。

polyhedra <s > <i >

创建一个文件，其中包含可重建该块体的 创建多面体面命令（block create polyhedron face） 命令。该文件可直接作为数据文件调用。此功能用于提取模型的一部分（仅输出可见块体）。它也可用于减少模型所需的内存，适用于构建过程中删除了大量块体的模型。若未指定文件名，则文件名为 多面体输出文件名（spoly.txt）。可给出可选精度 n，即坐标所输出的有效数字位数。该参数只能与文件名一起给出。默认值为 i = 12。

position

列出范围内每个块体的位置。

profile keyword

列出指定量在一条直线上等间距各点处的值。

对于剖面，只能指定下列各量中的一个。

acceleration [blocklistprofileoptions]

网格点处的加速度大小（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-x [blocklistprofileoptions]

网格点处的 x 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-y [blocklistprofileoptions]

网格点处的 y 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-z [blocklistprofileoptions]

网格点处的 z 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

condition [blocklistprofileoptions]

衡量网格单元变形程度的指标。[紧急：CS：此处链接所需的内容似乎需要加入文档集：链接到《命令参考》第 1.1.5 节内容的最终所在位置

density [blocklistprofileoptions]

网格单元的密度。

displacement [blocklistprofileoptions]

网格点处的位移大小

displacement-x [blocklistprofileoptions]

网格点处的 x 向位移

displacement-y [blocklistprofileoptions]

网格点处的 y 向位移

displacement-z [blocklistprofileoptions]

网格点处的 z 向位移

extra [blocklistprofileoptions]

额外变量的值。所用的额外变量索引默认为 1，可通过 index 修饰符关键字更改。该值默认取自网格点的额外变量，但可通过 source 修饰符关键字指定。该值默认按标量浮点类型处理，但可通过 type 修饰符关键字指定。

pore-pressure [blocklistprofileoptions]

网格单元中的孔隙压力。默认取网格点孔隙压力，但可用 source 关键字修饰符指定采用网格单元平均孔隙压力。

property [blocklistprofileoptions]

网格单元力学本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

property-fluid [blocklistprofileoptions]

网格单元流体本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

property-thermal [blocklistprofileoptions]

网格单元热学本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

ratio-local [blocklistprofileoptions]

各网格点处的局部不平衡力比率。与所有结果一样，可使用 :lkwd:’log’ 关键字修饰符将其换算为该值的对数。

saturation [blocklistprofileoptions]

网格点处的饱和度（仅当已指定 配置流体计算模式（model configure fluid） 时可用）

strain-increment [blocklistprofileoptions]

网格单元的应变增量张量，由当前位移场确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

strain-rate [blocklistprofileoptions]

网格单元的应变率张量，由当前速度场确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress [blocklistprofileoptions]

网格单元的应力张量，由各子网格单元应力的加权平均确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress-strength-ratio [blocklistprofileoptions]

当前应力与该网格单元破坏面的比值，由当前网格单元本构模型确定。并非所有本构模型都支持该计算。若不支持，则返回值为 10。返回值一般以 10 为上限。

stress-effective [blocklistprofileoptions]

网格单元的有效应力张量，由各子网格单元应力的加权平均减去网格单元平均孔隙压力确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

temperature [blocklistprofileoptions]

网格点处的温度。可用 source 修饰关键字改为指定采用基于网格单元的温度。

timestep-dynamic [blocklistprofileoptions]

该特定网格点的局部临界动力时步。（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

unbalanced-force [blocklistprofileoptions]

网格点处的不平衡力大小。

unbalanced-force-x [blocklistprofileoptions]

网格点处的 x 向不平衡力。

unbalanced-force-y [blocklistprofileoptions]

网格点处的 y 向不平衡力

unbalanced-force-z [blocklistprofileoptions]

网格点处的 z 向不平衡力

velocity [blocklistprofileoptions]

网格点处的速度大小

velocity-x [blocklistprofileoptions]

网格点处的 x 向速度

velocity-y [blocklistprofileoptions]

网格点处的 y 向速度

velocity-z [blocklistprofileoptions]

网格点处的 z 方向速度

slave i

列出从属于块体 ID i 的块体。

unbalanced-force

列出刚性块体的不平衡力。

velocity

列出块体的平动速度和转动速度。

wall

列出墙类型的块体。

water-table

列出地下水位定义。


block list profile 关键字块

下列修饰符可用于为以下各 列出区块剖面值命令（block list profile） 关键字提供附加信息：acceleration、acceleration-x、acceleration-y、acceleration-z、condition、density、displacement、displacement-x、displacement-y、displacement-z、extra、pore-pressure、property、property-fluid、property-thermal、ratio-local、saturation、strain-increment、strain-rate、应力（stress）、stress-effective、应力强度比（stress-strength-ratio）、温度（temperature）、timestep-dynamic、unbalanced-force、unbalanced-force-x、unbalanced-force-y、unbalanced-force-z、velocity、velocity-x、velocity-y 和 velocity-z。

begin v

设置剖面线的起点。若未给出，该值默认为原点。另请参见 c end 和 c 分段数（segments） 关键字。

component keyword

该关键字用于选择从矢量类型的值（如速度或位移）中提取哪个标量分量。若值类型不是矢量，则忽略该设置。可用的选项有：

x
矢量的 x 分量
y
矢量的 y 分量
z
矢量的 z 分量
magnitude
矢量的模
end v

设置剖面线的终点。若未给出，该值默认为 (1,1,1)。另请参见 c 起点（begin） 和 c 分段数（segments） 关键字。

index i

对于需要索引的关键字（最典型的是 extra），此参数指定应使用的索引。默认值为 1。

gravity b

若为 开启（on），则返回的施加力中包含重力。默认值为 关闭（off）。

gridpoint-id i

通过 ID 号为 i 的网格点的位置来指定历史记录的位置。

label s

为历史记录指定一个标签，用于打印输出和绘图。

log b

若为 开启（on），则返回的数值为原始值绝对值的以 10 为底的对数。默认值为 关闭（off）。

method

该关键字指定用于将基于网格单元的量插值到空间任意位置（包括网格点位置）的计算方法。

constant

假定数值在网格单元内部为常数。这是默认选项。位于网格点处或网格单元边界上的值将选取一个相邻网格单元来计算。

average

该方式使用与该网格点相连的所有网格单元的体积加权平均值。

inverse-distance-weight

该方式使用该点紧邻区域内最多 32 个网格单元的加权平均值。权重由网格单元形心到指定点距离的幂确定。

power f

指定用于对数值加权的距离幂次。默认的幂值为 3.0。

radius-ratio f

指定所选网格单元距该点的最大距离之比，该比值用于计算加权值。距离超过该值的网格单元将被折减。默认值为 0.75。

polynomial <tolerance f >

根据该点附近的网格单元，使用多项式函数拟合。退化自由度会被检测并剔除。可选的 tolerance 可用于更改检测退化所用的值。默认值为 1e-7。

name s

某些关键字（最典型的是 property）需要给出名称值才能完整指定。该名称决定所提取的具体属性名。

null

指定忽略网格单元值的判据。默认忽略 mechanical null 网格单元。

fluid b

若将该选项设为 开启（on），则流体本构模型为空的网格单元也会被忽略。

mechanical b

若将该选项设为 开启（on），则忽略力学本构模型为空的网格单元（这是默认设置）。

thermal b

若将该选项设为 开启（on），则忽略热学本构模型为空的网格单元。

position v

在 v 处指定历史记录的位置。该位置必须位于某个网格单元内部。

quantity keyword

该关键字用于选择从对称张量类型的值（如应力或应变）中提取哪个标量分量。若值类型不是张量，则忽略该设置。可用的选项有：

intermediate

中间主应力

maximum

最大（最正）的主应力值。请注意，在 FLAC3D 中压应力为负值（compressive stresses are negative）。

mean

平均压力值，定义为张量的迹除以 3。对于应力，该量通常称为压力。

minimum

最小（最负）主应力。注意在 FLAC3D 中压应力为负（compressive stresses are negative）。

norm

应变率的范数；参见 网格场数据名称（Zone Field Data Names） 中的公式

octahedral

八面体应力；参见 网格场数据名称（Zone Field Data Names） 中的公式

shear-maximum

最大剪应力

total-measure

在主空间中张量值到原点的距离

volumetric

体积变化，即迹

von-mises

Von Mises 度量；参见 网格场数据名称（Zone Field Data Names） 中的公式

xx

张量的 xx 分量

xy

张量的 xy 分量

xz

张量的 xz 分量

yy

张量的 yy 分量

yz

张量的 yz 分量

zz

张量的 zz 分量

segments i

通过将剖面线分段，指定沿线从 c 起点（begin） 到 c end 均匀分布的点数（点数将为 i + 1）。若未给出，该值默认为 2。

source keyword

某些关键字（如 extra 和 pore-pressure）既可从网格单元结构、也可从网格点结构提取。默认值为 gridpoint。

gridpoint

数值直接取自网格点。

zone

从网格单元中提取数值。

stress b

少数张量类型的 quantity 选项会根据该值是否被视为应力而具有不同行为。当该值来自 extra 之类的变量时，无法自动判定。此选项允许用户指定传入的张量值应按应力处理。

type keyword

在某些情况下，值的类型（标量、矢量或张量）无法事先确定。例如，额外变量可保存全部三种类型的值。该关键字允许指定假定其所属的类型。若原始值类型不匹配，则返回 0.0。

scalar

标量浮点类型。这是默认值。

vector

矢量类型。

tensor

张量类型。

zone-id i

指定历史记录的位置位于 ID 为 i 的网格单元的形心处。
