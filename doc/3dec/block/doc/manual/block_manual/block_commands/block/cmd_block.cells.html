block cells 命令

语法

block cells keyword <range>

主要关键字：

自适应（adaptive）    size

设置单元映射接触检测中使用的单元数。默认值为 10 x 10 x 10。

adaptive b

开启或关闭自适应单元空间。当块体尺寸范围非常大时，自适应单元空间很有用。在导入大量块体时，不建议开启自适应单元空间，但可以在导入之后开启。默认值为 off。

size i <iy > <iz >

设置 \(x\) 方向上的单元数，其后可选地给出 \(y\) 方向和 \(z\) 方向上的单元数。若未给出 \(y\) 和 \(z\) 的值，则假定它们与 \(x\) 的值相同。（默认值 = 10。）
