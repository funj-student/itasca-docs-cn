block generate 命令

语法

block generate keyword

主要关键字：

按 VRML 文件生成（from-vrml）    按几何集生成（from-geometry）    按地形生成（from-topography）    voronoi

生成一组块体。块体的创建方法由所用的第一个关键字确定。

from-vrml keyword

根据 VRML 文件（虚拟现实建模语言）中的块体几何创建块体。VRML 文件中的形状必须是封闭的凸曲面。文件必须为 VRML 2.0 格式。

break-angle f

指定面间夹角上限，小于该角度时两个分离的面将合并。默认值为 1 度。

filename s

指定 VRML 文件的文件名。

from-geometry keyword

创建四面体块体以填充由几何体集合定义的封闭体积。

cut-angle f

用于捕获表面特征的阈值角度。默认值为 45°。使用较大的切割角可平滑掉与三角剖分粗糙度相关的多余表面特征。若表面重新网格化后存在相交曲面，则使用较小的切割角。

gradation-surface f

四面体网格表面上相邻三角形尺寸随局部尺寸自适应而增大或减小时的渐变速率

gradation-volume f

相邻四面体远离表面时尺寸增大的速率。

maximum-edge f

指定所生成的任何四面体的最大棱边长度。实际最大棱边长度将接近该值，但结果不保证精确。

minimum-edge f

指定所生成任何四面体的最小棱边长度。实际的最小棱边长度将接近该值，但不保证结果精确。

merge

若指定，则同一组中的所有块体将合并为一个块体。

set s

指定用于定义曲面的几何体集合。默认将使用当前的几何体集合。

from-topography <keyword ...> <range>

通过将范围内的表面面向外拉伸，直到与几何体集合中的多边形相交，从而生成块体。若块体面不是平面，则可对其三角剖分。

break-angle f

将折角设为大于 0，可在两个三角形面之间的夹角小于 f 时通过合并这些面来简化几何体集合。默认值为 0。

direction v

指定用于在表面面上创建块体的拉伸方向。自表面网格点起，沿该方向投射射线，直到与几何体集合中的多边形相交。由此确定所创建块体的形状和尺寸。默认情况下该值为 (0,0,1)。若某面的法向与该方向矢量平行（容差约为 0.5 度），则即使该面在范围内也会被忽略。

geometry-set s

指定用于定义块体所拉伸至的曲面的几何体集合。默认将使用当前的几何体集合。

group s1 <slot s2 >

将组 s1 赋给所创建的块体，位于槽 s2 中。若未指定，默认槽为 默认（Default）。组逻辑的用法在 组（Groups） 中描述。

plane keyword
给出 plane 关键字以表示拉伸目标是平面而非几何体集合。该平面必须由 normal 和 origin 定义。
normal v

若指定了 plane，则给出所沿拉伸平面的法向。

origin v

若指定了 plane，则给出所沿拉伸平面的原点。

ratio f

指定从表面面向几何集分布块体所用的比率。比率为 1.1 表示该方向上每条块体棱边的长度是前一块体的 1.1 倍。因此，默认情况下比率 > 1 意味着块体沿正 \(z\) 方向逐渐变大。若未指定，默认比率为 1.0。

segments i

指定在现有表面块体面与几何集之间创建的块体层数。默认情况下该值为 1。

voronoi keyword

创建 Voronoi 块体以填充由几何体集合（限定表面）定义的封闭体积。

cut-angle f

用于捕获表面特征的阈值角度。默认值为 45°。使用较大的切割角可平滑掉与三角剖分粗糙度相关的多余表面特征。若表面重新网格化后存在相交曲面，则使用较小的切割角。

gradation-surface f

在受限表面上，由于局部尺寸自适应而使两个种子点之间的距离变化（增大或减小）的速率。

gradation-volume f

两个种子点之间的间距远离限定表面时增大的速率。

maximum-edge f

指定两个种子点之间的最大距离。实际最大距离将接近该值，但结果不保证精确。

minimum-edge f

指定两个种子点之间的最小距离。实际最小距离将接近该值，但结果不保证精确。

set s

指定用于定义受限表面的几何集。默认情况下将使用当前的几何集。
