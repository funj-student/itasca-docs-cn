block densify 命令

语法

block densify keyword ... <range>

主要关键字：

gradient-limit    hexahedra    joint-set    join    最大长度（maximum-length）    重复次数（repeat）    分段数（segments）    tetrahedra

提高块体密度。在给定范围内细分块体以提高块体化程度。除给出 tetrahedra 关键字外，块体通过沿平行于整体坐标 \(x\)、\(y\)、\(z\) 轴的方向切割节理来细分。

gradient-limit

将对选作“加密”的块体进行检查，以尽量确保相邻块体之间的加密程度最多相差一级。这可能意味着会有比实际落入范围的块体更多的块体被加密。

hexahedra

若范围内的块体为六面体（8 面体），请使用该关键字。加密六面体块体时可以获得一定的效率提升，命令执行速度将明显加快。若范围内的块体不是六面体，则该关键字被忽略，并使用默认的加密方案。

joint-set i

为用该命令创建的面和节理指定节理 ID i。

join

跨用该命令创建的节理合并块体。

maximum-length f1 <f2 <f3 >>

这按顺序指定要加密的最大棱边长度。若未指定 f2 和 f3，则将其设为与 f1 相同的数值。

repeat <i >

将加密重复 i 次，从而递归地应用范围与加密设置。例如，这可用于生成八叉树网格。注意：若未给出次数，则 3DEC 将重复进行，直到达到 maximum-length 指定的长度，每次应用 segments 中指定的划分。

segments i1 <i2 <i3 >>

这指定 \(x\)、\(y\) 和 \(z\) 方向上的细分数。若未指定 i2 和 i3，则将其设为与 i1 相同的数值。

tetrahedra

四面体块体的劈分方式是先在各棱边中点处切割。这样会得到四个新的四面体和位于中央的一个八面体。随后沿对角线再作两次切割，将八面体劈分为四个四面体（见下图）。注意：若给出 tet 关键字，则对四面体块体忽略 \(segments\) 值。非四面体的块体则按常规沿整体 x、y 和 z 轴劈分。
