block to-flac3d 命令

语法

block to-flac3d keyword

主要关键字：

导出面分组（face-groups）    文件名（filename）    合并连接节点（merge-join）    导出单元分组（zone-groups）

将 3DEC 的网格单元和节理导出为文件，用于创建 FLAC3D 的网格单元和接触面。FLAC3D 的网格单元将被赋予与 3DEC 中块体组相同的组名和槽位。 此外，若将 Merge-Join 设为 \(true\)，网格单元还将在槽位 主块 ID 槽位（smaster） 中被赋予等于块体主 ID 的组名。 面将在槽位‘jset’中被赋予与节理 id（以字符串形式）相关的组名。实际的面组名由节理组 id 加上 \(_n\) 构成，其中 \(n\) 是为区分穿过其他节理的面而所需的递增编号。 接触面名称将与宿主面名称相同，并加上前缀 \(i\)。接触面将被赋予的组名就是节理组 id 加上前缀 \(i\)。这样，通过组范围即可方便地为构成不同节理组的接触面赋予属性。

face-groups b

将 b 设为 \(true\) 或 \(on\) 可导出用户定义的面组名（即节理组 id 之外的其他组名）。默认情况下不导出面组名。

filename s keyword

指定输出文件的名称。将创建两个文件：扩展名为 .f3grid 的网格文件，以及调用该网格文件的 .dat 文件。

binary b

默认情况下，网格文件将以二进制格式输出。将 b 设为 \(false\) 或 \(off\) 可按 ASCII 格式输出。

merge-join b

默认情况下，连接后的 3DEC 块体导入到 FLAC3D 时会合并其网格点。将 b 设为 \(false\) 或 \(off\) 可阻止该合并。

zone-groups b

将 b 设为 \(true\) 或 \(on\) 可导出用户定义的网格单元组名（即块体组之外的其他组名）。默认情况下不导出网格单元组名。
