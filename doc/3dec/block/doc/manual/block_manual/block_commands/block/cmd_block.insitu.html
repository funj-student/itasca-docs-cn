block insitu 命令

语法

block insitu keyword ... <range>

主要关键字：

流体温度（fluid-temperature）    pore-pressure    principal    应力（stress）    地形初始应力（topography）    上覆荷载 xx 应力（overburden-xx）    上覆荷载 yy 应力（overburden-yy）    上覆荷载 zz 应力（overburden-zz）

指定地应力或流体条件。

fluid-temperature f <gradient v >

设置流体初始温度。可选的 gradient 关键字给出从 (0,0,0) 处的指定值起算的 x、y、z 方向温度梯度。

pore-pressure f <keyword>

设置孔隙水压力。该命令将设置网格点孔隙压力。若 configure fluid 为 开启（on），则对流动平面上的流动节点设置孔隙压力；否则，对节理子接触设置流体压力。

gradient v

指定孔隙压力沿 x、y、z 方向的梯度，该梯度以原点处给定的值为基准。

principal keyword ...

初始化可变形块体中的地应力。也可指定可选的梯度和量测点。

direction-intermediate v

设置中间主应力的方向。只需为两个主应力分量提供方向。也可用倾角和倾向代替方向矢量。

direction-maximum v

设置最大主应力的方向。只需为两个主应力分量提供方向。也可用倾角和倾向代替方向矢量。

direction-minimum v

设置最小主应力的方向。只需为两个主应力分量提供方向。也可用倾角和倾向代替方向矢量。

intermediate f

设置中间主应力。

origin v

指定量测点，其默认值为原点。

maximum f

设置最大主应力。

minimum f

设置最小主应力。

dip-maximum f

设置最大主应力的倾角。可用倾角和倾向代替矢量方位。只需为两个主应力分量指定方位。

dip-direction-maximum f

设置最大主应力的倾向。可用倾角和倾向代替矢量方位。只需为两个主应力分量指定方位。

dip-intermediate f

设置中间主应力的倾角。可用倾角和倾向代替矢量方位。只需为两个主应力分量指定方位。

dip-direction-intermediate f

设置中间主应力的倾向。可用倾角和倾向代替矢量方位。只需为两个主应力分量指定方位。

dip-minimum f

设置最小主应力的倾角。可用倾角和倾向代替矢量方位。只需为两个主应力分量指定方位。

dip-direction-minimum f

设置最小主应力的倾向。可用倾角和倾向代替矢量方位。只需为两个主方向指定方位。

gradient-z f

指定 z 方向（竖向）的应力梯度。可选的位置用于指定应力测点的坐标。若未给出，则假定默认坐标为 0,0,0。梯度为竖向的应力变化量。其他所有应力按比例增大，以防止应力旋转。

nodisplacements

可选的 nodisplacements 关键字使（由初始应力引起的）法向位移不从 azero（零应力下的水力张开度）中扣除。因此若使用 nodisplacements，则 aperture-initial 为初始应力下的张开度，而不是零应力张开度。

stress 初始 xx 应力（fsxx0 ）初始 yy 应力（fsyy0 ）初始 zz 应力（fszz0 ）初始 xy 应力（fsxy0 ）初始 xz 应力（fsxz0 ）初始 yz 应力（fsyz0 ）<gradient-x fsxxx fsyyx fszzx fsxyx fsxzx fsyzx > <gradient-y fsxxy fsyyy fszzy fsxyy fsxzy fsyzy > <gradient-z fsxxz fsyyz fszzz fsxyz fsxzz fsyzz > <nodisplacements>

通过指定完整的应力张量以及沿 x、y、z 方向的可选梯度，初始化可变形块体中的地应力。若给出梯度，则假定输入的应力为 0,0,0 处的应力，并按相应方式施加梯度。例如，在点 x,y,z 处，xx 应力为 sxx = \(sxx0\) + \(sxxx\)*x + \(sxxy\)*y + \(sxxz\)*z。

nodisplacements 关键字使（由初始应力引起的）法向位移不从 aperture-initial（零应力下的水力张开度）中扣除。因此若使用 nodis，则 aperture-initial 为初始应力下的张开度，而不是零应力张开度。

topography <keyword ...>

根据上覆岩层密度初始化地应力。该命令用于顶面不规则的模型，此类模型中上覆荷载会引起应力的显著变化。

ratio-x f

设置 \(x\) 方向应力相对于竖向应力的比值。竖向由重力方向确定。

ratio-y f

设置 \(y\) 方向应力相对于竖向应力的比值。竖向由重力方向确定。

ratio-z f

设置 \(z\) 方向应力相对于竖向应力的比值。竖向由重力方向确定。

overburden f
设置叠加到地形应力上的竖向上覆应力。若模型未延伸至实际地表，该选项会很有用。请注意，压应力为负值。
水平方向的上覆应力由所指定的比值计算得到。
overburden-xx f

设置上覆应力的 xx 分量。请注意，压应力为负值。

overburden-yy f

设置上覆应力的 yy 分量。请注意，压应力为负值。

overburden-zz f

设置上覆应力的 zz 分量。请注意，压应力为负值。
