block fill 命令

语法

block fill <keyword ...> <range>

主要关键字：

区块分组名（block-group）    边界接触分组名（boundary-contact-group）    内部接触分组名（internal-contact-group）

范围内的所有开挖块体都被填充（即恢复参与计算）。可使用这些关键字在填充时将块体、边界接触或内部接触赋给某个组（以及可选的槽）。

block-group s1 <slot s2 >

将填充的块体赋给组 s1。

boundary-contact-group s1 <slot s2 >

将填充块体的边界接触赋给组 s1。

internal-contact-group s1 <slot s2 >

将填充块体的内部接触赋给组 s1。

充填块体（及其接触）未被赋予材料或本构属性。应在 fill 操作之后，使用命令中给出的分组名称完成该赋值。

有关 excavate 和 fill 的若干注意事项

block excavate 和 block fill 命令必须谨慎使用。block excavate 命令会在内存中保留初始开挖块体的全部几何形状。block fill 命令则只是替换原块体。若自块体开挖以来开挖形状已发生显著变化，原块体与其相邻块体可能发生重叠，从而导致数值不稳定。由于块体已通过 block excavate 命令合并，若只填充开挖区的一部分，则必须采用特殊步骤。

  1. 填充整个开挖区。
  2. 取消填充体内块体的合并。
  3. 执行计算时步（model cycle） 0，以在填充块体与开挖块体之间创建子接触。
  4. 重新开挖本步骤中不需填充的块体。
  5. 验证该过程的结果，并检查网格单元与节理的属性。
