block analyze-stability 命令

语法

block analyze-stability free-face s <keyword>

主要关键字：

区块附加变量槽位（block-extra）    黏聚力（cohesion）    摩擦（friction）    stiffness-normal    stiffness-shear

将块体视为“孤立刚体”来分析其稳定性。块体的创建方法由所用的第一个关键字决定。free-face 关键字用于指定块体自由面的面组名（即将要施加边界应力释放的面）。

可使用以下关键字定义节理属性。若未定义，则这些属性由接触的属性导出。

block-extra i

指定用于存储块体平均安全系数的额外变量槽。块体平均 FOS 由各面 FOS 值计算得到。若未给出 block-extra 关键字，则块体平均 FOS 不会随块体存储（但仍会打印到屏幕上）。

cohesion f

指定块体面的黏聚力。若未定义，则该属性由接触属性导出。

friction f

指定块体面的节理摩擦。若未定义，则该属性由接触属性导出。

stiffness-normal f

指定块体面的法向刚度。若未定义，则该属性由接触属性导出。

stiffness-shear f

指定块体面的剪切刚度。若未定义，则该属性由接触属性导出。

该命令之前所需的输入

‐ 定义块体模型并对其进行网格划分（网格单元划分） ‐ 定义地应力 ‐ 定义节理属性（刚度、黏聚力、内摩擦角） ‐ 为块体的“自由”面指定面组名

命令的输出

识别其面与隧道自由面相接触的块体。这些块体按不同组存储在槽“isolated_blocks”中。合并的块体放在同一个块体组中。

对这些组，计算以下结果：

  • 块体每个网格点处的位移
  • 面上的力
  • 每个网格单元面的安全系数

控制台中将给出具有自由面的块体组列表，并包含以下信息：

Group ID     Number of blocks     Volume     FOS-Min     FOS-mean

注意，“FOS-min”定义为每组安全系数的最小值，“FOS-mean”定义为平均值。

可绘制以下结果：

  • 每个块体面的安全系数
    • 块体 – 面块体 – 等值线 – 运动学 FOS
  • 网格点上的位移矢量
    • 块体 - 矢量 – 类型 = 位移
  • 块体位移等值线（量值、x 分量、y 分量或 z 分量）
    • 块体 – 按等值线着色 - 值 = 量值、x 分量等
  • 块体面上的最终边界力
    • 块体 - 矢量 – 类型 = 不平衡力
