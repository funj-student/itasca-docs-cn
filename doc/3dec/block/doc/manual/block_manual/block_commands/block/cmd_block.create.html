block create 命令

语法

block create keyword ... <range>

主要关键字：

砖块（brick）    鼓形（drum）    polyhedron    分组（group）    棱柱（prism）    tetrahedron    隧道（tunnel）    墙体（wall）

创建块体。块体的创建方法由所用的第一个关键字决定。关键字 brick、drum、prism、tetrahedron 或 tunnel 将依据包围区域形状创建块体。关键字 polyhedron 可用于依据多面体的四个或更多面创建块体。

brick f1 f2 <f3 f4 <f5 f6 >>

使用 brick 关键字可以创建规则的六面“砖形”区域。该区域在 \(x\) 方向上从 f1 延伸到 f2；若可选地给出 \(y\) 和 \(z\) 的范围，则同样处理。若未给出 \(y\) 和 \(z\) 的范围，则将其设为与 \(x\) 相等。

drum keyword ...

由两个面创建鼓形块体。所有关键字都是必需的。

center-1 v

指定第一个面的中心。

center-2 v

指定第二个面的中心。

radius-1 f

指定第一个面的半径。

radius-2 f

指定第二个面的半径。

edges i

指定构成鼓形侧面的棱边数。

polyhedron keyword

通过指定多面体的各个面来定义多面体。该命令中必须使用多个 face 关键字来定义单个多面体的所有面。注意：续行符号（…）可以无限制使用——但不要从定义顶点的矢量内部续行。

face <joint-set i > <face-group s1 <slot s2 >> v1 v2 v3 ...

定义多面体的一个面。每个面必须输入 3 到 n 个顶点，按顺时针顺序（从块体外部观察该块体面）。若提供了 joint-set i，则由该面导出的块体将赋给该节理组。类似地，若提供了 face-group s1，则由该面导出的块体将赋给该面组。

group s1 <slot s2 >

当使用 group 时，块体被赋给组 s1。若其后跟有可选的 slot 关键字，则组 s1 被赋给槽 s2；否则赋给名为 默认（Default） 的槽。组逻辑的用法在 i 组（Group） 一节中描述。

prism keyword ...

由两个面创建棱柱形块体，除非将 nonplanar 设为 真值（true），否则这两个面都必须是平面且凸的。可使用 face-1 与 face-2，或 table-1、table-2 与 axis 的组合来指定面。

face-1 v1 v2 v3 ...

用 n 个顶点定义第一个面，按顺时针或逆时针顺序均可。

face-2 v1 v2 v3 ...

定义第二个面，其顶点数与 face-1 相同，且按相同顺序给出。

axis v1 v2

指定一条定义棱柱体方位轴的直线（仅与 table-1 和 table-2 一起使用）。

table-1 s1

使用表格 s1 创建第一个面。

table-2 s2

使用表格 s2 创建第二个面。

nonplanar b

若设为 真值（true），则允许指定的平面为非平面；默认值为 假值（false）。

tetrahedron v1 v2 v3 v4 <joint-set i1 i2 i3 i4 >

由四个指定顶点创建四面体块体。顶点可按任意顺序给出。与 polyhedron face 命令相比，该命令提供了创建四面体块体的更简便方法。使用 joint-set i 指定节理组 ID。

tunnel keyword ...

生成具有完整内、外块体的圆形隧道模型。块体尺寸自中心沿径向向外递增。用户可以控制用于创建该模型的块体数量。

blocks-radial f

设置从隧道边界到模型边界沿径向生成的环形块体数。（默认值 = 1。）

blocks-tangential f

设置隧道圆周每个 45 度扇段内生成的块体数。整个圆周上的总数为 8 × n。（默认值 = 1。）

blocks-axial f

设置沿隧道轴线生成的块体数。（默认值 = 1。）

boundary f

设置从隧道边界到模型边界的隧道半径数，该值必须大于 1.0。（默认值 = 4.0。）

dip f

设置隧道轴线的倾角。（默认值 = 0。）

dip-direction f

设置隧道轴线的倾向。（默认值 = 0。）

length f1 f2

设置隧道相对于隧道原点沿倾角和倾向的位置。隧道沿隧道中心线的长度将为 f1 - f2。（默认值为 f1 = −10，f2 = 10.0。）

origin v

设置隧道中心的原点。隧道轴线将通过该点。（默认值 = 0,0,0。）

radius f

设置隧道的半径。（默认值 = 1.0。）

radius-ratio f

设置自中心向外的径向方向上块体尺寸的乘子。它用于使块体尺寸自中心向外渐变。（默认值 = 1.0。）

wall b

指定所创建的块体应为墙型块体。
