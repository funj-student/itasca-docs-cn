block trace 命令

语法

block trace keyword

主要关键字：

ID 标识（id）    名称（name）    position

追踪某个对象。使用该命令可在模型运行过程中对某些对象的位置和速度进行采样和存储，得到的空间轨迹可绘制出来。每条 block trace 命令只能追踪一个对象。迹线可随时添加。使用 purge 关键字可清除所有迹线的内容，使用 delete 关键字可删除所有迹线。使用 LIST trace 命令可获取所有迹线的汇总信息。

每条迹线都根据 TRACE 命令发出的顺序被赋予唯一的 ID 号。不过，可用 id 关键字指定特定的 ID 号。所有迹线都在同一采样间隔上采样。默认情况下，追踪机制的采样间隔为 10 步。采样间隔可通过 trace rep 关键字或 SET trace rep 命令更改。不能为不同的迹线指定不同的追踪间隔。

id i

追踪 ID 为 i 的块体形心的位置和速度。

name s

为迹线指定名称。

position v

追踪形心最靠近 v 的块体的位置和速度。
