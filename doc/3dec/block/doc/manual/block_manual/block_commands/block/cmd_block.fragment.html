block fragment 命令

语法

block fragment <keyword> <range>

主要关键字：

compute    碎片编号写入附加变量（fill-extra）    按碎片填充分组名（fill-group）    导出碎片信息（dump）

用于如下所述计算和操作碎块数据的命令。

compute

计算模型中的碎块集合。碎块定义为一组通过完整子接触相连的块体。完整子接触是指未发生拉伸或剪切破坏（state = 0）且具有非零黏聚力或抗拉强度的子接触。若两个块体之间的任何子接触是完整的，则认为这些块体属于同一碎块。

fill-extra i

将碎块编号写入块体额外变量索引 i（若省略槽，则该命令默认使用 i = 1）。

fill-group slot s <maximum i >

取计算得到的碎块，在组槽 s 中指定块体组名。这样做是为了能用不同颜色绘制碎块。可选关键字 maximum-groups 将最大组数设为 i。若碎块数大于 i，则组名会重复。

dump <filename s >

将与该碎块相关的信息输出到文件名为 s 的文件（默认值 =“fragments.txt”）。当前输出的内容为碎块编号、碎块体积、碎块表面积以及碎块中的块体数。
