block joint-plane 命令

语法

block joint-plane b <keyword>

主要关键字：

delete    容差（tolerance）    new

切换用于绘制节理平面的计算。该设置控制绘制节理平面所用数据结构的计算。这些数据结构的计算耗时且占用大量内存。取消该计算只影响绘图，不影响任何力学计算。

delete

删除现有的节理平面数据结构。

tolerance f

设置合并节点的容差。若节点之间的距离小于 f，则将合并这些节点。默认值为块体容差（block tolerance）的 0.1 倍。

new b

切换是否使用新的节理绘图算法。默认值为 \(on\)。
