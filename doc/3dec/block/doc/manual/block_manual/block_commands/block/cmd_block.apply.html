block apply 命令

语法

block apply keyword <range>

主要关键字：

velocity    velocity-x    velocity-y    velocity-z

对刚性块体施加速度。速度施加在刚性块体的形心上。可通过提供 范围（range） 来限制该项的作用范围。

velocity v <[blockapplyblock]>

将 \(x\)、\(y\) 和 \(z\) 方向上的恒定速度设为 v。

velocity-x f <[blockapplyblock]>

设置 \(x\) 方向上的恒定速度。

velocity-y f <[blockapplyblock]>

设置 \(y\) 方向上的恒定速度。

velocity-z f <[blockapplyblock]>

设置 \(z\) 方向上的恒定速度。


block apply 关键字块

以下关键字适用于 block apply 命令的下列各个关键字：

fish s

指定的 FISH 符号用于提供乘子。

table s

设置荷载乘子，其值来自 table create 命令给出的乘子。表格必须由一系列数据对组成：时间、f(time)。在给定的离散点之间进行线性插值。
