block cut 命令

语法

block cut keyword ... <range>

主要关键字：

dfn    几何（geometry）    joint-set    节理组 ID（jointset-id）    set    隧道（tunnel）

切割块体。该命令根据下列关键字指定的参数生成一组不连续面。块体会被完全劈开（即不允许部分裂隙）。

dfn keyword

按指定的离散裂隙网络切割块体。DFN 中的每条裂隙都会产生一次切割，但请注意，生成的节理通常大于 DFN 中的实际裂隙。划分网格之后，使用命令 CHANGE dfn 为 DFN 裂隙内部与外部的子接触设置不同的属性。必须提供 name 或 id 关键字。

name s

使用名称为 s 的 DFN 进行切割。

id i

使用 ID 为 i 的 DFN 进行切割。

geometry s

使用名称为 \(s\) 的几何体集合进行切割。警告：曲面几何体中的每个多边形都会产生一次切割，因此为使创建的块体数量最少，建议尽可能简化几何体以减少多边形数量。

joint-set <keyword ...>

按所给关键字描述的节理组切割块体。若未给出，这些参数的默认值为零，但 persistence 和 number 除外，它们的默认值均为 1。

dip f <f2 >

设置组成该节理组的节理的倾角（以度为单位，即节理在 \(y\) = 0 平面以下的角度；见下文注释）。可选的随机偏差 f2 指定偏差限值；每次块体劈分施加不同的偏差。

dip-direction f <f2 >

设置组成该节理组的节理的倾向（以度为单位），其角度为 \(a\)，其中 0 < \(a\) < 360◦，自正 \(z\) 轴起顺时针量测，该轴视为北向（见下文注释）。由 f 指定随机偏差，每次块体切割的偏差各不相同。

join

跨该命令创建的节理合并块体。

number i

指定该组中的节理数目。节理关于节理组原点（由 origin 关键字给出）对称生成。

origin v

设置节理组原点（即起点）。生成的第一条节理将通过该点。

points v1 v2 v3

通过由点 v1、v2 和 v3 定义的平面来指定节理方位。

persistence f

设置位于节理路径上的任一给定块体被劈开的概率（即若 f = 0.5，则平均有 50% 的块体会被劈开）。

spacing f <f2 >

设置该节理组中节理之间的间距。可通过 f2 可选地指定随机偏差（每次块体切割各不相同）。

jointset-id i

设置用该命令创建的所有面和接触的节理组 ID。这将覆盖本应自动分配的编号。节理面 ID 通常会在每次创建新面的操作中自动递增，自动 ID 分配的基准编号从 0 开始。使用 set minimum-id 关键字（见下文）可将基准编号设为 0 以外的值。节理组 ID 可与 kwd:\(range joint-set\) 一起用于识别特定的节理。

set

配置用该命令执行的切割操作的选项。

split-face b

指定是否劈分非凸面。（默认值为 开启（on）。）

minimum-angle f

设置块体切割所允许的最小棱边角。（默认值为 1º。）

minimum-id i

设置节理面 ID 编号的起始编号。

tunnel keyword ...

方法 1：在由关键字 face-1 和 face-2 定义的两个面之间创建隧道。隧道面的形状由任意数量的顶点规定，其坐标为 顶点 a1（va1）、顶点 a2（va2）、顶点 a3（va3） 等。顶点之间的直线（按所列的各自顺序）连接这两个面，从而定义隧道边界。两个面上必须具有相同数量的顶点，这些顶点可以位于模型内部或外部。

方法 2：在由关键字 table-1 和 table-2 定义的两个表格之间创建隧道。隧道的创建步骤相同：各表格上按各自顺序排列的点以直线相连，从而定义隧道边界，等等。表格在第三维上的方位由 axis 关键字确定。

face-1 顶点 a1（va1 ）顶点 a2（va2 ）顶点 a3（va3 ）... &

用 3 到 n 个顶点定义隧道面。若对较长的顶点输入行使用续行符（&），不要将 v 的值拆分到多行。

face-2 顶点 b1（vb1 ）顶点 b2（vb2 ）顶点 b3（vb3 ）... &

定义对应的隧洞面，其顶点数与为 face-1 提供的顶点数相同。

radial

使隧道形状所用的切割面为指向中心的径向切割，而不是与隧道边缘相切。注意：模型中看似多出的切割线是由于任何单次切割都必须完全穿过块体所致。因此，穿过第一个顶点的第一次切割会同时切穿隧道轮廓的两侧。

group s <slot s >

为所定义隧道区域内的块体指定特定的组名（以及可选的槽）。

axis v1 v2

使所要创建的隧道沿由 v1 和 v2 定义的轴线，使用 table-1 和 table-2 定向。

table-1 s

指定用作第一个隧道面的表格。

table-2 s

指定用作第二个隧道面的表格。
