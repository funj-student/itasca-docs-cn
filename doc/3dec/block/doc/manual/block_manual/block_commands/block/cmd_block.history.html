block history 命令

语法

block history <name s > location-keyword variable-keyword <keyword ...>

主要关键字：

节点 ID 位置（gridpointid）    position    单元 ID 位置（zoneid）    acceleration    acceleration-x    acceleration-y    acceleration-z    condition    density    displacement    displacement-x    displacement-y    displacement-z    extra    pore-pressure    property    property-fluid    property-thermal    ratio-local    strain-increment    strain-rate    应力（stress）    应力强度比（stress-strength-ratio）    stress-effective    温度（temperature）    timestep-dynamic    unbalanced-force    unbalanced-force-x    unbalanced-force-y    unbalanced-force-z    velocity    velocity-x    velocity-y    velocity-z

添加块体数值的历史记录。请参阅通用的 c 历程（history） 命令。可使用可选的 name 关键字为该历史记录指定名称，以便日后引用。若未指定，则将根据其内部赋予的 ID 号自动给出默认名称。

该命令要求提供一个 location-keyword 和一个 variable-keyword。这两类关键字在下文分组列出。

可对块体所涵盖的任意位置处的任意标量场变量记录块体历史。一旦指定，历史记录的位置将随块体一起移动。

历史记录的位置可按多种方式指定：按空间位置指定，按具有特定 ID 号的块体形心指定，或按具有特定 ID 号的网格点位置指定。

若历史记录值基于网格点，则使用块体内部的加权函数计算该值。

若该值基于网格单元，且所给位置与该网格单元的形心不一致，则通过曲线拟合算法确定该值。所用算法可在后面的 [blockhistoryoptions] 中指定。默认情况下，认为值在网格单元内为常数。

注意，若要记录特定网格点的历史记录，需以 gridpointid 作为位置来记录块体历史，或指定网格点的 position。

用于 location-keyword 的关键字选项

gridpointid i

将历史记录位置设置在 ID 为 i 的网格点处。

position v

将历史记录位置设置在位置 v 处。

zoneid i

将历史记录位置设置为 ID 为 i 的网格单元的形心。


用于 variable-keyword 的关键字选项

该内容至少还会在另一处重复出现

acceleration [blockhistoryoptions]

网格点处的加速度大小（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-x [blockhistoryoptions]

网格点处的 x 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-y [blockhistoryoptions]

网格点处的 y 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-z [blockhistoryoptions]

网格点处的 z 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

condition [blockhistoryoptions]

衡量网格单元变形程度的指标。该数值介于 0 与 1 之间，1 表示理想四面体，0 表示严重变形的网格单元。它是边长比、体积比和正交性三种度量的最小值。参见 block.zone.condition。

density [blockhistoryoptions]

网格单元的密度。

displacement [blockhistoryoptions]

网格点处的位移大小

displacement-x [blockhistoryoptions]

网格点处的 x 向位移

displacement-y [blockhistoryoptions]

网格点处的 y 向位移

displacement-z [blockhistoryoptions]

网格点处的 z 向位移

extra [blockhistoryoptions]

额外变量的值。所用的额外变量索引默认为 1，可通过 index 修饰符关键字更改。该值默认取自网格点的额外变量，但可通过 source 修饰符关键字指定。该值默认按标量浮点类型处理，但可通过 type 修饰符关键字指定。

pore-pressure [blockhistoryoptions]

网格单元中的孔隙压力。默认取网格点孔隙压力，但可用 source 关键字修饰符指定采用网格单元平均孔隙压力。

property [blockhistoryoptions]

网格单元力学本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

property-fluid [blockhistoryoptions]

网格单元流体本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

property-thermal [blockhistoryoptions]

网格单元热学本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

ratio-local [blockhistoryoptions]

各网格点处的局部不平衡力比率。与所有结果一样，可使用 :lkwd:’log’ 关键字修饰符将其换算为该值的对数。

strain-increment [blockhistoryoptions]

网格单元的应变增量张量，由当前位移场确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

strain-rate [blockhistoryoptions]

网格单元的应变率张量，由当前速度场确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress [blockhistoryoptions]

网格单元的应力张量，由各子网格单元应力的加权平均确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress-strength-ratio [blockhistoryoptions]

当前应力与该网格单元破坏面的比值，由当前网格单元本构模型确定。并非所有本构模型都支持该计算。若不支持，则返回值为 10。返回值一般以 10 为上限。

stress-effective [blockhistoryoptions]

网格单元的有效应力张量，由各子网格单元应力的加权平均减去网格单元平均孔隙压力确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

temperature [blockhistoryoptions]

网格点处的温度。可用 source 修饰关键字改为指定采用基于网格单元的温度。

timestep-dynamic [blockhistoryoptions]

该特定网格点的局部临界动力时步。（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

unbalanced-force [blockhistoryoptions]

网格点处的不平衡力大小。

unbalanced-force-x [blockhistoryoptions]

网格点处的 x 向不平衡力。

unbalanced-force-y [blockhistoryoptions]

网格点处的 y 向不平衡力

unbalanced-force-z [blockhistoryoptions]

网格点处的 z 向不平衡力

velocity [blockhistoryoptions]

网格点处的速度大小

velocity-x [blockhistoryoptions]

网格点处的 x 向速度

velocity-y [blockhistoryoptions]

网格点处的 y 向速度

velocity-z [blockhistoryoptions]

网格点处的 z 方向速度


block history 关键字块

以下修饰符可用于为 block history 关键字提供附加信息。使用其中任一修饰符时，历史记录的位置需按上文所述通过 position、zone-id 或 gridpoint-id 指定。

以下关键字适用于 block apply 命令的下列各个关键字：acceleration、acceleration-x、acceleration-y、acceleration-z、condition、density、displacement、displacement-x、displacement-y、displacement-z、extra、pore-pressure、property、property-fluid、property-thermal、ratio-local、strain-increment、strain-rate、应力（stress）、stress-effective、应力强度比（stress-strength-ratio）、温度（temperature）、timestep-dynamic、unbalanced-force、unbalanced-force-x、unbalanced-force-y、unbalanced-force-z、velocity、velocity-x、velocity-y 和 velocity-z。

component keyword

该关键字用于选择从矢量类型的值（如速度或位移）中提取哪个标量分量。若值类型不是矢量，则忽略该设置。可用的选项有：

x

矢量的 x 分量

y

矢量的 y 分量

z

矢量的 z 分量

magnitude

矢量的模

index i

对于需要索引的关键字（最典型的是 extra），此参数指定应使用的索引。默认值为 1。

gravity b

若为 开启（on），则返回的施加力中包含重力。默认值为 关闭（off）。

gridpoint-id i

通过 ID 号为 i 的网格点的位置来指定历史记录的位置。

label s

为历史记录指定一个标签，用于打印输出和绘图。

log b

若为 开启（on），则返回的数值为原始值绝对值的以 10 为底的对数。默认值为 关闭（off）。

method

该关键字指定用于将基于网格单元的量插值到空间任意位置（包括网格点位置）的计算方法。

constant

假定数值在网格单元内部为常数。这是默认选项。位于网格点处或网格单元边界上的值将选取一个相邻网格单元来计算。

average

该方式使用与该网格点相连的所有网格单元的体积加权平均值。

inverse-distance-weight

该方式使用该点紧邻区域内最多 32 个网格单元的加权平均值。权重由网格单元形心到指定点距离的幂确定。

power f

指定用于对数值加权的距离幂次。默认的幂值为 3.0。

radius-ratio f

指定所选网格单元距该点的最大距离之比，该比值用于计算加权值。距离超过该值的网格单元将被折减。默认值为 0.75。

polynomial <tolerance f >

根据该点附近的网格单元，使用多项式函数拟合。退化自由度会被检测并剔除。可选的 tolerance 标志可用于更改检测退化所用的值。默认值为 1e-7。

name s

某些关键字（最典型的是 property）需要给出名称值才能完整指定。该名称决定所提取的具体属性名。

position v

在 v 处指定历史记录的位置。该位置必须位于某个网格单元内部。

quantity keyword

该关键字用于选择从对称张量类型的值（如应力或应变）中提取哪个标量分量。若值类型不是张量，则忽略该设置。可用的选项有：

intermediate

中间主应力

maximum

最大（最正）的主应力值。请注意，在 FLAC3D 中压应力为负值（compressive stresses are negative）。

mean

平均压力值，定义为张量的迹除以 3。对于应力，该量通常称为压力。

minimum

最小（最负）主应力。注意在 FLAC3D 中压应力为负（compressive stresses are negative）。

norm

应变率的范数；参见 网格场数据名称（Zone Field Data Names） 中的公式

octahedral

八面体应力；参见 网格场数据名称（Zone Field Data Names） 中的公式

shear-maximum

最大剪应力

total-measure

在主空间中张量值到原点的距离

volumetric

体积变化，即迹

von-mises

Von Mises 度量；参见 网格场数据名称（Zone Field Data Names） 中的公式

xx

张量的 xx 分量

xy

张量的 xy 分量

xz

张量的 xz 分量

yy

张量的 yy 分量

yz

张量的 yz 分量

zz

张量的 zz 分量

source keyword

某些关键字（如 extra 和 pore-pressure）既可从网格单元结构、也可从网格点结构提取。默认值为 gridpoint。

gridpoint

数值直接取自网格点。

zone

从网格单元中提取数值。

stress b

少数张量类型的 quantity 选项会根据该值是否被视为应力而具有不同行为。当该值来自 extra 之类的变量时，无法自动判定。此选项允许用户指定传入的张量值应按应力处理。

type keyword

在某些情况下，值的类型（标量、矢量或张量）无法事先确定。例如，额外变量可保存全部三种类型的值。该关键字允许指定假定其所属的类型。若原始值类型不匹配，则返回 0.0。

scalar

标量浮点类型。这是默认值。

vector

矢量类型。

tensor

张量类型。

zone-id i

指定历史记录的位置位于 ID 为 i 的网格单元的形心处。
