block import 命令

语法

block import filename s <binary>

从文件导入一组块体。将导入名为 s 的文件。文件名中可包含路径。若未指定扩展名，则假定为 .3dgrid 网格文件（.3dgrid）。

可给出可选关键字 二进制格式标志（sbinary） 以表示二进制输入文件。默认情况下假定为 ASCII 文件格式。

导入的块体可以是刚性的，也可以是可变形的（已划分网格的）。刚性块体由面定义，可变形块体由网格单元定义。

3DEC 网格格式说明

3DEC 的 ASCII 格式网格文件具有以下规定：注释行以星号开头；空行将被忽略；数值之间的逗号分隔符是可选的。

以“G”开头的行表示网格点定义。一个网格点包含一个整数标识符（ID 编号），随后是该网格点的 x、y、z 坐标（浮点数）。

以“F”开头的行表示面定义。一个面包含一个整数标识符（ID 号），其后是三个或更多的网格点 ID（整数）。只需为刚性块体定义面。

以“Z”开头的行表示网格单元定义。一个网格单元包含一个网格单元标识符（ID 号），以及构成该网格单元的 4 个网格点的标识符（仅支持四面体网格单元）。只需为可变形块体定义网格单元。

以“B”开头的行表示块体定义。一个块体包含一个块体标识符（ID 号）、一个整数网格单元标识符，然后是前面带 面 ID 列表标记（sF） 的面 ID 列表，或前面带 单元 ID 列表标记（sZ） 的网格单元标识符列表。

网格点和网格单元的 ID 号必须为正整数。ID 号不必按顺序或连续排列（允许编号中存在空缺）；但是，网格单元或面所引用的每个网格点 ID 都必须存在于网格点列表的某处。

以“JS”开头的行表示一个节理组。节理组 ID 之后是成对的、由 s- 连接的块体。本节内容是可选的。若未指定节理组 ID，将由 3DEC 自动分配。

以“BGROUP”开头的行表示块体的组定义。紧跟单词 BGROUP 之后的文本即为该组的名称。在组名之后，用块体 ID 号依次列出属于该组的所有块体。

以“ZGROUP”开头的行表示网格单元的组定义。紧跟单词 ZGROUP 之后的文本即为该组的名称。在组名之后，用网格单元 ID 号依次列出属于该组的所有网格单元。

以“FGROUP”开头的行表示一组面。面分组用于范围逻辑中，使用户可以将特性、边界条件、速度等施加到一组面上。面分组行包含面分组名称。FGROUP 行之后是包含先前定义的面标识符的各行。面标识符之间以空格分隔。创建网格时，这会将分组名称分配给该行中的所有面。

以“JGROUP”开头的行表示节理组。紧跟单词 JSGROUP 之后的文本是该组的名称，以及由 s- 连接的块体对。
