block dynamic 命令

语法

block dynamic keyword <range>

主要关键字：

特征值计算（eigen）    list    free-field

配置动力计算可用的选项。

eigen <keyword>

计算弹性系统的固有频率与振型。进一步说明见下文。

delete

删除特征值数据。

list

列出特征模态频率（假定已计算过）。

modes i <keyword>

计算前 i 阶特征模态值。将列出频率最低的 10 阶模态。

模态 说明
1 第一阶弯曲模态
2 与第 1 阶模态正交的模态
3 第二阶弯曲模态
4 与第 2 阶模态正交的模态
5 第一阶扭转模态
6 第三阶弯曲模态
7 与第 6 阶模态正交的模态
8 轴向变形模态
9 第四阶弯曲模态
10 与第 9 阶模态正交的模态
setmode

将计算得到的模态复制到网格点额外变量以便绘图。警告：从 1 到 \(n\) 的网格点额外变量将被矢量覆盖（其中 \(n\) 为分析中的模态数）。

tolerance f

设置容差。

free-field <keyword>

对动力自由场进行操作。讨论见下文。

apply <keyword ...>

创建自由场网格单元块体。材料属性与本构模型取为模型侧面块体中的值。每个自由场网格中的块体都是合并的。自由场网格的应力由模型侧面网格单元获得。对自由场网格点施加平衡力以维持静力平衡。自由场网格点上不施加任何边界条件。在模型侧面的所有网格点上，会发生以下情况：

  • 施加自由场条件（移除任何固定速度条件）。
  • 施加自由场应力。
  • 施加用于维持静力平衡的平衡力。
x 向下限（fx1 ）x 向上限（fx2 ）z 向下限（fz1 ）z 向上限（fz2 ）

模型四个边界的位置（默认值 = \(x\) 和 \(z\) 坐标的最小值与最大值）。

gap f

设置自由场与主模型之间的显示间隙（默认值 = 模型长度的 5%）。

thickness f

设置自由场块体的厚度（默认值 = 模型长度的 5%）。

tolerance f

用于查找模型边界上需施加自由场条件的网格点的容差（默认值 = ATOL）。

delete

删除所有自由场网格。

link b

将自由场与主模型连接/重新连接（开启（on）；默认值）。设为 关闭（off） 则断开连接。

list

列出动力自由场数据。

特征值计算

该命令仅适用于刚性块体模型。刚性块体系统的运动学变量为每个块体的 6 个自由度，即三个平动和三个转动。在刚性块体模型中，可变形性由节理刚度给出。为刚性块体系统组装整体刚度矩阵，该矩阵将相邻块体施加于块体的力与力矩同块体的位移和转动联系起来。质量矩阵假定为对角矩阵，对每个块体而言由三个等于块体质量的项以及三个坐标方向上的转动惯量组成。这一假定包含近似，因为坐标方向上的转动惯量一般并非块体的主转动惯量。

必须先计算动力（未缩放）质量。必须给出命令 SET dynamic on，随后给出 执行计算时步（model cycle） 0，以强制计算动力质量。注意：特征值计算需要求解刚度矩阵，占用较大的存储空间。因此，建议在执行特征值计算之前先保存模拟状态，然后再恢复以继续动力分析。更多信息参见主题 i 固有频率与振型计算（Calculation of Natural Frequencies and Modes of Vibration）。

动力自由场

使用 自由场边界施加命令（block dynamic free-field apply） 可创建动力自由场。该动力自由场由一维有限差分计算构成，与主计算并行执行，并为动力分析提供侧向边界条件，此时在模型底部施加竖直传播的平面波。自由场对模型的要求如下：

  • 可变形块体
  • 矩形底面
  • 平行于 \(x\) 轴和 \(z\) 轴的竖直侧向边界（假定 \(y\) 轴为竖直方向）
  • 顶面可能不规则（因此自由场高度也不同）

六个自由场块体由四个侧向自由场网格和四个角部自由场网格组成，前者对应模型的四个侧面，后者充当侧向自由场网格的自由场边界。自由场网格中的块体是标准的可变形块体。自由场网格中的节理结构与模型侧向边界中的相同。因此，模型侧面上的节理迹线假定水平延伸进入自由场网格。默认情况下，创建自由场块体时自由场网格中的所有块体都会合并，但用户之后可以取消合并。自由场块体的网格划分与模型侧面的网格划分类似。侧向自由场块体厚度为两个网格点，并相互连接以一起运动。角部自由场网格在每一层有四个网格点，同样相互连接以一起运动。

在创建动力自由场之前，模型必须处于静力平衡状态。

使用自由场逻辑的标准步骤如下：

  1. 将主模型运行至静力平衡。
  2. 自由场边界施加命令（block dynamic free-field apply）
  3. 在模型底部和自由场底部设置动力边界条件（对于深部地下模型，还可能在顶部设置）。
  4. 运行动力分析。

在某些情况下，用户可能需要改变自由场网格的初始状态（例如取消某些块体的合并、改变属性或荷载等）。可按如下方式进行：

  1. 将主模型运行至静力平衡。
  2. 自由场边界施加命令（block dynamic free-field apply）
  3. 自由场边界连接命令（block dynamic free-field link） 关闭（off）
  4. 在自由场中进行任何更改。
  5. 在自由场底部设置静力边界条件。
  6. 运行至静力平衡。
  7. 自由场边界连接命令（block dynamic free-field link） 开启（on）
  8. 在模型底部和自由场底部设置动力边界条件（对于深部地下模型，还可能在顶部设置）。
  9. 运行动力分析。
