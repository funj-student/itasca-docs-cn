block face apply 命令

语法

block face apply keyword <history s > <range>

主要关键字：

convection    flux    点荷载（point-load）    x 向点荷载（point-load-x）    y 向点荷载（point-load-y）    z 向点荷载（point-load-z）    stress-principal    应力（stress）    stress-xx    stress-xy    stress-xz    stress-yy    yz 向应力（stress-yz）    stress-zz    westergaard

在范围内的块体面上施加条件。

convection f1 f2 <[blockfaceapplyblock]>

f1 为发生对流时介质的温度 \(T_e\)。f2 为对流传热系数 \(h\)（例如，单位为 \(W⁄m^{2}\)º C）。对流边界条件施加在指定的面范围内。history 关键字对对流不起作用。

flux f <[blockfaceapplyblock]>

f 为初始热通量（例如，单位为 \(W⁄m^2\)）。通量施加在指定的面范围内。该命令用于指定流入（f > 0）或流出（f < 0）网格热边界的恒定通量。通量的衰减可通过可选的 history 关键字用 FISH 历史记录表示。例如，下面的 FISH 函数对所施加的通量作指数衰减：

[theini = 0.0]
[deconst = -1.0]
fish def decay
  decay=math.exp(deconst*(thermal.age-thini))
end
block face apply flux=10 hist fish @decay
point-load v1 location v2 <[blockfaceapplyblock]>

在位置 \(v2\) 处施加大小为 \(v1\) 的点荷载（仅适用于可变形块体）。网格点力由输入位置插值计算得到。

point-load-x f location v <[blockfaceapplyblock]>

在位置 \(v2\) 处沿 x 方向施加大小为 \(f\) 的点荷载（仅适用于可变形块体）。网格点力由输入位置插值计算得到。

point-load-y f location v <[blockfaceapplyblock]>

在位置 \(v2\) 处沿 y 方向施加大小为 \(f\) 的点荷载（仅适用于可变形块体）。网格点力由输入位置插值计算得到。

point-load-z f location v <[blockfaceapplyblock]>

在位置 \(v2\) 处沿 z 方向施加大小为 \(f\) 的点荷载（仅适用于可变形块体）。网格点力由输入位置插值计算得到。

stress-principal keyword ... <[blockfaceapplyblock]>

在范围内的块体面上施加应力。

direction-intermediate v

设置中间主应力方向。

direction-maximum v

设置最大主应力方向。

direction-minimum v

设置最小主应力方向。

intermediate f

设置中间主应力。

maximum f

设置最大主应力。

minimum f

设置最小主应力。

dip-maximum f

设置最大主应力倾角。

dip-direction-maximum f

设置最大主应力的倾向。

dip-intermediate f

设置中间主应力倾角。

dip-direction-intermediate f

设置中间主应力的倾向。

dip-minimum f

设置最小主应力倾角。

dip-direction-minimum f

设置最小主应力的倾向。

gradient-z

设置 z 方向上的应力梯度。只能指定 z 方向的梯度。其他方向会按其比例缩放，以防止应力旋转。

origin v

指定应力测量的位置。

stress 初始 xx 应力（fsxx0 ）初始 yy 应力（fsyy0 ）初始 zz 应力（fszz0 ）初始 xy 应力（fsxy0 ）初始 xz 应力（fsxz0 ）初始 yz 应力（fsyz0 ）<keyword> <[blockfaceapplyblock]>

设置边界应力参数：\(xx\) 应力、\(yy\) 应力、\(zz\) 应力、\(xy\) 应力、\(xz\) 应力、\(yz\) 应力。若给定梯度，则假定这些应力施加在 0,0,0 处。

必须为 \(block face apply stress\) 命令指定范围短语。

注意

默认情况下，所有荷载和应力都假定为恒定且永久，并叠加到已有的永久荷载上。若在与荷载或应力同一命令行上给出 \(fish\) 或 \(table\) 关键字，则施加瞬态（随时间变化）荷载（见下文）。

gradient-x xx 应力 x 向梯度（fsxxx ）yy 应力 x 向梯度（fsyyx ）zz 应力 x 向梯度（fszzx ）xy 应力 x 向梯度（fsxyx ）xz 应力 x 向梯度（fsxzx ）yz 应力 x 向梯度（fsyzx ）

指定 x 方向上的应力梯度。

gradient-y xx 应力 y 向梯度（fsxxy ）yy 应力 y 向梯度（fsyyy ）zz 应力 y 向梯度（fszzy ）xy 应力 y 向梯度（fsxyy ）xz 应力 y 向梯度（fsxzy ）yz 应力 y 向梯度（fsyzy ）

指定 y 方向上的应力梯度。

gradient-z xx 应力 z 向梯度（fsxxz ）yy 应力 z 向梯度（fsyyz ）zz 应力 z 向梯度（fszzz ）xy 应力 z 向梯度（fsxyz ）xz 应力 z 向梯度（fsxzz ）yz 应力 z 向梯度（fsyzz ）

指定 z 方向上的应力梯度。

若指定了梯度，则边界应力呈线性变化，其中 sxx0 等为由 stress 关键字定义的位于原点（0,0,0）处的应力，并且其中：

\(sxx =sxxo + (sxxx∗x) + (sxxy∗y) + (sxxz∗z)\) \(syy =syyo + (syyx∗x) + (syyy∗y) + (syyz∗z)\) \(szz =szzo + (szzx∗x) + (szzy∗y) + (szzz∗z)\) \(sxy =sxyo + (sxyx∗x) + (sxyy∗y) + (sxyz∗z)\) \(sxz =sxzo + (sxzx∗x) + (sxzy∗y) + (sxzz∗z)\) \(syz =syzo + (syzx∗x) + (syzy∗y) + (syzz∗z)\)

gradient-x、gradient-y 和 gradient-z 关键字必须在同一输入行上跟在 block face stress 命令之后。（若需要续行，请在行末使用 …。）

注意，所施加的应力始终作用于原点（0,0,0）。示例：

block face apply stress -5,0,0,0,0,0 &
grad-z 5,0,0,0,0,0 &
range pos-z -1 1

; 此命令为 xx 应力施加梯度，使其从 −10
            ;   （z = −1 处）变化到 z = 1 处的零。
stress-xx f <gradient v > <[blockfaceapplyblock]>

设置 \(xx\) 方向上的边界应力。可选的 \(gradient\) 关键字可用于指定 xx 应力在 x、y 和 z 方向上的变化。若给定梯度，则假定应力值 \(f\) 施加在 0,0,0 处。

stress-xy f <gradient v > <[blockfaceapplyblock]>

设置 \(xy\) 方向上的边界应力。可选的 \(gradient\) 关键字可用于指定 xy 应力在 x、y 和 z 方向上的变化。若给定梯度，则假定应力值 \(f\) 施加在 0,0,0 处。

stress-xz f <gradient v > <[blockfaceapplyblock]>

设置 \(xz\) 方向上的边界应力。可选的 \(gradient\) 关键字可用于指定 xz 应力在 x、y 和 z 方向上的变化。若给定梯度，则假定应力值 \(f\) 施加在 0,0,0 处。

stress-yy f <gradient v > <[blockfaceapplyblock]>

设置 \(yy\) 方向上的边界应力。可选的 \(gradient\) 关键字可用于指定 yy 应力在 x、y 和 z 方向上的变化。若给定梯度，则假定应力值 \(f\) 施加在 0,0,0 处。

stress-yz f <gradient v > <[blockfaceapplyblock]>

设置 \(yz\) 方向上的边界应力。可选的 \(gradient\) 关键字可用于指定 xx 应力在 x、y 和 z 方向上的变化。若给定梯度，则假定应力值 \(f\) 施加在 0,0,0 处。

stress-zz f <gradient v > <[blockfaceapplyblock]>

设置 \(zz\) 方向上的边界应力。可选的 \(gradient\) 关键字可用于指定 xx 应力在 x、y 和 z 方向上的变化。若给定梯度，则假定应力值 \(f\) 施加在 0,0,0 处。

westergaard keyword ... <[blockfaceapplyblock]>

在块体面上的网格点处添加附加动力质量，以模拟相邻水体的作用。该方法由 Westergaard（1933）提出。

density-water f

设置水的密度。

depth f

设置水库中水的平均深度（恒定附加质量）。若已指定水面，则不使用该值。

direction f

设置重力向量（若与静态重力定义不同）。

project i

完整求解涉及每个网格点的一个 3 × 3 矩阵。在 3DEC 中，该矩阵被对角化。默认情况下，每一行都被累加到对角线上。该关键字（proj = 1）通过基于面法向计算对角线来提供更好的解。

remove

移除任何先前已定义的附加质量。

surface v

若需要计算深度，则设置水面位置。

mass-x

仅在 \(x\) 方向上添加质量。

mass-y

仅在 \(y\) 方向上添加质量。

mass-z

仅在 \(z\) 方向上添加质量。


block face apply 关键字块

以下关键字适用于 block face apply 命令的下列各个关键字：

fish s

指定的 FISH 符号用于提供乘子。

table s

设置荷载乘子，其值来自 table create 命令给出的乘子。表格必须由一系列数据对组成：时间、f(time)。在给定的离散点之间进行线性插值。
