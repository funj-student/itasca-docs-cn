block face list 命令

语法

block face list keyword <rigid> <range>

主要关键字：

bad-edge    bad-normal    check    extra    分组（group）    information    position    vertices

列出块体面的信息。输出仅针对可变形块体；若给出关键字 rigid，则输出改为仅列出刚性块体。

bad-edge

列出同一条棱边上存在 3 个顶点的块体面；用于诊断网格划分问题。

bad-normal

列出法向不指向块体外部（即反向面）的块体面。

check

列出对与面子接触逻辑相关的数据结构进行内部检查所得的信息。用于诊断问题。

extra i

列出额外变量信息。

group

列出组名。

information <keyword>

列出一般面信息，包括面编号、块体编号、法向量、面积、节理编号和组名。这是 block face list 命令的默认关键字。

position

列出面形心的位置。

vertices

列出范围内构成各面的顶点。
