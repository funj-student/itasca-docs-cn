block zone initialize 命令

语法

block zone initialize keyword <range>

主要关键字：

状态（state）    应力（stress）    stress-principal    stress-xx    stress-xy    stress-xz    stress-yy    yz 向应力（stress-yz）    stress-zz

初始化网格单元变量。

state i

四面体的塑性指示被设为 i。通常 i 取值为 0，以便重置破坏指示。

stress <keyword ...>
初始化完整应力状态，按分量指定。未指定的分量假定为零。
警告——该命令仅初始化网格单元应力。要同时初始化网格单元应力和接触应力，请使用 block insitu。
xx f

xx 应力分量

xy f

xy 应力分量

xz f

xz 应力分量

yy f

yy 应力分量

yz f

yz 应力分量

zz f

zz 应力分量

stress-principal <keyword ...>
主应力状态，可用现有关键字按量值和方向指定。注意：至少必须指定两个方向，未指定的量值假定为零。注意：在每个下列关键字之后都可以使用 [zoneinitializeoptions]，从而可独立地随空间变化。
警告——该命令仅初始化网格单元应力。要同时初始化网格单元应力和接触应力，请使用 block insitu。
direction-intermediate v [zoneinitializeoptions]

中间主应力方向。

direction-maximum v [zoneinitializeoptions]

最大主应力方向。

direction-minimum v [zoneinitializeoptions]

最小主应力方向。

intermediate f [zoneinitializeoptions]

中间主应力量值。

maximum f [zoneinitializeoptions]

最大（最正）主应力。

minimum f [zoneinitializeoptions]

最小（最负）主应力。

stress-xx f [zoneinitializeoptions]

初始化网格单元的 \(xx\) 应力（总应力）。

stress-xy f [zoneinitializeoptions]

初始化网格单元的 \(xy\) 应力（总应力）。

stress-xz f [zoneinitializeoptions]

初始化网格单元的 \(xz\) 应力（总应力）

stress-yy f [zoneinitializeoptions]

初始化网格单元的 \(yy\) 应力（总应力）

stress-yz f [zoneinitializeoptions]

初始化网格单元的 \(yz\) 应力（总应力）

stress-zz f [zoneinitializeoptions]

初始化网格单元的 \(zz\) 应力（总应力）


block zone initialize 关键字块

以下关键字可用于修改（modify）给定的值。若修饰符关键字的说明中提到它可作用于何种类型的值（例如标量值、矢量值等），务必确保修饰符与主关键字值的类型相匹配。

以下关键字适用于 block zone initialize 命令的下列各个关键字：stress-xx、stress-xy、stress-xz、stress-yy、yz 向应力（stress-yz） 和 stress-zz。中间主应力方向（direction-intermediate）、最大主应力方向（direction-maximum）、最小主应力方向（direction-minimum）、中间（intermediate）、最大值（maximum） 和 最小值（minimum）。

add

将（Add）指定值加到现有值上。

gradient v <origin v >

对给定的标量值施加梯度（gradient）。

multiply

将（Multiply）现有值乘以指定值。

vary v

对所给的标量值应用 线性变化（linear variation）。
