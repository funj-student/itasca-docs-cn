block zone size 命令

语法

block zone size keyword <range>

主要关键字：

center    边长（edgelength）    孤立点（isolated-point）

在使用 block zone generate-new 命令之前设置可变形块体的网格划分条件。

center v keyword ...

从点 v 生成径向渐变的网格。若 center 位于某个块体内部，则将生成棱边长度为 edgelength-center f 的均匀网格。

edgelength-1 f

将距中心点 Distance-1 处的棱边长度设为 f。

distance-1 f

设置距中心点的距离 f，在该距离处将使用 edgelength-1。

edgelength-2 f

将距中心点 Distance-2 处的棱边长度设为 f。

distance-2 f

设置距中心点的距离 f，在该距离处将使用 edgelength-2。

edgelength f

参数 f 定义四面体网格单元的平均棱边长度。

isolated-point v

指定块体内部孤立点 v 附近的网格单元尺寸。

edgelength f

参数 f 定义 Isolated-Point 附近四面体网格单元的平均棱边长度。
