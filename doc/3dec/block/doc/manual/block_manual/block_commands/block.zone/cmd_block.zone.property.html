block zone property 命令

语法

block zone property <density f > keyword ... <range>

对本构模型进行属性赋值。属性是“名称 值”对，其中名称是命令中给出的关键字，值的类型则特定于该属性。

模型与属性

也可以给出特殊的 density 关键字，用于为网格单元指定密度；它不是本构模型属性，而是存储在网格单元类中。

所有本构模型都具有与之关联的属性。

3DEC 中有 19 个基本力学本构模型和 11 个选项相关的力学模型。它们分类如下：弹性（elastic）、弹塑性（elastic-plastic）、动力（dynamic）、蠕变（creep）、热学（thermal）。
