block zone generate 命令

语法

block zone generate keyword <range>

主要关键字：

center    边长（edgelength）    high-order-tetra    限制迭代节点数（limit-iteration）    hexahedra    详细输出（verbose）    rezone    alternate    check    fix    网格点匹配（gridpoint-match）    gridpoint-post-match    容差（tolerance）

设置可变形块体的网格划分条件。

center v keyword ...

从点 v 生成径向渐变的网格。若 center 位于某个块体内部，则将生成棱边长度为 edgelength-center f 的均匀网格。

edgelength-center f

将中心点处的棱边长度设为 f。

edgelength-distance f

将 distance 处的棱边长度设为 f。

distance f

设置距中心点的距离 f，在该距离处将使用 edgelength-distance。

edgelength f

参数 f 定义四面体网格单元的平均棱边长度。对于使用常规方案无法正确划分网格的块体，可使用 alternate 关键字（见下文）。此时块体独立于相邻块体进行划分，并在划分之后执行网格点匹配。一般而言，该方案会导致网格单元形状较差，应作为最后的手段。

以更长或更短的长度重试网格单元生成都是安全的。以不同的棱边长度重试网格生成通常会得到良好结果。对于扁平或狭窄的块体，有时较短的长度更好。对于大块体，可能需要增大棱边长度。

high-order-tetra

该关键字使常应变单元转换为退化的等参砖块单元（为 4 个侧面而非 6 个侧面）。每条网格单元棱边的中心会添加一个额外网格点。只有在已使用常规 block zone generate 命令对块体划分网格之后，才能使用该命令。高阶网格单元不能与低阶网格单元合并（block join）。必须在创建任何块体之前给出 model config highorder 命令。

高阶网格单元的塑性解比普通常应变四面体网格单元更精确。在某些条件下，其解可能不如混合离散化网格单元（生成六面体区块单元命令（block zone generate hexahedra））精确。但高阶逻辑不具有混合离散化网格单元那样的形状限制。

高阶网格单元中的应力可投影到网格点上（参见 列出区块网格点应力命令（block gridpoint list stress））。注意：高阶单元与自由场边界以及节理流体流动不兼容。

limit-iteration i

将内部网格点间距算法限制为网格点数少于 i 的网格单元。该间距算法旨在使内部网格点均匀分布。对于包含大量网格单元的块体，这一过程可能非常缓慢，而且可能没有必要。该命令允许用户对这些块体跳过间距算法。

hexahedra

在立方体、六面多面体中生成六面体网格单元。每个六面体网格单元由 2 组各五个相互重叠的四面体网格单元组成。这称为混合离散化，在发生塑性变形时可大幅改善求解结果。注意：该技术仅适用于规则的六面多面体，用于使网格单元叠合在几何上相容。关键字 single quad 表示将每个六面块体划分为五个互不重叠的四面体。

divisions i1 i2 i3

控制离散化的方式。i1、i2 和 i3 分别为沿三个局部方向生成的网格单元数（如图 1.2 所示）：i1 为沿最短棱边长度方向的网格单元数；i2 为沿中间棱边长度方向的网格单元数；i3 为沿最长棱边长度方向的网格单元数。每个坐标轴上的最大细分数为 200。

ratio-multiply f

允许在整个块体内自动渐变网格单元尺寸。可惜它是在块体局部坐标系中工作的，因此仅当模型中只有一个块体时才有用。若模型中有多个块体，则每个块体都将从其左下角开始渐变。

verbose b

在网格单元生成过程中输出额外的打印信息。将 关闭（off） 设为关闭详细输出。默认值为 开启（on）。

rezone

允许在循环计算之后对块体重新划分网格。该关键字旨在解决回填已置空块体的问题。这些块体中的网格单元常因畸变而坍塌。这一新关键字可能对这类情况有帮助。新网格单元中的应力将为 0.0。

edge-length f

将重新划分网格的块体的棱边长度设为 f。

alternate

启用另一种网格划分方案，其中块体表面上的网格点不必强制与相邻块体的网格点匹配。仅当改变网格单元的棱边长度仍无法成功划分块体网格时，才可使用该关键字。在创建网格点之后，相邻块体的网格点会被调整以与之匹配。

check

检查面网格点是否匹配。

fix v

定义位于位置 v 的单个网格点（顶点）的位置。当需要在特定位置（内部或外部）施加边界条件时，该命令很有用。可以使用多个 fix 关键字来固定多个顶点。

gridpoint-match <b >

切换块体之间的网格点匹配。这可能导致应力分布不均匀，也可能影响合并块体边缘附近网格单元中的应力。

gridpoint-post-match

对先前已划分网格的块体执行网格点匹配。

tolerance f1 f2

更改网格划分过程中使用的容差值（默认值为 f1 = 10−6，f2 = 10−4）。
