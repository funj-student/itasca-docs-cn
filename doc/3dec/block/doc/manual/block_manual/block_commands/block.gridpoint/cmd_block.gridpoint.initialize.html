block gridpoint initialize 命令

语法

block gridpoint initialize keyword <range>

主要关键字：

displacement    displacement-x    displacement-y    displacement-z    目标力比（ratio-target）    pore-pressure    温度（temperature）    解析法温度（temperature-analytical）    velocity    velocity-x    velocity-y    velocity-z    extra

为网格点变量指定初始值。若未给定范围，则影响所有网格点。

displacement v <[blockgpinitializeblock]>

初始化网格点的 \(x\)、\(y\) 和 \(z\) 方向位移。

displacement-x f <[blockgpinitializeblock]>

初始化网格点的 \(x\) 方向位移。

displacement-y f <[blockgpinitializeblock]>

初始化网格点的 \(y\) 方向位移。

displacement-z f <[blockgpinitializeblock]>

初始化网格点的 \(z\) 方向位移。

ratio-target f <[blockgpinitializeblock]>

指定力学计算中被视为收敛的目标局部力比。默认值为 1e-4。局部力比达到该值时，网格点的收敛值为 1.0。参见 求解模型（model solve） 命令中的 convergence 关键字。

pore-pressure f <[blockgpinitializeblock]>

初始化网格点的网格单元压力。

temperature f <[blockgpinitializeblock]>

初始化网格点温度（必须已配置热计算——CONFIG thermal）。

temperature-analytical f <xgrad ftx > <ygrad fty > <zgrad ftz > <gradient ftx fty ftz >

为解析热解初始化温度。

velocity v <[blockgpinitializeblock]>

初始化 \(x\)、\(y\) 和 \(z\) 方向上的网格点速度。

velocity-x f <[blockgpinitializeblock]>

初始化 \(x\) 方向上的网格点速度。

velocity-y f <[blockgpinitializeblock]>

初始化 \(y\) 方向上的网格点速度。

velocity-z f <[blockgpinitializeblock]>

初始化 \(z\) 方向上的网格点速度。

extra i a<[blockgpinitializeblock]>

初始化额外变量 i 的值。


block gridpoint initialize 关键字块

以下关键字可用于修改（modify）给定的值。若修饰符关键字的说明中提到它可作用于何种类型的值（例如标量值、矢量值等），务必确保修饰符与主关键字值的类型相匹配。

以下关键字适用于 block gridpoint initialize 命令的下列各个关键字：displacement、displacement-x、displacement-y、displacement-z、extra、pore-pressure、目标力比（ratio-target）、温度（temperature）、velocity、velocity-x、velocity-y 和 velocity-z。

add

将（Add）指定值加到现有值上。

gradient v <origin v >

对给定的标量值施加梯度（gradient）。

local

指定为该关键字提供的值采用网格点的局部坐标系（若有）。默认情况下，数值按全局坐标系初始化。

该关键字不能与 block gridpoint initialize 命令的下列关键字一起使用：extra。

multiply

将（Multiply）现有值乘以指定值。

vary v

对所给的标量值应用 线性变化（linear variation）。
