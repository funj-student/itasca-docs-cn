block gridpoint list 命令

语法

block gridpoint list keyword <range>

主要关键字：

density-scaling-factors    displacement    力（force）    join    mass    pore-pressure    position    apply    应力（stress）    温度（temperature）    thermal    velocity    分组（group）    extra

列出网格点的信息。

density-scaling-factors

列出网格点密度缩放因子。

displacement

列出网格点位移。

force

列出网格点不平衡力。

join

列出已合并的网格点。

mass

列出网格点位置、质量与块体连接关系。

pore-pressure

列出网格点孔隙压力。

position

列出网格点在模型坐标系中的位置。

apply keyword

按下列关键字列出边界条件的信息。

added-mass

动力附加质量

displacement

列出边界处的位移。

free-field

动力自由场信息

force

列出边界处的力。

reactions keyword
forces

列出任何具有固定速度的网格点处的反力。

tractions

以周围面上的平均面力形式，列出固定速度点处的反力。

state

列出由边界代码 ix、iy、iz 指定的边界条件状态。

0 自由 1 应力（或力） 2 黏性 3 速度

summary

列出施加在 \(x\)、\(y\) 和 \(z\) 边界上的总力。

velocity

列出施加在边界上的速度。

stress

列出网格点应力（仅适用于高阶单元）。

temperature

列出网格点温度。

thermal

列出网格点热质量、温度状态、温度变化与热量。

velocity

列出网格点速度。

group

列出网格点组名。

extra i

列出网格点额外变量信息。
