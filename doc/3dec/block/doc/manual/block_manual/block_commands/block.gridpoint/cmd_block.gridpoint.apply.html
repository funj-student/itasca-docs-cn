block gridpoint apply 命令

语法

block gridpoint apply keyword ... <range>

主要关键字：

力（force）    force-x    force-y    force-z    velocity    velocity-normal    velocity-x    velocity-y    velocity-z    viscous    x 向黏性边界（viscous-x）    y 向黏性边界（viscous-y）    z 向黏性边界（viscous-z）    reaction    reaction-x    reaction-y    reaction-z    source    温度（temperature）

对块体网格点施加边界条件。

force v <[blockgpapplyblock]>

在位置 v 处设置荷载（仅适用于可变形块体）。

force-x f <[blockgpapplyblock]>

设置 \(x\) 方向上的荷载。

force-y f <[blockgpapplyblock]>

设置 \(y\) 方向上的荷载。

force-z f <[blockgpapplyblock]>

设置 \(z\) 方向上的荷载。

注意

默认情况下，所有荷载都假定为恒定且永久，并叠加到已有的永久荷载上。若在与荷载同一命令行上给出 \(fish\) 或 \(table\) 关键字短语，则施加瞬态（随时间变化）荷载（见下文）。

velocity v <[blockgpapplyblock]>

设置速度（仅适用于可变形块体）。

velocity-normal f <[blockgpapplyblock]>
为可变形块体设置法向速度。法向定义为块体面的法向。若在与速度条件相同的方向上施加 velocity-normal 0，则速度边界条件将被移除。同一顶点上可以施加两个 velocity-normal 0 条件。若施加了这两个条件，则该条件转变为 施加网格点 x 向速度命令（block gridpoint apply velocity-x） 0、施加网格点 y 向速度命令（block gridpoint apply velocity-y） 0、施加网格点 z 向速度命令（block gridpoint apply velocity-z） 0。
该命令要求包含该顶点的整个面都在范围内。
velocity-x f <[blockgpapplyblock]>

设置 \(x\) 方向的速度（仅适用于可变形块体）。

velocity-y f <[blockgpapplyblock]>

设置 \(y\) 方向的速度（仅适用于可变形块体）。

velocity-z f <[blockgpapplyblock]>

设置 \(z\) 方向的速度（仅适用于可变形块体）。

viscous

在指定范围的所有方向上设置黏性边界。

注意

黏性边界不能与速度边界同时使用。黏性边界可以与应力边界组合使用。动力分析中可使用无反射边界。

viscous-x <keyword ...>

设置 \(x\) 方向上的无反射边界。

viscous-y <keyword ...>

设置 \(y\) 方向上的无反射边界。

viscous-z <keyword ...>

设置 \(z\) 方向上的无反射边界。

reaction <[blockgpapplyblock]>

设置沿与范围内所有顶点处不平衡力相反方向施加的点荷载。应在该 reaction 命令之前给出 model cycle 1 命令，以便计算不平衡力。施加该命令时，将移除所有速度边界条件。

reaction-x <[blockgpapplyblock]>

设置沿相反 \(x\) 方向施加的点荷载。

reaction-y <[blockgpapplyblock]>

设置沿相反 \(y\) 方向施加的点荷载。

reaction-z <[blockgpapplyblock]>

设置沿相反 \(z\) 方向施加的点荷载。

source f <[blockgpapplyblock]>

在指定范围内的每个 网格点 上，以给定量值（例如，单位为 \(W\)）将生热源 f 作为点源施加。当向已存在热源的网格点施加新热源时，新热源的量值将替换现有热源的量值。

temperature f <[blockgpapplyblock]>

在指定范围内的所有网格点上，温度固定为 f。fish 或 table 关键字可用于指定温度历史记录。（见下文。）


block apply 关键字块

以下关键字适用于 \(block gridpoint apply\) 命令的下列各个关键字：力（force）、force-x、force-y、force-z、reaction、reaction-x、reaction-y、reaction-z、source、温度（temperature）、velocity、velocity-normal、velocity-x、velocity-y 和 velocity-z。

fish s

指定的 FISH 符号用于提供乘子。

table i

为由 TABLE 命令给出的乘子。TABLE n 由一系列数据对组成：时间、f(time)。在给定的离散点之间进行线性插值。

verbose b

增加屏幕输出信息。默认设置为 假值（false）。
