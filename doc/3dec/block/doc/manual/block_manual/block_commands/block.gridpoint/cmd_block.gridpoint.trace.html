block gridpoint trace 命令

语法

block gridpoint trace keyword

追踪块体网格点的位置与速度。参见 c 追踪（trace） 命令。

使用该命令可在模型运行过程中采样并存储块体上网格点的位置与速度。所得的轨迹可在程序界面中可视化。每条 block gridpoint trace 命令只能创建一个迹线位置。迹线可以随时添加。

使用 列出追踪命令（trace list） 命令可获得所有迹线的汇总。

以下关键字可用于指定追踪哪个块体网格点位置。

id i

添加与网格点 ID i 相对应的位置的迹线。

position v

在位置 v 处添加迹线，该位置必须落在某个网格点上。
