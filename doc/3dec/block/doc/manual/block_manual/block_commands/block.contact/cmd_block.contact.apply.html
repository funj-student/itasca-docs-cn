block contact apply 命令

语法

block contact apply pore-pressure f <range>

该命令可对刚性块体或可变形块体的节理子接触指定流体压力。在未执行另一条 block contact apply 命令或该子接触被删除之前，所指定的流体压力保持不变。block contact apply 命令每次都会把压力累加到施加在该子接触上的流体作用力增量中。正压力使节理张开。要消除某接触上的压力，可用 block contact apply 命令施加该压力的负值。使用 列出区块接触孔隙压力命令（block contact list pore-pressure） 命令可获取模型中流体压力的当前值。使用 列出区块接触应力命令（block contact list stress） 命令可获取模型中各子接触处“有效”法向应力的当前值。

流体压力固定在该可选范围内的子接触上。若省略范围，则假定该命令作用于所有子接触。
