block contact history 命令

语法

block contact history <name s > location-keyword variable-keyword <keyword ...>

主要关键字：

接触 ID（contact-id）    倾角（dip）    倾向（dip-direction）    position    子接触 ID（subcontact-id）    面积（area）    area-sum    displacement-normal    displacement-shear    displacement-shear-x    displacement-shear-y    displacement-shear-z    displacement-shear-maximum    force-normal    force-normal-sum    force-shear    force-shear-sum    stress-normal    stress-shear    stress-shear-x    stress-shear-y    stress-shear-z    velocity-shear    velocity-shear-x    velocity-shear-y    velocity-shear-z

添加接触量的历史记录。请参阅通用的 c 历史（history） 命令。可用可选的 name 关键字为该历史记录指定名称，以便日后引用；若不指定，则系统会根据内部赋予的 id 号为其生成默认名称。

该命令要求提供一个 location-keyword 和一个 variable-keyword。这两类关键字在下文分组列出。

已合并的接触不能添加历史记录。该接触涉及的两个块体必须当前可见。

用于 location-keyword 的关键字选项

contact-id i

把历史记录位置设为 ID 为 i 的接触。这仅适用于接触类历史记录 \(area-sum\)、\(force-normal-sum\) 和 \(force-shear-sum\)。

dip f

使用 \(position\) 关键字时，只考虑倾角等于 f 的接触或子接触。

dip-direction f

使用 \(position\) 关键字时，只考虑倾向等于 f 的接触或子接触。

position v

把历史记录位置设为 v。历史记录将记录在距该位置最近的接触或子接触上。

subcontact-id i

把历史记录位置设为 ID 为 i 的子接触。


用于 variable-keyword 的关键字选项

area

获取子接触的面积。

area-sum

获取指定接触所有子接触面积之和。

displacement-normal

获取接触法向位移。

displacement-shear

获取剪切位移的大小。

displacement-shear-x

获取整体坐标系下剪切位移的 \(x\) 分量。

displacement-shear-y

获取整体坐标系下剪切位移的 \(y\) 分量。

displacement-shear-z

获取整体坐标系下剪切位移的 \(z\) 分量。

displacement-shear-maximum

获取过去任意时刻观测到的最大剪切位移。

force-normal

获取子接触法向力。

force-normal-sum

获取指定接触所有子接触法向力的合力。

force-shear

获取接触剪力。

force-shear-sum

获取指定接触所有子接触剪力的合力。

stress-normal

获取接触法向应力。

stress-shear

获取接触剪应力。

stress-shear-x

获取整体坐标系下剪应力的 \(x\) 分量。

stress-shear-y

获取整体坐标系下剪应力的 \(y\) 分量。

stress-shear-z

获取整体坐标系下剪应力的 \(z\) 分量。

velocity-shear

获取接触剪切速度的大小。

velocity-shear-x

获取整体坐标系下剪切速度的 \(x\) 分量。

velocity-shear-y

获取整体坐标系下剪切速度的 \(y\) 分量。

velocity-shear-z

获取整体坐标系下剪切速度的 \(z\) 分量。
