block contact jmodel 命令

语法

block contact jmodel keyword <range>

主要关键字：

指定本构模型（assign）    continuously-yielding    power    默认值（default）    list    load

该命令用于在 3DEC 中为子接触指定节理本构模型或用户自定义节理模型（UDJM）（参见 3DEC 中的本构模型（Constitutive Models in 3DEC））。

assign keyword

把动态节理本构模型 \(jmodel\)（用 keyword 指定）赋予范围内所有子接触。若尚未加载该库，系统将尝试自动加载。

bilinear-mohr

把双线性莫尔-库仑节理模型赋予范围内的子接触。

continuously-yielding

将连续屈服节理模型赋予范围内的子接触。

elastic

将弹性节理模型赋予范围内的子接触。

mohr

将莫尔-库仑节理模型赋予范围内的子接触。

power

将幂律节理模型赋予范围内的子接触。

softening-mohr

将软化-愈合莫尔-库仑节理模型赋予范围内的子接触。

default s

将名称为 \(s\) 的用户自定义模型赋予范围内的所有子接触。

list keyword
names <s >

列出模型关键字、名称和版本号。

properties <s >

列出模型的属性列表。

states <s >

列出模型可能的状态标志。

table

列出接触（节理）材料映射表。

load <s >

动态加载节理本构模型。动态库的名称应为“jmodeljmodel006.dll”。例如，节理模型“mohr”的库名称为“jmodelmohr006.dll”。
