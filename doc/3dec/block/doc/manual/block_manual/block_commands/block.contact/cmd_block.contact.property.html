block contact property 命令

语法

block contact property keyword ... <range>

为子接触指定节理本构模型属性。可用的属性取决于赋给该接触的本构模型。 属性是“名称 值”对，其中名称是命令中给出的关键字，值的类型则特定于该属性。

该赋值将影响任何节理模型包含所指定属性的块体接触——请注意，某些属性（例如 friction‑residual）会出现在不止一个节理模型中。将属性赋值限制为具有特定节理模型赋值的块体接触，可通过命令的 范围（range） 组成部分来实现。例如，在下面的情况中：

block contact property cohesion 0.7e6 range jmodel softening-mohr

范围（range） 组成部分将 cohesion 属性的指定限制为具有软化莫尔-库仑（softening-mohr）节理模型赋值的网格单元。

有关每种节理本构模型的更多细节，参见 3DEC 中的本构模型（Constitutive Models in 3DEC）。

莫尔-库仑（mohr）节理模型

属性（Properties）在 3DEC 理论（3DEC Theory） 部分的 3DEC 中的莫尔-库仑节理模型（Mohr-Coulomb Joint Model In 3DEC） 主题中描述，该处给出模型的完整概述。为方便起见，下面也一并列出。

mohr
模型属性

cohesion    cohesion‑residual    dilation    dilation-zero    friction    friction‑residual    stiffness‑normal    stiffness‑shear    tension    tension-residual

软化-愈合莫尔-库仑（softening-mohr）节理模型

属性（Properties）在 3DEC 理论（3DEC Theory） 部分的 3DEC 中的软化-愈合莫尔-库仑节理模型（Softening-Healing Mohr-Coulomb Joint Model In 3DEC） 主题中描述，该处给出模型的完整概述。为方便起见，下面也一并列出。

shmohr
模型属性

alpha    cohesion    cohesion‑residual    dc    dilation    dilation‑residual    dilation‑zero    friction    friction‑current    friction‑residual    healing    slip    stiffness‑normal    stiffness‑shear    tension    tension‑residual

双线性莫尔-库仑（bilinear-mohr）节理模型

属性（Properties）在 3DEC 中的双线性莫尔-库仑节理模型（Bilinear Mohr-Coulomb Joint Model In 3DEC） 中描述，该处给出模型的完整概述。为方便起见，下面也一并列出。
