block contact compute 命令

语法

block contact compute keyword <range>

主要关键字：

平均迹线长度（average-trace-length）    center-density    mass-density    p10    p20    p21    p30    p32    p33    trace-center-density    trace-mass-density    percolation

计算节理统计量。可计算经范围过滤的多种裂隙密度度量。

average-trace-length keyword

返回平均迹长（迹线长度除以迹线条数），其中迹线是裂隙与输入平面几何集的交线。

geometry s

平均迹长在名为 s 的平面几何集范围内测量。

center-density keyword

是关键字 \(P30\) 的同义词。

mass-density

是关键字 \(P32\) 的同义词。

p10 keyword

返回沿 begin 与 end 定义的直线、或沿 geometry 关键字所定义几何集各边的 P10（单位测量长度内的裂隙数目）。

geometry s

P10 沿名为 s 的几何集各边测量。不能与 begin 或 end 关键字一起给出。

begin v

定义测量 P10 的参考线起点。不能与 geometry 关键字一起给出。

end v

定义测量 P10 的参考线终点。不能与 geometry 关键字一起给出。

p20 keyword

返回由 geometry 关键字所定义几何上的 P20（单位测量面积内的裂隙数目）。

geometry s

P20 在名为 s 的平面几何集范围内测量。

p21 keyword

返回由 geometry 关键字所定义几何上的 P21（单位测量面积内的裂隙长度）。

geometry s

P20 在名为 s 的平面几何集范围内测量。

p30 keyword

返回指定盒体内的 P30（单位测量体积内的裂隙数目）。

box x 向下限（fx1 ）x 向上限（fx2 ）y 向下限（fy1 ）y 向上限（fy2 ）z 向下限（fz1 ）z 向上限（fz2 ）

P30 在盒体体积内测量。

p32 keyword

返回指定盒体内的 P32（单位测量体积内的裂隙面积）。

box x 向下限（fx1 ）x 向上限（fx2 ）y 向下限（fy1 ）y 向上限（fy2 ）z 向下限（fz1 ）z 向上限（fz2 ）

P32 在盒体体积内测量。

p33 keyword

返回指定盒体内的 P33（单位测量体积中的裂隙体积）。

box x 向下限（fx1 ）x 向上限（fx2 ）y 向下限（fy1 ）y 向上限（fy2 ）z 向下限（fz1 ）z 向上限（fz2 ）

P33 在盒体体积内测量。

trace-center-density

是关键字 \(P20\) 的同义词。

trace-mass-density

是关键字 \(P21\) 的同义词。

percolation

P33 的同义词。
