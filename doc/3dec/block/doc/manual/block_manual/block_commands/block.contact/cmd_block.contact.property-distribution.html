block contact property-distribution 命令

语法

block contact property-distribution s 属性赋值（fvalue ）keyword <range>

主要关键字：

高斯分布偏差（deviation-gaussian）    均匀分布偏差（deviation-uniform）    梯度（gradient）    add    multiply    应用线性变化（vary）

修改节理模型属性。属性名由 s 表示，所赋的值由 属性赋值（fvalue） 表示。属性应接受 float 类型的值。虽然技术上此处可以使用任何有效类型，但任何分布关键字都不会生效，此时可能应改用 设置块体接触属性（block contact property） 命令。

修饰该值的短语必须紧跟属性值给出。有关修改值以及这些关键字用法的更多信息，参见 值修饰符（Value Modifiers） 主题。

deviation-gaussian f

使用高斯分布来随机指定属性值，其中均值为 属性赋值（fvalue），标准差为 f。

deviation-uniform f

使用均匀分布来随机指定属性值，其中均值为 属性赋值（fvalue），标准差为 f。

gradient v <origin v >

对属性值应用 梯度（gradient）。

add

在属性值上加上（Add） 属性赋值（fvalue）。

multiply

将属性值乘以（Multiply） 属性赋值（fvalue）。

vary v

对属性值应用 线性变化（linear variation）。
