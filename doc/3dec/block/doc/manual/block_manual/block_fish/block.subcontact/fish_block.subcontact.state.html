block.subcontact.state

语法

i = block.subcontact.state(bscp)
block.subcontact.state(bscp) = i

获取/设置子接触状态指示符。

子接触的破坏状态用一个 64 位变量表示。每一位对应一种可能状态。不同的节理本构模型具有不同的可能状态（参见 3DEC 中的本构模型（Constitutive Models in 3DEC））。莫尔-库仑模型的可能状态见下表。

MC 破坏状态 值 标签
当前发生剪切破坏 1 slip-n
当前发生拉伸破坏 2 tension-n
过去发生过剪切破坏 4 slip-p
过去发生过拉伸破坏 8 tension-p

通过置位不同位，可组合多种状态。例如，过去曾拉伸破坏、当前正在剪切破坏的子接触，其状态值为 8 + 1 = 9。值为 0 表示未破坏，即弹性状态。

返回值：i - 状态指示符
接受：i - 状态指示符
参数：子接触指针（bscp） — 块体子接触指针
