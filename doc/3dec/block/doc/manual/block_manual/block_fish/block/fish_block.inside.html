block.inside

语法

blp = block.inside(v<,b>)

若输入位置位于某块体内部，则返回该块体。若设为 真值（true），则只搜索可见块体；默认值为 假值（false）。若该点不在任何块体内，则返回 无接触（null）。

返回值：区块指针（blp） - 块体指针
参数：点位置与仅可见块标志（v`+ - point <:bool:`b） - 是否仅使用可见块体的布尔指示符
