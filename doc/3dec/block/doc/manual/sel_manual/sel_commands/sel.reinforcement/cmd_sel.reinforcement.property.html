sel reinforcement property 命令

语法

sel reinforcement property i keyword ...

主要关键字：

活动半长（active-half-length）    轴向断裂应变（rupture-axial-strain）    剪切断裂应变（rupture-shear-strain）    拉伸断裂应变（rupture-tension-strain）    轴向刚度（stiffness-axial）    stiffness-shear    剪切屈服力（yield-shear-force）    拉伸屈服力（yield-tension-force）

为加筋单元属性 \(i\) 赋值。

active-half-length f

有效半长。

rupture-axial-strain f

轴向破坏应变。若轴向应变超过该值，单元将不再承受轴向荷载。

rupture-shear-strain f

剪切破坏应变。若剪切应变超过该值，单元将不再承受剪切荷载。

rupture-tension-strain f

拉伸破坏应变。

stiffness-axial f

轴向刚度 {F/L]

stiffness-shear f

剪切刚度 [F/L]

yield-shear-force f

极限剪切承载力 [F]。单元不能承受大于 \(f\) 的剪力。

yield-tension-force f

极限轴向承载力 [F]。单元不能承受大于 \(f\) 的轴力。
