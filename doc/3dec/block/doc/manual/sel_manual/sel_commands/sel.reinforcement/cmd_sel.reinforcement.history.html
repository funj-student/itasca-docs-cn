sel reinforcement history 命令

语法

sel reinforcement history keyword <range>

采样加筋单元的响应。单元的节点将相对于创建加筋单元的网格单元面外侧按逆时针顺序排列。

必须通过 element-id 或 position 指定要采样的单元。若使用 position v，则取距离 v 最近的单元。

displacement-axial [reinforcementhistoryoptions]

获取单元中的轴向位移。

displacement-shear [reinforcementhistoryoptions]

获取单元中的剪切位移。

force-axial [reinforcementhistoryoptions]

获取轴力（全局坐标系）。

force-shear [reinforcementhistoryoptions]

获取剪力。

strain-axial [reinforcementhistoryoptions]

获取单元中的轴向应变。

strain-shear [reinforcementhistoryoptions]

获取单元中的剪切应变。


sel reinforcement history 关键字块

必须提供以下两个标识符中的一个（且仅一个），以指明要提取其历史记录的加筋单元；历史记录为以下之一：轴向位移（displacement-axial）、displacement-shear、force-axial、force-shear、轴向应变（strain-axial） 和 剪切应变（strain-shear）。

position v

特定单元由坐标（v）确定（取最近的单元）。若使用该关键字，则不应使用 element-id 和 node-id。

element-id i

特定单元由单元 ID 号标识。若使用该关键字，则不应使用 position 和 node-id。
