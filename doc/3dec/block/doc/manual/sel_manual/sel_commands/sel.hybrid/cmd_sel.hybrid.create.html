sel hybrid create 命令

语法

sel hybrid create keyword ... <range>

主要关键字：

沿线（by-line）    按几何集生成（from-geometry）    集合ID（cid）    销钉长度（dowel-length）    faceplate    分组（group）    property    分段数（segments）    分段长度（segment-length）    间距（spacing）    tension

创建混合锚杆单元。注意，当混合加筋用于完全可变形块体时，必须先将其离散为网格单元，然后才能指定加筋位置。

by-line v1 v2

沿直线创建由一个或多个单元组成的混合锚杆。

from-geometry s <range>

根据名为 s 的几何集创建混合锚杆。范围作用于该几何集中的棱边列表。

cid i

设置混合锚杆的集合 ID。默认情况下，由单条命令创建的所有混合锚杆单元被赋予同一个集合 ID。这使用户能够识别由多个单元组成的连续锚杆。

dowel-length f

设置杆体分段的半长。

faceplate

在混合锚杆起点 (x1,y1,z1) 处添加垫板。垫板通过将第一个节点附着到网格来模拟。垫板具有无限强度。

group s1 <slot s2 >

将混合锚杆单元分配到槽 s2 中名为 s1 的组（若提供）。

property i

设置分配给混合锚杆的属性编号。

segments i

设置混合锚杆被划分的分段数。只需指定 \(segments\) 或 \(segment-length\) 中的一个。

segment-length f

设置每个分段的长度。只需指定 \(segments\) 或 \(segment-length\) 中的一个。

spacing keyword

根据所提供的关键字设置节点间距。

constant
无论沿锚杆长度上节理的位置如何，节点都将以恒定间距布置。此为默认值。
variable

节点间距将随之改变，以确保每对节理之间至少有一个节点。警告：这可能导致锚杆分段过小，从而在大轴向应变下迅速破坏。

tension f

设置混合锚杆中存在的初始拉力。
