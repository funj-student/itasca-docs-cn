sel hybrid property 命令

语法

sel hybrid property i keyword ...

主要关键字：

cross-sectional-area    density    销钉刚度（dowel-stiffness）    销钉应变限值（dowel-strainlimit）    销钉屈服（dowel-yield）    grout-cohesion    grout-friction    grout-stiffness    perimeter    拉伸断裂应变（rupture-tension-strain）    thermal-expansion    yield-compression    yield-tension    young

为混合锚杆属性 \(i\) 赋值。
cross-sectional-area f

设置横截面积 \(A\)。

density f

设置密度 \(ρ\)。

dowel-stiffness f

设置杆体剪切刚度 [F/L]。

dowel-strainlimit f

设置杆体的剪切应变限值。

dowel-yield f

设置杆体的剪力屈服限值 [F]。

grout-cohesion f

设置注浆体黏结强度 \(c_g\)。[F / L]

grout-friction f

设置注浆体内摩擦角 \(ϕ_g\)

grout-stiffness f

设置注浆体刚度 \(k_g\)。[F / L2]

perimeter f

设置注浆体周长的长度。仅当注浆体内摩擦角大于 0 时才需要。

rupture-tension-strain f

设置混合单元破坏且不再承受轴向荷载时的轴向应变。

thermal-expansion f

设置热膨胀系数 \(α_t\)。

yield-compression f

设置压缩屈服强度 \(F_c\)。[F]

yield-tension f

设置拉伸屈服强度 \(F_t\) [F]。混合锚杆不能承受大于 \(f\) 的轴向荷载。

young f

设置杨氏模量 \(E\)。
