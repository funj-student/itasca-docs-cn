sel hybrid history 命令

语法

sel hybrid history keyword <range>

采样混合锚杆的响应。若使用 sel hybrid create 命令创建混合锚杆，则由此创建的每个单元的节点均按以下顺序排列：锚杆总体方向从第一个点指向第二个点（即每个单元的节点连接顺序使得从端 1 到端 2 的方向与从起点到终点的方向一致）。

axial-displacement [hybridhistoryoptions]
axial-strain [hybridhistoryoptions]
cable-state [hybridhistoryoptions]

获取单元的拉伸屈服状态。值 {0, 1, 2} 分别表示从未屈服、当前屈服或曾经屈服。

dowel-displacement [hybridhistoryoptions]
dowel-force [hybridhistoryoptions]
dowel-state [hybridhistoryoptions]
dowel-strain [hybridhistoryoptions]
force [hybridhistoryoptions]

获取单元中的平均轴力（正值为拉伸，负值为压缩）。

grout-slip [hybridhistoryoptions]

获取单元端部注浆体（剪切耦合弹簧）中的滑移。符号约定以混合锚杆的平均轴向方向为基准（+/-）。

grout-stress [hybridhistoryoptions]

获取单元端部注浆体（剪切耦合弹簧）中的应力。符号约定以混合锚杆的平均轴向方向为基准（+/-）。

stress [hybridhistoryoptions]

获取单元中的轴向应力（正值为拉伸，负值为压缩）。


sel hybrid history 关键字块

必须提供以下四个标识符中的一个（且仅一个），以指明要提取其历史记录的混合单元；历史记录为以下之一：轴向位移（axial-displacement）、轴向应变（axial-strain）、锚索状态（cable-state）、销钉位移（dowel-displacement）、销钉力（dowel-force）、销钉状态（dowel-state）、销钉应变（dowel-strain）、力（force）、浆液滑移（grout-slip）、浆液应力（grout-stress） 和 应力（stress）。

position v

特定单元由坐标（v）确定（取最近的单元）。若使用该关键字，则不应使用 element-id、node-id 和 dowel-id。

dowel-id i

特定单元由所关联杆体的杆体 ID 确定。若使用该关键字，则不应使用 position、element-id 和 node-id。

element-id i

特定单元由单元 ID 号确定。若使用该关键字，则不应使用 position、dowel-id 和 node-id。

node-id i

特定单元由其所关联节点之一的节点 ID 确定。若使用该关键字，则不应使用 position、dowel-id 和 element-id。
