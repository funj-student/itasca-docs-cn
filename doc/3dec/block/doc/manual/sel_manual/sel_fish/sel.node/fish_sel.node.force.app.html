sel.node.force.app

语法

向量访问

v/f = sel.node.force.app(snp<,i>)

获取节点施加的力。若提供可选参数 i，则返回值限制为指定的矢量分量（1 = \(x\)，2 = \(y\)，3 = \(z\)）。

返回值：v 或 f- 施加的力
参数：结构节点指针（snp） - 节点指针 i - 可选的矢量分量指标

分量访问

f = sel.node.force.app.x(snp)

获取施加的力的 \(x\) 分量。

返回值：f - \(x\) 施加的力
参数：结构节点指针（snp） - 节点指针
f = sel.node.force.app.y(snp)

获取施加的力的 \(y\) 分量。

返回值：f - \(y\) 施加的力
参数：结构节点指针（snp） - 节点指针
f = sel.node.force.app.z(snp)

获取施加的力的 \(z\) 分量。

返回值：f - \(z\) 施加的力
参数：结构节点指针（snp） - 节点指针
