flowplane.pos

语法

向量访问

v/f = flowplane.pos(fpp<,i>)

获取流动面的位置。若提供可选参数 i，则返回值限制为指定的矢量分量（1 = \(x\)，2 = \(y\)，3 = \(z\)）。

返回值：

v 或 f - 位置或位置的分量
参数：

流节点指针（fkp） - 流动面指针

i - 可选的向量分量

分量访问

f = flowplane.pos.x(fpp)

获取流动面位置的 \(x\) 分量。

返回值：f - 流动面位置的 \(x\) 分量
参数：流节点指针（fkp） - 流动面指针
f = flowplane.pos.y(fpp)

获取流动面位置的 \(y\) 分量。

返回值：f - 流动面位置的 \(y\) 分量
参数：流节点指针（fkp） - 流动面指针
f = flowplane.pos.z(fpp)

获取流动面位置的 \(z\) 分量。

返回值：f - 流动面位置的 \(z\) 分量
参数：流节点指针（fkp） - 流动面指针
