flowknot.fix.proppant

语法

b = flowknot.fix.proppant(fkp)
flowknot.fix.proppant(fkp) = b

获取/设置支撑剂变化标志（真值（true） = 自由；假值（false） = 体积分数恒定）。

返回值：b - 支撑剂变化标志
接受：b - 支撑剂变化标志
参数：流节点指针（fkp） — 渗流节点指针
