flowplane property 命令

语法

flowplane property keyword ... <range>

主要关键字：

a 系数（a-factor）    b 系数（b-factor）    最大开度（aperture-maximum）    最小开度（aperture-minimum）    初始开度（aperture-initial）

设置流动平面属性。

a-factor f

设置导流能力中关于张开度的指数。默认值为 3.0。

b-factor f

设置导流能力的“b”因子。默认值为 1.0。

aperture-maximum f

设置流量计算中节理允许的最大水力张开度。

aperture-minimum f

设置节理允许的最小水力张开度。

aperture-initial f

设置法向应力为零时的水力张开度。若在 block insitu 命令中使用了 nodisplacement 关键字，则 aperture-initial 为施加法向应力下的初始水力张开度。
