flowknot history 命令

语法

flowknot history <name s > location-keyword variable-keyword <keyword ...>

设置流动节点变量的历史记录。请参阅通用的 c 历史（history） 命令。可通过可选的 name 关键字为历史记录指定名称以便后续引用。若未指定，则根据其内部分配的 id 编号赋予默认名称。

该命令要求提供一个 location-keyword 和一个 variable-keyword。这两类关键字在下文分组列出。

用于 location-keyword 的关键字选项

flowknot-id i

将历史记录位置设在 ID 为 i 的流动节点处。

position v

将历史记录位置设在位置 v 处。将使用距 v 最近的流动节点提供历史值。


用于 variable-keyword 的关键字选项

pore-pressure

设置流动节点孔隙压力的历史记录。

temperature

设置流动节点温度的历史记录。
