模型改变后的初始应力

某些情况下，在达到目标应力分布的过程中，可变形块体采用一种材料模型，而后续模拟改用另一种模型。可使用 指定块体网格单元本构模型（block zone cmodel assign） 命令更改网格单元的模型。如果将一种模型替换为另一种非空模型，受影响网格单元中的应力会保留：

模型改变后的初始应力

model new
model large-strain on

block create brick 0,5 0,5  0,5
;
block zone generate edgelength 1.0
;
block zone cmodel assign elastic
block zone prop  dens 2000 bulk 3e8 shear 2e8
;
model gravity 0 0 -10
;
block gridpoint apply vel-x = 0.0  vel-z = 0.0 range pos-z 0.0
;
history mechanical unbalanced-maximum
model cycle 250
;
block zone cmodel assign mohr-coulomb
block zone prop  dens 2000 bulk 3e8 shear 2e8 friction 34

运行到此处时，初始弹性模型产生的应力仍然存在，并作为采用新莫尔—库仑模型区域的初始应力。

应记住两点。第一，如果通过 block excavate 命令将模型任意部分设为空块体，即使随后又换成非空块体，该空块体中的全部应力也已被移除。第二，如果一种材料模型被另一种替换，且从物理上说新模型中的应力应为零，则必须使用 block insitu 命令，将该区域应力重置为零。例如，开采岩石并用回填材料替代时就会出现这种情况；回填材料初始应无应力。
