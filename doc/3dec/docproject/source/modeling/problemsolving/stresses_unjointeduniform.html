无节理介质中的梯度应力：均匀材料

在地表附近，不能忽略应力随深度的变化。设置重力命令（model gravity） 命令用于告知 3DEC，重力加速度作用于模型。必须理解，设置重力命令（model gravity） 命令不会直接在模型中产生应力；它只是使体积力作用于可变形块体的所有网格点（或刚性块体的质心）。这些体积力对应各网格点周围材料的重量。如果没有初始应力，这些力会使材料在步进过程中沿力的方向运动，直到网格单元应力产生大小相等、方向相反的力。在适当边界条件下，例如底部固定、侧面滚动边界，模型确实会自行产生与施加重力相容的重力应力。不过，这一过程效率较低，因为达到平衡可能需要数百甚至数千步。更好的方法是初始化内部应力，使其同时满足平衡条件和重力梯度。按地形设置初始应力命令（block insitu topography） 命令通常是最佳方法。内部应力还必须与应力边界上的边界应力一致。

虽然边界应力和原位应力已指定为满足力平衡，模型通常仍需要一定循环计算。这是因为边界力仅在循环结束时施加，原位应力会产生微小力不平衡。通常在数百个循环内即可减小这种不平衡。

例如，考虑地下 200 m 深处一个 20 m × 20 m × 20 m 的均匀无节理材料箱体，底部固定，其余五个面采用应力边界。下例为该问题条件产生平衡系统：

具有重力梯度的初始应力状态

model new
model large-strain on

block create brick 0,20 0,20 0,20
;
block zone generate edgelength 4.0
;
block zone cmodel assign mohr-coulomb
block zone prop  dens 2500 bulk 5e9 shear 3e9 friction 35
;
model gravity 0 0 -10
;
; 为顶部距地表 200 m 的块体赋予初始应力
block insitu topography ratio-x 0.5 ratio-y 0.5 overburden [-200*10*2500]

; 在侧面施加应力
block face apply stress -2.75e6,-2.75e6,-5.5e6 0,0,0 &
      grad-z   1.25e4, 1.25e4, 2.5e4 0,0,0 range pos-x  0.0
block face apply  stress -2.75e6,-2.75e6,-5.5e6 0,0,0 &
      grad-z   1.25e4, 1.25e4, 2.5e4 0,0,0 range pos-x 20.0
block face apply  stress -2.75e6,-2.75e6,-5.5e6 0,0,0 &
      grad-z   1.25e4, 1.25e4, 2.5e4 0,0,0 range pos-y  0.0
block face apply  stress -2.75e6,-2.75e6,-5.5e6 0,0,0 &
      grad-z   1.25e4, 1.25e4, 2.5e4 0,0,0 range pos-y 20.0
      
      ; 在顶部施加应力
block face apply  stress   0,0,-5.0e6 0,0,0 range pos-z 20.0

; 固定底部
block gridpoint apply vel-z = 0.0  range pos-z  0.0
model solve
;

本例水平应力和梯度均为竖直应力和梯度的一半，但只要不违反屈服准则（本例为莫尔—库仑准则），也可设为其他值。准备好上述数据文件后，应循环计算模型，检查是否达到平衡。如果确实发生材料破坏，例如将 phi 降至 10º，则不平衡力的大小将与施加荷载大致处于同一数量级。
