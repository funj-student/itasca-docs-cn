位移边界

不能在 3DEC 中直接控制位移；实际上，如理论与背景（Theory and Background）所述，位移并不参与计算过程。要在可变形块体模型的边界施加给定位移，必须固定边界，并规定边界在给定步数内的速度（使用 block gridpoint apply 命令）。如果目标位移为 \(D\)，则在时间增量 \(T\) 内施加速度 \(V\)（例如 \(D = VT\)），其中 \(T = \Delta tN\)。\(\Delta t\) 为时间步长，\(N\) 为步数（或循环数）。实际应用时，应保持 \(V\) 较小、\(N\) 较大，以尽量减小对所模拟系统的冲击。

block gridpoint apply 命令用于固定可变形块体网格点在 \(x\)、\(y\) 或 \(z\) 方向的速度，使用的关键字分别为 velocity-x、velocity-y、velocity-z；也可仅使用 velocity，此时需提供三个速度分量。对于不与 \(x\)、\(y\) 和 \(z\) 轴平行的边界，也可以指定法向速度（关键字 :kwd:velocity-normal`）。可使用 block fix 命令，将刚性或可变形块体的速度固定为当前速度。对于刚性块体，如需指定与当前值不同的速度，请使用 block apply 命令。也可以使用 FISH 函数改变速度。

对于可变形块体，可通过带 FISH函数（fish） 或 表格插值取值（table） 关键字的 block gridpoint apply 命令施加随时间变化的速度时程；对于刚性块体，则使用带 FISH函数（fish） 或 表格插值取值（table） 关键字的 block apply 命令。要规定速度时程，这些关键字必须与命令位于同一行。如应力边界（Stress Boundary）所述，速度边界始终应在应力边界之后赋予。可变形块体的固定速度条件可通过 block gridpoint apply-remove 命令移除；刚性块体则通过 block apply remove 命令移除。
