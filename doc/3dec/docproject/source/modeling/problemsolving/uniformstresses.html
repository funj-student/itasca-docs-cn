无节理介质中的均匀应力：无重力

对于深地下开挖，由于开挖顶部至底部的重力应力变化相对于作用于所模拟岩体的应力大小很小，可忽略这一变化。可以省略 设置重力命令（model gravity） 命令，使重力加速度默认为零。通过 block insitu 命令设置初始应力，例如：

block insitu stress -5e6 -5e6 -1e7 0.0 0.0 0.0

在整个模型中，将分量 \(\sigma_{11}\)（或 \(\sigma_{xx}\)）、\(\sigma_{22}\)（或 \(\sigma_{yy}\)）和 \(\sigma_{33}\)（或 \(\sigma_{zz}\)）分别设为压应力 5×106、5 × 106 和 5 × 107。如果只需在模型子区域设置应力，可以添加范围参数。block insitu 命令将全部应力设为给定值，但不保证这些应力处于平衡。至少可能存在三个问题。第一，应力可能违反赋予可变形块体的非线性本构模型屈服准则。此时，发出 求解模型（model solve） 命令后，块体内网格单元会立即发生塑性流动，应力重新调整；应试算一步并检查响应，例如绘制块体状态，以检查这种可能性。第二，应力状态可能导致模型内部节理滑移或分离。绘制子接触状态应能指示发生节理运动的位置。第三，模型边界上规定的应力可能不等于给定初始应力。此时，一发出 求解模型（model solve） 命令，边界网格点就会开始运动；同样应检查输出，例如绘制速度，以排查这种可能。

下例命令生成一个单块体，其初始应力与规定边界应力平衡：

处于平衡的初始应力与边界应力

model new
model random 10000
model large-strain on

block create brick 0,10  0,10  0,10
;
block zone generate edgelength 2.0
;
block zone cmodel assign el
block zone prop  dens 1000 bulk 8e9 shear 5e9
;
block gridpoint apply vel-z 0 range pos-z 0.0 
block face apply stress -5e6,0,0 0,0,0 range pos-x  0.0
block face apply stress -5e6,0,0 0,0,0 range pos-x 10.0
block face apply stress 0,-5e6,0 0,0,0 range pos-y  0.0
block face apply stress 0,-5e6,0 0,0,0 range pos-y  10.0
block face apply stress 0,0,-1e7 0,0,0 range pos-z 0.0
block face apply stress 0,0,-1e7 0,0,0 range pos-z 10.0

block insitu stress  -5e6  -5e6  -1e7  0,0,0
model step 1
