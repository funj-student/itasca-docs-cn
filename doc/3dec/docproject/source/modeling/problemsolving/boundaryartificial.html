人工边界

人工边界分为两类：对称平面和截断平面。对称平面利用实际系统的对称条件；模拟无限或非常大的系统时，则需要截断平面。

对称平面

有时可以利用系统几何和荷载关于一个或多个平面对称这一事实。例如，如果一切均关于某个竖直（\(yz\)）平面对称，则该平面上的水平位移为零。因此，可以将该平面设为边界，并使用 block gridpoint apply velocity-x 0 命令固定所有网格点的水平方向。如果对称平面上的速度尚不为零，该命令会将其置零。在此情况下，竖直对称平面上的速度 \(y\) 分量和 \(z\) 分量不受影响；不应固定它们。类似考虑也适用于水平对称平面。可使用 block gridpoint apply velocity-normal 0 命令设置与坐标轴成一定角度的对称平面。

不连续面的存在使对称平面的应用更加困难。在 3DEC 中使用对称平面时，建模人员始终应仔细考虑节理方位的影响。

边界截断——远场边界的位置

模拟无限体（例如地下隧道）或非常大的物体时，由于内存和计算时间限制，可能无法用网格单元覆盖整个物体。应将人工边界设置在距离关注区域足够远的位置，使该区域的行为不受明显影响。了解这些边界应放多远，以及关注区域内计算所得应力和位移可能存在多大误差，会很有帮助。

选取人工边界位置时，应考虑以下几点：

  1. 固定边界会使应力和位移均被低估，而应力边界的影响相反。
  2. 这两种边界条件给出的结果将真实解夹在其中，因此可采用较近的边界进行两次试算，并对两个结果取平均，合理估计真实解。
  3. 边界位置的影响对弹性体最为明显，因为出现塑性行为时，位移和应力变化更局限于局部；存在一个自然的影响截断距离，大部分变化发生在该距离以内。因此，人工边界可放得稍近一些，而不致引入严重误差。但是，任何人工边界都不能近到吸引塑性流动，否则将使解失效。

开展详细分析之前，最好始终先运行几个边界位置不同的粗略模型，评估边界对计算响应的潜在影响。
