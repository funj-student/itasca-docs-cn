与其他方法的比较

有关 3DEC 的常见问题包括：3DEC 是 distinct element 程序还是 discrete element 程序？二者有何区别？3DEC 与其他程序有何关系？下面给出一个定义，希望借此澄清这些问题。

许多有限元、边界元和拉格朗日有限差分程序都包含接触面单元或“滑移线”，使其能够在一定程度上模拟非连续材料。然而，它们的计算形式通常受到下列一项或多项限制：第一，使用许多相交接触面时，计算逻辑可能失效；第二，可能没有自动识别新接触的机制；第三，计算形式可能仅限于小位移和／或小转动。这类程序通常由已有连续介质程序改造而来。

只有计算机程序满足以下条件时，才能将其所用方法称为离散单元法（discrete element method）：

  1. 允许离散物体发生有限位移和转动，包括完全分离；并且
  2. 随着计算进行，能够自动识别新接触。

如果不具备第一个特征，程序就无法再现非连续介质中的某些重要机制；如果不具备第二个特征，程序就只能处理少量且相互作用预先已知的物体。Cundall 和 Strack（1979）提出 distinct element method 一词，用来指一种特定的离散单元方案：采用可变形接触，并在时域内显式求解原始运动方程（而不是变换后的模态方程）。

符合上述离散单元法定义的计算机程序主要有四类。（《理论与背景》第 1.1.1 节进一步讨论了这些类别及代表性程序。）

  1. 离散元程序（Distinct Element Programs）——这类程序采用显式时间推进，直接求解运动方程。物体可以为刚性，也可以通过划分为单元而成为可变形体；接触是可变形的。3DEC 属于这一类。
  2. 模态法——对于刚体，该方法与离散元法相似；但对于可变形体，则采用模态叠加。
  3. 非连续变形分析——接触为刚性，物体可以为刚性或可变形。通过迭代方案实现互不穿透条件；物体的可变形性来自应变模态的叠加。
  4. 动量交换法——接触和物体均为刚性：两个接触物体在瞬时碰撞过程中交换动量。该方法能够表示摩擦滑动。

已发表的一些方案看似类似离散单元法，但本质不同，或缺少一个或多个必要组成部分。例如，许多文献采用极限平衡法研究一个或多个刚体的稳定性（Hoek（1973）；Warburton（1981）；Goodman 和 Shi（1985）；Lin 和 Fairhurst（1988））。该方法计算物体的静力平衡，并不处理伴随物体位移而发生的力分布变化。
