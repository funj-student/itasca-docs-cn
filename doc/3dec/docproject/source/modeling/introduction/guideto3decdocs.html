3DEC 文档指南

3DEC 7.0 版帮助文档包含本程序的完整文档。

  • 可直接从程序中即时访问文档（使用帮助 → 帮助（Help → Help）菜单命令）。
  • 文档通过内联帮助（Inline Help）工具与命令及 FISH 函数集成，几乎可即时、准确地访问对应参考文档。
  • 任意页面的右上角均有内置搜索框。
  • 可使用浏览器的查找对话框在各页面中查找内容（按 Ctrl + F 打开）。
  • 需要时，可以方便地复制和粘贴文档中的内容。
  • 它为全部程序文档提供了统一来源。
  • 文档包含反馈机制，用户可以对所呈现的内容发表评论（见每页底部的“这些内容对您有帮助吗？…”链接）。

3DEC 文档的这一部分按以下方式组织。

3DEC
这是 3DEC 专用文档的“首页”。为方便使用，首页提供两个表格，作为访问 3DEC 所用全部主要命令和 FISH 函数的入口。文档的其他主要部分，要么专门介绍与 3DEC 集成的其他 Itasca 数值模拟程序（PFC 和 FLAC3D 部分），要么介绍所有数值程序共用的软件功能（程序指南（Program Guide）和脚本（Scripting））。
3DEC 建模（3DEC Modeling）
本部分是 3DEC 专用用户指南。首先提供 3DEC 的一般性介绍（Introduction）。随后的入门（Getting Started）部分是开始实际操作本程序的最佳起点。使用 3DEC 求解问题（Problem Solving with 3DEC）部分详细讨论了 3DEC 建模过程中的各主要步骤。
3DEC 理论与背景（3DEC Theory and Background）
本部分详细说明 3DEC 的理论公式，包括描述系统力学行为的数学模型及其数值实现。此处还包含接触面计算逻辑和安全系数计算的参考信息。本部分内容与以往印刷版手册中的《理论与背景》《流固相互作用》和《本构模型》各卷密切对应。
3DEC 命令与 FISH（3DEC Commands and FISH）
本部分对 3DEC 模型对象（网格单元、结构单元、建模块和拉伸体）作核心说明，并提供与其相关的全部命令和 FISH 函数的参考文档。
可选模块（Options）
此处收录与 3DEC 可选模块（C++ 选项、热分析、蠕变、动力分析）有关的全部资料。
示例（Examples）
此处提供大量示例。所有示例的项目均随程序提供，可通过帮助 → 示例…（Help → Examples…）命令访问。本部分内容与以往印刷版手册中的《应用示例》和《验证问题》各卷密切对应，并有所扩展。
索引：示例（Index: Examples）
本页按类别列出文档中的全部示例。
