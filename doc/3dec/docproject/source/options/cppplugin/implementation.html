实现

实用结构

程序提供了一些结构／类，以辅助编写本构模型及与之通信。其中一些由“base007.dll”提供，该库定义了所有插件接口共有的基础功能；另一些由“jmodels007.dll”提供，该库定义了节理本构模型系统所用的专用接口。所有这些类定义的完整文档均可在程序员接口（Programmer’s Interface）文档的基础接口模块中找到。

“base007.dll”提供：

Int, UInt, Byte, UByte, Double, Float 等——定义于“base/src/basedef.h”。这些类型替代标准 C++ 类型 int、unsigned、char、double 等。使用这些替代类型是为了定义一致的大小。例如，无论平台如何，Int 都保证为一个有符号 32 位量。

String——定义于“base/src/basebool.h”。该类派生自 std::basic_string<wchar_t>，即 ANSI C++ 标准字符串类。String 类增加了一些方便的实用函数，例如字符串到数值的转换。

DVect3——定义于“base/src/vect.h”。该类实际上是模板类 Vector3<T> 的 double 实例。类似的预定义类型有 IVect (Vector3<Int>) 和 UVect (Vector3<UInt>)。该类使三维矢量能够像基本类型一样使用，并通过完整的运算符重载提供便利的语法。

Variant —— 定义于 “base/src/variant.h”。 它定义了一种可表示多种不同基本类型的类型 （例如 String、Double、Int 等）。 该类用于向本构模型传递属性以及从本构模型传出属性。

Axes —— 定义于 “base/src/axes.h”。 该类允许定义正交归一基。该基可用于 在由传统笛卡尔坐标轴表示的“整体”基之间转换坐标。

SymTensor —— 定义于 “base/src/symtensor.h”。 该类定义一个 3 \(\times\) 3 的对称张量，通常用于表示应力和应变。 成员访问可通过 s11()、s12()、s13()、s22() 等函数实现。 成员修改可通过 rs11()、rs12() 等函数实现。 此外，特征向量信息（即主方向和主值）可通过 getEigenInfo() 函数获得。 辅助类 SymTensorInfo 用于使用户在保持主方向不变的同时修改主值， 并用所得结果构造一个新的 SymTensor。

Orientation3 —— 定义于 “base/src/orientation.h”。 该类提供 方位（即空间中的一个方向）的存储与操作。 该方位既可通过法向矢量指定，也可通过倾角和倾向指定。

本构模型示例

3DEC 所使用的所有本构模型的源代码均提供出来，供用户查看或修改。 为便于说明，这里摘录了文件 “jmodelexample.*” 中所含莫尔-库仑弹塑性模型的一部分。 jmodelexample.h 头文件（jmodelexample.h） 给出了该模型的类声明， 其中还包括模型唯一类型编号的定义。 在该模型中，部分变量仅供内部使用（例如 tan_friction_）： 它们占用每个子接触中的内存，但 3DEC 用户无法更改或打印它们。 另请注意，getProperty()/setProperty 接口用于保存/恢复。

jmodelexample.h:

#pragma once

#include "jmodels/src/jointmodel.h"

namespace jmodels
{
  class JModelExample : public JointModel {
  public:
    JModelExample();
    virtual String         getName() const;
    virtual String         getPluginName() const { return getName(); }
    virtual String         getFullName() const;
    virtual UInt           getMinorVersion() const; 
    virtual String         getProperties() const;
    virtual String         getStates() const;
    virtual Variant        getProperty(UInt index) const;
    virtual void           setProperty(UInt index,const Variant &p,UInt restoreVersion=0);
    virtual JModelExample *clone() const { return new JModelExample(); }
    virtual Double         getMaxNormalStiffness() const { return kn_; }
    virtual Double         getMaxShearStiffness() const { return ks_; }
    virtual void           copy(const JointModel *mod);
    virtual void           run(UByte dim,State *s); // 若 !isValid(dim)，则调用 initialize(dim,s)
    virtual void           initialize(UByte dim,State *s); // 调用 setValid(dim)
    // 可选 
    virtual Double         getStressStrengthRatio(const Double &,const DVect3 &) const { return 10.0; }
    virtual void           scaleProperties(const Double &,const std::vector<UInt> &) { throw std::exception("Does not support property scaling"); }
    virtual bool           supportsStressStrengthRatio() const { return false; }
    virtual bool           supportsPropertyScaling() const { return false; }
  private:
    Double kn_;
    Double ks_;
    Double cohesion_;
    Double friction_;
    Double dilation_;
    Double tension_;
    Double zero_dilation_;
    Double res_cohesion_;
    Double res_friction_;
    Double res_tension_;
    Double tan_friction_;
    Double tan_dilation_;
    Double tan_res_friction_;
    Int    kn_tab_;
    Int    ks_tab_;
  };
} // namespace models

// 文件结束

该模型的构造函数已在 典型模型构造函数（Typical Model Constructor） 中列出。示例 初始化函数与运行函数（initialize and run functions） 给出了用于初始化和执行（“运行”）的成员函数清单。注意，为节省时间，受保护的模型变量（例如 tan_friction_）不在每个循环计算，而是在初始化时于 Initialize 方法中计算。另请注意使用 State 结构来提供位移增量和力。成员函数 getProperties、getStates、getProperty、setProperty 和 copy 的清单请参阅文件 “jmodelexample.cpp”。

initialize() 和 run() 函数

  void JModelExample::initialize(UByte dim,State *s) 
  {
    JointModel::initialize(dim,s);
    tan_friction_    = tan(friction_ * dDegRad);
    tan_res_friction_ = tan(res_friction_ * dDegRad);
    tan_dilation_    = tan(dilation_ * dDegRad);
  }

  void JModelExample::run(UByte dim,State *s) 
  {
    JointModel::run(dim,s);
    /* --- 状态指示量：                                  */
    /*     将“当前”信息存为“过去”信息，并关闭“当前”信息 ---*/
    if (s->state_ & slip_now) s->state_ |= slip_past;
    s->state_ &= ~slip_now;
    if (s->state_ & tension_now) s->state_ |= tension_past;
    s->state_ &= ~tension_now;

    Double kna  = kn_ * s->area_;
    Double ksa  = ks_ * s->area_;

    // 法向力
    Double fn0 = s->normal_force_;
    s->normal_force_inc_ = -kna * s->normal_disp_inc_;
    s->normal_force_ += s->normal_force_inc_;

    // 针对节理张开或进入受拉状态的时间步进行修正
    // s->dnop_ 是 s->normal_disp_inc_ 中引起分离或受拉的部分
    s->dnop_ = s->normal_disp_inc_;
    if ((fn0 > 0.0)               && 
        (s->normal_force_ <= 0.0) && 
        (s->normal_force_inc_ < 0.0))
    {
        s->dnop_ = -s->normal_disp_inc_ * fn0 / s->normal_force_inc_;
        if (s->dnop_ > s->normal_disp_inc_) s->dnop_ = s->normal_disp_inc_;
    }

    // 抗拉强度
    Double ten;
    if (s->state_)
      ten = -res_tension_ * s->area_;
    else
      ten = -tension_ * s->area_;

    // 检查拉伸破坏
    bool tenflag = false;
    if (s->normal_force_ <= ten) 
    {
      s->normal_force_  = ten;
      if (!s->normal_force_)
      {
        s->shear_force_ = DVect3(0,0,0);
        tenflag = true; // 完全拉伸破坏
      }
      s->state_ |= tension_now;
      s->normal_force_inc_ = 0.0;
      s->shear_force_inc_ = DVect3(0,0,0);
    }

    // 剪切力
    if (!tenflag) 
    {
      s->shear_force_inc_ = s->shear_disp_inc_ * -ksa;
      s->shear_force_ += s->shear_force_inc_;
      Double fsm = s->shear_force_.mag();
      // 抗剪强度
      Double fsmax;
      if (!s->state_)
        fsmax = cohesion_ * s->area_ + tan_friction_ * s->normal_force_;
      else 
      { // 若残余摩擦角为零，则采用峰值
        Double resamueff = tan_res_friction_;
        if (!resamueff) resamueff = tan_friction_;
        fsmax = res_cohesion_ * s->area_ + resamueff * s->normal_force_;
      }
      if (fsmax < 0.0) fsmax = 0.0;
      //  检查滑移
      if (fsm >= fsmax) 
      {
        Double rat = 0.0;
        if (fsm) rat = fsmax / fsm;
        s->shear_force_ *= rat;
        s->state_ |= slip_now;
        s->shear_force_inc_ = DVect3(0,0,0);
        // 剪胀
        if (dilation_)
        {
          Double zdd = zero_dilation_;
          Double usm = s->shear_disp_.mag();
          if (!zdd) zdd = 1e20;
          if (usm < zdd) 
          {
            Double dusm  = s->shear_disp_inc_.mag();
            Double dil = 0.0;
            if (!s->state_) dil = tan_dilation_;
            else
            {
              // 若残余剪胀角为零，则采用峰值
              //     Double resdileff = tan_res_dilation_;
              // 注意：3DEC 的 CLJ1 中未定义残余剪胀
              Double resdileff = tan_dilation_;
              if (!resdileff) resdileff = tan_dilation_;
              dil = resdileff;
            }
            s->normal_force_ += kna * dil * dusm;
          }
        } // 剪胀
      } // fsm>fsmax
    } // if (!tenflg)
  }

对本构模型的 FISH 支持

在 3DEC 中可使用 FISH 内置函数 子接触属性（block.subcontact.prop）。 它可用于表达式的左侧或右侧。 因此，

val = block.subcontact.prop(cxp, p_name)

将地址为 子接触地址（cxp） 的子接触中名为 属性名称（p_name） 的属性的浮点值存入 属性值（val）。 属性名称（p_name） 可以是包含属性名称的字符串， 也可以是取值为此类字符串的 FISH 变量。 例如，block.subcontact.prop(cxp,'friction') 将指代内摩擦角。 若 子接触地址（cxp） 中没有本构模型， 或该模型不具有所指定的属性， 则返回 0.0。类似地，

block.subcontact.prop(cxp, p_name) = val

将 属性值（val） 存储到子接触 子接触地址（cxp） 中名为 属性名称（p_name） 的属性中。 若 子接触地址（cxp） 中没有本构模型， 或该模型不具有所指定的属性， 或 属性值（val） 不是整数或浮点数，则不存储任何内容。 在两种用法中，子接触地址（cxp） 都必须是子接触指针， 而 属性名称（p_name） 必须是字符串或包含字符串的 FISH 变量。

创建用户自定义模型 DLL

使用模板

在 Visual Studio 2017 或 2019 中创建本构模型项目的最简单方法， 是使用 Itasca 公司提供的 ItascaProjectTemplates 扩展（ItascaProjectTemplates） 扩展模板。

如需了解如何手动完成，请参见 |flac3d| 实现文档（|flac3d| Implementation document） 中的“手动配置”部分。

加载和运行用户自定义模型 DLL

节理模型 DLL 文件可在 3DEC 运行期间 通过给出命令 contact jmodel load filename（其中为 DLL 的文件名）加载到软件中。 若将 DLL 文件放置在 “exe64\plugins\jmodel” 文件夹中，则会自动加载。 此后，引用该模型及其属性的 3DEC 和 FISH 函数 即可识别新的模型名称和属性名称。 若对已加载的模型再次给出 contact jmodel load 命令，则不会执行任何操作， 但会显示一条提示信息。

在将本构模型插件赋予网格单元之前， 必须先通过给出 model configure plugin 命令将模型配置为可使用插件。 配置完成后，除非您的 3DEC 许可证包含 C++ 插件选项，否则模型将无法进行循环计算。
