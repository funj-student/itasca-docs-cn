编写新的节理本构模型

引言

用户可为 3DEC 创建自己的节理本构模型。该模型必须用 C++ 编写并编译为 DLL 文件（动态链接库），并可在需要时加载。模型的主要功能是根据法向和剪切位移返回新的法向力和剪切力。不过，模型还必须提供其他信息（例如模型名称和材料属性名称），并说明模型与程序代码交互方式的某些细节。

在 C++ 语言中，重点是采用面向对象的程序结构方法，即用类来表示对象。与对象关联的数据由对象封装，在对象外部不可见。与对象之间的通信通过成员函数完成，这些函数对封装的数据进行操作。此外，C++ 对对象层次结构提供了强有力的支持：新的对象类型可从基对象派生，基对象的成员函数可被派生对象提供的类似函数取代。这种安排对程序的模块化有明显好处。例如，主程序可能需要在代码的许多不同部分访问许多不同种类的派生对象，但只需引用基对象，而无须引用派生对象。运行时系统会自动调用相应派生对象的成员函数。Stevens（1994）对 C++ 编程作了很好的介绍；这里假定读者已具备该语言的实用知识。

关于用 C++ 编写可在 3DEC 中运行的节理本构模型的方法，见 方法（Methodology）。其中包括基类、成员函数、模型注册、模型与 3DEC 之间传递的信息以及模型状态指示变量的说明。DLL 模型的实现及示例见 实现（Implementation）。其中包括模型所用支持函数的说明、一个示例模型的源代码、对用户自定义模型的 FISH 支持，以及创建和加载 DLL 的机制。本节引用的所有文件都位于 “\pluginfiles\jmodels\src” 目录中。

注意，DLL 必须使用 Microsoft Visual Studio 2017 或 2019 编译，才能在 3DEC 中运行。

为快速入门并提供一个可供检查的项目，请执行以下步骤。

  1. 假定已安装 3DEC 7.0 以及 Visual Studio 2017 或 2019，在 3DEC 7.00 安装目录的 PluginFiles 目录中找到文件 “ItascaProjectTemplates.vsix”。

  2. 双击该安装文件即可执行安装。 （为此，您可能需要拥有该计算机的管理员权限。） 按提示完成安装。

  3. 启动 Visual Studio 2017 或 2019。

    若使用 Visual Studio 2017：

    1. 从菜单中选择 文件 ‣ 新建 ‣ 项目。
    2. 从“已安装”部分中选择“Visual C++”类别。
    3. 您应能看到 “Itasca 本构模型” 选项。
    4. 在下方为项目指定名称。 您也可以选择新项目和新解决方案的存放位置。 然后按下 “确定”。

    若使用 Visual Studio 2019：

    1. 在启动对话框右侧的选项中，选择“创建新项目”。
    2. 在 “搜索项目模板” 字段中键入 ‘itasca’。
    3. 选择 “Itasca 本构模型” 选项并按下 “下一步”。
    4. 为项目指定名称。 您也可以选择新项目和新解决方案的存放位置。 然后按下 “创建”。

  4. 将出现一个对话框，要求您为新本构模型命名。该名称将作为类的名称，也是代码中引用该模型时使用的名称。之后可通过直接编辑源代码更改此名称。若您安装了多个兼容版本的 Itasca 程序，请先选择计划使用该本构模型的那个版本。 按下 “接受并关闭”。

  5. 系统将为您创建一个项目，并以内部莫尔-库仑模型的源代码作为起点。 您可以自由修改该项目，以匹配您特定的模型行为。

  6. 您应更新解决方案，使其使用最新版本的 Windows SDK 和运行时库。 方法是右击“解决方案资源管理器”中的解决方案行，然后选择“重定目标项目”。

参考文献

Stevens, A. Teach Yourself C++, 4th Ed. New York: MIS Press (1994).
