热学选项

3DEC 的热学选项可模拟瞬态热传导。热学逻辑有两种 彼此独立的表述。第一种是采用显式或隐式 有限差分法的数值表述。该方法在短时间情况下更为准确，并包含 热-力-流体耦合。第二种是解析表述，利用无限介质中点热源的 叠加。该方法适用于长时间热学问题，且 计算速度很快。两种方法的对比功能列于下文。

表 1：数值表述与解析表述所具备功能之比较
功能 数值 解析
热-力耦合 是 是
热-流体耦合 是 否
流体中的热对流 是 否
温度边界 是 否
热流量边界 是 否
热对流边界 是 否
绝热边界 是 是
非均质热学块体属性 是 否
热源 是 是
