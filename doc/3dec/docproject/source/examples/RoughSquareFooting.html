黏性无摩擦材料上的粗糙方形基础

问题描述

注意

要在 3DEC 中查看此项目，请使用菜单命令 Help ► Examples…。选择“3DEC/ VerificationProblems/ Footing”，然后选择“Foot.prj”进行加载。所用的主数据文件（main data files）显示在本示例的末尾。所有数据文件都可在该项目中找到。

本问题涉及对黏性无摩擦材料（特雷斯卡模型）上粗糙矩形基础承载力的数值确定。

宽度为 \(2a\)、长度为 \(2b\) 的基础位于弹塑性特雷斯卡材料上，该材料具有以下属性：

剪切模量（\(G\)）：1 GPa

体积模量（\(K\)）：2 GPa

黏聚力（\(c\)）：0.1 MPa

内摩擦角（\(\phi\)）：0°

剪胀角（\(\psi\)）：0°

上限解与下限解

该问题真为三维问题，虽然不存在精确解，但已将承载力 \(q\)（定义为破坏时的平均基底压力）的上、下限通过极限分析导出（例如见 Chen，1975）。采用 Shield 和 Drucker（1953）破坏机制得到的上限 \(q^u\) 具有如下形式

\[q^u = c \ \left(5.24 + 0.47 \ {{a}\over{b}}\right) \ \ \ \ {{a}\over{b}} \geq\ 0.53\]
\[q^u = c \left(5.14 + 0.66 \ {{a}\over{b}}\right) \ \ \ \ {{a}\over{b}} < 0.53\]

其中 \(c\) 为材料的黏聚力。下限 \(q^l\) 对应于条形基础的承载力，其值为

\[q^l = c \ (2 + \pi)\]

3DEC 模型

在数值算例中，基础为方形，由尺寸 \(a\) = 3 m 和 \(b\) = 3 m 的区域表示。我们利用四分之一对称性，数值模拟采用 15 m × 15 m × 10 m 的平行六面体区域（如图 1（Figure 1）所示）。选取坐标轴系统，使 \(x\) 轴和 \(y\) 轴位于基础的水平面内，\(z\) 轴竖直向上（见图 1（Figure 1））。

图 1：3DEC 模拟的区域——四分之一对称。

施加于该区域的边界条件如图 2（Figure 2）所示。

图 2：3DEC 分析的边界条件——四分之一对称。

远端 \(x\)、\(y\) 和 \(z\) 边界的位移在各方向上受到限制，与 \(x\) = 0 和 \(y\) = 0 平面相应的对称边界分别限制 \(x\) 和 \(y\) 方向的位移。板面为粗糙：\(x\) 和 \(y\) 方向的位移受到限制；并在 3 m × 3 m 区域上沿 \(z\) 负方向施加速度以模拟基础加载。

模型包含一个块体，离散为 22,500 个 quad 网格单元。（模型几何及其离散化如图 3（Figure 3）所示。）代表基础的区域共覆盖 3 × 3 个网格单元。在与基础代表区域接触的节点上施加大小为 10−2 m/s 的速度，共计算 8000 步。

图 3：3DEC 网格——四分之一对称。

结果与讨论

数值模拟对应的荷载-位移曲线如图 4（Figure 4）所示。历史记录 2 为归一化的平均基底压力 \(p/c\)；历史记录 3 为归一化的承载力上限值 \(q^u /c\)，二者均与基础中心处的归一化竖向位移 \(u_z /a\) 对照绘制。承载力的数值为 578 kPa。该值与理论上限值 571 kPa 非常接近（相对绝对差为 1.2%）。数值模拟结束时的位移场如图 5（Figure 5）所示。

用于生成数值解的数据文件为“foot-hex.dat”。“foot.fis”中的 FISH 函数 荷载计算函数（fload） 计算归一化的平均基底压力 \(p/c\)。

图 4：荷载-位移曲线。

图 5：剖面中位移矢量的 3DEC 图。

该压入问题采用高阶四面体单元求解。图 6（Figure 6）显示荷载-位移曲线。承载力值为 619 kPa。这略大于理论上限（相对绝对差为 8%）。在此情况下，高阶单元的结果不如混合离散化准确。

图 6：高阶单元的荷载-位移曲线。

图 7：节点混合离散化的荷载-位移曲线。

图 7（Figure 7）显示了采用节点混合离散化（NMD）时的结果。其结果与采用高阶单元的模型所得结果非常相似。

同一问题也采用规则四面体网格划分求解。然而，用该模型计算的压入压力（如图 8（Figure 8）所示）并不收敛于有限值（即压力随竖向位移持续增大）。该问题说明了 quad 网格划分和混合离散化相对于规则四面体网格单元的主要优势：在弹塑性模型中，采用四面体网格单元的模型无法为极限荷载计算给出准确的解。

图 8：采用四面体网格划分计算的荷载-位移曲线。

数据文件

foot-hex.dat

;==========================================================================
; 验证试验——采用 3DEC 模拟无限大、
;                      各向同性、均质 Tresca 介质中矩形区域的压入
;
; 采用四边形网格的混合离散
; 采用 Mohr-Coulomb 模型的块体
;
;==========================================================================
model new
model large-strain on

block create brick 0 15 0 15 0 10
;
; --- 块体网格划分 ---
;
block zone generate hexahedra divisions 10 15 15
;
; --- 材料参数 ---
;
block zone cmodel assign mohr-coulomb
block zone property bulk 2.e9 shear 1.e9 density 2600  ...
                    cohesion 1.e5 tension 1e20 
block contact material-table default prop stiffness-normal 1e10 ...
                                          stiffness-shear 1e10

;
; --- 边界条件 ---
block gridpoint apply velocity-x 0 range position-x 0
block gridpoint apply velocity-y 0 range position-y 0
block gridpoint apply velocity 0 0 0 range position-x 15
block gridpoint apply velocity 0 0 0 range position-y 15
block gridpoint apply velocity 0 0 0 range position-z 0

block gridpoint group 'foot' range position-x -0.1 3.1  ...
                                   position-y -0.1 3.1 position-z 10
block gridpoint apply velocity-x 0. velocity-y 0. velocity-z -1e-2 ...
                      range group 'foot'
  
program call 'foot.fis'
[setup('foot')]

model history mechanical unbalanced-maximum
fish history load
fish history solution
fish history disp
history name '2' label '3DEC'
history name '3' label 'Analytic'
history name '4' label 'Displacement'
model cycle 8000
model save 'foot-hex'
program return

foot.fis

fish automatic-create off
;---------------------------------------------------------------------
; 定义监测基础总荷载与位移的 FISH 函数
;---------------------------------------------------------------------
fish define setup(name)
    global points = map
    global solution = (5.24+0.47)
    global cohesion = 1e5
	
    ; 找到基础上的所有网格点并存入映射
    global n = 0
    loop foreach local gp block.gp.list
        if block.gp.isgroup(gp,name) then
            points(map.size(points)) = gp ; 存入映射，采用随机的唯一索引
            local height = block.gp.pos.z(gp) ; 存储基础高度
        end_if
    end_loop
    ; 找到基础右侧、与其等高的第一个网格点
    local xnext = 20.0
    loop foreach gp block.gp.list
        if block.gp.isgroup(gp,name)==false then
            if block.gp.pos.z(gp)==height then
              if block.gp.pos.y(gp)==0
                xnext = math.min(xnext,block.gp.pos.x(gp))
              endif
            end_if
        end_if
    end_loop
    global width = (3.0 + xnext) * 0.5 ; 修正后的宽度
    global center = block.gp.near(0,0,10)
end
;---------------------------------------------------------------------
; p_load：基础平均压力 / c
; c_disp：基础中心竖向位移大小 / a
;---------------------------------------------------------------------
fish define load
    local accum = 0.0
    loop foreach local gp points
        accum = accum - block.gp.force.reaction.z(gp)
    end_loop
    global disp = -block.gp.disp.z(center)
    load = accum / (width * width * cohesion)
end
