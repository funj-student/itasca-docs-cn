欢迎使用 3DEC 7.0 文档。

3DEC 旧版本的用户在深入本版本的命令与 FISH 之前，可先从 面向 3DEC 5.2 用户的 3DEC 7（3DEC 7 for 3DEC 5.2 Users） 页面入手。

3DEC 使用的主要命令汇总于下面的列表。注意其中既包括 3DEC 特有命令，也包括 PFC 和 FLAC3D 常用的命令。

表 1：3DEC 命令
c block c 历史（history）
c 数据（data） c 模型（model）
c dfn c 绘图（plot）
c 域（domain） c 程序（program）
c FISH函数（fish） c 项目（project）
c 流动（flow） c sel
c 碎片（fragment） c 结构单元（structure）
c 几何（geometry） c 表格插值取值（table）
c 分组（group） c 追踪（trace）
