各向异性应力弹性介质中的圆形衬砌隧道

问题描述

注意

要在 3DEC 中查看该项目，请使用菜单命令 帮助 ► 示例…。选择 “BlockSel/ VerificationProblems/ linedCircularTunnel”，然后选择 “LinedCircularTunnel.prj” 载入。所用的主数据文件（data file）显示在本示例末尾。其余数据文件可在该项目中找到。

半径 5 m 的圆形隧道位于 30 m 深处的软弹性土体中（\(E\) = 48 MPa，\(\nu\) = 0.34，\(\rho\) = 2000 kg/m3）。地应力为竖向 600 kPa、水平 300 kPa。隧道由 125 mm 厚的喷射混凝土衬砌支护（\(E=25 GPa\)，\(\nu=0.15\)）。假定支护与开挖同时施作，且处于预先存在的各向异性双向应力场中。在平面应变条件下，针对地层-支护接触面的两种极限情况——无滑移（无相对剪切位移）和完全滑移（不传递剪应力）——计算支护位移与内力（以轴力和弯矩表示）以及接触面接触应力。将这些计算值与 Einstein 和 Schwartz（1979）的解析解进行比较。

解析解

解析解（Einstein 和 Schwartz，1979）采用 图 1（Figure 1） 中的符号表示。支护位移包括径向分量 \(u_s\) 和切向分量 \(v_s\)。内力包括轴力 \(T\) 和弯矩 \(M\)。接触面接触应力包括法向分量 \(\sigma_R\) 和剪切分量 \(\tau_{R\theta}\)。

图 1：解析解的符号约定：(a) 地层介质；(b) 隧道衬砌；(c) 衬砌内力的正方向。

无滑移解——对于无滑移解，接触面边界条件为地层与支护之间不发生相对剪切位移。无滑移解由以下公式给出：

\[\begin{split}\begin{split} u_s &= {PR(1 + \nu) \over E} \biggl\{ {1\over2}(1 + K)a^*_0 + {1\over2}(1 - K)\left[4(1 - \nu)b^*_2 - 2a^*_2 \right]\cos 2\theta \biggr\} \\ v_s &= {PR(1 + \nu) \over E} \biggl\{ -(1 - K)\left[a^*_2 + (1 - 2\nu) b^*_2 \right]\sin 2\theta \biggr\} \\ T &= {P R \over 2} \biggl\{ (1 + K)(1 - a^*_0) + (1 - K)\left[1 + 2a^*_2 \right]\cos 2\theta \biggr\} \\ M &= {P R^2 \over 2} \biggl\{ {1\over2}(1 - K)\left[1 - 2a^*_2 + 2b^*_2 \right]\cos 2\theta \biggr\} \\ \sigma_R &= {P \over 2} \biggl\{ (1 + K)(1 - a^*_0) - (1 - K)\left[1 - 6a^*_2 + 4b^*_2 \right]\cos 2\theta \biggr\} \\ \tau_{R\theta} &= {P \over 2} \biggl\{ (1 - K)\left[1 + 6a^*_2 - 2b^*_2 \right]\sin 2\theta \biggr\} \end{split}\end{split}\]
其中： \(\theta\) = 角位置（相对于水平方向逆时针量取）；
  \(R\) = 隧道半径；
  \(P\) = 竖向应力；
  \(K\) = 水平与竖向应力之比；
  \(E\) = 地层的杨氏模量；
  \(\nu\) = 地层的泊松比；以及
  \(a^*_0,a^*_2,b^*_2\) = 无量纲系数（见下面的公式）。
\[\begin{split}\begin{split} a^*_0 &= { C^* F^* (1 - \nu) \over C^* + F^* + C^* F^* (1 - \nu)} \\ a^*_2 &= \beta b^*_2 \\ b^*_2 &= { C^* (1 - \nu) \over 2\bigl[C^* (1 - \nu) + 4\nu - 6\beta - 3\beta C^*(1 - \nu) \bigr]} \\ \beta &= { (6 + F^*) C^* (1 - \nu) + 2F^* \nu \over 3F^* + 3C^* + 2C^* F^* (1 - \nu)} \end{split}\end{split}\]
其中： \(C^*\), \(F^*\) = 分别为压缩比和柔度比（见随后两个公式）。
(1)\[\begin{split}\begin{split} C^* &= { E R (1 - \nu_s^2) \over E_s A_s (1 - \nu^2)} \\ F^* &= { E R^3 (1 - \nu_s^2) \over E_s I_s (1 - \nu^2)} \end{split}\end{split}\]
其中： \(E_s\) = 支护的杨氏模量；
  \(\nu_s\) = 支护的泊松比；
  \(A_s\) = 单位隧道长度上支护的平均横截面积
      （对于厚度恒为 \(t\)、\(A_s = t\) 的支护）；以及
  \(I_s\) = 单位隧道长度上支护的惯性矩
      （对于厚度恒为 \(t\)、\(I_s = t^3/12\) 的支护）。

完全滑移解——对于完全滑移解，接触面边界条件为地层与支护之间不传递剪应力。完全滑移解由以下公式给出：

\[ \begin{align}\begin{aligned}\begin{split}\begin{split} u_s &= {PR(1 + \nu) \over E} \biggl\{ {1\over2}(1 + K)a^*_0 - (1 - K)\left[(5 - 6\nu)a^*_2 - (1 - \nu) \right]\cos 2\theta \biggr\} \\ v_s &= {PR(1 + \nu) \over E} \biggl\{ {1\over2}(1 - K)\left[(5 - 6\nu)a^*_2 - (1 - \nu) \right]\sin 2\theta \biggr\} \\ \\\end{split}\\\begin{split} T &= {P R \over 2} \biggl\{ (1 + K)(1 - a^*_0) + (1 + K)\left[1 - 2a^*_2 \right]\cos 2\theta \biggr\} \\ M &= {P R^2 \over 2} \biggl\{ (1 - K)\left[1 - 2a^*_2 \right]\cos 2\theta \biggr\} \\ \\\end{split}\\\begin{split} \sigma_R &= {P \over 2} \biggl\{ (1 + K)(1 - a^*_0) - (1 - K)\left[3 - 6a^*_2 \right]\cos 2\theta \biggr\} \\ \tau_{R\theta} &= 0 \end{split}\end{split}\end{aligned}\end{align} \]
其中： \(\theta\) = 角位置（相对于水平方向逆时针量取）；
  \(R\) = 隧道半径；
  \(P\) = 竖向应力；
  \(K\) = 水平与竖向应力之比；
  \(E\) = 地层的杨氏模量；
  \(\nu\) = 地层的泊松比；以及
  \(a^*_0\), \(a^*_2\) = 无量纲系数（见随后的公式）。
\[\begin{split}\begin{split} a^*_0 &= { C^* F^* (1 - \nu) \over C^* + F^* + C^* F^* (1 - \nu)} \\ a^*_2 &= { (F^* + 6)(1 - \nu) \over 2F^* (1 - \nu) + 6(5 - 6\nu)} \end{split}\end{split}\]
其中： \(C^*\), \(F^*\) = 分别为压缩比和柔度比（见上文公式 (1)）。

3DEC 模型

该问题用解析解中的以下参数来描述：

几何  
隧道半径（\(R\)） 5 m
地应力  
竖向应力（\(P\)） 600 kPa
水平与竖向应力之比（\(K\)） 0.5
（\(\sigma_{xx}=-300\) kPa；\(\sigma_{zz}=-600\) kPa）  
地层属性  
杨氏模量（\(E\)） 48 MPa
泊松比（\(\nu\)） 0.34
（剪切模量 = 17.91 MPa；体积模量 = 50 MPa）  
线性属性  
杨氏模量（\(E_s\)） 25 GPa
泊松比（\(\nu_s\)） 0.15
厚度（\(t\)） 125 mm

3DEC 模型模拟的是无限弹性地层中圆形隧道的一个薄片，处于预先存在的各向异性双向应力场中并受平面应变条件约束。3DEC 模型的几何形状见 图 2（Figure 2）。远场边界置于 20 倍隧道半径的距离处，以近似无限边界。地应力施加于所有网格单元，同时也作为荷载施加在远场边界上。通过在 \(y\) 方向包含一层薄材料并在这两个面上施加对称边界条件来实现平面应变条件。在 \(x=0\) 和 \(z=0\) 处的平面上也施加对称边界条件。对于网格点，这要求保持垂直于该平面的位移为零。对于节点，这要求保持垂直于该平面的位移为零，并保持绕位于该平面内的两个轴的转动为零。（通过重新对齐并固定相应的节点局部坐标系，以及指定相应的速度固定条件来施加合适的节点条件——该过程的说明见掘进衬砌隧道（Advancing Lined Tunnel）。）

3DEC 网格在 \(y\) 方向上只含一层网格单元，且随远离隧道而逐渐变疏（见 图 2（Figure 2））。模型沿隧道边界的分辨率为 24 个网格单元。带交叉网格图案的衬砌结构单元（选择该网格图案的原因见衬砌与加筋梁（Liner-Reinforced Beam））附着在沿隧道边界的网格单元面上（见 图 3（Figure 3））。衬砌-网格单元接触面刚度（\(k_n\) 和 \(k_s\)）按 衬砌属性 中该公式（this equation）取值，并按该公式后文所述将数值增大 100 倍。（下文将确认本系统满足接触面变形很小的判据。）

结果与讨论——定性评估

我们通过绘制隧道拱顶和起拱线处网格点与节点的位移（见 图 4（Figure 4）），确认接触面变形相对于网格单元变形很小（从而确认弹性接触面刚度 \(k_n\) 和 \(k_s\) 足够大）。网格点与节点之间的相对位移相比网格点位移很小。

图 4：无滑移情况下隧道拱顶（网格点 1873，节点 50）与起拱线（网格点 1，节点 1）处网格点和节点的位移。

若在不加支护的情况下运行模型（即删除衬砌单元），隧道拱顶和起拱线均向内移动（见 图 5（Figure 5））。当包含支护时，隧道拱顶仍向内移动，但隧道起拱线向外移动（见 图 6（Figure 6）），因为支护抵抗了地层的向内运动。如果允许衬砌在支护-地层接触面处滑移（将衬砌属性 coupling-cohesion-shear 设为零），衬砌与地层之间将发生相对剪切运动（见 图 7（Figure 7））。

图 5：无衬砌时地层的位移场。

图 6：衬砌与地层的位移场（无滑移）。

图 7：衬砌与地层的位移场（完全滑移）。

无滑移和完全滑移两种情况下衬砌中的轴力 \(T\) 和弯矩 \(M\) 见 图 8（Figure 8） 至 图 11（Figure 11）。当允许衬砌滑移时，轴力变得更均匀，弯矩略有增大。我们定义衬砌表面坐标系，其 \(x\) 轴沿隧道轴线（即全局 \(y\) 方向），\(z\) 轴垂直于壳单元中面（指向内侧）。这对应于应力恢复过程中的 surface = (0, 1, 0) 方向。（需指定该表面坐标系，详见应力恢复过程（Stress Recovery Procedure）。）在该坐标系下，轴力对应薄膜应力合力 \(N_y\)，弯矩对应弯曲应力合力 \(M_y\)。在这些图中，衬砌的取向为从左到右对应闭式解中的角位置 \(\theta\) 由零到九十度。注意 \(N_y\) 和 \(M_y\) 的这些值与解析解中 \(T\) 和 \(M\) 的值符号相反。（正的 \(N_y\) 使壳单元伸长，正的 \(M_y\) 在由表面坐标系正 \(z\) 方向所定义的壳单元一侧外缘产生正应力。）

接触面接触应力 \(\sigma_R\) 和 \(\tau_{R\theta}\) 在无滑移和完全滑移两种情况下的结果见 图 12（Figure 12） 至 图 15（Figure 15）。这些值由连接衬砌节点与网格单元的法向和剪切耦合弹簧得到。正法向应力表示分离，该约定与解析解相反。绘出的剪应力仅表示大小；方向可通过 FISH 函数 衬砌单元法向耦合弹簧加载方向（struct.liner.normal.dir） 和 衬砌单元剪切耦合弹簧加载方向（struct.liner.shear.dir） 输出或获取。

图 16（Figure 16） 至 图 24（Figure 24） 给出了无滑移和完全滑移两种情况下支护位移、内力以及接触面接触应力与解析解的定量比较。FISH 函数从 3DEC 模型中提取所需数值，并与解析值比较。将 “no_slip”变量（no _slip） FISH 变量设为 1 或 0，即可分别选用无滑移或完全滑移解析解。支护位移（\(u_s\) 和 \(v_s\)）用 结构节点全局位移（struct.node.disp.global） 函数在节点处采样。内力（\(T\) 和 \(M\)）用 壳单元节点应力合力（struct.shell.resultant） 函数在单元形心处采样。此外，接触面接触应力（\(\sigma_R\) 和 \(\tau_{R\theta}\)）通过用 衬砌单元法向耦合弹簧应力（struct.liner.normal.stress） 和 衬砌单元剪切耦合弹簧应力（struct.liner.shear.stress） 函数计算衬砌结构单元节点处三个耦合弹簧的平均值，在衬砌结构单元形心处采样。

对于无滑移和完全滑移两种情况，响应均与解析解吻合良好。支护位移与解析解相符，最大偏差约为 2%（位于隧道拱顶）。轴力与解析解相符，最大偏差约为 1.2%。在远离模型端部处（\(\theta\) 等于 0 和 90 度处），接触面接触应力与解析解相符。端部位置存在约 10% 的误差（注意 图 19（Figure 19） 和 图 24（Figure 24） 中的离群点），这源于网格的不对称性。端部两个节点所分配的面积不相等，因为它是使用该节点的各单元面积三分之一的累加。在每个端部，一个节点的面积是另一个的两倍，这会影响应力计算，使结果不对称。注意这两个离群点分别位于解析解两侧，且其平均值等于解析解。

数据文件

LinedCircularTunnel.dat

model new
model large-strain off
fish automatic-create off
[global t1 = 'Lined Circular Tunnel ']
[global t2 = 'in an Elastic Medium with Anisotropic Stresses']
[global t = t1 + t2]
model title [t]
; 创建岩土体，即网格单元。
block create tunnel block-radial 40 blocks-tangential 12 blocks-axial 1 ...
    boundary 20 length 0 0.4 radius 5.0 radius-ratio 1.05
    
block delete range pos-x -105 0
block delete range pos-z -105 0
block join

block zone generate edgelength 10.0

block group 'rock'
block group 'tunnel' range cylinder end-1 0 0 0 end-2 0 0.4 0 radius 5.0
block face group 'surface' range group-intersection 'rock' 'tunnel'

block delete range group 'tunnel'

; 材料模型和参数                            
block zone cmodel assign elastic
block zone property bulk 5e7 shear 1.791e7 dens 2500

; 创建支护，即衬砌结构单元。
struct liner create by-block-face range group 'surface'
struct liner property isotropic (2.5e10, 0.15) thickness 0.125 ...
                      coupling-stiffness-normal 2.0763e10 ...
                      coupling-stiffness-shear 2.0763e10 ...
                      coupling-cohesion-shear 1e20
                      
; 在整个网格中赋予原位应力。
block zone initialize stress xx -3e5 yy -3e5 zz -6e5

; 指定边界条件。
; 在远场边界施加应力
block face apply stress-xx -3e5 range pos-x 105.0
block face apply stress-zz -6e5 range pos-z 105.0
  ; 对于网格点，采用以下对称条件。
block gridpoint apply velocity-x 0.0 range pos-x 0.0
block gridpoint apply velocity-z 0.0 range pos-z 0.0
block gridpoint apply velocity-y 0.0 range pos-y 0.0
block gridpoint apply velocity-y 0.0 range pos-y 0.4

; 对于结构节点，采用以下对称条件。
struct node system-local x (1,0,0) y (0,-1,0)    ...
            range position-x 0   ; x=0 平面
struct node fix system-local                     ...
            range position-x 0
struct node fix velocity-x rotation-y rotation-z ... 
            range position-x 0
struct node system-local x (0,0,-1) y (0,-1,0)   ... 
            range position-z 0   ; z=0 平面
struct node fix system-local                     ... 
            range position-z 0
struct node fix velocity-x rotation-y rotation-z ... 
            range position-z 0
struct node fix velocity-y rotation-x rotation-z ... 
            range position-y 0   ; y=0 平面
struct node fix velocity-y rotation-x rotation-z ... 
            range position-y 0.4 ; y=Ymax 平面
; 历史
model history mechanical ratio-local
block history displacement-x position (5,0,0)        ; 隧道起拱线
block history velocity-x     position (5,0,0)
struct node history displacement-x position (5,0,0)
struct node history velocity-x     position (5,0,0)
block history displacement-z position (0,0,5)        ; 隧道拱顶
block history velocity-z     position (0,0,5)
struct node history displacement-z position (0,0,5)
struct node history velocity-z     position (0,0,5)
history interval 10
; 
model save 'starting'
; 无支护工况
struct liner delete
model solve ratio 1e-4
model title [t]
model save 'No Support'
; 允许滑移的工况
model restore 'starting'
struct liner property coupling-cohesion-shear 0
model solve ratio 1e-4 
model title [t + " - Full Slip"]
model save 'Full Slip'
; 不允许滑移的工况
model restore 'starting'
model solve ratio 1e-4 
model title [t + " - No Slip"]
model save 'No Slip'

program return
