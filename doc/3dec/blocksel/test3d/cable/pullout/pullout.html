示例：注浆锚索的拉拔试验

问题描述

注意

要在 3DEC 中查看该项目，请使用菜单命令 帮助 ► 示例…。选择 “BlockSel/ Cable/ pullout”，然后选择 “pullout.prj” 载入。所使用的数据文件显示在本示例末尾。

确定锚索锚杆属性最常用的方法是在现场对注浆锚索的小段进行拉拔试验。通常将 10 至 50 cm 长的段注浆锚固于钻孔中。这些段的端部用安装在隧道表面的千斤顶拉拔，并通过筒夹楔块式锚具与锚索连接。将施加到锚索上的力和锚索的变形绘成轴力/挠度曲线。通常由该曲线确定注浆体黏结的峰值抗剪强度，并换算为单位锚索长度上的强度（吨/米）。

本示例模拟单根直径 15.2 mm 锚索的拉拔试验。锚索的材料属性为：

表 1：锚索属性
锚索面积 181 mm^2
锚索模量 98.6 GPa
锚索黏结长度 17.7 m
锚索抗拉承载力 0.5 MN

我们为注浆体选取以下属性：

表 2：注浆体属性
注浆体黏结刚度 112 MN/m/m
注浆体黏结强度 0.175 MN/m

这些数值代表软弱注浆体（例如见 Hyett 等，1992）。注意，锚索长度和注浆体强度是为快速运行模型而选取的。其目的是说明锚索单元的性能。

锚索被划分为 10 个分段。通过为第一个节点指定速度来施加拉拔力。

FISH 函数 pullf 用于监测锚索上的拉拔力（单位锚索长度的拉拔力）。拉拔力由锚索被拉拔时在块体上产生的反力之和确定。注意，反力在循环计算结束时被置零，因此 pullf 中的拉拔力计算在循环停止前一步结束。该模型的数据文件见 pullout.dat

图 1（Figure 1） 显示了试验结束时锚索中的轴力分布。试验所得总拉拔力随位移变化的曲线见 图 2（Figure 2）。如该图所示，峰值荷载与注浆体黏结强度的输入值非常接近。

图 1：拉拔试验中锚索的轴力。

图 2：锚索注浆体剪力（N/m）随锚索位移（m）的变化（注浆体内摩擦 = 0）。

一般而言，锚索的剪切黏结强度会随作用在锚索上的有效压力增大而增大。在上述模型中并未出现这种情况，因为注浆体的摩擦强度设为了 0。为检验其对围压的依赖性，运行同一模型，但赋予非零的注浆体摩擦和周长。注浆体内摩擦角设为 30◦。周长按孔径为锚索直径两倍来确定。使用行内 FISH 进行计算。该试验结果见 图 3（Figure 3）。可以看到，该锚索确实强于注浆体摩擦强度为零的锚索。

图 3：锚索注浆体剪力（N/m）随锚索位移（m）的变化（注浆体内摩擦 = 30◦）。

参考文献

Hyett, A. J., W. F. Bawden and R. D. Reichert. “The Effect of Rock Mass Confinement on the Bond Strength of Fully Grouted Cable Bolts,” Int. J. Rock Mech. Min. Sci. & Geomech. Abstr., 29(5), 503-524 (1992).

数据文件

pullout.dat

model new
model random 10000
model large-strain on

block create brick -1,1 -1,1 -2,0

block zone gen edgelength .5 
block zone cmodel assign elastic
block zone prop bulk 5e9 shear 3e9 density 2500

block gridpoint apply vel 0 0 0 range pos-x -1
block gridpoint apply vel 0 0 0 range pos-x 1
block gridpoint apply vel 0 0 0 range pos-y -1
block gridpoint apply vel 0 0 0 range pos-y 1
block gridpoint apply vel-z 0 range pos-z -2
block gridpoint apply vel-z 0 range pos-z 0

struct cable create by-line 0,0,-1.77  0,0,-0.01 seg 10
struct cable prop cross-sectional-area 181e-6 young 98.6e9 yield-tension 5e6 grout-stiffness 1.12e8 grout-cohesion 1.75e5

; 在局部坐标系中施加速度，x 为轴向
struct node fix velocity-x range pos-z -0.02 0.02
struct node ini velocity-x 0.05 range pos-z -0.02 0.02

; 施加应力
block insitu stress -2e6 -2e6 0 0 0 0
;
fish def pullf
    local sum = 0.0
    loop foreach gpp block.gp.list
        sum = sum - block.gp.force.reaction.z(gpp)
    endloop
    pullf = sum / 1.77 ; 锚杆长度
end

fish hist pullf

struct node his disp-z pos 0 0 0
struct cable his grout-stress pos 0 0 -1

model save 'pullout-ini'
model cycle 10000

model save 'pullout'

pullout-confined.dat

model rest 'pullout-ini'

; 添加摩擦强度，假定孔半径为锚索半径的两倍
struct cable prop grout-friction 30.0 grout-perimeter [2.0*math.pi*2.0*math.sqrt(181e-6/math.pi)]
model cycle 10000

model save 'pullout-confined'
