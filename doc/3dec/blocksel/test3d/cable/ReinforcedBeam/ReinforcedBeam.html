锚索加筋梁

问题描述

注意

要在 3DEC 中查看该项目，请使用菜单命令 帮助 ► 示例…。选择 “BlockSel/ Cable/ ReinforcedBeam”，然后选择 “ReinforcedBeam.prj” 载入。所用的主数据文件（data file）显示在本示例末尾。其余数据文件可在该项目中找到。

本示例说明承受重力荷载的简支轻配筋梁的行为。采用锚索单元表示配筋。

通过在梁中心加入零强度接触面，在梁中形成一条竖向裂缝。若在不加筋的情况下运行模型（即删除 structure cable create 命令），系统表现为在接触面处分离的两块独立块体。这两块块体支承在滚轴上，因此当系统失稳时可以彼此移开（见 图 1（Figure 1））。

图 1：3000 次循环后的结构构型（无锚索）。

若在梁底部纤维附近插入锚索后重新运行模型，则锚索承担梁下部分产生的拉力。模型稳定后锚索中的最终轴力分布见 图 2（Figure 2）。锚索中的这些拉力由沿锚索长度发展起来的注浆体应力产生（见 图 3（Figure 3））。最大竖向中线位移约为 10 mm。

图 2：锚索中的最终轴力分布。

图 3：最终注浆体应力分布。

锚索的平均轴向方向从左到右，与 沿线创建锚索单元命令（structure cable create by-line） 命令所给各点的方向一致。在 图 3（Figure 3） 中可以看到，注浆体应力在锚索右侧为正、左侧为负。这些数值可用 列出锚索单元浆液命令（structure cable list grout） 命令输出。

在之前的模型中，注浆体黏结强度设得很大以防止注浆体破坏。若将注浆体黏结强度设为 1.5 × 105 N/m 并重新运行模型，可以发现系统仍然稳定；但在加载过程中，中部区域的注浆体发生屈服（锚索滑动）（见 图 4（Figure 4））。该区域的注浆体应力等于注浆体黏结强度（见 图 5（Figure 5）），拉力分布到锚索更远处（对比 图 2（Figure 2） 和 图 6（Figure 6）），最大竖向中线位移从 10 mm 增大到 11.8 mm。

图 4：最终注浆体滑移状态（降低后的注浆体黏结强度）。

图 5：最终注浆体应力分布（降低后的注浆体黏结强度）。

图 6：锚索中的最终轴力分布（降低后的注浆体黏结强度）。

数据文件

ReinforcedBeam.dat

model new
model large-strain on
model random 10000
model title "Cable-reinforced beam"
; 创建由网格单元组成的梁 
block create brick 0 6 0 1 0 3
block create brick 6 12 0 1 0 3
block zone generate edgelength 0.5

; 节理参数
block contact property stiffness-normal 1e10 stiffness-shear 1e10
block contact material-table default property stiffness-normal 1e10 ...
                                              stiffness-shear 1e10

; 网格单元参数
block zone cmodel assign elastic
bloc zone property bulk 1e9 shear .3e9 dens 2400

; 边界条件，约束左右下角点
block gridpoint apply velocity-z 0 range position-z 0 position-x 0
block gridpoint apply velocity-z 0 range position-z 0 position-x 12

; 重力加速度
model gravity 10

model save 'Start'
======================================================
; 先计算无锚索的工况
block mechanical damping combined
model cycle 3000
model save 'NoCable'
==================================================
; 然后重新计算有锚索的工况
model restore 'Start'
; 创建锚索并设置参数
struct cable create by-line (0.1, 0.5, 0.1) (11.9, 0.5, 0.1) id=1 segments=13
struct cable property cross-sectional-area=2e-3 young=200e9 ...
                      yield-tension=1e20 grout-stiffness=1e10 ...
                      grout-cohesion=1e20 
block mechanical damping combined
model solve ratio 1e-4
model save 'Cable'
=====================================================
; 现在允许锚索发生破坏
struct cable property grout-cohesion 1.5e5
model solve ratio 1e-4
model save 'CableFail'
