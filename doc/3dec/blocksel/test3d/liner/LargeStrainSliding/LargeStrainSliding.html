大应变滑移演示

问题描述

注意

要在 3DEC 中查看该项目，请使用菜单命令 帮助 ► 示例…。选择 “BlockSel/ Liner/ LargeStrainSliding”，然后选择 “LargeStrainSliding.prj” 载入。所用的主数据文件（data file）显示在本示例末尾。其余数据文件可在该项目中找到。

将一个 0.33 m2 的衬砌置于 1 m³ 土体块顶部，先向下压入土体，然后沿土体表面横向移动。该问题以大应变模式运行。衬砌先向下移动 10 cm，然后沿对角线横向移动，直到衬砌位于顶面原始角点处。对于衬砌与网格单元之间如此大的相对运动，必须将衬砌的大应变滑移标志设为 开启（on）。（衬砌通过节点-网格单元连接与网格相互作用。这些连接存储网格单元及其内部的插值位置，以便在节点与网格单元之间传递力和速度。默认情况下，即使在以大应变模式运行时，这些插值位置也不会改变。通过将大应变滑移标志设为 设置衬砌单元滑动属性命令（structure liner property slide） 开启（on），可使插值位置随网格迁移。）

3DEC 模型为一个 1 m³ 的土体块，其顶部中央放置由 xx 个衬砌单元组成、面积 0.33 m2 的混凝土衬砌，如 图 1（Figure 1） 所示。土体赋予弹性属性（\(E\) = 15 MPa，\(\nu\) = 0.3）。衬砌材料赋予对应于 0.1 m 厚混凝土衬砌的属性（\(E\) = 25 GPa，\(\nu\) = 0.15，\(t\) = 0.1 m），并赋予以下衬砌-网格单元接触面属性：

接触面法向刚度（interface normal stiffness）（\(k_n\)） 8 × 108 N/m3
接触面剪切刚度（interface shear stiffness）（\(k_s\)） 8 × 108 N/m3
抗拉强度（\(f_t\)） 0 MPa
黏聚力（\(c\)） 0 MPa
残余黏聚力（\(c_r\)） 0 MPa
摩擦角（\(\phi\)） 0 degrees

图 1：用于大应变滑移演示的 3DEC 模型。

首先，从数据文件中删除 设置衬砌单元滑动属性命令（structure liner property slide） 命令，以关闭大应变滑移运行该问题。施加 10 cm 向下位移后网格单元中的 \(zz\) 向应力见 图 2（Figure 2）。该阶段响应合理，因为衬砌节点与网格单元之间尚未发生大的相对运动。然而，在衬砌沿对角线移动后，从 图 3（Figure 3） 中可以看到 \(zz\) 向应力与网格单元变形场不再与衬砌位置一致。这是不正确的。插值位置并未从初始位置移动，因此网格仍感受到作用于块体中心的压力。

当开启大应变滑移重新运行该问题时，行为是正确的（见 图 4（Figure 4） 和 图 5（Figure 5））。\(zz\) 向应力与网格单元变形场均与衬砌位置一致，因为插值位置已随网格迁移而跟随衬砌运动。事实上，甚至可以将衬砌完全移出网格，如 图 6（Figure 6） 所示。若衬砌节点随后重新与任何网格单元面接触，相应连接将会重新建立（见 图 7（Figure 7））。

图 2：土体中的竖向应力（大应变滑移关闭；法向位移 10 cm）。

图 3：土体中的竖向应力（大应变滑移关闭；剪切位移 47.6 cm）。

图 4：土体中的竖向应力（大应变滑移开启；法向位移 10 cm）。

图 5：土体中的竖向应力（大应变滑移开启；剪切位移 47.6 cm）。

图 6：土体中的竖向应力（大应变滑移开启；剪切位移 105 cm）。

图 7：土体中的竖向应力（大应变滑移开启；剪切位移 -453 cm）。

数据文件

LargeStrainSliding.dat

; 衬砌结构单元应用算例
; 衬砌大应变滑动演示
model new
model random 10000
fish automatic-create off
model title 'Demonstration of Large-Strain Sliding for a Liner'

; 创建土体。
block create brick 0 1

; 切割长方体，以添加覆盖表面 1/3 的正方形衬砌
block cut joint-set dip 90 dip-direction 90 or 0.33 0 0
block cut joint-set dip 90 dip-direction 90 or 0.66 0 0
block cut joint-set dip 90 dip-direction 0 or 0 0.33 0
block cut joint-set dip 90 dip-direction 0 or 0 0.66 0

block join

block zone gen edgelength 0.1
block zone cmodel assign elastic
block zone prop dens 2000 bulk=12.5e6 shear=5.77e6  ; 土体

; 大应变计算所需的默认接触参数
block contact material-table default prop stiff-norm 1e8 stiff-shear 1e8

block gridpoint apply velocity-z 0 range position-z 0

; 创建混凝土衬砌。
struct liner create by-block-face range position (0.33,0.33,1) (0.66,0.66,1) 
struct liner property isotropic=(25e9,0.15) thickness=0.1  ; 混凝土
struct liner property coupling-stiffness-normal=8e8 ...
                      coupling-stiffness-shear=8e8  ...
                      coupling-yield-normal=0.0     ...
                      coupling-cohesion-shear=0.0   ...
                      coupling-cohesion-shear-residual=0.0 ...
                      coupling-friction-shear=0.0
struct node fix velocity  ; 完全固定所有节点

struct damping combined-local
model large-strain on
block history name='szz' stress-zz position (0.5,0.5,1)
model cycle 1 ; 获取时间步长
[global dt_ = mech.timestep]

model save 'slide0'

; 施加衬砌位移，并关闭衬砌大应变滑动
struct node initialize velocity 0 0 [-1e-4/dt_] local ; 法向位移 = -10 cm
model cycle 1000                                  ; 剪切位移 = 0
model save 'slide1-off'

struct node initialize velocity ...
                       [3.3e-4/dt_] [-3.3e-4/dt_] 0.0 local ; 法向位移 = 0
model cycle 1000                                       ; 剪切位移 = +476 cm
model save 'slide2-off'

model restore 'slide0'
; 启用衬砌大应变滑动
struct liner property slide on

; 施加衬砌位移
struct node initialize velocity 0 0 [-1e-4/dt_] local ; 法向位移 = -10 cm
model cycle 1000                                  ; 剪切位移 = 0
model save 'slide1'

struct node initialize velocity ...
                       [3.3e-4/dt_] [-3.3e-4/dt_] 0.0 local ; 法向位移 = 0
model cycle 1000                                       ; 剪切位移 = +476 cm
model save 'slide2'
model cycle 1200                             ; 剪切位移 = +571 cm
model save 'slide3'

struct node initialize velocity 0 0 [1e-3/dt_] local ; 法向位移 = +12 cm
model cycle 120                                  ; 剪切位移 = 0
struct node initialize velocity [-3.3e-3/dt_] [3.3e-3/dt_] 0.0 ; 法向位移 = 0
model cycle 315                                      ; 剪切位移 = -1500 cm
struct node initialize velocity 0 0 [-1e-4/dt_] local ; 法向位移 = -12 cm
model cycle 1200                                  ; 剪切位移 = 0
model save 'slide4'
