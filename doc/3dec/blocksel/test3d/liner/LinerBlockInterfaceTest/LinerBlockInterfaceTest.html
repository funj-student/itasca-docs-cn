衬砌-块体接触面行为的简单测试

问题描述

注意

要在 3DEC 中查看该项目，请使用菜单命令 帮助 ► 示例…。选择 “BlockSel/ Liner/ LinerBlockInterfaceTest”，然后选择 “LinerBlockInterfaceTest.prj” 载入。所用的主数据文件（data file）显示在本示例末尾。其余数据文件可在该项目中找到。

将衬砌置于土体块顶部，然后沿不同方向移动。监测并绘制其中一个衬砌耦合弹簧的法向、剪应力与位移，以演示衬砌-块体接触面属性对系统响应的影响。

3DEC 模型为一个 1 m³ 的土体块，其顶部中央放置由 8 个衬砌单元组成、面积 0.33 m2 的混凝土衬砌，如 图 1（Figure 1） 所示。土体赋予弹性属性（\(E\) = 15 MPa，\(\nu\) = 0.3）。衬砌材料赋予对应于 0.1 m 厚混凝土衬砌的属性（\(E\) = 25 GPa，\(\nu\) = 0.15，\(t\) = 0.1 m）。衬砌-块体接触面属性（\(k_n\)、\(k_s\)、\(f_t\)、\(c\)、\(c_r\)、\(\phi\)）赋予如下。

接触面刚度（\(k_n\) 和 \(k_s\)）取为 8 × 108 N/m3，以依据 衬砌刚度经验规则（the liner stiffness rule of thumb）保证接触面变形很小。赋予以下接触面强度属性：

抗拉强度（\(f_t\)） 4 MPa
黏聚力（\(c\)） 4 MPa
残余黏聚力（\(c_r\)） 2 MPa
摩擦角（\(\phi\)） 20 degrees

为演示衬砌-网格单元接触面的行为，施加以下条件。所有网格点和节点的速度完全固定。对所有节点施加相同的速度，使衬砌作为刚体运动。这些条件阻止网格单元和衬砌材料中产生内应力；只有衬砌-网格单元接触面弹簧被加载。监测并绘制中心耦合弹簧处的法向、剪应力与位移。在法向应力-法向位移图中，符号约定为压缩和重叠为正（以与表示法向接触面行为（normal interface behaviors）的图一致）。在剪应力-剪切位移图中，剪应力和剪切位移均绘制其大小（以与表示剪切接触面行为（shear interface behaviors）的图一致）。

图 1：用于衬砌-块体接触面行为简单测试的 3DEC 模型。

试验分六个阶段进行。每个阶段施加法向或剪切位移，另一个位移分量保持固定。各阶段所施加的位移列于 表 2（Table 2），其中正/负法向位移表示分离/重叠，沿对角线方向 (1,1,0) 的剪切运动为正。试验结果见 图 2（Figure 2） 至 图 7（Figure 7）。

表 2：所施加的衬砌位移
阶段 法向 (mm) 剪切 (mm)
1a 0 +15
1b 0 -5
2 -10 0
3 0 +10
4 +20 0
6a -20 0
6b 0 +6

在阶段 1 中，先施加 15 mm 的正向剪切位移，再施加 5 mm 的负向剪切位移。响应见 图 2（Figure 2），可与接触面剪切行为（shear interface behavior）对比。该曲线的斜率等于单位面积的剪切耦合弹簧刚度 \(k_s\)，最大值等于黏聚力 \(c\)（因为该阶段接触面法向应力为零）。卸载斜率与加载斜率相同。

在阶段 2 中，衬砌向下移动 10 mm。响应见 图 3（Figure 3），可与接触面法向行为（normal interface behavior）对比。该曲线的斜率等于单位面积的法向耦合弹簧刚度 \(k_n\)。该阶段接触面法向应力 \(\sigma_n\) 等于 8 MPa。在阶段 3 中再施加 10 mm 的剪切位移，响应见 图 4（Figure 4）。剪应力增大并达到最大值 6.91 MPa，该值符合以下关系式

\[\tau_{\rm max} = c + \sigma_n \tan\phi\]

其中：

\(c\) = 黏聚力；

\(\sigma_n\) = 接触面法向应力；以及

\(\phi\) = 内摩擦角。

在阶段 4 中，衬砌向上移动 20 mm。响应见 图 5（Figure 5）。当接触面法向应力达到抗拉强度 \(f_t\)（4 MPa）时，弹簧断裂，使接触面法向应力降至零。当衬砌拉伸破坏时，有效黏聚力变为 \(c_r\)，抗拉强度设为零。总相对法向位移继续被跟踪，以便在间隙闭合时重新产生压缩法向应力。在阶段 5 中再施加 2 mm 的剪切位移，响应见 图 6（Figure 6）。峰值剪应力从 6.91 MPa 降至 2 MPa，因为接触面法向应力为零，此时使用残余黏聚力（residual cohesion）。在阶段 6 中，衬砌向下移动 20 mm，然后再施加 6 mm 的剪切位移。响应见 图 7（Figure 7）。间隙已闭合，接触面法向应力再次为 8 MPa。峰值剪应力为 4.91 MPa，与残余黏聚力（residual cohesion）一致。

数据文件

LinerZoneInterfaceTest.dat

; 衬砌应用算例
; 衬砌与块体接触面行为的简单试验
model new
model random 10000
model large-strain off
model title 'Simple Test of Liner-Block Interface Behavior'

; 创建土体。
block create brick 0 1

; 切割长方体，以添加覆盖表面 1/3 的正方形衬砌
block cut joint-set dip 90 dip-direction 90 or 0.33 0 0
block cut joint-set dip 90 dip-direction 90 or 0.66 0 0
block cut joint-set dip 90 dip-direction 0 or 0 0.33 0
block cut joint-set dip 90 dip-direction 0 or 0 0.66 0

block join

block zone gen edgelength 0.1

block zone cmodel assign elastic
block zone property dens 2000 bulk=12.5e6 shear=5.77e6  ; 土体

; 创建混凝土衬砌。
struct liner create by-block-face range position (0.33,0.33,1) (0.66,0.66,1) 
struct liner property isotropic=( 25e9, 0.15) thickness=0.1  ; 混凝土
struct liner property coupling-stiffness-normal=8e8 ...
                      coupling-stiffness-shear=8e8  ...
                      coupling-yield-normal=4e6     ...
                      coupling-cohesion-shear=4e6   ...
                      coupling-cohesion-shear-residual=2e6 ...
                      coupling-friction-shear=20.0
;
; 完全固定所有网格单元
block gridpoint apply velocity 0 0 0 range pos-x 0
block gridpoint apply velocity 0 0 0 range pos-x 1
block gridpoint apply velocity 0 0 0 range pos-y 0
block gridpoint apply velocity 0 0 0 range pos-y 1
block gridpoint apply velocity 0 0 0 range pos-z 0
block gridpoint apply velocity 0 0 0 range pos-z 1

struct node fix velocity    ; 完全固定所有节点
struct liner history name='nstr' ...
                     coupling-stress-normal       node 3 component-id 3
struct liner history name='ndis' ...
                     coupling-displacement-normal node 3 component-id 3
struct liner history name='sstr' ...
                     coupling-stress-shear        node 3 component-id 3
struct liner history name='sdis' ...
                     coupling-displacement-shear  node 3 component-id 3

; 向衬砌施加六组法向／剪切位移。
struct damping combined-local
model cyc 1 ; 获取时间步长
[dt_ = mech.timestep]
struct node initialize velocity ...
            [0.707e-5/dt_] [0.707e-5/dt_] 0 local     ; 法向位移 = 0 mm
model cycle 1500                                      ; 剪切位移 = +15 mm
struct node initialize velocity ...
            [-0.707e-5/dt_] [-0.707e-5/dt_] 0 local   ; 法向位移 = 0 mm
model cycle 500                                       ; 剪切位移 = -5 mm
model save 'stage1'

struct node initialize velocity 0 0 [-1e-5/dt_] local ; 法向位移 = -10 mm
model cycle 1000                                      ; 剪切位移 = 0 mm
model save 'stage2'

struct node initialize velocity ...
            [0.707e-5/dt_] [0.707e-5/dt_] 0 local     ; 法向位移 = 0 mm
model cycle 1000                                      ; 剪切位移 = +10 mm
model save 'stage3'

struct node initialize velocity 0 0 [1e-5/dt_] local  ; 法向位移 = +20 mm
model cycle 2000                                      ; 剪切位移 = 0 mm
model save 'stage4'

struct node initialize velocity ...
            [0.707e-5/dt_] [0.707e-5/dt_] 0 local     ; 法向位移 = 0 mm
model cycle 200                                       ; 剪切位移 = +2 mm
model save 'stage5'

struct node initialize velocity 0 0 [-1e-5/dt_] local ; 法向位移 = -20 mm
model cycle 2000                                      ; 剪切位移 = 0 mm
struct node initialize velocity ...
            [0.707e-5/dt_] [0.707e-5/dt_] 0 local     ; 法向位移 = 0 mm
model cycle 600                                       ; 剪切位移 = +6 mm
model save 'stage6'
