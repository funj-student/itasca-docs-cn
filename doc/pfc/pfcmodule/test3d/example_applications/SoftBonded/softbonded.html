软黏结材料的生成与试验

问题描述

注意

本算例的项目文件可在 PFC 中查看或运行。[1]所用的数据文件（data files）列于本算例末尾。

以下示例说明使用 软黏结（Soft-Bond） 接触模型生成和试验黏结颗粒模型的过程。首先在周期性域中生成由球颗粒组成的系统，然后在低围压下使其固结。这是通过使用以 FISH 函数实现的伺服算法，使周期性域尺寸发生畸变以达到规定应力状态来实现的。随后在现有接触上安装软黏结接触模型，同时重置接触力。在这个初始无应力系统的基础上，进行以下试验：直接拉伸试验、无侧限压缩试验和有侧限压缩试验。文中讨论了建模过程各阶段所采用的方法，并研究了材料的响应。

数值模型

试样生成

通过调用文件 make_brick.dat 生成初始堆积，该文件使用 servo.fis 中定义的 FISH 函数。试样在整个模型域内生成，所有方向均采用周期性边界条件，以避免边界效应。函数 伺服域（servo_domain） 实现伺服控制算法，旨在更新各方向的域尺寸，以达到并维持规定应力。试样中的应力使用测量球（measurement sphere）监测。请注意，该球被扩展以涵盖整个域，其计算的应力值按域的实际体积进行缩放。

本阶段的目标是生成致密、连接良好的堆积。由于接触模型和性质将在后续阶段被覆盖，因此采用简单的 linear 接触模型。摩擦系数设为零，接触变形参数相对于规定目标应力设置得足够大，以优化计算时间并防止出现较大重叠。请注意，增大目标应力或采用摩擦接触会改变堆积的几何形状，从而影响其后续行为。

为方便起见，文件 make_brick.dat 进行了部分参数化。文件 doall_A10.dat 演示了如何执行该文件以及本例所选参数：

; 生成堆积体
model random 10001
[resolution = 10]   ; 试样宽度方向上的球数近似值 
[davg  = 2.5e-3]    ; 球平均直径 (m)
[dratio = 1.66]     ; 球最大/最小直径比 [-]
[tag = 'A'+ string(resolution)]
program call 'make_brick.dat'

平均球颗粒直径设为 2.5 mm，最大与最小直径比为 1.66，以防止球颗粒局部排列成晶体结构。本例中使用的参数 分辨率（resolution） 表示试样横向尺寸上的目标球颗粒数量；试样长宽比设为 2:1。

接触模型与性质

初始堆积生成后，使用文件 bond_sb.dat 安装 软黏结（soft-bond） 接触模型，并为后续试验准备试样。将接触力重置为零，同时将球颗粒的平动和转动速度及其累积力/力矩和位移重置，并将接触模型替换为 软黏结（soft-bond） 模型。有关该接触模型行为和性质的详细说明，请参阅其文档。

为方便起见，文件 bond_sb.dat 进行了部分参数化。文件 doall_A10.dat 演示了如何执行该文件以及本例所选参数如下：

; 安装接触模型
model restore [string.build('brick_%1-iso',tag)]
[igap     = 0.0*davg ] 
[emod     = 50.0e9   ]
[kratio   = 2.5      ]
[fric     = 0.5      ]
[ten_mean = 20.0e6  ]
[ten_std  = 0.0e6    ]
[coh_mean = 100.0e6  ]
[coh_std  = 0.0e6    ]
[soft     = 0.0      ]
[cut      = 1.0      ]
[tag += '_G0_E50_KR25_S0_C1']
program call 'bond_sb.dat'

接触有效模量设为 50 GPa，法向与剪切刚度比为 2.5，摩擦系数为 0.5。接触抗拉强度设为 20 MPa，黏聚力设为 100 MPa。请注意，尽管文件 bond_sb.dat 允许设置强度参数的正态分布，但本例未使用该功能，所有接触均赋予相同的强度参数。最后，软化系数设为 0.0，软化抗拉强度因子设为 1。采用这些值即禁止软化，模型在破坏方面的行为与 线性平行黏结（linear parallel-bond） 接触模型基本相同。

直接拉伸试验

下面描述并比较两种模拟直接拉伸试验的方法。第一种方法识别试样竖直方向两端的两层球颗粒，并固定其速度。第二种方法使域沿竖直方向向外畸变。

方法 1：使用球颗粒固定

文件 tt.dat 通过固定顶部和底部两层球颗粒的速度来执行直接拉伸试验。为方便起见，该文件进行了部分参数化，文件 doall_A10.dat 演示了如何执行该文件以及本例所选参数如下：

; 进行直接拉伸试验
[tag = 'A10_G0_E50_KR25_S0_C1']
model restore [string.build('brick_%1-bonded',tag)]
[strain_rate = 1.0]
[tag += '_SR1']
program call 'tt.dat'
[tag = 'A10_G0_E50_KR25_S0_C1']
model restore [string.build('brick_%1-bonded',tag)]
[strain_rate = 0.1]
[tag += '_SR01']
program call 'tt.dat'

试验进行两次，采用不同的规定应变率（1.0 和 0.1）。应力—应变响应如下图所示。

图 1：应变率为 1.0 的直接拉伸试验的应力—应变曲线。

图 2：应变率为 0.1 的直接拉伸试验的应力—应变曲线。

两条曲线均显示出脆性材料的典型响应，杨氏模量约为 29 GPa，两种情况下最大抗拉强度均约为 8 MPa。应变率对结果影响较小：应变率较大时，峰值强度略高，达到峰值时的应变略大，且试验初期的振荡更明显。

方法 2：使用域畸变

通过沿竖直方向扩展域尺寸进行类似试验。用于施加该试验的文件为 tt2.dat，由 doall_A10.dat 调用：

[strain_rate = 1.0]
[tag += '_SR1']

结果与讨论

上述文件展示了一套有效流程，可用于生成黏结颗粒模型，并进行直接拉伸、无侧限压缩和有侧限压缩试验。本例采用软黏结接触模型。上述结果均采用一组禁止软化的参数，所得行为表现为脆性材料，抗压与抗拉强度比约为 4.0，这是线性平行黏结材料通常得到的值，但通常远低于大多数岩石的比值。

通过执行文件 doall_A10_S10_C0.dat 进行第二组试验。此时，通过将软化因子设为 10.0、抗拉强度软化因子设为 0.0 来激活软化。这意味着一旦某接触达到抗拉强度，该接触便进入软化阶段，其软化刚度为加载刚度的 1/10，并且仅在拉力达到 0.0 时断裂。直接拉伸和无侧限压缩试验得到的应力—应变曲线如下所示。

图 8：软化参数为 10 的直接拉伸试验的应力—应变曲线。

图 9：软化参数为 10 的无侧限压缩试验的应力—应变曲线。

在直接拉伸下，应力—应变曲线在达到峰值强度前表现出明显的软化，峰值强度约为 14 MPa（无软化时为 8 MPa）。在压缩下，峰值强度约为 100 MPa，抗压与抗拉强度比约为 7。

通过执行文件 doall_A10_S20_C0_COH1000.dat 进行第三组试验。此时，通过将软化因子设为 20.0、抗拉强度软化因子设为 0.0，并提高黏结黏聚力以禁止剪切破坏，来激活软化。

图 10：软化参数为 20 且不允许剪切破坏的直接拉伸试验的应力—应变曲线。

图 11：软化参数为 20 且不允许剪切破坏的无侧限压缩试验的应力—应变曲线。

采用这些参数后，压缩峰值强度增至约 200 MPa，拉伸峰值强度增至约 17 MPa，抗压与抗拉强度比约为 12.0。

make_brick.dat

; 文件名：make_brick.dat
; 
; 生成各向同性、均质的球集合体，采用周期性
; 边界条件，并在低各向同性围压下稳定 
; 使用伺服控制算法使周期域发生畸变 
;
; ===================================================================

; 设置域范围（长宽比 2:1）与边界条件
model domain extent [-0.5*resolution*davg] [0.5*resolution*davg] ...
                    [-0.5*resolution*davg] [0.5*resolution*davg] ...
                    [-1.0*resolution*davg] [1.0*resolution*davg] ...
                     condition periodic
                     
; 分布球至目标低孔隙率，并设置密度和 
; 局部阻尼属性
[dmin = 2.0*davg / (1.0 + dratio)]
[dmax = dmin * dratio]
ball distribute porosity 0.36 radius [0.5*dmin] [0.5*dmax] 
ball attribute density 2000.0 damp 0.7

; 选择接触模型
contact cmat default model linear ...
                     method deformability emod 1e8 kratio 2.5

; 监测
model history name 'ratio-average' mechanical ratio-average
model history name 'timestep' timestep

; 执行若干初始循环，并定期将 
; 自旋和速度重置为零，以松弛初始重叠，
; 然后求解至平衡 
model cycle 1000 calm 100
model solve ratio-average 5e-3
model save [string.build('brick_%1-pkg',tag)]

; 使用伺服控制算法使集合体在
; 预定的低各向同性应力状态下稳定

; 加载工具函数
program call 'servo.fis' suppress

; 参数定义（供伺服控制函数使用）
[servo_do_z = true     ]  
[servo_ts_xx = -1.0e5  ]
[servo_ts_yy = -1.0e5  ]
[servo_ts_zz = -1.0e5  ]
[servo_gain  =  1.0e-4 ]
[servo_tol = 1e-2]

servo.fis

; 文件名：servo.fis
; 
; 用于定义伺服控制算法的工具函数 
; 通过使周期域畸变来施加目标围压
;
; ===================================================================

fish define servo_domain
  global Lx = domain.max.x() - domain.min.x()
  global Ly = domain.max.y() - domain.min.y()
  global Lz = domain.max.z() - domain.min.z()
  local vol = Lx*Ly*Lz
  local m = measure.find(1)
  local mr = math.sqrt((0.5*Lx)^2+(0.5*Ly)^2+(0.5*Lz)^2)
  local mv = (4.0/3.0)*math.pi*mr^3
  measure.radius(m) = mr
  local stress = measure.stress(m) *mv/vol
  global s_xx = stress(1,1)
  global servo_xdiff = servo_ts_xx - s_xx
  global servo_xrate = servo_gain *servo_xdiff 
  domain.strain.rate.xx = servo_xrate
  global s_yy = stress(2,2)
  global servo_ydiff = servo_ts_yy - s_yy
  global servo_yrate = servo_gain *servo_ydiff 
  domain.strain.rate.yy = servo_yrate
  global s_zz = stress(3,3)
  if servo_do_z then 
    global servo_zdiff = servo_ts_zz - s_zz
    global servo_zrate =  servo_gain * servo_zdiff
  endif
  domain.strain.rate.zz = servo_zrate
end

fish define servo_halt
  servo_halt = false
  local delta = math.max(math.abs(servo_xdiff/servo_ts_xx) ...
               ,math.abs(servo_ydiff/servo_ts_yy))
  if servo_do_z then 
    delta = math.max(math.abs(servo_zdiff/servo_ts_zz),delta)
  endif
  if delta < servo_tol then
    servo_halt = true
    domain.strain.rate.xx = 0.0
    domain.strain.rate.yy = 0.0
    domain.strain.rate.zz = 0.0
  endif
end
; ===================================================================
program return
; 文件结束：servo.fis
