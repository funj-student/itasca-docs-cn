measure history 命令

语法

measure history <id id > keyword id 第二个 ID（id2 ）| v

主要关键字：

配位数（coordination） porosity position-x position-y position-z radius strainrate-xx strainrate-xy xz 向应变率（strainrate-xz） strainrate-yx strainrate-yy yz 向应变率（strainrate-yz） zx 向应变率（strainrate-zx） zy 向应变率（strainrate-zy） zz 向应变率（strainrate-zz） stress-xx stress-xy stress-xz stress-yx stress-yy yz 向应力（stress-yz） zx 向应力（stress-zx） zy 向应力（stress-zy） stress-zz

添加测量历史。历史是可在模型运行期间采样并存储的浮点变量。 紧跟在 history 之后的可选 ID 标识（id） 创建具有指定 ID 的历史。 若未指定，则使用下一个可用的历史 ID。 在下面给出的某个关键字之后，必须给出 1) 位置矢量，或 2) 附加的 id 关键字，以定义特定的测量对象。 有关历史操作的详细信息，请参阅常用的 c 历史（history） 命令。

coordination

测量对象内部的配位数，即每个体的平均接触数。

porosity

测量对象内部的孔隙率。

position-x

测量对象的 x 位置。

position-y

测量对象的 y 位置。

position-z (3D only)

测量对象的 z 位置。

radius

测量对象的半径。

strainrate-xx

测量对象内部应变率的 xx 分量。

strainrate-xy

测量对象内部应变率的 xy 分量。

strainrate-xz (3D only)

测量对象内部应变率的 xz 分量。

strainrate-yx

测量对象内部应变率的 yx 分量。

strainrate-yy

测量对象内部应变率的 yy 分量。

strainrate-yz (3D only)

测量对象内部应变率的 yz 分量。

strainrate-zx (3D only)

测量对象内部应变率的 zx 分量。

strainrate-zy (3D only)

测量对象内部应变率的 zy 分量。

strainrate-zz (3D only)

测量对象内部应变率的 zz 分量。

stress-xx

测量对象内部应力的 xx 分量。

stress-xy

测量对象内部应力的 xy 分量。

stress-xz (3D only)

测量对象内部应力的 xz 分量。

stress-yx

测量对象内部应力的 yx 分量。

stress-yy

测量对象内部应力的 yy 分量。

stress-yz (3D only)

测量对象内部应力的 yz 分量。

stress-zx (3D only)

测量对象内部应力的 zx 分量。

stress-zy (3D only)

测量对象内部应力的 zy 分量。

stress-zz (3D only)

测量对象内部应力的 zz 分量。
