measure delete 命令

语法

measure delete <range>

删除测量对象。默认情况下，删除所有测量对象。 可指定范围以将操作限制于选定对象。

用法示例

以下示例说明如何使用 删除测量对象（measure delete） 命令删除 测量区域。

; 创建 3 个量测区域
measure create radius 0.5
measure create radius 0.5
measure create radius 0.5

; 利用范围删除 ID 为 1 的量测区域
measure delete range id 1
; 删除所有量测区域
measure delete
