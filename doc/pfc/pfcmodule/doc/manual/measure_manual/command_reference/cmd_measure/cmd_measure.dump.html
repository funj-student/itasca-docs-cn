measure dump 命令

语法

measure dump id i keyword

主要关键字：

文件（file） 表格插值取值（table）

导出累积尺寸分布数据。

file s

将信息导出到名为 s 的文件。

警告

此功能尚不可用。

table 表格索引（itab ）

将信息导出到 ID 为 表格索引（itab） 的表。该表将被创建或覆盖（若 已存在）。

用法示例

以下示例说明如何使用 输出累积粒径分布数据（measure dump） 命令将颗粒尺寸分布数据导出到表。

measure create id 1 bins 100 0.0 0.50 rad 4.0
measure dump id 1 table 1
