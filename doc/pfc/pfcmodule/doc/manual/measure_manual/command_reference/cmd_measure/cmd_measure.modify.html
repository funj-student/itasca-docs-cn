measure modify 命令

语法

measure modify keyword ...

主要关键字：

分组数（bins） ID 标识（id） radius x y z 容差（tolerance） position

修改测量区域。必须指定 ID。若不存在具有指定 ID 的测量区域， 则抛出错误。以下关键字适用。若未指定某个属性， 则保留原值。有关以下可修改属性的详细说明，请参阅 创建测量区域（measure create） 命令。

bins i 浮点值下限（fl ）高度系数（fh ）

修改尺寸分布计算的 bin 数量（i）以及最低和最高 bin 边界（浮点值下限（fl） 和 高度系数（fh））。 落在测量区域内的所有体（如刚性簇和球颗粒）按三维（二维）中体积（面积）等效 球（圆）直径进行分 bin。计算体的累积体积百分比（0 到 1 之间）随 bin 尺寸的变化， 并可使用 输出累积粒径分布数据（measure dump） 命令导出到表。 表中保存 bin 边界，某个 bin 的百分比由保存其下边界的表项给出。

id i

指定 ID。

radius f

测量圆（球）的半径。

x f

测量圆（球）中心的 x 坐标。

y f

测量圆（球）中心的 y 坐标。

z f (3D only)

测量圆（球）中心的 z 坐标。

tolerance f

用于在孔隙率计算中累积与测量区域相交的体体积的百分比（范围：p ≥ 0）。

position v

测量圆（球）中心的位置。

用法示例

以下示例说明如何使用 修改测量区域（measure modify） 命令修改 测量区域（例如 ID = 1）。

measure modify id 1 rad 4.0 x 2.0 y 2.0 z 2.0 per 0.0
