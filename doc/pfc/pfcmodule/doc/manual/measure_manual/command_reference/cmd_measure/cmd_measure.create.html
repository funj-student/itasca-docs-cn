measure create 命令

语法

measure create keyword ...

主要关键字：

分组数（bins） ID 标识（id） position radius 容差（tolerance） position-x position-y position-z

创建测量区域。测量区域为{二维中圆盘；三维中球体}。每当调用 clean 命令，或每当调用查询测量值的 FISH 内置函数时，都会触发测量计算（见“测量内置函数（Measure Intrinsics）”）。

bins i 分箱下边界值（fl ）分箱上边界值（fh ）

指定尺寸分布计算的 bin 数量（i）以及最低和最高 bin 边界（分箱下边界值（fl） 和 分箱上边界值（fh））。 落在测量区域内的所有体（如刚性簇和球颗粒）按{二维中面积；三维中体积}等效 {二维中圆；三维中球}直径进行分 bin。计算体的累积体积百分比（0 到 1 之间）， 并可使用 输出累积粒径分布数据（measure dump） 命令导出到表。 表项保存每对 bin 边界的平均值及相应的计算百分比。

id i

测量 ID。若未指定，则赋予下一个可用 ID。

position v

测量对象中心的位置。默认值为全局坐标系原点。

radius f

测量对象的半径。默认值为 1.0。

tolerance f

指定孔隙率计算中累积与测量区域相交的体体积时的相对容差。完全落在测量区域内的体体积 累加为 \(V_s\)；\(V_{\cap}\) 保存与测量区域相交的体体积之和，并创建这些体的列表 intersectList。按体积从大到小的顺序重新访问 intersectList 中的体。 访问 intersectList 中的体时，将该体的体积从 \(V_{\cap}\) 中减去，并将相交体积 加到 \(V_s\) 中。当 \(V_{\cap} / (V - V_s) \leq f\) 时，不再访问相交体。 这保证实际孔隙率与计算值的相对偏差在 f 以内。 对于非零的 f，孔隙率通常会被略微高估。默认情况下，f = 0.01。

对于刚性簇，使用体素化方法计算相交体积。将包围所有子颗粒的{二维中正方形；三维中立方体}轴对齐包围盒递归 二分五次。在每一层，检查每个盒子是否同时包含于刚性簇和测量区域。 保留进一步细化的盒子包括：位于测量区域内且与刚性簇表面相交的盒子、位于刚性簇内且与 测量区域表面相交的盒子，以及与测量区域表面和刚性簇表面均相交的盒子。完全落在刚性簇和测量区域内的盒子体积加到 相交体积总和中。根据体积随每层细化的收敛情况应用修正 （利用当前细化层盒子边长对数与 该层累积体积的关系），以高效、准确地估计相交体积。因此，较低的 百分比值并不意味着相交体积估计更准确， 因为此类计算可能非常耗时。

position-x f

测量对象中心的 x 坐标。默认值为 0.0。

position-y f

测量对象中心的 y 坐标。默认值为 0.0。

position-z f （仅限 3D）

测量对象中心的 z 坐标。默认值为 0.0。

用法示例

以下示例说明如何使用 创建测量区域（measure create） 命令对 测量区域进行操作。

创建用于测量孔隙率、配位数、应力和 应变的测量区域：

measure create radius 4.0 tolerance 0.001

创建用于绘制颗粒尺寸分布曲线的测量区域：

measure create id 1 bins 100 0.0 0.5 radius 4.0
