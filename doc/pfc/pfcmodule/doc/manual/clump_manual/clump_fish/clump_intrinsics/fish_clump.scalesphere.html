clump.scalesphere

语法

b = clump.scalesphere(c,f)

将刚性簇缩放至等效球体。刚性簇缩放后其{二维中面积；三维中体积}与直径为 f 的{二维中圆；三维中球}相同。子颗粒被缩放，其位置被修改，体积被更新。

注意

  • 缩放后刚性簇的所有子颗粒必须落在模型域内，该操作才能成功。
  • 若用户先前已通过 clump attribute 或 FISH（刚性簇体积（clump.vol）、刚性簇实际主惯性矩（clump.moi.prin.real） 或 刚性簇实际惯性矩（clump.moi.real））指定体积或惯性矩，则主惯性矩处于固定状态，不会被缩放。更多细节见 刚性簇惯性矩固定状态（clump.moi.fix） 内置函数。
返回值：

b - 表示操作成功/失败的布尔值
参数：

c - 刚性簇指针

f - {二维中圆；三维中球}的直径
