clump results 命令

语法

clump results keyword ...

主要关键字：

活动（active）    添加属性（add-attribute）    移除属性（remove-attribute）

修改刚性簇结果逻辑的用法。该逻辑可将不同时刻的模型状态精简版本（即刚性簇几何形状加刚性簇属性）输出为二进制文件。刚性簇结果可用于重建模型状态，作为高效后处理的工具（例如生成动画、计算停留时间等）。刚性簇结果文件不能替代 PFC 模型状态文件，使用该逻辑重建的模型不应进行循环计算。请参阅 设置结果文件（model results） 命令，以指定何时创建结果文件以及随后如何导入这些文件。

active b

设置刚性簇结果创建的开关状态。

add-attribute s

将刚性簇属性 s（如 clump attribute 命令中所定义）添加到刚性簇结果中记录。 重建结果时，将填充该属性。可使用 刚性簇列表属性（clump list attribute） 命令列出所有刚性簇属性。 还可使用 group 和 extra 关键字添加刚性簇分组和额外变量。

remove-attribute s

从刚性簇结果中移除要记录的刚性簇属性 s（如 clump attribute 命令中所定义）。 可使用 group 和 extra 关键字移除刚性簇分组和额外变量。
