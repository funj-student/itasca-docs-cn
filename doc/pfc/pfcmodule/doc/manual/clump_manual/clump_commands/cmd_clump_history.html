clump history 命令

语法

clump history <name sid > keyword id ID 标识（id ）| position v

主要关键字：

displacement displacement-x displacement-y displacement-z x 向欧拉角（euler-x） y 向欧拉角（euler-y） z 向欧拉角（euler-z） force-contact force-contact-x force-contact-y 力接触 z（force-contact-z） force-unbalanced force-unbalanced-x force-unbalanced-y 力不平衡 z（force-unbalanced-z） moment-contact 弯矩接触 x（moment-contact-x） 弯矩接触 y（moment-contact-y） 弯矩接触 z（moment-contact-z） moment-unbalanced 弯矩不平衡 x（moment-unbalanced-x） 弯矩不平衡 y（moment-unbalanced-y） 弯矩不平衡 z（moment-unbalanced-z） position-x position-y position-z rotation spin 旋转 x（spin-x） 旋转 y（spin-y） 旋转 z（spin-z） velocity velocity-x velocity-y velocity-z

添加刚性簇值的历史。历史（history） 是通过在模拟期间定期采样模型属性而赋值的浮点值表。有关历史操作的详细信息，请参阅常用的 c 历史（history） 命令。

可使用可选的 name 关键字为历史指定名称以便后续引用；若未指定，则历史将根据其内部分配的 id 编号获得默认名称。

在下面给出的某个关键字之后，必须给出 1) 附加的 id 关键字后跟整数 ID 标识（id），或 2) 附加的 lkwd:\(position\) 关键字后跟位置矢量 v，以定义特定的刚性簇。

displacement

循环计算累积的刚性簇位移矢量的模。

displacement-x

循环计算产生的累积位移的 x 分量。

displacement-y

循环计算产生的累积位移的 y 分量。

displacement-z (3D ONLY)

循环计算产生的累积位移的 z 分量。

euler-x (3D ONLY)

当前刚性簇方位的 x 欧拉角（单位为度）。仅当启用方位追踪后才会更新方位（见 设置方向跟踪（model orientation-tracking） 命令）。参见 clump attribute 命令的 euler 关键字。

euler-y (3D ONLY)

当前刚性簇方位的 y 欧拉角（单位为度）。仅当启用方位追踪后才会更新方位（见 设置方向跟踪（model orientation-tracking） 命令）。参见 clump attribute 命令的 euler 关键字。

euler-z (3D ONLY)

当前刚性簇方位的 z 欧拉角（单位为度）。仅当启用方位追踪后才会更新方位（见 设置方向跟踪（model orientation-tracking） 命令）。参见 clump attribute 命令的 euler 关键字。

force-contact

由接触产生的力的大小。

force-contact-x

接触力的 x 分量。

force-contact-y

接触力的 y 分量。

force-contact-z (3D ONLY)

接触力的 z 分量。

force-unbalanced

不平衡力的大小（施加力、接触力与重力之和）。

force-unbalanced-x

不平衡力的 x 分量。

force-unbalanced-y

不平衡力的 y 分量。

force-unbalanced-z (3D ONLY)

不平衡力的 z 分量。

moment-contact

接触力矩之和的{二维为数值；三维为大小}。

moment-contact-x (3D ONLY)

接触力矩的 x 分量。

moment-contact-y (3D ONLY)

接触力矩的 y 分量。

moment-contact-z (3D ONLY)

接触力矩的 z 分量。

moment-unbalanced

接触力矩与外加力矩之和的{二维值；三维大小}。

moment-unbalanced-x (3D ONLY)

不平衡力矩的 x 分量。

moment-unbalanced-y (3D ONLY)

不平衡力矩的 y 分量。

moment-unbalanced-z (3D ONLY)

不平衡力矩的 z 分量。

position-x

刚性簇形心位置的 x 分量。

position-y

刚性簇形心位置的 y 分量。

position-z (3D ONLY)

刚性簇形心位置的 z 分量。

rotation (2D ONLY)

刚性簇的当前方位。仅当启用方位追踪后才会更新方位（见 设置方向跟踪（model orientation-tracking） 命令）。

spin

刚性簇角速度的{二维为值；三维为模}，单位为弧度/秒。

spin-x （3D 专用）

刚性簇角速度的 x 分量，单位为弧度/秒。

spin-y （3D 专用）

刚性簇角速度的 y 分量，单位为弧度/秒。

spin-z （3D 专用）

刚性簇角速度的 z 分量，单位为弧度/秒。

velocity

刚性簇平动速度矢量的模。

velocity-x

刚性簇速度的 x 分量。

velocity-y

刚性簇速度的 y 分量。

velocity-z

刚性簇速度的 z 分量。
