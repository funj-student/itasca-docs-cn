clump fix 命令

语法

clump fix keyword ... <range>

主要关键字：

spin 旋转 x（spin-x） 旋转 y（spin-y） 旋转 z（spin-z） velocity velocity-x velocity-y velocity-z

固定指定的刚性簇速度。因此，刚性簇在指定方向上的运动保持恒定。

spin

角速度被固定。

spin-x （3D 专用）

固定角速度的 x 分量。

spin-y （3D 专用）

固定角速度的 y 分量。

spin-z （3D 专用）

固定角速度的 z 分量。

velocity

平动速度被固定。

velocity-x

固定平动速度的 x 分量。

velocity-y

固定平动速度的 y 分量。

velocity-z （3D 专用）

固定平动速度的 z 分量。
