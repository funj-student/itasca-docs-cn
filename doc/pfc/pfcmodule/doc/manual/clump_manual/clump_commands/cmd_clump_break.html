clump break 命令

语法

clump break <keyword> <range>

主要关键字：

合并（combine） 惯性容差（inertia-tolerance） pebbles 平面（plane）

将刚性簇拆分为子颗粒。待拆分的子颗粒必须是球体或刚性块体（见 ball clump 和 rblock clump 命令）。子颗粒返回其原来的容器，并保留与其他部件的接触。重新计算子颗粒的惯性性质。使用范围来确定要拆分的刚性簇。没有剩余子颗粒的刚性簇将被删除；仍有子颗粒的刚性簇则重新计算其惯性性质。

combine b

将破碎后的子颗粒合并为新刚性簇。保留与破碎子颗粒的所有接触。默认情况下 combine = 假值（false）。

inertia-tolerance f

指定用于计算剩余或新刚性簇惯性属性的容差。可接受 0.00005 到 1 之间的值（f 默认值为 0.01）。f 值越小，惯性属性估计越精确。

pebbles i ...

按 ID 指定一个或多个要拆分的子颗粒。子颗粒必须是球体或刚性块体。不能与 plane 关键字同时使用。

plane keyword ...

指定使用平面确定要破碎的子颗粒。不能与 pebbles 关键字同时给出。

normal v

指定平面法向。

point v

指定平面上的一点。
