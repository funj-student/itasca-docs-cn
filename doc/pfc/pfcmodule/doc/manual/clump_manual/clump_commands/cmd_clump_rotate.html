clump rotate 命令

语法

clump rotate keyword ... <range>

主要关键字：

轴（axis） 角度（angle） 点（point） 更新方向（update-orientation）

旋转刚性团簇。使用 point 关键字时还可能修改质心位置。旋转遵循右手定则，二维中旋转轴指向观察者。不允许将刚性团簇旋转至其子颗粒形心落在模型域之外。若任一刚性团簇未通过该检查，则所有刚性团簇均不旋转。若方位追踪处于活动状态，默认会更新方位，但可将其禁用（见 update-orientation 关键字）。

axis 轴矢量（vaxis ）

旋转轴。

angle 角度系数（fang ）

旋转角度（度），遵循右手定则。

point 旋转矢量（vrot ）

绕指定点发生旋转。若缺少该关键字，则绕每个刚性团簇的形心旋转。

update-orientation b

显式设置该 rotate 命令的方位更新状态。若启用了方位追踪，则用于更新方位。默认情况下会更新方位。
