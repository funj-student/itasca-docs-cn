ball clump 命令

语法

ball clump keyword <range>

主要关键字：

添加子颗粒（add-pebble） 创建（create）

从范围内的球颗粒创建单个刚性簇，或向现有刚性簇添加一个球颗粒。这些球颗粒会转换为刚性簇的子颗粒，并从球颗粒容器中移除。

add-pebble [modblock]

将范围内的球颗粒添加到现有刚性簇。必须给出 id 关键字，以指定将球颗粒添加到哪个刚性簇。

create [modblock]

从范围内的球颗粒创建刚性簇。

ball clump 关键字块

以下关键字可用于修改所提供的基础值，即 添加子颗粒（add-pebble） 与 创建（create）。

calculate f

此关键字指定：刚性簇的位置、体积和惯性张量将 按密度恒定的假定由子颗粒分布计算。包含 刚性簇的空间被递归细分为{二维中的正方形；三维中的立方体}盒子。 完全位于任一子颗粒内部的全部盒子的{二维中的面积；三维中的体积}与 惯性张量将被累加。累加惯性张量时采用平行轴定理。每次迭代都会外推 “最终”体积，当满足以下任一条件时迭代停止：1）待细分的单元总数达到 1e6，或 2）外推体积与估计体积之差在期望容差之内。 默认情况下，百分比差异 f = 0.01。允许的最小值为 0.00005，用户应注意，将百分比设为如此小的值 可能需要相当大的计算量才能算出这些属性。所计算出的刚性簇 形心将赋给该刚性簇。

density f

刚性簇密度，默认值为 1.0。

group s <slot slot > <pebble> ...

对于新建的刚性簇，槽位 槽位（slot） 处的分组名称设为 s。 可选的 pebble 关键字指定将该分组赋给子颗粒， 而不是赋给刚性簇。 如果未指定 slot，则槽位 默认（Default） 处的分组名称设为 s。

id i

刚性簇 ID。若未指定，则使用下一个可用的 ID。

inertia 有限元 11（fe11 ）有限元 22（fe22 ）有限元 33（fe33 ）有限元 12（fe12 ）有限元 13（fe13 ）有限元 23（fe23 ）（二维中仅 1 个分量 ）

设置刚性簇当前构型下的惯性“张量”。惯性张量的值为 {二维中对应极惯性矩的浮点数；三维中二阶张量}。三维中必须按 e11、e22、e33、e12、e13、e23 的顺序指定 6 个参数，采用行/列约定。还必须指定 体积，且该关键字不能与 calculate 关键字同时给出。

position v

刚性簇位置，默认值为原点。该位置为刚性簇形心的位置。 该关键字不能与 calculate 关键字同时给出。

position-x f

刚性簇形心位置的 x 分量，默认值为 0。此关键字不能与 calculate 关键字同时给出。

position-y f

刚性簇形心位置的 y 分量，默认值为 0。此关键字不能与 calculate 关键字同时给出。

position-z f （仅限 3D）

刚性簇形心位置的 z 分量，默认值为 0。此关键字不能与 calculate 关键字同时给出。

volume f

将{二维中的单位厚度体积；三维中的体积}设为 f。还必须 指定惯性张量，且此关键字不能与 calculate 关键字同时给出。请注意，该参数不影响刚性簇的几何形状； 因此刚性簇的表观几何体积保持不变。该体积（质量即由其 计算）用于求解刚性簇的运动方程。
