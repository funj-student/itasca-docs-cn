ball delete 命令

语法

ball delete <range>

删除球颗粒。若未指定范围，则删除模型中的所有球颗粒。

用法示例

可使用范围元素的任意组合来指定待删除球颗粒的范围。 例如，下面的示例先生成立方体球颗粒集合体，然后删除球颗粒以 形成隧洞交叉口。仅创建该集合体的下半部分。

; 设置模型域
model domain extent -15 15
; 生成球
ball generate radius 0.25 cubic box -10 10 -10 10 -5 0
; 删除盒子内的球
ball delete range ...
              cylinder end-1 -3.0 -16.0 0.0 end-2  -3.0 16.0 0.0 radius 3.0
ball delete range ...
              cylinder end-1  7.0 -16.0 0.0 end-2 -12.0 16.0 0.0 radius 2.0 ...
              position-x -5.0 15
