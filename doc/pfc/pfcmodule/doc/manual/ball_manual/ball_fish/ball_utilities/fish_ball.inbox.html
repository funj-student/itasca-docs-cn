ball.inbox

语法

l = ball.inbox(vl,vu<,b>)

获取其范围与某个盒体相交的球颗粒列表。 范围是指球颗粒的轴对齐包围盒。 指定 b = 假值（false） 表示仅返回位置落在该盒体内的球颗粒。

注意

  • 该函数使用基于单元空间的算法进行高效空间搜索，因此假定球颗粒已正确映射 到单元空间中。在恢复模型之后，或在创建球颗粒之后，必须在使用该函数之前 执行 清理模型对象命令（model clean） 命令。
返回值：

l - 指向球颗粒列表的指针
参数：

矢量长度（vl） - 长方体的下角点

vu - 长方体的上角点

b - 可选的相交判定说明符
