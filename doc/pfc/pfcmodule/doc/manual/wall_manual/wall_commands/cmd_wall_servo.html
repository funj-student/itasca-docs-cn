wall servo 命令

语法

wall servo keyword ... <range>

主要关键字：

activate 力（force） 增益系数（gain-factor） 增益更新（gain-update） 速度最大（velocity-max） force-x force-y force-z

wall servo 能够通过伺服机构控制选定墙的平动速度，以施加或维持所需的作用力。

伺服机构采用带自适应增益的比例控制器，如下所述。

设 \(\mathbf{F}^{t}\) 为目标力（由用户输入），\(\mathbf{F}^{c}\) 为模型中所有碎片对墙施加的反作用力。墙速度 \(\mathbf{v}\) 分解为两个分量：

(1)\[\mathbf{v} = v_n \mathbf{\hat{n}} + \left( \mathbf{v} - v_n \mathbf{\hat{n}} \right)\]

其中 \(v_n\) 为沿方向 \(\mathbf{\hat{n}}\) 的速度有符号大小，

(2)\[v_n = \left( \mathbf{v} \cdot \mathbf{\hat{n}} \right)\]

其中 \(\mathbf{\hat{n}} = \mathbf{F}^{t} / \left\| \mathbf{F}^{t} \right\|\) 为目标力方向上的单位矢量。

\(v_n\) 的值按如下方式调整：

(3)\[v_n = G \left( F^{t} + F^{c} \right)\]

其中 \(G\) 为控制器增益，\(F^{t} = \mathbf{F}^{t} \cdot \mathbf{\hat{n}}\) 和 \(F^{c} = \mathbf{F}^{c} \cdot \mathbf{\hat{n}}\) 分别为目标伺服力和反作用力的有符号大小。

为保证稳定性，增益自动按下式取值：

(4)\[G = \frac{\alpha} {K^{c} \Delta t}\]

其中 \(\alpha\) 为用户可通过 增益系数（gain-factor） 关键字设置的松弛因子（默认 0.8），\(K^{c}\) 为涉及该墙的所有机械接触的等效平动刚度之和，\(\Delta t\) 为当前时步。请注意，用户可通过 增益更新（gain-update） 关键字指定增益更新间隔。

注意

  • 伺服控制仅调整沿目标伺服力方向的速度分量。正交方向的速度不变。
  • 目标荷载以力而非应力的形式表示，因为 PFC 无法判断墙的哪一区域实际上在向颗粒施加载荷。
  • 在建模过程的任意时刻，可使用 墙体伺服激活（wall servo activate） 命令激活或停用选定墙的伺服控制。 若希望墙停止运动，请务必同时将墙速度重置为零（使用 墙体属性速度（wall attribute velocity） 命令）。

适用以下关键字：

activate b

设置伺服控制的活动状态。默认值为 假值（false）。

force v

设置目标力（在全局坐标系中表示）。

gain-factor f

设置增益松弛因子。默认值为 0.8。

gain-update i

设置增益更新间隔。默认值为 1。

velocity-max f

指定最大速度大小。

force-x f

设置目标力的 x 分量（在全局坐标系中表示）。

force-y f

设置目标力的 y 分量（在全局坐标系中表示）。

force-z f (3D ONLY)

设置目标力的 z 分量（在全局坐标系中表示）。

用法示例

“颗粒试样探压（Probing a Granular Specimen）”示例演示了使用 wall servo 命令对颗粒试样进行各向同性或偏应力加载。

以下命令行演示如何使用该命令在剪切盒中进行直剪试验：

model new
model title 'Wall servo example: Shear Box'

model random 10001
model domain extent -0.4 0.4 -0.3 0.3
model large-strain on
contact cmat default model linear method def emod 1e7 krat 2.5 ...
                            prop dp_nratio 0.2

; --- 创建剪切盒上部
wall generate name 'top' box -0.25 0.25  0.0   0.125
wall delete wall range set name 'topBottom'
wall create name 'topExt' vertices -0.3 0.0 -0.25 0.0
wall group 'top' 
; --- 创建剪切盒下部
wall generate name 'bot' box -0.25 0.25 -0.125 0.0 
wall delete wall range set name 'botTop'
wall create name 'botExt' vertices 0.25 0.0 0.3 0.0 
wall group 'bot' range group 'top' not 

; --- 生成球集合体，并在重力下稳定
ball distribute poros 0.17                  ...
                resolution 0.006            ...
                radius 0.8 1.2              ...
                box -0.25 0.25 -0.125 0.125
ball attribute density 2500.0
ball property 'fric' 0.01
model gravity 10.0
model cycle 100 calm 10
model solve ratio-average 1e-3
model mechanical time-total 0.0
model save 'sb-init'

; --- 启用顶部墙的伺服控制以施加目标力
ball attribute displacement 0.0 0.0 damp 0.7
ball property 'fric' 0.5
[m=100.0]              ; mass
[p=m*global.gravity()] ; 力
wall servo force [p] activate on range set name 'topTop'
history id 1 mechanical age 
history id 2 mechanical solve ratio-average
history id 11 wall displacement-x name 'topTop' 
history id 12 wall displacement-y name 'topTop' 
history id 21 wall force-contact-y name 'topTop' 
history id 22 wall force-contact-x name 'botRight' 
history id 23 wall force-contact-y name 'botRight' 
model solve
model save 'sb-load'

; --- 保持顶部墙的伺服控制，同时叠加一个正交速度
history purge
model mechanical time-total 0.0
ball attribute displacement 0.0 0.0 
wall attribute displacement 0.0 0.0 
wall attribute velocity-x 0.001 range group 'top'
model solve time 5.0
model save 'sb-move'
program return

请注意，试验分两个阶段进行。第一阶段，在顶压板上以规定的作用力激活伺服机构。 第二阶段，还为顶压板设置水平速度。由于所规定的速度与 wall servo 命令所用力的方向正交，因此不会被修改。
