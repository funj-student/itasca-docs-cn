wall export 命令

语法

wall export keyword <range>

主要关键字：

几何（geometry）

导出墙。若未指定范围，则导出模型中的所有墙。 目前只能将墙导出到几何集。

geometry keyword
set s

将几何集基本名称设置为 s。若指定 split 关键字，则 每面墙导出到专用几何集，其名称由基本名称后附加单词 墙体（wall） 和墙 ID 组成 （例如，基本名称为 我的集合（myset）、墙 ID 为 1 时，名称为 ‘myset_wall1’）。请注意，此时会覆盖同名的现有几何集。 否则，所有墙导出到一个名为 s 的唯一几何集，且不删除该几何集中的现有几何对象。 默认几何集基本名称为 walls。

split

若指定 split 关键字，则每面墙导出到专用几何集。默认情况下，所有墙 导出到一个唯一几何集（见上文）。

用法示例

wall export 命令可用于将墙的几何形状导出到几何集。几何集随后可直接用于 后处理，或导出为 STL 文件以供第三方 CAD 软件使用。 有关几何逻辑的详细信息见此处（here）。


以下示例创建三面墙，并使用默认参数执行 墙体导出几何（wall export geometry） 命令。 墙被导出到一个标记为 walls 的唯一几何集，如 图 1（Figure 1） 所示。

model domain extent -10 10
wall generate sphere position 0.0 0.0 5.0 radius 2.5
wall generate cone base -2.5 0.0 -5.0 axis 1 1 1 height 2.0 radius 0.1 2.5 ...
                   cap true true  resolution 0.5 one-wall
wall generate disk radius 5.0 dip 45.0 dip-direction 90.0

wall export geometry
geometry export 'walls.stl' format stl

图 1：使用默认参数时，墙体导出几何（wall export geometry） 命令将墙的几何形状导出到一个 标记为 walls 的唯一几何集。

可覆盖默认参数以控制命令的结果。下面的示例构建与上面相同的模型， 但使用 split 关键字将每面墙自动导出到专用几何集。 随后可使用 导出几何对象命令（geometry export） 命令将每个几何集导出为 STL 文件。

model domain extent -10 10
wall generate sphere position 0.0 0.0 5.0 radius 2.5
wall generate cone base -2.5 0.0 -5.0 axis 1 1 1 height 2.0 radius 0.1 2.5 ...
                   cap true true  resolution 0.5 one-wall
wall generate disk radius 5.0 dip 45.0 dip-direction 90.0

wall export geometry split
geometry set 'walls_wall1'
geometry export 'wall1.stl' format stl

图 2：在本例中，使用 split 关键字使每面墙导出到专用几何集。
