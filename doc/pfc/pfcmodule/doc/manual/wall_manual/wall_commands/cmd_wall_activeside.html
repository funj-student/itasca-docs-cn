wall active-sides 命令

语法

wall active-sides keyword <range>

主要关键字：

both bottom neither top

指定面片的哪一侧处于活动状态。非活动侧允许球颗粒或子颗粒穿过而不受排斥。默认情况下，所有面片的两侧均处于活动状态。范围应用于面片。可使用 set range element 按墙筛选。可使用墙箭头图可视化法向矢量，以判断面片法向的方位。

注意

当球颗粒或子颗粒从墙的非活动侧迁移到活动侧时，不会采取措施缓解产生的大作用力。因此，在这些情况下可能出现较大速度。

both

将两侧均设置为活动。

bottom

将与面片法向矢量方向相反的一侧设置为活动。

neither

将两侧均设置为非活动。不会产生任何作用力。

top

将沿面片法向矢量方向的一侧设置为活动。
