修订历史

始终可以在 Itasca 网站上查阅 PFC 的修订历史。请访问页面：PFC 6.0 文档页面（http://www.itascacg.com/ftp_pub/pfc/v600/pfc600.html）（适用于 PFC3D 和 PFC2D）。也可以在程序内部使用菜单命令 Tools —> Check Modifications… 访问此页面。

下文给出每个修订版的详细信息。

当前修订版

修订版本 9

01/18/19

  • 修复使用 FISH 或 Python 设置刚性块体位置或旋转刚性块体时的错误。
  • 更新网络许可，使其支持较旧的 CPU。
  • 修复墙面片的接触解析中的错误。当使用参考间隙，或者球颗粒或子颗粒与面片之间存在明显重叠时，该错误可能会显现。
  • 将三维刚性块体的接触解析改为使用 GJK+EPA 结合直接重叠计算，而非凸包计算。在确定三维接触位置时，该版本效率更高、鲁棒性更强。
  • 确保合并面片时三维 EPA 中的弱序。
  • 新增 CONTACT CMAT PROXIMITY 命令。
  • 弃用 CMAT ADD/DEFAULT/MODIFY 命令中 PROXIMITY 关键字的用法。
  • 升级至 Qt 5.12。
