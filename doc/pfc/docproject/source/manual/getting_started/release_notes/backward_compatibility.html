与 PFC 5.0 的向后兼容性

保存文件在 PFC 5.0 与 PFC 6.0 之间不兼容。保存文件系统已经过改造， 因此在今后任何 PFC 发行版中都不应再出现这种情况。PFC 5.0 的 Subversion 36 提供了 to6 命令，可将保存文件导出为与 PFC 6.0 一致的格式。请注意，FISH 函数 不会被转换，需要在 PFC 6.0 中重新定义。数据文件几乎是兼容的，但语法上已有 若干改进。PFC 6.0 包含一个内置的文件转换工具，可通过 program convert 命令访问。
