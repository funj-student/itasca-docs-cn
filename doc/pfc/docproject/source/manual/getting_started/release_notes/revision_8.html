修订版 8

12/14/18

  • 修复侵蚀刚性块体时的一个缺陷：在极端情况下，由于缺少连通性信息，可能会发生崩溃。
  • 修复三维中刚性块体全接触求解的一个问题，该问题可能导致大型模型的循环计算随时间变慢，并出现内存膨胀。
  • 修复 thermalpipe 接触模型中 ballthermal 属性及其继承的保存/恢复。
  • 侵蚀支持多线程。
  • 修复可能导致刚性块体接触求解错误的 GJK 缺陷。
  • 使所有刚性块体创建工具本地化，并修复切割时出现的一个缺陷。
  • 通过 FISH 创建球颗粒时，检查半径为 0 的情况。
  • 文档更新。
  • 使 HISTORY 系列命令一致使用 POSITION 关键字，并更新文档。
  • 修复含墙面片的接触在恢复时可能出现的缺陷。
  • 改进模型中存在大量被抑制接触时的循环计算性能。
  • 修复刚性块体 BBM 算例，使其采用正确的应力度量，并在隧道算例中使用修正后的数值。
  • 修复从其他窗格激活时编辑器的焦点问题。
  • 修复文档搜索的焦点问题。
  • 修复刚性块体在未与圆角接触时出现重叠的问题。
