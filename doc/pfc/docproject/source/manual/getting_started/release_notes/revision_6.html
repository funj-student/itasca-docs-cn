修订版 6

11/12/18

  • 清理 IRBlock 和 IRBlockModule 的注释。
  • 修复 PROGRAM LIST PRINCIPAL 命令。
  • 创建刚性块体时，新增检查，确保面片具有明确定义的法向。
  • 为 WALL-ZONE CREATE 命令新增 FILL 关键字，以确保创建所有墙面片。
  • 确保侵蚀过程中面片法向始终保持明确定义。
  • 文档更新。
  • 为能量追踪编写 MODEL ENERGY 命令的文档，并修复该命令的转换工具。
  • 修复复杂几何形状下墙面片添加的问题。
  • 更新 extruder 单元质量检查。
  • 当引入退化面片时，使由顶点添加刚性块体的过程更加稳健。
  • 通过引入空间哈希，加快顶点数量较多时的侵蚀计算速度。
  • 若标准版本在三维中失败，则切换 Quickhull 实现。
  • 修复命令转换工具，使其能够处理续行。
