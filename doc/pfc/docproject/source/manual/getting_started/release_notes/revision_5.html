修订版 5

11/02/18

  • 新增刚性块体的 Python 访问接口。
  • 修复了一些阻碍自定义接触模型构建的问题。
  • 修复了一些阻碍创建自定义 C++ FISH 内置函数的问题。
  • 修复了 plotitem modify 缺陷，该缺陷仅影响与 PFC 相关的绘图项。
  • 进行了修改，使模型域范围更新时会清理裂隙。
  • 修复了一个内联帮助的崩溃缺陷。
  • 修复了绘图窗口在成为获得焦点的顶层控件时不刷新的问题。
  • 修复了若干使用 MathJax 无法正确渲染的公式。
  • 文档更新。
  • 新增用于创建 C++ FISH 内置函数和 C++ 接触模型的模板，并附有文档。
