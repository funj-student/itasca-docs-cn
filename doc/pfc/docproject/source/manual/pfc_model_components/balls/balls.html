球颗粒

球颗粒是刚性的 {二维中为单位厚度的圆盘；三维中为球体}。其表面由球体半径（\(R\)）确定。 球颗粒只有一组表面性质。 球颗粒可以平动和转动（由 \(\{\mathbf{v},\mathbf{w}\}\) 确定，即广义速度与角速度或自旋）。 球颗粒的运动服从运动方程。 这要求存在质量性质、加载条件和速度条件。 质量性质为质量、质心位置和惯性张量（\(\{m,\mathbf{x},\mathbf{I}\}\)）。 质量性质由密度（\(\rho\)）和半径确定。 加载条件由以下各项确定：与其他部件相互作用产生的力和力矩； 重力（由 \(\mathbf{g}\) 确定，即重力加速度矢量）； 以及外部施加的力和力矩（由 \(\mathbf{F_A}\) 和 \(\mathbf{M_A}\) 确定）。 速度条件由速度固定标志 \(V_f\) 确定，{二维中为 3 个值；三维中为 6 个值}。

球颗粒通过三种方式插入计算域（参见 设置模型域命令（model domain） 命令）：逐个创建球颗粒（使用 ball create）、 生成互不重叠的球颗粒集合（使用 ball generate）， 或分布相互重叠的球颗粒以匹配指定的粒径分布（使用 ball distribute）。

ball attribute 和 ball property 命令用于指定球颗粒的属性和性质，如“模型组件（Model Components）”一节所述。 使用 球体列表属性（ball list attribute） 和 列出球体属性（ball list property） 命令可以列出完整的属性/性质列表以及特定属性/性质的值。
