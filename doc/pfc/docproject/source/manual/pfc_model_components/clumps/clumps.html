刚性簇

刚性簇是由 \(n\) 个刚性球状子颗粒组成的刚性集合体。其表面由子颗粒的位置和半径定义（\(\{\mathbf{x}^{(i)},R^{(i)}\},i=1,2,\ldots{,n}\)）。刚性簇的表面属性可以针对每个子颗粒分别指定。刚性簇可以平移和旋转（由 \(\{\mathbf{v},\mathbf{w}\}\) 定义，即广义速度和角速度，或称刚性簇质心的自旋）。刚性簇的运动服从运动方程。这要求存在质量属性、加载条件和速度条件。质量属性包括质量、质心位置和惯性张量（\(\{m,\mathbf{x},\mathbf{I}\}\)）。质量属性定义如下。加载条件由以下各项定义：与其他部件相互作用产生的力和力矩；重力（由 \(\mathbf{g}\) 定义，即重力加速度矢量）；以及作用于刚性簇的外部施加力和力矩（由 \(\mathbf{F_A}\) 和 \(\mathbf{M_A}\) 定义）。速度条件由刚性簇的速度固定条件 \(V_f\) 定义，其值为 {2D 时三个值；3D 时六个值}。

质量属性由以下方式定义：（1）参考构型和刚性簇密度（\(\rho\)）；（2）参考构型以及针对该参考构型的 \(\{m,\mathbf{x},\mathbf{I}\}\)；或（3）闭合表面以及由刚性簇密度给出的相关质量属性。在这三种情况下，参考构型都定义了用于接触检测/求解的刚性簇表面，且必须提供该构型。第一种情况下，质量属性由参考构型中子颗粒的位置和尺寸确定，并计及球体重叠。第二种情况下，质量属性由直接指定确定；这样可将质量分布与子颗粒分布分开，使子颗粒仅用于表示表面。第三种情况下，质量属性通过自动计算确定（参见 惯性计算参考页面（http://number-none.com/blow/inertia/index.html）），并假定参考构型与该闭合表面一致。

推荐的刚性簇工作流程是首先定义一组用于代表所需颗粒的刚性簇模板（参见 刚性簇模板创建（clump template create））。可以采用由 {2D 时为线段；3D 时为三角形面片} 构成、且为流形并可定向的闭合几何体形式给出表面描述，用于 1) 生成子颗粒分布，以及 2) 计算质量属性。创建气泡堆积刚性簇模板命令（clump template create bubblepack） 命令用于自动创建子颗粒，以所需保真度表示该表面。表面描述可以是凸的，也可以是凹的。一旦定义了这组刚性簇模板，就可以通过三种方式将刚性簇插入计算域中（参见 设置模型域命令（model domain） 命令）：逐个复制刚性簇（使用 clump replicate）；生成互不重叠的刚性簇集合（使用 clump generate）；或分布相互重叠的刚性簇以匹配指定的尺寸分布（使用 clump distribute）。

或者，也可以使用 clump create 命令创建不引用刚性簇模板的刚性簇。用户既可以直接指定质量属性，也可以使用 计算刚性簇生成命令（clump create calculate） 命令，基于球颗粒分布并采用考虑球体重叠的体素化方法计算实际质量属性。

clump attribute 和 clump property 命令用于指定刚性簇属性和子颗粒特性，具体如“模型组件（Model Components）”一节所述。使用 刚性簇列表属性（clump list attribute） 和 刚性簇列表属性（clump list property） 命令可以列出完整的属性/特性列表以及特定属性/特性的值。
