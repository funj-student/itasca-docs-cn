接触与接触模型

PFC 模型中的颗粒通过广义内力 [1] 在接触处发生相互作用。接触力学体现在采用软接触方法的颗粒相互作用法则中，对于该方法，所有变形都发生在刚体之间的接触处。颗粒相互作用法则称为接触模型（contact models）；每个接触都分配一个接触模型。

接触在循环计算过程中自动创建和删除，如“35.0 - 创建/删除接触（35.0 - Create/delete Contacts）”一节所述。运动学变量 [2] 用于描述体和接触的运动，在“接触求解（Contact Resolution）”一节中定义。这些运动学变量由接触模型用来确定适当的相互作用，并将在各部分接触模型的介绍中被引用。接触模型可以手动分配，也可以通过接触模型分配表（CMAT）（Contact Model Assignment Table (CMAT)）分配。

本节概述接触检测、接触求解和接触模型分配的流程。这些预备性主题是详尽介绍 PFC 接触模型的前奏。最后，命令和 FISH 两节详细说明操作接触与接触模型的机制。

  • 接触识别（Contact Resolution）
  • 接触模型分配表（CMAT）（Contact Model Assignment Table (CMAT)）
  • 接触模型（Contact Models）
  • 命令（Commands）
  • FISH 函数（FISH Functions）

尾注

[1]广义内力由一个力和一个力矩组成，它们在接触位置处以大小相等、方向相反的方式作用于两个部件。由于力施加在接触位置处，还会为每个部件附加一个力矩。模拟表面-表面相互作用的接触模型会更新该力以及这些力矩贡献；然而，模拟远距离相互作用的接触模型则更新该力以及两个内力矩，这两个内力矩无需大小相等、方向相反。
[2]运动学研究物体系统的运动，而不考虑引起该运动的力的作用；动力学则研究力与运动学变量之间的关系。PFC 模型的动力学体现在颗粒相互作用定律中。
