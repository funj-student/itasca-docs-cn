接触模型分配表（CMAT）

接触模型分配表（CMAT）控制新创建接触的接触模型及其关联性质的分配，同时也提供接触创建流程所使用的检测距离。CMAT 由一组有序的槽位（通过 cmat add 命令填充）以及针对每种接触类型的默认槽位（通过 cmat default 命令设置）组成。每个槽位包含一个接触模型及其性质和方法 [1]，每个非默认槽位还包含一个 PFC 范围。每当创建接触时，该接触都会映射到 CMAT 的某个槽位中，并利用该槽位中的信息分配接触模型及其关联的性质和方法。槽位映射过程如下：

  1. 按顺序访问每个非默认槽位，若接触位于该槽位的范围内，则选中该槽位。
  2. 若未选中任何槽位，则选择与接触类型相对应的默认槽位。

CMAT 还可以通过 cmat apply 命令应用于一定范围内的现有接触。CMAT 条目可通过 cmat modify 命令修改，并可通过 cmat remove 命令删除。教程示例“使用 CMAT（Using the CMAT）”演示了使用 CMAT 构建复杂系统的基本用法和高级用法。
