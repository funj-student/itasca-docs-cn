接触模型

本节介绍接触模型的构造（内置接触模型列表见 此处（here））。该描述 采用“符号约定（Notations）”主题和“接触解析（Contact Resolution）”一节中定义的术语与符号，并假定 读者已熟悉这些内容。

所有接触模型描述所共有的框架 在“接触模型框架（Contact Model Framework）”一节中给出。该框架规定了接触模型如何与其所嵌入的 离散元建模框架相互作用。 随后介绍的是 内置接触模型库（built-in contact models library）。每种接触模型的 公式表述描述了接触模型如何利用其属性以及两个接触部件的相对运动来更新广义内力。 使用 C++ 插件选项（C++ Plugin Option） 实现自定义接触模型的能力在 “用户自定义接触模型（User-Defined Contact Models）”中描述。
