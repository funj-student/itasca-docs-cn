墙体

墙是一种流形曲面，由称为面片的{二维中的线段；三维中的三角面片}构成。 曲面由网格定义。墙的表面性质可以针对每个面片独立指定。 墙可以平动和转动（由 \(\{\mathbf{v},\mathbf{w}\}\) 定义，即广义速度与角速度，或墙绕参考点的自旋）。 墙的运动不遵循运动方程。 可以对每个顶点施加平动速度以模拟墙的变形（\(\{\mathbf{v}^{(k)}\}_{k=1,2,\ldots,n}\)——这些值直接指定）。 墙的变形必须保持墙的流形性质。

可以使用 wall create 创建墙，并可逐个添加面片（使用 wall addfacet）。 若先前已存在面片，则面片必须与其保持{二维中的顶点相连；三维中的边相连}。 另一种做法是使用 wall generate 命令生成简单的墙构型（例如箱体、平面、球体、圆柱体、锥体等）。 在三维中，还可以使用几何逻辑从 .stl 或 .dxf 文件导入墙（参见“几何（Geometry）”一节）。

wall attribute 和 wall property 命令用于指定墙的属性和面片的性质，如“模型组件（Model Components）”一节所述。 使用 墙体列表属性（wall list attribute） 和 墙体列表属性（wall list property） 命令可以列出完整的属性/性质列表以及特定属性/性质的值。
