索引：PFC 命令

下面列出了可与 PFC 配合使用的所有命令——包括所有 Itasca 软件通用的那些命令。命令按主命令词的首字母顺序组织，并按来源排序（PFC 命令和通用命令）。

PFC 命令 通用命令  
c 球体（ball） c 砖块（brick） c 模型（model）
c contact c 数据（data） c 绘图（plot）
c 颗粒簇（clump） c 域（domain） c 程序（program）
c rblock c FISH函数（fish） c 项目（project）
c 墙体（wall） c 分组（group） c 表格插值取值（table）
  c 历史（history） c 追踪（trace）
  c 测量（measure）  

注意

程序中大多数操作类任务（而非模型构建类任务）都包含在三个通用主命令词之内：c 程序（program）（call、continue、load、log、quit、return 等）、c 模型（model）（cycle、new、save、restore、solve 等）以及 项目（project）（execute、restore、save 等）。

所有可在 c 程序（program） 组内使用的命令——call, continue, convert, customer-title-1, customer-title-2, directory, echo, echo-line, floating-point-check, list, load, log, log-file, mail, notice, pagination, pause, playback, quit, return, stop, system, threads, undo, warning——都可以在其前面省略“program”一词的情况下使用。因此，program call 和 call 在语法上均有效且等价。
