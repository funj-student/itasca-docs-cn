10.0 - 运动定律

力学运动定律以及热学体属性的更新在 循环点 10.0 进行。本节将介绍力学运动定律。有关热学公式的 细节，请参阅 PFC 热学公式（PFC Thermal Formulation）。

单个刚性颗粒的运动由作用在其上的合力和力矩向量 决定，并可以通过颗粒中某一点的平动运动 以及颗粒的转动运动来描述。质心的运动通过 其位置 \(\mathbf x\)、速度 \(\dot{\mathbf x}\) 和加速度 \(\ddot {\mathbf x}\) 来描述。颗粒的转动运动通过其角速度 \(\pmb \omega\) 和角加速度 \(\dot {\pmb \omega}\) 来描述。

运动方程可以表示为两个向量方程：一个将合力 与平动运动联系起来，另一个将合力矩与转动运动联系起来。

平动运动

平动运动的方程可以写成向量形式

(1)\[\mathbf F=m(\ddot{\mathbf x} - \mathbf g)\qquad\hbox{(translational motion)}\]

式中，\(\mathbf F\) 为合力，即作用在 颗粒上的所有外施力的总和；\(m\) 为颗粒的质量；\(\mathbf g\) 为体力加速度向量 （例如重力荷载）。

球颗粒和刚性团簇的平动运动方程通过二阶 Velocity Verlet 算法 [Verlet1967] 求解。这种积分方法具有二阶精度，经常 用于分子动力学模拟，因为对于保守系统，能量围绕 与系统精确能量相对应的常值振荡。

假设上一循环在时刻 \(t\) 求解了方程 (1)，并且 为当前循环确定的时步为 \(\Delta t\)。半步速度 \(\dot{\mathbf{x}}^{(t+\Delta t/2)}\) 按下式计算

(2)\[\dot{\mathbf{x}}^{(t+\Delta t/2)} = \dot{\mathbf{x}}^{(t)} + \frac{1}{2} \left(\frac{\mathbf{F}^{(t)}}{m}+\mathbf{g}\right) \Delta t\]

时刻 \(t+\Delta t\) 的位置采用半步速度进行更新

(3)\[\mathbf{x}^{(t+\Delta t)} = \mathbf{x}^{(t)} + \dot{\mathbf{x}}^{(t+\Delta t/2)} \Delta t\]

在 力-位移（force displacement） 循环点期间，针对 当前循环更新作用力，从而得到更新后的加速度 \(\ddot{\mathbf{x}}^{(t+\Delta t)}\)。随后 更新速度

(4)\[\dot{\mathbf{x}}^{(t+\Delta t)} = \dot{\mathbf{x}}^{(t+\Delta t/2)} + \frac{1}{2} \left(\frac{\mathbf{F}^{(t+\Delta t)}}{m}+\mathbf{g}\right) \Delta t\]

在 PFC 中，方程 (4) 的最终速度更新发生在 时步确定（timestep determination） 循环点的初始 步骤中，或在完成一系列循环时的收尾阶段中（如 此处（here） 所述）。 因此，如果在循环点 10.0 之后查询球颗粒或刚性团簇的速度，实际查询到的是 半步速度 \(\dot{\mathbf{x}}^{(t+\Delta t/2)}\)。

旋转运动

刚体旋转运动的基本方程为

(5)\[\mathbf L = \mathbf I \pmb \omega \qquad\hbox{(rotational motion)}\]

其中 \(\mathbf L\) 为角动量，\(\mathbf I\) 为惯性张量，\(\pmb \omega\) 为 角速度。对时间求导，即可由方程 (5) 得到 欧拉方程

(6)\[\mathbf M = \dot {\mathbf L} = \mathbf I \dot{\pmb\omega} + \pmb{\omega} \times \mathbf L\]

其中 \(\mathbf M\) 为作用在刚体上的合力矩。该关系式是在固连于刚体质心的局部 坐标系中表述的。

球颗粒与二维刚性团簇的旋转运动

若局部坐标系的取向使其沿物体的 惯性主轴，则方程 (6) 简化为欧拉运动方程：

(7)\[\begin{split}M_1 &= I_1\ \dot\omega_1 + (I_3-I_2)\omega_3\omega_2 \\ M_2 &= I_2\ \dot\omega_2 + (I_1-I_3)\omega_1\omega_3 \\ M_3 &= I_3\ \dot\omega_3 + (I_2-I_1)\omega_2\omega_1 \\\end{split}\]

其中 \(I_1\)、\(I_2\) 和 \(I_3\) 为物体的主转动惯量； \(\dot \omega_1\)、\(\dot \omega_2\) 和 \(\dot \omega_3\) 为绕各主轴的 角加速度；\(\omega_1\)、\(\omega_2\) 和 \(\omega_3\) 为绕各主轴的 角速度；\(M_1\)、\(M_2\) 和 \(M_3\) 为参考主轴坐标系表述的 合力矩分量。

对于半径为 \(R\) 的{二维为圆盘形；三维为球形}物体，其质量均匀 分布于整个体积中，质心与其形心重合。对于轴线始终保持 在面外方向的圆盘形物体，\(\omega_1 = \omega_2 \equiv 0\)，从而可得

(8)\[M_3 = I \dot{\omega_3} = (\frac{1}{2}mR^2)\dot{\omega_3}\]

对于球形物体，任何固连于质心的局部坐标轴系统都是主轴 系统，且三个主转动惯量彼此相等。对于球形物体， 方程 (7) 在整体坐标轴系统中可简化为

(9)\[\mathbf M = \mathbf I \dot{\pmb{\omega}} = (\frac{2}{5}mR^2)\dot{\pmb{\omega}}\]

对于球颗粒（二维和三维）以及二维刚性团簇，旋转运动方程采用上文所述的 Velocity Verlet 算法求解。在不失一般性的前提下采用向量记法，其中 二维时 \(\omega_1 = \omega_2 \equiv 0\)，且惯性张量为对角阵。请注意，对于二维 刚性团簇，极转动惯量可取用户指定的任意值。

首先计算半步角速度

(10)\[{\pmb{\omega}}^{(t+\Delta t/2)} = {\pmb{\omega}}^{(t)} + \frac{1}{2} \left( \frac{\mathbf{M}^{(t)}}{\mathbf I} \right) \Delta t\]

在 力-位移（force displacement） 循环点期间，针对当前循环 更新力矩，从而得到更新后的角加速度 \(\dot{\pmb{\omega}}^{(t+\Delta t)}\)。随后更新角速度

(11)\[{\pmb{\omega}}^{(t+\Delta t)} = {\pmb{\omega}}^{(t+\Delta t/2)} + \frac{1}{2} \left( \frac{\mathbf{M}^{(t+\Delta t)}}{\mathbf I} \right) \Delta t\]

三维刚性团簇的旋转运动

三维刚性团簇在整体坐标系中可能具有完整的惯性张量，因此其 旋转运动方程无法在整体坐标系中简化为欧拉方程（方程 (7)）。在 PFC3D 中，二阶和四阶算法均可用于对刚性团簇的旋转运动进行积分（请参阅 clump order 命令）。 在两种情形下，均存储角动量 \(\mathbf L\)、表示相对主轴系统取向的四元数 \(q_c\) 以及主转动惯量 \(\mathbf J\)。 在详细介绍这些二阶与 四阶格式之前，先介绍四元数的基础知识。

四元数

四元数是四维向量，常用于表示三维旋转和 取向 [Shoemake1985]。与欧拉角表示法相比，四元数不会出现 万向节死锁（即某些构型下自由度的丧失）。四元数 定义如下

(12)\[q = q_0 + q_i i + q_j j + q_k k = q_0 + \mathbf q\]

其中 \(i\)、\(j\) 和 \(k\) 为基元素。\(q_0\) 称为标量部分，\(\mathbf q\) 为 向量部分。基元素之间的乘积由下列恒等式定义

(13)\[\begin{split}\begin{array}{c} i^2 = j^2 = k^2 = ijk = -1 \\ ij = k \\ jk = i \\ ki = j \end{array}\end{split}\]

两个四元数的乘积称为 Hamilton 积，它由分配律 和上述恒等式确定。在标量/向量记法下，该乘积由下式给出

(14)\[q p = p_0 q_0 - \mathbf p \cdot \mathbf q + p_0 \mathbf q + q_0 \mathbf p + \mathbf p \times \mathbf q\]

由于叉积的存在，两个四元数的乘积一般不可交换（\(q p \neq p q\)）。向量 \(\mathbf v\) 与四元数的乘积，可通过构造标量部分为 0 的纯向量四元数（即在标量/向量记法下为 \(v = 0 + \mathbf v\)）并按方程 (14) 的定义执行乘法来实现。四元数的加法与 减法按分量逐一进行。

四元数的共轭定义为

(15)\[q^* = q_0 - \mathbf q\]

而四元数的模长由下式给出

(16)\[\|q\| = q_0^2 + q_i^2 + q_j^2 + q_k^2 = q q^* = q^* q\]

单位四元数（其中 \(\|q\| = 1\)）可转换为纯旋转矩阵。要用单位四元数旋转 向量 \(\mathbf v\)，需构造纯向量四元数 \(v=0+\mathbf v\) （标量部分为 0），并作乘积

(17)\[v' = qvq^*\]

\(v'\) 的向量分量即为旋转后的向量。先进行旋转 \(q\) 再进行 旋转 \(p\) 的连续旋转由四元数乘积 \(p q\) 给出，这意味着只要它们都是单位四元数，任意多次旋转都可以 合成为单个四元数并一次施加。单位四元数的性质有：\(q\) 与 \(-q\) 表示相同的旋转，\(q\) 的逆 旋转为其共轭 \(q^*\)，而零旋转为 \(q = 1\)，此时向量部分为 \(\mathbf 0\)。

二阶解法

[Buss2000] 提出了不同阶次的算法，用于求解上文定义的转动运动方程。 这些算法基于角速度的泰勒级数展开，以便在一个时步内提供 更精确的平均角速度估计值。PFC 实现了 所谓的增广二阶方法。时刻 \(t\) 的角速度通过 重新整理方程 (5) 计算得到

(18)\[\pmb \omega^{(t)} = \mathbf{I}^{(t)-1} \mathbf L^{(t)}\]

请注意，整体坐标系中的惯性张量（或逆惯性张量）可以通过 用刚性团簇朝向 \(q_c\) 旋转主惯性矩来获得

(19)\[\begin{split}\begin{array}{c} \mathbf{I} = q_c \mathbf J q_c^* \\ \mathbf{I}^{-1} = q_c \mathbf J^{(-1)} q_c^* \end{array}\end{split}\]

时刻 \(t\) 的角加速度通过重新整理方程 (6) 并 使用方程 (19) 确定

(20)\[\dot{\pmb \omega}^{(t)} = q_c^{(t)} \mathbf J^{(-1)} q_c^{(t)*} \left(\mathbf M^{(t)}-\mathbf \omega^{(t)} \times \mathbf L^{(t)} \right)\]

而该时步内的平均角速度估计为

(21)\[\bar{\pmb{\omega}} = \pmb \omega^{(t)} + \dot{\pmb \omega}^{(t)} \frac{\Delta t}{2} + \left(\dot{\pmb{\omega}}^{(t)} \times \pmb \omega^{(t)} \right) \frac{\Delta t^2}{12}\]

平均角速度用于更新刚性团簇朝向 \(q_c^{(t + \Delta t)}\)，具体做法是 计算角位移 \(\theta=\bar{\pmb{\omega}}\Delta t\)，将其转换为 单位四元数，并用该单位四元数旋转 \(q_c^{(t)}\)

(22)\[q_c^{(t + \Delta t)} = \left(cos\left(\frac{\theta}{2}\right) + sin\left(\frac{\theta}{2}\right) \frac{\bar{\pmb{\omega}}}{\|\bar{\pmb{\omega}}\|}\right) q_c^{(t)}\]

刚性团簇朝向更新完成后，新的角速度 \(\pmb \omega ^{(t + \Delta t)}\) 由下式给出

(23)\[\pmb \omega ^{(t + \Delta t)} = q_c^{(t+\Delta t)} \mathbf J^{(-1)} q_c^{(t+\Delta t)*} \mathbf L^{(t)}\]

四阶解法

可以证明，四元数的时间导数由下式给出

(24)\[\dot q_c = \frac{1}{2} \omega q_c\]

其中 \(\omega\) 是纯矢量四元数，其矢量分量为 \(\pmb\omega\)（即角 速度）。将方程 (18) 和 (19) 代入 (24) 可得：

(25)\[\dot q_c = \frac{1}{2} \left(q_c \mathbf J^{(-1)} q_c^* \mathbf L \right) q_c\]

将标准四阶 Runge-Kutta 方法应用于上述方程。时刻 \(t + \Delta t\) 的朝向由下式给出

(26)\[q_c^{(t+\Delta t)} = q_c^{(t)} + \frac{\Delta t}{6} \left(k_1+2k_2+2k_3+k_4\right)\]

四元数 \(k_1\) 按下式计算

(27)\[k_1 = \frac{1}{2} \left(q_c^{(t)} \mathbf J^{(-1)} q_c^{(t)*} \mathbf L^{(t)} \right) q_c^{(t)}\]

朝向四元数的一个中间值

(28)\[ {q_{c1}} = q_c^{(t)}+k_1 \frac{\Delta t}{2}\]

用于计算 \(k_2\) 四元数

(29)\[k_2 = \frac{1}{2} \left( {q_{c1}} \mathbf J^{(-1)} {q_{c1}^*} \mathbf L^{(t)} \right) {q_{c1}}\]

朝向四元数的下一个中间值

(30)\[ {q_{c2}} = q_c^{(t)}+k_2 \frac{\Delta t}{2}\]

用于按下式计算 \(k_3\) 四元数

(31)\[k_3 = \frac{1}{2} \left( {q_{c2}} \mathbf J^{(-1)} {q_{c2}^*} \mathbf L^{(t)} \right) {q_{c2}}\]

朝向四元数的最后一个中间值

(32)\[ {q_{c3}} = q_c^{(t)}+k_3 \Delta t\]

用于按下式计算 \(k_4\) 四元数

(33)\[k_4 = \frac{1}{2} \left( {q_{c3}} \mathbf J^{(-1)} {q_{c3}^*} \mathbf L^{(t)} \right) {q_{c3}}\]

刚性团簇朝向更新完成后，使用方程 (23) 将角速度更新至时刻 \(t + \Delta t\)。该 公式与 [Johnson2008] 中给出的公式类似。
