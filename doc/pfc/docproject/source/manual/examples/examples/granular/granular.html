颗粒试样的力学性质探究

注意

本算例的项目文件可在 PFC 中查看或运行。[1]所用的数据文件（data files）列于本算例末尾。

引言

本算例展示如何使用 PFC 研究颗粒试样的力学性质。虽然讨论以 PFC2D 为主，但同样适用于 PFC3D。分别生成无黏聚力的松散和密实球颗粒集合体，并施加不同加载条件，包括各向同性压缩、双轴压缩、简单剪切和纯剪切，以突出其力学行为差异。

试样生成

颗粒试样的组构会显著影响其力学行为，这一点已得到广泛确认。由于试样生成过程决定组构，因此生成符合实际的材料组构十分重要。本算例采用一种简单流程，创建接触连接良好且具有各向同性的试样。用于生成材料的主数据文件为“MakeSpecimen.dat”，下面讨论其中部分代码行。

该文件的开头几行调用另外两个文件，以载入若干实用函数。这两个文件将在后续各节中介绍。

program call 'StrainUtilities.p2fis' suppress  
program call 'StressUtilities.p2fis' suppress

以下两行用于设置 模型计算域范围命令（model domain extent） 以及 接触模型分配表（CMAT）（Contact Model Assignment Table (CMAT)） 的默认槽位：

model domain extent -0.1 0.1 
contact cmat default model linear method deformability emod 1.0e8 kratio 2.5

在 PFC 中需要执行这两步：1) 在创建任何模型组件之前必须先定义域； 2) 必须定义模型对象之间如何相互作用，因为默认情况下 空接触模型（null contact model） 会被分配给接触。改变接触分配行为的一种方式是适当地填充 CMAT 的默认槽位。在本例中，空接触模型被替换为 线性接触模型（linear contact model）。此外，还指定了 变形方法参数（deformability method parameters） 以设置接触模型刚度。请注意，在此阶段未指定接触摩擦系数，其默认值为零。

使用 墙体生成盒（wall generate box） 命令生成一个方形盒子，即材料容器。该盒子由四面墙组成，这些墙被扩展以便为后续运动作好准备。为方便起见，创建了四个保存墙指针的全局 FISH 变量。

wall generate name 'vessel' box -0.035 0.035 expand 1.5
[wp_left  = wall.find('vesselLeft')]
[wp_right = wall.find('vesselRight')]
[wp_bot   = wall.find('vesselBottom')]
[wp_top   = wall.find('vesselTop')]

此外还创建了两个实用 FISH 函数。这些函数用于计算容器的尺寸。

fish define wlx
  wlx  = wall.pos.x(wp_right) - wall.pos.x(wp_left)
end
fish define wly
  wly  = wall.pos.y(wp_top)   - wall.pos.y(wp_bot)
end

在盒子内分布球颗粒以达到 0.2 的目标孔隙率（见 ball distribute 命令）。球颗粒的密度和局部阻尼属性通过 ball attribute 命令设置。

ball distribute 命令允许在指定体积内以目标孔隙率创建球颗粒，且假定球颗粒之间不发生重叠。系统平衡后将得到不同的孔隙率，其大小取决于球颗粒的重叠量。一般而言，这一差异可能很小。请注意使用 设置随机数种子命令（model random） 命令，以确保模型多次运行时创建出相同的球颗粒分布。只要开启确定性模式（默认设置——更多细节请参阅 设置确定性模式命令（model deterministic） 命令），整个模拟集的最终结果也将完全相同。

model random 10001
ball distribute porosity 0.2 radius 0.0006 0.0009 box -0.035 0.035

我们希望球颗粒-球颗粒接触与球颗粒-面片接触具有不同的摩擦系数。可以使用 CMAT 为球颗粒-球颗粒接触与球颗粒-面片接触指定该属性，也可以使用接触属性的 继承（inheritance） 机制来获得相同的结果。本算例采用后一种方法，直接指定 fric 属性——对球颗粒使用 ball property 命令，对墙面片使用 wall property 命令。

ball property 'fric' [ballFriction]
wall property 'fric' [wallFriction]

尽管 ball distribute 命令可确保球颗粒完全落在指定的生成盒内，但由于球颗粒之间可能存在较大重叠，它们仍有可能逸出；因而可能产生较大的速度。为防止这种情况发生，使用 执行计算时步（model cycle） 命令执行若干循环。使用 calm 关键字定期将球颗粒的速度（平动和转动）置零，从而从系统中移除动能。可用类似方式使用 清零模型速度命令（model calm） 命令将球颗粒和刚性簇的平动与转动速度置零。该命令在集合体用 求解模型（model solve） 命令循环至平衡后调用。

model cycle 1000 calm 10
model solve ratio-average 1e-5
model calm

最后，调用两个 FISH 函数。第一个函数在该文件本身中定义；它识别没有活动接触的球颗粒，并将它们归入名为 floaters 的分组。第二个是 FISH 函数，它定义在“StrainUtilities.p2fis”中，用于识别将在后续模拟中测量应变的应变计球。

fish define identify_floaters
  loop foreach local ball ball.list
    ball.group.remove(ball,'floaters')
    local contactmap = ball.contactmap(ball)
    local size = map.size(contactmap)
    if size <= 1 then
      ball.group(ball) = 'floaters'
    endif
  endloop
end
[identify_floaters]
[ini_gstrain(wly)]

应力与应变测量工具

测量应力

下面讨论在颗粒集合体中测量应力的几种不同方法。相应的 FISH 函数定义在文件“StressUtilities.p2fis”中。请注意，在 PFC2D 中，计算应力时假定球颗粒为具有单位厚度的圆盘。

第一种方法是利用试样施加在容器壁上的反作用力。下面两个函数对相对两壁上的反作用力求平均，再除以各方向上壁面的代表面积，从而返回水平应力和竖直应力：

fish define wsxx
    global wp_left, wp_right, wly
    wsxx = 0.5*(wall.force.contact.x(wp_left) - ...
           wall.force.contact.x(wp_right))/ wly 
end

fish define wsyy
    global wp_bot, wp_top, wlx
    wsyy = 0.5*(wall.force.contact.y(wp_bot) -  ...
           wall.force.contact.y(wp_top)  )/ wlx
end

或者，也可以在模型内创建测量区域（Measurement regions）（使用 创建测量区域（measure create） 命令），并用其计算位于测量区域内或与测量区域相交的接触上的平均应力（详情请参阅此处（here））。

相同的计算定义在“StressUtilities.p2fis”文件中（compute_spherestress 函数），可对 measure 逻辑计算的结果进行验证。

fish define compute_spherestress(rad)
  command
    contact group 'insphere' remove
    contact group 'insphere' range circle radius [rad]
  endcommand
  global ssxx = 0.0
  global ssxy = 0.0
  global ssyx = 0.0
  global ssyy = 0.0
  loop foreach contact contact.groupmap("insphere","ball-ball")
    local cf = contact.force.global(contact)
    local cl = ball.pos(contact.end2(contact)) - ...
               ball.pos(contact.end1(contact))
    ssxx = ssxx + comp.x(cf) *comp.x(cl)
    ssxy = ssxy + comp.x(cf) *comp.y(cl)
    ssyx = ssyx + comp.y(cf) *comp.x(cl)
    ssyy = ssyy + comp.y(cf) *comp.y(cl)
  endloop
  local vol = (math.pi*rad^2)
  ssxx = - ssxx / vol
  ssxy = - ssxy / vol
  ssyx = - ssyx / vol
  ssyy = - ssyy / vol
end

该计算可以针对不同的探测体积进行（该体积相对于颗粒尺寸要足够大）。例如，compute_averagestress 函数（位于“StressUtilities.p2fis”中）计算整个容器体积上的平均应力。

fish define compute_averagestress
  global asxx = 0.0
  global asxy = 0.0
  global asyx = 0.0
  global asyy = 0.0
  loop foreach local contact contact.list("ball-ball")
    local cforce =  contact.force.global(contact)
    local cl = ball.pos(contact.end2(contact)) - ...
               ball.pos(contact.end1(contact))
    asxx = asxx + comp.x(cforce)*comp.x(cl)
    asxy = asxy + comp.x(cforce)*comp.y(cl)
    asyx = asyx + comp.y(cforce)*comp.x(cl)
    asyy = asyy + comp.y(cforce)*comp.y(cl)
  endloop
  asxx = - asxx / (wlx*wly)
  asxy = - asxy / (wlx*wly)
  asyx = - asyx / (wlx*wly)
  asyy = - asyy / (wlx*wly)
end

测量应变

与应力类似，应变也可以用多种方法评估。下面讨论几种方法，相应的 FISH 函数可在“StrainUtilities.p2fis”中找到。

宏观轴向应变和侧向应变也可以由边界墙的相对位移计算得到：

(1)\[\epsilon_{ii} = \frac{L_{ii} - L_{ii}^{(0)}}{L_{ii}^{(0)}}\]

其中 \(L_{ii}^{(0)}\) 和 \(L_{ii}\) 分别为试样在 \(i\) 方向上的初始长度与当前长度。

测量（Measure） 逻辑可用于评估给定步时在某一测量区域上的应变率。因此，可将计算得到的应变率乘以当前时步，从而在每次迭代中累积应变增量。由于需要在每个循环中计算应变率并累积应变增量，这一操作的计算量可能很大。

fish define ini_mstrain(sid)
  command
    ball attribute displacement multiply 0.0
  endcommand
  global mstrains = matrix(2,2)
  global mp = measure.find(sid)
end

fish define accumulate_mstrain
  global msrate =  measure.strain.rate(mp)
  global mstrains = mstrains + msrate * global.timestep
  global xxmstrain = mstrains(1,1)
  global xymstrain = mstrains(1,2)
  global yxmstrain = mstrains(2,1)
  global yymstrain = mstrains(2,2)
end

评估应变的另一种方法依赖于测量标距颗粒之间的相对位移。该方法的优点是可同时测量轴向应变和切向应变，但缺点在于受系统离散性质的影响。函数 初始化总应变（ini_gstrain）（位于“StrainUtilities.p2fis”中）可用于为应变测量布置标距颗粒。沿 y 轴使用 最近球体（ball.near） FISH 工具函数识别出四个等间距的标距颗粒，并赋予分组标识 gauge_balls。记录它们的初始相对位置，即可计算任意时刻的应变，如用于计算切向应变的 xy 向总应变（xygstrain） 函数所示。

fish define ini_gstrain(ly)
  local pos = vector(0.0,-0.5*ly)*0.75
  global gb1 = ball.near(pos)
  ball.group(gb1) = 'gauge_balls'
  pos = vector( 0.0,-0.5*ly)*0.25
  global gb2 = ball.near(pos)
  ball.group(gb2) = 'gauge_balls'
  pos = vector( 0.0, 0.5*ly)*0.25
  global gb3 = ball.near(pos)
  ball.group(gb3) = 'gauge_balls'
  pos = vector(0.0, 0.5*ly)*0.75
  global gb4 = ball.near(pos)
  ball.group(gb4) = 'gauge_balls'
  global gl12_0  = ball.pos(gb2) - ball.pos(gb1)
  global gl13_0  = ball.pos(gb3) - ball.pos(gb1)
  global gl14_0  = ball.pos(gb4) - ball.pos(gb1)
end

fish define xygstrain
  local gl12 = ball.pos(gb2) - ball.pos(gb1)
  global xygstrain12 = (comp.x(gl12) - comp.x(gl12_0))/ comp.y(gl12_0) 
  local gl13 = ball.pos(gb3) - ball.pos(gb1)
  global xygstrain13 =  (comp.x(gl13) - comp.x(gl13_0))/ comp.y(gl13_0) 
  local gl14 = ball.pos(gb4) - ball.pos(gb1)
  global xygstrain14 =  (comp.x(gl14) - comp.x(gl14_0))/ comp.y(gl14_0) 
  xygstrain = (xygstrain12 + xygstrain13 + xygstrain14) /3.0
end

双轴试验

前几节讨论的工具被组合起来以执行一个简单的双轴试验。双轴试验分两个阶段进行：先是一个各向同性固结阶段，在该阶段中试样在指定的围压下达到平衡；随后是在恒定侧向应力下沿竖直方向进行双轴压缩。

在固结阶段，试样以应变控制的方式加载，但容器边界墙的速度通过伺服控制机制进行调整，从而获得目标围压。

在双轴压缩阶段，对作为加载压板、以恒定速度运动的顶墙和底墙停用伺服控制，而左墙和右墙的伺服控制保持激活，以维持围压。试样所经受的应力和应变通过计算相对墙上的作用应力与相对位移，以宏观方式确定。历史（History） 逻辑用于监测系统的演化。

伺服控制机制

wall servo 命令用于设置每面墙的伺服控制的活动状态和参数。

[txx = -5.0e5]
[tyy = -5.0e5]
wall servo activate on force-x [ txx*wly] ...
                       velocity-max 0.1 range set name 'vesselRight'
wall servo activate on force-x [-txx*wly] ...
                       velocity-max 0.1 range set name 'vesselLeft'
wall servo activate on force-y [ tyy*wlx] ...
                       velocity-max 0.1 range set name 'vesselTop'
wall servo activate on force-y [-tyy*wlx] ...
                       velocity-max 0.1 range set name 'vesselBottom'

请注意，该命令确实以力而非应力作为输入参数。原因在于墙的“活动”面积取决于模型，而 PFC 没有可用于评估该面积的信息。例如，在本模型中，容器墙最初被扩展以容纳试验过程中的运动，墙的“活动”部分对应于容器尺寸 局部 x 权重（wlx） 和 局部 y 权重（wly）。因此，要施加目标应力，作为 wall servo 命令输入的力必须随试验过程中 局部 x 权重（wlx） 和 局部 y 权重（wly） 的变化而调整。这是通过使用 设置FISH回调命令（fish callback） 命令在循环序列中注册函数来实现的（关于回调函数的详细讨论请参阅 本教程（this tutorial））。

fish define servo_walls
  wall.servo.force.x(wp_right) =   txx*wly
  wall.servo.force.x(wp_left)  =  -txx*wly
  wall.servo.force.y(wp_top)   =   tyy*wlx
  wall.servo.force.y(wp_bot)   =  -tyy*wlx
end
fish callback add servo_walls  9.0

各向同性固结阶段

调用文件“CompactSpecimen.dat”来执行该阶段。先计算容器的初始尺寸，并定义施加于颗粒试样的各向同性应力。竖直墙和水平墙均发生移动，以逐步施加所需的应力。函数 伺服墙体（servo_walls） 被注册为在每个循环中求解运动方程之前执行。模拟过程中使用 历史（History） 逻辑记录水平应力和竖直应力。开启方向追踪（见 设置方向跟踪（model orientation-tracking） 命令），以便跟踪和可视化球颗粒的方位。

模型循环计算，直至基于墙测量的水平应力和竖直应力接近指定应力（在用户定义的容差内），且平均不平衡力比 ratio-average 小于或等于 1e-6（见 模型求解比平均（model solve ratio-average） 命令）。这一复杂的停止判据定义在函数 停止标志（stop_me） 中，该函数在每个循环结束时执行。它通过 模型求解 FISH 停止命令（model solve fish-halt） 命令注册为求解限制。下面给出了就位阶段各方向的应力状态。

[tol =  5e-3]
fish define stop_me
  if math.abs((wsyy - tyy)/tyy) > tol
    exit
  endif
  if math.abs((wsxx - txx)/txx) > tol
    exit
  endif
  if mech.solve("ratio-average") > 1e-6
    exit
  endif
  stop_me = 1
end

偏应力加载阶段

调用文件“BiaxialTest.dat”来执行该阶段。

修改球-球接触和球-面片接触的摩擦系数，这些摩擦系数是在前几个阶段为获得试样所需孔隙率而设置的。

ball property 'fric' [ballFriction]
wall property 'fric' [wallFriction]

平衡后的系统即可进行双轴试验。对顶墙和底墙设置大小相等、方向相反的恒定速度，执行应变控制的压缩试验。侧墙的速度通过前文所述的伺服控制机制更新，以维持适当的围压。

[rate = 0.2]
wall servo activate off range set name 'vesselTop' ...
                              set name 'vesselBottom' union 
wall attribute velocity-y [-rate*wly] range set name 'vesselTop'
wall attribute velocity-y [ rate*wly] range set name 'vesselBottom'

计算容器的初始尺寸，并将应变变量（轴向应变、侧向应变和体积应变）设为零。这些值将在模拟过程中根据相应墙之间的相对距离更新，并使用 历史（History） 逻辑记录。

[ly0 = wly]
[lx0 = wlx]
[wexx = 0.0]
[weyy = 0.0]
[wevol = 0.0]

fish define wexx
  wexx  = (wlx - lx0) / lx0 
end

fish define weyy
  weyy = (wly - ly0) / ly0
end

fish define wevol
  wevol = wexx + weyy
end

fish history name '51' wexx
fish history name '52' weyy
fish history name '53' wevol
history purge

系统被加载至 7.5% 的竖向应变（参见 target 变量及其在 停止标志（stop_me） 函数中的用法）。

[stop_me = 0]
[target = 0.075]
fish define stop_me
  if weyy <= -target then
    stop_me = 1
  endif
end

密实试样与松散试样的双轴试验

为评估松散试样与密实试样之间的差异，分别对二者进行双轴试验。为生成松散或密实的颗粒堆积，调整了球-球接触处摩擦系数的相应取值。数据文件“Doall.dat”包含以下命令：制备松散试样、在指定围压下对其进行压实，最后执行双轴压缩。

model new

[wallFriction = 0.0    ]

program call 'MakeSpecimen'
model save ['specimen'+filename]
program call 'CompactSpecimen'

program call 'BiaxialTest'

model new

program call 'BiaxialTest'

为获得松散试样，球-球接触采用 0.3 的摩擦系数。该值在整个模拟过程中保持不变（试样制备、各向同性压实、双轴压缩）。墙摩擦系数设为零，使球-面片接触中不会产生剪力。采用无摩擦的墙可减小制备阶段和压缩阶段的边界效应。

为制备密实试样，球-球接触处的摩擦系数初始设为零。在制备阶段和压实阶段之后、双轴压缩之前，再将球-球接触的摩擦系数设为所需值 0.3。

在固结阶段结束时测得，松散试样与密实试样的孔隙率分别为 \(n\) = 0.187 和 \(n\) = 0.151。

弹性参数的计算

材料的弹性性质可通过在弹性条件下进行加载/卸载试验并测量杨氏模量和泊松比来确定。该过程在文件“LoadUnload.dat”中实现。图 5（Figures 5） 和 图 6 给出了密实试样的轴向偏应力与体积应变随轴向应变变化的曲线。由这些图可得，杨氏模量为

(2)\[E = \frac{\Delta \sigma_a}{\Delta \varepsilon_a} \simeq 70 \mbox{MPa}\]

而泊松比为

(3)\[\nu = \frac{\Delta \varepsilon_r}{\Delta \varepsilon_a} \simeq 0.2\]

剪切模量可用下式估算：

(4)\[G = \frac{E}{2(1+\nu)} \simeq 30 \mbox{MPa}\]

简单剪切试验与纯剪切试验

本节介绍对压实试样进行剪切试验的准备工作。剪切模拟采用密实试样。共执行了简单剪切试验和纯剪切试验（见 图 7（Figures 7） 和 图 8）。

简单剪切（图 7（Figure 7））是一种特殊的变形情形，其中速度向量只有一个分量取非零值。在固体力学中，它被定义为等体积的平面变形：在该变形过程中，存在一组具有给定参考方位的线元，其长度和方位保持不变。此情形下，剪应变定义为

(5)\[\gamma_{xy} = \frac{\Delta x}{L_y}\]

其中 \(L_y\) 表示沿 y 方向的长度。

图 7：简单剪切试验的边界条件。

纯剪切（图 8（Figure 8））是无旋应变的一个示例：物体在一个方向上被拉长，同时在垂直方向上被缩短。纯剪应力 \(\tau\) 与纯剪应变 \(\gamma\) 之间的关系由下式给出：

(6)\[\tau = \gamma G\]

其中 \(G\) 为剪切模量。在这些条件下，剪应变可按下式计算：

(7)\[\gamma_{xy} = \frac{\Delta x}{L_y} + \frac{\Delta y}{L_x}\]

图 8：纯剪切试验的边界条件。

通过在循环序列中注册函数 循环剪切（cyclic_shear） 来执行加载/卸载循环。

[load = 1]
[rate = 0.001]
[xfactor = 0.0]
[yfactor = 0.0]
fish define cyclic_shear
  wall.vel.x(wp_left)  =        xfactor*rate ; 左墙
  wall.vel.x(wp_right) = -1.0 * xfactor*rate ; 右墙
  wall.vel.y(wp_top)   = -1.0 * yfactor*rate ; 顶墙
  wall.vel.y(wp_bot)   =        yfactor*rate ; 底墙
  if defxy < 0.0005
    if load = 1
      xfactor = 1.0
      yfactor = -2.0
      exit
    else
      if defxy < -0.0005
        load = 1
        exit
      endif
      exit
    endif
  else
    xfactor = -1.0
    yfactor = 2.0
    load = 0
  endif
end

fish callback add shear_strain_stress 2.0 
fish callback add cyclic_shear        3.0

; excerpt-rxlr-start
fish define wsxx
    global wp_left, wp_right, wly
    wsxx = 0.5*(wall.force.contact.x(wp_left) - ...
           wall.force.contact.x(wp_right))/ wly 
end

fish define wsyy
    global wp_bot, wp_top, wlx
    wsyy = 0.5*(wall.force.contact.y(wp_bot) -  ...
           wall.force.contact.y(wp_top)  )/ wlx
end
; excerpt-rxlr-end

; excerpt-xmps-start
fish define compute_averagestress
  global asxx = 0.0
  global asxy = 0.0
  global asyx = 0.0
  global asyy = 0.0
  loop foreach local contact contact.list("ball-ball")
    local cforce =  contact.force.global(contact)
    local cl = ball.pos(contact.end2(contact)) - ...
               ball.pos(contact.end1(contact))
    asxx = asxx + comp.x(cforce)*comp.x(cl)
    asxy = asxy + comp.x(cforce)*comp.y(cl)
    asyx = asyx + comp.y(cforce)*comp.x(cl)
    asyy = asyy + comp.y(cforce)*comp.y(cl)
  endloop
  asxx = - asxx / (wlx*wly)
  asxy = - asxy / (wlx*wly)
  asyx = - asyx / (wlx*wly)
  asyy = - asyy / (wlx*wly)
end
; excerpt-xmps-end

; excerpt-womr-start
fish define compute_spherestress(rad)
  command
    contact group 'insphere' remove
    contact group 'insphere' range circle radius [rad]
  endcommand
  global ssxx = 0.0
  global ssxy = 0.0
  global ssyx = 0.0
  global ssyy = 0.0
  loop foreach contact contact.groupmap("insphere","ball-ball")
    local cf = contact.force.global(contact)
    local cl = ball.pos(contact.end2(contact)) - ...
               ball.pos(contact.end1(contact))
    ssxx = ssxx + comp.x(cf) *comp.x(cl)
    ssxy = ssxy + comp.x(cf) *comp.y(cl)
    ssyx = ssyx + comp.y(cf) *comp.x(cl)
    ssyy = ssyy + comp.y(cf) *comp.y(cl)
  endloop
  local vol = (math.pi*rad^2)
  ssxx = - ssxx / vol
  ssxy = - ssxy / vol
  ssyx = - ssyx / vol
  ssyy = - ssyy / vol
end
; excerpt-womr-end

PureShear.dat

model large-strain on
; excerpt-ttnr-start
wall servo activate off
fish callback remove servo_walls 1.0 

;定义球与墙的摩擦参数
ball property 'fric' [ballFriction]
wall property 'fric' [wallFriction]

[ly0 = wly]
[lx0 = wlx]

[defxy = 0]
[tauxy = 0]
fish define shear_strain_stress
  x_strain = (wlx-lx0)
  y_strain = (wly-ly0)
  defxy = x_strain/ly0 + y_strain/lx0
  tauxy = (wsxx-wsyy)/2
end
; excerpt-ttnr-end

; excerpt-ioxx-start
[load = 1]
[rate = 0.001]
[xfactor = 0.0]
[yfactor = 0.0]
fish define cyclic_shear
  wall.vel.x(wp_left)  =        xfactor*rate ; 左墙
  wall.vel.x(wp_right) = -1.0 * xfactor*rate ; 右墙
  wall.vel.y(wp_top)   = -1.0 * yfactor*rate ; 顶墙
  wall.vel.y(wp_bot)   =        yfactor*rate ; 底墙
  if defxy < 0.0005
    if load = 1
      xfactor = 1.0
      yfactor = -2.0
      exit
    else
      if defxy < -0.0005
        load = 1
        exit
      endif
      exit
    endif
  else
    xfactor = -1.0
    yfactor = 2.0
    load = 0
  endif
end
; excerpt-ioxx-end

fish history name '51' tauxy
fish history name '61' defxy

; excerpt-nnvv-start
fish callback add shear_strain_stress 2.0 
fish callback add cyclic_shear        3.0 
; excerpt-nnvv-end

model orientation-tracking on
model solve time 0.2
