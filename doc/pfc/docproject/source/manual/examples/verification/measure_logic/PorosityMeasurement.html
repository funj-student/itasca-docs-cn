Measure 逻辑

问题描述

注意

本算例的项目文件可在 PFC 中查看或运行。[1]所用的数据文件（data files）列于本算例末尾。

测量逻辑（参见 创建测量区域（measure create） 命令）借助 PFC 加以运行，以计算孔隙率。生成了两个由按类晶体模式排列的单一粒径球颗粒构成的规则堆积，以及一个多分散堆积。孔隙率采用半径不同的测量圆（在 3D 中为测量球）计算。数值结果的精度通过与解析值进行比较来评估。

闭式解

考虑两种类晶体堆积。这两种堆积均由相互接触且无重叠的等半径球颗粒组成。第一种堆积为简单立方排列（2D 视图见 图 1（Fig. 1）），其中每个球颗粒在 2D 中与四个相邻球颗粒接触（在 3D 中为六个）。第二种堆积为六边形排列（见 图 2（Fig. 2）），其中每个球颗粒在 2D 中与六个相邻球颗粒接触（在 3D 中为十二个）。在所有可能的规则二维或三维堆积中，六边形排列是最密实的一种。对于这两种堆积，只要堆积延伸到足够大的区域以致边界的影响可以忽略，孔隙率就与球颗粒的尺寸无关（二维和三维堆积的详尽讨论请参阅 [Deresiewicz1958a]）。

堆积的密度 \(D\) 定义为固体物质所占面积 \(A_s\) 与总面积 \(A\) 之比。若假定总面积由固体面积与孔隙面积两部分组成，且不存在重叠，则密度与孔隙率 \(n\) 之间存在以下关系：

\[n = 1 - D = 1 - \frac{A_s}{A}\]

对于简单立方堆积，在二维情况下有：

(1)\[n = 1 - \frac{\pi R^2}{(2R)^2}=1-\frac{\pi}{4} \approx 0.2146\]

在三维情况下则为：

(2)\[n = 1 - \frac{4/3 \pi R^3}{(2R)^3}=1-\frac{\pi}{6} \approx 0.4764\]

对于六边形堆积，在二维情况下有：

(3)\[n = 1 - \frac{\pi R^2}{(\sqrt{3}R)(2R)}=1-\frac{\pi}{2 \sqrt{3}} \approx 0.0931\]

在三维情况下则为：

(4)\[n = 1 - \frac{8 \pi R^3}{(6\sqrt{3}R^2)(4R\sqrt{2/3})}=1-\frac{\pi}{3 \sqrt{2}} \approx 0.2595\]

对于多分散集合体，采用专门的流程计算孔隙率（参见 get_poros 函数，其定义见 “PolydisperseAssembly.dat（二维）（PolydisperseAssembly.dat (2D)）” 与 “PolydisperseAssembly.dat（三维）（PolydisperseAssembly.dat (3D)）”），该流程利用模型中各球颗粒表面积（在 3D 中为体积）之和与试样总表面积（在 3D 中为体积）之比进行计算。

(5)\[n = 1-\frac{S_{balls}}{S} \quad (2D) \quad \quad n = 1-\frac{V_{balls}}{V} \quad (3D)\]

数值模型

使用若干参数化的 FISH 函数生成用于计算各堆积孔隙率的测量圆（在 3D 中为测量球）。

这些函数定义在 {2D 为 “MeasureLogic.dat（二维）（MeasureLogic.dat (2D)）”；3D 为 “MeasureLogic.dat（三维）（MeasureLogic.dat (3D)）”} 中。

define_meas_parameters 函数接受两个参数：测量数量（nmeas），用户可通过它定义在堆积内创建的测量区域数目；以及 接触点数量（pcntg），通过它可定义 tolerance 值（该值在 创建测量区域（measure create） 命令中指定）。最后一个参数决定了在测量区域内计算孔隙率时所允许的误差容差（< 接触点数量（pcntg））。详情请参阅参考页。

各测量区域在模型中的尺寸和位置均为随机。这一点在 create_meas_regions 函数中定义。

为验证孔隙率计算的准确性，定义了一个带三个参数的 check_error 函数：属性值（val） 为孔隙率的参考值，在规则集合体的情况下由式 (1)、(2)、(3)、(4) 计算得到，在多分散集合体的情况下则直接使用式 (5) 计算，该值用于与数值结果进行比较；t 为一个字符串变量，用于定义表格的名称，该表格将保存孔隙率测量中所产生误差的数值；平均半径（average_radius） 为组成集合体的球颗粒的平均半径，在对模拟结果进行后处理时用于对测量区域的直径进行归一化。

在规则集合体的情况下，使用一个参数化的 FISH 函数，通过 ball generate 命令构建每一种排列（2D 见“RegularAssembly.dat（二维）（RegularAssembly.dat (2D)）”，3D 见“RegularAssembly.dat（三维）（RegularAssembly.dat (3D)）”）。该函数有三个参数：尺寸、分辨率和排列类型，分别对应 size、结果数量（nres） 和 接触类型ID（itype）。每种排列构建两个模型。这两个模型分别包含 9 行 9 列球颗粒（3D 中为 9x9x9）和 30 行 30 列球颗粒（3D 中为 30x30x30）。

分辨率越高，孔隙率测量中所产生的平均误差越低。原始数据存储在四个表格中（参见 表格插值取值（table） 命令参考页），每种被考察的排列对应一个表格。

图 6（Fig. 6） 给出了平均误差，该误差以对数坐标绘制为用于测量孔隙率的圆直径的函数，圆直径由球颗粒的平均半径归一化。同样可以看出，最低的误差（< 1%，即对数轴上的负值）对应于最高的分辨率和最大的测量区域。

我们可以得出以下观察结果：

  • 孔隙率的测量在局部上始终是正确的，考虑到所采用的 tolerance 等于 0，这一点就更为明显；
  • 局部测量相对于由解析计算得到的整体孔隙率的准确性，取决于测量区域所截取的面积相对于整体面积在孔隙/固体比例方面的代表性；
  • 因此，测量区域越大，提供准确测量的可能性就越大；并且
  • 更明显的是，分辨率越高，测量区域就越能代表整体结构。

相对于规则试样，误差相对较高，这是由于整个试样内的孔隙率值不均匀。因此，在这种情况下，采用更大的测量区域可使测量结果更为集中，尽管似乎更难消除一个较小的误差（\(\simeq 2\) %）。

数据文件

MeasureLogic.dat（三维）

; 文件名：MeasureLogic.dat（3D）
;
; 测试 PFC 中力学球体计算与测量逻辑的集成。 
; 采用随机半径的测量球计算孔隙率。 
; 将不同模型分辨率下的孔隙率结果与 
; 解析解进行对比。
;
; Itasca Consulting Group, Inc.
;
; ========================================================================

fish def define_meas_parameters(nmeas, pcntg)
; 参数： 
;   - nmeas：整数值，表示将要创建的随机布置的
;             探测测量圆的个数
;             改变该参数可观察其对最终结果的影响
;   - pcntg：MEASURE 函数的 'percentage' 参数
; 
  global p = pcntg
  global n = nmeas
end


fish def compute_meas_center(r)
;随机计算测量球球心的坐标
;参数：
;	- r：测量球半径
;
    global xmin, xmax, ymin, ymax, zmin, zmax
    local xcmin = xmin+r
    local xcmax = xmax-r
    local ycmin = ymin+r
    local ycmax = ymax-r
    local zcmin = zmin+r
    local zcmax = zmax-r
    global xc = xcmin + (xcmax - xcmin)*math.random.uniform
    global yc = ycmin + (ycmax - ycmin)*math.random.uniform
    global zc = zcmin + (zcmax - zcmin)*math.random.uniform
end


fish define create_meas_regions
  measradius = array.create(n)
  local maxmeasradius = math.min((0.99*(zmax-zmin)), ...
                        math.min((0.99*(xmax-xmin)), ...
                        (0.99*(ymax-ymin))))
  loop ii(1,n)
    measradius(ii) = math.max(maxmeasradius/15,...
                              math.random.uniform*(0.5*(maxmeasradius)))
  end_loop
  loop ii(1,n)
    command
      [compute_meas_center(measradius(ii))]
      measure create pos-x [xc] pos-y [yc] pos-z [zc] ...
                     radius [measradius(ii)] tolerance [p]
    end_command
  end_loop
end

fish define check_error(val,t,averageradius)
; 将测量圆内计算得到的孔隙率
; 与解析值进行比较
; 参数： 
;   - val：孔隙率的精确值
;   - t：存放最终数值结果的表名
;
  global result = table.create(t)
  local it = 0
  local averageerror = 0
  loop foreach local mp measure.list
    it = it + 1
    local res = measure.porosity(mp)
    local diff = 100.0 * (res - val) / val
    averageerror = averageerror + math.abs(diff)
    table(t,math.abs(diff))=measradius(it)/averageradius
  endloop
  global check_error = averageerror/it
end

;=========================================================================
; 文件结束：MeasureLogic.dat（3D）

PolydisperseAssembly.dat（三维）

; 文件名：PolydisperseAssembly.dat（3D）
; 构建多分散颗粒集合体，并用 PFC 中的 
; 测量逻辑计算孔隙率
; ========================================================================
;

model new
program call 'MeasureLogic'

fish def poly_assembly(size)
; 在正方形区域中创建多分散堆积
; 参数：
;	- size：计算域尺寸
;
  global xmin       = 0.0
  global ymin       = 0.0
  global xmax       = size
  global ymax       = size
  global zmin       = 0.0
  global zmax       = size
  
  global width      = xmax-xmin  ; 箱体宽度
  global height     = ymax-ymin  ; 箱体高度
  global depth      = zmax-zmin  ; 箱体厚度
  global tot_vol    = (width)*(height)*(depth)
  
  local num         = 10000   ; 颗粒数量
  
  local rlo         = size/100
  local rhi         = 1.25*rlo
  local oversize    = rhi
  
  command
    model domain extent ([0.0-oversize],[width+oversize])  ...
                        ([0.0-oversize],[height+oversize]) ...
                        ([0.0-oversize],[depth+oversize])
    wall generate box (0.0, [width]) (0.0, [height]) (0.0, [depth]) 
  end_command
 
  ;--- 生成球体并指定其参数
  command
    ball generate radius [rlo] [rhi] gauss ...
                  box ([width*0.02], [width*0.98])   ...
                      ([height*0.02], [height*0.98]) ...
                      ([depth*0.02], [depth*0.98])   ...
                      id=1,[num]
  end_command
end

fish def averageradius
  local rad = 0
  loop foreach local bp ball.list
    rad = rad + ball.radius(bp)
  endloop
  global averageradius = rad/ball.num
end

fish def get_poros ;计算孔隙率的精确值
  local sum = 0.0
  loop foreach local bp ball.list
    sum = sum + 1.33333* math.pi * ball.radius(bp)^3
  end_loop
  global get_poros = 1.0 - sum / tot_vol
end

[poly_assembly(5.0)]

[get_poros]
[define_meas_parameters(5000, 0.0)]
[create_meas_regions]

fish def display_error(porosity, s)
  global error = check_error(porosity,s,averageradius)
  local oo = io.out(string.build("Average Error = %1%)",error))
end
[display_error(get_poros,'Polydisperse')]

model save 'PolydisperseAssembly'

; 文件结束：PolydisperseAssembly.dat（3D）

RegularAssembly.dat（三维）

; 文件名：RegularAssembly.dat（3D）
; 构建规则颗粒集合体，并用 PFC 中的
; 测量逻辑计算孔隙率
; ========================================================================
;

model new
program call 'MeasureLogic'

fish define regular_assembly(size, nres,itype)
; 在立方体区域中创建单一粒径球的规则堆积
; 参数：
;   - size：计算域尺寸
;   - nres：堆积的分辨率
;   - itype：堆积类型（0：简单立方；#0：六方）
;
  global    xmin       = 0.0
  global    ymin       = 0.0
  global    xmax       = size
  global    ymax       = size
  global    zmin       = 0.0
  global    zmax       = size

  global    radius      = size / (2.0*nres)
  local     numballs    = nres^2

  command
    model domain extent [xmin] [xmax] [ymin] [ymax] [zmin] [zmax]
  end_command

  if itype = 0 then
    command
      ball generate rad [radius] number [numballs] cubic
    end_command
  else
    command
      ball generate rad [radius] number [numballs] hexagonal
    end_command
  endif
end

fish def display_error(porosity, s)
  global error = check_error(porosity,s,radius)
  local oo = io.out(string.build("Average Error = %1%)",error))
end

[define_meas_parameters(5000,0.0)] ;定义测量参数

; 简单立方堆积 - 低分辨率
[regular_assembly(18.0, 9, 0)]
[create_meas_regions]
[display_error(0.4764,'cubic_lores')]
model save 'cubic_lores'
;
; 简单立方堆积 - 高分辨率
ball delete
[regular_assembly(18.0, 30, 0)]
[display_error(0.4764,'cubic_hires')]
model save 'cubic_hires'
;
; 六方堆积 - 低分辨率
ball delete
[regular_assembly(18.0, 9, 1)]
[display_error(0.2595,'hexa_lores')]
model save 'hexa_lores'
;
; 六方堆积 - 高分辨率
ball delete
[regular_assembly(18.0, 30, 1)]
[display_error(0.2595,'hexa_hires')]
model save 'hexa_hires'

model save 'RegularAssembly'

fish def display_error(porosity, s)
  global error = check_error(porosity,s,averageradius)
  local oo = io.out(string.build("Average Error = %1%)",error))
end
[display_error(get_poros,'Polydisperse')]

model save 'PolydisperseAssembly'

RegularAssembly.dat（二维）

; 文件名：RegularAssembly.dat（2D）
; 构建规则颗粒集合体，并用 PFC 中的 
; 测量逻辑计算孔隙率
; ========================================================================
;

model new
program call 'MeasureLogic'

fish define regular_assembly(size, nres,itype)
; 在正方形区域中创建单一粒径球的规则堆积
; 参数：
;	- size：计算域尺寸
;   - nres：堆积的分辨率
;   - itype：堆积类型（0：简单立方；#0：六方）
; 
  global xmin       = 0.0
  global ymin       = 0.0
  global xmax       = size
  global ymax       = size

  global radius     = size / (2.0*nres) 
  local numballs    = nres^2

  command
    model domain extent [xmin] [xmax] [ymin] [ymax]
  end_command

  if itype = 0 then
    command
      ball generate rad [radius] number [numballs] cubic
    end_command
  else
    command
      ball generate rad [radius] number [numballs] hexagonal
    end_command
  endif
end

fish def display_error(porosity, tablename)
  global error = check_error(porosity,tablename,radius)
  local oo = io.out(string.build("Average Error = %1%)",error))
end

[define_meas_parameters(5000, 0.00)] ;定义测量参数

; 简单立方堆积 - 低分辨率
[regular_assembly(18.0, 9, 0)]
[create_meas_regions]
[display_error(0.2146,'cubic_lores')]
model save 'cubic_lores'
;
; 简单立方堆积 - 高分辨率
ball delete
[regular_assembly(18.0, 30, 0)]
[display_error(0.2146,'cubic_hires')]
model save 'cubic_hires'
;
; 六方堆积 - 低分辨率
ball delete
[regular_assembly(18.0, 9, 1)]
[display_error(0.0931,'hexa_lores')]
model save 'hexa_lores'
;
; 六方堆积 - 高分辨率
ball delete
[regular_assembly(18.0, 30, 1)]
[display_error(0.0931,'hexa_hires')]
model save 'hexa_hires'

model save 'RegularAssembly'

; ========================================================================
; 文件结束：RegularAssembly.dat（2D）
