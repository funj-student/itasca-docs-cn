黏附滚动阻力线性接触模型：休止角

引言

注意

本算例的项目文件可在 PFC 中查看或运行。[1]所用的数据文件（data files）列于本算例末尾。

在本例中，通过向上提升一个初始装满在重力作用下静止的球颗粒的容器来形成颗粒堆积体。计算中采用 黏附滚动阻力线性接触模型（adhesive rolling resistance linear contact model），并以不同的最大吸引力 \((F_0)\) 取值多次进行模拟，以研究其对堆积体最终形状的影响。结果表明，如预期一样，增大 \(F_0\) 会使堆积体的坡角增大。黏附滚动阻力线性模型具有吸引力作用范围 \((D_0)\)，它定义了球颗粒之间吸引力开始不为零的距离。在模拟过程中改变 \(D_0\) 的取值时，需要使用接触模型分配表（CMAT）来确保表面间隙小于吸引力作用范围的球颗粒之间会自动创建接触，文中还演示了实现该行为所需的步骤。本例在 PFC2D 和 PFC3D 中均有介绍。

PFC2D 模型

初始状态

初始模型状态由容器中在重力作用下静止的颗粒柱组成，如 图 1（Figure 1） 所示。该模型使用数据文件 make_system.dat (2D) 创建。下面讨论该文件中的部分代码行。

图 1：初始模型状态。

为方便起见，输入参数使用内联 FISH 定义为全局 FISH 变量（参见 执行 FISH：内联 FISH 或 FISH 片段（Executing FISH: Inline FISH or FISH Fragments） 主题），具体代码如下：

[cyl_rad    =   50.0e-3] ; 容器半宽 [m]
[cyl_height =  100.0e-3] ; 容器高度 [m]
[ravg       =   1.5e-3 ] ; 球平均半径 [m]
[rdev       =   0.5    ] ; 球半径相对偏差 [-]
[dens       =   2.0e3  ] ; 球密度 [kg/m3]
[poros      =   0.3    ] ; 初始孔隙率 [-]

 ;  接触模型参数
[emod   = 1.0e6]  ; 杨氏模量（deformability 方法）[Pa]
[kratio = 2.0  ]  ; 刚度比（deformability 方法）[-]
[fric   = 0.01 ]  ; 摩擦系数 [-]
[dpnr   = 0.2  ]  ; 法向临界阻尼比 [-]
[dpsr   = 0.2  ]  ; 切向临界阻尼比 [-]
[dpm    = 3    ]  ; 阻尼器模式 [-]
[rfric  = 0.0  ]  ; 滚动阻力系数 [-]
[F0     = 0.0  ]  ; 最大吸引力 [N]
[D0     = 0.0  ]  ; 吸引范围 [m]

第一组参数定义容器尺寸，以及所生成球颗粒云的粒径分布、密度和孔隙率。容器设置为 100 mm × 100 mm 的正方形，球颗粒半径围绕 1.5 mm 的均值具有 0.5 的相对偏差，密度为 2000 kg/m3。几何体由两个独立的墙体构成：一个横跨整个计算域的水平底面，以及一个由 3 个面片组成的容器。

wall generate id 1               ...
              name 'base_plane'  ...
              plane

wall create id 100                                                 ...
            name 'container'                                       ...
     vertices [-1.0*cyl_rad] 0.0 [-1.0*cyl_rad] [cyl_height]        ...
              [-1.0*cyl_rad] [cyl_height] [1.0*cyl_rad] [cyl_height] ...
              [1.0*cyl_rad] [cyl_height] [1.0*cyl_rad] 0.0

初始球颗粒云使用 ball distribute 命令创建：

ball distribute porosity [poros]                      ...
                resolution [ravg]                     ...
                radius [1.0-0.5*rdev] [1.0+0.5*rdev] ...
                box [-1.0*cyl_rad] [1.0*cyl_rad]     ...
                               0.0 [cyl_height]

第二组参数定义系统中将使用的接触模型属性。黏附滚动阻力线性接触模型（adhesive rolling resistance linear contact model） 被分配给球-球接触，滚动阻力线性接触模型（rolling resistance linear contact model） 被分配给球-墙接触。球-墙接触处不会产生吸引力，因此球颗粒不会黏附在墙面上。

contact cmat default type ball-ball model arrlinear ...
                            method deformability       ...
                                     emod      [emod]   ...
                                     kratio    [kratio] ...
                            property fric      [fric]   ...
                                     dp_nratio [dpnr]   ...
                                     dp_sratio [dpsr]   ...
                                     dp_mode   [dpm]    ...
                                     rr_fric   [rfric]  ...
                                     adh_f0    [F0]     ...
                                     adh_d0    [D0]
contact cmat default type ball-facet model rrlinear ...
                            method deformability       ...
                                     emod      [emod]   ...
                                     kratio    [kratio] ...
                            property fric      [fric]   ...
                                     dp_nratio [dpnr]   ...
                                     dp_sratio [dpsr]   ...
                                     dp_mode   [dpm]    ...
                                     rr_fric   [rfric]

这些属性的详细说明请参见 黏附滚动阻力线性接触模型一节（adhesive rolling resistance linear contact model section）。在当前阶段，摩擦系数取很小的值，滚动阻力系数设为零，且不存在吸引力。采用这些取值是为了获得相对密实的初始状态。接触有效模量设为 1 MPa（使用接触模型的 变形性（deformability） 方法）。该取值足以保证系统处于刚性颗粒极限范围内（即接触有效模量与颗粒柱底部最大应力的比值足够大，或者反过来说，重叠量与相接触的球颗粒直径相比很小，从而进一步增大接触刚度也不会影响计算结果），同时又优化了估算时步。

最后，设置重力以及球颗粒密度和局部阻尼系数属性；然后使用以下命令将系统求解至平衡：

ball attribute density [dens] damp 0.7
model large-strain on 
model cycle 1000 calm 10
model gravity 9.81
model solve ratio-average 1e-5
ball attribute damp 0.0
model save 'init.p2sav'
program return

请注意，将 calm 关键字与 执行计算时步（model cycle） 命令配合使用，可有效消除因使用 ball distribute 命令而固有的大初始重叠所产生的能量。在此阶段将局部阻尼设为 0.7 这一较大值，因为我们只关心最终的平衡状态，而不关心系统所经历的路径。在进入堆积体形成阶段之前，局部阻尼被重新设为零。

堆积体形成

通过将容器墙体向上提升来形成堆积体。这由以下一组命令完成（位于文件 move_container.dat (2D) 中）：

[cyl_vel = 5.0e-2]  ; 向上的速度 [m/s] 
model mechanical time-total 0.0

 ;  *** 修改材料参数
 ;  修改现有球-球与球-面片接触的参数。
contact property fric [fric] rr_fric [rfric] adh_f0 [F0] adh_d0 [D0] ... 
 range contact type 'ball-ball'
contact property fric [fric] rr_fric [rfric] ... 
 range contact type 'ball-facet'
 ;  修改未来球-球接触的参数。
contact cmat default type ball-ball model arrlinear ... 
 method deformability ... 
 emod [emod] ... 
 kratio [kratio] ... 
 property fric [fric] ... 
 dp_nratio [dpnr] ... 
 dp_sratio [dpsr] ... 
 dp_mode [dpm] ... 
 rr_fric [rfric] ... 
 adh_f0 [F0] ... 
 adh_d0 [D0]
 ;  修改未来球-面片接触的参数。
contact cmat default type ball-facet ... 
 property fric [fric] rr_fric [rfric]
 ;  对 a_d0 的修改已自动改变邻近距离。
 ;  通过重新映射网格空间强制生成新接触。
model clean

wall attribute velocity-y [cyl_vel] range id 100 by wall
ball attribute displacement multiply 0.0
model solve time [0.75*cyl_height/cyl_vel]
wall attribute velocity-y 0.0 range id 100 by wall
model solve ratio-average 1e-5
model save ...
 [string.build('final-fric_%1_rfric_%2_F0_%3_D0_%4.p2sav',fric,rfric,F0,D0)]
program return

该文件并非用于直接执行，而是由 Python 脚本按顺序调用，以完成一系列具有不同属性集的模拟。共有四个属性：摩擦系数（摩擦（fric））、滚动阻力系数（滚动摩擦（rfric））、最大吸引力（F0）和吸引力作用范围（D0）。这些属性被赋给现有的接触，以及后续循环中可能形成的接触。摩擦（fric） 和 滚动摩擦（rfric） 的取值赋给所有接触，而 F0 和 D0 的取值只赋给球-球接触。这给出了一个使用 CMAT 创建 arrlinear 材料的示例，相关讨论详见 此链接（this link）。

这四个属性在 Python 脚本中被赋值（位于文件 do_analysis.py 中）：

import itasca
itasca.command("python-reset-state off")

fric_list  = [0.5]
rfric_list = [0.1]
# F0_list is {0, 1, 5} times weight of single particle [N]
# D0_list is 100% of avg. particle radius [m]
F0_list = [0.0,0.14,0.7]
D0_list = [1.5e-3]

for f in fric_list:
  for rf in rfric_list:
    for myF0 in F0_list:
      for myD0 in D0_list:
        itasca.command("""
                         model restore \'init\'
                         [fric  = {0}]
                         [rfric = {1}]
                         [F0    = {2}]
                         [D0    = {3}]
                         program call \'move_container.dat\'
                       """.format(f,rf,myF0,myD0)
        )

脚本中定义了四个列表，并使用嵌套循环为单次模型运行赋予特定的属性组合。每次运行时，先恢复初始状态，再将这些属性赋予四个 FISH 变量，随后调用 move_container.dat 数据文件。模型运行采用以下属性值。摩擦系数和滚动摩擦系数分别固定为 0.5 和 0.1。最大吸引力分别设为单个颗粒平均重量的零倍、一倍和五倍（\(W = \rho V g = \rho (\pi R^2 t) g \approx 0.14\) N），吸引范围固定为平均颗粒半径的 100%。

最大吸引力 \((F_0)\) 取三种不同取值时的最终状态如图 2 至 4 所示。当不存在吸引力时，形成图 2（Figure 2） 所示的堆积体。当 \(F_0\) 设为颗粒平均重量时，堆积体变得更密实，休止角更大，因为吸引力使颗粒相互拉近，如图 3（Figure 3） 所示。当 \(F_0\) 增大到颗粒平均重量的五倍时，吸引力变得过大，无法形成堆积体；颗粒转而保持容器形状，如图 4（Figure 4） 所示。如果此时通过执行以下命令（在文件 zero_F0.dat (2D) 中）将吸引力设为零：

model restore 'final-fric_0.5_rfric_0.1_F0_0.7_D0_0.0015.p2sav'

contact property adh_f0 0.0
contact cmat default type ball-ball ...
             property adh_f0 0.0
model cycle 10
model solve ratio-average 1e-5
model save 'zero_F0.p2sav'
program return

那么颗粒将无法再保持容器形状，集合体随之坍塌，形成图 5（Figure 5） 所示的散落堆积体。

PFC3D 模型

PFC3D 模型与上述 PFC2D 模型类似，不同之处在于容器为圆柱体（高度和直径均为 100 mm），球颗粒的平均半径为 3.0 mm，相对偏差为 0.25，以限制模型规模。初始系统见图 6（Figure 6）。该模型使用文件 make_system.dat (3D) 构建，堆积体的形成过程使用文件 do_analysis.py 模拟，该文件依次调用 move_container.dat (3D)，以不同的最大吸引力取值执行多次运行。

图 6：初始模型状态。

模型运行采用以下属性值。摩擦系数和滚动摩擦系数分别固定为 0.5 和 0.1。最大吸引力分别设为单个颗粒平均重量的零倍、一倍和五倍（\(W = \rho V g = \rho ({4\over3} \pi R^3) g \approx 2.2 \times 10^{-3}\) N），吸引范围固定为平均颗粒半径的 5%。

最大吸引力 \((F_0)\) 取三种不同取值时的最终状态如图 7 至 9 所示。当不存在吸引力时，形成图 7（Figure 7） 所示的堆积体。当 \(F_0\) 设为颗粒平均重量时，堆积体变得更密实，休止角更大，因为吸引力使颗粒相互拉近，如图 8（Figure 8） 所示。当 \(F_0\) 增大到颗粒平均重量的五倍时，吸引力变得过大，无法形成堆积体；颗粒转而保持容器形状，如图 9（Figure 9） 所示。如果此时通过执行以下命令（在文件 zero_F0.dat (3D) 中）将吸引力设为零：

那么颗粒将无法再保持容器形状，集合体随之坍塌，形成图 10（Figure 10） 所示的散落堆积体。

讨论

本算例在 PFC2D 和 PFC3D 中检验 黏结滚动阻力线性接触模型（adhesive rolling resistance linear contact model），其情形为：将初始装满球颗粒、在重力作用下静止的容器向上移动，从而形成堆积体。研究了堆积体形状随最大吸引力 \((F_0)\) 增大而发生的演化，并表明其符合预期行为。增大 \(F_0\) 会使堆积体的坡角增大；当 \(F_0\) 增大到足够程度时，球颗粒集合体不再形成堆积体，而是保持容器形状。本算例给出的定性结果与预期行为一致。

do_analysis.py

#=========================================================================
# do_analysis.py
#=========================================================================
import itasca
itasca.command("python-reset-state off")
fric_list  = [0.5]
rfric_list = [0.1]
# F0 is {0, 1, 5} times weight of single particle [N]
# D0 is 5% of avg. particle radius [m]
F0_list = [0.0, 2.2e-3, 1.1e-2]
D0_list = [1.5e-4]

for f in fric_list:
  for rf in rfric_list:
    for myF0 in F0_list:
      for myD0 in D0_list:
        itasca.command("""
                         model restore 'init'
                         [fric  = {0}]
                         [rfric = {1}]
                         [F0    = {2}]
                         [D0    = {3}]
                         program call 'move_container.dat'
                       """.format(f,rf,myF0,myD0)
        )
