合成岩体（SRM）试样的创建

引言

注意

本算例的项目文件可在 PFC 中查看或运行。[1]所用的数据文件（data files）列于本算例末尾。

岩体是由岩基质组成的复杂系统，其材料性质可能非均质，且往往遍布不连续面（例如裂隙、节理、断层等）。这类系统中的破坏可能发生在岩基质中，也可能沿不连续面发生，或同时发生在两处。PFC 已被成功用于研究此类系统的力学行为，这得益于 光滑节理接触模型（smoothjoint contact model）（[Pierce2012a]）的发展。该建模方法是将裂隙信息（即裂隙的几何形状与性质）叠加到黏结颗粒模型（BPM，[Potyondy2015d]）上。BPM 用于模拟完整岩石，而裂隙的力学行为则通过修改与裂隙相交的接触处的接触模型来引入。由于 PFC 模型本质上是离散的，破坏既可发生在完整的 BPM 区域，也可沿裂隙面发生。由这种配置确定岩体性质的方法被称为合成岩体（SRM）方法。

随着 离散裂隙网络逻辑（discrete fracture network logic） 的加入，开展此类研究所需的建模步骤在 PFC 6.0 中被大大简化，本教程即演示了这一点。

完整的 BPM 模型使用 线性平行黏结接触模型（linear parallel bond contact model） 创建。为高效地建立足尺模型，采用了 brick 逻辑（brick logic），即先在周期性空间中创建一个小模型，随后再将其组装为足尺模型。最后生成 DFN，并将其用于为与裂隙相交的接触赋予 光滑节理接触模型（smoothjoint contact models）。创建黏结颗粒模型的支持由 材料建模支持（material-modeling support） 包提供，但本文未使用该包，因为它目前尚不支持在周期性空间中创建材料。

PFC2D 模型

文件“doall.p2dvr”依次调用其他数据文件，以执行建模过程的各个步骤。采用这种策略可以有效地管理多步骤模拟。

构建完整岩石

完整试样的创建分两步完成。首先在周期性空间中将一个小系统求解至平衡。然后将该系统作为一个砖块，通过组装来创建更大的足尺模型。

文件 make_brick.dat（二维）（make_brick.dat (2D)） 用于创建基本砖块。

; 文件名：make_brick.dat (2D)
;
; 在周期性空间中创建一个基块 
;=========================================================================
model new
model large-strain on
model domain extent -2.0 2.0 condition periodic
contact cmat default model linear property kn 1e5
model random 10001
ball distribute porosity 0.08 radius 1.0 1.6 res 0.025
ball attribute density 2500.0 damp 0.7
model cycle 1000 calm 10
model mechanical timestep scale
model solve
model calm
brick make id 1
brick export id 1 skip-errors
program return
;=========================================================================
; 文件结束：make_brick.dat (2D)

本阶段的目标是构建一个密实且连接良好的集合体。接触模型分配表（CMAT） 的默认槽位中填充的是具有指定法向刚度的 线性接触模型（linear contact model）。使用 ball distribute 命令创建球颗粒以匹配目标孔隙率，并设置密度和局部阻尼属性。随后将系统求解至平衡（先使用带 calm 关键字的 执行计算时步（model cycle） 命令，再使用 求解模型（model solve） 命令）。图 1（Figure 1） 展示了导出为二进制文件（参见 导出砖块（brick export） 命令）以备后续使用的砖块。

图 1：基本砖块。

使用“make_intact.dat（二维）（make_intact.dat (2D)）”中的命令来组装砖块。在本例中，砖块在水平方向上复制两次、在竖直方向上复制四次，最终模型尺寸为 8.0 × 16.0 个长度单位，包含约 35,000 个球颗粒。请注意，导入砖块不会修改 接触模型分配表（CMAT） 的默认槽位。因此，需要通过赋予 线性平行黏结接触模型（linear parallel bond contact model） 并将 lin_mode = 1 来修改这些槽位。该属性将线性分量的法向力计算模式设为增量式而非绝对式。使用 deformability 方法设置微观属性，以满足接触模型线性部分的目标杨氏模量。应用 CMAT，使所有接触都被赋予更新后的接触模型，并将接触力/力矩清零。将接触力/力矩清零并把法向力计算改为增量模式可消除内建应力，在某些情况下可能是需要的。最后，使用 contact method 命令将所有相互重叠的球颗粒之间的接触黏结起来，并相应设置平行黏结属性。通常不宜在 CMAT 中指定 bond 方法，因为这将导致尝试对所有后续创建的接触进行黏结。图 2（Figure 2） 展示了完整试样。

; 文件名：make_intact.dat (2D)
;
; 在足尺模型中组装基块并安装线性平行黏结模型 
;=========================================================================
model new
model domain extent -4.0 4.0 -8.0 8.0
brick import id 1 
brick assemble id 1 origin -4.0 -8.0 size 2 4
contact cmat default model linearpbond method deformability ...
                     emod 60e9 kratio 2.5 property fric 0.5 lin_mode 1 
contact cmat apply
ball attribute force-contact multiply 0.0 moment-contact multiply 0.0
contact method bond gap 0.0 pb_deformability emod 60e9 kratio 2.5
contact property pb_ten 1e8 pb_coh 5e7 pb_fa 20.0
model save 'intact'
program return
;=========================================================================
; 文件结束：make_intact.dat (2D)

图 2：完整试样。

叠加裂隙

文件“make_fractured.dat（二维）（make_fractured.dat (2D)）”用于将裂隙叠加到完整的 BPM 上。

; 文件名：make_fractured.dat (2D)
;
; 恢复完整黏结颗粒模型 - 生成离散裂隙网络并将光滑节理接触
; 模型安装到被裂隙切穿的接触上 
;=========================================================================
model restore 'intact'
model random 10001
fracture template create 'test' size power-law 3 size-limits 1 100
fracture generate dfn 'fractures' template 'test' ...
                  generation-box -4 4 -8 8 p10 1.5 begin (0,-8) end (0,8)
fracture combine angle 30.0 distance 1.0 merge
fracture combine angle 40.0 distance 1.0 merge
fracture contact-model model 'smoothjoint' install 
model save 'fractured'
program return
;=========================================================================
; 文件结束：make_fractured.dat (2D)

使用 创建裂隙模板命令（fracture template create） 命令定义统计 DFN 模型。在本例中，裂隙遵循幂律尺寸分布，指数为 -3，长度范围为 1 至 100 个单位。DFN 是以 DFN 模板作为统计模型进行的一次实现。生成一个 DFN（参见 生成裂隙命令（fracture generate） 命令），其停止准则基于沿一条竖直线的裂隙频率，即 P10。使用 合并裂隙命令（fracture combine） 命令对该 DFN 进行变换，以合并方位相似且在空间上彼此接近的裂隙。这一操作可能是有益的，因为合并之前的裂隙数量可能不必要地偏多。最后，使用 裂隙接触模型模型（fracture contact-model model） 命令在与裂隙相交的接触中安装 光滑节理接触模型（smoothjoint contact model）。请注意，也可以使用任何其他接触模型。图 3（Figure 3） 展示了最终系统，图 4（Figure 4） 展示了该系统的细部。

图 3：含裂隙试样。

图 4：细部视图——光滑节理接触用光滑节理法向表示。

讨论

本教程演示了如何使用 brick 逻辑（brick logic） 高效地创建大尺度 BPM。此外，还给出了生成并简化 DFN 的步骤。与裂隙相交的接触被赋予 光滑节理接触模型（smoothjoint contact model），并设置其属性。所得的 SRM 试样已处于可进行进一步测试以确定其强度特性的状态。

参考文献

[Pierce2012a]Pierce, M.E., and C. Fairhurst，“合成岩体在大型采矿中的应用”（Synthetic Rock Mass Applications in Mass Mining），载于 Harmonising Rock Engineering and the Environment（第 12 届 ISRM 国际大会论文集，中国北京，2011 年 10 月），第 109-114 页，Q. Qian and Y. Zhou 编，ISBN 978-0-415-80444-8，伦敦：Taylor & Francis Group（2012）。
[Potyondy2015d]Potyondy, D. O.，“黏结颗粒模型作为岩石力学研究与应用的工具：当前趋势与未来方向”（The Bonded-Particle Model as a Tool for Rock Mechanics Research and Application: Current Trends and Future Directions），Geosystem Engineering，18(1)，第 1–28 页（2015），DOI:10.1080/12269328.2014.998346。
