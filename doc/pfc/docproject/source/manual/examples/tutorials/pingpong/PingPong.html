乒乓球

引言

注意

本算例的项目文件可在 PFC 中查看或运行。[1]所用的数据文件（data files）列于本算例末尾。

此示例模拟一场乒乓球比赛。

这里展示了 wall generate 命令的基本用法。使用 设置FISH回调命令（fish callback） 命令，以便在球颗粒撞击球台或球网时执行特定操作。在比赛过程中使用 ball trace 命令追踪球颗粒的轨迹。

数值模型

“CreateTable.dat (3D)” 数据文件创建球台和球拍。首先，根据计算域尺寸计算球台尺寸。

fish define dim_table
  xTable=array.create(1,2)
  yTable=array.create(1,2)
  xTable(1,1) = domain.min.x*0.95
  xTable(1,2) = domain.max.x*0.95
  Lx = math.abs(xTable(1,1))+math.abs(xTable(1,2))
  Ly = Lx*0.6
  yTable(1,1) = domain.min.y*0.95
  yTable(1,2) = yTable(1,1)+Ly
  zTable = (domain.min.z+domain.max.z)*0.5
end
[dim_table]

随后使用 wall generate 命令创建球台台面，以生成一个平面多边形墙体（多边形（polygon） 关键字）。球台的桌腿也通过使用 圆柱（cylinder） 关键字引入四个圆柱形墙体来创建。 对墙体进行分组和命名（下面给出的是四个墙体中的第一个），以便于后续操作。

; 创建球桌
wall generate group 'table' polygon           ...
            [xTable(1,2)] [yTable(1,1)] [zTable] ...
            [xTable(1,2)] [yTable(1,2)] [zTable] ...
            [xTable(1,1)] [yTable(1,1)] [zTable] ...
            [xTable(1,1)] [yTable(1,2)] [zTable]

; 插入桌腿
wall generate group 'table' cylinder        ...
     axis 0 0 -1                            ...
     base [xTable(1,2)] [yTable(1,1)] [zTable] ...
     height [Ly*0.5]                        ...
     one-wall                               ...
     radius [Lx*0.02]

最后，将球网创建为一个新的多边形墙体。

; 创建球网
wall generate group 'net' polygon                                   ...
     [(xTable(1,1)+xTable(1,2))*0.5] [yTable(1,1)] [zTable]           ...
     [(xTable(1,1)+xTable(1,2))*0.5] [yTable(1,2)] [zTable]           ...
     [(xTable(1,1)+xTable(1,2))*0.5] [yTable(1,1)] [zTable+Lx*0.075] ...
     [(xTable(1,1)+xTable(1,2))*0.5] [yTable(1,2)] [zTable+Lx*0.075]

然后创建球拍，并将其放置在球台两端。球拍使用 圆盘（disk） 关键字由两个圆盘形墙体表示。

; 创建球拍
wall generate group 'player1' disk ... ;球拍 Player1
    dip 90                ...
    dip-direction 90      ...
    position [xTable(1,1)] [(yTable(1,1)+yTable(1,2))*0.5] [zTable+Ly*0.3] ...
    rad [Lx*0.05]

wall generate group 'player2' disk ... ;球拍 Player2
    dip 90                ...
    dip-direction 90      ...
    position [xTable(1,2)] [(yTable(1,1)+yTable(1,2))*0.5] [zTable+Ly*0.3] ...
    rad [Lx*0.05]

图 1：球台、球网和球拍。

准备比赛的最后一步是创建球颗粒。其初始速度按分量分别设置。

;定义球的初始速度
[XballInitialVelocity = -3.0]
[ZballInitialVelocity = 2.0]

比赛过程中使用 ball trace 命令追踪球颗粒的轨迹。球颗粒的密度和初始速度使用 ball attribute 命令设置。

;创建球
ball create id 1 rad [Lx*0.005]                           ...
                 position [xTable(1,2)*0.98]              ...
                          [(yTable(1,1)+yTable(1,2))*0.5] ...
                          [zTable+Ly*0.3]
ball trace id 1
ball attribute density 10                       ...
               velocity-x [XballInitialVelocity] ...
               velocity-z [ZballInitialVelocity]

每个 PFC 模型中都必须定义 接触模型分配表（CMAT）（Contact Model Assignment Table (CMAT)）。模型域中的每个接触都按这种方式分配接触本构模型。CMAT 的默认槽位针对球颗粒-面片接触定义。选择带有库仑准则、并与这些接触相关联的线性模型。

;球-面片接触的线性模型
contact cmat default type ball-facet model linear ...
        property kn 1e6 ks 1e6 fric 0.009

为完成模型的准备工作，还需要一些函数来控制球拍的运动，并在出现失误时停止比赛。为此，创建两个 FISH 函数，并使用 设置FISH回调命令（fish callback） 命令将它们注册到回调事件。

;设置 FISH 回调以检查球是否触及球网
fish callback add checknet event contact_activated
;设置 FISH 回调以准备球拍位置
fish callback add tablecontact event contact_activated

使用 列出循环序列（program list cycle-sequence） 命令列出 PFC 循环期间的循环点，使用 FISH 列表回调列表（fish list callback-list） 命令列出可用的回调事件。可以在循环序列中的预设循环点之间插入 FISH 函数。

在本示例中，我们选择使用回调事件来管理球颗粒-球网和/或球颗粒-球台的相互作用。对于使用 contact_activated 事件的球颗粒-球网接触（参见“线性模型回调事件（Linear Model Callback Events）”），每次接触被激活时，函数 检查网络（checknet） 都会检查它是否为球颗粒-球网接触。若是，则发送 Fault! 消息。

; 检查球与球网的接触
fish define checknet(arr)
    ct=arr(1)
    ; 对于球-面片接触，contact.end1 指球，
    ; contact.end2 指面片
    if wall.group(wall.facet.wall(contact.end2(ct))) == "net"
      io.out("Net!!")
      bp = ball.find(1)
      ball.vel(bp,1)=0
      ball.vel(bp,3)=0
    endif
end

请注意，使用 contact_create/delete 和/或 contact_activated 事件有不同的方式：只要两个部件的单元范围接触或重叠，就可以创建接触（参见 35.0 - 创建/删除接触（35.0 - Create/delete Contacts） 参考页）。接触在创建时初始为非活动状态，需要执行接触解析才能确定其活动状态。球颗粒-球网接触可能被创建并保持非活动状态，此时比赛必须继续进行。

对于球颗粒-球台接触，每次删除接触时，都会调用函数 表格接触（tablecontact）。如果发现球颗粒已触及球台，则相应选手的球拍会移动到根据抛物线抛体理论预测的新位置。

; 计算球拍的新位置并移动它！
fish define moverackets
  bp = ball.find(1)
  xvel = ball.vel.x(bp)
  zvel = ball.vel.z(bp)
  xpos = ball.pos.x(bp)
  zpos = ball.pos.z(bp)
  if xvel < 0
    if xpos > 0
      ball.vel(bp,1)=0
      ball.vel(bp,3)=0
      io.out("Fault!!")
    endif
    wp = wall.find(7)
    L = xTable(1,1) - xpos
  else
    if xpos < 0
      ball.vel(bp,1)=0
      ball.vel(bp,3)=0
      io.out("Fault!!")
    endif
    wp = wall.find(8)
    L = xTable(1,2) - xpos
  endif
  zM = (zvel/xvel)*L + (-9.81/2)*((L/xvel)^2)
  if zM > domain.min.z
    if zM < domain.max.z
      wall.pos.z(wp) = zM + zpos
    endif
  endif
end

;检查球与球桌的接触！
fish define tablecontact(ct)
    con = ct(1)
    ; 对于球-面片接触，contact.end1 指球，
    ; contact.end2 指面片
    if wall.group(wall.facet.wall(contact.end2(con))) == "table"
        moverackets
    endif
end
