用于 PFC3D6.0 的 CFD 模块

注意

  • 用于 PFC3D6.0 的耦合计算流体动力学（CCFD）附加模块已停止发布。已购买 CCFD 附加模块的现有客户仍可在 PFC3D6.0 中继续使用该附加模块。
  • CCFD 模块已更名为 CFD 模块。所有命令、FISH 内置函数和 Python 绑定均相同，只是前缀由“ccfd”改为“cfd”。
  • 本节介绍如何将新的 CFD 模块与第三方流体流动求解器配合使用。[CS：以下内容是否可考虑删除？] 原始 CCFD 模块文档可在此处获取：ref-pfc_ccfd_addon-。

计算流体动力学（CFD）模块允许在 PFC3D 中求解某些 流体-颗粒相互作用问题。CFD 模块不包含 CFD 求解器。 CFD 模块仅在 PFC 的三维版本中可用。该模块提供命令和 脚本函数，用于连接 CFD 软件并求解流体-颗粒 相互作用问题，其方法是体积平均的粗网格方法， 该方法最初由（Tsuji et. al, 1993）描述 [Tsuji1993]。 并非所有流体-颗粒相互作用问题都能用本模块提供的 粗网格方法求解。有关其他 DEM/流体耦合方法和 应用的概述，请参阅 （Furtney et. al, 2013） [Furtney2013]。

在粗网格方法中，描述流体流动的方程在一组 尺寸大于 PFC 颗粒的单元上进行数值求解。 流体对颗粒的作用力按局部方式分配给 每个颗粒，并基于该颗粒所占流体单元中的流体状态。 流体-颗粒相互作用力的公式在 实际孔隙率和雷诺数范围内是准确且平滑变化的 （湍流效应已包含在流体-颗粒 相互作用项中）。

相应的体积力以某个流体单元上的平均值形式 施加到流体上。孔隙率和流体的曳力由 每个流体单元中颗粒属性的平均值计算得到。双向 耦合通过周期性地在 PFC 与流体流动求解器之间 交换这些信息来实现。PFC 与流体流动软件 之间信息的同步与交换通常通过 TCP socket 通信完成。

用该方法可研究的流体流动结构的长度尺度 大于 PFC 颗粒。任何基于连续介质的 流体流动模型都可与 PFC 一起使用，包括 Navier-Stokes 方程、势流和 Euler 方程。PFC 所作的假设 为：(i) 流体单元大于 PFC 颗粒；(ii) 流体属性在流体单元上呈分段线性， 以及 (iii) 流体单元不发生移动。

该模块提供以下方法：

  • 读取流体网格，
  • 在每个流体单元中存储流体速度、流体压力、流体压力梯度、流体黏度和流体密度，
  • 计算孔隙率，以及
  • 在 PFC 循环过程中自动将流体-颗粒相互作用力施加到颗粒上。
