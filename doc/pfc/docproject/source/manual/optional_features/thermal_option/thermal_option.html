热学计算

PFC 的热学模块可模拟由 PFC 颗粒组成的材料中的瞬态热传导与储热，以及热致应变与热致力的产生。热学材料被表示为 热库（与每个力学体相关联）与热学接触（与每个力学 接触相关联）构成的网络。热流通过连接各热库的活动热学接触中的传导发生。辐射传热与对流 传热未包含在本公式中。热致应变通过在 PFC 材料中 改变颗粒尺寸而产生。力学接触模型也可计入热致力。

每个力学接触都关联一个热学接触，但其中只有一部分接触是活动的。默认情况下，如果 热学接触 所对应的力学接触是活动的，则该热学接触也是活动的。然而，若希望获得更大的灵活性， 可以用自定义准则 抑制热学接触。一旦指定了热学微观性质，后续的加载或损伤（以黏结 断裂的形式）将改变活动管道的数量，从而改变材料传导热量的能力。例如， 当黏结材料被压缩并形成新的活动接触时，宏观导热系数将会增大， 但当黏结 断裂、接触变为非活动时，宏观导热系数将会减小。
