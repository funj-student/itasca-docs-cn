命令

对热学墙进行操作。

注意

启用热学选项时，系统会为每面墙和每个面片关联一个热学扩展。 无法直接创建或删除热学墙或热学面片。相反，若创建或删除墙或面片， 则相应的热学墙或面片也会被创建或删除。

墙热学命令

wall thermal attribute
wall thermal extra
wall thermal group
wall thermal initialize
wall thermal list
wall thermal property

修改过的核心命令

  • wall thermal attribute command
  • wall thermal extra command
  • wall thermal group command
  • wall thermal initialize command
  • wall thermal list command
  • wall thermal property command
