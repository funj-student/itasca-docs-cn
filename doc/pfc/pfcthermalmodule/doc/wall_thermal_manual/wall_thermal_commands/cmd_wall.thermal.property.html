wall thermal property 命令

语法

wall thermal property s a<s1 a1...> <range>

为热学墙面片赋予表面性质。 值 a 赋予名称为 s 的表面性质。 可指定任意数量的名称—值对。

注意

热学墙面片性质是用于填充接触模型属性的表面性质。 它们不同于热学墙属性（使用 wall thermal attribute 命令修改）， 后者是热学墙的特征，例如 temperature 或 unbalpower。

用法示例

请注意区分 属性 与 性质！ 教程示例“属性与性质（Attributes and Properties）”详细讨论了这一问题。
