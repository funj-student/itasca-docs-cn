wall thermal list 命令

语法

wall thermal list <keyword> <range>

主要关键字：

显示属性（attribute） contact extra 分组（group） property

列出热学墙信息。 默认情况下，列出热学墙 ID、温度和固定条件。 使用 attribute 关键字列出所有热学墙属性。

注意

使用 设置列表精度命令（model precision） 命令可更改所列浮点值的精度。

attribute <s >

列出热学墙属性。若未给出 s，则列出可用属性。 若指定 s，则列出每面热学墙的该属性值。 属性是热学墙的特征，例如 temperature 和 unbalpower。 它们不同于表示表面条件并用于接触模型以描述相互作用的热学面片性质。

contact <all>

列出与某面热学墙的接触。 列出接触 ID、另一接触碎片 ID、接触类型、活动状态、抑制状态和接触模型。 默认情况下，仅列出活动接触。使用 all 关键字列出活动和非活动接触。

extra i

列出索引 i 处的额外变量。

group s

列出槽位 s 处的分组名称。

property <s >

列出热学墙性质。 若未给出 s，则列出每个热学墙面片的可用性质。 若指定 s，则列出每个热学墙面片的该性质值。

性质表示表面条件，用于接触模型以描述相互作用。 它们不同于属性，后者是热学墙的特征，例如 temperature 和 unbalpower。
