wall thermal attribute 命令

语法

wall thermal attribute <facet> keyword ... <range>

主要关键字：

温度（temperature）

设置热学墙属性的值。 此命令是 wall thermal initialize 命令的同义词。 可使用 wall thermal list 命令列出各个属性，所有热学墙属性均可可视化。 可选的 facet 关键字可与 temperature 关键字一起使用，以设置指定范围内面片的温度。

注意

与墙属性和性质类似，热学墙属性与热学墙性质之间存在根本区别。热学墙属性是热学墙的特征，例如 temperature。

temperature f <keyword>

temperature

add f

将 f 加到现有值上。

gradient v

在每个坐标轴方向上施加从原点开始的线性梯度。

gradient-x f

在 x 方向上施加从原点开始的线性梯度。

gradient-y f

在 y 方向上施加从原点开始的线性梯度。

gradient-z f

在 z 方向上施加从原点开始的线性梯度。

multiply f

将现有值乘以 f。

replace f

用 f 替换现有值。
