rblock tractions 命令

语法

rblock tractions keyword ... <range>

主要关键字：

接触活动（contact-active） 常数（constant） 方向 x（direction-x） 上覆荷载（overburden） ratio

计算与规定应力状态一致的刚性块体—刚性块体和刚性块体—面片接触处的作用力。 可指定恒定应力张量或重力应力。若指定重力且未指定均匀应力张量， 则计算包含重力的作用力；重力方向必须与某一全局轴重合。计算重力 上覆压力，并考虑非均匀密度和非均匀上边界。请注意，若接触模型支持参考间隙，则按其计算，使得当压缩力趋于 0 时，接触间隙与参考间隙之和也趋于 0。

contact-active b

指定是否为非活动接触设置力。若为 true（默认值），则仅为活动接触设置力。 若为 false，则为所有接触设置力，并且非活动接触可能被激活。

constant f1 f2 f3 f4 f5 f6 （仅 3 个分量 用于 2D）

设置恒定应力张量的分量。必须指定所有分量。三维中必须按 stress-xx、stress-yy、stress-zz、stress-xy、stress-sxz、stress-syz 的顺序指定 6 个参数。二维中必须按 stress-xx、stress-yy、stress-xy 的顺序指定 3 个参数。

direction-x v （3D 专用）

如果为 ratio 关键字提供两个参数，则可用此关键字指定体系采用的局部 \(x\) 方向。根据 \(x\) 方向和重力方向自动确定 \(y\) 方向，以构成正交归一坐标系。可能会调整 \(x'\) 方向，使其与重力方向垂直。默认的 \(x\) 方向为 (1,0,0)。不能与 constant 关键字同时使用。

overburden f

假定模型的竖直边界不代表地表，指定计入计算的上覆应力。默认值为 0.0。注意，压应力为负，因此此值通常为负。不能与 constant 关键字同时使用。

ratio f <:flt:'fy'> (3D ONLY)

确定竖向与水平应力的比值。两个水平应力均设为竖向应力乘以此值。若给出可选的第二个参数 y 向尺寸（fy），则局部 x 和 y 方向使用不同的比值。注意，此时使用 direction-x 关键字区分局部方向。不能与 constant 关键字同时使用。
