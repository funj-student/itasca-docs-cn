rblock dilate 命令

语法

rblock dilate <keyword> f <keyword> <range>

主要关键字：

keep-inertial relative

通过膨胀改变刚性块体圆角。刚性块体由核心形状表示，核心形状由{二维中线性 面片；三维中三角面片}组成。核心形状为凸、封闭且流形。当圆角 非零时，核心形状沿所有方向扩展一个指定半径的{二维中圆；三维中球}， 其中心经过核心形状外表面的所有点。圆角值 对应于该扩展{二维中圆；三维中球}的半径。圆角可减少 高密度堆积模型中的接触数量，并加快接触解析。

膨胀刚性块体是指核心形状保持不变，并在原始核心形状上增加圆角。 换言之，{二维中角点；三维中棱边和角点}被倒圆，每个面片平面沿法向向外（即 远离形心）移动圆角距离。这使刚性块体变大。 默认情况下，惯性性质调整为凸{二维中多边形；三维中多面体}的惯性性质，该凸形的各面 已沿面片法向向外平移圆角距离。若刚性块体 已有圆角，则将该圆角加到旧值上。

keep-inertial

膨胀时不对惯性性质进行调整。当圆角距离较小时，这可能有优势。

relative

圆角程度按 f 与和刚性块体尺寸相同的{二维中圆；三维中球}半径的乘积计算。
