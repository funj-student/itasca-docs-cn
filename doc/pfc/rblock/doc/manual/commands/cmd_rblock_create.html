rblock create 命令

语法

rblock create keyword ...

主要关键字：

长方体（box） 圆（circle） 圆锥（cone） 圆柱（cylinder） density 按几何集生成（from-geometry） 分组（group） ID 标识（id） 圆角（rounding） 球体（sphere） vertices

使用指定属性创建单个刚性块体。在创建刚性块体之前必须指定模型域。 该刚性块体不能用于复制。除非给出 density 关键字，否则创建时假定为单位密度。惯性属性根据刚性块体几何形状自动计算。

注意

  • 在创建刚性块体之前必须指定模型域。
  • 在循环计算期间，只能在循环点 0 之前创建刚性块体（即在计算时步时）。
box x 向最小值（fxmin ）x 向最大值（fxmax ）<fymin fymax <fzmin fzmax >> (z-components are 3D ONLY)

创建轴对齐盒体形状的刚性块体。在指定 x 方向的盒体范围后，若省略后续范围， 则使用最近指定的范围。

circle keyword ... (2D ONLY)

在二维中生成封闭圆形刚性块体。

position 位置矢量（vpos ）

圆心位置，默认值为原点。

radius 搜索半径（frad ）

圆半径，默认值为 1.0。

resolution 端边分辨率（fres ）

面片分辨率。设置面片数量使面片长度小于 端边分辨率（fres） * 搜索半径（frad）。默认情况下，端边分辨率（fres） = 0.1。

cone keyword ... (3D only)

在三维中创建圆锥形刚性块体。

axis v3

圆锥对称轴的方向，从基点出发指向正 z 方向（默认）。

base v3

圆锥底面（即底端中心）的位置，默认为原点。

height 高度系数（fh ）

圆锥高度。这是从底面位置到顶点（若为截锥，则到顶端中心）的距离。默认情况下，高度系数（fh） = 1。

radius 底部摩擦（fbot ）<ftop >

圆锥半径。默认情况下，底部摩擦（fbot） = 1.0，顶部摩擦（ftop） = 0.0，表示创建圆锥。若 顶部摩擦（ftop） > 0.0，则创建截锥（即尖端被切去的圆锥）。此时，底部摩擦（fbot） 为底面位置处的底部半径，顶部摩擦（ftop） 为沿对称轴距底面位置 高度系数（fh） 处的截锥顶部半径。

resolution 端边分辨率（fres ）

圆锥端部边缘的分辨率。设置端部边缘数量使边缘长度小于 端边分辨率（fres） * 底部摩擦（fbot）。若要生成 顶部摩擦（ftop） > 0 的截锥，则端部边缘长度小于 端边分辨率（fres） * min(底面半径（fradbot）, 顶部摩擦（ftop）)。默认情况下，端边分辨率（fres） = 0.1。

cylinder keyword ... (3D Only)

在三维中创建圆柱形刚性块体。

axis v3

圆柱对称轴的方向，从基点出发。

base v3

圆柱底面（即底端中心）的位置，默认为原点。

height 高度系数（fh ）

圆柱高度。这是从底面位置到顶端中心的距离。默认情况下，高度系数（fh） = 1。

radius 搜索半径（frad ）

圆柱半径，即从对称轴到侧面的距离。

resolution 端边分辨率（fres ）

圆柱两端边缘的分辨率。端边数目设定为使边长小于 端边分辨率（fres） * 搜索半径（frad）。默认 端边分辨率（fres） = 0.1。

density f

刚性块体密度，默认值为 1.0。

from-geometry <set > <range>

由几何集中多边形的顶点创建刚性块体。若未提供几何集，则使用当前几何集。可选范围应用于指定几何集中的多边形。

group s <slot slot > ...

对于新建的刚性块体，槽位 槽位（slot） 处的分组名称设置为 s。 若未指定 slot，则槽位 默认（Default） 处的分组名称设置为 s。

id i

刚性块体 ID。若未指定，则使用下一个可用 ID。

rounding <relative> f

引入刚性块体圆角。刚性块体由核心形状表示，核心形状由{二维中线性 面片；三维中三角面片}组成。核心形状为凸、封闭且流形。当圆角 非零时，核心形状沿各方向扩展一个指定半径的{二维中圆；三维中球}， 其中心经过核心形状外表面的所有点。圆角值 对应于该扩展{二维中圆；三维中球}的半径。若给出 relative 关键字， 则圆角按 f 与和刚性块体尺寸相同的{二维中圆；三维中球}半径的乘积计算。 圆角改变时，惯性性质也随之改变。

sphere keyword ... (3D ONLY)

在三维中创建球形刚性块体。球体通过细化二十面体（即由 20 个相同的等边三角形组成的球面）生成，使边长小于 resolution 关键字定义的长度。

position 位置矢量（vpos ）

球体形心位置，默认值为原点。

radius 搜索半径（frad ）

球体半径，默认值为 1.0。

resolution 端边分辨率（fres ）

面片边缘的分辨率。设置面片数量使边缘长度小于 端边分辨率（fres） * 搜索半径（frad）。默认情况下，端边分辨率（fres） = 0.1。

vertices v1 v2 ...

指定刚性块体的顶点。计算输入点的凸包，并由该凸包创建刚性块体。
