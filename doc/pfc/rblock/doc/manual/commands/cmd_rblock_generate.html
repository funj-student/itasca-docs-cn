rblock generate 命令

语法

rblock generate keyword ... <range>

主要关键字：

方位角（azimuth） 长方体（box） diameter density 高程（elevation） FISH 分布（fish-distribution） FISH 大小（fish-size） gauss 分组（group） ID 标识（id） 数量（number） size 模板（templates） 倾角（tilt） 尝试次数（tries）

生成无重叠的刚性块体。当达到目标刚性块体数量，或达到无重叠放置刚性块体的尝试次数时，该过程停止。默认情况下，刚性块体的位置和尺寸在整个模型域内按均匀分布抽取。因此，生成的刚性块体集合受随机数生成器状态的影响（见 设置随机数种子命令（model random））。刚性块体尺寸也可通过 gauss 关键字从高斯分布中抽取。单条 rblock generate 命令可使用多个刚性块体模板。可选范围在每次生成时应用于每个刚性块体；若刚性块体不落在该范围内，则不会添加到模型，也不影响停止准则。此命令与 rblock distribute 命令不同：后者在达到目标孔隙率之前不考虑重叠地分布刚性块体。

注意

  • 在生成刚性块体之前必须指定模型域。
  • 在循环计算期间，只能在循环点 0 之前创建刚性块体（即在计算时步时）。
azimuth 最小方位角系数（fazlow ）最大方位角系数（fazhi ）

用于随机旋转刚性块体模板的方位角范围。方位角旋转是绕{二维中平面外方向；三维中 z 轴}的右手旋转，单位为度。

box x 向最小值（fxmin ）x 向最大值（fxmax ）y 向最小值（fymin ）y 向最大值（fymax ）z 向最小值（fzmin ）z 向最大值（fzmax ）(z-components are 3D ONLY)

刚性块体将完全落在该盒体内，因此不会与盒体的面或边重叠。默认情况下，盒体为模型域。

diameter

指定用于缩放刚性块体的线性尺寸为{二维中圆盘；三维中球体}的体积等效直径。

density 密度系数（fdens ）

刚性块体密度，默认值为 1。

elevation 长宽比系数（fellow ）最大伸长系数（felhi ）(3D ONLY)

用于随机旋转刚性块体模板的仰角范围。仰角旋转是绕 y 轴的右手旋转，单位为度。

fish-distribution 距离系数（fdist ）a1...an

刚性块体尺寸从 FISH 函数 距离系数（fdist） 所表示的分布中抽取。 函数参数可按 指定，尽管不需要任何函数参数。 该 FISH 函数必须返回表示刚性块体尺寸的浮点值。 不能同时使用 gauss 或 size 关键字指定 FISH 分布。

fish-size 最大尺寸值（fsize ）

生成时用于缩放刚性块体的尺寸可由名称为 最大尺寸值（fsize） 的 FISH 函数指定。 该 FISH 函数的返回值应为刚性块体尺寸的线性度量，且函数应接受 一个刚性块体指针参数。

gauss <fcutoff >

指定刚性块体尺寸从高斯分布中选取，其均值为 (最小尺寸系数（fsizelow） + 最大尺寸系数（fsizehi）)/2， 标准差为 (最大尺寸系数（fsizehi） - 最小尺寸系数（fsizelow）)/2。 可选的 截断系数（fcutoff）（默认值 0.1）乘以 最小尺寸系数（fsizelow） 构成允许的最小尺寸。

group s <slot slot > ...

指定生成的刚性块体在槽位 槽位（slot） 处赋予分组名称 s。 若未指定 slot 关键字，则将分组名称赋予槽位 默认（Default）。

id 最小 ID（idlow ）<idhi >

生成的第一个刚性块体的 ID 设置为 最小 ID（idlow），默认情况下为下一个可用 ID。若指定 最大 ID（idhi），则用于计算要生成的刚性块体数量。刚性块体 ID 按顺序选取。

number 裂隙总数（inum ）

指定要生成的刚性块体数量。

size 最小尺寸系数（fsizelow ）<fsizehi >

指定生成期间使用的尺寸范围。若未指定 最大尺寸系数（fsizehi），则 最大尺寸系数（fsizehi） = 最小尺寸系数（fsizelow）。默认情况下，最大尺寸系数（fsizehi） = 最小尺寸系数（fsizelow） = 1.0。不能与 fish-distribution 关键字同时给出。

templates 裂隙总数（inum ）状态名称（stname ）<f > ...

指定要输入的刚性块体模板对数量 裂隙总数（inum），随后给出这些模板对。模板对由刚性块体模板名称和生成期间所用刚性块体模板的相对比例组成。各相对比例除以比例总和得到百分比。若未指定百分比，则从给定模板中等概率抽取刚性块体模板。若未指定模板，则从所有刚性块体模板中随机选择。

tilt 最小倾角系数（ftiltlow ）最大倾角系数（ftilthi ）(3D ONLY)

用于随机旋转刚性块体模板的倾斜角范围。倾斜旋转是绕 x 轴的右手旋转，单位为度。

tries 尝试次数索引（itries ）

用指定数量的刚性块体填充指定区域的尝试次数。默认情况下，尝试次数索引（itries） = 20,000。
