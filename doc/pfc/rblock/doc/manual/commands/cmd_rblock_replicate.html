rblock replicate 命令

语法

rblock replicate s keyword ...

主要关键字：

角度（angle） 轴（axis） density diameter FISH 大小（fish-size） 分组（group） ID 标识（id） original-position position position-x position-y position-z size

由名称为 s 的模板复制刚性块体。若未给出尺寸度量，则保留刚性块体模板体积。若未给出 density 关键字，则保留刚性块体模板密度。

注意

  • 在复制刚性块体之前必须指定模型域。
  • 复制后的刚性块体必须完全位于模型域内。
  • 在循环计算期间，只能在循环点 0 之前创建刚性块体（即在计算时步时）。
angle 角度系数（fang ）

绕某轴旋转刚性块体的角度（度），遵循右手定则。若未指定角度，则不发生旋转。二维中，旋转绕平面外方向逆时针进行。

axis 轴矢量（vaxis ）(3D ONLY)

绕某轴旋转刚性块体。若未指定轴，则不发生旋转。

density 密度系数（fden ）

刚性块体密度。

diameter 直径系数（fdiam ）

体积设置为{二维中单位厚度圆盘；三维中球体}的体积，其直径为 直径系数（fdiam）。

fish-size 源文件名（sfname ）贯通阈值（fval ）

使用名称为 源文件名（sfname） 的 FISH 函数将刚性块体模板的“尺寸”缩放为 贯通阈值（fval）。该 FISH 函数必须接受一个刚性块体指针参数，并返回表示刚性块体尺寸线性度量的浮点值。

group s <slot slot >

新建刚性块体的分组槽位 槽位（slot） 设置为 s。 若未指定 slot，则将 s 赋予分组槽位 默认（Default）。

id ID 标识（id ）

刚性块体 ID，默认情况下为下一个可用 ID。

original-position

指定将刚性块体形心设置为刚性块体模板创建时的原始位置。

position 位置矢量（vpos ）

刚性块体位置，默认值为原点。该关键字不能与 original-position 关键字同时给出。

position-x 浮点 x 向位置（fposx ）

刚性块体位置的 x 分量，默认值为 0。该关键字不能与 original-position 关键字同时给出。

position-y y 向位置系数（fposy ）

刚性块体位置的 y 分量，默认值为 0。该关键字不能与 original-position 关键字同时给出。

position-z z 向位置系数（fposz ）(3D ONLY)

刚性块体位置的 z 分量，默认值为 0。该关键字不能与 original-position 关键字同时给出。

size f

将刚性块体缩放至{二维中面积 f；三维中体积 f}；
