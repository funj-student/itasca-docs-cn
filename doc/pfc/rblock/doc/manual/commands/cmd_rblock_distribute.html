rblock distribute 命令

语法

rblock distribute keyword ... <range>

主要关键字：

分组（bin） 长方体（box） diameter FISH 大小（fish-size） 分组数量（number-bins） porosity 分辨率（resolution）

分布允许重叠的刚性块体。当达到目标孔隙率时该过程停止。默认情况下，刚性块体的位置和尺寸在整个模型域内按均匀分布抽取。因此，生成的刚性块体集合受随机数生成器状态的影响（见 设置随机数种子命令（model random））。刚性块体尺寸也可通过 gauss 关键字从高斯分布中抽取。可指定多个刚性块体分布，每个分布具有各自的尺寸范围、体积分数和唯一刚性块体模板。可选范围在每次生成时应用于每个刚性块体；若刚性块体不落在该范围内，则不会添加到模型，也不影响停止准则。此命令与 rblock generate 命令不同：后者从单一分布中选择刚性块体尺寸，并在无重叠的情况下生成刚性块体，直到达到目标刚性块体数量或达到放置刚性块体的尝试次数。

注意

  • 在生成刚性块体之前必须指定模型域。
  • 此操作很可能导致明显的刚性块体重叠。
  • 在循环计算期间，只能在循环点 0 之前创建刚性块体（即在计算时步时）。
bin 分组索引（ibin ）keyword ...

指定 bin 分组索引（ibin） 的分布属性。可指定任意数量的分布，每个分布具有半径范围、体积分数和分布类型。所有分布的体积分数之和必须为 1。

azimuth 最小方位角系数（fazlow ）最大方位角系数（fazhi ）

用于随机旋转刚性块体模板的方位角范围。方位角旋转是绕{二维中平面外方向；三维中 z 轴}的右手旋转，单位为度。

density 密度系数（fdens ）

刚性块体密度，默认值为 1。

elevation 长宽比系数（fellow ）最大伸长系数（felhi ）(3D ONLY)

用于随机旋转刚性块体模板的仰角范围。仰角旋转是绕 y 轴的右手旋转，单位为度。

fish-distribution FISH 字符串（sfish ）a1...an

刚性块体尺寸从 FISH 函数 FISH 字符串（sfish） 所表示的分布中抽取。函数参数可按 指定，尽管不需要任何函数参数。该 FISH 函数必须返回表示刚性块体尺寸的浮点值。不能同时使用 gauss 或 size 关键字指定 FISH 分布。

gauss <fcutoff >

指定刚性块体尺寸从高斯分布中选取，其均值为 (最小半径系数（fradlow） + 最大半径系数（fradhi）)/2，标准差为 (最大半径系数（fradhi） - 最小半径系数（fradlow）)/2。可选的 截断系数（fcutoff）（默认值 0.1）乘以 最小半径系数（fradlow） 构成允许的最小尺寸。

group s <slot slot >

指定生成的刚性块体在槽位 槽位（slot） 处赋予分组名称 s。 若未指定 slot 关键字，则将分组名称赋予槽位 默认（Default）。

size 最小尺寸系数（fsizelow ）<fsizehi >

指定生成期间使用的尺寸范围。若未指定 最大尺寸系数（fsizehi），则 最大尺寸系数（fsizehi） = 最小尺寸系数（fsizelow）。默认情况下，最大尺寸系数（fsizehi） = 最小尺寸系数（fsizelow） = 1.0。不能与 fish-distribution 关键字同时给出。

template 状态名称（stname ）

要使用的刚性块体模板的名称。

tilt 最小倾角系数（ftiltlow ）最大倾角系数（ftilthi ）(3D ONLY)

用于随机旋转刚性块体模板的倾斜角范围。倾斜旋转是绕 x 轴的右手旋转，单位为度。

volume-fraction 体积分数系数（fvfrac ）

该分布中刚性块体的体积分数。所有分布的体积分数之和必须为 1。

box x 向最小值（fxmin ）x 向最大值（fxmax ）y 向最小值（fymin ）y 向最大值（fymax ）z 向最小值（fzmin ）z 向最大值（fzmax ）(z-components are 3D ONLY)

刚性块体将完全落在该盒体内，因此不会与盒体的面或边重叠。默认情况下，盒体为模型域。

diameter

指定用于缩放刚性块体的线性尺寸为{二维中圆盘；三维中球体}的体积等效直径。

fish-size 源文件名（sfname ）

生成时用于缩放刚性块体的尺寸可由名称为 源文件名（sfname） 的 FISH 函数指定。该 FISH 函数的返回值应为刚性块体尺寸的线性度量，且函数应接受一个刚性块体指针参数。

number-bins 裂隙总数（inum ）

用于生成集合体的分布数量。

porosity 孔隙率系数（fporos ）

最终孔隙率设置为 孔隙率系数（fporos）。默认情况下，孔隙率系数（fporos） = {二维为 0.16；三维为 0.359}，对应于{二维圆盘；三维球体}紧密单分散堆积的孔隙率。

resolution 端边分辨率（fres ）

可选分辨率，可用作每个生成刚性块体尺寸的乘数。默认情况下，端边分辨率（fres） = 1.0。
