rblock construct 命令

语法

rblock construct keyword ...

主要关键字：

density 从球体（from-balls） 按几何集生成（from-geometry） 分组（group） 圆角（rounding）

构建一组刚性块体。刚性块体可构建为填充{二维中一个多边形或多边形集合；三维中一个体或体集合}，或基于非协调的 Voronoi 或 Delaunay 单元构建。三维中该过程可能产生一定重叠。此外，圆角会引入初始重叠。因此，刚性块体构建完成后，可能需要进行增量法向力计算。

注意

  • 在创建刚性块体之前必须指定模型域。
  • 在循环计算期间，只能在循环点 0 之前创建刚性块体（即在计算时步时）。
density f

刚性块体密度，默认值为 1.0。

from-balls <keyword>

使用 Voro++ 由球颗粒构建刚性块体。假定球颗粒填充一个轴对齐盒体；球颗粒的最大范围 用作 Voronoi 剖分的边界。可使用可选的 polydisperse 关键字指定 是否计算加权 Voronoi 剖分（Laguerre 剖分）。该操作后不删除球颗粒。

polydisperse b

指定是否计算加权 Voronoi 剖分（Laguerre 剖分）。加权 Voronoi 剖分使用球颗粒半径对单元边界加权，使 Voronoi 单元尺寸更接近球颗粒尺寸分布。默认情况下不计算加权 Voronoi 剖分。

periodicity x 向尺寸（bx ）按（by ）单元指针（bz ）(z-component is 3D ONLY)

指定剖分时是否在各方向采用周期边界条件。

from-geometry <set > keyword ... <range>

由几何集 set 构建刚性块体。若未提供几何集，则使用当前几何集。 除非给出 voronoi 或 delaunay 关键字，否则将几何集中的多边形 按指定的最小和最大边长剖分为三角形（默认）或四边形单元。可选范围应用于几何集中的多边形。 二维中，由这些单元构建刚性块体。 三维中，以此简化表面为基础构建四面体或六面体刚性块体。 若给出 voronoi 或 delaunay 关键字，则将几何集中的节点 用作 Delaunay 三角剖分的种子，并由 Voronoi 或 Delaunay 单元构建刚性块体。

delaunay

由 Delaunay 单元构建刚性块体。几何节点用作 Delaunay 三角剖分的种子。

hexahedral (3D ONLY)

指定所得刚性块体主要为六面体。这通常会产生较少的刚性块体来离散给定体积，但可能导致一定重叠。 若给出 voronoi 或 delaunay 关键字，则无效果。

internal (3D ONLY)

指定存在背景网格以控制网格单元尺寸。对于几何集中的每个节点，第一个额外变量必须是指定目标边长的浮点值。网格随后尽量贴合该内部背景网格。仅可在生成四面体和六面体时使用。

minimum-edge f

三角形或四边形表面单元的最小边长。二维中，它对应于 刚性块体的最小边长。 若给出 voronoi 或 delaunay 关键字，则无效果。

maximum-edge f

三角形或四边形表面单元的最大边长。二维中，它对应于 刚性块体的最大边长。 若给出 voronoi 或 delaunay 关键字，则无效果。

patch-angle-tolerance f

用于以度为单位界定简化表面中面片块（相连三角形组）的参数。 相邻三角形之间的夹角大于该值时，将在两个面片块之间划出边界。 较小值倾向于产生大量小面片块，最终离散接近初始表面，但质量可能较差（即所得表面单元的长宽比可能较大）。 较大值倾向于产生较少、较大的面片块。默认值为 20 度， 该参数的最大值可考虑为 45 度。 若给出 voronoi 或 delaunay 关键字，则无效果。

quadrilateral f <all>

指定表面单元主要呈四边形（即具有 4 个节点）。 若给出 all 关键字，则所有表面单元均为四边形。这可能导致 表面单元长宽比较大。 若给出 voronoi 或 delaunay 关键字，则无效果。

tetrahedral (3D ONLY)

指定所得刚性块体为四面体。这是默认行为，不能 与 quadrilateral 关键字同时给出。 若给出 voronoi 或 delaunay 关键字，则无效果。

voronoi

由 Voronoi 单元构建刚性块体。几何节点用作 底层 Delaunay 三角剖分的种子。请注意，Voronoi 剖分是非协调的， 仅保留所有单元节点均位于域内且位于由种子几何节点构成的轴对齐包围盒内的 Voronoi 单元。

group s <slot slot > ...

对于新建的刚性块体，槽位 槽位（slot） 处的分组名称设置为 s。 若未指定 slot，则槽位 默认（Default） 处的分组名称设置为 s。

rounding f <relative>

引入刚性块体圆角。刚性块体由核心形状表示，核心形状由{二维中线性 面片；三维中三角面片}组成。核心形状为凸、封闭且流形。当圆角 非零时，核心形状沿各方向扩展一个指定半径的{二维中圆；三维中球}， 其中心经过核心形状外表面的所有点。圆角值 对应于该扩展{二维中圆；三维中球}的半径。若给出 relative 关键字， 则圆角按 f 与和刚性块体尺寸相同的{二维中圆；三维中球}半径的乘积计算。 圆角改变时，惯性性质也随之改变。
