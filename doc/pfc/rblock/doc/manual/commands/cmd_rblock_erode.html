rblock erode 命令

语法

rblock erode <keyword> f <range>

主要关键字：

minimum-distance relative skip-errors

通过侵蚀改变刚性块体圆角。刚性块体由核心形状表示，核心形状由{二维中线性 面片；三维中三角面片}组成。核心形状为凸、封闭且流形。当圆角 非零时，核心形状沿所有方向扩展一个指定半径的{二维中圆；三维中球}， 其中心经过核心形状外表面的所有点。圆角值 对应于该扩展{二维中圆；三维中球}的半径。圆角可减少 高密度堆积模型中的接触数量，并加快接触解析。

侵蚀尝试产生新的核心形状，使圆角后的刚性块体尺寸与 先前的核心形状基本相同。该过程 通常产生面片平面不变、但{二维中角点；三维中棱边 和角点}被倒圆的圆角刚性块体。对于高密度堆积的刚性块体集合，这在计算上可能非常有利，可剔除大量活动接触。 侵蚀通过将核心形状的所有面片沿面片法向向内（即朝向形心）平移圆角距离来实现。若原始核心形状具有较好的 径向对称性，且圆角相对于面片到形心的距离较小，则侵蚀所得核心形状的表面拓扑 （即面片数量和连接关系）与原始核心形状相同。但在某些情况下，侵蚀可能产生 不同拓扑。此时，为保持表面拓扑不变，计算新核心形状的主长宽比，并沿主长宽比方向拉伸旧核心形状 以匹配新核心形状的长宽比。无论哪种情况，侵蚀刚性块体时惯性性质均不改变。 若指定圆角距离过大，则无法进行侵蚀，因为会产生负体积 刚性块体（即面片被平移越过形心）。 此时将发生错误，除非给出 skip-errors 关键字，此时改为发出警告。 若刚性块体先前已有圆角，则侵蚀核心形状，并将旧圆角加到新圆角上。

minimum-distance

圆角程度按 f 与面片到刚性块体形心最小距离的乘积计算。对于非常薄的 刚性块体，这比使用 relative 选项更有效。

relative

圆角程度按 f 与和刚性块体尺寸相同的{二维中圆；三维中球}半径的乘积计算。

skip-errors

若指定圆角距离过大，则无法进行侵蚀，因为会产生负体积 刚性块体（即面片被平移越过形心）。该关键字指定 发出警告而非错误。
