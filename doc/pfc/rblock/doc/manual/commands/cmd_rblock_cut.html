rblock cut 命令

语法

rblock cut keyword ... <range>

主要关键字：

长宽比（aspect-ratio） 裂隙（fractures） 分组（group） 分组裂隙（group-fractures） 分组侧（group-sides） 相交盒（intersects-box） 保留接触（keep-contacts） 平面（plane） 持久性（persistence） 移除薄片（remove-sliver） size 薄片分组（sliver-group） 薄片完整（sliver-intact） 移除薄片（sliver-remove）

切割范围内的刚性块体。这是通过用平面切片切割核心形状来实现的。 既可按单个平面切割，也可按 DFN 中的裂隙切割。由于块体为凸体，按单个平面或裂隙切割 只能产生两个凸刚性块体。提供了若干准则来确定是否保留切割产生的刚性块体； 不满足准则的刚性块体视为薄片。薄片的存在可能对性能产生负面影响，因此应尽量避免。 薄片准则包括：切割点与切割平面上指定点的距离、所得块体的长宽比、所得块体的最小{二维中面积；三维中体积}， 或所得块体{二维中面积；三维中体积}与原始块体{二维中面积；三维中体积}的最小比值。薄片可被删除，或者若检测到薄片， 可将切割视为不成功并保留原始刚性块体（见 sliver-remove 关键字）。还加入了全局持续性 （见 persistence 关键字），以便按概率确定切割是否成功。

注意

  • 仅切割核心形状。
  • 在循环计算期间，只能在循环点 0 之前切割刚性块体（即在计算时步时）。
aspect-ratio f

指定切割所得刚性块体产生薄片的最大长宽比。 默认值为 100。

fractures <s > <keyword ...>

使用裂隙切割刚性块体。若给出可选的 DFN 名称 s，则仅使用指定 DFN 中的裂隙。默认情况下，所有切割顶点都必须落在某个裂隙内，切割才算成功。这等价于要求裂隙必须切穿整个块体。 可选的 throughgoing 关键字指定：只要裂隙与刚性块体相交，就切割该块体。因此，完全位于刚性块体内部的小裂隙也可切割该块体。 可选的 infinite-plane 关键字指定将每条裂隙视为无限平面。 裂隙按面积从大到小逐一处理。

infinite-plane

将每条裂隙视为无限平面，切割整个模型。不能与 throughgoing 关键字同时给出。

throughgoing

裂隙切割与其相交的刚性块体。不能与 Infinite-plane 关键字同时给出。

group s <slot slot >

对于被切割的刚性块体，分组槽位 槽位（slot） 设置为 s。 若未指定 slot，则将 s 赋予分组槽位 默认（Default）。

group-fractures <keyword ...>

应用来自裂隙的分组。

sides b

若 b 为真，则根据块体形心位于切割裂隙上方还是下方，将裂隙中的分组名称附加 “_above” 或 “_below”。默认情况下 b = false。

slot 槽位（slot ）

使用槽位 槽位（slot） 中的裂隙分组名称设置刚性块体分组。

group-sides s <slot slot >

根据块体形心位于切割平面或裂隙上方还是下方，将槽位 槽位（slot） 设置为 s 并附加 “_above” 或 “_below”。 若未指定 slot，则将 s 赋予分组槽位 默认（Default）。

intersects-box x 向最小值（fxmin ）x 向最大值（fxmax ）<fymin fymax <fzmin fzmax >> (z-components are 3D ONLY)

将切割限制于与指定盒体相交的刚性块体。在指定 x 方向的盒体范围后，若省略后续范围， 则使用最近指定的范围。

keep-contacts b

切割刚性块体时，所有现有接触将被删除，并可能在原先存在接触的位置创建新接触。默认情况下，根据 接触模型分配表（CMAT） 的设置， 在这些新接触处插入新的接触模型。当 b = 真值（true） 时，在可能的情况下保留先前的接触模型。切割块体之间的接触 还设置法向接触力。

plane keyword ...

用单个平面切割范围内的所有块体。

normal 法向速度（vnorm ）

指定平面法向。默认情况下，法向指向{二维中 y 方向； 三维中 z 方向}正方向。

point 顶点指针（vpt ）

指定平面上的一点。默认情况下，平面上的点为原点。

radius f

指定切割半径。若从平面上的点（由 point 关键字指定）到平面与 刚性块体相交所得任一点的距离大于 f，则切割不成功。

persistence f

指定切割的持续性。若切割成功，则选取一个均匀随机数 来模拟持续性；若该值大于或等于 f，则放弃切割 并保留原始刚性块体。默认值为 1.0。

remove-sliver b

指定遇到薄片时的行为。若满足以下任一条件，则切割视为产生薄片： 1) 所得刚性块体之一的长宽比大于 aspect-ratio 关键字指定的值；2) 所得刚性块体之一的{二维中面积；三维中体积} 与原始刚性块体的比值小于 size relative 关键字指定的值； 或 3) 所得刚性块体之一的{二维中面积；三维中体积}小于 size absolute 关键字 指定的值。若检测到薄片条件，则可删除作为薄片的块体（若 b 为 真值（true））， 或视为切割不成功并保留原始刚性块体（若 b 为 假值（false））。默认情况下 删除薄片。

size keyword

指定切割被视为成功的尺寸参数。

absolute f

指定切割所得刚性块体产生薄片的绝对最小{二维中面积；三维中体积}。 默认值为 0.0。

relative f

指定所得刚性块体之一的{二维中面积；三维中体积}与原始刚性块体的相对比值达到多少时产生薄片。 若{二维中面积；三维中体积}比值小于 f，则产生薄片。 默认该值为 0.05。

sliver-group s <slot slot >

对于被判定为薄片的切割刚性块体，分组槽位 槽位（slot） 设置为 s。 若未指定 slot，则将 s 赋予分组槽位 默认（Default）。 若使用 sliver-intact 关键字保持刚性块体完整，则该分组将赋予所有原本会因切割而产生薄片的完整刚性块体。

sliver-intact b

指定遇到薄片时的行为。若满足以下任一条件，则切割视为产生薄片： 1) 所得刚性块体之一的长宽比大于 aspect-ratio 关键字指定的值；2) 所得刚性块体之一的{二维中面积；三维中体积} 与原始刚性块体的比值小于 size relative 关键字指定的值； 或 3) 所得刚性块体之一的{二维中面积；三维中体积}小于 size absolute 关键字 指定的值。若检测到薄片条件，则当 b 为 真值（true） 时， 切割视为不成功并保留原始刚性块体。该关键字不应与 sliver-remove 关键字同时使用。

sliver-remove b

指定遇到薄片时的行为。若满足以下任一条件，则切割视为产生薄片： 1) 所得刚性块体之一的长宽比大于 aspect-ratio 关键字指定的值；2) 所得刚性块体之一的{二维中面积；三维中体积} 与原始刚性块体的比值小于 size relative 关键字指定的值； 或 3) 所得刚性块体之一的{二维中面积；三维中体积}小于 size absolute 关键字 指定的值。若检测到薄片条件，则可删除作为薄片的块体（若 b 为 真值（true））， 或保留薄片（若 b 为 假值（false））。 默认情况下删除薄片。该关键字不应与 sliver-intact 关键字同时使用。
