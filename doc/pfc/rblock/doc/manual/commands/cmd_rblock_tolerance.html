rblock tolerance 命令

语法

rblock tolerance keyword ...

主要关键字：

常数（constant）    extent    velocity

设置接触检测容差。刚性块体插入单元空间的 范围尺寸为最小范围尺寸加上以下各项之和的两倍：1) 最大 相互作用距离；2) 常数接触检测容差（constant - 默认 0）；3) 所有方向上最小范围的最大长度乘以范围容差 （extent - 默认 \(\frac{1}{32}\)）；4) 平动速度的最大分量乘以 速度容差（velocity - 默认 0）。每当刚性块体自上次映射到单元空间以来沿任一方向累计平移该和值时， 将重新映射到单元空间中。当任何碎片（即球颗粒、刚性簇子颗粒、 刚性块体或面片）的扩展范围重叠时，可创建接触。 更多细节见“30.0 - 更新空间搜索数据结构（30.0 - Update Spatial Searching Data Structures）”和“35.0 - 创建/删除接触（35.0 - Create/delete Contacts）”中循环操作的说明。

注意

在恢复模型之后，必须先调用 clean，然后才能 修改范围容差。

constant 接触容差（fctol ）<range>

指定常数接触检测容差。该容差按每个刚性块体分别指定。

extent 边容差（fetol ）

指定范围接触检测容差。这是所有刚性块体的全局设置。

velocity 体积容差（fvtol ）

指定速度接触检测容差。这是所有刚性块体的全局设置。
