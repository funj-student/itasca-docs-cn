命令

对全局 CFD 设置进行操作。

CFD 命令

cfd buoyancy
启用／停用浮力项。
cfd coupling
启用／停用 PFC 耦合。
cfd cycling
设置 PFC 循环状态。
cfd interval
指定更新间隔。
cfd list
列出 CFD 设置。
cfd porosity
设置孔隙率计算模式。
cfd read
从文件中读取流体网格或流体属性。
cfd term
修改曳力计算中使用的项。
cfd update
更新孔隙率、颗粒施加的力以及曳力。

注意

本节未记录的若干命令在 CCFD 附加组件文档 CCFD 附加组件命令（CCFD Add-on Commands） 中描述。这些命令 是 CCFD 附加组件专用的。

  • cfd buoyancy command
  • cfd interval command
  • cfd read command
  • cfd term command
  • cfd list command
  • cfd update command
  • cfd coupling command
  • cfd porosity command
