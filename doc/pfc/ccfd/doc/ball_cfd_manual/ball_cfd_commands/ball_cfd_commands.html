命令

对 CFD 球颗粒进行操作。

注意

启用 CFD 选项时，系统会为每个球颗粒关联一个 CFD 扩展。 无法直接创建或删除 CFD 球颗粒。取而代之的是，若创建或删除球颗粒，则相应的 CFD 球颗粒 也会被创建或删除。

球颗粒 CFD 命令

ball cfd attribute
ball cfd extra
ball cfd group
ball cfd history
ball cfd initialize
ball cfd list

修改过的核心命令

  • ball cfd attribute command
  • ball cfd extra command
  • ball cfd group command
  • ball cfd history command
  • ball cfd initialize command
  • ball cfd list command
