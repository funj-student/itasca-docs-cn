clump cfd attribute 命令

语法

clump cfd attribute keyword ... <range>

主要关键字：

力（force）    porosity

设置刚性团簇 CFD 属性的值。此命令是 clump cfd initialize 命令的同义词。 各个属性可使用 clump cfd list 命令列出，所有刚性团簇 CFD 属性 均可可视化。

force v <keyword>

流体施加于刚性团簇的力，即曳力。

add f

将 f 加到现有值上。

gradient v

在每个坐标轴方向上施加从原点开始的线性梯度。

gradient-x f

在 x 方向上施加从原点开始的线性梯度。

gradient-y f

在 y 方向上施加从原点开始的线性梯度。

gradient-z f

在 z 方向上施加从原点开始的线性梯度。

multiply f

将现有值乘以 f。

replace f

用 f 替换现有值。

porosity b

孔隙率贡献模式。若为 真值（true）（默认值），则刚性团簇对其关联的 CFD 单元的孔隙率有贡献。
