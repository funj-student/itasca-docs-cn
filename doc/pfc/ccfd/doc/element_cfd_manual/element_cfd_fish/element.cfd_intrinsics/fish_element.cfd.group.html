element.cfd.group

语法

s = element.cfd.group(e<,i>)
element.cfd.group(e<,i>) = s

获取/设置 CFD 单元分组。

返回值：

s - 组名
接受：

s - 组名
参数：

b - CFD 单元指针

i - 可选的分组槽位。若未提供，则 i 等于 1。
