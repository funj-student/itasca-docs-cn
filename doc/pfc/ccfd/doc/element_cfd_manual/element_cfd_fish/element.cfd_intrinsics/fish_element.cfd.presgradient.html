element.cfd.presgradient

语法

向量访问

v = element.cfd.presgradient(e<,i>)
element.cfd.presgradient(e<,i>) = v

获取/设置 CFD 单元的压力梯度。

返回值：

v - CFD 单元压力梯度向量或分量
接受：

v - CFD 单元压力梯度向量或分量
参数：

e - CFD 单元指针

i - 可选的向量分量

分量访问

f = element.cfd.presgradient.x(e)
element.cfd.presgradient.x(e) = f

获取/设置 CFD 单元压力梯度的 x 分量。

返回值：f - CFD 单元压力梯度向量的 x 分量
接受：f - CFD 单元压力梯度向量的 x 分量
参数：e - CFD 单元指针
f = element.cfd.presgradient.y(e)
element.cfd.presgradient.y(e) = f

获取/设置 CFD 单元压力梯度的 y 分量。

返回值：f - CFD 单元压力梯度向量的 y 分量
接受：f - CFD 单元压力梯度向量的 y 分量
参数：e - CFD 单元指针
f = element.cfd.presgradient.z(e)
element.cfd.presgradient.z(e) = f

获取/设置 CFD 单元压力梯度的 z 分量。

返回值：f - CFD 单元压力梯度向量的 z 分量
接受：f - CFD 单元压力梯度向量的 z 分量
参数：e - CFD 单元指针
