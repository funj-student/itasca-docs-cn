element cfd attribute 命令

语法

element cfd attribute keyword ... <range>

主要关键字：

density dragforce dragx 向力命令（dragforce-x） dragy 向力命令（dragforce-y） dragz 向力命令（dragforce-z） presgradient x 向压力梯度（presgradient-x） y 向压力梯度（presgradient-y） z 向压力梯度（presgradient-z） pressure velocity velocity-x velocity-y velocity-z viscosity

设置单元 CFD 属性的值。此命令是 element cfd initialize 命令的同义词。 可使用 element cfd list 命令列出单个属性，并且所有单元 CFD 属性均可 可视化。

density f

流体密度。

dragforce v

曳力的大小。

dragforce-x f

曳力的 x 分量。

dragforce-y f

曳力的 y 分量。

dragforce-z f (3D ONLY)

曳力的 z 分量。

presgradient v

压力梯度的大小。

presgradient-x f

压力梯度的 x 分量。

presgradient-y f

压力梯度的 y 分量。

presgradient-z f (3D ONLY)

压力梯度的 z 分量。

pressure f

流体压力。

velocity v

流体速度的大小。

velocity-x f

流体速度的 x 分量。

velocity-y f

流体速度的 y 分量。

velocity-z f (3D ONLY)

流体速度的 z 分量。

viscosity f

流体黏度。
