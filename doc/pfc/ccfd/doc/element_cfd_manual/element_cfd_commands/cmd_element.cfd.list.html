element cfd list 命令

语法

element cfd list <keyword> <range>

主要关键字：

显示属性（attribute）    extra    分组（group）

列出 CFD 单元信息。 默认情况下，列出 CFD 单元 ID、每个面的节点数、面数和形心位置。 使用 attribute 关键字列出所有 CFD 单元属性。

注意

使用 设置列表精度命令（model precision） 命令可更改所列浮点值的精度。

attribute <s >

列出 CFD 单元的属性。若未给出 s，则列出可用的属性。 若指定了 s，则列出每个 CFD 单元该属性的值。 属性是 CFD 单元的特征。可接受的值为 density、dragforce、 porosity、position、presgradient、pressure、radius、velocity、 viscosity 以及 volume。

extra i

列出索引 i 处的额外变量。

group s

列出槽位 s 处的分组名称。
