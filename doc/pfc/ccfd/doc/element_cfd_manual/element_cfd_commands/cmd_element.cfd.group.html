element cfd group 命令

语法

element cfd group s <keyword ...> <range>

主要关键字：

add    remove    槽位（slot）

指定 CFD 单元的分组名称。分组逻辑的用法在 分组（Groups） 中说明。 默认情况下，s 被赋予分组槽位 默认（Default）。 使用 add 关键字将分组名称赋予下一个可用的槽位，使用 remove 关键字 可将 s 从所有槽位中移除。

add

把 s 赋给下一个可用槽位。

remove

将 s 从所有槽位中移除。

slot 槽位（slot ）

把组槽位 槽位（slot） 设为 s。默认使用槽位 默认（Default）。
