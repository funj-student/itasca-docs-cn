黏结材料的套筒三轴试验

问题描述

注意

要查看此项目，请使用菜单命令 Help ► Examples…。选择“Example Applications/SleevedTriaxialTest”，然后选择“SleevedTriaxialTest.f3prj”加载。 所用主数据文件（main data files）见本示例末尾。其余数据文件可在项目中找到。

本示例演示使用基于壳的结构单元对黏结颗粒模型（BPM）进行一组套筒三轴试验。此类模型也可仅用 PFC 研究。但那样需要相当多的 FISH 来使套筒壁模拟弹性膜的行为。此处，套筒由壳创建，BPM 在套筒内合成，如 图 1（Figure 1） 所示。如 墙—网格耦合方案（Wall-Zone Coupling Scheme） 一节详细所述，PFC 墙从属于基于壳的结构单元。PFC 球颗粒与墙面片之间存在接触；每个球颗粒—面片接触处的接触力和力矩用于确定等效力系，以施加到相应的壳节点。本模型中，为简单起见，试样在无初始应力下创建，压板以恒定速度位移。 以本示例为基础，可方便地定义 BPM 的破坏包络线。

图 1：套筒三轴试验的几何形状。BPM 在套筒内创建。

耦合 PFC-FLAC3D 模型

在创建耦合 PFC-FLAC3D 模型之前，必须先加载 PFC 模块。这些模块是 包含用于实例化所有 PFC 相关模型组件的代码的 DLL。此外，还有一组模块用于将 PFC 墙与 FLAC3D 网格单元和基于壳的结构单元耦合。默认情况下，打开 FLAC3D 应用程序时不加载这些模块。可通过 Tools ► Load PFC 菜单项或以下命令加载这些模块：

program load module 'contact'
program load module 'pfc'
program load guimodule 'pfc'
program load module 'pfcthermal'
program load guimodule 'pfcthermal'
program load module 'ccfd'
program load guimodule 'ccfd'
program load module 'wallsel'
program load module 'wallzone'

项目在加载任何附加模块后保存一次后，再次打开该项目时将自动加载这些模块。请注意，附加模块会保持加载状态，直到关闭 FLAC3D 应用程序。

PFC 球颗粒在由 FLAC3D 壳组成的圆柱套筒内创建。为使每次运行数据文件时创建相同的初始球颗粒云，使用 设置随机数种子命令（model random） 命令将随机种子初始化为指定值。改变随机种子将得到不同的球颗粒实现，但统计上这些实现相同。与网格单元和结构单元不同，所有 PFC 模型组件（即球颗粒、刚性簇、墙和接触）只能存在于用户指定的模型域内（见 设置模型域命令（model domain） 命令）。该限制使接触检测和空间搜索得以简化和优化。由于 PFC 始终在大应变模式下运行，必须为网格单元和结构单元显式激活大应变模式（见 设置大变形模式命令（model large-strain） 命令）。PFC 默认使用球颗粒和刚性簇的真实惯性性质求解动力运动方程。本模型中，我们希望 PFC 采用时步缩放（见 设置力学分析参数命令（model mechanical） 命令），该方法类似于 FLAC3D 的默认行为。

完成这些准备步骤后，我们开始创建初始模型。

;定义圆柱的相关参数
[rad = 1.0]
[height = 3.0]
[segments = 6]
[halfLen = height/2.0]
[freeRegion = height/2.0*0.8]

;用几何逻辑创建圆柱
;首先创建圆弧，构成一圈边
geometry edge create by-arc origin (0,0,[-halfLen]) ...
   start ([rad*(-1)],0,[-halfLen]) end (0,[rad*(-1)],[-halfLen]) ...
   segments [segments]
geometry edge create by-arc origin (0,0,[-halfLen]) ...
   start (0,[rad*(-1)],[-halfLen]) end ([rad],0,[-halfLen]) ...
   segments [segments]
geometry edge create by-arc origin (0,0,[-halfLen]) ...
   start ([rad],0,[-halfLen]) end (0,[rad],[-halfLen]) ...
   segments [segments]
geometry edge create by-arc origin (0,0,[-halfLen]) ...
   start (0,[rad],[-halfLen]) end ([rad*(-1)],0,[-halfLen]) ...
   segments [segments]
;拉伸这些边以形成圆柱
geometry generate from-edges extrude (0,0,[height]) segments [segments*2]

圆柱套筒在几何逻辑中创建，以便作为壳导入。圆弧创建为几何边并竖向拉伸，形成圆柱套筒。可使用方括号记法（即“[]”）而非“@”运算符来定义 FISH 变量，并在命令中使用这些值。

几何体创建完成后，我们转而处理结构单元。

;从几何逻辑中将结构单元作为壳导入
;并赋予组和参数
structure shell import from-geometry 'Default' element-type dkt-cst 
structure node group 'middle' range position-z [-freeRegion] [freeRegion]
structure node group 'top' range position-z [freeRegion] [freeRegion+1]
structure node group 'bot' range position-z [-freeRegion-1] [-freeRegion]
structure shell group 'middle' range position-z [-freeRegion] [freeRegion]
structure shell property isotropic (1e6, 0.0) thick 0.25 density 930.0
;初始化结构单元相关的数据结构 
model cycle 0
;为了使用 STRUCTURE APPLY 命令 
;将每个结构单元的局部坐标系
;设置为指向三轴压力室的中心
fish define setLocalSystem
    loop foreach local s struct.node.list()
        local p = struct.node.pos(s)
        local nid = struct.node.id.component(s)
        local mvec = vector(0,0,comp.z(p))
        zdir = math.unit(p-mvec)
        ydir = vector(0,0,1)
        command
            structure node system-local z [zdir] y [ydir] ...
                      range component-id [nid]
        endcommand
    endloop
   command
     structure node fix system-local
   endcommand
end
[setLocalSystem]
;确保结构单元已启用局部阻尼
structure damp local
;固定结构单元节点以生成试样
structure node fix velocity rotation

使用 structure shell import 命令由所创建的几何体生成壳。 同时赋予单元组和节点组，以简化边界条件赋值。代码片段还展示了一个 FISH 函数，用于将每个节点的局部轴系设置为指向圆柱中心，以便使用 structure shell apply 命令对模型中部壳单元施加压力。z 方向直接指向圆柱中心，y 方向向上。固定节点的速度和转动，使球颗粒可在套筒内达到平衡。

现在为套筒和压板创建墙。

;创建结构单元的墙表示
wall-structure create
;用于设置压板宽度相对于圆柱半径之比的参数
[rad2 = rad*1.3]
;创建压板
wall generate name 'platenTop' polygon ([-rad2],[-rad2],[halfLen]) ...
                                       ([rad2],[-rad2],[halfLen])  ...
                                       ([rad2],[rad2],[halfLen])   ...
                                       ([-rad2],[rad2],[halfLen])
wall generate name 'platenBottom' polygon ([-rad2],[-rad2],[-halfLen]) ...
                                          ([rad2],[-rad2],[-halfLen])  ...
                                          ([rad2],[rad2],[-halfLen])   ...
                                          ([-rad2],[rad2],[-halfLen])
;将墙的分辨率策略设为 full，并设置截断角用于 
;邻近接触                                          
wall resolution full
wall attribute cutoff-angle 20

套筒使用 wall-structure create 命令创建。此时为每个壳面创建墙面片，墙面片顶点的速度和位置从属于相应的壳节点。顶、底压板使用 wall generate 命令创建，并使用 wall resolution 命令将墙解析模式设置为 full。一般而言，接触存在于 PFC 球颗粒与墙面片之间。若将解析模式设置为 none，则面片与球颗粒之间的所有接触都会被界定，并影响球颗粒的力—位移响应。但当墙面片尺寸接近球颗粒尺寸时，这可能产生比将墙理想化为无面片的完美表面时多得多的接触。full 方案用于缓解这种情况，cutoff-angle 用于控制墙的“平滑度”。墙解析详见 PFC 中的面片墙（Faceted Walls in PFC） 主题。

墙创建完成后，在套筒内创建 BPM。

;设置球体模量并生成任意重叠的球体集合
[ballemod = 1.0e8]
ball distribute box [-rad] [rad] [-rad] [rad] [-halfLen] [halfLen] ...
                porosity 0.3 radius 0.05 0.1 ...
                range cylinder end-1 (0,0,[-halfLen]) end-2 (0,0,[height]) ...
                      radius [rad*0.95]

;设置球体属性
ball attribute density 2600 damp 0.8
;设置默认接触行为 - 
;deformability 法用于设置 
;接触模型线性部分的参数
contact cmat default model linearpbond method deformability ...
                   emod [ballemod] kratio 1.0 
;允许球体重新排列， 
;每 100 个循环将线速度与角速度清零
model cycle 1000 calm 100

;提供一定摩擦以耗散额外能量 
;并将其应用于所有接触
contact cmat default model linearpbond method deformability ...
                   emod [ballemod] kratio 1.0 property fric 0.3
contact cmat apply
;求解至较小的平均比率
model solve ratio-average 1e-8

;对球-球接触进行黏结
contact method bond gap 1.0e-2 range contact type 'ball-ball'
;修改现有接触参数 
;使线性力按增量方式计算并
;提供强度
contact property lin_mode 1 lin_force 0 0 0 pb_ten 2e5 pb_coh 2e6
;设置接触模型中平行黏结部分的刚度 
contact method pb_deformability emod [ballemod] kratio 1.0 ...
        range contact type 'ball-ball'

;这一组操作将清除所有球体速度 
;以及模型中的所有接触力
;从而使试样完全无应力并保持黏结
model calm
ball fix velocity spin
model cycle 2
ball free velocity spin

;释放套筒中段的节点 
;同时保持顶部与底部边缘固定
structure node free velocity rotation range group 'middle'

PFC 球颗粒和刚性簇既可在无初始重叠下创建，也可在任意初始重叠下创建。 本例中，使用 ball distribute 命令在平行六面体体积内按指定体积分数创建具有任意重叠的球颗粒云。随后赋予球颗粒属性，并使用 contact cmat 命令指定接触模型行为。完成这些步骤后，允许球颗粒重新排列。执行计算时步（model cycle） 命令中的 calm 关键字用于定期移除系统的所有动能。随后给出 contact cmat 命令以修改接触模型分配表，并将该更改应用于所有接触。施加一定摩擦以移除额外能量，然后将球颗粒系统循环至较小平均比率。给出 contact method bond 命令，通过在所有间隙小于或等于指定值的球颗粒—球颗粒接触处安装平行黏结来创建 BPM。接触方法是一组对接触执行任务的操作，可能修改多个接触属性。黏结安装后，指定平行黏结强度，并通过设置 lin_mode = 1，将 线性平行黏结（linear parallel bond） 接触模型线性部分的法向力计算设置为增量模式。这样可快速生成无内应力的 BPM。此外，设置平行黏结组分的刚度。通过移除所有速度并固定球颗粒速度和自旋，若干循环后所有接触力归零。结果是 BPM 处于无内应力的平衡状态。最后，释放套筒中部的壳节点，为三轴试验做准备。无应力 BPM 的初始接触如下图所示。

图 2：无应力 BPM 的初始接触力。

无应力 BPM 创建后，还需做一些额外工作来构建进行三轴试验的环境。首先是用于根据压板计算应力和应变的 FISH 函数。

;定义 stress FISH 函数以测量应力与应变
fish define stress
    local topForce = math.abs(comp.z(wall.force.contact(platenTop))) 
    local botForce = math.abs(comp.z(wall.force.contact(platenBottom)))
    currentStress = 0.5*(topForce+botForce)/area
    stress = currentStress
    strain = (height - (comp.z(wall.pos(platenTop)) - ...
              comp.z(wall.pos(platenBottom))))/height * 100
    if failureStress <= currentStress
        failureStress = currentStress
        failureStrain = strain
    endif
end

此处利用压板在 z 方向上的力计算压板上的平均应力。应变也根据试样高度计算。FISH 参数 破坏应力（failureStress） 和 破坏应变（failureStrain） 用于记录峰值应力和应变。该信息在下面的 FISH 函数中用于终止循环。

;定义 halt FISH 函数以停止循环 
;在压板位移且材料发生破坏时
fish define halt
    halt = 0
    if currentStress < failureStress * 0.85
        halt = 1
    endif
end

一旦当前应力水平低于最大应力的 85%，循环将停止。可使用 FISH 函数配合 模型求解 FISH 停止命令（model solve fish-halt） 命令终止循环。函数 停止（halt） 返回值为 1 时循环终止。

以下 FISH 函数用于逐步增加试样上的围压：

;定义 FISH 函数以增大各向同性围压 
;分级施加，使黏结材料在加载过程中不发生破坏
fish define rampUp(beginIn,ending,increment)
    command
        ball attribute displacement (0,0,0)
        structure node initialize displacement (0,0,0)
    endcommand
    begin = beginIn
    loop while (math.abs(begin) < math.abs(ending))
        begin = begin + increment
        command
            ;施加围压
            structure shell apply [begin] range group 'middle'
            ;在压板上施加相同的围压
            wall servo force (0,0,[begin*area]) activate true ...
                 range name 'platenTop'
            wall servo force (0,0,[-begin*area]) activate true ...
                 range name 'platenBottom'
model cycle 200
            model calm
        endcommand
    endloop
    command
        ;应力状态建立后循环并关闭 
        ;墙体上的伺服机制
model cycle 1000
        wall servo activate false
        wall attribute velocity (0,0,0) range name 'platenTop'
        wall attribute velocity (0,0,0) range name 'platenBottom'
    endcommand
end

该函数的核心是逐步增加压板和套筒上的围压。由于已为壳指定局部坐标系，使用 structure shell apply 命令施加围压很简单。此外，使用内置墙伺服机构和 wall servo 命令对压板施加应力。现在可以压缩一些合成材料了。

结果与讨论

首先进行无侧限压缩（UCS）试验：移除套筒并固定压板速度。试验结果如下图所示。还显示了断裂的黏结，以展示 BPM 破坏时的广泛损伤。请注意，响应直至破坏都相当线性，且试验在峰值应力的 85% 处自动停止。该 BPM 的峰值 UCS 为 2.20e+06 Pa，对应应变 1.13%。

图 3：BPM 在 UCS 试验中的应力—应变响应及断裂的接触黏结。

为进行第一次三轴试验，加载原始 BPM，并将应力从 1e3 Pa 起以 1e3 Pa 增量升至 1e4 Pa。接触见 图 4（Figure 4）。请注意，应力为各向同性，因为接触几乎保持原始构型。这可以通过接触按力矢量方向而非连接球颗粒的方向绘制来判断。

图 4：应力施加后按力方向绘制的接触力。

围压为 1e4 Pa 的试验结果见 图 5（Figure 5）。试样在应变 1.15% 处破坏，峰值应力为 2.16e+06 Pa。图 6（Figure 6） 和 图 7（Figure 7） 分别给出 5e4 Pa 和 1e5 Pa 下的应力—应变响应及断裂接触黏结。下表列出各围压水平下 BPM 破坏时的峰值应力。请注意，与真实材料一样，峰值强度随围压增大而提高。此外，随围压增加，应力—应变曲线保持线性且斜率相近。低围压下应力的轻微下降可归因于使用墙测量应力以及球颗粒数量相对较少。

;使线性力按增量方式计算并
;提供强度
contact property lin_mode 1 lin_force 0 0 0 pb_ten 2e5 pb_coh 2e6
;设置接触模型中平行黏结部分的刚度 
contact method pb_deformability emod [ballemod] kratio 1.0 ...
        range contact type 'ball-ball'

;这一组操作将清除所有球体速度 
;以及模型中的所有接触力
;从而使试样完全无应力并保持黏结
model calm
ball fix velocity spin
model cycle 2
ball free velocity spin

;释放套筒中段的节点 
;同时保持顶部与底部边缘固定
structure node free velocity rotation range group 'middle'

;用于在压板位移过程中计算应力与应变的函数
;这些值将记录为历史
;首先找到顶部与底部压板 
[platenTop = wall.find('platenTop')]
[platenBottom = wall.find('platenBottom')]
;定义计算所需的若干变量
[failureStress = 0]
[currentStress = 0]
[failureStrain = 0]
[area = math.pi()*rad^2.0]
;定义 stress FISH 函数以测量应力与应变
fish define stress
    local topForce = math.abs(comp.z(wall.force.contact(platenTop))) 
    local botForce = math.abs(comp.z(wall.force.contact(platenBottom)))
    currentStress = 0.5*(topForce+botForce)/area
    stress = currentStress
    strain = (height - (comp.z(wall.pos(platenTop)) - ...
              comp.z(wall.pos(platenBottom))))/height * 100
    if failureStress <= currentStress
        failureStress = currentStress
        failureStrain = strain
    endif
end

;定义 halt FISH 函数以停止循环 
;在压板位移且材料发生破坏时
fish define halt
    halt = 0
    if currentStress < failureStress * 0.85
        halt = 1
    endif
end

;定义 FISH 函数以增大各向同性围压 
;分级施加，使黏结材料在加载过程中不发生破坏
fish define rampUp(beginIn,ending,increment)
    command
        ball attribute displacement (0,0,0)
        structure node initialize displacement (0,0,0)
    endcommand
    begin = beginIn
    loop while (math.abs(begin) < math.abs(ending))
        begin = begin + increment
        command
            ;施加围压
            structure shell apply [begin] range group 'middle'
            ;在压板上施加相同的围压
            wall servo force (0,0,[begin*area]) activate true ...
                 range name 'platenTop'
            wall servo force (0,0,[-begin*area]) activate true ...
                 range name 'platenBottom'
model cycle 200
            model calm
        endcommand
    endloop
    command
        ;应力状态建立后循环并关闭 
        ;墙体上的伺服机制
model cycle 1000
        wall servo activate false
        wall attribute velocity (0,0,0) range name 'platenTop'
        wall attribute velocity (0,0,0) range name 'platenBottom'
    endcommand
end
;设置压板速度
[platenVel = 0.000003]

;保存模型以备后用（包含这些 FISH 工具函数），此时
;尚未施加任何围压
model save 'beforeApplication'

;-------------------------------------------------------------------
;试验 1：对试样进行 UCS 试验
structure shell delete
wall attribute velocity-z [-platenVel] range name 'platenTop'
wall attribute velocity-z [platenVel] range name 'platenBottom'
ball attribute displacement (0,0,0)
fish history stress
fish history strain
model solve fish-halt halt
model save 'ucs'
[io.out(string(failureStress) + 'Pa ')]
[io.out('at' + string(failureStrain) + '% strain')]
