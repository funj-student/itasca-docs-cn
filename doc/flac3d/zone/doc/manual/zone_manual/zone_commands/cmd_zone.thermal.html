zone thermal 命令

语法

zone thermal keyword

主要关键字：

本命令可用的关键字如下，用于设置热分析参数：活动（active）    cmodel    隐式求解（implicit）    list    property    属性分布（property-distribution）    time-total    单元基于温度（zone-based-temperature）

为热分析设置参数（仅在已指定 配置热力计算模式（model configure thermal） 时可用）。以下关键字适用：

active b

将热计算设为 开启（on） 或 关闭（off）。在指定 配置热力计算模式（model configure thermal） 之后，默认为 开启（on）。

cmodel keyword <range>

将热本构模型与网格中的指定网格单元相关联。它还允许查询本构模型的属性和状态。

assign keyword

为 范围（range） 中的所有网格单元指派热模型。仅当模型已配置为热计算时（参见 配置流体计算模式（model configure fluid） 和 数学模型说明（Mathematical Model Description））才能给出此关键字。

advection-conduction

指派平流-传导模型。

anisotropic

指派热各向异性模型。

hydration

指派热水化模型。

isotropic

指派热各向同性模型。

null

指派热空模型。

list

列出可用的热本构模型及其属性。

implicit b

开启或关闭隐式模式（开启（on） 或 关闭（off））。默认情况下隐式模式为 关闭（off）。隐式模式需要手动指定时步。请注意，指定过大的时步可能导致迭代矩阵求解器无法收敛。（参见隐式公式（Implicit Formulation））

list keyword
information

列出关于网格单元特定热计算设置的一般信息。

property keyword <range>
列出范围内所有与指定属性相匹配的热属性值。
property keyword <range>

为范围内所有网格单元的热本构模型指派属性。可指派任意数量的名称-值对。任何具有匹配属性名的本构模型都将被指派该值。平流-传导（Advection-Conduction） 模型的属性列于此处（here），各向异性热传导（Anisotropic Heat Conduction） 模型的属性列于此处（here），各向同性热传导（Isotropic Heat Conduction） 模型的属性列于此处（here），水化（Hydration） 模型的属性列于此处（here）。

property-distribution s akeyword <range>

为范围内所有网格单元的热本构模型指派单个属性名。可使用下列可选关键字值使属性值在空间上变化。

add

将 a 加到（Add）属性值上。此关键字仅适用于浮点类型属性值。

deviation-gaussian f

使用高斯分布随机指派该值，均值为 a，标准差为 f。此关键字仅适用于浮点类型属性值。

deviation-uniform f

使用均匀分布随机指派该值，均值为 a，标准差为 f。此关键字仅适用于浮点类型属性值。

gradient v <origin v >

对属性值施加梯度（gradient）。此关键字仅适用于浮点类型属性值。

multiply

将属性值乘以（Multiply） a。

vary v

对属性值施加线性变化（linear variation）。此关键字仅适用于浮点类型属性值。

time-total f

指定累积的网格单元热时间，其定义为网格单元热处于活动状态的所有时步之和。一旦设定，热时间将随后续计算循环继续累积。

zone-based-temperature b

开启或关闭基于网格单元的温度。默认情况下温度在网格点处计算和存储，网格单元温度即网格点值的平均值。当此项设为 开启（on） 时，网格单元温度存储在网格单元中，网格点温度被忽略。必须使用 单元温度（zone.temp） FISH 内置函数手动设置温度。
