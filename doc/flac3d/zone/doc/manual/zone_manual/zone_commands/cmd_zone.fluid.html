zone fluid 命令

语法

zone fluid keyword

主要关键字：

本命令可用的关键字如下，用于设置流体分析参数：活动（active）    比奥（biot）    cmodel    快速流动（fastflow）    快速流动松弛（fastflow-relaxation）    隐式求解（implicit）    list    property    属性分布（property-distribution）    饱和度容差（saturation-tolerance）    time-total    追踪（track）    单元基于孔隙压力（zone-based-pp）

此命令为地下水流体流动分析设置参数。这些命令仅在执行 配置流体计算模式（model configure fluid） 命令之后可用。这些参数仅适用于网格单元，其他模型单元可能有不同的值。

active b

给出 配置流体计算模式（model configure fluid） 命令后，网格单元的流体过程默认处于 开启（on） 状态。指定 active 关闭（off） 可抑制网格单元的流体计算。通常不需要此命令，它从属于 单元流体活动（zone fluid active） 设置。

biot b

若开启，流体流动计算使用 Biot 系数 \(α\) 和 Biot 模量 \(M\)。若关闭，则使用流体模量 \(K_f\) 和孔隙率 \(n\)，且 \(α\) = 1。默认为关闭。参见Biot 系数与 Biot 模量（Biot Coefficient and Biot Modulus）。

cmodel keyword

将流体本构模型与网格中的指定网格单元相关联。它还允许查询本构模型的属性和状态。

assign keyword <range>

为 范围（range） 中的所有网格单元指派流体模型。仅当模型已配置为流体计算时（参见 配置流体计算模式（model configure fluid））才能给出此关键字。流体模型在为流体流动配置的网格（Grid Configured for Fluid Flow）中介绍。

anisotropic

指派各向异性流动模型。

isotropic

指派各向同性流动模型。

null

指派空流体模型。

list

列出可用的流体本构模型及其属性。

fastflow b

开启或关闭快流（fastflow）求解方案。参见完全饱和快流（Fully Saturated Fast Flow）。

fastflow-relaxation f

设置快流求解方案中使用的松弛参数。

implicit b

流体流动模型中的隐式求解方案被设为 开启（on） 或 关闭（off）。默认为 关闭（off）。

list
information

输出流体模型的当前配置设置和状态信息。

property keyword <range>

输出范围内所有网格单元中指定流体属性的值。

biot f

Biot 系数（颗粒压缩性）\(\alpha\)。默认值为 1.0。

porosity f

孔隙率 \(n\)。默认值为 0.5。

undrained-thermal-coefficient f

不排水热系数 \(\beta\)。

permeability f

各向同性渗透率 \(k\)。FLAC3D 中所用的渗透率定义为常规水力渗透率除以水的单位重度。如果 单元流体活动（zone fluid active） 开启（on） 生效，则渗透率必须非零。

dip f

主渗透率平面的倾角（单位为度）。

dip-direction f

主渗透率平面的倾向方位角（单位为度）。

permeability-1 f

主渗透率值。

permeability-2 f

主渗透率值。

permeability-3 f

主渗透率值。

permeability-xx f

xx 分量渗透率。

permeability-xy f

xy 分量渗透率。

permeability-xz f

xz 分量渗透率。

permeability-yy f

yy 分量渗透率。

permeability-yz f

yz 分量渗透率。

permeability-zz f

zz 分量渗透率。

rotation f

主渗透率平面的旋转角（单位为度）。

property keyword ... <range>

为范围内所有网格单元的流体流动本构模型指派属性。可指派任意数量的名称-值对。值 a 的类型必须与属性 s 所期望的类型相匹配。任何具有匹配属性名的本构模型都将被指派该值。

biot f

Biot 系数（颗粒压缩性）\(\alpha\)。默认值为 1.0。

porosity f

孔隙率 \(n\)。默认值为 0.5。

undrained-thermal-coefficient f

不排水热系数 \(\beta\)。

各向同性流体流动：

permeability f

各向同性渗透率 \(k\)。FLAC3D 中所用的渗透率定义为常规水力渗透率除以水的单位重度。如果 单元流体活动（zone fluid active） 开启（on） 生效，则渗透率必须非零。

各向异性流体流动：

dip f

主渗透率平面的倾角（单位为度）。

dip-direction f

主渗透率平面的倾向方位角（单位为度）。

permeability-1 f

主渗透率值。

permeability-2 f

主渗透率值。

permeability-3 f

主渗透率值。

permeability-xx f

xx 分量渗透率。

permeability-xy f

xy 分量渗透率。

permeability-xz f

xz 分量渗透率。

permeability-yy f

yy 分量渗透率。

permeability-yz f

yz 分量渗透率。

permeability-zz f

zz 分量渗透率。

rotation f

主渗透率平面的旋转角（单位为度）。

property-distribution s akeyword ... <range>

为范围内所有网格单元的流体流动本构模型指派单个属性名。可使用下列可选关键字值使属性值在空间上变化。

add

将 a 加到（Add）属性值上。此关键字仅适用于浮点类型属性值。

deviation-gaussian f

使用高斯分布随机指派该值，均值为 a，标准差为 f。此关键字仅适用于浮点类型属性值。

deviation-uniform f

使用均匀分布随机指派该值，均值为 a，标准差为 f。此关键字仅适用于浮点类型属性值。

gradient v <origin v >

对属性值施加梯度（gradient）。此关键字仅适用于浮点类型属性值。

multiply

将属性值乘以（Multiply） a。

vary v

对属性值施加线性变化（linear variation）。此关键字仅适用于浮点类型属性值。

saturation-tolerance f

仅当累积饱和度变化大于此值时，才会将饱和度变化对网格点的影响施加到网格点上。这样做是为了提高计算效率。默认值为 1x10:exp:\(-3\)

time-total f

指定累积的网格单元流体时间，其定义为网格单元流体处于活动状态的所有时步之和。一旦设定，流体时间将随后续计算循环继续累积。

track keyword

TRACK 命令在网格中指定位置放置一个粒子。粒子随流体流动，并在有限时间段内记录其路径。网格必须配置为流体流动（参见 配置流体计算模式（model configure fluid）），并且网格单元必须具有非空流体模型，粒子才能存在于该网格单元中。如果该位置未映射到满足这些要求的网格单元，则不会创建粒子（也不会输出错误消息）。粒子没有质量，且不以任何方式影响流动或力学行为；它们只是被流体携带并记录其运动。如有需要，可在不同时刻给出多个 TRACK 命令。粒子示踪用法的示例参见多孔区域的一维充填（One-Dimensional Filling of a Porous Region）中的数据文件。位置与关键字给出如下。

active b

开启或关闭粒子示踪（开启（on） 或 关闭（off））。track 默认关闭。

create keyword

在网格单元中创建一个或多个粒子。所创建粒子的位置和数量由以下关键字控制。后面的 <[zonefluidblock]> 可用于指定所创建粒子的属性。

point v ... <[zonefluidblock]>

在网格中指定位置 v 放置一个粒子。每给出一个矢量值，就会再创建一个粒子。

line keyword ... <[zonefluidblock]>

沿一条线向网格中添加粒子。

begin v

指定该线的起点位置。默认值为 (0,0,0)。

end v

指定该线的终点位置。默认值为 (0,0,0)。

segment i

指定将线等分为 i + 1 段，从而向网格中引入 i 个粒子。默认值为 2。

plane keyword ... <[zonefluidblock]>

沿由两条线定义的平面向网格中添加粒子。

begin v

指定将定义该平面的两条线的公共起点。默认值为 (0,0,0)。

end-1 v

指定第一条线的终点。默认值为 (0,0,0)。

end-2 v

指定第二条线的终点。默认值为 (0,0,0)。

segment i1 i2

将第一条线分为 i1 + 1 等段；将第二条线分为 i2 + 1 等段。沿该平面将在均匀间隔的网格上向网格中引入 i1 x i2 个粒子。i1 和 i2 的默认值为 2。

delete <range>

删除给定 range 内的粒子

group s keyword <range>

为范围内的粒子指派或移除分组。分组逻辑的用法在分组（Groups）中介绍。

remove

从给定范围内的粒子中移除分组 s。这不会移除粒子本身。

slot s

将给定范围内的分组指派到名为 s 的槽位。默认情况下分组将指派到槽位 默认（Default）

list <path>

列出关于示踪粒子的概要信息。如果省略 path 关键字，则输出当前粒子位置信息。如果包含 path 关键字，则输出粒子路径信息。

trace <name s > i

为 ID 号为 i 的粒子创建位置示踪（参见 trace 命令）。

zone-based-pp b

指定孔隙压力应直接从网格单元获取，而不是由网格点平均得到。网格单元孔隙压力必须通过 FISH 使用 单元孔隙压力（zone.pp） 内置函数手动指派。

.. rubric:: zone fluid 关键字块 :class: h2 :name: zonefluidblock

在创建粒子时，可以选择性地提供以下附加配置设置。它们适用于关键字：线（line）、平面（plane） 和 点（point）。

group s1 <slot s2 >

将所创建的粒子指派到分组 s1，并（如给出）将该分组指派到槽位 s2。默认槽位名为 默认（Default）。

tail b

当为 开启（on）（默认设置）时，粒子在网格中移动时会自动存储其路径上的一系列坐标。如果为 关闭（off），粒子只跟踪其当前位置。

tortuosity f

迂曲度以 f 指定，其定义为直线路径与流体穿过网格单元的实际路径之比。该因子将用于乘以根据流速计算得到的示踪增量；如果未给出，则默认为 1。
