zone create 命令

语法

zone create keyword

主要关键字：

可用的基本形状关键字如下，供 zone create 命令在指定要创建的网格形状时使用：砖块（brick）    圆柱壳（cylindrical-shell）    圆柱（cylinder）    圆柱相交（cylindrical-intersection）    退化砖块（degenerate-brick）    金字塔（pyramid）    径向砖块（radial-brick）    径向圆柱（radial-cylinder）    径向隧道（radial-tunnel）    tetrahedron    隧道相交（tunnel-intersection）    均匀楔形体（uniform-wedge）    楔形体（wedge）

zone.create 命令用预定义的网格模式填充基本形状（brick、cylinder 等）。

关于使用基本形状创建网格过程的进一步讨论和示例，请参见基于基本形状的网格（Primitive-Based Grids）。

要从二维横截面创建网格单元再将其挤出到第三维，请参见 挤出命令（extrude） 命令和 GUI 中的“挤出器”窗格，以及 单元生成从挤出器（zone generate from-extruder） 命令。

要从可交互的块体组合创建网格单元并能控制曲线边，请参见 building-block 命令和 GUI 中的“块体构建”窗格，以及 从构建块生成单元命令（zone generate from-building-blocks） 命令。

要创建单个网格点，请参见 zone gridpoint create。

使用此命令并采用 brick 关键字、将 size 设为 (1,1,1)，即可创建单个网格单元。

FLAC3D 还可以读入多种格式的外部生成网格，请参见 导入网格（zone import） 命令。

关于使用 zone create 划分网格

  • 参见Problem Solving with FLAC3D 中的基于基本形状的网格（Primitive-Based Grids）
  • 参见Tutorial: First FLAC3D Model 中的进一步讨论：用基本形状划分网格（Further Discussion: Meshing With Primitives）

zone create 关键字块


网格单元创建修饰符

所创建形状的特征（例如全局坐标位置、网格单元数量）通过在形状关键字之后指定下述关键字来定义。与每种形状相关的数值条目汇总于上表，并在各图中加以图示（单击上方任一缩略图可查看参考放大图）。上文所示的 zone.create 形状关键字都接受下面块中列出的关键字，除非各说明中另有注明。主要关键字为：砖块（brick）、圆柱（cylinder）、圆柱相交（cylindrical-intersection）、圆柱壳（cylindrical-shell）、退化砖块（degenerate-brick）、金字塔（pyramid）、径向砖块（radial-brick）、径向圆柱（radial-cylinder）、径向隧道（radial-tunnel）、tetrahedron、隧道相交（tunnel-intersection）、均匀楔形体（uniform-wedge） 和 楔形体（wedge）。

dimension f ...

为某些形状指定内部区域的尺寸。当未明确给出控制点时使用这些值。 某个形状最多可能需要七个 dimension 条目（f1、f2、f3、…、f7）。条目与尺寸请参见上图。如果未给出 dimension，则各条目按参考点之间长度的 20% 计算。

此关键字只能与 zone create 命令的下述形状关键字一起使用（其余形状不支持该关键字）：cylindrical-intersection、cylindrical-shell、radial-brick、radial-cylinder、radial-tunnel 和 tunnel-intersection。

edge f

为网格各侧面指定边长。如果未指定 point 1、point 2 和 point 3，则距 point 0 的距离大小由 edge 定义。默认情况下，边长即该方向上指定的网格单元数量。

fill b <group s1 <slot s2 >>

如果指定，某些形状的内部区域（见上文网格形状属性汇总（Summary of Mesh Shape Properties））将用网格单元填充。如果未指定，内部区域将不含网格单元。如果给出了带有效名称的可选关键字 group，则该名称 s1 将指派给所填充的网格单元。

此关键字只能与 zone create 命令的下述形状关键字一起使用（其余形状不支持该关键字）：cylindrical-intersection、radial-brick、radial-cylinder、radial-tunnel 和 tunnel-intersection。

group s1 <slot s2 >

在创建时为此基本形状指派分组名 s1。默认情况下（未提供 slot 关键字时），该分组指派到槽位 默认（Default）。分组逻辑的用法在分组（Groups）中介绍。

merge b

如果此关键字设为 真值（true），网格外表面上的网格点将与现有网格面合并。在执行 zone.create 命令期间，会对每个边界网格点与已存在网格单元的边界网格点逐一检查。内部网格点不检查。如果两个边界网格点相互之间的距离在 1 × 10-7（相对于网格点位置矢量的模）的容差范围内，则假定它们是同一个点，并使用第一个网格点，而不再为所有后续计算创建新点。如果 merge 设为 假值（false），则这两个网格点不会合并为一个。

point i keyword

关键字 point 0、point 1、point 2 … point 16 指定形状的参考（角）点。默认情况下，point 0 位于（x = 0，y = 0，z = 0）。默认情况下，point 1、point 2 和 point 3 设为沿 x、y 和 z 方向的正交距离，其大小等于该方向上的网格单元数量。指定 point 1、point 2 和 point 3 时，矢量 point 0 - point 1、point 0 - point 2 和 point 0 - point 3 必须构成右手坐标系。

某个形状最多可能需要 16 个点。所需数量见上文网格形状属性汇总（Summary of Mesh Shape Properties）。这些点的位置在参考图像中图示（单击上方任一缩略图即可访问）。

以下选项可用于定义任意给定点的位置

v <add>

位置以矢量 v 给出。如果使用可选关键字 add，则 v 的值将加到 point 0 的位置上。

gridpoint s

使用名称为 s 的网格点位置。请参见 zone gridpoint create 命令。这允许用户预先在空间中创建命名参考点，并在创建基本形状时引用它们。

ratio f1 <f2... >

此关键字指定一个比率，用于按递增或递减的几何比对网格单元间距进行布置。该比率所定义的网格单元尺寸分布使沿边的每个网格单元都是前一个的 f 倍。某些形状最多可能需要五个比率条目（f5）。对于每种形状，各条目及其对应的网格单元方向参见参考图像（单击上方任一缩略图）。如果未给出 ratio，则所有条目默认为 1.0。

size i1 <i2 ... >

此关键字指定每种形状的网格单元数量。某些形状最多可能需要五个（i5）。所需数量列于上文网格形状属性汇总（Summary of Mesh Shape Properties）。每种形状的各条目及其对应方向参见参考图像（单击上方任一缩略图）。如果未指定，size 值默认为 10。

sweep-axis

给出此关键字时，将以边 point 0 - point 2 为轴，扫掠边 point 1 - point 4 和 point 3 - point 5。不使用此关键字时，网格面将落在（point 0，point 1，point 3）和（point 2，point 4，point 5）平面上。

此关键字只能与 zone create 命令的下列关键字一起使用：cylinder 和 cylindrical-shell。
