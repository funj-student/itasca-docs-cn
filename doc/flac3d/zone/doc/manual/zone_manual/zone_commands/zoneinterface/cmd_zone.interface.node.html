zone interface node 命令

语法

zone interface <s > node keyword <range>

主要关键字：

本命令可用的关键字如下，用于管理接触面节点（含义见下文）：displacement-shear、位移小（displacement-small）、extra、分组（group）、历史（history）、initialize-stresses、list、stress-shear、应力法向增量（stress-normal-increment）、property、更新（update）

配置接触面节点。

若给出接触面名称 s，则该命令仅作用于该接触面的节点；否则该命令作用于可选范围内所有接触面的节点。

displacement-shear v

覆盖范围内所有接触面节点的剪切位移矢量。其数值将被约束为垂直于接触面法向方向。

displacement-small f

以小应变模式运行的接触面通过比较两个相互作用面的“虚拟位置”来获得其力，其中点的“虚拟位置”是该点的原始坐标加上迄今累积的位移（displacement-small）。如果一个接触对象被移除（例如隧道内的充填体），并用同一接触面替换为另一个对象（例如安装衬砌），则可能出现很大的初始应力，因为接触面两侧看起来相互侵入（原因是旧对象的虚拟位置相对于新对象的指定位置已经改变）。

与特定接触面 s 相关的存储位移可乘以系数 f，使用关键字 displacement-small。通常该系数为零，从而将组成接触面“宿主”的各面虚拟位置恢复到其原始位置。此时，当其坐标与接触面宿主面的原始坐标一致时，新的相互作用对象不会产生初始应力。但也可以为 f 指定非零值，以模拟两个接触对象之间的初始不匹配。

该命令会改变接触面内以及相接触的两个面的虚拟位置。然而，对于新建的接触面，在开始循环之前无法找到“目标”面。因此，若目标面（即不带接触面单元的面）已有一定变形，为使所有位置都被重置，应在执行该命令之前至少执行一个循环。

extra i a[interfacenodeblock]

设置数组索引 i 处的接触面节点额外变量值。

group s <keyword>

向范围内的接触面节点添加分组名 s。分组逻辑的使用见分组（Groups）。该命令可采用 zone interface node 槽位名 = 分组名（"slotname = groupname"） 的形式——需要引号，等号处的空格被忽略——其中 槽位名（slotname） 为槽位赋值，分组名（groupname） 为分组名。

一个接触面节点可属于不同槽位中的多个分组，最多 128 个。group 范围元素可用于按分组名称选择对象。

以下可选关键字可用：

remove

从接触面节点中移除 s。若未指定槽位，则从包含该分组名的所有槽位中移除。

slot s

将组分配到名为 s 的槽位。默认槽位名称为 默认（Default）。

history <name sn >keyword

可在指定的接触面节点处对接触面 s 的接触面变量进行采样。见 history 命令。请注意，该命令其后不接范围。定义了以下关键字：

displacement-normal keyword

法向位移（正值表示侵入量增大）。

id i <name s >

表示应在接触面 s 中编号为 i 的接触面节点处记录时程。若未指定特定接触面，则其后必须指定接触面名称。

position v

表示应在接触面 s 的节点中距位置 v 最近的节点处记录时程。若未指定特定接触面，则将查找任意接触面上最近的节点。

displacement-shear keyword

剪切位移大小

id i <name s >

表示应在接触面 s 中编号为 i 的接触面节点处记录时程。若未指定特定接触面，则其后必须指定接触面名称。

position v

表示应在接触面 s 的节点中距位置 v 最近的节点处记录时程。若未指定特定接触面，则将查找任意接触面上最近的节点。

stress-normal keywrd

法向应力（压应力为正）

id i <name s >

表示应在接触面 s 中编号为 i 的接触面节点处记录时程。若未指定特定接触面，则其后必须指定接触面名称。

position v

表示应在接触面 s 的节点中距位置 v 最近的节点处记录时程。若未指定特定接触面，则将查找任意接触面上最近的节点。

stress-shear keyword

剪应力大小

id i <name s >

表示应在接触面 s 中编号为 i 的接触面节点处记录时程。若未指定特定接触面，则其后必须指定接触面名称。

position v

表示应在接触面 s 的节点中距位置 v 最近的节点处记录时程。若未指定特定接触面，则将查找任意接触面上最近的节点。

initialize-stresses

初始化范围内所有与表面面接触的接触面节点上的法向力和剪切力。这些力的数值由节点宿主面上的面力确定。这意味着，若已初始化网格单元应力，则接触面力可被初始化为近似协调，从而减少达到初始平衡所需的循环次数。

请注意，由于法向应力由绝对侵入量决定，法向应力的初始化通过为每个受影响节点设置 stress-normal-increment 值来实现。

list keyword

列出范围内接触面节点的信息。

displacement

节点的累积位移、剪切位移和小应变位移。

extra i

接触面节点额外索引 i 中存储的值。

host

宿主网格单元面，以及用于附着的权重值。

information

位置、法向方向、有效面积以及接触容差。

property keyword

节点处接触面性质的值。可用的性质名称为：

bonded-slip

表示是否允许滑移的标志。

cohesion

黏聚力，单位为应力

cohesion-residual

残余黏聚力。若赋以大于或等于零的值，则在摩擦剪切破坏后将该值赋给 cohesion。

dilation

剪胀角，单位为度

friction

摩擦角，单位为度

friction-residual

残余摩擦角。若赋以大于或等于零的值，则在摩擦剪切破坏后将该值赋给 friction。

shear-bond-ratio

剪切黏结强度，以抗拉强度的比值表示。

stiffness-normal

法向刚度，单位为应力/位移。

stiffness-shear

切向刚度，单位为应力/位移。

tension

抗拉强度，单位为应力

tension-residual

残余抗拉强度。若赋以大于或等于零的值，则在摩擦剪切破坏后将该值赋给 tension。

state

接触面节点的当前状态

stress

剪应力和法向应力以及剪应力方向

target

目标面信息，包括侵入量

velocity

节点处速度

stress-shear v [interfacenodeblock]

为范围内所有接触面节点设置增量剪应力 v。

stress-normal-increment f [interfacenodeblock]

为范围内所有接触面节点将法向应力增量设为 f。请注意，压应力为正。法向应力增量将加到由接触面侵入量计算得到的法向应力上。

property keyword ...

为范围内所有接触面节点指定一个或多个新的性质值。

cohesion f [interfacenodeblock]

黏聚力［应力］

friction f [interfacenodeblock]

摩擦角［度］

stiffness-normal f [interfacenodeblock]

法向刚度［应力/位移］

stiffness-shear f [interfacenodeblock]

切向刚度［应力/位移］

cohesion-residual f [interfacenodeblock]

残余黏聚力 [应力]。若指定大于或等于零的值，则在摩擦剪切破坏后将该值赋给 cohesion。默认值为 -1.0。

friction-residual f [interfacenodeblock]

残余摩擦角 [度]。若指定大于或等于零的值，则在摩擦剪切破坏后将该值赋给 friction。默认值为 -1.0。

tension-residual f [interfacenodeblock]

残余抗拉强度 [应力]。若指定大于或等于零的值，则在摩擦剪切破坏后将该值赋给 tension。默认值为 -1.0。

tension f [interfacenodeblock]

抗拉强度［应力］

bonded-slip b

是否允许黏结接触面段发生滑动。默认为关闭（即当黏结完好时不允许滑动）。仅在指定了黏结接触面（已设置 tension）时适用。

shear-bond-ratio f [interfacenodeblock]

剪切黏结强度设为法向黏结强度（抗拉）的 sbr 倍。请注意，仅给出 sbratio 并不会建立黏结；还必须设置抗拉黏结强度。sbratio 的默认值为 100（即剪切黏结为抗拉黏结的 100 倍）。仅在指定了黏结接触面（已设置 tension）时适用。

update b <range>

该命令禁止在接触面发生移动后搜索新的接触。无论位移多大，都保持相同的接触。使用时需谨慎，因为位移较大时可能产生不符合物理实际的行为。默认行为为 开启（on），即允许正常搜索新的和已断裂的接触。


zone interface node 关键字块

以下关键字可用于修改（modify）所提供的值。若修饰关键字的说明中提及其可适用的值类型（例如标量值、矢量值等），请确保修饰关键字与主关键字的值类型相匹配。命令的主关键字为：extra、应力法向增量（stress-normal-increment） 和 stress-shear。黏聚力（cohesion）、cohesion-residual、摩擦（friction）、friction-residual、shear-bond-ratio、stiffness-normal、stiffness-shear、tension 和 tension-residual。

add

将（Add）指定值加到现有值上。

gradient v <origin v >

对给定的标量值施加梯度（gradient）。

multiply

将（Multiply）现有值乘以指定值。

vary v

对所给的标量值应用 线性变化（linear variation）。
