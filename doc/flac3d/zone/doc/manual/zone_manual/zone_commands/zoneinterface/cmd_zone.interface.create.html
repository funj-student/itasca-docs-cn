zone interface create 命令

语法

zone interface <s > create keyword ...

主要关键字：

按面（by-face）    单元（element）    node

在接触面 s 上创建节点或单元。如果未给出接触面名称，则命令作用于所有接触面。

创建接触面有两种方法。第一种是使用 by-face 关键字从一系列网格单元面派生一个或多个接触面。第二种是由三个点指定一个三角形接触面element。最后，此命令还可用于构造接触面node，该节点又可与 element 关键字配合使用。

如果给出接触面名称 s，则在该名称的接触面尚不存在时创建它。所创建的单元和节点将添加到该接触面。如果未指定名称，将自动创建使用默认名称的新接触面。

by-face <keyword ...> <range>

在指定范围内的所有表面网格单元面上创建接触面单元。如果所选面上已存在该接触面的接触面单元，将发生错误。

break-angle f

当接触面单元施加到面上时，默认情况下共享角点处的节点是共享的。如果接触面单元（或网格单元面）之间的夹角大于此角度，则将在同一点创建重复节点。这样效果更好，因为在角点处会有两个使用不同法向量的不同节点起作用。

默认折角为 30 度。角度以度为单位输入。

break-slot s

除 break-angle 和 merge-nodes 关键字之外，用户还可指定一个槽位，以判定接触面节点何时不应跨单元共享。如果使用 break-slot 关键字，则当承载接触面单元的面或网格单元分组在所指定槽位中不同时，接触面节点不共享。

请注意，可以指定 任意（Any），表示分组指派的任何差异都将表明节点不应共享。

group s <slot slot >

新建的接触面将被指派分组 s。分组逻辑的用法在分组（Groups）中介绍。此命令可采用形式 zone interface node 槽位名 = 分组名（"slotname = groupname"）——需要引号，等号处的空格忽略——其中 槽位名（slotname） 是槽位指派，分组名（groupname） 是分组名。

请注意，接触面节点和单元参与分组层级——因此可以使用指派给接触面的分组名来选择节点和单元。

一个接触面节点可属于不同槽位中的多个分组，最多 128 个。group 范围元素可用于按分组名称选择对象。

slot 关键字可用于指定新分组要使用的槽位。默认槽位为 默认（Default）。

请注意，默认情况下将在槽位 默认（Default） 中指派与接触面名称相匹配的分组字符串。

merge-nodes b

如果设为 假值（false），则使每个面在每个角点处创建各自独立的接触面节点。因此一个典型的四边形表面将在同一表面上具有四个独立的接触面节点。这既有优点也有缺点。

优点是可以自动处理尖锐角点，因此无需创建单独的接触面。另一个优点是由于接触面节点密度增加，在大应变运动下（尤其是沿边）可获得更可靠的结果。

缺点是计算开销约增大 4 倍，并且由于每个节点独立计算侵入量（且通常会选择不同的目标面），法向侵入量往往不连续。平均而言这尚可接受，但侵入量及其相关量（法向应力、处于摩擦极限时的剪应力等）的云图将远不如前者平滑。

默认值为 真值（true）。

separate <keyword>

如果使用可选的 separate 关键字，则由范围选择内部网格单元面。所选面的列表随后将自动分离（如同 zone separate），并将接触面单元放置在一侧。separate 关键字之后可用的关键字如下：

new-side-origin v

指定接触面放置在分离面的哪一侧。它选择其面法向量指向 v 的一侧。如果未指定，所用值将为原点 (0,0,0)。

new-side-group s

指定接触面放置在分离面的哪一侧。它选择其网格单元属于指定分组的一侧。

clear-attach

如果指定，则清除边界上的任何附着条件。默认情况下，存在附着条件将导致错误。

element point i keyword ...

通过指定三个点创建三角形接触面单元。必须在 element 关键字之后指定三个顶点 point 1、point 2 和 point 3。每个点都可通过 position 关键字创建并在空间中定位，也可指定 ID 为 i 的现有接触面节点。所创建的接触面单元即使在位置上与某个网格面相对应，也不附着到该网格面上。该单元在空间中是固定的。单元的作用侧由绕单元边缘行走来定义：从 point 1 到 point 2 再到 point 3；按顺时针方向行走时作用侧朝上。

对于单元的每个点，必须提供下列两个关键字之一。

node i

以 ID 为 i 的先前创建的接触面节点标识该点。

position v

以在位置 v 处创建的新接触面节点标识该点。

node v

这将在位置 v 处创建一个接触面节点。如果所选位置已存在节点，则报告错误。所创建的节点在空间中是固定的。
