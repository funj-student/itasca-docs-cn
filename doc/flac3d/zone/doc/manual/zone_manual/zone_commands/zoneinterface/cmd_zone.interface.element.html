zone interface element 命令

语法

zone interface <s > element keyword <range>

主要关键字：

本命令可用的关键字如下：delete    extra    分组（group）    list    最大边长（maximum-edge）

管理网格单元接触面单元。如果未给出接触面名称，则命令作用于所有接触面。

如果给出接触面名称 s，则命令仅作用于该接触面的单元；否则命令作用于可选范围内所有接触面中的单元。

delete

所选范围内与该接触面相关联的所有接触面单元都将被删除。

extra i a[interfaceelementblock]

设置数组索引 i 的接触面单元附加变量值。可使用标准的 [interfaceelementblock] 列表在空间上修改该值。

group s <keyword>

将分组名 s 添加到范围内的接触面单元。分组逻辑的用法在分组（Groups）中介绍。此命令可采用形式 zone interface element 槽位名 = 分组名（"slotname = groupname"）——需要引号，等号处的空格忽略——其中 槽位名（slotname） 是槽位指派，分组名（groupname） 是分组名。

一个接触面元素可属于不同槽位中的多个分组，最多 128 个。group 范围元素可用于按分组名称选择对象。

以下可选关键字可用：

remove

从接触面单元中移除 s。如果未指定槽位，则该分组名将从找到它的所有槽位中移除。

slot s

将组分配到名为 s 的槽位。默认槽位名称为 默认（Default）。

list keyword
extra i

列出数组索引 i 的接触面单元附加变量值。

information

显示范围内所有单元的节点、面积和法向量。

maximum-edge f

f 是范围内接触面单元的最大边长。接触面将被细分，直到所有这些单元的边长都小于所给值。默认情况下，每个四边形网格单元面创建两个三角形单元。


zone interface element 关键字块

以下关键字可用于修改（modify）所给的值。如果修饰符关键字的说明提到它可应用于何种类型的值（例如标量值、矢量值等），请务必使修饰符与主关键字的值相互匹配。该命令的主关键字为：extra。

add

将（Add）指定值加到现有值上。

gradient v <origin v >

对给定的标量值施加梯度（gradient）。

multiply

将（Multiply）现有值乘以指定值。

vary v

对所给的标量值应用 线性变化（linear variation）。
