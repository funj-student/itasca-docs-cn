zone densify 命令

语法

zone densify keyword ... <range>

主要关键字：

本命令可用的关键字如下：长宽比（aspect-ratio）    边限值（edge-limit）    全局函数（global）    gradient-limit    local    最大长度（maximum-length）    分段数（segments）    重复次数（repeat）


此命令查找范围内的所有网格单元，并将它们细分为填充相同体积的较小网格单元。这会创建新的网格单元，并且通常会创建新的网格点。新网格单元将复制原网格单元的分组指派。

请注意，这可能会产生与周围网格未完全连接的“悬挂”网格点。应在计算循环之前使用 单元附着按面（zone attach by-face） 命令，以确保模型行为连续。

关于网格单元加密的用法讨论与示例，请参见网格加密（Densifying Grids）；关于基于几何数据创建“八叉树”网格过程的讨论与示例，请参见基于几何的加密：八叉树网格划分（Geometry-Based Densification: Octree Meshing）。

请注意，对含退化网格单元类型（楔形、四面体、金字塔等）的网格进行加密可能会出现问题。三角形面的加密将使用所有线汇交的退化点。如果该点在跨三角形面相连的两个网格单元上不相同，则所得几何形态将不正常，即使已附着也会在求解中产生小的伪影。这类几何形态还可能产生意外的拓扑表面，与网格单元面分离相互作用不良。该命令将尝试检测该情况并向用户发出警告。

aspect-ratio f

此选项目前仅适用于六面体（砖块）类型的网格单元。尝试用于其他类型将导致错误。

如果判定某网格单元的长宽比超过此限值，则仅沿该方向使用为该自由度给出的乘数值进行加密。这可以与 repeat 关键字配合使用，沿最长方向系统地细分网格单元，直到长宽比降至所需值以下。

edge-limit f

如果网格单元的最大边长超过此值，则将在三个方向上使用 segments 乘数对其进行加密。如果低于此值，则忽略。此值可与 repeat 组合使用，系统地细分网格单元，直到最大边长小于该限值。

请注意，此行为与 maximum-length 关键字不同，后者会动态计算细分次数。当使用 repeat 关键字时，唯一区别在于 maximum-length 关键字允许在不同方向上采用不同的长度限值。

global

这指定应用 segments 关键字的网格单元边为与全局 x、y、z 轴最为接近对应的那些边。

gradient-limit

选择进行加密的网格单元将接受检查，以尽量确保相邻网格单元的加密级别最多相差一级。这可能意味着实际加密的网格单元多于落在范围内的数量。

local

此项用于按局部段顺序设置要加密的网格单元。局部段顺序沿 e1、e2 和 e3 边，其中 e1、e2 和 e3 分别是该网格单元第 1 与第 2、第 1 与第 3、第 1 与第 4 个网格点之间的边。这是默认设置。

maximum-length f1 <f2 <f3 >>

此项按局部或全局 x、y、z 方向的顺序指定要加密的最大边长。如果未指定 f2 和 f3，则将其设为与 f1 相同的数值。对每个网格单元计算细分数（用以代替 segments 关键字所指定的值），以使所得边长低于最大值。所得细分数被约束为 2 的幂（1、2、4、8、…）。

请注意，这与 edge-limit 关键字的行为不同，后者将使用 segments 关键字中指定的细分数。当使用 repeat 关键字时，唯一区别在于 maximum-length 关键字允许在不同方向上采用不同的长度限值。

segments i1 <i2 <i3 >>

此项按顺序指定要加密的网格单元的细分数。如果未指定 i2 和 i3，则将其设为与 i1 相同的数值。

请注意，在非常不规则的初始网格上不建议使用非均匀分段值——尤其是由 griddle 等网格生成工具产生的网格。相邻网格单元的局部方向可能差异很大，使用 global 关键字虽可缓解这些影响，但无法消除。

如果使用非均匀分段值，应选择彼此成整数倍关系的数值。例如，1、2、4 通常比 2、3、5 产生更好的网格。

repeat <i >

将加密重复 i 次，从而递归应用范围与加密设置。例如，这可用于创建八叉树网格。请注意，如果未给出次数，FLAC3D 将重复至达到 edge-limit，每次应用 segments 中指定的细分。
