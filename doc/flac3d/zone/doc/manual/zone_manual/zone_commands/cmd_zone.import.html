zone import 命令

语法

zone import s <s2 >keyword

主要关键字：

use-given-ids    格式（format）

从文件导入网格。将导入名为 s 的文件。路径可以是文件名的一部分。如果未指定扩展名，则假定为 单精度 3 网格（.f3grid）。

目前支持三种格式：FLAC3D 原生格式（网格文件名（*.f3grid））、ANSYS（*.lis 文件（*.lis））和 ABAQUS（*.inp 文件（*.inp））。格式将根据文件扩展名自动确定，但可用 format 关键字覆盖。

该命令为输入文件中指定的每个网格点创建一个新网格点。不检查重复的网格点。用户需自行将导入的网格与现有几何合并。如果网格单元退化或无法支持两重叠加，将输出警告消息。

可用以下关键字：

use-given-ids

强制 FLAC3D 使用与导入文件中指定的相同的网格点和网格单元 ID。

format keyword

指定输入文件的预期格式，覆盖通过检查文件扩展名作出的任何默认判断。以下格式类型可用：

flac3d

此项指定 FLAC3D 原生 ASCII 或二进制格式网格文件，预期扩展名为 单精度 3 网格（f3grid）。二进制格式网格文件通常比 ASCII 格式网格文件更小且导入更快。FLAC3D 网格文件 ASCII 格式的详细说明见下文。

ansys

此项指定 ANSYS 兼容的网格文件，通常预期扩展名为 lis 文件（lis）。请注意，此处启用的 ANSYS 格式通常需要两个不同的文件，二者扩展名相同。假定第一个文件包含网格点信息，第二个包含网格单元信息。在 ANSYS 中使用“nlist”命令将节点（网格点）输出到文件；使用“elist”命令将单元（网格单元）输出到另一文件。不支持节点数超过 8 的任何 ANSYS 单元。

abaqus

此项指定 ABAQUS 兼容的网格文件，通常预期扩展名为 inp 文件（inp）。可接受的 ABAQUS 单元为“c3d4”、“c3d5”、“c3d6”和“c3d8”。不支持其他 ABAQUS 单元。


FLAC3D 网格格式规范

FLAC3D ASCII 格式网格文件具有以下规范：注释行以星号开头；空行被忽略；数值之间的逗号分隔符是可选的。

以“G”开头的行表示网格点定义。一个网格点包含一个整数标识符（ID 编号），随后是该网格点的 x、y、z 坐标（浮点数）。

以“Z”开头的行表示网格单元定义。一个网格单元包含网格单元类型标识符、整数网格单元标识符以及组成该网格单元的网格点标识符。

网格点和网格单元的 ID 编号必须为正整数。ID 编号不必顺序或连续（编号中允许有空缺）；但网格单元引用的每个网格点 ID 都必须在网格点列表中的某处存在。如果指定了 use-given-ids 关键字，则 网格文件名（*.f3grid） 文件中指定的网格点和网格单元 ID 编号将用于最终网格。否则，网格点和网格单元将使用下一个可用的 ID 编号生成（默认）。此外，use-given-ids 关键字允许以分片方式导入网格。例如，如果存在以下网格文件：

g1.f3grid – 网格点定义

g2.f3grid – 更多网格点定义

g3.f3grid – 更多网格点定义

z13.f3grid – 使用来自 g1 和 g3 的网格点 ID 的网格单元定义

z12.f3grid – 使用来自 g1 和 g2 的网格点 ID 的网格单元定义

groups.f3grid – 网格单元所属的分组

则可以按如下方式导入：

zone import 'g1.f3grid' use-given-ids

zone import 'g3.f3grid' use-given-ids

zone import 'z13.f3grid' use-given-ids

zone import 'g2.f3grid' use-given-ids

zone import 'z12.f3grid' use-given-ids

zone import 'groups.f3grid' use-given-ids

为此，唯一的要求是：在创建需要这些网格点的网格单元之前，网格点必须已经存在。此外，在将网格单元放入分组之前，网格单元必须已经存在。

可识别以下网格单元类型标识符：

B8 – 砖块型网格单元

W6 – 楔形网格单元

P5 – 金字塔型网格单元

B7 – 退化砖块型网格单元

T4 – 四面体型网格单元

对于网格单元定义，网格点 ID 编号必须按 FLAC3D 的标准顺序指定（参见 网格单元内节点与面的方向（Orientation of Nodes and Faces within a Zone））。楔形、金字塔型、退化砖块型和四面体型网格单元的多余点不在网格文件中指定。对于 B8 网格单元，必须指定 8 个网格点；对于 W6 网格单元，必须指定 6 个网格点，依此类推。

以“ZGROUP”开头的行表示网格单元的分组定义。紧跟在 ZGROUP 一词之后的文本是分组名称。在分组名称之后，属于该分组的所有网格单元都用网格单元 ID 编号指定。以“F”开头的行表示面定义。面行包含一个类型标识符（该面的唯一标识符）以及一组网格点 ID，这些网格点构成网格单元中的一个面。类型面标识符定义为：“T3”用于四面体网格单元的面，“Q4”用于四边形网格单元的面。

以“FGROUP”开头的行表示一组面。面分组用于范围逻辑中，使用户可以将特性、边界条件、速度等施加到一组面上。面分组行包含面分组名称。FGROUP 行之后是包含先前定义的面标识符的各行。面标识符之间以空格分隔。创建网格时，这会将分组名称分配给该行中的所有面。
