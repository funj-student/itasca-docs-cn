zone dynamic 命令

语法

zone dynamic keyword

主要关键字：

本命令可用的关键字如下：活动（active）    damping    free-field    list    多步（multi-step）    time-total

此命令为动力模型设置参数（仅在启用动力模型选项时可用——参见动力分析（Dynamic Analysis））。这些参数仅适用于网格单元，其他模型单元可能有不同的值。

active b

给出 模型配置动力分析命令（model configure dynamic） 命令后，网格单元的动力选项默认处于 开启（on） 状态。用于指定网格单元力学计算是否采用动力模式。通常不需要此设置，它从属于 模型动力活动命令（model dynamic active） 设置。

damping keyword <range>

此命令为动力分析选择阻尼类型。动力分析中的阻尼在力学阻尼与材料响应（Mechanical Damping and Material Response）主题中介绍。阻尼值可在模型内随区域而变化。以下关键字适用：

artificial-viscosity f1 f2

设置 von Neumann（f2）和 Landshoff（f2）常数，通常两者都应为 1.0。此阻尼仅适用于主网格。请参见人工黏性（Artificial Viscosity）主题。

combined f <gradient v >

组合局部阻尼（参见组合阻尼（Combined Damping））。默认阻尼值为 0.8。可施加 梯度（gradient） 以在空间上改变该参数。

local f <gradient v >

局部阻尼（参见局部非黏性阻尼（Local Nonviscous Damping））。默认阻尼值为 0.8。可施加 梯度（gradient） 以在空间上改变该参数。

hysteretic keyword

启用滞回阻尼（参见滞回阻尼（Hysteretic Damping））。以下关键字与系数是可用于表示 G / Gmax 变化的函数。

default f1 f2

由含两个参数的三次方程表示的默认模型。

hardin f1

含一个参数的 Hardin/Dernevich 方程。

off

关闭滞回阻尼。

sigmoidal-3 f1 f2 f3

含三个参数的 S 形方程。

sigmoidal-4 f1 f2 f3 f4

含四个参数的 S 形方程。

reduction-minimum

设置模量折减系数的下限值。默认值为 0.005。

rayleigh <f1 <gradient v > f2 <gradient v > <mass> <stiffness>>

对于动力计算，通常需要在给定频率范围内提供一定比例的临界阻尼。此类阻尼称为 Rayleigh 阻尼（参见Rayleigh 阻尼（Rayleigh Damping）），其中 f1 = 在中心频率 f2 处起作用的临界阻尼比例。（注意：程序输入频率的单位为周/秒或赫兹——不是弧度/秒。）可选修饰符 stiffness 和 mass 表示阻尼分别限于刚度比例或质量比例。如果省略这些修饰符，则使用常规 Rayleigh 阻尼。

注意：通过指定刚度阻尼，数值稳定的临界时步将自动减小。如果发生大网格变形，仍可能出现不稳定。此时应使用 模型动力时步（model dynamic timestep） 命令降低时步。

free-field keyword

控制自由场边界条件（仅适用于动力选项；参见自由场边界（Free-Field Boundaries））。也可使用下列关键字代替布尔值：

b

如果为 开启（on），则创建自由场边界网格单元。如果为 关闭（off），则销毁自由场边界网格单元及其余相关的施加条件。

plane-x

仅在垂直于 X 轴的平面上创建自由场网格单元。因此自由场网格单元将创建在模型的 -X 和 +X 侧，而不会在模型的 -Y 和 +Y 侧创建，也不会创建角部网格单元。当使用 FLAC3D 模拟二维动力问题时，这很有用。

plane-y

仅在垂直于 Y 轴的平面上创建自由场网格单元。因此自由场网格单元将创建在模型的 -Y 和 +Y 侧，而不会在模型的 -X 和 +X 侧创建，也不会创建角部网格单元。当使用 FLAC3D 模拟二维动力问题时，这很有用。

list

动力计算模式信息

multi-step b

开启或关闭多重时步（参见动力多重时步（Dynamic Multi-stepping））。多重时步可加速网格单元尺寸或模量差异较大的动力模型的计算。临界时步大于全局临界时步的网格区域将被更新得较少，从而节省执行时间。该逻辑是通用的，因为所有网格单元、网格点和结构都包含在内。用户除开启该功能外无需做其他操作。

time-total f

指定累积的网格单元动力时间，其定义为网格单元动力模式处于活动状态的所有时步之和。一旦设定，动力时间将随后续计算循环继续累积。
