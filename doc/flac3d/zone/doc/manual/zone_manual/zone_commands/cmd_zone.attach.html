zone attach 命令

语法

zone attach keyword

主要关键字：

关键字：delete    按面（by-face）    节点 ID 位置（gridpointid）    分组（group）    list

创建附着的网格点。一个网格单元上的网格点可以刚性附着（或称从属）到其他网格单元的主网格点、边或面上。这使得拓扑上并不完全匹配的网格也能表现为单一网格。每个如此附着的网格点都会创建一个内部数据结构（附着点），可通过命令和 FISH 访问。

请注意，附有接触面单元的面以及与嵌入衬砌相连的面将不予考虑。

附着逻辑完全通用：它可以成功附着两侧任意分布的网格点或面。不过，如果从一条边到下一条边的点数总是按整数倍增加（例如每两个点对应三个网格点），并且附着面的一侧始终比另一侧的面更小，则效果最佳。

示例应用以及关于限制的进一步讨论，请参见连接相邻基本形状（Connecting Adjoining Primitive Shapes）。

创建、销毁或操作附着条件需要下列关键字之一。

delete <range>

移除给定范围内所有从属网格点上的附着条件。如果未提供范围，则移除所有附着条件。

by-face keyword ... <range>

在网格中搜索范围内的所有表面面。此处的表面面定义为未与另一侧的网格单元完全拓扑连接的面。对于共面且相互接触（在容差范围内）的面，将自动在一侧的网格点与另一侧的面之间生成附着条件。面较小的一侧将被选为附着侧（从属侧）。

以下可选关键字用于控制选择哪些面和网格点进行附着。

snap b

如果 snap 设为 开启（on）（默认值），则从属网格点的位置会移动到与其从属的主网格点位置一致，无论在设置时还是在计算循环过程中都是如此。如果 snap 设为 关闭（off），从属网格点将随主网格点相对移动，但其位置可能不同。

tolerance-absolute f

如果指定，f 是从属网格点与目标面之间为创建附着条件所允许的最大绝对距离。默认值为 0.0，表示改用相对容差方案。

tolerance-angle f

仅当两个面之间的夹角小于 f 度时才进行附着。默认该值为 5 度。对于会产生非平面的复杂曲面，有时需要增大此容差。

tolerance-relative f

仅当距离处于 f 乘以面形心位置绝对值所得的范围内时，网格点才会附着到面上。默认值为 1x10-5。如果网格创建存在额外误差，可能需要增大此值。[CS：请核查；此处用法含糊（过去时？误差何时“was”]

gridpointid ID 值（ids ）keyword

将 ID 号为 ID 值（ids） 的单个网格点附着到：另一个网格点、两个网格点之间的边，或网格单元面。需要下列关键字之一来指明附着条件的目标。

to-gridpointid 单元标记索引（idm ）<snap b >

将该网格点附着到 ID 为 单元标记索引（idm） 的网格点。默认情况下 snap 为 开启（on），这会使网格点 ID 值（ids） 移动到与网格点 单元标记索引（idm） 相同的位置，无论在设置时还是在计算循环过程中都是如此。

关键字： to-edgeids ID1 值（id1 ）第二个 ID（id2 ）keyword ...

ID 号为 ID 值（ids） 的网格点附着到由网格点 i1 与 i2 之间连线所定义的边上。

可应用下列可选关键字之一。

weight f

可给出可选关键字 weight 来定义网格点 ID 值（ids） 在网格点 i1 与 i2 之间的位置。如果 weight = 0.0，则 ID 值（ids） 位于 i1 处；如果 weight = 1.0，则 ID 值（ids） 位于 i2 处。如果未指定，该加权值将根据网格点 ID 值（ids） 的位置自动计算。

snap b

默认情况下 snap 为 开启（on），这会使网格点 ID 值（ids） 自动移动到由 i1 与 i2 之间的加权所确定的位置，无论在设置时还是在计算循环过程中都是如此。

关键字： to-faceid 单元深度索引（idz ）侧索引（iside ）keyword ...

ID 号为 ID 值（ids） 的网格点附着到 ID 为 单元深度索引（idz） 的网格单元的第 侧索引（iside） 面。 紧急：CS：此处引用的章节似乎不存在（参见 :flag2:-命令参考 第 1.1.4 节 网格单元内节点与面的方向-）。]

可应用下列可选关键字之一。

weight f1 f2 f3 f4

可给出可选关键字 weight，以相对于面的顶点来定义网格点 ID 值（ids） 在面 单元深度索引（idz）、侧 1 索引（iside1） 上的位置。所给的四个值均须介于 0.0 与 1.0 之间，且其和应为 1.0（假定从属位置位于该面上）。例如，第一个顶点的位置对应 1.0、0.0、0.0、0.0，而面中心对应 0.25、0.25、0.25、0.25。

snap b

默认情况下 snap 为 开启（on），这会使网格点 ID 值（ids） 自动移动到由网格单元面 单元深度索引（idz）、侧 1 索引（iside1） 上的加权所确定的位置，无论在设置时还是在计算循环过程中都是如此。

group s keyword ... <range>
对给定范围内（如果指定）的网格点附着数据结构进行分组（Group）。可应用下列可选关键字之一。
slot s

将该分组指派到槽位 s。

remove

从范围内的所有附着条件中移除分组 s。如果未指定 slot，则会从找到该分组的所有槽位中将其移除。

list <range>

列出范围内所有附着条件的信息。该信息包括从属网格点、主目标以及（在适用时的）加权因子。
