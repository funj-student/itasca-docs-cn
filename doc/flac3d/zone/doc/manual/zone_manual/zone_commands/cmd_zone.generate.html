zone generate 命令

语法

zone generate keyword

主要关键字：

本命令可用的关键字如下：从构建块（from-building-blocks）    从挤出器（from-extruder）    按地形生成（from-topography）    按几何集生成（from-geometry）

这组命令基于某种算法生成网格单元，通常依据其他某种数据结构。以下关键字可用：

from-building-blocks <set s >

从当前块体构建集生成网格单元。参见 building-blocks 命令。如果使用可选关键字 set，则将从名为 s 的集（而非当前集）生成网格单元。

from-extruder <keyword ...>

从当前挤出器集生成网格单元。

area-check b

指定生成网格单元时是否应检查下层子单元的面积。默认值为“true”。如果将“Area-Check”设为“true”，而每个叠加层中三角形子单元的面积 \(\le\) 整个单元面积的 10%（在二维“挤出”窗格中），则将产生错误。

from-topography <keyword ...> <range>

通过将范围内的表面面挤出直至与几何集中的多边形相交来生成网格单元。

关于使用此选项创建网格单元的讨论与示例，可参见地表地形与分层（Surface Topography and Layering）。

geometry-set s

指定用于定义网格单元所挤出到的表面的几何集。默认将使用当前几何集。

segments i

指定在现有表面网格单元面与几何集之间创建的网格单元层数。默认此值为 1。

direction v

指定用于在表面面上创建网格单元的挤出方向。从表面网格点出发，沿此方向投射射线，直至与几何集中的多边形相交。这将确定所创建网格单元的形状和尺寸。默认此值为 (0,0,1)。如果某个面的法向与该方向矢量平行（容差约为 0.5 度），则即使该面在范围内，也会被忽略。

ratio f

指定用于从表面面到几何集分布网格单元的比率。比率 1.1 表示该方向上每个网格单元边长为前一个网格单元边长的 1.1 倍。如果未指定，默认比率为 1.0。

group s1 <slot s2 >

将为所创建的网格单元指派分组 s1，槽位为 s2。如果未指定，默认槽位为 默认（Default）。分组逻辑的用法在分组（Groups）中介绍。

face-group s1 <slot s2 >

为通过挤出所选原始面而创建的新表面面指派槽位 s2 中的分组 s1。默认不指派分组名。如果未指定，所用槽位为 默认（Default）。

from-geometry <keyword ...>

通过识别几何集中的闭合体积并创建填充该体积的网格单元来生成网格单元。该命令分三步运行：首先对原始表面（面）进行三角剖分以创建初始粗网格；其次使用用户指定的参数，用三角形单元或混合单元（以四边形为主模式）重新划分初始网格；最后调用体网格划分器，用四面体网格单元或混合网格单元（以六面体为主模式）填充各体积。默认情况下使用以六面体为主的模式（表面网格为以四边形为主）。请注意，输入表面应为平面，以便正确进行三角剖分。

以下可选关键字可用。

set s

指定用于定义网格单元所挤出到的表面的几何集。默认将使用当前几何集。

minimum-edge f

指定沿边的最小表面单元尺寸 f > 0。实际尺寸将接近该值，但不保证结果完全精确。

maximum-edge f

指定沿边的最大表面单元尺寸 f > 0。实际尺寸将接近该值，但不保证结果完全精确。

size-surface f

指定表面网格上所需的单元尺寸。随着单元远离边缘，其尺寸趋向于该值（如果 > 0，依据 Gradation-Surface 参数）。此参数可用于使表面单元更细或更粗。默认值 0 表示尺寸将根据沿边的单元尺寸自动确定。

gradation-surface f

指定沿边的单元尺寸的渐变率 f > 0（从 Minimum-Edge 到 Maximum-Edge 的渐变），以及表面网格内部（当指定 Size-Surface 时）的渐变率。接近 0 的值会导致更渐进的过渡。默认值为 0.5。

size-volume f

指定闭合体积内所需的网格单元尺寸。当网格单元远离边界面（表面网格）时，其尺寸趋向该值。默认值 0 表示尺寸将根据表面单元尺寸自动确定。

gradation-volume f

指定闭合体积内网格单元尺寸（从表面单元尺寸到 Size-Volume 参数所定义尺寸）的渐变率 f > 0。接近 0 的值会导致更渐进的过渡。默认值为 0.5。

cut-angle f

指定用于界定表面重划分网格所用初始表面片（初始三角化网格中相连三角形构成的组）的切割角。两个相邻三角形之间的夹角大于此值时，将在两个片之间划定界线。较小的值往往产生大量小片，最终网格接近初始网格但质量可能较差。较大的值往往产生较少的大片，更有利于重划分网格，但最终网格可能偏离初始网格更远（几何误差增大）。默认值为 20°，45° 应视为最大值。

tetrahedron

如果指定，则仅生成四面体网格单元。

bring-to-building-blocks

如果指定，则体积离散化的结果也将发送到块体构建集。

grid-file s

如果指定，则体积离散化的结果将发送到输出文件 s（不生成网格单元）。如果存在 Bring-To-Building-Blocks，则 Grid-File 关键字无效。
