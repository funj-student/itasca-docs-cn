zone face list 命令

语法

zone face list keyword <range>

主要关键字：

apply    groups    information

列出关于网格单元面的信息。

apply <keyword>

列出网格单元面上施加条件的值和类型。若省略可选关键字，则默认使用 conditions。

conditions

列出已在面上创建的施加条件。它并不逐一列出每个面上的每个条件，而是列出所创建的各个独立的施加条件。例如，命令 单元面施加应力法向（zone face apply stress-normal） 无论涉及多少个单独的面，都只会创建一个条目。此关键字不使用范围短语。

items

显示正在施加到范围内每个面上的条件。

items-gridpoints

显示正在施加到范围内每个网格点上的条件列表，这些条件由施加于相连面的条件引起。此关键字中的范围短语作用于所有网格点的列表。

groups

列出指派给范围内每个面的分组，以及构成该面的网格点和两侧的网格单元。

information

对范围内的每个面，列出与其相连的网格点 ID、两侧的网格单元、隐藏与选择状态以及存在的任何分组指派。
