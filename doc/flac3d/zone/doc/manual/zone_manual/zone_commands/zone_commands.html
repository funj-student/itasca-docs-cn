命令

对网格单元进行操作。此处列出的命令：

  • zone 命令（zone commands）
  • zone face 命令（zone face commands）
  • zone gridpoint 命令（zone gridpoint commands）
  • zone interface 命令（zone interface commands）

关于 FLAC3D 网格单元（zone） 的详细说明及其实现与结构，请参见三维显式有限体积模型的公式（Formulation of a 3D Explicit Finite Volume Model）一节。

网格单元通过网格点相互连接。

网格单元可以借助接触面节点和单元，通过接触面逻辑跨表面相互作用。

网格单元面可用于跟踪和命名网格单元表面。需要注意的是，并不存在真正独立的网格单元面数据结构。网格单元面仅是与各个网格单元边界建立的关联。因此，网格单元面没有唯一的 id 编号，而是由网格单元 ID 编号与侧面编号配对，或由网格点 ID 编号列表来标识。
