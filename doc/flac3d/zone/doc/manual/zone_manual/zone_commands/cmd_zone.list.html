zone list 命令

语法

zone list <keyword> <range>

主要关键字：

本命令可用的列表关键字如下，用于输出网格单元的各项信息（各关键字含义见下文）：density    extra    fluid-density    网格点（gridpoint）    分组（group）    hysteretic    information    join    力学（mechanical）    pore-pressure    principal    principal-effective    剖面（profile）    property    状态（state）    strain    strain-increment    strain-rate    应力（stress）    stress-effective    summary    tetrahedra

列出网格单元数据。若未给出关键字，命令的默认输出即与 information 关键字关联的输出。

density

网格单元质量密度。

extra i

数组索引为 i 的附加网格单元变量。

fluid-density

网格单元流体密度（仅在已指定 配置流体计算模式（model configure fluid） 时可用）。

gridpoint

与网格单元相关联的网格点 ID 号。

group <slot s >

网格单元分组指派。如果使用 slot 关键字，则仅显示槽位 s 中的分组。

hysteretic

列出每个网格单元的滞回阻尼指派及参数值（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用；详情参见滞回阻尼（Hysteretic Damping））。

information

网格单元的一般信息：网格单元类型（砖块、楔形等）、所指派的本构模型、密度、体积和形心。

join

网格单元面（接合）连接

mechanical

网格单元力学计算的一般信息。大应变设置、节点混合离散设置、阻尼设置、最大局部力比的位置等。

pore-pressure

网格单元孔隙压力（由网格点值平均得到）

principal

网格单元的总主应力分量。

principal-effective

网格单元的有效主应力分量。

profile keyword

在沿一条线等间距分布的点上列出网格单元场变量（zone field variable）的值。

可用的网格单元场变量汇总如下：

acceleration [zonelistblock]

网格点处的加速度大小（仅在已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-x [zonelistblock]

网格点处的 x 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-y [zonelistblock]

网格点处的 y 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

acceleration-z [zonelistblock]

网格点处的 z 向加速度（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

condition [zonelistblock]

衡量网格单元变形严重程度的量（参见网格单元状态量（Condition Measure of Zones））。

density [zonelistblock]

网格单元的密度。

displacement [zonelistblock]

网格点处的位移大小

displacement-x [zonelistblock]

网格点处的 x 向位移

displacement-y [zonelistblock]

网格点处的 y 向位移

displacement-z [zonelistblock]

网格点处的 z 向位移

extra [zonelistblock]

额外变量的值。所用的额外变量索引默认为 1，可通过 index 修饰符关键字更改。该值默认取自网格点的额外变量，但可通过 source 修饰符关键字指定。该值默认按标量浮点类型处理，但可通过 type 修饰符关键字指定。

factor-of-safety [zonelistblock]

该网格点所能保持稳定的最大安全系数。仅在完成 设置安全系数分析参数（model factor-of-safety） 计算后可用。velocity-limit 关键字用于指定速度大小，超过该值的网格点在给定安全系数下视为不稳定。

pore-pressure [zonelistblock]

网格单元中的孔隙压力。默认情况下为网格点孔隙压力，但可使用 source 关键字修饰符指定网格单元平均压力。

property [zonelistblock]

网格单元力学本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

property-fluid [zonelistblock]

网格单元流体本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

property-thermal [zonelistblock]

网格单元热学本构模型的属性。属性名称必须通过 name 关键字修饰符指定。默认情况下假定该属性为浮点标量，但可通过 type 修饰符关键字指定。

ratio-local [zonelistblock]

各网格点处的局部不平衡力比率。与所有结果一样，可使用 :lkwd:’log’ 关键字修饰符将其换算为该值的对数。

saturation [zonelistblock]

网格点处的饱和度（仅当已指定 配置流体计算模式（model configure fluid） 时可用）

strain-increment [zonelistblock]

网格单元的应变增量张量，由当前位移场确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

strain-rate [zonelistblock]

网格单元的应变率张量，由当前速度场确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress [zonelistblock]

网格单元的应力张量，由各子网格单元应力的加权平均确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress-effective [zonelistblock]

网格单元的有效应力张量，由各子网格单元应力的加权平均减去网格单元平均孔隙压力确定。用 quantity 关键字指定要从该张量中提取哪个标量值。

stress-strength-ratio [zonelistblock]

当前应力与该网格单元破坏面的比值，由当前网格单元本构模型确定。并非所有本构模型都支持该计算。若不支持，则返回值为 10。返回值一般以 10 为上限。

temperature [zonelistblock]

网格点处的温度。可用 source 修饰关键字改为指定采用基于网格单元的温度。

timestep-dynamic [zonelistblock]

该特定网格点的局部临界动力时步。（仅当已指定 模型配置动力分析命令（model configure dynamic） 时可用）

unbalanced-force [zonelistblock]

网格点处的不平衡力大小。

unbalanced-force-x [zonelistblock]

网格点处的 x 向不平衡力。

unbalanced-force-y [zonelistblock]

网格点处的 y 向不平衡力

unbalanced-force-z [zonelistblock]

网格点处的 z 向不平衡力

velocity [zonelistblock]

网格点处的速度大小

velocity-x [zonelistblock]

网格点处的 x 向速度

velocity-y [zonelistblock]

网格点处的 y 向速度

velocity-z [zonelistblock]

网格点处的 z 方向速度

property keyword ...
赋给网格单元的材料属性。每种本构模型的属性名称随模型定义一起列出（参见 本构模型（Constitutive Models） 一节中的模型定义）。
state <keyword>

塑性状态指示量。默认关键字为 any。

any

列出该网格单元任一四面体子网格单元中所有塑性状态标志的并集（默认）。

average

如果超过 50% 的四面体子网格单元处于该塑性状态，则输出该状态。

strain

列出剪应变率、剪应变增量、体积应变率和体积应变增量。应变率基于当前速度场，应变增量基于当前位移场。

strain-increment

应变增量张量，基于当前位移场。

strain-rate

应变率张量，基于当前速度场。

stress

网格单元总应力的分量。

stress-effective

网格单元有效应力的分量。

summary

网格单元模块状态汇总。

tetrahedra

列出网格单元各四面体子网格单元处的值。

gridpoint

与每个子网格单元相关联的四个网格点。

information

每个子网格单元的体积与形心位置。

principal

每个子网格单元的当前主应力，包括方向。

principal-effective

每个子网格单元的当前主有效应力，包括方向。

stress

每个子网格单元中的当前应力张量。

stress-effective

每个子网格单元中的当前有效应力张量。


zone list 关键字块

以下修饰符可用于为 列出单元剖面命令（zone list profile） 关键字提供附加信息。剖面位置必须使用 begin、end 和 segments 关键字来指定。以下关键字可用：acceleration、acceleration-x、acceleration-y、acceleration-z、condition、density、displacement、displacement-x、displacement-y、displacement-z、extra、factor-of-safety、pore-pressure、property、property-fluid、property-thermal、ratio-local、saturation、strain-increment、strain-rate、应力（stress）、stress-effective、应力强度比（stress-strength-ratio）、温度（temperature）、timestep-dynamic、unbalanced-force、unbalanced-force-x、unbalanced-force-y、unbalanced-force-z、velocity、velocity-x、velocity-y 和 velocity-z。

begin v

指定剖面线的起点。

component keyword

该关键字用于选择从矢量类型的值（如速度或位移）中提取哪个标量分量。若值类型不是矢量，则忽略该设置。可用的选项有：

x

矢量的 x 分量

y

矢量的 y 分量

z

矢量的 z 分量

magnitude

矢量的模

end v

指定剖面线的终点。

index i

对于需要索引的关键字（最典型的是 extra），此参数指定应使用的索引。默认值为 1。

gravity b

若为 开启（on），则返回的施加力中包含重力。默认值为 关闭（off）。

gridpointid i

通过 ID 号为 i 的网格点的位置来指定历史记录的位置。

log b

若为 开启（on），则返回的数值为原始值绝对值的以 10 为底的对数。默认值为 关闭（off）。

method

该关键字指定用于将基于网格单元的量插值到空间任意位置（包括网格点位置）的计算方法。

constant

假定数值在网格单元内部为常数。这是默认选项。位于网格点处或网格单元边界上的值将选取一个相邻网格单元来计算。

average

该方式使用与该网格点相连的所有网格单元的体积加权平均值。

inverse-distance-weight

该方式使用该点紧邻区域内最多 32 个网格单元的加权平均值。权重由网格单元形心到指定点距离的幂确定。

power f

指定用于对数值加权的距离幂次。默认的幂值为 3.0。

radius-ratio f

指定所选网格单元距该点的最大距离之比，该比值用于计算加权值。距离超过该值的网格单元将被折减。默认值为 0.75。

polynomial <tolerance f >

根据该点附近的网格单元，使用多项式函数拟合。退化自由度会被检测并剔除。可选的 tolerance 标志可用于更改检测退化所用的值。默认值为 1e-7。

name s

某些关键字（最典型的是 property）需要给出名称值才能完整指定。该名称决定所提取的具体属性名。

null

指定忽略网格单元值的判据。默认忽略 mechanical null 网格单元。

fluid b

若将该选项设为 开启（on），则流体本构模型为空的网格单元也会被忽略。

mechanical b

若将该选项设为 开启（on），则忽略力学本构模型为空的网格单元（这是默认设置）。

thermal b

若将该选项设为 开启（on），则忽略热学本构模型为空的网格单元。

position v

在 v 处指定历史记录的位置。该位置必须位于某个网格单元内部。

quantity keyword

该关键字用于选择从对称张量类型的值（如应力或应变）中提取哪个标量分量。若值类型不是张量，则忽略该设置。可用的选项有：

intermediate

中间主应力

maximum

最大（最正）的主应力值。请注意，在 FLAC3D 中压应力为负值（compressive stresses are negative）。

mean

平均压力值，定义为张量的迹除以 3。对于应力，该量通常称为压力。

minimum

最小（最负）主应力。注意在 FLAC3D 中压应力为负（compressive stresses are negative）。

norm

应变率的范数；参见 网格场数据名称（Zone Field Data Names） 中的公式

octahedral

八面体应力；参见 网格场数据名称（Zone Field Data Names） 中的公式

shear-maximum

最大剪应力

total-measure

在主空间中张量值到原点的距离

volumetric

体积变化，即迹

von-mises

Von Mises 度量；参见 网格场数据名称（Zone Field Data Names） 中的公式

xx

张量的 xx 分量

xy

张量的 xy 分量

xz

张量的 xz 分量

yy

张量的 yy 分量

yz

张量的 yz 分量

zz

张量的 zz 分量

segments i

指定沿剖面线从 begin 到 end 均匀分布的点数。

source keyword

某些关键字（如 extra 和 pore-pressure）既可从网格单元结构、也可从网格点结构提取。默认值为 gridpoint。

gridpoint

数值直接取自网格点。

zone

从网格单元中提取数值。

stress b

少数张量类型的 quantity 选项会根据该值是否被视为应力而具有不同行为。当该值来自 extra 之类的变量时，无法自动判定。此选项允许用户指定传入的张量值应按应力处理。

type keyword

某些情况下无法事先确定值的类型（标量、向量或张量）。例如额外变量可保存全部三种类型的值。该关键字可指定假定其为何种类型。若原值类型不匹配，则返回 0.0。

scalar

标量浮点类型。这是默认值。

vector

矢量类型。

tensor

张量类型。

velocity-limit f

指定用于判定对象在给定 factor-of-safety 值下是否稳定的速度限值。默认值为 1e-4。

zoneid i

指定历史记录的位置位于 ID 为 i 的网格单元的形心处。
