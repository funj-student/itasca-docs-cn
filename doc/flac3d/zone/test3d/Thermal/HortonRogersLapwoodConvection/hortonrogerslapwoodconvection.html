底部加热的饱和多孔介质中的稳态对流

注意

要在 FLAC3D 中查看此工程，请使用菜单命令 帮助 ‣ 示例…。选择“Thermal/ HortonRogers LapwoodConvection”，再选择“HortonRogers LapwoodConvection.f3dprj”即可加载。该工程的主数据文件（main data files）在本示例末尾给出。

多孔层底部加热时的稳态对流问题（Horton-Rogers-Lapwood 对流问题）是一个经典的对流应用。考虑一个厚度和横向范围均有限的饱和层。层的顶部和底部温度固定。边界对流体流动不透水，侧向边界绝热。问题的解取决于 Rayleigh 数 \(Ra\) 的值，该数在本问题中定义为

(1)\[Ra = {k \over k^T} (\rho_0 c_w) \cdot (\rho_0 g H) \beta_f (T_1 - T_0)\]

其中 \(H\) 为层的高度，\(T_1\)、\(T_0\) 分别为底部和顶部温度（例如见 Lapwood，1948）。当 Rayleigh 数低于最小临界值 \(4 \pi^2\)（约 39.48）时，问题具有平凡稳态解，其对应于比流量为零（导热解）。当 Rayleigh 数高于 \(4 \pi^2\) 时，还可能存在对流胞形式的非平凡解。物理上可实现多种不同的稳态对流模式；本节考虑不同的几何长宽比和 Rayleigh 数，并寻求其中一些解。

饱和多孔立方体

第一个示例涉及立方体中的二维对流。按模型采用的性质和尺寸，本问题的 Rayleigh 数约为 42。该值大于临界值 \(4 \pi^2\)。因此可以预期存在非平凡解。我们将说明其中一种解：一个二维卷，并将其与由线性稳定性分析导出的解析解进行比较。首先，从计算方法的说明开始。本示例的数据文件为“HRL-Convection-Cube-LowRa.dat”。

我们取导热解作为初始条件（见自然对流（natural convection）中的方程 (1) 和 (3)）。在 FLAC3D 中，对流体求解瞬态方程，因此必须提供流体体积模量的值。在现有算法中，该值影响模拟所采用的稳定时步的大小。我们选取 2 × 105 Pa，这意味着，对于显式模拟中所采用的性质值和网格单元尺寸，流体时步比热时步小一个数量级。

对于显式计算模式，我们将热时步固定为 5.5 × 1010 秒、流体时步固定为 5.5 × 109 秒。随后用 FISH 语言设计一个“supersolve”命令，在计算中每个超级步执行一个热步和 10 个流体流动步。这样，执行每个超级步后，热时间与流体时间即同步。

显式计算模式对本问题非常低效。另外，为减少计算时间，我们采用隐式计算模式，并将热模拟和流体模拟的时步均放大十倍。

隐式计算的设置如下

zone fluid implicit on
zone thermal implicit on
model fluid   timestep fix 5.5e10
model thermal timestep fix 5.5e11

隐式模式的命令列于下文（below）。

对于这类问题，可能存在多个解（一个导热解和一个或多个对流解，取决于 Rayleigh 数）。通常得到的是导热解，且往往需要一个小扰动才能使系统分岔到某个可能的对流解（例如性质的随机分布，或轻微倾斜重力）。在本示例中，我们通过在 \(x\) 方向将重力角度倾斜 0.06° 获得了二维卷。该扰动施加有限个计算步后被移除。请注意，若在无任何扰动的情况下将同一示例运行足够长的时间，似乎存在足够的数值噪声使解发生分岔，但此时会形成三维对流胞。

图 8（Figure 8） 中所示的温度云图（接近临界 Rayleigh 数时立方体中的二维卷）可与由线性扰动理论导出的 1 阶模态二维解析温度等值线值（例如见 Zhao 等 1997）进行比较，后者绘于图 10（Figure 10）。二维解析解的形式为

(2)\[{{T - T_0} \over {T_1 - T_0}} = C_1 {\rm cos} \bigl(\pi {x^{\ast} \over H} \bigr) {\rm sin} \bigl(\pi {y^{\ast} \over H} \bigr) + \bigl(1 - {z^{\ast} \over H} \bigr)\]

其中 \(x^{\ast} = x + {H \over 2}\)、\(y^{\ast} = y + {H \over 2}\)、\(z^{\ast} = z + {H \over 2}\)，而 \(C_1\) 为常数，此处通过要求 \(x^{\ast}\) = 0、\(z^{\ast} / H\) = 0.5 处数值与解析温度值相等来确定。


图 10：温度云图，解析稳态解，Rayleigh 数 = \(4\pi^2\)。

model new
model title '3D convection in a 4x1x1 porous box - Ra = 42 - medium'
fish automatic-create off
model config fluid thermal
program call 'HRL-Convection-FISH' suppress
[setup]
; --- 几何形状 ---
zone create brick size 48 12 12 point 0 -2e4 -5e3 -5e3 ...
                                point 1 2e4 -5e3 -5e3  ...
                                point 2 -2e4 5e3 -5e3  ...
                                point 3 -2e4 -5e3 5e3
zone face skin
; --- 热学、流体和力学模型 ---
zone thermal cmodel assign advection-conduction
zone fluid cmodel assign isotropic
zone cmodel assign elastic
; --- 参数 ---
;    （力学）
zone property bulk=[_bulk] shear=[_shear]
zone initialize density 2000 
;    （热学）
zone thermal property conductivity=[_condu] specific-heat=[_mspec]
zone thermal property conductivity-fluid=[_fcond] specific-heat-fluid=[_fspec]
zone thermal property expansion-fluid=[_fthex] expansion=[_thexp]
zone thermal property temperature-reference=20.0
;    （流体）
zone fluid property porosity=[_poros] permeability=[_mobil]
zone fluid property biot=1 undrained-thermal-coefficient=0
zone fluid biot off
zone gridpoint initialize fluid-modulus=2e5 
zone gridpoint initialize fluid-tension=-1e10
zone initialize fluid-density=[_fdens]
; --- 初始条件 ---
zone gridpoint initialize pore-pressure 0.5e8 grad 0 0 -1e4
zone initialize stress-xx -1.05e8 grad 0 0 2.1e4
zone initialize stress-yy -1.05e8 grad 0 0 2.1e4
zone initialize stress-zz -1.05e8 grad 0 0 2.1e4
; --- 边界条件 ---
zone face apply temperature [_T1] range group 'Bottom'
zone face apply temperature [_T0] range group 'Top'

model gravity 0 0 [-_grav]          
zone fluid implicit on
zone thermal implicit on
