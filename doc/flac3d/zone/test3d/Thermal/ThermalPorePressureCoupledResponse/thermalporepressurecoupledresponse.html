热—孔隙压力耦合响应

注意

本示例的项目文件可在 FLAC3D 中查看/运行。[1] 该项目的主数据文件见本示例末尾（main data files）。

提供了两个简单示例以说明热—流体流动—力学应力耦合响应。两个示例均涉及一个饱和且不排水的单元。第一个示例中单元无侧限，第二个示例中单元完全受限。两种情况下均通过热源使温度升高。

对于无侧限试验，单元发生膨胀、孔隙压力降低。由于单元边界自由，总平均应力保持为零。

无侧限情形下体应变的解析解为

(1)\[\Delta \epsilon _v\ =\ {{\alpha\ M \ \beta +\ 3K\ \alpha_t\ } \over {K +\ \alpha^2 \ M}} \Delta T\]

而孔隙压力变化的解析解为

(2)\[\Delta p\ =\ M\ (- 3 \alpha\ \alpha_t +\ \beta ) \Delta T\]

其中：

\(\alpha\) = Biot 系数；

\(M\) = Biot 模量；

\(\alpha_t\) = 排水线性热膨胀系数；

\(\beta\) = 不排水体积热膨胀系数；

\(K\) = 排水体积模量；以及

\(\Delta T\) = 温度变化。

在受限试验中，体积变化为零，且孔隙压力因温度升高而增大。由于单元边界固定，此情形下总平均应力增大。

总平均应力变化的解析解为

(3)\[\Delta \sigma_{ii}\ =\ -\ (3K \alpha_t +\ \alpha M \beta) \Delta T\]

而孔隙压力变化的解析解为

(4)\[\Delta p\ =\ M \beta \Delta T\]

参数及其无量纲值为：

密度（\(\rho\)） 1
体积模量（\(K\)） 0.67
剪切模量（\(G\)） 0.4
孔隙率（\(n\)） 0.5
Biot 模量（\(M\)） 4
Biot 系数（\(\alpha\)） 1
线性热膨胀系数（\(\alpha_t\)） 3
不排水体积热膨胀系数（\(\beta\)） 5
导热系数（\(k\)） 1
比热（\(C_p\)） 1
温度增量（\(\Delta T\)） 0.4

对于无侧限试验，由方程(1)和(2)计算得到的 \(\Delta \epsilon _v\) \((\Delta \epsilon _v = \Delta \epsilon _{11} + \Delta \epsilon _{22} + \Delta \epsilon _{33})\) 和 \(\Delta p\) 的值分别为 2.230 和 -0.918。FLAC3D 的结果与这些值一致（差异小于 0.01%）。

对于受限试验，计算得到的总平均应力变化 \(\Delta \sigma_{ii}\) 和孔隙压力变化 \(\Delta P\) 分别为 -10.412 和 8.000。两个值与方程(3)和(4)的解析值之差均小于 0.01%。

数据文件

model new
fish automatic-create off
model title 'Undrained thermo-poro-elastic unconfined and confined tests'
model large-strain off
model configure fluid thermal
program call 'fishFunctions'
; ------- 主计算 -------
zone create brick size 1 1 1 point 1 (1,0,0) point 2 (0,1,0) point 3 (0,0,1)
; --- 力学模型
zone cmodel assign elastic
zone property density [c_dens] bulk [c_k] sh [c_g]
; --- 流体流动模型
zone fluid cmodel assign isotropic
zone fluid property undrained-thermal-coefficient [c_u_thc]
zone fluid biot on
zone gridpoint initialize biot [c_biom]
zone gridpoint initialize fluid-tension -1e10
; --- 热学模型 
zone thermal cmodel isotropic
zone thermal property conductivity [c_cond] specific-heat [c_cv] ...
             expansion [c_thex]
;
zone apply source 1. range position-z -1 2
model save 'tpe_cpl-ini'

; --- 无围压试验
; 设置
model fluid active off
model thermal timestep fix 8e-4
; 试验
model mechanical active off 
model thermal active on
model step 500
model mechanical active on 
model thermal active off 
model fluid active off
model step 500
[ana_sol(0)]
model save 'tpe_cpl-unconfined'
fish list [v_strain] [delta_p]
fish list [err_vol] [err_pp]

; --- 有围压试验
model restore 'tpe_cpl-ini'
; 设置
zone gridpoint fix velocity ; <--- 施加围压
model fluid active off
model thermal timestep fix 8e-4
; 试验 
model mechanical active off 
model thermal active on
model step 500
model mechanical active on 
model thermal active off
model step 500
[ana_sol(1)]
model save 'tpe_cpl-confined'
fish list [delta_sxx] [delta_p]
fish list [err_sxx] [err_pp]

program return
