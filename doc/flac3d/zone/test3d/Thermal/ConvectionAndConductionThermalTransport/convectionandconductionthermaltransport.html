强制对流与导热作用下热输运的一维解

注意

要在 FLAC3D 中查看此工程，请使用菜单命令 帮助 ‣ 示例…。选择“Thermal/ ConvectionAndConduction ThermalTransport”，再选择“ConvectionAndConduction ThermalTransport.f3dprj”即可加载。该工程的主数据文件（main data files）在本示例末尾给出。

本示例说明正向和反向强制对流对温度分布的影响，其对应于厚度为 \(L\) 的饱和平面板中的正向导热。不考虑自然对流，且在整个模拟过程中达西通量保持恒定。板的顶部和底部温度固定。温度最初均匀且等于 \(T_0\)，随后在顶部突然升高至 \(T_1\)。随时间推移监测板内温度的演化。

在稳态时，能量平衡方程（该方程（this equation）及其后三个方程）的一维形式可表示为

\[{{\partial^2 \hat T} \over {\partial \hat x^2}} - P_e {{\partial \hat T} \over {\partial \hat x}} = 0\]

其中 \(\hat T = (T - T_0)/ T_0\)、\(\hat x = x / L\)，坐标原点位于板的底部，\(x\) 向上，\(P_e = \rho_0 c_w q_w L / k^T\)，\(P_e\) 为 Peclet 数，\(q_w\) 为 \(x\) 方向的比流量。

在 \(\hat x = 0\) 处 \(\hat T = 0\)、在 \(\hat x = 1\) 处 \(\hat T = \hat T_1\) 的边界条件下，其解为

\[\hat T = \hat T_1 {{e^{P_e \hat x} - 1} \over {e^{P_e} - 1}}\]

工程中提供了用于与解析解比较的全局 FISH 常量和 FISH 函数。本次模拟的 Peclet 数量级为 1.54。对流—导热的数值解（实线）与纯导热的解析解（符号）在图 1（Figure 1） 和 图 2（Figure 2） 中进行了比较。从这些图中可以看出，流体流动的影响使温度曲线沿流动方向偏移。

对流—导热的 FLAC3D 温度分布与稳态解析解在图 3（Figure 3） 和 图 4（Figure 4） 中进行了比较。从这些图可以看出，对于本次特定模拟，两者吻合非常好。

数值模拟可在启用流体配置（见“ConvectionAndConductionThermalTransportFluidOn.dat”）或不启用流体配置（见“ConvectionAndConductionThermalTransportFluidOff.dat”）的情况下进行，也可采用附着的网格（见“ConvectionAndConductionThermalTransportFluidAttach.dat”）。这三种数据文件分别对应于上述三种建模方式。

通过针对不同的网格 Peclet 数和 Courant 数运行这些文件，可以了解 FLAC3D 中所实现数值算法的稳定性。例如，通过改变网格密度和比流量，可以得出算法保持稳定的网格 Peclet 数和 Courant 数取值范围。（见稳定性与精度（Stability and Accuracy）中关于数值稳定性的讨论。）

数据文件

ConvectionAndConductionThermalTransportFluidOn.dat

model new
model title 'Conduction/Advection in a plane sheet - config fluid'
fish automatic-create off
model configure thermal fluid
;
zone create brick size 1 1 25 point 1 (0.1,0,0) point 2 (0,0.1,0) ...
                              point 3 (0,0,1)
zone face skin
; --- 加载 FISH 常量和函数 ---
program call 'fishFunctions' suppress
; --- 热学模型 ---
;  （无需指定有效属性）
;  （设置材料密度无需力学模型）
;  （f_thexp = 0，因此不存在自然对流）
zone thermal cmodel advection-conduction
zone thermal property conductivity 1.6 specific-heat 0.2
zone thermal property conductivity-fluid 0. specific-heat-fluid 0.2
; --- 流体模型 ---
zone fluid cmodel assign isotropic
zone fluid property permeability 2 porosity 0.5
zone fluid biot off
zone gridpoint initialize fluid-modulus 50
zone initialize fluid-density 1
zone initialize density 1000 

zone face apply temperature 100 range group 'Bottom'
zone face apply temperature   0 range group 'Top'
model save 'cond-adv_fl-on_init'

; 正向对流
zone face apply pore-pressure 5. range group 'Bottom'
zone face apply pore-pressure 0. range group 'Top'
model mechanical active off 
model thermal active off
model fluid active on
model step 1000
model mechanical active off 
model fluid active off 
model thermal active on
model step 20
[cons]
[num_sol]
[ana_sol]
model step 80
[num_sol]
[ana_sol]
model step 900
[num_sol]
[ana_sol]
[ssac_sol]
model save 'cond-adv_fl-on_fwd'

; 反向对流
model restore 'cond-adv_fl-on_init'
zone face apply pore-pressure 5. range group 'Top'
zone face apply pore-pressure 0. range group 'Bottom'
model mechanical active off 
model thermal active off
model fluid active on
model step 1000
model mechanical active off 
model fluid active off 
model thermal active on
model step 20
[cons]
[num_sol]
[ana_sol]
model step 80
[num_sol]
[ana_sol]
model step 900
[num_sol]
[ana_sol]
[ssac_sol]
model save 'cond-adv_fl-on_bwd'

program return

ConvectionAndConductionThermalTransportFluidAttach.dat

model new
model title ...
      'Conduction/Advection in a plane sheet - attached grid/config fluid'
fish automatic-create off
model configure thermal fluid
; --- 加载 FISH 常量和函数 ---
program call 'fishFunctions' suppress
; 上部细网格连接到下部粗网格
zone create brick size 1 1 10 point 0 (0,0,0)     point 1 (0.1,0,0)   ...
                              point 2 (0,0.1,0)   point 3 (0,0,0.5)
zone create brick size 2 2 15 point 0 (0,0,0.5)   point 1 (0.1,0,0.5) ...
                              point 2 (0,0.1,0.5) point 3 (0,0,1)
zone attach by-face range position-z .499 .501
; --- 热学模型 ---
;  （无需指定有效属性）
;  （设置材料密度无需力学模型）
;  （f_thexp = 0，因此不存在自然对流）
zone thermal cmodel advection-conduction
zone thermal property conductivity 1.6 specific-heat 0.2
zone thermal property conductivity-fluid 0. specific-heat-fluid 0.2

zone fluid cmodel assign isotropic
zone fluid property permeability 2 porosity 0.5
zone fluid biot off
zone gridpoint initialize fluid-modulus 50

zone initialize density 1000 
zone initialize fluid-density 1

zone face apply temperature 100 range position-z 0
zone face apply temperature   0 range position-z 1

model save 'cond-adv_fl-att_init'

; 正向对流
zone face apply pore-pressure 5. range position-z 0
zone face apply pore-pressure 0. range position-z 1

; --- 首先建立流场 ---
model mechanical active off 
model thermal active off

model step 4000
; --- 设置 ---

model fluid active off 
model thermal active on

; （平流–传导结果用实线绘制）
model step 20

model mechanical active off

; --- 设置 ---

model step 20
[cons]
[num_sol]
[ana_sol]

[num_sol]
[ana_sol]

[num_sol]
