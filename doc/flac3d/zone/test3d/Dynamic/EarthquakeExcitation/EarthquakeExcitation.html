均匀土层的一维地震激励

注意

要在 FLAC3D 中查看此项目，请使用菜单命令 帮助 ‣ 示例…。选择“Dynamic/EarthquakeExcitation”并选择“EarthquakeExcitation.f3prj”以加载。 该项目的主数据文件见本示例末尾（main data files）。其余数据文件可在项目中找到。

提供了一个由数字化地震波激励的 20 m 土层的示例，以说明在涉及波传播、多重嵌套循环以及相当大循环应变的情况下使用滞回阻尼时，能够给出合理的行为。

数字化地震记录从名为“gilroy1.acc”的文件导入。土层底部和中部的 应力/应变滞回环分别示于 图 1（Figure 1） 和 图 2（Figure 2），三个位置的加速度 历史示于 图 3（Figure 3） 至 图 5（Figure 5）。模拟为一维，仅在剪切方向施加激励。请注意，本示例中初始应力为零。如果指定了非零的初始竖向和水平应力状态，则左右边界应附着，以形成一维模拟。

滞回模型似乎能以合理方式处理多重嵌套循环。模型 底部的能量耗散明显大于中部。最大 循环应变约为 0.1%。时步大小不受滞回 阻尼影响。

检查初始剪应力状态 —— 在实验室试验中，初始剪应力假定为零，因此滞回环通常是对称的。在实际应用中，初始剪应力不太可能为零（例如路堤表面附近的土单元中）。滞回阻尼的使用者必须确定材料初始状态的最佳估计，因为 FLAC3D 中的滞回公式依赖于剪应变的既往历史。可以区分两种情形：

  1. 如果在施加一组平衡应力之后才激活滞回阻尼，则初始剪应变为零，剪应力的循环往复将倾向于关于起始点对称。
  2. 如果初始应力是在滞回阻尼处于活动状态下通过对模型施加应变而建立的，则后续剪应力的循环往复将倾向于不对称，因为应变的初始偏置使应力较高一侧的应力/应变曲线斜率更平缓。

通过修改这一简单应用来说明这些情形。在初始剪应力为零的情况下，模型的循环响应几乎对称，如 图 1（Figures 1） 和 2 所示。

在 20 m 土层中初始化 0.1 MPa 的均匀剪应力，并在边界施加相等的静剪应力以保持初始 平衡，然后重复模拟。将以下命令加入数据文件。

; 初始条件
zone initialize stress-xz 1e5

以及在边界条件部分：

zone face apply stress-xz 1e5 range union position-z=0 position-z=20

所得动力响应与原模拟相同，但滞回环整体上移了 0.1 MPa。图 6（Figure 6） 显示了模型底部的结果；请与 图 1（Figure 1） 比较。这对应于上述情形 1。

图 6：土层底部的剪应力与剪应变关系；剪应力仅初始化为 0.1 MPa。

为使初始应变与初始应力相协调， 安排滞回阻尼在初始应力状态建立期间处于活动状态。对于该情形， 在数据文件中施加边界条件的部分加入以下命令。

zone face apply stress-xz 1e5 range union position-z=0 position-z 20
; 启用滞回阻尼并求解至平衡
zone dynamic damping hysteretic default -3.325 0.823
zone dynamic damping local 0.7
model solve
; 重置模型
zone gridpoint initialize velocity (0,0,0)
zone dynamic time-total 0
zone dynamic damping local 0.0

剪应力施加于网格边界，但不在网格内部初始化。因此，采用静力求解（为加快收敛，在滞回阻尼之外再加上局部阻尼）来建立内部应力。由于静力求解期间滞回阻尼处于活动状态，动力模拟开始时应变将与应力相协调。系统的动力响应由 图 7（Figure 7） 中绘制的应力/应变滞回环表示。该情形下存在明显的不对称。土体（由于初始应力/应变状态）已经部分屈服。沿同一加载方向进一步应变会产生更多屈服，而沿相反方向应变最初则起减小屈服的作用。这对应于上述情形 2。

图 7：土层底部的剪应力与剪应变关系。剪应力为 0.1 MPa，静力求解后的初始应变为 0.041%。

在滞回阻尼处于活动状态下进行完整静力求解、以获得应力和应变相协调的起始状态，这种方法可用于更 复杂的模型，例如坡面区域含有初始剪应力的路堤。该方法的一个缺点是，随着接近平衡状态，静力求解可能涉及许多逐渐衰减的振荡循环。虽然这些循环往往很小（几乎不影响所需的应力状态），但它们会使许多状态存储在内存栈上（见滞回阻尼公式、实现与标定（Hysteretic Damping Formulation, Implementation and Calibration））。这些存储的状态在动力加载初期即从栈中删除，但它们占用内存，并在计算时间上带来一些初始开销。在 FLAC3D 的未来版本中，或许可以加入相应逻辑，允许用户在静力初始化结束时清空栈，同时保留最新的应力相容应变状态用于采用滞回阻尼的动力模拟。

数据文件

EarthquakeExcitation.dat

;---------------------------------------------------------------------
; 动力问题所用脚本文件
; 均匀层的一维地震激励
;---------------------------------------------------------------------
fish automatic-create off
model new
model large-strain off
model title 'One-dimensional earthquake excitation of uniform layer'
model configure dynamic
; 创建网格单元
zone create brick size 1 1 20
; 分配本构模型和属性
zone cmodel assign elastic
zone property density 1000 shear 5e8 bulk 10e8
; 边界条件
zone gridpoint fix velocity-y
zone gridpoint fix velocity-z
table 'acc' import 'gilroy1.acc'
zone face apply acceleration-x -0.02 table 'acc' range position-z=0
; 历史
model history name='time' dynamic time-total
zone history name='sxz1' stress-xz zoneid = 1
zone history name='exz1' strain-increment-xz zoneid = 1
zone history name='sxz10' stress-xz zoneid = 10
zone history name='exz10' strain-increment-xz zoneid = 10
zone history name='acc00' acceleration-x position (0,0, 0)
zone history name='acc10' acceleration-x position (0,0,10)
zone history name='acc20' acceleration-x position (0,0,20)
; 设置阻尼，循环计算至时间 25
zone dynamic damping hysteretic default -3.325 0.823
model solve time-total 25
model save 'EarthquakeExcitation'
