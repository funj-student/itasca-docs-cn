承压层中的非稳定地下水流动

注意

要在 FLAC3D 中查看此工程，请使用菜单命令 帮助 ► 示例…。选择“Fluid/UnsteadyGroundwaterFlowConfinedLayer”，再选择“UnsteadyGroundwaterFlowConfinedLayer.f3dprj”即可加载。该工程的主数据文件（main data files）在本示例末尾给出。

一条宽度为 \(L\) = 100 m 的长路堤位于浅层饱和土层上。路堤的宽度（\(L\)）远大于土层厚度，且其渗透率与土体的渗透率 \(k\) = 10-12 m2/(Pa sec) 相比可忽略不计。测得土体的 Biot 模量为 \(M\) = 10 GPa。均质层中已达到初始稳态条件。本示例的目的是研究当上游水位瞬时抬升 \(H_0\) = 2 m 时层内孔隙压力的变化。这对应于路堤上游侧孔隙压力升高 \(p_1 = H_0 {\rho}_w g\)（水的密度 \({\rho}_w\) = 1000 kg/m3，重力加速度 \(g\) = 10 m/s2）。图 1（Figure 1） 给出了问题的几何：

图 1：土层中的承压流动。

可假定层内流动为一维。模型宽度为 \(L\)。初始为零的超孔隙压力 \(p\) 在模型一端突然升高至值 \(p_1\)。相应的解析解具有以下形式

\[\hat{p}(\hat{z},t)\ =\ 1 - \hat{z} - {2 \over {\pi}} \sum_{n=1}^\infty e^{- n^2\pi^2 \hat{t}}\left({\sin {n \pi \hat{z}} \over n}\right)\]

其中 \(z\) 轴沿路堤宽度方向，原点位于上游侧，\(\hat{p} = {p\over p_1}\)、\(\hat{z} = {z \over {L}}\)、\(\hat{t} = c t/L^2\) 和 \(c = M k\)。

在 FLAC3D 模型中，该层定义为由 25 个网格单元组成的柱体。位于 \(z\) = 0 的面上的超孔隙压力固定为 2 × 104 Pa，位于 \(z\) = 100 m 的面上的超孔隙压力固定为零。模型网格见图 2（Figure 2）。

解析解编写为 FISH 函数，以便在与 \(\hat{t}\) = 0.05、0.1、0.2 和 1.0 相对应的选定流体流动时间直接与数值结果进行比较。这些时刻的解析和数值孔隙压力结果存储在表格中。

图 2：承压土层中流体流动的 FLAC3D 网格。

UnsteadyGroundwaterFlowConfinedLayer-Explicit.dat 包含本问题的 FLAC3D 数据文件，采用显式格式求解。UnsteadyGroundwaterFlowConfinedLayer-Implicit.dat 包含采用隐式格式的数据文件。显式解在四个流体流动时刻的解析与数值超孔隙压力比较见图 3（Figure 3），隐式解见图 4（Figure 4）。两图中绘制的是归一化超孔隙压力（\(p/p_1\)）随归一化距离（\(z/L\)）的变化，其中表 2、4、6 包含超孔隙压力的解析解，表 1、3、5 包含 FLAC3D 解。显式和隐式解对应的四个流动时间均为 5 × 104、105、2 × 105 和 106 秒。所考虑的最后一个时刻已达到稳态条件。对于两种求解格式，稳态时解析与数值孔隙压力之差均小于 0.1%。

数据文件

UnsteadyGroundwaterFlowConfinedLayer-Explicit.dat

model new
model large-strain off
model title 'Unsteady groundwater flow in a confined layer: Explicit Method'
fish automatic-create off
model configure fluid
program call 'fishFunctions'
[constants]
zone create brick size 1 1 25 point 1 (10 0 0) point 2 (0 10 0) ...
                              point 3 (0 0 [length])
; --- 流体流动模型 ---
zone fluid cmodel assign isotropic
zone fluid biot on
zone fluid property permeability [c_cond] 
zone gridpoint initialize biot [c_biom]
zone face apply pore-pressure [dp1] range position-z 0
zone face apply pore-pressure 0    range position-z 100
; --- 设置 ---
model mechanical active off
model fluid active on
;
model solve fluid time-total  5e4
zone gridpoint list fluid range position-x -0 position-y 0
[num_sol]
[ana_sol]
model solve fluid time-total 10e4
[num_sol]
[ana_sol]
model solve fluid time-total 20e4
[num_sol]
[ana_sol]
model solve fluid time-total 100e4
[num_sol]
[ana_sol]
model save 'confinedlayer-explicit'
