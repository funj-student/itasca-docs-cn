采用 CYSoil 模型的排水三轴试验——恒定剪胀

注意

要在 FLAC3D 中查看此项目，请使用菜单命令 帮助 ► 示例…。 选择“ConstitutiveModels/ DrainedTriaxialConstantDilationCYSoil”并选择“DrainedTriaxialConstantDilationCYSoil.f3dprj”以加载。 该项目的主数据文件见本示例末尾（main data file）。

使用 CYSoil 模型（CYSoil model）对密砂、中密砂和松砂进行三轴试验模拟。 模型特性列于表 1（Table 1）。本示例不考虑 帽盖屈服；因此 flag_cap 设为 0（默认值）。在这种情况下，需要初始 压力 \(p_{ini}\)，程序用它计算体积模量和剪切模量。 剪胀为恒定值；因此 flag_dilation 设为 1，并为剪胀 特性赋值。初始应力状态为各向同性，平均压力等于 100 kPa。试验过程中围压 保持恒定，模型底部在轴向（\(y-\)）方向固定，并在模型顶部施加 10-6 m/步的轴向速度。此外，还进行了三次 卸载/再加载循环。

表 1：CYSoil 模型特性
参数 密砂 中密砂 松砂
\(G_{ref}\) 300 225 150
\(\phi_f\) 40 35 30  
\(\psi_f\) 10 5 0
\(c\)   0 或 100 kPa  
\(p_{ref}\) (kPa)   100  
\(p_c\) (kPa)   100  
\(\nu\)   0.2

无黏聚力模拟的偏应力与轴向应变关系图见 图 1（Figure 1），其中包括密砂、中密砂和松砂三种情况。该图显示了模型预期的双曲线行为，以及越密的土所达到的更高破坏水平。 图中还显示了三段卸载/再加载循环。无黏聚力模拟的体积应变与 轴向应变关系图见 图 2（Figure 2）。 图中体积行为呈单调变化；密砂的剪胀行为清晰可见。 黏聚力设为 100 kPa 的模拟的相应结果示于 图 3（Figure 3） 和 图 4（Figure 4）。 从图 3（Figure 3）可以看出，有黏聚力砂的初始刚度高于无黏聚力砂。同样，有黏聚力材料的破坏偏应力也更高。

数据文件

DrainedTriaxialConstantDilationCYSoil.dat

model large-strain off
; 排水三轴试验——恒定剪胀角
model title "Drained triaxial test - cap-yield-soil"
;
zone create brick size 1 1 1
zone face skin
zone cmodel assign cap-yield
;
zone initialize stress xx -100. yy -100. zz -100.
zone face apply stress-norm -100. range group 'East' or 'West'
zone face apply stress-norm -100. range group 'North' or 'South'
zone face apply velocity-z     0. range group 'Bottom'
zone face apply velocity-z -1e-6  range group 'Top'
;
zone property density 1000 pressure-reference=100. exponent=1.0 ...
              beta=0.35 poisson 0.2
zone property flag-dilation=1 friction-mobilized=0 
zone property shear-reference=[_Gref] friction=[_friu] ...
              cohesion=[_coh] dilation=[_dilu] 
zone property flag-cap=0 pressure-initial=100. 
;
fish define _cy_q
    local _z = zone.head
    global _cy_q = zone.prop(_z, 'stress-deviatoric')
    global _vsi  = zone.strain.vol.inc(_z)
end
;
history interval 50
zone history displacement-z position (1,1,1)
fish history _cy_q
fish history _vsi
;
fish define trip
    loop local i (1,3)
        command
            zone face apply velocity-z -1e-6 range group 'Top'
model step 8000
            zone face apply velocity-z  1e-7 range group 'Top'
            mode step 6000
            zone face apply velocity-z -1e-7 range group 'Top'
model step 6000
        end_command
    end_loop
end
;
model step 3000
[trip]
zone face apply velocity-z -1e-6  range group 'Top'
model step 23000
;
history export '2' vs '1' reverse table 'deviatoricStress'
history export '3' vs '1' reverse table 'volumetricStrain'
table 'deviatoricStress' ...
      export [string.build('deviatoricStress%1', _IChoice)] truncate 
table 'volumetricStrain' ...
      export [string.build('volumetricStrain%1', _iChoice)] truncate 
;
