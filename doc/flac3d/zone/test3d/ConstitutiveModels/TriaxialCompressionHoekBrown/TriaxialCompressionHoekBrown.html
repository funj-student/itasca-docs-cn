采用 Hoek-Brown 模型的三轴压缩试验

注意

本示例的项目文件可在 FLAC3D 中查看/运行。[1] 该项目的主数据文件见本示例末尾（main data file）。

使用 Hoek-Brown-PAC 模型进行的三轴压缩试验（triaxial compression tests） 针对Hoek-Brown 模型（Hoek-Brown model）重复进行，材料特性相同：

\(m_b\) 5
\(s\) 0.5
\(\sigma_{ci}\) 1.0 MPa
\(\sigma^{cv}_3\) 1.5 MPa
\(E\) 100 MPa
\(\nu\) 0.35

进行两次压缩加载试验：

在零围压下，\(\sigma_{3}/\sigma_{ci}\) = 0，以及

在高围压下，\(\sigma_{3}/\sigma_{ci}\) = 1。

对于零围压情况，我们指定相关联流动法则；这通过以下命令实现：

zone property flag-dilation = -1

对于较高围压情况，我们需要指定一个剪胀角， 使其与为 Hoek-Brow-PAC 模型的三轴压缩试验（triaxial compression test for the Hoek-Brow-PAC model）所选定的极限恒体积应力 \(\sigma^{cv}_3\) = 1.5 一致。 我们相对于 \(\sigma^{cv}_3\) = 1.5 处的非关联零剪胀，对应当前围压水平 \(\sigma_{3}\) = 1 的剪胀值进行线性插值。 然后，当前剪胀 \(\psi_c\) 取为当前摩擦角 \(\phi_c\) 的某一比例， 使用线性插值：

\[{\psi_c \over \phi_c} = 1 - {\sigma_3 \over \sigma^{cv}_3} = 0.333\]

以下命令用于对该情况应用修正的 Hoek-Brown 模型：

zone property flag-dilation = 0.333

零围压情况下的 FLAC3D 结果与解析解进行了比较（见 采用 Hoek-Brown-PAC 模型的三轴压缩试验（Triaxial Compression Test with Hoek-Brown-PAC Model））， 比较见图图 1（Figure 1）和 图 2（Figure 2）， 高围压情况的结果比较见图 图 3（Figure 3）和 图 4（Figure 4）。

数据文件

TriaxialCompressionHoekBrown.dat

; 修正 Hoek–Brown 材料的三轴试验，
model new
model large-strain off
fish automatic-create off
model title "Triaxial Test on a Hoek-Brown material"
program call 'input_record'
[input]
zone create brick size 1 1 1
zone cmodel assign hoek-brown
zone property density = 1.0 shear=[shear]    bulk=[bulk]
zone property constant-sci=[sig_ci] constant-mb=[mb] ...
              constant-s=[s] constant-a=[a]
[locptrs]
zone face apply velocity-y [y_vel] range position-y 1.0
zone face apply velocity-y [-y_vel] range position-y 0.0
fish history record_variables
history interval 1000
fish history eps_xx
fish history eps_yy
fish history eps_yy
fish history sig_xx
fish history sig_yy
fish history sig_zz
model save 'ini'
; 无围压
zone property flag-dilation = -1
[global sig_conf=0.0]
zone face apply stress-xx = [sig_conf]
zone face apply stress-zz = [sig_conf]
zone initialize stress xx = [sig_conf] yy = [sig_conf] zz = [sig_conf]
model step [cyc]
model save 'conf0'
; 有围压
model restore 'ini'
zone property flag-dilation = 0.333
[global sig_conf=-1.0]  ; 负值表示压缩
zone face apply stress-xx = [sig_conf]
zone face apply stress-zz = [sig_conf]
zone initialize stress xx = [sig_conf] yy = [sig_conf] zz = [sig_conf]
model step [cyc]
model save 'conf1'
