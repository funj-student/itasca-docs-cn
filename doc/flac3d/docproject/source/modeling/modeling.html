FLAC3D 建模

本部分旨在总体介绍 FLAC3D，并概述程序的使用。这里介绍的许多主题在帮助的后续部分中有更详尽的说明。本部分分为三个主要部分。

  • 介绍（Introduction）

顾名思义，本部分帮助用户初步了解程序、其功能、工具和实用程序，以及设计思路和用途。

  • 教程（Tutorials）

本节最适合希望立即上手的用户。它包含若干教程，逐步指导使用 FLAC3D 所涉及的最基本任务。

  • 使用 FLAC3D 解决问题（Problem Solving with FLAC3D）

本节详细介绍用于构建 flac3d model 的顺序建模方法。

本部分（FLAC3D 建模）之后各节的内容可简要概括如下：

FLAC3D 理论与背景（FLAC3D Theory and Background）——提供 FLAC3D 基本组成部分的背景信息和理论基础说明。

可选模块（Options）——提供可选模块的完整文档。

示例（Examples）——提供应用示例、验证问题以及帮助文档中所有其他示例的访问入口。

上述内容构成 FLAC3D 专用文档部分；此外，文档的其他主要部分还包括以下内容。

程序指南 > 程序运行机制（Program Guide > Program Mechanics）——概述在程序中开展建模项目的方法。此处包含大部分用户界面文档。

脚本（Scripting）——提供在模型中使用 FISH 和 Python 进行脚本操作的完整参考文档。

这些部分放在 FLAC3D、PFC 或 3DEC 各节之外，因为其内容与这些程序全部相关。
