达到平衡

设置完初始条件时、模型计算结束时，以及可能存在的多个中间阶段，模型都需要达到“平衡”。到目前为止的示例中，通过简单的 求解模型（model solve） 命令实现这一点。但如何知道已经达到平衡？如何判断计算循环数是否超过需要，或模型的某个局部是否仍需继续计算？

FLAC3D 的计算循环可以通过 执行计算时步命令（model step） 或 执行计算时步（model cycle） 命令手动执行。在某些情况下，这很有用，最常见的是在边界规定了速度后，希望步进至达到特定总位移。但一般而言，您希望循环至满足某个条件——例如，动力模拟可以循环至经过指定时间。求解模型（model solve） 命令允许持续循环，直到满足一个或多个限制条件（通过后续关键字指定）。在静力模型中，最常关注的限制是“直到模型达到平衡”。

由于 FLAC3D 使用基于物理规律的迭代过程达到静力平衡，因此所谓“处于平衡”与完全收敛到静力解的含义相同。FLAC3D 提供多种方式，用于度量和显示模型距离收敛或平衡状态还有多远。不过，与往常一样，对相关问题了解越充分，模型就越可能高效而准确。

收敛准则

FLAC3D 提供五种不同准则，用于判断何时达到平衡：最大不平衡力、局部力比、平均力比、最大力比和收敛值。以下分别说明这些选项（更详细的公式见不平衡力及力比计算（Out-of-Balance Force and Ratio Calculation））。

最大不平衡力

第一种也是最简单的收敛度量称为最大不平衡力。尽管现在已不常用，但它仍可用作 求解模型（model solve） 准则，也可通过 FISH 内置函数 zone.unbal 获取。

模型中的每个网格点（或结构节点）都受到网格单元、结构单元、重力等产生的力。将这些力相加，得到作用于网格点的净力。最大不平衡力是所有力求和后剩余力的任一分量绝对值的最大值。该力驱动网格点趋向平衡。如果该力为零，可认为网格点已收敛或处于平衡。

作为总体收敛度量，最大不平衡力的主要缺点是它并非无量纲量。适当的目标值取决于模型尺寸、网格单元尺寸、材料性质和应力量级。无法提供一个可用作经验法则的统一数值。这也是它不再常用作求解准则的原因。

局部最大力比

局部力比是衡量网格点局部收敛情况的无量纲量。其思路很简单：将各力求和后剩余的不平衡分量，除以施加于该网格点的总力的某种度量。为提高性能，采用矢量的“曼哈顿范数”，也称“出租车范数”，定义为：

\[\langle v_i \rangle = |v_x| + |v_y| + |v_z|\]

即矢量各分量绝对值之和。于是，局部力比可定义为：

\[\frac{\langle \sum_i f_i\rangle}{\sum_i \langle f_i \rangle}\]

其中，\(f_i\) 为施加到某网格点上的全部力矢量。

局部最大力比是模型中所有网格点局部力比的最大值。这是衡量模型收敛情况的一种非常保守的指标。不过，当某网格点承受的力少于两个，或作用于该点的全部力均沿同一方向时，它存在缺陷。此时，唯一可能的“平衡”状态是分子和分母都趋近于零，而二者的比值将趋近于 1。

FLAC3D 会检测仅有一个力向量作用于网格点的情况，并自动将其排除。但如果多个同向力作用于同一网格点，或者第二个力相对于主要驱动力可以忽略，这项检查就不够充分。这些点会主导最大局部力比，使模型看起来始终无法有效收敛。

实际中，这种情况并不常见，大多数模型都不会遇到。但它确实会发生，因此为保证任意模型都能采用默认准则收敛，求解模型（model solve） 没有将最大局部力比作为默认收敛准则。

网格点最后计算的局部力比会被存储，可在 FISH 中通过 节点局部力比（gp.ratio） 获取，也可在绘图项中作为局部力比使用。

平均力比

平均力比定义为所有网格点不平衡力分量之和，除以施加于各网格点的全部力的总和。即：

\[\frac{ \sum_j^n \langle \sum_i f_i \rangle }{ \sum_j^n \sum_i \langle f_i \rangle }\]

该指标能够可靠衡量系统的整体收敛情况。对于相对均匀的模型，它表现很好。其稳健性足够高，因此 求解模型（model solve） 的默认收敛准则设为 ratio-average 1e-5。

不过，对于很不均匀的模型，局部收敛问题的影响可能被平均过程掩盖，用户因而无法察觉某个可能最受关注的区域仍需计算。这种情况可能由网格单元尺寸差异或较大的刚度差异引起。对于大型复杂模型，在信赖该指标之前，应仔细检查。见下文讨论。

最大力比

最大力比定义为最大不平衡力，除以作用于所有网格点的平均总力。平均总力定义为：

\[\frac{\sum_j^n \sum_i \langle f_i^j \rangle}{N}\]

其中，\(N\) 为模型中的网格点总数。

收敛

convergence 求解方式的提出，是为了让用户能更好地控制所需的收敛判据，并克服依赖局部力比可能带来的缺点。

首先，创建一个称为局部力比目标值的新网格点场变量。在每个网格点和节点处，该值默认为 1e-4。可以通过 初始化单元网格点目标力比（zone gridpoint initialize ratio-target） 命令和 FISH 内置函数 节点目标力比（gp.ratio.target） 修改。该值表示对该特定网格点而言可视为“收敛”的局部力比。这意味着网格不同位置的局部收敛准则可以不同。

我们定义一个新量，直截了当地称为收敛值，即当前局部力比与目标局部力比之比。因此，收敛值为 1.0 时视为“已收敛”。最大收敛值则度量模型总体收敛程度，与 求解模型（model solve） 中的 convergence 关键字关联。收敛值可用于绘图项，也可在 FISH 中通过 节点收敛值（gp.convergence） 内置函数获取。默认情况下，convergence 为 1.0，与 ratio-local 限值为 1e-4 完全相同。

如果局部力比计算在特殊情况下失效，可以将该网格点或节点的 ratio-target 设为较大值，实际上将其从整体收敛准则中排除。此外，模型中很小的区域对达到收敛所需时间产生过大影响的情况并不少见，原因可能是这些区域很小、很刚硬，或二者兼有。例如，少量刚度很高的结构支护，常常会主导一个很大模型的收敛时间。确认放宽这些节点的准则对主要关注的模型结果影响可以忽略后，可将其 ratio-target 设为 1e-3 或更高。

力比

局部力比、最大力比、平均力比和收敛值这四种收敛度量，可以统一由 ratio 关键字引用。默认情况下，ratio 对应平均力比。可以用 zone ratio 命令指定 ratio 改为表示局部力比、最大力比或收敛值。这使用户可以选择由哪种准则驱动程序中与 ratio 值关联的各类伺服控制功能。

请注意，为使默认伺服设置总体保持有效，需要对某些收敛度量进行缩放，使其落入默认平均力比准则的预期范围。ratio-local 和 ratio-maximum 乘以 0.1，convergence 乘以 1e-5。

许多情况下，也可以使用 ratio-average、ratio-local、ratio-maximum 或 convergence 关键字，明确指定所采用的准则。

选择收敛准则

如果 求解模型（model solve） 命令未指定收敛准则，默认采用 ratio 为 1e-5。根据我们的经验，对于复杂程度一般的模型，平均力比 1e-5 大致对应局部力比限值 1e-4。因此，选取 1e-4 作为默认 ratio-target。

对于大多数工程应用，最大局部力比 1e-4 通常已经足够，甚至偏保守。对许多用途而言，最大局部力比 1e-3，甚至高至 1e-2 也可能足够。模型的中间阶段（开挖顺序等）尤其如此，因为每一步后都耗时达到“完全”收敛，对模型最终状态的影响可能微乎其微。

  • 一般建议在每个数据文件开始时，使用 zone ratio 和 structure ratio 命令，将默认准则设为 convergence。也可以明确采用基于 ratio-target 为 1e-4 的 convergence 为 1。如果计算时间有限，可考虑提高默认收敛值。无论是否提高这些目标收敛准则，我们都建议花时间评估模型，确保对您关注的结果而言已充分收敛。下一节讨论这一问题。

评估平衡状态

为便于说明，我们使用一个极其简化的模型：地表开挖区域周围设有加固墙。基本几何形状见图 1（Figure 1）。

图 1：沟槽开挖的简化示意模型。

首次演示的完整数据文件如下。请注意，为说明问题，此处有意未使用 单元松弛开挖（zone relax excavate）。

model new
model large-strain off
; 创建网格单元
zone create brick size 30 30 30
zone face skin
zone group 'Trench' range position (0,0,24) (3,6,30)
; 本构模型和参数
zone cmodel assign mohr-coulomb
zone property bulk 3e6 shear 2e6 density 1000
zone property cohesion 1e5 friction 25 tension 1e3
zone cmodel assign elastic range group 'Wall'
zone property bulk 3e6 shear 2e6 density 1000
; 边界条件
zone face apply velocity-normal 0 range group 'East' or 'West'
zone face apply velocity-normal 0 range group 'North' or 'South'
zone face apply velocity-normal 0 range group 'Bottom'
; 初始条件
model gravity 10
zone initialize-stresses
model solve
; 历史
model history mechanical ratio-average
zone history displacement-x position (3,0,30)
zone history displacement-z position (4,0,30)
; 开挖
zone delete range group 'Trench'
; 求解
model solve
model save 'simple'

应始终通过以下检查，确认模型是否真正达到足够的平衡程度。首先，记录主要关注区域的位移和／或速度时程。如果循环结束时，这些位移仍变化较快，则模型尚未调整完毕。其次，绘制局部力比或收敛度的图形（等值线和等值面）。收敛度等值面图尤其有助于判断模型何处收敛最慢，以及应该在等值线图中进一步检查哪些位置（可能需要使用切割平面查看模型内部）。

图 2（Figure 2） 显示平均力比时程和沟槽顶部位移时程。注意，平均力比采用对数坐标绘制。对于行为正常的模型，预期会出现这种对数坐标下近似线性（即指数式）的收敛。破坏或其他非线性行为会导致收敛出现扰动，而不受约束的渐进破坏会使曲线趋于水平。位移时程同样显示出典型的轻微欠阻尼响应。可以清楚看到，沟槽壁顶部已停止明显运动，模型实际上已达到平衡。

图 2：简单沟槽模型的平均不平衡力比与位移时程。

图 3（Figure 3） 显示检查收敛度等值线的结果。虽然模型大部分区域的收敛度远小于 1，但靠近表面的少量网格点仍明显较高。这是此类问题的典型现象；表面网格点具有相同的抵抗运动惯性质量，而应力产生的驱动力较小。底部网格点通常会（也需要）先收敛，微小调整逆重力方向传播，因此表面网格点最后收敛。如果采用更严格的 convergence 1 准则，模型达到平衡所需步数会再增加一半。这是否重要，取决于表面网格点相对较小的调整有多大意义。如果准确的地表沉降值十分关键，就可能必须作这一更改。

图 3：网格点收敛度等值线。

较大刚度差异的影响

为说明一些可能的困难，我们在开挖后向沟槽添加钢衬砌，引入较大的局部刚度差异。修改后的完整数据文件如下。

-model new
model large-strain off
; 创建网格单元
zone create brick size 30 30 30
zone face skin
zone group 'Trench' range position (0,0,24) (3,6,30)
zone face group 'Wall' internal ...
          range group 'Brick1' group 'Trench' position-z 24.1 30
; 本构模型和参数
zone cmodel assign mohr-coulomb
zone property bulk 3e6 shear 2e6 density 1000
zone property cohesion 1e5 friction 25 tension 1e3
; 边界条件
zone face apply velocity-normal 0 range group 'East' or 'West'
zone face apply velocity-normal 0 range group 'North' or 'South'
zone face apply velocity-normal 0 range group 'Bottom'
; 初始条件
model gravity 10
zone initialize-stresses
model solve
; 历史
model history mechanical ratio-average
zone history displacement-x position (3,0,30)
zone history displacement-z position (4,0,30)
; 开挖
zone delete range group 'Trench'
; 安装衬砌
struct shell create by-zone-face range group 'Wall'
struct shell property isotropic 10e9 0.1 thick 1
model solve
model save 'stiff'

修改后模型的历史见图 4（Figure 4）。虽然平均力比表现出类似特征，但历史表明模型尚未稳定到平衡状态。问题在于，刚度很大的结构墙导致较高的惯性质量（见为确保数值稳定而确定力学时间步（Mechanical Timestep Determination for Numerical Stability）），而驱动沉降的力不变。这意味着与壳单元连接的网格点运动相对缓慢，其收敛值落后于模型其他部分。最终，这一局部扰动可能被模型的大部分区域掩盖，使模型平均而言看似已经收敛。

图 4：带有高刚度加固墙的沟槽的平均不平衡力比和位移时程。

图 5：收敛值为 5 的等值面。

图 5（Figure 5） 中的收敛值等值面图显示，墙周围区域难以达到平衡。如果将采用的收敛准则改为

plot 'Isosurface' export bitmap filename 'Isosurface.png' -skip-test

那么模型将耗时更长，但也能达到有较大把握认为已经平衡的状态，如图 6（Figure 6）所示。
