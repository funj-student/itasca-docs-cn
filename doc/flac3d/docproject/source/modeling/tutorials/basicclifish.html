教程：使用 FISH

本节面向运行过本程序（至少求解过简单问题）、但尚未使用 FISH 语言的用户，不要求编程经验。为充分利用此处示例，应在本程序交互运行时亲自试用。可通过 i 控制台（Console）窗格，直接在命令行输入简短程序。每运行完一个示例，发出 新建模型（model new） 命令清除当前内容，为下一个示例做好准备。较长的 FISH 函数也可使用内置编辑器（editor）输入数据文件；这些文件可在编辑器中直接执行，也可在控制台中调用（调用数据文件（program call））。

在本程序的命令提示符（command prompt）处输入下例各行，并在每行末尾按 <Enter>。

定义 FISH 函数

fish define fname
    abc = 22 * 3 + 5
end

Note

In examples orchid is used to color highlight FISH symbols (variables and user-defined functions); bold violet is used to highlight FISH statement words and intrinsic functions.

注意，输入第一行后，命令提示符变为 FISH>；输入 end 语句后，恢复通常的提示符。这种变化可让您知道当前是在使用命令，还是在定义 FISH 函数。定义FISH函数命令（fish define） 语句后的所有行都作为 FISH 函数定义的一部分，直到输入 end 语句（statement）。不过，如果输入了包含错误的一行，例如在空行输入 \(=\) 符号，则会再次显示 Flac3d> 3dec> 提示符及错误信息。这种情况下，必须从 定义FISH函数命令（fish define） 语句开始，重新从头定义 FISH 函数。由于很容易出错，通常使用内置编辑器将 FISH 函数输入数据文件。这些文件既可直接从编辑器执行，也可使用 调用数据文件（program call） 命令执行，与不含 FISH 的本程序数据文件相同。稍后将介绍这一过程；现在继续在命令行中操作。假设前面的各行均正确输入，且当前看到 Flac3d> 3dec> 提示符，则可输入以下一行，“执行”上例定义的 fname 函数：

[fname]

该行会执行函数中定义的算术运算。下面一行

abc = 22 * 3 + 5

是一条“赋值语句”。出现等号时，会计算等号右侧表达式，并将结果赋予左侧变量。注意，算术运算遵循通常约定：加、减、乘、除分别使用 +、-、* 和 / 符号。^ 表示“乘方”。

上述操作创建两个对象：一个可按用户需要调用的函数对象，以及一个名为 abc 的变量；函数执行后，abc = 71。在全局符号（global symbols）控件组中，可以同时看到 fname FISH 函数与变量 abc。此外，还可以使用方括号调用内联 FISH 表达式，将 abc 的值输出到命令行：

[abc]

消息

71

将显示在命令提示符处。fname 与 abc 均使用下文介绍的内联 FISH 语法执行。定义符号 abc 后，就可以在本程序命令中引用它。FISH 函数可任意命名，但要让函数返回一个值，函数名应与函数内部更新的某个数值变量名相同，或者使用 return 语句 return，如下文所述。

变量

现在输入一个略有不同的程序，先使用 新建模型（model new） 命令清除旧函数并重置模型状态。

使用变量

model new
fish define abc
    hh = 22
    abc = hh * 3 + 5
end

这里引入一个“变量”FISH 变量 hh（hh），赋值为 22，并在下一行使用。注意，FISH 函数名已改为 FISH 符号 abc（abc），与函数中定义的 FISH 变量相同。如果通过内联 FISH 执行此函数，即 [FISH 符号 abc（abc）]，会出现与前例完全相同的输出。不过，现在有两个 FISH 符号。两者都有值，但一个（FISH 符号 abc（abc））称为“函数”，另一个（FISH 变量 hh（hh））称为变量。区别如下：

当引用一个 FISH 符号名称时，如果该符号对应函数，就执行关联函数；如果该符号不是函数名，则使用该符号的当前值。

将 FISH 函数名设为与函数内部赋值变量同名，是从 FISH 函数执行中提供返回值的一种方法。该机制经常使用，尤其在需要 FISH 历程（使用 创建FISH变量历程命令（fish history） 命令）或使用 FISH 回调（使用 设置FISH回调命令（fish callback） 命令）时。另一种方法是通过 return 语句退出函数。

以下试验有助于澄清变量与函数的区别。试验前请注意，内联 FISH 可以设置任意用户自定义 FISH 符号的值，不受该符号最初在哪个 FISH 函数中引入的限制。现在输入以下各行，但不要发出 新建模型（model new） 命令，因为需要将之前输入的程序保留在内存中：

[abc = 0] 
[hh = 0]
[hh]
[abc]
[hh]

前两行将 FISH 符号 abc（abc） 和 FISH 变量 hh（hh） 的值设为 0。由于第一行是赋值操作，函数 FISH 符号 abc（abc） 不会执行。注意，虽然其值已修改，FISH 符号 abc（abc） 仍引用同一个 FISH 函数。除非通过 定义FISH函数命令（fish define） 命令重新定义，FISH 符号 abc（abc） 始终指向所定义的 FISH 函数。两个赋值操作后，输出 FISH 变量 hh（hh） 的值。[FISH 符号 abc（abc）] 这一行执行 FISH 函数，并在命令行输出该次执行更新后的值。函数之所以执行，是因为 FISH 符号 abc（abc） 引用函数，且当前并不是给 FISH 符号 abc（abc） 赋值。因此，如最后一行所示，FISH 符号 abc（abc） 的值与 FISH 变量 hh（hh） 的值都已改变。

虽然强烈建议使用内联 FISH 语法操作 FISH 变量，但下面给出另一种可实现相同效果的语法：

[global abc=0, hh=0]
fish list [hh]
fish list [abc]
fish list [hh]

此处，第二条 列出FISH变量命令（fish list） 命令使 FISH 符号 abc（abc） 被执行，因为 FISH 符号 abc（abc） 是函数名称，从而更新 FISH 变量 hh（hh） 和 FISH 符号 abc（abc） 的值。

为检验理解，请输入下一示例中略作修改的命令序列，并解释为何显示结果不同。

使用 FISH 进行自定义计算

下例展示如何将三轴试样顶部压板的总荷载保存为历程，以供后续检查。

记录 FISH 变量的历程

model new
model large-strain off
zone create brick size 1 2 1
zone face skin
zone cmodel assign mohr-coulomb
zone property shear=1e8 bulk=2e8 cohesion=1e5 tension=1e10
zone face apply velocity (0,0,0) range group "South"
zone face apply velocity-y -1e-5 range group "North"
[ad1 = gp.near(0,2,0)]
[ad2 = gp.near(1,2,0)]
[ad3 = gp.near(0,2,1)]
[ad4 = gp.near(1,2,1)]
fish define load
    load = gp.force.unbal(ad1)->y + gp.force.unbal(ad2)->y  + ...
           gp.force.unbal(ad3)->y + gp.force.unbal(ad4)->y
end
fish history load
zone history displacement-y position (0,2,0)
model step 1000
plot item create chart-history history '1' vs '2' reverse on

注意，FISH 变量 load 等于另外四个变量 节点 y 向不平衡力（gp.force.unbal(index)->y） 的和。FISH 网格变量 节点不平衡力（gp.force.unbal） 是可在 FISH 程序中使用的网格量示例，称为 FISH 内置函数；网格相关内置函数的完整列表见网格单元网格点函数（Zone Gridpoint Functions）。FISH 内置函数通常对应预定义模型量，但有时也定义更复杂的模型操作。

本例中，FISH 内置函数 节点不平衡力（gp.force.unbal） 提供网格点不平衡力；其中 \(y\) 分量通过 ->y 获取；每次调用 节点不平衡力（gp.force.unbal） 都必须提供网格点内存地址或指针。地址通过函数 get_ad 查找，该函数使用 FISH 网格点内置函数 最近节点（gp.near），获取最接近全局（\(x,y,z\)）坐标 (0,2,0)、(1,2,0)、(0,2,1) 和 (1,2,1) 的网格点地址。创建历程后，在循环计算更新历程时，会执行 FISH 函数 load（改变历程更新频率，见 设置历程采样间隔命令（history interval） 命令）。由于函数内更新了 load 的值，即函数名与更新变量名相同，因此每次调用时历程都会包含更新值。计算结束后，可以像绘制预定义的本程序历程一样，直接绘制 load 历程（历程 1）。这一行强烈提示需要增加一个关于历程绘图的主题。同样，也可使用 FISH 函数对计算历程进行后处理或输出，以进一步分析。

下例展示如何监测某个网格单元中的应力。

记录 FISH 变量的历程

model new
model large-strain on

block create brick 0 10 0 10 0 10
block zone generate edgelength 10
block zone cmodel assign elastic
block zone property density 1000 bulk 1e9 shear 0.7e9 
block gridpoint apply velocity-z 0.0 range position-z -0.01 0.01
model gravity 0 0 -10
fish define stress_z
  zoneIdx = block.zone.near(5,5,5)
  stress_z = block.zone.stress.zz(zoneIdx)
end
fish history stress_z
model cycle 200
plot item create chart-history history '1' vs '2' reverse on

本例使用 FISH 内置函数 最近区块单元（block.zone.near），查找质心最接近 (5,5,5) 的网格单元指针。随后，FISH 内置函数 block.zone.stress.zz 提供该网格单元的 \(zz\) 应力。创建历程后，在循环计算更新历程时，会执行 FISH 函数 z 向应力函数 stress_z（stress_z）（改变历程更新频率，见 设置历程采样间隔命令（history interval） 命令）。由于函数内更新了 z 向应力函数 stress_z（stress_z） 的值，即函数名与更新变量名相同，因此每次调用时历程都会包含更新值。计算结束后，可以像绘制预定义的本程序历程一样，直接绘制 z 向应力函数 stress_z（stress_z） 历程（历程 1）。这一行强烈提示需要增加一个关于历程绘图的主题。同样，也可使用 FISH 函数对计算历程进行后处理或输出，以进一步分析。

凡是需要数值的本程序命令位置，都可以使用FISH内联表示法 []，代入 FISH 变量或函数的名称

这条简单规则是 FISH 一项强大功能的关键：范围、施加应力、属性等都可以在 FISH 函数中计算，并以符号形式用于本程序命令。因此，只需方便地改变参数，无须修改输入文件中的许多数值。

例如，假设已知材料的杨氏模量和泊松比。如果用户需要使用体积模量和剪切模量，可使用以下方程，通过 FISH 函数推导：

\[G={E\over2(1+\nu)}\]
\[K={E\over3(1-2\nu)}\]

可以按下例所示，将这些方程编入一个名为 FISH 函数 derive（derive） 的 FISH 函数：

FISH 函数计算体积模量和剪切模量

model new
fish define derive(y_mod,p_ratio)
    s_mod = y_mod / (2.0 * (1.0 + p_ratio))
    b_mod = y_mod / (3.0 * (1.0 - 2.0 * p_ratio))
end
[derive(5e8,0.25)]
[b_mod] 
[s_mod]

注意，通过给出函数 FISH 函数 derive（derive） 的名称，并将参数放在圆括号内来执行函数。此处参数分别为杨氏模量和泊松比，它们作为临时变量用于计算体积模量和剪切模量；因此 FISH 函数 derive（derive） 执行后，它们不会作为 FISH 变量存在。计算所得体积模量和剪切模量（分别为 体积模量变量 b_mod（b_mod） 和 剪切模量变量 s_mod（s_mod）），随后可按下例以符号形式用于本程序命令：

在本程序输入中使用符号变量

zone create brick size (2,2,2)
zone cmodel assign elastic
zone property bulk [b_mod] shear [s_mod]
zone list prop bulk
zone list prop shear

可按通常方式输出 bulk 和 剪切（shear），检查这些操作的结果，例如使用 列出单元属性命令（zone list property） 命令。

FISH 规则、语法与语句示例

选择 FISH 变量和函数名称非常灵活。名称可包含下划线字符（_）。名称必须以字母开头，即不能以数字或特殊字符开头，而且不能包含任何算术运算符（+、-、/、* 或 ^）。所选名称不能与任一 FISH 内置函数名称相同。FISH 变量名不区分大小写，因此 变量 aVariable（aVariable） 与 变量 AVARiable（AVARiable） 是同一个变量。

除在全局符号（global symbols）控件组中查看 FISH 变量／函数名称外，还可以使用 列出FISH变量命令（fish list） 命令获得全部当前变量和函数的列表。该命令将按名称字母顺序输出所有当前值。

fish list

现在研究如何通过 FISH 编程作出判断和执行重复操作。以下 FISH 语句可将程序的指定部分重复多次：

loop 循环变量 var（var） (a1, a2)

endloop

loop 和 endloop 是 FISH 语句（statements）；符号 循环变量 var（var） 表示循环变量，a1 和 a2 表示界定循环上下限的表达式或单个变量。下例展示如何用循环或重复序列，计算前十个整数的和与乘积：

受控循环：FISH

model new
fish define xxx
    sum  = 0
    prod = 1
    loop n (1,10)
        sum  += n
        prod *= n
    endloop
    io.out('The sum is ' + string(sum) + ' and the product is ' + string(prod))
end
[xxx]

本例中，循环变量 n 依次取 1 至 10，每取一个值，都执行循环内部（loop 与 endloop 之间）的语句。如前所述，可以用变量名或算术表达式替代数字 1 或 10。注意，exit 语句可跳出 FISH 循环，continue 语句可跳过当前循环剩余指令，进入下一次循环。

传统 for 循环：FISH

model new
fish define xxx
    sum  = 0
    prod = 1
    loop for (n = 1, n <= 10, n += 1)
        sum  += n
        prod *= n
    endloop
    io.out('The sum is ' + string(sum) + ' and the product is ' + string(prod))
end
[xxx]

除上述标准循环外，还可使用 loop foreach 结构，方便地遍历模型对象集合，例如网格单元、网格点、结构单元节点等。此时必须由 FISH 内置函数提供对象容器，例如 zone.list（FLAC3D）或 block.zone.list（3DEC）。loop foreach 的一个实际用途，是在本程序网格中设置弹性模量的非线性初始分布。假设某场地杨氏模量由以下方程给出：

\[E=E_\circ+c\sqrt{z}\]

其中，\(z\) 为地表以下深度，\(c\) 和 \(E\)∘ 为常数。可编写 FISH 函数，为网格设置合适的体积模量和剪切模量，如下例所示：

施加模量的非线性初始分布

model new
zone create brick point 0 (0,0,0) point 1 (-10,0,0) ...
                  point 2 (0,10,0) point 3 (0,0,-10)
zone cmodel assign elastic
fish define install(y_zero,cc)
    loop foreach pnt zone.list
        z_depth = -zone.pos(pnt)->z
        y_mod = y_zero + cc * math.sqrt(z_depth)
        zone.prop(pnt,'young') = y_mod
    endloop
end
[install(1e7,1e8)]
zone property poisson 0.25
plot item create zone contour property name 'young'

model new
block create brick 0 30 0 30 -30 0
block cut joint-set dip 36 dip-direction 270 spacing 6 number 20
block cut joint-set dip -58 dip-direction 270 spacing 6 number 20
block zone generate edgelength 2
block zone cmodel assign elastic

fish define install(y_zero,cc)
    loop foreach pnt block.zone.list
        z_depth = -block.zone.pos.z(pnt)
        y_mod = y_zero + cc * math.sqrt(z_depth)
        block.zone.prop(pnt,'young') = y_mod
    end_loop
end
[install(1e7,1e8)]
block zone property poisson 0.25
;plot item create block contour value property name 'young'

同样，可以通过输出或绘制剪切模量和体积模量，验证函数运行是否正确。

注意，loop foreach 适用于任意可索引的 FISH 类型，包括列表、映射、指向模型对象容器的指针，甚至字符串、矢量和张量。

在函数 install 中，循环遍历全局网格单元列表中的全部单元。FISH 语句 loop foreach 是 loop 语句（statement）的一种变体，将 单元指针 pnt（pnt） 依次设为 zone.list。 block.zone.list。中的各个网格单元。在循环内，使用每个网格单元质心的 \(z\) 坐标，根据上述方程计算杨氏模量。假定基准面或地表参考点为 \(z\) = 0。变量 单元位置（zone.pos）(单元指针 pnt（pnt）) 和 单元属性值（zone.prop）(单元指针 pnt（pnt）, 属性名 'young'（'young'）) 是 zone 内置函数。（回顾前文讨论过的 gridpoint 内置函数 节点不平衡力（gp.force.unbal）。）这里直接在 FISH 函数中设置属性，而不采用前例中的 设置网格单元属性（zone property） 命令。 变量 单元位置（block.zone.pos）(单元指针 pnt（pnt）) 和 单元属性（block.zone.prop）(单元指针 pnt（pnt）, 属性名 'young'（'young'）) 是 zone 内置函数。这里直接在 FISH 函数中设置属性，而不采用前例中的 设置块体网格单元属性（block zone property） 命令。

看过几个 FISH 函数示例后，下面简要讨论 FISH 的语法和风格。完整的 FISH 语句占一行。不过，只要除最后一行外的每行都以续行符（…）结尾，就可以分成两行或多行输入。使用临时变量作为衔接点来组合较长公式，也很方便。下例展示了这种方法：

拆分长行

model new
fish define long_sum  ;对多个量求和的示例
    global v1,v2,v3,v4,v5,v6,v7,v8,v9,v10,v11,v12,v13,v14,v15
    
    local temp = v1 + v2 + v3 + v4 + v5 + v6 + v7 + v8 + v9 + v10
    long_sum = temp + v11 + v12 + v13 + v14 + v15
    
    temp = v1 + v2 + v3 + v4 + v5 + v6 + v7 + v8 + v9 + v10 ...
              + v11 + v12 + v13 + v14 + v15
    
end

本例将十五个变量的和拆为两部分。将 局部变量 temp（temp） 声明为 local，意味着仅在执行 FISH 函数 long_sum（long_sum） 时使用，随后丢弃。默认情况下，FISH 变量为全局变量，即在发出 新建模型（model new） 命令之前一直保留在内存中。可以通过 global 语句显式将变量设为全局。将其他函数或命令不会使用的所有 FISH 变量声明为 local，是一种良好习惯，也可能更高效。例如，可以按以下方式使用局部变量构建循环：

loop foreach local pnt zone.list

loop foreach local pnt block.zone.list

或

loop local n (1,10)

还要注意 FISH 函数 long_sum（long_sum） 定义后分号的用法，它表示注释。分号后的所有字符都被 FISH 编译器忽略，但会回显到日志文件。在程序中添加有信息价值的注释，是良好的编程习惯。一些程序使用了缩进，即在某些行开头插入空格，表示相关的一组语句。可以在变量名与算术运算之间任意插入空格，以提高可读性。同样，使用缩进标明循环、条件分支等结构也是良好习惯。FISH 中空格具有“语法意义”，即不能在变量名或函数名内部插入空格。

现在还应讨论变量类型。输出各程序示例中的变量时，您可能注意到，数值要么不带小数点，要么以“E 格式”输出，即以 E 表示指数。在任何时刻，一个 FISH 变量或函数名都属于若干类型之一，且类型还在增加：布尔、整数、矩阵、指针、实数、字符串、列表、二维矢量、三维矢量、张量、映射或结构体。这些类型可随上下文动态改变，但一般用户通常无须担心变量类型，因为它会自动设置。考虑以下示例：

变量类型

model new
fish define types
    v1 = 2
    v2 = 3.4
    v3 = 'Have a nice day'
    v4 = v1 * v2
    v5 = v3 + ', old chap'
    v6 = vector(1,2,3)
    v7 = matrix(vector(1,1,1))
    v8 = true
    v9 = list.range(1,15)
end

FISH 中还有一个常用语言元素：if then else 语句。以下三类语句允许在 FISH 程序中作出判断：

if [expression] then
   ...
else if [expression] then
   ...
else
   ...
endif

这些语句允许有条件地执行 FISH 函数片段；else if、else 和 then 均为可选。expression必须求值为布尔类型，或可转换为布尔类型的值。例如，整数恰好为零时视为 假值（false），否则视为 真值（true）。布尔运算符有多种类型，包括：

== # != > < >= <=

各符号含义均采用通常定义，只有 # 需要说明，它表示“不等于”，与 != 同义。如果表达式求值为真，则执行 if 后紧接的语句，直到遇到 else if、else 或 endif。如果条件为假，则继续判断各 else if 语句。否则，若存在 else 语句，则执行 else 与 endif 之间的语句；若不存在，则跳转到 endif 后第一行。下例说明这些语句的作用：

if else endif 结构的作用

model new
fish define abc(xx)
    if xx > 0 then
        abc = 33
    else
        abc = 11
    endif
end
[abc(1)]
[abc(-1)]

本例中，显示的 FISH 符号 abc（abc） 值取决于执行 FISH 符号 abc（abc） 时提供的参数。建议尝试不同判断符号，例如将 > 替换为 <。

到目前为止，均通过内联 FISH 的方括号 []，从本程序调用 FISH 函数。反过来也可以，即从 FISH 函数内部发出本程序命令。大多数有效的本程序命令都可嵌入以下 FISH 语句之间：

command

endcommand

从 FISH 程序调用本程序命令，主要有两个原因。第一，可以通过 FISH 函数，执行上述预定义 FISH 内置函数无法完成的操作。第二，可以用 FISH 控制本程序的完整运行过程。为说明 command endcommand 语句（statement）的第一种用途，可编写一个 FISH 函数，在材料不同深度安装多个锚索单元。锚索数量和分段数作为参数传入函数。需要许多锚索单元时，逐条输入包含不同网格值的 structure cable create 命令非常繁琐。不过，利用 FISH，可以在循环内调用本程序命令，并在循环过程中自动赋予锚索端点位置，如下例所示：

model new
zone create brick size 10 3 5

        local z_d = n - 0.5

            structure cable create by-line 0.0 1.5 [z_d] 7.0 1.5 [z_d] ...
                                   segments [segs]

列表

用户常希望保存一个对象列表，以便后续循环遍历。例如，这些对象可以是网格单元的计算值，也可以是特定网格点指针。FISH 为此提供三种容器，称为列表（lists）、映射（maps）和数组（arrays）。其中最常用且适用性最广的是 list。

列表存放多个任意类型的 FISH 变量，可以循环遍历或通过整数索引访问。列表可调整大小、插入值，以及在末尾或开头添加值。下方简单示例展示如何创建整数列表并对其求和。

列表示例

model new
fish define list_operation
    ;创建数组并用 2 的乘积填充
    arr = list.create(10)
    loop local n (1,10)
        arr(n) = 2*n
    endloop
      
    ;计算数组元素的和与乘积
    sum = 0
    prod = 1
    local i = 1
    loop while (i <= list.size(arr))
        sum = sum + arr(i)
        prod = prod * arr(i)
        i = i + 1
    endloop
    io.out('The sum is ' + string(sum) + ' and the product is ' + string(prod))
end
[list_operation]

本例先创建列表并填入数值，再使用 loop while 结构遍历列表项，计算并输出和与乘积。

列表还可以用于对各元素重复计算。数学运算符作用于列表时，会分别对列表中的每个元素应用运算。访问运算符 -> 也如此，会返回一个列表，包含对原列表各元素执行 -> 的结果。上面列表示例的另一种写法如下：

列表示例（另一种写法）

model new
fish define list_operation
    ;创建数组并用 2 的乘积填充
    arr = list.range(1,10)*2
    ;计算数组元素的和与乘积
    sum = list.sum(arr)
    prod = 1
    loop foreach i arr
        prod *= i
    endloop
    io.out('The sum is ' + string(sum) + ' and the product is ' + string(prod))
end
[list_operation]

映射与数组

映射是一种关联容器，即可通过插入值时所使用的另一个通用 FISH 键访问映射成员。映射可动态调整大小，也可相加，将多个映射拼接起来。映射适合根据已知键快速查找值。

映射示例

model new
fish define map_operation
    ; 创建并填充映射
    my_map = map('key1',1,  'key2',2,  3,3) ; 三个初始键值对
    my_map('key4') = 4
    my_map(3.94) = 5
    
    ;计算映射元素的和与乘积
    value = my_map('key4')
    io.out('The value associated with key4 is ' + string(value))
end
[map_operation]

数组与列表相似，但有两项重要区别。第一，创建数组时可指定多个维度；只要内存允许，维度数量不受限制。第二，数组可能非常大，因此按引用传递，而非按值传递。这意味着，如果令 a 等于 b，且 b 为数组，则二者都指向同一个数组。

数组示例

model new
fish define array_operation
    ; 创建三维数组
    arr = array.create(4,5,6)
    arr(2,3,4) = 3.0
    arr(1,1,1) = 1.0
    
    brr = arr
    brr(4,4,4) = 4.0   ; brr 和 arr 是同一个数组！
    io.out(arr(4,4,4))
end
[array_operation]

列表、映射和数组都可使用 loop foreach 结构遍历。对于映射，循环变量为各映射项保存的值，而非键值。可使用 映射键（map.keys） 内置函数遍历映射的键值。

列表拆分与筛选

如上所述，列表类型在 FISH 中有些特殊。仅用几行 FISH 代码，便可实现重复计算。此外，如果列表足够大，这些操作还可自动在系统全部线程上执行，从而透明地实现多线程计算。

拆分（Splitting）指重复调用 FISH 内置函数或用户自定义函数的选项。使用特殊参数前缀运算符 ::，表示该参数是可迭代类型，其内容将被拆分，针对每个值单独调用一次。各次调用的返回值按原顺序组合为列表类型。

与列表运算符相同，如果列表足够大，且函数被标记为线程安全，则会自动在全部可用线程上执行。通过 定义FISH函数命令（fish define） 命令创建的 FISH 函数从不视为线程安全。如果不具备线程安全性，仍会拆分，但仅在一个线程上顺序执行。

新增了一类特殊的 FISH 函数，称为运算器（operators），允许用户编写的 FISH 函数在拆分时多线程运行。FISH 运算器比普通函数限制更多，目的是保证在线程环境中安全使用。不过，它们是实现自定义模型行为最快的可用方式，尤其在循环计算期间使用时。

此外，列表类型支持筛选。通过向列表传入布尔值列表而非整数索引，可以自动选取其子集。真值（true） 对应的值被保留，假值（false） 对应的值被移除。因此，可以快速高效地找出满足给定准则的项目子列表。

下面给出一个简单示例，作为前述历程示例的另一种实现。这种实现更灵活，也快得多：

利用拆分计算表面荷载

model new
model large-strain off
zone create brick size 1 2 1
zone face skin
zone cmodel assign mohr-coulomb
zone property shear=1e8 bulk=2e8 cohesion=1e5 tension=1e10
zone face apply velocity (0,0,0) range group "South"
zone face apply velocity-y -1e-5 range group "North"
[ad = list(gp.list)(gp.isgroup(::gp.list,"North"))]
fish define load
    load = list.sum(gp.force.unbal(::ad)->y)
end
fish history load
zone history displacement-y position (0,2,0)
model step 1000
plot item create chart-history history '1' vs '2' reverse on

model new
model large-strain off
block create brick 0 1 0 2 0 1
block zone generate edgelength 0.5
block zone cmodel assign mohr-coulomb
block zone property dens 2000 shear=1e8 bulk=2e8 cohesion=1e5 tension=1e10
block gridpoint apply velocity (0,0,0) range pos-y 0
block gridpoint apply velocity-y -1e-2 range pos-y 2

fish define make_list
  ad = list
  loop foreach gp block.gp.list
    if block.gp.pos.y(gp) > 1.99
       ad('end') = gp  ; 追加到列表
    endif
  endloop
end
[make_list]

fish define load
    load = list.sum(block.gp.force.reaction.y(::ad))
end

fish history load
block history displacement-y position (0,2,0)
model step 1000
plot item create chart-history history '1' reversed-x on reversed-y on vs '2'

首先，

list(gp.list)

语句将 gp.list 返回的、指向模型全部网格点容器的指针，转换为模型全部网格点的列表。然后调用函数 节点分组归属判断（gp.isgroup） 并拆分，对模型中每个网格点单独调用，结果以布尔值列表返回。

gp.isgroup(::gp.list,"North")

将该结果作为参数传入网格点列表，返回与标记为“North”的表面分组相连的网格点列表。

该 FISH 函数接收这个缩减后的指针列表，并调用

gp.force.unbal(::ad)

它再次为列表 节点指针列表 ad（ad） 中的每个网格点指针单独调用，并返回结果列表，此处为不平衡力矢量列表。对该列表应用 ->y 运算符，将返回这些矢量 y 分量的列表。最后使用 列表求和（list.sum） 内置函数，对全部数值求和，得到最终总力。

作为可亲自输入的单行示例，以下内联 FISH 将所有网格单元的 xx 应力增加 500：

[ zone.stress(::zone.list)->xx += 500 ]

以下一行为模型中每个网格点位置的 x 分量添加一个不同的随机值：

[ gp.pos(::gp.list)->x ::+= math.random.uniform(gp.num) ]

如果提供一个参数，均匀随机数（math.random.uniform） 函数将返回含有该数量随机值的列表，数值介于 0.0 与 1.0 之间。gp.num 函数返回模型中的网格点数。拆分运算符 :: 与 += 运算符结合使用，是拆分运算符唯一可以出现在函数参数之外的情况，表示右侧赋值本身也要拆分，使每次赋值函数调用都获得不同的值。

首先创建位于 y = 2 的全部网格点列表。只需遍历全部网格点并检查坐标，将 y 坐标等于 2 的点加入列表。可按图示使用 :end 在列表末尾添加元素：

ad('end') = gp

第二个 FISH 函数接收这个缩减后的指针列表，并调用

block.gp.force.reaction.y(::ad)

它为列表 节点指针列表 ad（ad） 中的每个网格点指针单独调用，并返回结果列表，此处为 y 方向反力列表。最后使用 列表求和（list.sum） 内置函数，对全部数值求和，得到最终总力。

作为可亲自输入的单行示例，以下内联 FISH 将所有网格单元的 xx 应力增加 500：

[ block.zone.stress.xx(::block.zone.list) += 500 ]

此处，block.zone.stress.xx 作用于模型中的全部网格单元，并使每个网格单元的应力 xx 分量增加 500。

以下一行为模型中每个网格点位置的 x 分量添加一个不同的随机值：

[ block.gp.pos.x(::gp.list) ::+= math.random.uniform(block.gp.num) ]

如果提供一个参数，均匀随机数（math.random.uniform） 函数将返回含有该数量随机值的列表，数值介于 0.0 与 1.0 之间。block.gp.num 函数返回模型中的网格点数。拆分运算符 :: 与 += 运算符结合使用，是拆分运算符唯一可以出现在函数参数之外的情况，表示右侧赋值本身也要拆分，使每次赋值函数调用都获得不同的值。

FISH 自动创建

以上全部示例采用默认 FISH 符号创建模式。赋值左侧一旦出现未知单词，就创建新的全局 FISH 符号。右侧出现新符号则报错。

对于本教程中这种简短、简单的入门 FISH 函数，这没有问题。但随着 FISH 脚本越来越大、变量越来越多，就会产生问题。全局变量数量增加后，可能意外地在两个不同位置使用相同名称，在不知情的情况下覆盖原值。还可能因为名称输入错误，未意识到自己创建了新变量，而非改变旧变量的值。

为解决这一问题，一旦开始编写具有一定规模的 FISH 程序，我们强烈建议在数据文件开头、新建模型（model new） 之后发出 fish auto-create 关闭（off） 命令。您会发现，手册中几乎所有示例数据文件都这样做。这会强制显式声明所有新变量为 local 或 global。局部符号仅存在于其声明所在的函数或运算器内部，不能从外部引用。尽量将所有变量设为局部，仅在必要时创建全局符号。
