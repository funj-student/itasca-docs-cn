FLAC3D Modeling • Introduction

FLAC3D 功能

功能

FLAC3D 提供广泛的功能，用于解决力学，尤其是地质力学中的复杂问题。与 FLAC 一样，FLAC3D 为地质材料的力学响应提供了专门的数值表示方法。程序内置十五种基本材料模型：“null”模型；三种弹性模型（各向同性弹性、横观各向同性弹性和正交各向异性弹性）；以及十一种塑性模型（Drucker-Prager、Mohr-Coulomb、应变硬化／软化、遍布节理、双线性应变硬化／软化遍布节理、双屈服、修正 Cam-clay、帽盖屈服、土体弹塑性〔双曲线型〕、Hoek-Brown 和修正 Hoek-Brown）。这些模型在本构模型（Constitutive Models）一节中有详细说明。FLAC3D 网格中的每个网格单元都可以采用不同的材料模型或性质，并可为任意性质指定连续梯度或统计分布。

此外，还提供接触面（或滑移面）模型，用于表示网格中两个或多个部分之间的明确接触面。接触面是允许滑移和／或分离的平面，可据此模拟断层、节理或摩擦边界。接触面模型见接触面（Interfaces）一节。

与周围岩土相互作用的结构，如隧道衬砌、桩、板桩、锚索、岩锚或土工织物，可通过 FLAC3D 的结构单元功能进行模拟。既可以考察支护对开挖稳定性的作用，也可以研究岩土失稳对地表结构的影响。各种结构单元类型见结构单元（Structural Elements）。

对于采用兼容材料模型的任何 FLAC3D 模型，都可以自动计算安全系数。该计算基于“强度折减法”：通过改变强度性质进行一系列模拟，确定出现不稳定状态的条件。由此找到对应失稳点的安全系数，并确定模型中的临界破坏面。安全系数算法见安全系数（Factor of Safety）一节。

FLAC3D 还内置了功能强大的编程语言 FISH，允许用户定义新变量和函数。对于希望根据自身特定需求定制分析的用户，FISH 提供了独特的功能。例如，FISH 可实现以下操作：

  • 按用户规定改变网格中的性质（例如，模量随深度非线性增加）；
  • 绘制和打印用户定义变量（即定制图）；
  • 实现专用网格生成器；
  • 对数值试验进行伺服控制；
  • 指定特殊边界条件；
  • 实现随时间和空间的变化；以及
  • 自动开展参数研究。

教程：使用 FISH（Tutorial: Working with FISH）介绍了 FISH 入门知识。有关 FISH 语言的详细参考资料，见FISH 脚本参考（FISH Scripting Reference）一节。

程序具有丰富的图形功能，几乎可为任何问题变量生成图。高分辨率视频模式下提供三维图形渲染。绘图功能包括消隐图、表面等值线图和矢量图。绘制的变量可以显示在穿过模型的任意剖切平面前方、后方或平面上。模型可视化的交互工具见绘图窗格（The Plot Pane）。

可选功能

提供四项可选功能（动力分析、热分析、蠕变材料行为模拟和 C++ 插件），各自作为独立模块，可按模块另行付费加入 FLAC3D。

通过可选动力计算模块，可使用 FLAC 进行动力分析。用户指定的加速度、速度或应力波可作为外部边界条件或模型内部激励，直接输入模型。FLAC3D 提供吸收边界和自由场边界条件，用于模拟模型周围无限弹性介质的影响。动力计算可与地下水流模型耦合；包括动力孔隙压力产生（液化）在内的耦合程度，见物理过程及相互作用建模（Modeling Physical Processes and Interactions）。动力分析功能见动力分析（Dynamic Analysis）。

FLAC3D 提供作为专用模块的热分析选项。该模型模拟材料中的瞬态热流及随后产生的热应力。热模型既可独立运行，也可与静态或动态的力学应力计算或孔隙压力计算耦合。（耦合相互作用见物理过程及相互作用建模（Modeling Physical Processes and Interactions）。）热分析功能见热分析（Thermal Analysis）。

另有可选材料模型，用于模拟与时间相关的材料行为（蠕变）（所有蠕变模型均见3DEC 和 FLAC3D 中的蠕变本构模型（Creep Constitutive Models in 3DEC and FLAC3D））。

通过 C++ 插件功能，可使用 C++ 编写用户自定义本构模型和 FISH 内置函数，并编译为 DLL（动态链接库）文件，供需要时加载。DLL 文件使用 Microsoft Visual C++ Version 10.0（Microsoft Visual Studio 2010）编译。编写新本构模型的流程见编写新本构模型（Writing New Constitutive Models）。编写新 |fish| 内置函数的流程见 :ref:linktoc++plugins。上一行需要链接到旧版 FISH 卷的第 4 节，但该节目前缺失

物理过程及相互作用建模

FLAC3D 的默认计算模式为静力学分析。也可以独立于力学计算进行地下水流分析或传热分析。地下水流模型和热模型都可与力学应力模型耦合，也可彼此耦合。由于 FLAC 采用完整运动方程，因此这些耦合机制既适用于静力分析，也适用于动力分析。

耦合机制分为三类相互作用：力学与地下水流、力学与热、热与地下水流。下面说明 FLAC3D 对每一类相互作用的模拟程度。

力学与地下水流耦合——FLAC3D 中可以指定多种流固相互作用。其中一种为固结，即孔隙压力缓慢消散引起固体（如土体）发生位移。此时有两种力学效应共同作用：1）网格单元中的流体通过孔隙压力变化响应力学体积变化；2）孔隙压力变化引起有效应力变化，影响固体的响应（例如，有效应力降低可能诱发塑性屈服）。还可以指定由颗粒可变形引起的流固耦合。

只需开启或关闭渗流计算，FLAC3D 即可计算考虑或不考虑孔隙压力消散时的孔隙压力效应。此外，可通过在本构模型中考虑不可逆体积应变，模拟动力孔隙压力产生（例如与液化有关的孔压产生）。这可通过两种不同的内置本构模型实现：“Finn”模型和“Byrne”模型。两种模型均随动力选项提供。

默认情况下，假定孔隙率和渗透率为常数。但通过 FISH 函数，可将这些性质设置为体积应变的函数。因此，FLAC3D 能够模拟力学应力与地下水流的双向耦合。

FLAC3D 不直接模拟其他类型的相互作用，例如部分饱和材料颗粒间的毛细力、电力或化学力。但通过编写适当的 fish 函数，可以计入其中一些效应。同样，可通过 FISH 函数，使局部流体模量随压力或时间等其他量变化。

热力耦合——FLAC3D 中的热力耦合是单向的：温度变化可通过热膨胀系数引起力学应力变化。但物体的力学变化不会导致温度变化或热学性质变化。此外，由于 FISH 可以访问温度和材料性质，还可以将力学性质设为温度变化的函数。

热与地下水流耦合——将孔隙压力设为温度变化的函数，即可将热计算与地下水流计算耦合。饱和基质中流体和颗粒的热膨胀都会产生体积应变。孔隙压力变化由这种体积应变以及力学体积应变共同引起。地下水流也会影响传热；程序提供了考虑对流热量输运的平流模型。该平流模型还可模拟随温度变化的流体密度以及流体中的热平流。

与力学性质一样，通过 FISH 访问温度与性质值，可以将地下水性质设置为温度变化的函数。

6.0 版新增功能

相对于 5.0 版的更新概述

FLAC3D 6.0 包含许多改进；以下各节概述了新增功能。现有为 5.0 版创建的数据文件将无法按原方式运行。FLAC3D 6.0 无法恢复旧版保存的文件。有关 5.0 版数据文件的转换，请参阅 6.0 版文档中有关数据文件转换的主题，以及命令和 FISH 映射页面。

网格生成

  • 构建块

    新增交互式结构化网格生成工具构建块窗格（Building Blocks Pane），进一步丰富了 FLAC3D 的网格生成（mesh generation）选项。构建块类似于三维版的拉伸器窗格（Extruder Pane）。其支持的功能包括：

    • 将几何曲面（从 CAD 或其他来源导入）用作背景数据。
    • 将点捕捉到几何曲面、边和节点。
    • 将选定面和边控制点贴合到弯曲的几何曲面上。
    • 轻松选择节点、边、面和块体。
    • 对选定对象进行任意变换，包括平移、旋转和缩放。
    • 逐边控制网格单元的离散划分和分布。
    • 自动传递网格单元数量和分布设置，以保持连接关系。
    • 为各块体指定网格单元倍增系数，并自动在边界间生成连接条件。
    • 可暂时隐藏块体以便查看。
    • 可分割块体，以生成更多可操作的表面。
    • 可在同一集合内或不同集合之间复制和粘贴块体。
    • 提供预定义形状与构型库，既可用作建模起点，也可剪切并粘贴到您的模型中。
    • 根据网格单元总数或网格单元边长，自动指定网格单元尺寸。
    • 拉伸器可将其描述发送到构建块，以便对主要为二维的布局进行三维修改。
    • 给定初始封闭几何体积，即可自动生成初始构建块表示。
    • 可从 FLAC3D 网格导入构建块，从而允许第三方程序（或 Griddle）自动创建粗略体积分解，然后以交互方式进行定制和细化。

  • 导入网格

    除导入 FLAC3D 网格文件外，FLAC3D 现在还可以直接导入 ANSYS 和 ABAQUS 格式的网格文件。因此，可以使用能够将结果导出为这两种格式之一的各种第三方网格生成程序。

  • 八叉树与加密网格

    过去，在采用八叉树策略和局部加密生成的网格中，沿断层创建接触面十分困难且耗时。现已更新 按面分离单元命令（zone separate by-face） 命令，允许干净地分离部分连接的表面。此外，还改进了 单元附着按面（zone attach by-face） 命令，使生成的网格连接更可靠。最后，新增 zone validate 命令，以帮助检测并显示仍可能未正确连接的区域。

交互式建模

新增了一个交互式模型操作窗格，称为模型窗格（Model Pane）。它允许您以交互方式查看、选择和命名网格单元与网格单元面，并对其应用操作。随着 FLAC3D 的持续开发，将创建更多交互工具，以支持模型创建的更多阶段。

以这种方式对模型状态所做的每项更改，都会生成为命令并存储在状态记录（State Record）中。状态记录可用于创建数据文件，以便以后重新创建以交互方式建立的基础模型，或对其进行参数化。

结构单元

FLAC3D 的结构单元功能尤其受益于命令语法的改进；现在，它使用与程序其余部分相同的约定和关键字。此外，还添加了许多选项，使结构支护的创建更加便捷。其中包括：

  • 现在通过简单命令即可正确施加锚索预张力，无需使用 FISH。
  • 能够从几何和 CAD 数据创建一维结构（锚索、桩、梁）和二维结构（壳、衬砌、土工格栅）。例如，见 structure cable import 命令。
  • 能够在一次操作中分离内部网格单元表面，并在分离的表面间安装衬砌。见 structure liner create by-face 命令。
  • 能够将创建的锚索自动连接到衬砌节点。见 structure cable create 命令。
  • 使用模型窗格（Model pane）功能，可以轻松选择用于布置结构加固的复杂曲面。

新增本构模型

除持续改进现有本构模型的行为和响应外，FLAC3D 6.0 还提供以下新模型：

  • 用于模拟土体的塑性硬化模型（Plastic-Hardening）。
  • 用于模拟湿润引起的变形的膨胀模型（Swell）。
  • 将各向异性弹性与弱节理破坏相结合的遍布节理各向异性模型（Ubiquitous-Anisotropic）。
  • Mohr-Coulomb 拉伸模型（Mohr-Coulomb-Tension），在受拉时产生可张开和闭合的“虚拟”裂缝，从而更真实地模拟动力荷载下的拉伸行为。
  • 用于模拟土体的帽盖屈服模型（Cap-Yield）。
  • 将 Mohr-Coulomb 破坏、遍布节理和幂律蠕变结合的幂律 Mohr-Coulomb 遍布节理模型（Power-Mohr-Ubiquitous）。

此外，通过C++ 用户自定义模型（C++ User-Defined-Models）创建自己的本构行为比以往更加容易，提供的 Visual Studio 模板可帮助您入门。一如既往，程序提供所有内置本构模型的源代码，既可用于验证实现后的行为，也可作为用户修改和扩展的基础。

命令与脚本

FLAC3D 的命令语法已更新，以提高一致性和清晰度。所有命令尽量遵循名词 - 动词 - 选项 - 修饰项 - 范围的标准模式。命令关键字采用新的连字符语法，使完整命令能够被记录和列出以便理解，同时仍允许不希望输入完整词语的用户使用缩写。程序特别注意在各处始终用相同关键字表示相同概念，从而更容易将某一部分学到的知识应用到其他部分。

还实施了新的 FISH 内置函数命名约定。这大幅提高了函数名的清晰度，并使编辑器能够在输入过程中自动突出显示正确和错误的内置函数名。

为帮助用户继续使用已有数据文件和 FISH，FLAC3D 6.0 编辑器内置了转换工具。该工具使用启发式方法判断数据文件是否采用旧的 5.0 语法，并自动询问用户是否将其转换为 6.0 语法。也可以手动启动此转换。

FISH 中还增加了许多新类型，包括布尔、张量、矩阵以及关联数组或映射。通过 Visual Studio 模板创建项目，再利用插件选项创建自定义 C++ FISH 内置函数，现在也变得容易得多。

FLAC3D 还新增了功能更强大的内置编辑器。现在提供行号、代码折叠、改进的搜索和改进的语法高亮等功能。

可用的 PFC 模块

Itasca 正朝着通用平台发展，使所有软件方法——目前作为独立程序销售（FLAC3D、PFC 等）——都可在运行时加载到同一系统中。从 FLAC3D 6.0 开始，可在运行时将兼容版本的 PFC 直接加载到 FLAC3D 中，实现球体与网格单元或结构单元的直接耦合。程序已内置初步的直接耦合支持。

交互式帮助

  • 屏幕帮助

    现在，整套文档均可通过帮助文件在屏幕上查看。用户可以快速搜索和浏览内容、查看和复制示例，同时也能使用其他集成帮助功能。

  • 内联帮助

    按 Ctrl+Spacebar 将启用新的内联帮助功能，提示可用选项，并帮助您交互构建命令。

    在数据文件（data file）或命令提示符（command prompt）中工作时，随时按 F1 即可获得即时帮助，打开 FLAC3D 帮助，显示光标所在命令或关键字的完整文档。

其他新增功能与更新

上述远非新增功能和改进的完整清单。尚未介绍的内容包括：

  • 更快地设置初始条件

    新增 zone initialize-stresses 命令，即使几何形状不规则、密度变化，也可以自动计算重力引起的竖向应力初始近似值。水平应力也可以初始化为竖向应力的某个比例。此外还提供其他选项。

  • 更新的保存／恢复系统

    保存文件现在采用新格式（与 5.0 版不兼容），预计可使未来版本的 FLAC3D 保持向后兼容。

  • 网格单元开挖自动卸荷

    新增 zone relax 命令，可自动逐步卸除开挖区域的作用，避免虚假惯性效应加剧所显示的损伤。通过从 1.0 降至 0.0 的乘数，随时间逐步减小网格单元的作用。用户可以控制卸荷曲线的具体形状，默认采用基于当前力学力比的伺服控制。当折减系数达到 0.0 时，网格单元自动设为 NULL，并移除施加条件。

  • 更快的动力模拟

    针对模型中存在较大尺寸或刚度差异的情况，动力多步进（dynamic multi-stepping）选项有了很大改进。根据具体模型，这可能大幅加快动力模拟。

  • 动力输入向导（Dynamic Input Wizard）

    该工具预处理输入信号，并输出可导入动力分析的表。它可以使用多种方法进行频率滤波和基线校正，并导出处理后的数据。

  • 更新的 APPLY 功能

    施加边界条件时，现在可以使用局部（每个网格点、面或网格单元）的 FISH 乘数。当对网格点施加多个约束时，局部坐标系会自动确定。在非笛卡尔坐标轴对齐的表面施加法向速度条件时，无需再手动指定平面。

  • Westergaard 动水压力近似

    用于动力模拟中流体边界的 Westergaard 近似，现已作为施加边界条件直接内置于 FLAC3D。

  • 结果文件

    FLAC3D 现在可以导出结果文件；见 设置结果文件（model results） 命令。这些文件远小于保存文件，仅用于后处理和分析。用户可以完全控制其中包含模型的哪些内容。这些文件（以及保存文件）也可以与生成影片帧（Generate Movie Frames）对话框配合使用，自动生成模型影片帧。

  • 可视化

    • 改进了绘图项界面，增加拖放和剪切／粘贴支持。
    • 优化了网格单元绘图项，并采用多线程处理，因此生成和响应速度应明显加快。
    • 现在可以命名和保存绘图视图（相机设置），以供后续恢复和参考。
    • 简化了绘图项的全部属性，使任何时候都仅显示有效选项。
    • 还更新了与绘图有关的命令语法；绘图项控制开关关键字经过修改，使其布局和结构与交互界面中显示的属性相似。
    • 改进了从绘图窗口导出数据文件的选项，使其更加可靠。生成的数据文件现在采用易读格式，可编辑后用于自定义脚本。

  • 用户界面改进

    • 改进了控制面板（Control Panel），提供更大灵活性。
    • 新增的FISH 浏览器（FISH browser）控件组显示模型中所有 FISH 符号的名称及当前值。
    • 更好地支持浮动窗格，包括在其中嵌入局部工具栏和控制面板的选项。

  • 许可证验证增强

    • 能够从具有多个有效许可证的服务器中选择指定许可证。
    • 许可证系统扫描所有可用密钥，寻找同时匹配所用程序和选项的密钥。
    • 许可证出错时，提供更清楚的消息与反馈。
    • 现在可以在同一个 USB 密钥中包含多个独立许可证。
