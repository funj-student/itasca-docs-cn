FLAC3D 流体热力耦合表述——数学描述

本节考虑流固过程与热传导功能的耦合（通过对流（convection）功能实现的流体热耦合另见相应内容）。多数涉及同时发生变形及流体／热扩散机制的工程分析，采用解耦技术进行（例如本节（this section））。除这些计算模式外，FLAC3D 还提供流体热力耦合分析选项，即可研究瞬态流动和／或热条件下多孔材料的力学响应。虽然本节主要讨论变形与流体扩散问题建模，为完整起见，仍在此给出控制 FLAC3D 流体热力响应的一般方程。

FLAC3D 在准静态 Biot 理论框架内表述耦合变形扩散过程，可用于涉及多孔介质中单相 Darcy 流的问题。该模型可表示水和油等各种流体。

描述流体通过多孔介质流动的变量包括孔隙压力、饱和度和比流量向量的三个分量。这些变量通过流体质量平衡方程、流体输运的 Darcy 定律、描述流体对孔隙压力、饱和度、体积应变和温度变化响应的本构方程，以及关联非饱和范围内孔隙压力与饱和度的状态方程相互联系。力学本构定律计入孔隙压力和温度影响，从而完成热、流动和力学耦合。

假定体积应变率和温度变化率已知，利用 Darcy 定律，将质量平衡方程代入流体本构关系，可得到以孔隙压力和饱和度表示的微分方程，并可针对特定几何形状、性质、边界和初始条件求解。

约定与定义

按符号约定，\(a_i\) 表示笛卡尔参考坐标系中向量 \(\{ a \}\) 的 \(i\) 分量；\(A_{ij}\) 为张量 \([A]\) 的 \((i,j)\) 分量。此外，\(f_{,i}\) 表示 \(f\) 对 \(x_i\) 的偏导数。（符号 \(f\) 表示标量变量或向量分量。）

爱因斯坦求和约定仅适用于指标 \(i\)、\(j\) 和 \(k\)，对于涉及空间维度的分量，它们取值为 1、2、3。当用于矩阵方程时，这些指标可取任意值。

采用 SI 单位说明参数和变量量纲。转换至其他单位制的方法见单位制（System of Units）。

以下参考量有助于表征瞬态流动。

特征长度：

(1)\[L_c = {{volume \ of \ flow \ domain}\over{surface \ area \ of \ flow \ domain}}\]

流体扩散率：

(2)\[c = {{k} \over {1 / M + {\alpha}^2 / {\alpha}_1}}\]

其中，\(k\) 为流动性系数（FLAC3D 渗透率），\(M\) 为 Biot 模量，\(\alpha\) 为 Biot 系数，\({\alpha}_1 = K + 4/3 G\)，\(K\) 为排水体积模量，\(G\) 为多孔材料的剪切模量。

Biot 系数考虑多孔材料颗粒的可压缩性。如果 \(\alpha\) 等于 1，则认为颗粒不可压缩，Biot 模量 \(M\) 等于 \(K_f / n\)，其中 \(K_f\) 为流体体积模量，\(n\) 为孔隙率。流体扩散系数变为

(3)\[c = {{k} \over {n / K_f + 1 / {\alpha}_1}}\]

注意，对于仅流动计算，即刚性材料，流体扩散率为

(4)\[c = {k M}\]

关于这些性质关系的进一步讨论，见流体流动分析的性质与单位（Properties and Units for Fluid-Flow Analysis）。

特征时间：

(5)\[t_c = {{L_c^2}\over{c}}\]

控制微分方程

当热量以传导方式在材料区域内输运时，描述多孔材料流体热力响应的微分方程如下。

输运定律

流体输运由 Darcy 定律描述：

(6)\[q_i = - k_{il} \ \hat{k}(s) \left[ p - {\rho}_f x_j g_j \right] _{,l}\]

其中，\(q_i\) 为比流量向量，\(p\) 为流体孔隙压力，\(k\) 为介质绝对流动性系数张量（FLAC3D 渗透率张量），\(\hat{k}(s)\) 为相对流动性系数，是流体饱和度 \(s\) 的函数；\({\rho}_f\) 为流体密度，\(g_i\)、\(i\) = 1,3 为重力向量的三个分量。

为供后文引用，将量 \(\phi = (p - {\rho}_f x_j g_j) / ({\rho}_f g)\) 定义为水头，其中 \(g\) 为重力向量的模；将 \({\rho}_f g \phi\) 定义为压力水头。

传导热流由 Fourier 热输运定律描述：

(7)\[q_i^T = - k^T_{ij} T_{,j}\]

其中，\(q_i^T\) 为热通量向量，\(T\) 为温度，\(k^T\) 为导热系数张量。请注意，FLAC3D 表述中考虑温度、通量、对流和绝热边界条件。

平衡定律

小变形情况下，流体质量平衡可表示为

(8)\[-q_{i,i} + q_v = {{\partial\zeta}\over{\partial t}}\]

其中，\(q_v\) 为体积流体源强度，单位为 [1/sec]；\(\zeta\) 为流体含量变化，或由扩散性流体质量输运引起的单位多孔材料体积内流体体积变化，由 Biot (1956) 引入。

热能平衡表示为

(9)\[-q_{i,i}^T + q_v^T = {{\partial \zeta^T} \over {\partial t}}\]

其中，\(\zeta^T\) 为单位体积多孔材料储存的热量，\(q_v^T\) 为体积热源强度。

动量平衡形式为

(10)\[\sigma_{ij,j} + \rho g_i = \rho {{d v_i} \over{d t}}\]

其中，\(\rho = \rho_d + n s \rho_w\) 为总体密度，\(\rho_d\) 和 \(\rho_w\) 分别为干基质和流体密度，\(n\) 为孔隙率，\(s\) 为饱和度。

本构关系

流体含量变化的改变与孔隙压力 \(p\)、饱和度 \(s\)、力学体积应变 \({\epsilon}\) 和温度 \(T\) 的变化有关。孔隙流体的响应方程表述为

(11)\[{1 \over M} {{\partial p} \over {\partial t}} + {n \over s} {{\partial s} \over {\partial t}}= {1 \over s} {{\partial \zeta} \over {\partial t}} - \alpha {{\partial \epsilon} \over {\partial t}} + \beta {{\partial T} \over {\partial t}}\]

其中，\(M\) 为 Biot 模量 [N/m2]，\(n\) 为孔隙率，\(\alpha\) 为 Biot 系数，\(\beta\) 为不排水热系数 [1/°C]，后者考虑流体和颗粒的热膨胀。

FLAC3D 表述忽略毛细压力影响，并在饱和度小于 1 时将流体压力取为零。相对流体流动性与饱和度通过三次定律关联：零饱和度时为零，完全饱和时为 1：

(12)\[\hat{k}(s) = s^2(3 - 2s)\]

因此，非饱和区流体流动仅由重力驱动。虽然使初始干燥介质饱和不需要重力影响，但脱饱和过程由重力驱动。此时仍存在一定残余饱和度，因为饱和度趋近零时，表观渗透率 \(k \ \hat{k}(s)\) 也趋于零。

热本构定律表示为

(13)\[{1 \over M^T} {{\partial T} \over {\partial t}} = {{\partial \zeta^T} \over {\partial t}}\]

其中，\(M^T = 1/(\rho C_v)\)，\(\rho\) 为介质质量密度，\(C_v\) 为定容比热。

请注意，对几乎所有固体和液体，定压比热与定容比热基本相等。因此，\(C_v\) 和 \(C_{\rho}\) 可以互换使用。

多孔固体的本构响应形式为（符号约定见理论背景（Theoretical Background））

(14)\[\check \sigma_{ij} + \alpha {{\partial p} \over {\partial t}} \delta_{ij} = H(\sigma_{ij}, \xi_{ij} - \xi_{ij}^T, \kappa)\]

其中，方程左侧的量为 Biot 有效应力，\(\check\sigma_{ij}\) 为共旋应力率，\(H\) 为本构定律的函数形式，\(\kappa\) 为历史参数，\(\delta_{ij}\) 为 Kronecker δ，\(\xi_{ij}\) 为应变率。

热应变率表示为（见热应变（Thermal Strains））

(15)\[\xi_{ij}^T = {\alpha}_t {{\partial T} \over {\partial t}} \delta_{ij}\]

其中，\(\alpha_t\) 为线膨胀系数。

特别地，关联有效应力与应变的弹性关系为（小应变）

(16)\[\sigma_{ij} - \sigma_{ij}^o + \alpha (p - p^o) \delta_{ij} = 2G (\epsilon_{ij} - \epsilon_{ij}^T) + (K - {2 \over 3} G) (\epsilon_{kk} - \epsilon_{kk}^T)\]

其中，上标 \(^o\) 表示初始状态，\(\epsilon_{ij}\) 为应变，\(K\) 和 \(G\) 为排水弹性固体的体积模量和剪切模量。

Biot 与 Terzaghi 有效应力

Biot 有效应力 \(\sigma_{ij} + \alpha p \delta_{ij}\) 的表达式可根据柔度原理推导（见Biot 系数的影响（Effect of the Biot Coefficient）），因此它表征固体的变形能力。另一方面，Terzaghi 有效应力 \(\sigma_{ij} + p \delta_{ij}\) 度量固体基质承受的应力水平；仍用它检测塑性材料破坏，或弹性固体的潜在破坏。

协调方程

应变率与速度梯度关系为

(17)\[\xi_{ij} = {1 \over 2} \left[v_{i,j} + v_{j,i} \right]\]

FLAC3D 中的流体流动边界和初始条件

初始条件对应已知压力和饱和度。这两个值必须与 FLAC3D 表述一致：如果饱和度小于 1，孔隙压力必须为零，反之亦然。（FLAC3D 中默认初始孔隙压力为零，饱和度为 1。）

考虑四类边界条件，分别对应：（1）给定孔隙压力；（2）给定比流量沿边界法向的分量；（3）渗漏边界；（4）不透水边界。

FLAC3D 的边界默认不透水。

渗漏边界条件形式为

(18)\[q_n = h (p - p_e)\]

其中，\(q_n\) 为比流量沿边界外法向的分量，\(h\) 为渗漏系数 [m3/N-sec]，\(p\) 为边界表面孔隙压力，\(p_e\) 为假定发生流入或流出渗漏的外部区域孔隙压力。

可用 FISH 施加其他组合边界条件，例如给定某段边界总流入量时保持均匀压力。

请注意，不能将饱和度作为边界条件施加，这一点与 FLAC 不同。此外，为使模型保持完全饱和，可将流体抗拉限值设为较大的负数。
