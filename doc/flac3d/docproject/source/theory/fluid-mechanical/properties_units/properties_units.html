流体流动分析的性质与单位

FLAC3D 中与流体流动相关的性质包括：渗透系数 \(k\)、流体质量密度 \({\rho}_f\)，以及 Biot 系数 \(\alpha\) 和 Biot 模量 \(M\)（用于颗粒可压缩材料中的流动），或者流体体积模量 \(K_f\) 和孔隙率 \(n\)（仅用于颗粒不可压缩材料中的流动）。热耦合参数为排水线膨胀系数 \({\alpha}_t\)（热力耦合），以及不排水热系数 \(\beta\)（孔隙热耦合）。下文考察这些性质。

所有热、孔隙及力学量必须采用一致的单位制。程序不执行单位转换。

渗透系数

FLAC3D 使用的各向同性渗透系数 \(k\)，例如 SI 单位下的 m2/(Pa/sec)，在文献中也称为流动性系数。它是 Darcy 定律中压力项的系数，与水力传导系数 \(k_h\)（例如 m/s）的关系为

(1)\[k = {k_h \over {{\rho_f} g}}\]

其中，\(g\) 为重力加速度。

固有渗透率 \(\kappa\)，例如单位 m2，与 \(k\) 的关系为：

(2)\[k = {\kappa \over \mu}\]

其中，\(\mu\) 为动力黏度，例如 N-sec/m2。

可使用方程(1)或 eq:\(eqfluid-prop-k2\)，由速度单位的 \(k_h\)，或 [长度]2 单位的 \(\kappa\)，推导 FLAC3D 所需的 \(k\)。请记住，\(k\) 的最终单位必须为 [L3T/M]，例如 SI 单位下为 m3 sec/kg 或 m2/Pa-sec。采用 20° C 水的 \(\mu\) = 1.011 × 10-3 kg/(m-sec)、\(\rho_w g\) = 9.81 × 103 Pa/m，以及 1 Darcy = 10-8 cm2，可推导换算关系，为 FLAC3D 中的水计算 SI 单位下的 \(k\)：

\(k\)（SI 单位）\(\equiv \kappa\)（cm2）× 9.9 × 10-2

\(k\)（SI 单位）\(\equiv k_h\)（cm/sec）× 1.02 × 10-6

\(k\)（SI 单位）\(\equiv\) 以毫达西计的渗透率 × 9.9 × 10-13

如果网格内渗透率变化，时间步由最大渗透率控制（见此方程（this equation））。对于只需稳态、不需瞬态行为的问题，限制渗透率变化可能有助于加快收敛。例如，当流动完全从一个渗透率区域进入另一个时，渗透率变化比为 20:1 的系统，与 200:1 的系统相比，最终状态可能差别很小。

渗透系数（标量或张量）是网格单元性质，使用 单元流体属性（zone fluid property） 命令指定（见网格已配置流体流动（Grid Configured for Fluid Flow））。

质量密度

不同情况下，可向 FLAC3D 输入三种不同质量密度：固体基质干密度 \(\rho_d\)、固体基质饱和密度 \(\rho_s\) 和流体密度 \(\rho_f\)。请注意，仅在指定重力荷载时才需要密度。

如果 FLAC3D 已配置流体流动（配置流体计算模式（model configure fluid）），则必须使用固体材料的干密度。FLAC3D 根据已知流体密度、孔隙率 \(n\) 和饱和度 \(s\)，计算每个单元的饱和密度：\(\rho_s = \rho_d + n s \rho_f\)。

仅在不采用 配置流体计算模式（model configure fluid） 模式进行有效应力计算（静态孔隙压力分布）时，才输入饱和密度。通过 zone water 或 单元网格点初始化孔隙压力（zone gridpoint initialize pore-pressure） 命令指定地下水位位置。为地下水位以上网格单元指定干密度，以下指定饱和密度。

使用 zone property density 命令给定固体干密度或饱和密度。[DR：此内容应添加到 :cmd:`zone.property]流体密度可通过 单元水密度（zone water density） 命令全局指定，也可通过 单元初始化流体密度（zone initialize fluid-density） 命令使其随位置变化。但必须极其谨慎使用流体密度空间变化功能，因为 FLAC3D 中流体质量密度不进行平流输运。FLAC3D 中所有密度均为网格单元变量，且均为质量密度，例如 SI 单位 kg/m3。

流体模量

Biot 系数与 Biot 模量

Biot 系数 \(\alpha\) 定义为孔隙压力改变时，材料单元获得或失去的流体体积，与该单元体积变化之比。可通过用于确定材料排水体积模量 \(K\) 的同一排水试验确定。其变化范围为 \(3n/(2+n)\) 至 1，其中 \(n\) 为孔隙率。对于固体组分不可压缩的特殊情况，\(\alpha\) = 1；这也是 FLAC3D 采用的默认值。

对于理想多孔材料，Biot 系数与固体组分体积模量 \(K_s\) 的关系为：

(3)\[\alpha = 1 - {{K}\over{K_s}}\]

Biot 模量 \(M\) 定义为

(4)\[M = {{K_u - K}\over{\alpha^2}}\]

其中，\(K_u\) 为材料不排水体积模量。

对于理想多孔材料，Biot 模量与流体体积模量 \(K_f\) 的关系为：

(5)\[M = {{K_f}\over{n + (\alpha - n)(1 - \alpha)K_f/K}}\]

其中，\(n\) 为孔隙率。因此，对不可压缩固体组分（\(\alpha\) = 1），

(6)\[M = K_f / n\]

使用 单元流体比奥（zone fluid biot） 开启（on） 命令开启可压缩颗粒计算模式。Biot 系数是网格单元性质，通过 单元流体属性比奥（zone fluid property biot） 命令指定。Biot 模量是网格点变量，通过 zone gridpoint initialize biot-modulus 命令指定。

流体体积模量

可忽略颗粒可压缩性时，用户可以采用默认 Biot 系数，即 \(\alpha\) = 1，并为 Biot 模量赋予 \(K_f/n\) 值；也可输入流体体积模量 \(K_f\)。

体积模量 \(K_f\) 定义为

(7)\[K_f={\Delta P\over\Delta V_f/V_f}\]

其中，\(\Delta P\) 为体积应变 \(\Delta V_f/V_f\) 对应的压力变化。

输入流体模量 \(K_f\) 时，程序对不可压缩颗粒按方程(7)内部计算 Biot 模量。该计算利用节点体积平均，将网格单元性质孔隙率求至节点。随后，无论该性质先前给定何值，整个流动区域的 Biot 系数均设为 1。不可压缩颗粒的流体计算是 FLAC3D 默认方式，即 单元流体比奥（zone fluid biot） 关闭（off）。流体模量是网格点变量，通过 单元网格点初始化流体模量（zone gridpoint initialize fluid-modulus） 命令指定。

流体“压缩系数”\(C_f\) 是 \(K_f\) 的倒数，即 \(C_f = 1/K_f\)。例如，室温纯水的 SI 单位值为 \(K_f\) = 2 × 109 Pa。真实土体孔隙水可能含有一些溶解空气或气泡，会显著降低其表观体积模量。例如，Chaney (1978) 报告，在压实砂中，饱和度为 99% 的空气水混合物，其流体模量可降低一个数量级。对于地下水问题，可为网格不同部分采用不同水体积模量，以考虑空气含量变化。可用 FISH 函数按某种定律改变局部模量，例如令模量与压力成正比来表示气体，但用户应注意避免不符合物理实际的假设。

流体模量与收敛

如果需要稳态完全饱和流动，模量 \(M\) 或 \(K_f\) 对数值收敛过程不重要，因为系统响应时间和时间步都与 \(M\) 或 \(K_f\) 成反比；所需步数相同，与 \(M\) 或 \(K_f\) 无关。但对于含潜水面的系统，较低体积模量会加快稳态收敛，因为饱和度变化计算涉及 \(\Delta t\)，而非乘积 \(M \Delta t\) 或 \(K_f \Delta t\)（见此方程（this equation）及此方程（this equation））。固体与流体相互作用重要的系统更难评估，一些指导原则见时间尺度（Time Scale）。不过，与力学 \(K\) 相比，较高 \(M\) 或 \(K_f\) 会使求解收敛缓慢。无论如何，从数值角度，模拟中无需采用大于 \((K + 4/3 G)/\alpha^2\) 或 \((K + 4/3 G)n\) 二十倍的 \(M\) 或 \(K_f\) 值（见时间尺度（Time Scale）、此方程（this equation），示例见一维固结（1D Consolidation））。

排水与不排水分析中的流体模量

在 FLAC3D 中，只要选用了流体体积模量（或 Biot 模量）并指定了 配置流体计算模式（model configure fluid），就必须为固体骨架指定排水体积模量。程序随后将计算固体骨架的表观（不排水）体积模量，该模量会随时间演化。

也可以在不指定 配置流体计算模式（model configure fluid） 的情况下进行不排水分析。此时，应为固体骨架指定不排水体积模量 \(K_u\)。不排水体积模量为

(8)\[K_u = K + {\alpha}^2 M\]

对于不可压缩的固体组分，\(\alpha\) = 1，\(M = K_f/n\)，此公式变为

(9)\[K_u = K + {{K_f}\over n}\]

孔隙率

孔隙率 \(n\) 是无量纲数，定义为单元中孔隙体积与总体积之比。它与孔隙比 \(e\) 的关系为

(10)\[n = {e\over 1+e}\]

若未指定，\(n\) 的默认值为 0.5。\(n\) 应取 0 到 1 之间的正数，但使用较小值（例如小于 0.2）时应格外谨慎，因为孔隙流体的表观刚度与 \(K_f/n\) 成正比。当 \(n\) 较小时，该刚度可能远大于固体材料的刚度，导致 FLAC3D 求解需要很长时间才能收敛。此时可考虑减小 \(K_f\)（更多指导见流体模量与收敛（Fluid Moduli and Convergence）及时间尺度（Time Scale））。

FLAC3D 使用孔隙率计算介质的饱和密度，并在输入流体体积模量时计算 Biot 模量。FLAC3D 在计算循环中不更新孔隙率，因为这一过程耗时，而且只影响瞬态响应的斜率。孔隙率是通过 单元流体属性孔隙率（zone fluid property porosity） 命令指定的网格单元性质。

饱和度

饱和度 \(s\) 定义为流体占据的孔隙体积与总孔隙体积之比。在 FLAC3D 的公式体系中，若某点饱和度小于 1，则该点孔隙压力设为零。可在保持饱和度为 1 的同时减小局部流体模量，以考虑溶解空气和滞留空气的影响（即假设整个孔隙空间都存在一种等效流体）。虽然非饱和区域不存在孔隙压力，但其中滞留的流体仍有重量（即体力仍起作用），且流体在重力作用下流动（其表观渗透系数降低，见此式（this equation））。

初始饱和度可由用户给定，但 FLAC3D 也会在计算循环中根据需要更新饱和度，以维持质量平衡。注意，在 FLAC3D 中，饱和度不被视为独立变量，不能在任何网格点将其固定。

不排水热系数

不排水热系数 \(\beta\) 定义为不排水约束试验（不发生变形）中，单位温度变化引起的孔隙压力变化除以 3\(\alpha M\)。

对于理想多孔材料，该系数与颗粒的体积热膨胀系数 \(\beta_g\) 及流体的体积热膨胀系数 \(\beta_f\) 之间的关系为

(11)\[\beta = 3[\beta_g(\alpha - n) + \beta_f n]\]

不排水热系数是网格单元性质，通过 设置单元流体不排水热系数属性命令（zone fluid property undrained-thermal-coefficient） 命令指定。

流体抗拉极限

在细粒土中，孔隙水可能承受较大的拉力。在 FLAC3D 中，默认情况下可以产生负孔隙压力，直到达到某一极限，超过该极限后便会发生脱饱和。负孔隙压力极限通过 单元网格点初始化流体抗拉（zone gridpoint initialize fluid-tension） 命令设置，其值为负数（默认设为 -1015）。注意，负孔隙压力不同于毛细力、电力或化学力产生的“拉力”。后者最好通过增大本构模型中的有效应力来表示。流体负压与材料是否由颗粒组成无关；这种压力仅由充满流体的体积发生膨胀而产生。
