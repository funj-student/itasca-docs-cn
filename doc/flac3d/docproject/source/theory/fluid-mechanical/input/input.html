基于网格单元的孔隙压力

FLAC3D 新增通过 FISH 设置基于网格单元的孔隙压力的功能，可快速导入外部来源的孔隙压力，并计入由这种孔隙压力变化产生的应力增量。此功能严格用于计算网格单元孔隙压力变化引起的模型力学变化。启用此功能时，FLAC3D 中的流体流动不应处于激活状态。

此功能假定 FLAC3D 已配置流体计算（配置流体计算模式（model configure fluid）），且流体流动计算已关闭（单元流体活动（zone fluid active） 关闭（off））。

基于网格单元的孔隙压力存储在由 配置流体计算模式（model configure fluid） 命令启用的“流体网格单元”中。其变化产生的应力变化由以下方程确定：

(1)\[\begin{split}\begin{matrix} \sigma_{11}^{new} = \sigma_{11}^{old} - \alpha \Delta p \\ \\ \sigma_{22}^{new} = \sigma_{22}^{old} - \alpha \Delta p \\ \\ \sigma_{33}^{new} = \sigma_{33}^{old} - \alpha \Delta p \\ \end{matrix}\end{split}\]

其中，\(\alpha\) 为 Biot 系数，是流体模型的一项材料性质，默认为 1.0。

向 FLAC3D 指示使用基于网格单元孔隙压力的命令为 单元流体单元基于孔隙压力（zone fluid zone-based-pp） 开启（on）。使用该命令后，FISH 函数 单元孔隙压力（zone.pp） 可用于获取和赋予网格单元孔隙压力。请注意，当 单元流体单元基于孔隙压力（zone fluid zone-based-pp） 开启（on） 时，FLAC3D 会跟踪通过 FISH 函数 单元孔隙压力（zone.pp） 最近两次赋予该网格单元的孔隙压力，从而可计算孔隙压力变化（\(\Delta p = p^{new} - p^{old}\)）。每次通过 FISH 函数 单元孔隙压力（zone.pp） 赋予网格单元孔隙压力时，原先存储值成为 \(p^{old}\)，新赋值成为 \(p^{new}\)。如果遇到 zone fluid zone-based-pp on 命令，它会用平均的基于网格点的孔隙压力自动初始化基于网格单元的孔隙压力（\(p^{new}\) 和 \(p^{old}\) 两者）。

如果最初将 单元流体单元基于孔隙压力（zone fluid zone-based-pp） 设为 关闭（off），FLAC3D 将在计算中使用基于网格点的孔隙压力，这是 FLAC3D 的默认模式。

如果 单元流体单元基于孔隙压力（zone fluid zone-based-pp） 原先为 开启（on），随后发出 单元流体单元基于孔隙压力（zone fluid zone-based-pp） 关闭（off） 命令，则不会用基于网格单元的孔隙压力初始化基于网格点的孔隙压力。

命令 单元网格点固定孔隙压力（zone gridpoint fix pore-pressure） 和 单元网格点初始化孔隙压力（zone gridpoint initialize pore-pressure） 不改变基于网格单元的孔隙压力，只处理与网格点相关的量。绘制“网格单元 -> 按等值线着色 -> 数值：孔隙压力”时，仅显示网格点相关量。若需绘制基于网格单元的孔隙压力，可先将其存入 单元附加变量（zone.extra），再通过“网格单元 -> 按等值线着色 -> 附加变量；来源：网格单元”绘制。

下面是一个演示该功能用法的建模流程。

  1. 创建模型几何体（网格单元），不要忘记 配置流体计算模式（model configure fluid）。
  2. 为网格单元赋予力学模型和性质。
  3. 为网格单元赋予流体模型和 Biot 系数，后者默认为 1。
  4. 将 单元流体活动（zone fluid active） 设为 关闭（off），将 单元力学活动（zone mechanical active） 设为 开启（on），将 单元流体单元基于孔隙压力（zone fluid zone-based-pp） 设为 开启（on）。
  5. 使用 单元孔隙压力（zone.pp） 函数，为每个网格单元赋予基准孔隙压力。
  6. 使用 单元孔隙压力（zone.pp） 函数，为每个网格单元赋予更新后的孔隙压力。
  7. 求解至力学平衡。

“\datafiles\Fluid\ZoneBasedPorePressure”中提供一个简单算例，主要数据文件如下。

ZoneBasedPorePressure.dat：

model new
model large-strain off
model configure fluid
;
zone create brick size 2 2 2 point 1 (1 0 0) point 2 (0 1 0) point 3 (0 0 1)
zone gridpoint fix velocity-x range union position-x 0 position-x 1
zone gridpoint fix velocity-y range union position-y 0 position-y 1
zone gridpoint fix velocity-z range position-z 0
; 力学模型
zone cmodel assign elastic
zone property density 1.0 bulk 400 shear 300
model gravity 0 0 -1
; 流体流动模型
zone fluid cmodel assign isotropic
zone fluid property biot 1.0
;
model fluid active off
model mechanical active on
zone fluid zone-based-pp on
;
program call 'fishFunctions'
;
; 从 basetp.dat 文件读取基准孔隙压力，并存储到网格单元中
[_baseline]
; 从 updatetp.dat 文件读取更新后的孔隙压力和温度，并存储到网格单元中
[_update]
;
model solve
; 将基于网格单元的孔隙压力存入单元扩展变量
[_pt2extra]
;
model save 'zonebased'
