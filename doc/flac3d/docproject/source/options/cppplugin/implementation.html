实现

实用结构

提供了一些结构体/类，以帮助编写本构模型并与之通信。其中一些由“base007.dll”提供，它定义了所有插件接口共通的基础功能层。另一些由“conmodel007.dll”提供，它定义了本构模型系统使用的特定接口。在所有情况下，类定义的完整文档均可在 程序员接口（Programmer’s Interface） 文档的基础接口模块中查阅。

“base007.dll”提供：

Int, UInt, Byte, UByte, Double, Float 等——定义于“base/src/basedef.h”。这些类型替代标准 C++ 类型 int、unsigned、char、double 等。使用这些替代类型是为了定义一致的大小。例如，无论平台如何，Int 都保证为一个有符号 32 位量。

String——定义于“base/src/basebool.h”。该类派生自 std::basic_string<wchar_t>，即 ANSI C++ 标准字符串类。String 类增加了一些方便的实用函数，例如字符串到数值的转换。

DVect3——定义于“base/src/vect.h”。该类实际上是模板类 Vector3<T> 的 double 实例。类似的预定义类型有 IVect (Vector3<Int>) 和 UVect (Vector3<UInt>)。该类使三维矢量能够像基本类型一样使用，并通过完整的运算符重载提供便利的语法。

Variant —— 定义于 “base/src/variant.h”。 它定义了一种可表示多种不同基本类型的类型 （例如 String、Double、Int 等）。 该类用于向本构模型传递属性以及从本构模型传出属性。

Axes —— 定义于 “base/src/axes.h”。 该类允许定义正交归一基。该基可用于 在由传统笛卡尔坐标轴表示的“整体”基之间转换坐标。

SymTensor —— 定义于 “base/src/symtensor.h”。 该类定义一个 3 \(\times\) 3 的对称张量，通常用于表示应力和应变。 成员访问可通过 s11()、s12()、s13()、s22() 等函数实现。 成员修改可通过 rs11()、rs12() 等函数实现。 此外，特征向量信息（即主方向和主值）可通过 getEigenInfo() 函数获得。 辅助类 SymTensorInfo 用于使用户在保持主方向不变的同时修改主值， 并用所得结果构造一个新的 SymTensor。

Orientation3 —— 定义于 “base/src/orientation.h”。 该类提供 方位（即空间中的一个方向）的存储与操作。 该方位既可通过法向矢量指定，也可通过倾角和倾向指定。

除 ConstitutiveModel 和 State 接口之外，“conmodel007.dll”还在“convert.h”中提供以下两个实用函数：getYPFromBS() 和 getBSfromYP()。这些函数可用于将杨氏模量和泊松比的值转换为体积模量和剪切模量的值，反之亦然。

本构模型示例

FLAC3D 所使用的所有本构模型的源代码均已提供，供用户查看或修改。 此处为便于说明，我们摘录了文件“modelexample.*”中所含 Mohr-Coulomb 弹塑性模型的部分内容。 modelexample.h 文件（modelexample.h） 给出了该模型的类声明，其中还包括该模型唯一类型编号的定义。 请注意，ModelElastic 基类中的受保护变量多于性质名称（见 getProperties() 成员函数）。 在该模型中，某些变量仅供内部使用：它们在每个网格单元中占用内存，但 FLAC3D 用户无法更改或打印它们。 另请注意，getProperty()/setProperty 接口用于 Save/Restore。

modelexample.h：

#pragma once

#include "models/elastic/src/modelelastic.h"

namespace models {
    class ModelExample : public ModelElastic {
    public:
        ModelExample(unsigned short option=0);
        virtual String        getName() const override;
        virtual String        getFullName() const override;
        virtual UInt          getMinorVersion() const override; 
        virtual String        getProperties() const override;
        virtual String        getStates() const override;
        virtual Variant       getProperty(UInt index) const override;
        virtual void          setProperty(UInt index,const Variant &p,UInt restoreVersion=0) override;
        virtual ModelExample *clone() const override { return new ModelExample(); }      
        virtual void          copy(const ConstitutiveModel *mod) override;
        virtual void          run(UByte dim,State *s) override; 
        virtual void          initialize(UByte dim,State *s) override;
        // 可选
        virtual bool          isPropertyAdvanced(UInt i) const override;
        virtual bool          supportsStressStrengthRatio() const override { return true; }
        virtual bool          supportsPropertyScaling() const override { return true; }
        virtual Double        getStressStrengthRatio(const SymTensor &st) const override;
        virtual void          scaleProperties(const Double &scale,const std::vector<UInt> &props) override;

    private:
        virtual bool          updateParameters() override;
        virtual bool          updateParameters(bool bEUpdated,Double *sf1=nullptr,Double *sf3=nullptr);
        virtual Double        moduliReduction(const Double &factor) override;
        virtual void          apexCorrection(const Double &fric,State *s,DVect3 *prin,UInt *iPlasticity=nullptr,bool bBrittle=false);
        virtual void          tensionCorrection(State *s,DVect3 *prin,UInt *iPlasticity,const Double &ftz,bool bBrittle=false);
        virtual void          shearCorrection(State *s,DVect3 *prin,UInt *iPlasticity,const Double &fs);

        Double cohesion_ = 0.0;
        Double friction_ = 0.0;
        Double dilation_ = 0.0;
        Double tension_ = 0.0;
        bool brittle_ = false;
        Double nph_  = 0.0;
        Double csn_ = 0.0;
        Double nps_ = 0.0;
        Double rc_ = 0.0;
        Double sc1_ = 0.0;
        Double sc2_ = 0.0;
        Double sc3_ = 0.0;
    };
} // namespace models

// 文件结束

该模型的构造函数列于 典型模型构造函数（Typical Model Constructor）。示例初始化与运行函数（initialize and run functions）给出了用于初始化和执行（“运行”）的成员函数清单。请注意，为节省时间，受保护的模型变量 e1_、e2_、g2_ 等并非在每个计算循环中计算，而是在 ModelElastic::updateParameters 方法中进行初始化时计算。另请注意使用 State 结构来提供应变增量和应力。每个模型中都可以提供独立的部分，分别用于二维和三维执行，从而使相同的模型能在 FLAC 或 UDEC 中高效使用。在本示例中，二维部分与三维部分完全相同。成员函数的清单请参阅文件“modelexample.cpp”：getProperties、getStates、getProperty、setProperty 和 copy。

initialize() 和 run() 函数

    void ModelExample::initialize(UByte d,State *s) {
        ConstitutiveModel::initialize(d,s);
        updateParameters();
    }

    void ModelExample::run(UByte d,State *s) {
        ConstitutiveModel::run(d,s);

        if (s->modulus_reduction_factor_ > 0.0)
            moduliReduction(s->modulus_reduction_factor_);
// excerpt-state-start
        if (s->state_ & shear_now) s->state_ |= shear_past;
        s->state_ &= ~shear_now;
        if (s->state_ & tension_now) s->state_ |= tension_past;
        s->state_ &= ~tension_now;
// excerpt-state-end
        UInt iPlas = 0;

        ModelElastic::elasticTrial(s);
        s->viscous_ = true;        
        if (!canFail()) return;

        SymTensorInfo info;
        DVect3 prin = s->stnS_.getEigenInfo(&info);

        Double fs  = nph_*prin.z() - prin.x() - csn_;
        Double fsd = fs / rc_;
        Double ftz = prin.z() - tension_;
        if (fsd > 0.0 && fsd >= ftz)
            shearCorrection(s,&prin,&iPlas,fs);
        else if (ftz > 0.0 && ftz >= fsd)
            tensionCorrection(s,&prin,&iPlas,ftz,brittle_);
        apexCorrection(friction_,s,&prin,&iPlas,brittle_);

        if (iPlas) {
            s->stnS_ = info.resolve(prin);
            s->viscous_ = false;
        }
    }

    bool ModelExample::updateParameters() {
        Double rsin = std::sin(friction_ * degrad);
        nph_ = (1.0 + rsin) / (1.0 - rsin);
        csn_ = 2.0 * cohesion_ * sqrt(nph_);
        rsin = std::sin(dilation_ * degrad);
        nps_ = (1.0 + rsin) / (1.0 - rsin);
        rc_  = std::sqrt(1.0 + nph_*nph_);
        //
        if (friction_) {
            Double apex = cohesion_ / std::tan(friction_ * degrad);
            tension_ = std::min(tension_,apex);
        }
        //
        ModelElastic::updateParameters();
        //
        Double ra = e1_ - nps_ * e2_;
        Double rb = e2_ - nps_ * e1_;
        Double rd = ra - rb * nph_;
        sc1_  = ra / rd;
        sc3_  = rb / rd;
        sc2_  = e2_ * (1.0 - nps_) / rd;
        //
        return true;
    }

    bool ModelExample::updateParameters(bool bEUpdated, Double *sf1, Double *sf3) {
        if (cohesion_ < 0.0)
            throw std::runtime_error("Example model: cohesion is not allowed less than 0.");

        if (friction_ >= 90.0 || friction_ < 0.0)
            throw std::runtime_error("Example model: friction angle is not in the valid range of 0 to 90.");

        if (dilation_ > friction_)
            throw std::runtime_error("Example model: dilationn angle is not allowed greater than friction angle.");

        Double rsin = std::sin(friction_ * degrad);
        nph_ = (1.0 + rsin) / (1.0 - rsin);
        csn_ = 2.0 * cohesion_ * sqrt(nph_);
        rsin = std::sin(dilation_ * degrad);
        nps_ = (1.0 + rsin) / (1.0 - rsin);
        rc_  = std::sqrt(1.0 + nph_*nph_);
        //
        if (friction_) {
            Double apex = cohesion_ / std::tan(friction_*degrad);
            tension_ = std::min(tension_,apex);
        }
        //
        if (!bEUpdated) ModelElastic::updateParameters();
        //
        Double ra = e1_ - nps_*e2_;
        Double rb = e2_ - nps_*e1_;
        Double rd = ra  - rb*nph_;
        sc1_ = ra/rd;
        sc3_ = rb/rd;
        sc2_ = e2_*(1.0 - nps_)/rd;
        //
        if (sf1) *sf1 = -1.0/rd;
        if (sf3) *sf3 = nps_/rd;
        //
        return !bEUpdated;
    }

对本构模型的 FISH 支持

FISH 内建函数 单元属性值（zone.prop） 在 FLAC3D 中可用。 它可用于表达式的左侧或右侧。 因此，

val = zone.prop(zp, p_name)

将地址为 单元指针（zp） 的网格单元中名为 属性名称（p_name） 的性质的浮点值存入 属性值（val）。 属性名称（p_name） 可以是包含该性质名称的字符串，也可以是求值得到此类字符串的 FISH 变量。 例如，zone.prop(zp,'bulk') 将引用体积模量。 若 单元指针（zp） 中没有本构模型，或该模型不具有所命名的性质，则返回 0.0。类似地，

zone.prop(zp, p_name) = val

将 属性值（val） 存入网格单元 单元指针（zp） 中名为 属性名称（p_name） 的性质。 若 单元指针（zp） 中没有本构模型，或该模型不具有所命名的性质，或 属性值（val） 不是整数或浮点数，则不存储任何内容。 在两种用法中，单元指针（zp） 必须是网格单元指针，并且 属性名称（p_name） 必须是字符串或包含字符串的 FISH 变量。

创建用户自定义模型 DLL

使用模板

在 Visual Studio 2017 或 2019 中创建本构模型项目的最简单方法， 是使用 Itasca 公司提供的 ItascaProjectTemplates 扩展（ItascaProjectTemplates） 扩展模板。

加载和运行用户自定义模型 DLL

在 FLAC3D 运行期间，可通过给出命令 单元本构模型荷载（zone cmodel load） filename 并指定 DLL 的文件名，将模型 DLL 文件加载到其中。若将 DLL 文件放在“exe64\plugins\cmodel”文件夹中，则会自动加载。此后，FLAC3D 以及引用该模型及其性质的 FISH 函数将识别新的模型名称和性质名称。若对已加载的模型再次给出 单元本构模型荷载（zone cmodel load） 命令，则不会执行任何操作，但会显示一条提示信息。

在将本构模型插件赋给网格单元之前，必须先通过给出 model configure plugin 命令将模型配置为可使用插件。 配置之后，除非您的 FLAC3D 许可证包含 C++ 插件选项，否则模型将无法进行循环计算。
