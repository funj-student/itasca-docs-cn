数值公式

传导

能量平衡方程（energy-balance equation）与傅里叶定律（Fourier’s law）一起在 FLAC3D 中采用有限体积方法求解，该方法基于将介质离散为网格单元，而网格单元由两组叠合的常热流四面体组成。该数值格式以能量平衡方程的节点形式为基础。该表述等价于力学表述（见理论背景（Theoretical Background）中给出牛顿定律节点形式的那一表述）。只需分别用温度、热流向量和温度梯度替代速度向量、应力张量和应变率张量即可得到。所得的常微分方程组采用两种时间离散模式求解，分别对应显式格式和隐式格式。主要结果概述如下。

空间导数的有限体积近似

按惯例，四面体的节点在局部用 1 至 4 的编号表示，面 \(n\) 与节点 \(n\) 相对，上标 \((f)\) 表示相应变量在面 \(f\) 上的值。

假定四面体内温度呈线性变化；温度梯度通过应用高斯散度定理以温度的节点值表示，可写为

(1)\[T_{,j} = - {{1}\over{3V}} \sum_{l=1}^4 T^l\ n_j^{(l)}\ S^{(l)}\]

其中 \([n]^{(l)}\) 是面 \(l\) 的外向单位法向量，\(S\) 是该面的表面积，\(V\) 是四面体的体积。

能量平衡方程的节点表述

能量平衡方程（energy-balance equation）可表示为

(2)\[q_{i,i} + b^* = 0\]

其中

(3)\[b^* = \rho C_v {{\partial T}\over{\partial t}} - q_v\]

相当于力学节点表述中所用的瞬时“体力”。首先考虑单个四面体。利用这一类比，与四面体热流和体力平衡的节点热量 \(Q_e^n [W]\)（\(n\) = 1,4）可表示为

(4)\[Q_e^n = Q_t^n - {{q_v V}\over{4}} + m^n\ C_v^n {{dT}\over{dt}}^n\]

其中

(5)\[Q_t^n = {{q_i n_i^{(n)} S^{(n)}}\over 3}\]

以及

(6)\[m^n = {{\rho V}\over{4}}\]

原则上，能量平衡方程的节点形式是这样建立的：要求在每个全局节点处，汇聚于该节点的所有四面体提供的等效节点热量（\(-Q_e^n\)，对于两个叠合层除以二）与所施加边界热流和热源的节点贡献（\(Q_w^n\)）之和为零。

方程(5)中四面体热流向量各分量通过输运定律与温度梯度相联系（见傅里叶定律（Fourier’s law））。反过来，温度梯度的各分量可利用方程(1)以四面体的节点温度表示。

为节省计算机时间，FLAC3D 中采用网格单元表述。对某一网格单元的各节点 \(n\)，将该单元内所有汇聚于该节点的四面体的贡献（方程(5)）求和得到 \(Q_z^n\)，并对两个叠合层除以二。组装联系节点单元量 \(Q_z^n\) 与节点单元温度 \(T^n\)（\(n\) = 1,8）的局部单元矩阵 \([M]\)。由于矩阵是对称的，只计算 36 个分量。这些分量在计算开始时保存，并在大应变模式下每 10 步更新一次。按单元矩阵的定义，有

(7)\[Q_z^n = M_{nj} T^j\]

其中 \([T]\) 是节点单元温度的局部向量。

反过来，全局节点值 \(Q_T^n\) 通过叠加各网格单元的贡献得到。在记号上稍作宽松处理，对每个全局节点 \(n\) 可写为

(8)\[Q_T^n = C_{nj} T^j\]

其中 \([C]\) 是全局矩阵，此处 \([T]\) 是节点温度的全局向量。

再次考虑单个四面体，可写为

(9)\[- \sum Q_e^n + \sum Q_w^n = 0\]

其中为简化记号，用 \(\sum\) 符号表示汇聚于全局节点 \(n\) 的所有网格单元在该节点处贡献之和。（一个网格单元的贡献由该单元内所有四面体的贡献组成，对两个叠合层除以二。）将方程(4)代入方程(9)，经整理可得

(10)\[{{d T^n}\over{d t}} = - {{1} \over {\sum[m C_p]^n}} \left[Q_T^n + \sum Q_{app}^n \right]\]

其中 \(Q_T^n\) 是方程(8)所定义的节点温度的函数，而 \(\sum Q_{app}^n\) 是所施加体积源、边界热流和点源的已知贡献，定义为

(11)\[\sum Q_{app}^n = - \sum {\left[{{q_v V}\over{4}} + Q_w\right]}^n\]

方程(10)是节点 \(n\) 处能量平衡方程的节点形式；右端项 \(Q_T^n + \sum Q_{app}^n\) 称为“不平衡热量”。离散化中所涉及的每个全局节点都成立一个这样的表达式。它们共同构成常微分方程组，FLAC3D 中采用显式和隐式有限体积格式求解。下面对各格式的适用范围进行讨论。

显式有限体积格式

在显式格式中，假定节点温度在时间区间 \(\Delta t\) 内线性变化：方程(10)左端的导数用前向有限差分表示；不平衡热量在时刻 \(t\) 取值。从初始温度场开始，若温度未被固定，则各增量时刻的节点温度用下式更新

(12)\[T_{<t+\Delta t>}^n = T_{<t>}^n + \Delta T_{<t>}^n\]

其中

(13)\[\Delta T_{<t>}^n = {\chi}^n \left[ Q_{T <t>}^n + \sum Q_{app<t>}^n \right]\]

以及

(14)\[{\chi}^n = - {{\Delta t}\over{\sum [m C_p]^n}}\]

只有时间步长保持低于某一限值，显式方案才能达到数值稳定。

稳定性准则

为推导稳定性准则，考虑如下情形：对网格单元组合体中的某节点 \(n\)，从零初始状态施加温度扰动 \(T_0\)。利用方程(8)可得

(15)\[Q_T^n = C_{nn}\ T_0\]

若节点 \(n\) 属于对流边界，则有

(16)\[\sum Q^n_{app} = D_{nn}\ T_o\]

其中 \(D_{nn}\) 用于表示节点 \(n\) 处全局对流项中的温度系数。

经过一个热学时步后，节点 \(n\) 处的新温度为（见方程(12)至(14)）

(17)\[T_{<\Delta t>}^n = T_0 \left[ 1 - {{\Delta t}\over{\sum [m C_p]^n}} (C_{nn} + D_{nn}) \right]\]

为防止计算按相继的 \(\Delta t\) 重复进行时温度符号交替变化，上式中 \(T_0\) 的系数必须为正。该要求意味着

(18)\[\Delta t < {{\sum [m C_p]^n}\over{C_{nn} + D_{nn}}}\]

FLAC3D 中所用时步的取值为方程(18)右端在所有节点上的最小值乘以安全系数 0.8。

为评估所涉参数的影响，记住临界时步的以下表示形式是有用的。若 \(L_c\) 是最小四面体特征长度，则可写出如下形式的表达式

(19)\[\Delta t_{cr} = {{1}\over{m}} {\left [ {{\kappa}\over{L_c^2}} + {{h}\over{\rho\ C_v L_c}} \right ]}^{-1}\]

其中 \(\Delta t_{cr}\) 是临界时步，\(\kappa\)、\(h\)、\(\rho\) 和 \(C_v\) 已在前文数学模型说明（Mathematical Model Description）中定义，\(m\) 是大于 1 的常数，取决于介质的几何离散方式（例如，对于立方体的规则离散，\(m\) = 6——见 Karlekar 和 Desmond 1982）。

方程(19)中的临界时步对应于扩散“前缘”穿过整个四面体所需特征时间的量度。为估算前缘穿过某一特定区域所需的时间，可使用类似的表达式，只要将 \(L_c\) 解释为所考虑区域的特征长度。考虑无对流的情形。取区域与四面体特征时间之比可以看出，模拟扩散过程在该区域内传播所需的步数与区域和四面体特征长度平方之比成正比。该步数可能大到使仅使用显式方法变得难以承受。

另一方面，这种一阶方法的优点在于所计算的时步通常足够小，能够准确跟踪节点温度的波动。

隐式有限体积格式

为保证稳定性而对 \(\Delta t\) 大小加以限制的要求，有时会导致时步极小（约为几分之一秒），特别是涉及多层瞬态传导时。隐式格式消除了这一限制，但需要在每个时步求解联立方程。

FLAC3D 中的隐式格式采用 Crank-Nicolson 方法，其中假定节点温度在时间区间 \(\Delta t\) 内按二次规律变化。在该方法中，方程(10)中的导数 \(dT/dt\) 采用对应于半个时步的中心差分格式表示，而不平衡热量取 \(t\) 和 \(t + \Delta t\) 处的平均值来评价。在该格式中，有

(20)\[T^n_{<t + \Delta t>} = T_{<t>}^n + \Delta T_{<t>}^n\]

其中

(21)\[\Delta T_{<t>}^n = {\chi}^n \left[{{1}\over{2}} \left(Q_{T <t + \Delta t>}^n + Q_{T <t>}^n \right) + \sum \overline{Q^n_{app}}\right]\]

以及

(22)\[\sum \overline{Q^n_{app}} = {1 \over 2} \left( \sum Q^n_{app<t + \Delta t>} + \sum Q^n_{app<t>} \right)\]

由方程(8)中的定义，可写为

(23)\[Q_{T<t>}^n = C_{nj} T_{<t>}^j\]

以及

(24)\[Q_{T<t + \Delta t>}^n = C_{nj} T_{<t + \Delta t>}^j\]

利用(12)，最后一个表达式变为

(25)\[Q_{T<t + \Delta t>}^n = Q_{T<t>}^n + C_{nj} \Delta T_{<t>}^j\]

将方程(25)代入方程(21)后，可得（利用方程(23)）

(26)\[\Delta T_{<t>}^n = {\chi}^n \left[C_{nj} T_{<t>}^j + {{1}\over{2}} C_{nj} \Delta T_{<t>}^j + \sum \overline{Q_{app}^n}\right]\]

最后，重新整理各项，

(27)\[\left[\delta_{nj} - {{\chi}^n\over{2}} C_{nj}\right] \Delta T_{<t>}^j = {\chi}^n \left[C_{nj} T_{<t>}^j + \sum \overline{Q_{app}^n}\right]\]

为书写简便，把已知矩阵 \([A]\) 与矢量 \([b_{<t>}]\) 定义为

(28)\[A_{nj} = \delta_{nj} - {{\chi}^n\over{2}} C_{nj}\]

以及

(29)\[b_{n<t>} = {\chi}^n \left[C_{nj} T_{<t>}^j + \sum \overline{Q_{app}^n}\right]\]

采用这一约定，可将方程(27)写为

(30)\[A_{nj} \Delta T_{<t>}^j = b_{n<t>}\]

对网格中所涉及的每个节点都可写出这样一个方程。所得的方程组在 FLAC3D 中采用 Jacobi 迭代法求解。在该方法中，迭代 \(r + 1\) 和节点 \(n\) 处的温度增量用以下递推关系计算

(31)\[\Delta T_{<t>}^{n <r+1>} = \Delta T_{<t>}^{n <r>} + {{1}\over{A_{nn}}} \left[-A_{nj} \Delta T_{<t>}^{j <r>} + b_{n<t>}\right]\]

其中爱因斯坦记号约定仅适用于指标 \(j\)。利用方程(28)对 \([A]\) 的定义，方程(31)变为

(32)\[\Delta T_{<t>}^{n <r+1>} = \Delta T_{<t>}^{n <r>} + {{1}\over{1 - {{\chi}^n\over{2}} C_{nn}}} \left[{{\chi}^n\over{2}} C_{nj} \Delta T_{<t>}^{j <r>} - \Delta T_{<t>}^{n <r>} + b_{n<t>}\right]\]

初始近似值的选择使其满足

(33)\[\Delta T_{<t>}^{n <0>} = 0\]

因此，第一次近似 \(\Delta T_{<t>}^{n <1>}\) 采用与显式格式相同、但除以 \(\left( 1 - {{\chi^n}\over 2} C_{nn}\right)\) 的公式计算。（请注意，在 FLAC3D 中，与温度相关的边界条件（包含在 \(b_n\) 中）在隐式迭代过程中更新。）

在 FLAC3D 中，最少考虑 3 次、最多 500 次迭代，收敛判据的形式为

(34)\[\max\limits_n \ \ \big\vert\ \ \Delta T^{n<r+1>}_{<t>} - \Delta T^{n<r>}_{<t>} \ \ \big\vert\ \ < 10^{-2}\ \left( \max\limits_n \ \ \big\vert\ \ \Delta T^{n<r>}_{<t>} \ \ \big\vert \right)\]

时步大小必须兼顾隐式格式的收敛性和精度来选择。尽管 Crank-Nicolson 方法对 \(\Delta t\) 的所有正值（无对流时）都是稳定的，但除非矩阵 \([A]\) 严格对角占优，否则 Jacobi 方法的收敛性并非无条件保证：

(35)\[\sum\limits_{{j=1}\atop{j\ne k}}^n \ \ \bigg\vert\ \ A_{kj} \ \ \bigg\vert\ \ < \ \ \bigg\vert\ \ A_{kk} \ \ \bigg\vert\]

对 \(1 \le i \le n\)（见 Dahlquist 和 Bjorck 1974）。根据方程(28)对 \(A_{nj}\) 的定义以及方程(14)对 \(\chi^n\) 的定义，对于足够小的 \(\Delta t\)，该充分条件总能满足。若 Jacobi 方法未收敛，将发出错误信息。此时必须减小隐式时步的大小，或改用显式方法。（显式时步可作为下界。）

此外，尽管隐式方法具有二阶精度，仍可能需要一些经验判断才能选择合适的时步。实际上，其时步值必须相对于任何节点温度波动的波长保持较小。通常，在计算早期或其扰动阶段使用显式方法，而在模拟的其余部分则优先使用隐式方法。（或者，为获得更高精度，隐式方法也可采用显式时步值。）

在 FLAC3D 中选择隐式方法时，必须考虑计算时间和计算机内存两个因素。在隐式方法中，每个时步都必须求解一组方程，至少需要三次迭代。一个迭代步所需的计算量约等于显式格式中一个时步所需的计算量。此外，迭代过程中必须存储中间值，与显式格式相比需要分配额外的内存。不过，这些不便可被隐式方法通常允许的大得多的时步或所能获得的精度提升所大大抵消。

热-应力耦合

在瞬态模拟过程中的任何时候，都可把热传导与热-应力计算耦合起来。该耦合仅单向进行（即温度可引起应力变化，但由施加力引起的物体力学变化不会导致温度变化）。一般认为这一限制在此并不重要，因为准静态力学问题的能量变化通常可忽略不计。三角形网格单元中的应力变化由下式给出（据此方程（this equation））：

(36)\[\Delta \sigma _{ij}\ =\ -3K\ \alpha_t\ \Delta T \delta _{ij}\]

上述公式假定每个三角形网格单元内的温度恒定，该温度由周围网格点插值得到。在应用本构律之前，将该应力加到网格单元的应力状态中。

通过 FISH 访问温度和属性值，也可将力学属性设为温度变化的函数。

热-孔隙压力耦合

由温度变化引起的孔隙压力变化，可通过在节点孔隙压力计算中向热-力学项增加一项贡献来获得（见流体-力学相互作用中的此方程（equation））。

相应的总应力变化用以下表达式计算（据流体-力学相互作用中的此方程（this equation）、此方程（this equation）和此方程（this equation））：

(37)\[\Delta \sigma_{ij} =\ - \alpha \ M \beta \ \Delta T\ \delta _{ij}\]

对于不可压缩固体颗粒（\(\alpha\) = 1 且 \(M = {{K_f} \over {n}}\)），该式变为

(38)\[\Delta \sigma_{ij} =\ - {K_f \over n} \beta \ \Delta T\ \delta _{ij}\]

通过 FISH 访问温度和性质值，也可使地下水性质成为温度变化的函数。

平流

对流-传导的开发是对前述显式有限体积流体和热传导实现的扩展。其做法是在热能平衡中加入平流项（如此方程（this equation）所述），以计入流体引起的强制对流。此外，通过在输运方程（此方程（this equation））中考虑流体密度对温度的依赖性（此方程（this equation）），计入了自然对流的逻辑。

平流逻辑中热传导部分的数值实现采用传导（Conduction）中所述的有限体积格式。该算法经过修改，在评价热学步的新温度之前，通过在节点的不平衡热流中加入热贡献来计入对流。对流贡献按网格单元计算。首先，在每个热学时步，为赋予对流模型的每个网格单元计算热源项 \(\rho_0 c_w q_w \cdot \nabla T V\)。在该公式中，\(q_w\) 是该网格单元的流体比流量，\(\nabla T\) 是温度梯度，\(V\) 是网格单元体积。温度梯度由各四面体的节点温度利用高斯散度定理评价，并对网格单元取平均。随后将热源项分配到各节点并加到其不平衡热流中。最后，输运方程中所用的局部流体密度按此方程（this equation）中的定律根据网格单元温度更新，以计入自然对流。

平流逻辑将流体计算与热学计算耦合，并依赖流体和热学模块的顺序推进。它通过热学本构模型 单元热本构模型指定（zone thermal cmodel assign） advection-conduction 激活。平流项在热学计算期间加入，需要输入流体比流量。该比流量可手动提供，也可由流体流动计算提供。温度场在流体流动计算期间用于评价浮力项。

稳定性与精度

求解能量平衡方程（此方程（this equation））的数值格式的稳定性由两个数控制：网格 Péclet 数 \(P_e\) 和网格 Courant 数 \(C_r\)。对于均匀比热 \(c^T\)，能量平衡方程（此方程（this equation））可写为

(39)\[{{\partial T} \over {\partial t}} = \nabla \cdot (D \nabla T) - {\bf v} \cdot \nabla T\]

其中，按定义，

(40)\[D = {{k^T} \over {c^T}}\]

以及

(41)\[{\bf v} = {{\rho_0 c_w} \over c^T} {\bf q}_w\]

Péclet 数给出平流与扩散相对效应的量度，定义为

(42)\[P_e = {{\|{\bf v}\|} \over {D / \Delta L}}\]

其中 \(\Delta L\) 是网格尺寸。Courant 数是粒子在时步 \(\Delta t^T\) 内所覆盖的平流距离相对于 \(\Delta L\) 的量度：

(43)\[C_r = {{\|{\bf v}\| \Delta t^T} \over {\Delta L}}\]

例如在一维情形下，经典约束为 \(P_e \leq 2\) 和 \(C_r \leq 1\)（例如见 Perrochet 和 Bérod 1993）。在当前的实现中，显式流体和热学时步基于流体和热扩散率计算，与流体和传导逻辑中所采用的时步相同。因此程序对网格 Péclet 数不设固有的限制。然而，不同数值下的精度很可能不同，并受网格尺寸和时步的影响。

警告：请注意，FLAC3D 所采用的显式时步对平流逻辑并非无条件稳定。
