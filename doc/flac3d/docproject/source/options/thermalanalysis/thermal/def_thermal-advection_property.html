平流-传导性质

以下是 平流-传导（Advection-Conduction） 模型的性质：

advection-conduction
conductivity-effective f

有效导热系数。

conductivity-fluid f

流体导热系数。

density-fluid f

随温度变化的流体密度。

expansion f

基质线性热膨胀系数。更多信息见热-应力耦合（Thermal-Stress Coupling）。

expansion-fluid f

流体体积热膨胀系数。

gradient-x f (r)

温度梯度的x分量。

gradient-y f (r)

温度梯度的y分量。

gradient-z f (r)

温度梯度的z分量。

specific-discharge-x f

比流量的x分量。

specific-discharge-y f

比流量的y分量。

specific-discharge-z f

比流量的z分量。

specific-heat-effective f

基质密度上的有效比热。

specific-heat-fluid f

流体比热。

temperature-reference f

参考温度。该关键字也适用于水化（Hydration）。
