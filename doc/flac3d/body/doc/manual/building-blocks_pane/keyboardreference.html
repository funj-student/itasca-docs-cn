键盘参考

以下是与块体构建窗格相关的键盘操作列表。

按键 功能
空格键或 Control+空格键 为当前选择显示弹出式属性编辑器。
Backspace 清除当前选择。
Tab 当块体构建窗格具有输入焦点且操纵柄可见时，Tab 键将把焦点移到对象属性控件组中的参考点字段（如果可见）。
Return/Enter 接受当前建议的块体。
上方向键、Page Up、左方向键 在建议块体列表中向上滚动。
下方向键、Page Down、右方向键 在建议块体列表中向下滚动。
Shift+{上方向键或下方向键} 在对几何进行点到点捕捉时，滚动切换几何图层。
删除 删除块体或控制点。
Alt+单击 重新定位操纵柄而不移动所选对象。
Alt+滚轮 第一人称导航模式。
Control 或 Shift 修改选择行为（selection behavior）
Shift 修改操纵柄行为（handle behavior）；在拆分块体模式下切换捕捉目标的显示。
Shift+单击 可以进行点到点移动/捕捉。
Shift+3 打开或关闭显示曲面模式。
Esc 取消当前模式/操作。
A 显示所有块体。
Control+A 编辑 —> 全选会根据当前种子选择的类型，选择所有体点、棱边上的控制点、棱边、面或块体。
B 将面选择转换为块体选择。
C 进入控制点模式。
Control+C 编辑 —> 复制将所选块体从当前集合复制到剪贴板。
Control+Shift+C 编辑 —> 复制信息会复制“信息”控件组中的文本，并将其显示在一个小窗口中。
D 添加一个块体。
F1 显示块体构建窗格的帮助。
Shift+L 隐藏所选块体。
Control+Alt+L 缩放至所选对象。
Control+Shift+L 仅显示所选块体。
P 在平行投影和透视渲染模式之间切换。
S 在表面选择和深部选择之间切换。
T 拆分一个块体。
Control+V 编辑 —> 粘贴将剪贴板中的块体复制到当前集合中。
W 切换几何数据集中线框的可见性。
Control+X 编辑 —> 剪切将所选块体从集合中移除并放入剪贴板。
Control+Z 编辑 —> 撤销撤销上一条命令。
