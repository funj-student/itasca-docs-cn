隐藏块体

隐藏块体工具按钮（）使鼠标进入一种模式，在该模式下单击哪个块体就会隐藏哪个块体。

另一种方式是使用选择模式（）下的上下文菜单。使用它可以：

  • 右键单击未选中的块体并选择隐藏块体命令；或
  • 右键单击选中的块体（或多个选中块体之一）并选择隐藏所选块体命令。 （无论选中的是面还是块体，隐藏块体命令都有效。）

隐藏块体模式对于深入查看模型内部可能更有用，而隐藏块体命令对于隐藏模型表面上一定范围的块体可能更有用。不过，该命令也可以与深部选择（deep selection）配合使用。

分组

上下文菜单中还有按分组隐藏的命令。当您右键单击已指定分组的块体时，上下文菜单中将包含名为“隐藏分组中的块体：<name>”的命令，其中 <name> 会替换为实际的分组名称。

当您右键单击未指定分组的块体时，上下文菜单中将有“隐藏未指定分组的块体”命令，该命令将隐藏所有未指定分组的块体。

高亮显示的分组

高亮分组工具按钮（）下有一个名为“仅显示高亮显示的块体”的菜单命令。该命令将使处于高亮分组中的所有块体可见，并隐藏未高亮分组中的所有块体。

未选中的块体

单击标有“仅显示所选块体”的工具按钮（）将隐藏所有未被选中的块体。

坏块

单击标有“显示坏块”的工具按钮（）将隐藏足够多的块体，以便您能够从当前视点看到坏块。
