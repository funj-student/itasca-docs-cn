building-blocks set geometry 命令

语法

building-blocks set geometry keyword

将几何集与当前集合关联。可以为当前块体集合添加、移除或清除要使用的几何集。

几何集可与面、棱边和点对象（在某些情况下还包括块体对象；例如见 building-blocks block snapon 或 building-blocks face drape）可用的“snapon”和“drape”命令配合使用。

add s （添加）

添加名为 s 的几何集，以与当前块体集合关联。

clear

清除与当前块体集合关联的几何集列表。

remove s

从与当前块体集合关联的几何集列表中移除名为 s 的几何集。
