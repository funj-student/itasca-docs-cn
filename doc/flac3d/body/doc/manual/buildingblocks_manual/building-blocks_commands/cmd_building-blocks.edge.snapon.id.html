building-blocks edge snapon id 命令

语法

building-blocks edge snapon id i set s keyword <control-point b > <range>

主要关键字：

边（edge）（棱边） 点（point）（点） 多边形（polygon）（多边形）

将棱边捕捉到几何集。如果提供了 <范围（range）>，则对其中棱边的点进行平移。如果未提供，则平移所有点。

平移矢量的定义方式为：从当前块体集合中 :lkwd`id` 为 i 的点，指向几何set s 上的目标点。

几何集上的目标点由 keyword 指定。 对于带控制点的棱边，<control-point b> 选项指示当棱边上的点只有一个被移动时，棱边上的控制点是否应随之移动。对于带控制点的面，该选项指示当面的点并非全部被移动时，面上的控制点应移动到何处。默认值为 真值（true）。

edge id i <f >

目标点位于几何集中 ID 为 i 的棱边上。棱边上的确切位置由浮点数参数 f 定义。 如果 f = 0.0，则目标点为该棱边的第一个（起点）点；如果 f = 1.0，则目标点为该棱边的第二个（终点）点。 默认值为 f = 0.5（棱边中点）。

point id i

目标点为几何集中 ID 为 i 的点。

polygon id i <(f1, f2 )> （多边形局部坐标）

目标点位于几何集中 ID 为 i 的多边形上。多边形上的确切点由两个局部坐标（f1, f2）定义，其定义方式使得 (0.0,0.0) 对应多边形的形心。默认情况下，（f1, f2）初始总是设置为对应多边形的形心。
