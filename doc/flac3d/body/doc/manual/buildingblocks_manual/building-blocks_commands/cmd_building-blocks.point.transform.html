building-blocks point transform 命令

语法

building-blocks point transform <origin v_o > keyword <control-point b > <range> （点变换）

主要关键字：

reflect（镜像） 旋转（rotate）（旋转） 比例（scale）（缩放） 平移（translate）（平移）

变换点。如果未指定 <范围（range）>，则对所有点进行变换。

对于需要原点的那些选项（rotate、reflect 和 scale），可以提供一个可选的 origin 来指定该操作的原点。

对于带控制点的棱边，<control-point b> 选项指示当棱边上的点只有一个被移动时，棱边上的控制点是否应随之移动。对于带控制点的面，该选项指示当面的点并非全部被移动时，面上的控制点应移动到何处。默认值为 真值（true）。该选项对 reflect 关键字无效。

reflect keyword

关于某一平面进行镜像变换。

dip f1 dip-direction f2

指定由倾角 f1 和倾向 f2 定义的镜像平面。角度以度为单位。

plane v_1 v_2 v_3 （由三点定义的平面）

指定由三个点 v_1 v_2 v_3 定义的镜像平面。

rotate direction v angle f

按角度 f（单位为度）执行旋转，旋转轴经过坐标原点、方向为 v。

scale v （缩放）

通过分别在 \(x\)、\(y\) 和 \(z\) 方向上以 v 的系数增大或缩小各点到origin的距离，来缩放点的位置。

translate v

执行平移——将 v 加到待变换面的每个坐标点上。
