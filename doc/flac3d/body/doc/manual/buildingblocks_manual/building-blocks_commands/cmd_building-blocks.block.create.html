building-blocks block create 命令

语法

building-blocks block create keyword

主要关键字：

由面生成（from-faces）（由面创建） 六面体（hexahedron）（六面体） tetrahedron（四面体） 楔形体（wedge）（楔形体）

创建一个或多个块体。

from-faces <distance f > range（由面创建块体，距离 f，范围）

创建附着到由 范围（range） 所指定各面的块体。此处所有面都必须是外部面——每个面仅附着于一个块体。新块体将沿平均面法向从这些面“挤出”。挤出距离由 f 定义。如果未提供 f，则默认距离将与所给面所附着的所有块体中某个块体的最大对角线范围相关。

hexahedron <by-points v1 v2 v3 v4 v5 v6 v7 v8 > <group s <slot s >>

创建六面体块体。如果存在 by-points，其后必须跟随定义该块体的点（六面体需要八个点）。可选关键字 group 和 slot 将创建的块体指定到指定的分组和槽位。

指定点时，必须按正确的顺序。例如，如果 cp 是块体的中心点，hL 是块体棱边长度的一半，则应按以下顺序指定点：
  • v1(cp.x - hL, cp.y + hL, cp.z + hL)（角点 1）
  • v2(cp.x + hL, cp.y + hL, cp.z + hL)（角点 2）
  • v3(cp.x + hL, cp.y + hL, cp.z - hL)（角点 3）
  • v4(cp.x - hL, cp.y + hL, cp.z - hL)（角点 4）
  • v5(cp.x - hL, cp.y - hL, cp.z + hL)（角点 5）
  • v6(cp.x + hL, cp.y - hL, cp.z + hL)（角点 6）
  • v7(cp.x + hL, cp.y - hL, cp.z - hL)（角点 7）
  • v8(cp.x - hL, cp.y - hL, cp.z - hL)（角点 8）
tetrahedron <by-points v1 v2 v3 v4 > <group s <slot s >>

创建四面体块体。如果存在 by-points，其后必须跟随定义该块体的点（四面体需要四个点）。可选关键字 group 和 slot 将创建的块体指定到指定的分组和槽位。

指定点时，必须按正确的顺序。例如，对于一条棱边对齐 X 轴的四面体，如果 cp 是块体的中心点，hL 是块体棱边长度的一半，而 sL（支撑杆长度）用于指定未与坐标轴对齐的棱边长度（sL = 棱边长度 * sqrt(.75)）：
  • v1(cp.x - hL, cp.y - sL / 2, cp.z - sL / 2)（角点 1）
  • v2(cp.x + hL, cp.y - sL / 2, cp.z - sL / 2)（角点 2）
  • v3(cp.x, cp.y + sL / 2, cp.z - sL / 2)（角点 3）
  • v4(cp.x, cp.y, cp.z + sL / 2)（顶点 4）
wedge <by-points v1 v2 v3 v4 v5 v6 > <group s <slot s >>

创建楔形块体。如果存在 by-points，其后必须跟随定义该块体的点（楔形体需要六个点）。可选关键字 group 和 slot 将创建的块体指定到指定的分组和槽位。

指定点时，必须按正确的顺序。例如，如果 cp 是块体的中心点，hL 是块体棱边长度的一半，而 thL 是棱边长度的三分之一：
  • v1(cp.x - hL, cp.y - hL, cp.z - thL)
  • v2(cp.x + hL, cp.y - hL, cp.z - thL)
  • v3(cp.x, cp.y - hL, cp.z - thL + edgeLength * sqrt(.75))
  • v4(cp.x - hL, cp.y + hL, cp.z - thL)
  • v5(cp.x + hL, cp.y + hL, cp.z - thL)
  • v6(cp.x, + cp.y + hL, cp.z - thL + edgeLength * sqrt(.75))
