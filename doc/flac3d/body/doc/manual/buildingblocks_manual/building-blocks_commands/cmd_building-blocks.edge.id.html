building-blocks edge id 命令

语法

building-blocks edge id i keyword

主要关键字：

控制点（control-point）（控制点） ratio（比率） 比率隔离（ratio-isolate）（比率隔离） size（尺寸） type（类型）

修改棱边的属性。在当前块体集合中，将修改 ID 为 i 的棱边。

control-point keyword

修改该棱边的控制点。

add v （添加矢量）

在由矢量 v 定义的位置添加控制点。位置 v 必须在容差范围内位于该棱边上（见 building-blocks set tolerance）。

delete i

从棱边中删除由索引 i 定义的控制点。索引 i 是从 1 开始的正整数。

move v index i

将由索引 i 定义的控制点移动到由矢量 v 定义的新位置。

rotate origin v_1 direction v_2 angle f indices i1 <i2 > <i3 > ... （按索引旋转控制点）

围绕由 origin 点 v_1 和 direction 矢量 v_2 定义的旋转轴，按旋转角度 f（以度为单位）旋转由 indices 定义的棱边控制点。

translate v indices i1 <i2 > <i3 > ...

通过为每个位置加上 v，平移由 indices 标识的控制点。

ratio f

为棱边上的网格单元指定比率尺寸参数 f。比率参数 f 是必须介于 0.1 和 10.0 之间的浮点数。当根据块体生成网格单元时，比率定义沿块体棱边的相对网格单元分布。每个网格单元的尺寸将是前一个网格单元长度的 f 倍。默认值为 1.0（均匀网格单元——长度相同）。

每当更改某条棱边的 ratio 时，更改都会传播到所有与面相连的相对棱边。 如果将 ratio-isolate 设置为 真值（true），则更改将不会从该棱边向外传播；该标志的默认设置为 假值（false）（表示比率设置会传播）。

ratio-isolate b

设置一个标志，以隔离棱边上的 ratio 或 factor 赋值。如果为 真值（true），则比率/系数赋值不会传播到所有与面相连的相对棱边。此设置默认值为 假值（false）。

size i

指定棱边上的网格单元数。i 的值必须为正（最大 1000）。默认值为 3。 当根据块体集合生成网格单元时，附着到该棱边的所有块体都将沿该棱边所定义的方向具有 i 个网格单元。

每当更改某条边的 size 时，更改会传播到与面相连的对边。

type keyword

指定棱边的曲线类型。

arc （圆弧）

指定圆弧棱边。圆弧只能有一个控制点。

spline （样条曲线）

指定样条曲线棱边。

polyline

指定多段线边（这是默认的 type）。
