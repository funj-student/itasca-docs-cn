building-blocks block export 命令

语法

building-blocks block export keyword <range>

导出块体。如果未提供 <范围（range）>，则将导出所有块体。

to-file s

将块体导出到名为 s 的文件。

to-set s <offset v >

将块体导出到名为 s 的块体集合。如果提供了可选的 <offset v>，则在目标集合中所有坐标都将按该矢量平移。

to-geometry-set s

将块体导出到名为 s 的几何集。它仅将所给块体的“外部”面创建为一组多边形（四边形或三角形）。
