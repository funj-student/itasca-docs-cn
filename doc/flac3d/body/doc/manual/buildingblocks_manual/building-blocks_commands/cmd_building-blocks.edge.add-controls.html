building-blocks edge add-controls 命令

语法

building-blocks edge add-controls keyword <range>

向棱边添加控制点。如果未提供 <范围（range）>，则在当前块体集合中的所有棱边上添加控制点。

i

为每条棱边精确添加 i 个控制点（i 必须是不大于 20 的正整数）。添加的控制点将均匀分布。

use-size

添加与每条棱边上网格单元数量相同数量的控制点（见 building-blocks edge size）。
