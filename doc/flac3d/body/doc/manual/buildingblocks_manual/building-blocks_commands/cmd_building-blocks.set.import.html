building-blocks set import 命令

语法

building-blocks set import keyword

导入块体集合。

s1 <set s2 > <v >

从文件 s1 导入块体。该文件必须具有“.f3bset”、“.f3grid”或“.flac3d”扩展名之一（并且是该类型的有效文件）。目标块体集合为 s2。如果未提供 s2，则创建一个新集合，并根据文件名 s1 为其命名。当提供 <v> 时，导入块体所有点的坐标都将按该矢量平移。

extruder <to-set s > <v >

从 挤出窗格 中的当前集合导入块体。如果使用 to-set s 选项，则目标为名为 s 的块体集合。如果未使用，则目标为当前块体集合。当提供 <v> 时，导入块体所有点的坐标都将按该矢量平移。

注意

如果已存在与导入集合同名的集合，则将删除并替换它。
