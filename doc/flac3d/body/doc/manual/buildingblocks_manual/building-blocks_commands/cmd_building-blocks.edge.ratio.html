building-blocks edge ratio 命令

语法

building-blocks edge ratio f <range>

对棱边上的网格单元施加尺寸比率。如果提供了范围，则该比率应用于当前 <范围（range）> 中的棱边；如果未提供，则应用于所有棱边。比率 f 必须介于 0.1 和 10.0 之间（默认值为 1.0）。

当根据块体生成网格单元时，比率（类似于系数，见 building-blocks edge factor）定义沿块体棱边的相对网格单元分布。每个网格单元的尺寸将是前一个网格单元长度的 f 倍。默认值为 1.0（均匀网格单元——长度相同）。

当更改某条棱边的比率时，更改将传播到所有与面相连的相对棱边。如果将 building-blocks edge ratio-isolate 设置为 真值（true），则更改将不会从该棱边向外传播；该标志的默认设置为 假值（false）。
