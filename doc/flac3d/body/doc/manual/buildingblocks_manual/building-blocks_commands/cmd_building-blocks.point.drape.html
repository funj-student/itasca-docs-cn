building-blocks point drape 命令

语法

building-blocks point drape keyword <novalidate> <range>

将点移动到外部几何集上。要移动的点由 <范围（range）> 定义。每个点的移动沿由 keyword 定义的束线进行，直到它与外部几何集相交。<novalidate> 选项将跳过对作为披覆操作一部分被移动的所有块体的校验。

inwards v

将束线从每个点延伸至焦点 v。

outwards v

将束线从焦点 v 延伸至每个点。

direction v

将束线设置为恒定方向矢量 v。
