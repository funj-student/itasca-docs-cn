building-blocks face id 命令

语法

building-blocks face id i keyword

主要关键字：

控制点（control-point）（控制点） type（类型）

修改面的属性。在当前块体集合中，将修改 ID 为 i 的面。

control-point keyword

修改该面的控制点。

add i1 i2

添加尺寸为 i1 X i2 的面控制点网格，该网格表示面曲率的双三次样条插值。如果该面已有控制点，则替换该网格。非负参数 i1 和 i2 可以是 (0,2,3,..,20)。如果两者都为 0，则移除控制点。

delete

从该面删除控制点网格。

move v index (i1, i2 ) （移动控制点）

将控制点网格上由一对索引（i1, i2）定义的控制点移动到由矢量 v 定义的新位置。

rotate origin v_1 direction v_2 angle f indices (i1, i2 ) <(i3, i4 )> ... （按索引旋转控制点）

围绕由 origin 点 v_1 和 direction 矢量 v_2 定义的旋转轴，按旋转角度 f（以度为单位）旋转由 indices 定义的面控制点。

translate v indices (i1, i2 ) <(i3, i4 )> ... （平移控制点）

通过为每个位置加上 v，平移由 indices 标识的控制点。

type keyword

指定面的曲线类型。可以是无曲线或双三次样条曲线。

non-curved

指定无曲线面。

bi-cubic-spline

指定双三次样条曲面。
