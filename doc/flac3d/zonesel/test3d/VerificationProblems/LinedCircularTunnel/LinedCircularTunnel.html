各向异性应力弹性介质中的圆形衬砌隧道

问题描述

注意

要在 FLAC3D 中查看此工程，请使用菜单命令 帮助 ‣ 示例…。选择“VerificationProblems/ LinedCircularTunnel”，再选择“LinedCircularTunnel.f3prj”即可加载。所使用的数据文件（data files）在本示例末尾给出。其余数据文件可在该工程中找到。

半径 5 m 的圆形隧道位于 30 m 深处的软弹性土体中（\(E\) = 48 MPa，\(\nu\) = 0.34，\(\rho\) = 2000 kg/m3）。地应力为竖向 600 kPa、水平 300 kPa。隧道由 125 mm 厚的喷射混凝土衬砌支护（\(E=25 GPa\)，\(\nu=0.15\)）。假定支护与开挖同时施作，且处于预先存在的各向异性双向应力场中。在平面应变条件下，针对地层-支护接触面的两种极限情况——无滑移（无相对剪切位移）和完全滑移（不传递剪应力）——计算支护位移与内力（以轴力和弯矩表示）以及接触面接触应力。将这些计算值与 Einstein 和 Schwartz（1979）的解析解进行比较。

解析解

解析解（Einstein 和 Schwartz，1979）采用 图 1（Figure 1） 中的符号表示。支护位移包括径向分量 \(u_s\) 和切向分量 \(v_s\)。内力包括轴力 \(T\) 和弯矩 \(M\)。接触面接触应力包括法向分量 \(\sigma_R\) 和剪切分量 \(\tau_{R\theta}\)。

图 1：解析解的符号约定：(a) 地层介质；(b) 隧道衬砌；(c) 衬砌内力的正方向。

无滑移解——对于无滑移解，接触面边界条件为地层与支护之间不发生相对剪切位移。无滑移解由以下公式给出：

\[\begin{split}\begin{split} u_s &= {PR(1 + \nu) \over E} \biggl\{ {1\over2}(1 + K)a^*_0 + {1\over2}(1 - K)\left[4(1 - \nu)b^*_2 - 2a^*_2 \right]\cos 2\theta \biggr\} \\ v_s &= {PR(1 + \nu) \over E} \biggl\{ -(1 - K)\left[a^*_2 + (1 - 2\nu) b^*_2 \right]\sin 2\theta \biggr\} \\ T &= {P R \over 2} \biggl\{ (1 + K)(1 - a^*_0) + (1 - K)\left[1 + 2a^*_2 \right]\cos 2\theta \biggr\} \\ M &= {P R^2 \over 2} \biggl\{ {1\over2}(1 - K)\left[1 - 2a^*_2 + 2b^*_2 \right]\cos 2\theta \biggr\} \\ \sigma_R &= {P \over 2} \biggl\{ (1 + K)(1 - a^*_0) - (1 - K)\left[1 - 6a^*_2 + 4b^*_2 \right]\cos 2\theta \biggr\} \\ \tau_{R\theta} &= {P \over 2} \biggl\{ (1 - K)\left[1 + 6a^*_2 - 2b^*_2 \right]\sin 2\theta \biggr\} \end{split}\end{split}\]
其中： \(\theta\) = 角位置（相对于水平方向逆时针量取）；
  \(R\) = 隧道半径；
  \(P\) = 竖向应力；
  \(K\) = 水平与竖向应力之比；
  \(E\) = 地层的杨氏模量；
  \(\nu\) = 地层的泊松比；以及
  \(a^*_0,a^*_2,b^*_2\) = 无量纲系数（见下面的公式）。
\[\begin{split}\begin{split} a^*_0 &= { C^* F^* (1 - \nu) \over C^* + F^* + C^* F^* (1 - \nu)} \\ a^*_2 &= \beta b^*_2 \\ b^*_2 &= { C^* (1 - \nu) \over 2\bigl[C^* (1 - \nu) + 4\nu - 6\beta - 3\beta C^*(1 - \nu) \bigr]} \\ \beta &= { (6 + F^*) C^* (1 - \nu) + 2F^* \nu \over 3F^* + 3C^* + 2C^* F^* (1 - \nu)} \end{split}\end{split}\]
其中： \(C^*\), \(F^*\) = 分别为压缩比和柔度比（见随后两个公式）。
(1)\[\begin{split}\begin{split} C^* &= { E R (1 - \nu_s^2) \over E_s A_s (1 - \nu^2)} \\ F^* &= { E R^3 (1 - \nu_s^2) \over E_s I_s (1 - \nu^2)} \end{split}\end{split}\]
其中： \(E_s\) = 支护的杨氏模量；
  \(\nu_s\) = 支护的泊松比；
  \(A_s\) = 单位隧道长度上支护的平均横截面积
      （对于厚度恒为 \(t\)、\(A_s = t\) 的支护）；以及
  \(I_s\) = 单位隧道长度上支护的惯性矩
      （对于厚度恒为 \(t\)、\(I_s = t^3/12\) 的支护）。

完全滑移解——对于完全滑移解，接触面边界条件为地层与支护之间不传递剪应力。完全滑移解由以下公式给出：

\[ \begin{align}\begin{aligned}\begin{split}\begin{split} u_s &= {PR(1 + \nu) \over E} \biggl\{ {1\over2}(1 + K)a^*_0 - (1 - K)\left[(5 - 6\nu)a^*_2 - (1 - \nu) \right]\cos 2\theta \biggr\} \\ v_s &= {PR(1 + \nu) \over E} \biggl\{ {1\over2}(1 - K)\left[(5 - 6\nu)a^*_2 - (1 - \nu) \right]\sin 2\theta \biggr\} \\ \\\end{split}\\\begin{split} T &= {P R \over 2} \biggl\{ (1 + K)(1 - a^*_0) + (1 + K)\left[1 - 2a^*_2 \right]\cos 2\theta \biggr\} \\ M &= {P R^2 \over 2} \biggl\{ (1 - K)\left[1 - 2a^*_2 \right]\cos 2\theta \biggr\} \\ \\\end{split}\\\begin{split} \sigma_R &= {P \over 2} \biggl\{ (1 + K)(1 - a^*_0) - (1 - K)\left[3 - 6a^*_2 \right]\cos 2\theta \biggr\} \\ \tau_{R\theta} &= 0 \end{split}\end{split}\end{aligned}\end{align} \]
其中： \(\theta\) = 角位置（相对于水平方向逆时针量取）；
  \(R\) = 隧道半径；
  \(P\) = 竖向应力；
  \(K\) = 水平与竖向应力之比；
  \(E\) = 地层的杨氏模量；
  \(\nu\) = 地层的泊松比；以及
  \(a^*_0\), \(a^*_2\) = 无量纲系数（见随后的公式）。
\[\begin{split}\begin{split} a^*_0 &= { C^* F^* (1 - \nu) \over C^* + F^* + C^* F^* (1 - \nu)} \\ a^*_2 &= { (F^* + 6)(1 - \nu) \over 2F^* (1 - \nu) + 6(5 - 6\nu)} \end{split}\end{split}\]
其中： \(C^*\), \(F^*\) = 分别为压缩比和柔度比（见上文公式 (1)）。

FLAC3D Model

该问题用解析解中的以下参数来描述：

几何  
隧道半径（\(R\)） 5 m
地应力  
竖向应力（\(P\)） 600 kPa
水平与竖向应力之比（\(K\)） 0.5
（\(\sigma_{xx}=-300\) kPa；\(\sigma_{zz}=-600\) kPa）  
地层属性  
杨氏模量（\(E\)） 48 MPa
泊松比（\(\nu\)） 0.34
（剪切模量 = 17.91 MPa；体积模量 = 50 MPa）  
线性属性  
杨氏模量（\(E_s\)） 25 GPa
泊松比（\(\nu_s\)） 0.15
厚度（\(t\)） 125 mm

FLAC3D 模型模拟无限弹性地层中圆形隧道的薄片，该地层具有预先存在的各向异性双轴应力场，并处于平面应变条件下。FLAC3D 模型的几何形状见 图 2（Figure 2）。远场边界设于距隧道半径 20 倍处，以近似无限边界。地应力在所有网格单元中设置，同时也作为荷载施加在远场边界上。通过在 \(y\) 方向设置薄片材料并在两个面上施加对称边界条件来实现平面应变条件。在 \(x=0\) 和 \(z=0\) 平面也施加对称边界条件。对于网格点，这要求保持垂直于该平面的位移为零。对于节点，这要求保持垂直于该平面的位移为零，并保持绕位于该平面内的两个轴的转角为零。（通过重新对齐并固定相应的节点局部坐标系并指定适当的速度固定条件来施加相应的节点条件——该过程的说明见 推进式衬砌隧道（Advancing Lined Tunnel）。）

FLAC3D 网格在 \(y\) 方向仅包含一层网格单元，且随远离隧道而逐渐变粗（见 图 3（Figure 3））。模型沿隧道边界的分辨率为 24 个网格单元。具有交叉网格图案的衬砌结构单元（选择该网格图案的原因见 衬砌加强梁（Liner-Reinforced Beam））附着于沿隧道边界的网格单元面上（见 图 4（Figure 4））。衬砌-网格单元接触面刚度（\(k_n\) 和 \(k_s\)）采用 此方程（this equation）（见衬砌性质）取值并将该值增大 100 倍，正如该方程之后的正文所建议的。（下文将确认我们的系统满足接触面变形很小的准则。）

结果与讨论——定性评估

我们通过绘制隧道拱顶和起拱线处网格点与节点的位移（见图 5（Figure 5）），确认接触面变形相对于网格单元变形很小（从而确认弹性接触面刚度 \(k_n\) 和 \(k_s\) 足够大）。网格点与节点之间的相对位移相比网格点位移很小。

图 5：无滑移情况下隧道拱顶（Gp 1873、Nd 50）和拱腰（Gp 1、Nd 1）处网格点与节点的位移。

如果在无支护条件下运行模型（即删除衬砌单元），则隧道拱顶和起拱线均向内移动（见图 6（Figure 6））。当包含支护时，隧道拱顶仍向内移动，但隧道起拱线向外移动（见图 7（Figure 7）），因为支护抵抗了地层的向内移动。如果允许衬砌在支护-地层接触面上滑动（将 coupling-cohesion-shear 的衬砌性质设为零），则衬砌与地层之间会发生相对剪切运动（见图 8（Figure 8））。

图 7：衬砌和地层的位移场（无滑动）。

无滑移和完全滑移两种情况下衬砌中的轴力 \(T\) 和弯矩 \(M\) 如图 9（Figure 9）至图 12（Figure 12）所示。当允许衬砌滑动时，轴力变得更均匀，弯矩略有增大。我们定义衬砌表面坐标系，其 \(x\) 轴沿隧道轴线（全局 \(y\) 方向），其 \(z\) 轴垂直于壳单元中面（指向内侧）。这对应于应力恢复过程中的 surface = (0, 1, 0) 方向。（需要指定表面坐标系。详见 应力恢复过程（Stress Recovery Procedure）。）按该坐标系，轴力对应于薄膜应力合力 \(N_y\)，弯矩对应于弯曲应力合力 \(M_y\)。在这些图中，衬砌的方位使得从左到右对应于闭合形式解中的角位置 \(\theta\) 从零变化到九十度。请注意，这些 \(N_y\) 和 \(M_y\) 的取值与解析解中的 \(T\) 和 \(M\) 取值符号相反。（正的 \(N_y\) 使壳单元伸长，正的 \(M_y\) 在壳单元由表面坐标系正 \(z\) 方向所定义一侧的外缘纤维处产生正应力。）

无滑动和完全滑动两种情形的接触面接触应力 \(\sigma_R\) 和 \(\tau_{R\theta}\) 见图 13（Figure 13） 至图 16（Figure 16）。这些值由连接衬砌节点与网格单元的法向和切向耦合弹簧获得。正法向应力表示分离，该约定与解析解的约定相反。所绘的剪应力仅表示大小；方向可通过 FISH 函数 衬砌单元法向耦合弹簧加载方向（struct.liner.normal.dir） 和 衬砌单元剪切耦合弹簧加载方向（struct.liner.shear.dir） 打印或获取。

无滑动和完全滑动两种工况下，支护位移、内力以及接触面接触应力与解析解的定量比较见图 17（Figure 17）至图 25（Figure 25）。FISH 函数从 FLAC3D 模型中提取所需数值，并与解析值进行比较。通过将 “no_slip”变量（no _slip） FISH 变量分别设为 1 或 0，即可采用无滑动或完全滑动的解析解。支护位移（\(u_s\) 和 \(v_s\)）采用 结构节点全局位移（struct.node.disp.global） 函数在节点处采样。内力（\(T\) 和 \(M\)）采用 壳单元节点应力合力（struct.shell.resultant） 函数在单元形心处采样。此外，接触面接触应力（\(\sigma_R\) 和 \(\tau_{R\theta}\)）采用 衬砌单元法向耦合弹簧应力（struct.liner.normal.stress） 和 衬砌单元剪切耦合弹簧应力（struct.liner.shear.stress） 函数，通过计算 linerSEL 节点处三个耦合弹簧的平均值，在 linerSEL 形心处采样。

对于无滑动和完全滑动两种情形，计算结果与解析解吻合良好。支护位移与解析解一致，在隧道拱顶处最大偏差约为 2%。轴力与解析解一致，最大偏差约为 1.2%。在远离模型端部的位置（\(\theta\) 等于 0 和 90 度处），接触面接触应力与解析解一致。在端部位置存在约 10% 的误差（注意图 20（Figure 20） 和图 25（Figure 25） 中的离群点），这源于网格缺乏对称性。每个端部两个节点所分配的面积不相同，因为该面积是使用该节点的各单元面积三分之一的累加。在每个端部，一个节点的面积是另一个的两倍，这会影响应力计算，使结果不对称。请注意，这两个离群点界定了解析解，且其平均值等于解析解。

数据文件

LinedCircularTunnel.dat

model new
model large-strain off
fish automatic-create off
[global t = 'Lined Circular Tunnel in an Elastic Medium']
[t += ' with Anisotropic Stresses']
model title [t]
; 创建岩土体，即网格单元。
zone create radial-cylinder size 1 1 24 38 rat 1 1 1 1.087 ...
                            point 1 (100,0,0) point 2 (0,0.4,0) ...
                            point 3 (0,0,100) dimension 5 5 5 5
; 材料模型和参数
zone cmodel assign elastic
zone property bulk 5e7 shear 1.791e7
; 为模型边界命名
zone face skin
; 创建支护，即衬砌结构单元。
struct liner create by-zone-face range group 'West1'
struct liner property isotropic (2.5e10, 0.15) thickness 0.125 ...
                      coupling-stiffness-normal 2.0763e10 ...
                      coupling-stiffness-shear 2.0763e10 ...
                      coupling-cohesion-shear 1e20
; 在整个网格中赋予原位应力。
zone initialize stress xx -3e5 yy -3e5 zz -6e5
; 指定边界条件。
  ; 对于网格点，采用以下对称条件。
zone face apply velocity-normal 0.0 range group 'West2' or 'Bottom'
zone face apply velocity-normal 0.0 range group 'North' or 'South'
  ; 在远场边界施加应力
zone face apply stress-normal -3e5 range group 'East'
zone face apply stress-normal -6e5 range group 'Top'
; 对于结构节点，采用以下对称条件。
struct node system-local x (1,0,0) y (0,-1,0)    ...
            range position-x 0   ; x=0 平面
struct node fix system-local                     ...
            range position-x 0
struct node fix velocity-x rotation-y rotation-z ...
            range position-x 0
struct node system-local x (0,0,-1) y (0,-1,0)   ...
            range position-z 0   ; z=0 平面
struct node fix system-local                     ...
            range position-z 0
struct node fix velocity-x rotation-y rotation-z ...
            range position-z 0
struct node fix velocity-y rotation-x rotation-z ...
            range position-y 0   ; y=0 平面
struct node fix velocity-y rotation-x rotation-z ...
            range position-y 0.4 ; y=Ymax 平面
; 历史
model history mechanical ratio-local
zone history displacement-x position (5,0,0)        ; 隧道起拱线
zone history velocity-x     position (5,0,0)
struct node history displacement-x position (5,0,0)
struct node history velocity-x     position (5,0,0)
zone history displacement-z position (0,0,5)        ; 隧道拱顶
zone history velocity-z     position (0,0,5)
struct node history displacement-z position (0,0,5)
struct node history velocity-z     position (0,0,5)
history interval 10
;
model save 'starting'
; 无支护工况
struct liner delete
model solve ratio-local 1e-5
model title [t]
model save 'No Support'
; 允许滑移的工况
model restore 'starting'
struct liner property coupling-cohesion-shear 0
model solve ratio-local 1e-5
model title [t + " - Full Slip"]
model save 'Full Slip'
; 不允许滑移的工况
model restore 'starting'
model solve ratio-local 1e-5
model title [t + " - No Slip"]
model save 'No Slip'

program return
