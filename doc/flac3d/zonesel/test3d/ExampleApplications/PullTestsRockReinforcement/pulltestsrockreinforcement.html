全长黏结岩石加固拉拔试验的模拟

问题描述

注意

本示例的项目文件可在 FLAC3D 中查看/运行。[1] 该项目的主数据文件见本示例末尾（main data file）。

确定全长黏结岩石加固（例如注浆锚索、树脂注浆钢筋或岩石锚杆）性质最常用的方法是在现场对注浆加固的小段进行拉拔试验。通常将长 50 cm 或更长的段注浆锚固在钻孔中。这些段的端部通过安装在隧道表面的千斤顶牵引，并用筒夹楔块式锚具与锚索连接。将施加到加固体上的力和加固体的变形绘制成轴力-挠度曲线。由该曲线确定注浆黏结的峰值抗剪强度。几种锚索的半米长段拉拔试验结果如图 1（Figure 1） 所示。这些图以吨/米对以毫米计的变形表示。

图 1：黏结长度为 0.5 m、水灰比为 1/3 时各类锚索拉拔试验的现场结果。

在本示例应用中，使用 FLAC3D 模拟此类拉拔试验。使用 FLAC3D 中的结构单元模拟拉拔试验有两种不同方法：

  1. 锚索单元，其假定注浆体为弹塑性材料，具有围压相关性，但破坏后强度不丧失；以及
  2. 改进的桩单元，其考虑了围压变化、注浆体的应变软化行为以及加固体的断裂。

使用改进桩单元模拟加固体行为的另一个优点是可以考虑抗弯能力。当加固体受剪时需要这一行为，后文带拉伸断裂的拉拔试验（Pull-Test with Tensile Rupture）和岩石锚杆剪切试验（Shear Test on Rockbolts）中对此有描述。

以下示例的目的是演示这两种方法的使用及其能力。

方法 1：使用锚索单元模拟岩石加固

在以下各节中，使用锚索单元逻辑模拟拉拔试验。创建和查看锚索单元相关变量所需的命令见锚索命令（Cable Commands）。

无围压条件下的抗拔强度

首先考虑可忽略围压对加固体黏结抗剪强度影响的情形。必须从现场拉拔试验曲线中提取 FLAC3D 锚索-锚杆模型所需的锚索性质。当现场试验数据以单位长度力对变形表示时（如图 1（Figure 1） 所示），这很容易做到。假定锚索不发生屈服，则注浆体剪切刚度 grout-stiffness 的值就是该曲线的斜率，而极限黏结强度 grout-cohesion 则为单位长度上的峰值拉拔强度值。该假定可由以下事实证明：钢材通常在高于拉拔力所对应应力的应力下才屈服，如图 1（Figure 1） 所示。例如，对于直径为 15 mm、长度为 0.5 m 的典型锚索以及 1200 MPa 的（允许）屈服强度（在后续各节的 FLAC3D 模型中假定），最大屈服力为 212 kN。该值比图 1（Figure 1） 中注浆体破坏时的最高拉拔力 28 吨/米 × 0.5 = 140 kN 大约 50%。此外，在这些示例中，相对于注浆体的柔度，加固单元和岩石的柔度被忽略。

例如，此处所示的所有拉拔试验结果具有大致相同的加载斜率，因此对所有情况选取 grout-stiffness 的平均值：

\[{\hbox{grout\_stiffness}} \approx {{28\ {\hbox{tons/meter}}} \over {25 \times 10^{-3}{\hbox {meter}}}} = 1.12 \times 10^7\ {\hbox{N}\thinspace /\thinspace} {\hbox {m}}^2\]

该 grout-stiffness 值很低，表明该锚索的注浆质量相当差。典型的 grout-stiffness 值大约比该值高一个数量级或更多。

单根 15.2 mm 钢丝的 grout-cohesion 值就是以吨/米计的峰值抗剪阻力。在此情形下，grout-cohesion \(\approx\) 17.5 吨/米，即 17.5 × 104 N/m。为检验该 grout-cohesion 值是否合理，可以将其除以钢丝的近似表面积（假定黏结在注浆体/锚索界面处破坏）换算为注浆体抗剪强度。我们得到峰值抗剪强度为 3.66 MPa。该值应大致等于注浆体单轴抗压强度的二分之一，这表明要么注浆体质量很差，要么拉拔试验中允许锚索转动，从而导致注浆体抗剪强度值偏低。[2]

有围压条件下的抗拔强度

一般而言，锚索黏结抗剪强度将随作用在锚索上的有效压力（\(p\)‘）增大而增大。FLAC3D 中实现了一种线性规律，其中锚索黏结抗剪强度定义为常数（grout-cohesion）加上锚索上的有效压力乘以锚索周长（grout-permeter）再乘以摩擦角（grout-friction）的正切。在 FLAC3D 中通过给定锚索性质 grout-permeter 和 grout-friction 会自动激活这种压力相关性。请注意，在这种情况下，grout-cohesion 的输入数据必须对应于无围压条件下进行锚索拉拔试验时的黏结抗剪强度。摩擦角为 30°、初始围压为两个水平（即 \(p\)‘ = 2 和 4 MN/m2）时 15.2 mm 锚索拉拔试验的数值结果如图 7（Figure 7） 和图 8 所示。请将这些图与图 3（Figure 3） 进行比较。这些图表明破坏水平随初始围压增大而提高，说明锚索-岩石界面具有摩擦特性。15.2 mm 锚索有围压拉拔试验的结果是使用数据文件“Pull02.dat”和“Pull03.dat”得到的。

方法 2：使用改进桩单元模拟岩石加固

在以下各节中，使用 FLAC3D 中的改进桩单元逻辑模拟岩石加固。以下示例的目的是演示使用改进桩单元的建模流程。除演示模拟拉拔试验的功能外，本节还给出了与岩石锚杆剪切试验模拟相关的示例（见岩石锚杆剪切试验（Shear Test on Rockbolts）和带断裂的岩石锚杆剪切试验（Shear Test on Rockbolts with Rupture））。本节中的试验假定条件代表直径为 25 mm 的注浆锚杆，其注浆体性质与无围压条件下的抗拔强度（Pull-out Strength without Confinement）中定义的性质相同。

创建和查看改进单元相关变量所需的命令见桩命令（Pile Commands）。请注意，通过给定 设置桩单元锚杆标志属性命令（structure pile property rockbolt-flag） 开启（on） 命令可激活改进桩单元公式。

有围压条件下的拉拔试验

数据文件“Pulltest06.dat 数据文件（Pulltest06.dat）”展示了如何使用改进桩逻辑模拟有围压的拉拔试验。该模型与有围压条件下的抗拔强度（Pull-out Strength with Confinement）中讨论的模型等效，这次围压为 4 MN/m2。如剪切耦合弹簧的行为（Behavior of Shear Coupling Springs）中所述，改进桩逻辑中实现了一种线性规律，其中加固体抗剪强度定义为常数（coupling-cohesion-shear）加上加固体上的有效压力乘以加固体周长（perimeter）再乘以摩擦角（coupling-friction-shear）。在 FLAC3D 中通过给定加固体性质（perimeter）和（coupling-friction-shear）会自动激活这种压力相关性。

有围压条件下的拉拔试验——用户定义行为

本例演示使用 coupling-confining-table 选项，为垂直于锚杆轴线的主应力 \(σ_x\) 与 \(σ_y\) 不相等的情况，定义锚杆上围压的“平均”值 \(σ_c\)。

图 12（Figure 12） 显示了直径为 25 mm 的岩石锚杆情形下围压与偏应力关系数值计算得到的结果。图中横轴表示归一化偏应力，定义为

\[{ \sigma_x - \sigma_y } \over { \sigma_x + \sigma_y }\]

而纵轴表示归一化围压，

\[{ \sigma_c } \over { \sigma_x + \sigma_y }\]

该关系由 FLAC3D 中的拉拔试验模型得到，其中考虑了垂直于锚杆轴线的平面内不同偏应力值。平均围压 \(\sigma_c\) 通过测量将长度为 \(L\)、周长为 \(p\)、注浆摩擦角为 \(\phi\) 的锚杆拔出所需的力 \(F_p\) 并按以下表达式获得

\[\sigma_c = {{F_p} \over {p L \tan{\phi}}}\]

数据文件“Pulltest07.dat 数据文件（Pulltest07.dat）”创建的模型演示了 coupling-confining-table 选项的使用以及图 12（Figure 12） 所表示的关系。使用该数据文件获得的结果如图 13（Figure 13） 所示。在本示例中，垂直于岩石锚杆轴线的平面上的一个主应力为零。请注意，由于侧向应力为零，图 13（Figure 13） 中的抗拔阻力相比图 11（Figure 11） 大幅降低。

图 12：25 mm 岩石锚杆数值计算得到的归一化围压与归一化偏应力关系示例。

图 13：单根 25 mm 注浆锚杆情形下岩石锚杆拉拔力（N/m）与岩石锚杆轴向位移（m）的关系——侧向围压由图 12（Figure 12） 所表示的关系定义。

数据文件

Pull01.dat

; ==================================================================
;   注浆锚杆拉拔试验模拟
; ==================================================================
model new
model large-strain off
fish automatic-create off
[global t =  'Pull Test for Grouted Cable Anchor ']
[t += '(no external confinement, fric=0)']
model title [t]
; 创建单个岩块并设置其材料参数。
zone create brick size 4 7 4 point 1 (0.4,0,0) point 2 (0,0.7,0) ...
                             point 3 (0,0,0.4)
zone cmodel assign elastic
zone property bulk 5e9 shear 3e9
; 创建单根锚索并设置其相关参数
struct cable create by-line (0.2,0.0,0.2) (0.2,0.5,0.2) segments 10
struct cable property cross-sectional-area 181e-6 young 98.6e9 ...
                      yield-tension 0.232e6 grout-stiffness 1.12e7 ...
                      grout-cohesion 1.75e5 grout-friction 0.0 ...
                      grout-perimeter 7.85e-2
; 固定岩块自由端，并对锚索端部施加速度
zone face apply velocity-normal 0 range position-y 0
struct node fix velocity-x                    range position-y 0
struct node initialize velocity-x -1e-6 local range position-y 0
; 用于计算网格单元上反作用力的 FISH 函数
[global gplist = gp.list(gp.pos.y(::gp.list) < 0.05)]
fish define force
    return list.sum(gp.force.unbal.y(::gplist)) / 0.5
end
; 设置用于监测模型响应的历程
history interval 10
fish history name 'force' force
struct node history name 'disp' displacement-y component-id 1
; 施加速度以实现 2.0 cm 的总位移
model cycle 10000
model save 'pull-1-1'
model cycle 6500
model save 'pull-1-2'
model cycle 1000
model save 'pull-1-3'
model cycle 2500
model save 'pull-1-4'

;   注浆锚杆拉拔试验模拟
;     围压 2 MPa
