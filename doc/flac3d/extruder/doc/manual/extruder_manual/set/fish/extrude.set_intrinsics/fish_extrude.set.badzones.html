extrude.set.badzones

语法

b := extrude.set.badzones(sp<,bi>)（检查集合中是否存在几何不良的单元）

根据挤出器准则检查集合中是否有单元几何形状不良（仅对四边形单元进行检查）。如果集合中至少有一个不良四边形单元、其挤出为网格单元后可能导致“几何形状不良”错误，则返回 真值（true）。该函数检查二维四边形单元两个最严重的问题（在挤出窗格中）：单元非凸，或每个覆盖层中某个三角形子单元的面积 \(\le\) 整个单元面积的 10%。

返回值：b - 几何形状不良指示
参数：属性名（sp） - 集合指针 比奥系数（bi） - 指示是否应进行面积检查或忽略该检查
