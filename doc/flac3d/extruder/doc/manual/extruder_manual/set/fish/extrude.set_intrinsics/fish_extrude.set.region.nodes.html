extrude.set.region.nodes

语法

l := extrude.set.region.nodes(sp<,ib><,i>)（返回块体或集合中单元的节点位置列表）

获取二维矢量列表，这些矢量对应于 ID 为 蓝色强度分量（ib） 的块体内局部索引为 i 的单元的节点位置。索引 i 可从 1 变化到 挤出集合区域单元数量（extrude.set.region.element.num）。若未提供单元索引，则该函数返回块体内的所有节点。若未提供块体 ID，则该函数返回集合 属性名（sp） 内的所有节点。

返回值：

l - 节点位置列表
参数：

属性名（sp） - 挤出集合指针

蓝色强度分量（ib） - 块体 ID

i - 单元编号，满足 1 \(\le\) i \(\le\) 挤出集合区域单元数量（extrude.set.region.element.num）。
