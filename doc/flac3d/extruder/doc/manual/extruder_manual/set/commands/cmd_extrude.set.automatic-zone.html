automatic-zone 命令

语法

extrude set automatic-zone keyword

主要关键字：

direction 边（edge） size total（自动划分方向、边、尺寸与总数选项）

设置挤出集合的自动网格划分。

direction keyword

控制挤出的哪些部分被自动划分网格。若未指定，则保留最后一次指定的值（默认为 both）。

both

自动网格划分同时应用于二维构造数据和一维挤出线段数据。这是默认设置。

construction

自动网格划分仅应用于二维构造数据。

extrusion

自动网格划分仅应用于挤出线段数据。

edge f

自动网格划分将尽量使网格单元边的平均长度保持为值 f。若未提供，则使用先前的值。默认值为 1.0。

size i

自动网格划分将指定网格单元尺寸，使沿模型最大尺寸方向约有 i 个网格单元。 若未提供，则使用先前的值。默认值为 100。

total i （总数）

自动网格划分将指定网格单元尺寸，使所创建三维网格单元的总数约为（但不超过）i。
