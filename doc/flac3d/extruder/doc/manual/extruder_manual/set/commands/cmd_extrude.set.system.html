system 命令

语法

extrude set system keyword ...

主要关键字：

法向轴（normal-axis） 原点（origin） 无符号轴（u-axis） 变体轴（v-axis）（依次设置法向轴、原点、u 轴、v 轴）

设置坐标系。这些设置影响挤出对象坐标 (u,v,n) 如何映射到全局坐标（\(x,y,z\)）。

normal-axis v

设置法向轴 v（三维矢量）。这是挤出方向（垂直于二维局部 \(x\)、\(y\)）。

origin v

设置挤出变换的原点 v（三维矢量）。挤出时，二维挤出坐标 (0,0) 先映射到（\(x,y,z\)），然后旋转到 u,v,n 坐标系中。

u-axis v

设置 u 轴（三维矢量 v）。当模型挤出入三维时，该轴即为二维坐标系中 \(x\) 的方向。

v-axis v

设置 v 轴（三维矢量 v）。当模型挤出入三维时，该轴即为二维坐标系中 \(y\) 的方向。
