index 命令

语法

extrude segment index i keyword ...

主要关键字：

分组（group） 长度（length） 节点分组（node-group） position ratio size（依次为分组、长度、节点分组、位置、比率、网格单元数选项）

按 ID 修改线段。

group s1 <slot s2 >

将线段的分组名指定为 s1（若提供则使用槽位 s2，否则使用槽位 默认（Default））。

length f

设置线段长度 f。

node-group s1 <slot s2 >

将线段节点的分组名指定为 s1（若提供则使用槽位 s2，否则使用槽位 默认（Default））。

position f

设置线段位置。请注意，线段可能被分割、删除或延长。

ratio f

设置沿线段分布的网格单元尺寸比率 f。该设置以相对方式定义沿线段各段网格单元的尺寸，其中每个网格单元的尺寸将是前一个网格单元长度的 f 倍。默认值为 1.0（均匀网格单元——长度相同）。

size i

设置沿该线段的网格单元数 i（整数）。

注意

分组逻辑的用法在 分组（Groups） 主题中描述。
