命令

本页命令：c block、c 边（edge）、c 网格（mesh）、c 点（point）、c 分段（segment）、c set。

extrude block

块体是挤出集合（set）中的二维对象，由闭合边界及其内部的网格组成。块体的每条边界（外部或内部）必须至少包含 3 条相连的边（edges）（其中任意一条边由两个端点（points）和一个曲率类型定义）。

在挤出器中可创建两类块体：规则块体和不规则块体。规则块体是采用结构化网格的单连通三边或四边形多边形（三角形或四边形）。所有其他类型的块体均视为不规则块体，采用非结构化网格划分。不规则块体的示例包括：外边界上有 5 条或更多边的块体（可为凸或凹）、具有多重连通或多个边界的块体（例如包含嵌套块体的块体）、有边向内部突出的块体。

结构化和非结构化网格均由三角形和/或四边形单元组成。挤出时，网格的每个单元生成一个网格单元（六面体或楔形）。使用 单元生成从挤出器（zone generate from-extruder） 命令时，挤出集合（set）必须包含有效块体才能生成网格单元。

extrude edge

一条边主要由两个端点（points）及其曲率类型定义，曲率类型必须是以下之一：简单（直线）、折线、圆弧或样条。除简单类型外的其他类型还需由控制点进一步定义，控制点位于两端点之间并确定边的形状。

extrude mesh

可在挤出器中指定若干网格划分参数，以优化和微调非结构化网格。这些参数是全局参数，适用于挤出器中存在的所有集合。

extrude mesh gradation
extrude mesh list
extrude mesh mode
extrude mesh optimization
extrude mesh quad-weight
extrude mesh reset
extrude mesh shape-quality
extrude mesh target-size
extrude mesh type
  • gradation command
  • list command
  • mode command
  • optimization command
  • quad-weight command
  • reset command
  • shape-quality command
  • target-size command
  • type command

extrude point

挤出集合中的点通常是用于定义边的端点（两个端点之一）。它们不同于控制点：控制点位于边上各点的内部，用于塑造该边所形成的直线/曲线。

extrude point create
extrude point delete
extrude point group
extrude point id
extrude point list
extrude point transform

  • delete command
  • group command
  • id command
  • list command
  • transform command

extrude segment

挤出集合中挤出方向的长度和分块由线段确定。第三维的网格划分沿线段设置，类似于沿块体（blocks）的边（edges）定义网格划分的方式。

extrude segment add
extrude segment clear
extrude segment delete
extrude segment index
extrude segment list
extrude segment origin
  • add command
  • clear command
  • delete command
  • index command
  • list command
  • origin command

extrude set

挤出集合由用于生成 FLAC3D 网格单元的块体组成。一个模型可包含多个集合。在任何时刻，程序中有一个集合是当前活动集合。对整个集合的操作（块体验证、自动网格划分、删除等）通过 set 命令执行。

extrude set automatic-validate
extrude set automatic-zone
extrude set clear
extrude set delete
extrude set list
extrude set metadata
extrude set select
extrude set system
extrude set update-polygons
  • automatic-validate command
  • automatic-zone command
  • clear command
  • delete command
  • list command
  • metadata command
  • select command
  • system command
  • update-polygons command
