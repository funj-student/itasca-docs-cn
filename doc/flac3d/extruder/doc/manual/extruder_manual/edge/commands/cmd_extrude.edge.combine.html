combine 命令

语法

extrude edge combine keyword

主要关键字：

ID 标识（id） 容差（tolerance）

将多条边合并为单条边。

id i1 i2 i3 ...

将由指定 ID i1 i2 i3 … 的边合并为单条样条型边。程序会自动插入若干控制点，以最佳逼近原折线（由所指定的边组成）。只有两端各自连接不超过一条其他边的边才能合并。

tolerance f

指定新样条型边对原折线的逼近容差。容差 f 可在 0.001 至 0.999 之间变化，默认值为 0.1。容差值越小，在新生成的单条边上插入的控制点就越多。
