id 命令

语法

extrude edge id i <keyword ...>

主要关键字：

控制点（control-point） split 分组（group） ratio 比率隔离（ratio-isolate） size type（关键字）

按 ID 修改单条边。

control-point keyword
add <local> v2 <v2 ...>

在位置 v2（二维坐标矢量（\(x\)、\(y\)））处添加一个或多个控制点。若使用 local，则位置位于由该边定义的坐标系中，其中 \(x\) 从端点 1（0.0）到端点 2（1.0），而 \(y\) 垂直于该方向。

clear

移除所有控制点。

move i <local> v2

将索引为 i 的控制点移至位置 v2（二维坐标矢量（\(x\)、\(y\)））。若使用 local，则采用边的局部坐标系。见上文 add。

remove i <i ...>

移除一个或多个控制点。

split v2 <keyword>

在位置 v2（二维坐标矢量（\(x\)、\(y\)））处分割该边。如果未提供关键字“block”，或该边属于不规则块体，则该命令分割该边并删除该块体。

block

指定若该边属于规则块体，则分割将传播到所有相连的规则块体。

tolerance-merge f

指定容差 f，用作分割过程中合并点的容差。

group s1 <slot s2 > <remove>

将槽位 s2（若提供）中的分组名 s1 指定给该边。若给出 remove，则将该边从该分组/槽位中移除。slot 若未提供则为 默认（Default）。

ratio f

设置比率 f（介于 0.1 与 10.1 之间的数），用于沿边分布网格单元长度（每个网格单元的尺寸将是其前一个网格单元的 f 倍）。当 Ratio-Isolate 为 假值（false） 时，该设置会自动传播到规则块体的相关边上。

ratio-isolate b

该选项仅适用于构成规则（三边或四边形）块体的边。

设置控制比率传播的标志。当为 假值（false）（默认值）时比率设置传播。若设为 真值（true），则该边上的比率赋值不会传播到相关边。

size i

设置边上的网格单元数。这也会自动传播到规则块体的相关边。

type keyword

指定边的曲线类型。

arc （圆弧）
polyline
simple

这是默认类型（直线）。

spline （样条曲线）
