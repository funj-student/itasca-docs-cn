type 命令

语法

extrude mesh type keyword

主要关键字：

mixed unstructured

指定网格类型。默认情况下，三边和四边形规则块体使用结构化网格；该命令指定这些块体是否应使用非结构化网格。

mixed

对三边和四边形块体使用结构化网格，对所有其他块体使用非结构化网格。这是默认选项。

unstructured

对所有块体使用非结构化网格。如果使用该选项且网格模式（见 extrude mesh mode）设为 quad，则三角形块体仅用四边形划分（每条周长上的网格单元数应为偶数）。
