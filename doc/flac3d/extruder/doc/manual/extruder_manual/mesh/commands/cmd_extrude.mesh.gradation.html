gradation 命令

语法

extrude mesh gradation f

为非结构化网格划分器指定最大渐变率 f > 0。默认值为 0.5。

该参数控制网格单元尺寸从块体边界上指定的尺寸到块体内部由 target-size 定义的尺寸（见 extrude mesh target-size）之间的渐变。取值接近 0 时，网格单元尺寸的变化更平缓（更光滑）。
