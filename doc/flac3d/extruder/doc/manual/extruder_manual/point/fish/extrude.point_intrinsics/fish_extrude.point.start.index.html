extrude.point.start.index

语法

i := extrude.point.start.index(p)（返回该点在第一条相邻边内的局部索引）

获取点 n 在附着到该点的第一条边内的局部索引 i。这可结合 挤出点连接的首条边（extrude.point.start.edge）、挤出边下一条边（extrude.edge.next.edge） 和 挤出边下一条边的点索引（extrude.edge.next.index） 函数遍历附着到某节点的所有边。

返回值：i - 点索引，满足 1 \(\le\) i \(\le\) 2
参数：p - 点指针

几何节点在首条边中的局部索引（geom.node.start.index）
