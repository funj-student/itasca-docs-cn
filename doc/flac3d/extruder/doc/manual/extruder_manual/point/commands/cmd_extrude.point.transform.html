transform 命令

语法

extrude point transform keyword <range>

主要关键字：

合并容差命令（merge-tolerance） 原点（origin） 旋转（rotate） 比例（scale） 平移（translate） 控制点（control-point）（依次为合并容差、变换原点、旋转、缩放、平移、控制点选项）

变换点。几何变换可以是旋转、移动（平移）或缩放，或三者的任意组合。若为组合，则按以下顺序执行操作：scale rotate translate。scale 和 rotate 操作始终相对于 origin 进行。若未提供 <范围（range）>，则变换所有点。

merge-tolerance f <range>

设置合并容差。若提供，将用作合并点的容差。

origin v2

设置变换的原点（点中心）v2（二维矢量坐标）。

rotate f

设置旋转角度 f（单位为度）。

scale f1 <f2 >

缩放点；f1 = 沿 \(x\) 坐标的缩放系数，f2 = 沿 \(y\) 坐标的缩放系数。

translate v2

平移点。点按 v2（二维矢量坐标）移动。

control-point b

移动/冻结控制点。当为 真值（true）（默认值）时，控制点在其关联的点移动时随之移动。当为 假值（false） 时，控制点将被“冻结”。
