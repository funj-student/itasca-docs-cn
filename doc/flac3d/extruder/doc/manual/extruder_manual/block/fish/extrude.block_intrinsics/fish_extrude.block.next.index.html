extrude.block.next.index

语法

整数返回值（ir） := extrude.block.next.index(p,i)

获取与该边相连的下一个块体内某挤出边的局部索引 整数返回值（ir）（注意：同一条边在源块体 p 内的局部索引为 i）。这可用于通过 下一个挤出区块（extrude.block.next.block） 函数遍历与某条边相连的所有块体。

返回值：

整数返回值（ir） - 边索引
参数：

p - 源块体指针

i - 边索引

另请参见

相邻多边形的局部索引（geom.poly.next.index）
