id 命令

语法

extrude block id i keyword

主要关键字：

计算循环（cycle） 分组（group） 乘数（multiplier） split（关键字）

按 ID 修改单个块体。

cycle keyword

该命令仅适用于规则的三角形块体。

循环块体的边赋值，实际上以逆时针或顺时针方向旋转块体的方位。该命令用于改变将创建楔形网格单元的角部。

counter-clock-wise

逆时针循环。

clock-wise

顺时针循环。

group s1 <slot s2 > <remove>

将槽位 s2（若提供）中的分组名 s1 指定给该块体。若给出 remove，则将该块体从该分组/槽位中移除。slot 若未提供则为 默认（Default）。分组逻辑的用法在 分组（Groups） 主题中描述。

multiplier f

该命令仅适用于规则（三边或四边形）块体。

将网格单元乘数设为 f。

split <v2 > <tolerance-merge f >

该命令仅适用于规则（三边或四边形）块体。

在 v2（二维坐标矢量）处分割规则块体。若未提供位置，则块体将在形心处分割。若提供，tolerance-merge 指定分割过程中合并点的容差（即，当分割操作创建新块体时，距离在 tolerance-merge 以内的任意两点将自动合并为一点）。
