create 命令

语法

extrude block create keyword

主要关键字：

在（at） automatic 按边定义（by-edges） 按点（by-points）（关键字）

创建块体。

at f1 f2 <keyword>

由包围二维坐标 f1 、f2 的点的各边创建块体。

group s1 <slot s2 >

将所创建块体的分组名指定为 s1（若提供则使用槽位 s2，否则使用槽位 默认（Default））。

automatic <keyword> <range>

在范围内由预先存在的边创建规则和/或不规则块体。仅使用构成闭合多边形的边。如果未提供范围，则将由集合中所有存在的闭合多边形创建块体。

group s1 <slot s2 >

将所创建块体的分组名指定为 s1（若提供则使用槽位 s2，否则使用槽位 默认（Default））。

by-edges i1 i2 i3 ... <keyword>

由具有指定 ID i1 i2 i3 … 的边创建块体。边的顺序无关紧要。对于带内部边界的多边形，只需指定构成外边界的边。

group s1 <slot s2 >

将所创建块体的分组名指定为 s1（若提供则使用槽位 s2，否则使用槽位 默认（Default））。

by-points i1 i2 i3 ...

由具有指定 ID i1 i2 i3 … 的点创建块体。点的顺序无关紧要。点必须由边连接。对于带内部边界的多边形，只需指定外边界上的点。

group s1 <slot s2 >

将所创建块体的分组名指定为 s1（若提供则使用槽位 s2，否则使用槽位 默认（Default））。
