默认网格划分参数

挤出器中可对任何闭合（水密）多边形划分网格。结构化网格仅可用于单连通的三边或四边形多边形，而非结构化网格可应用于任何闭合多边形。以下选项控制网格的构建。

基本参数

仅创建非结构化网格

如果勾选该选项，则所有块体均使用非结构化网格，包括原本使用结构化网格划分的规则三边或四边形多边形。

当仅使用非结构化网格且勾选了网格模式（下一参数）时，三边多边形将仅用四边形划分（前提是每条周长上的网格单元数为偶数）。

非结构化网格中仅使用四边形

如果勾选该选项，网格划分器将尝试构建仅含四边形的网格。然而在某些条件下，网格划分器可能无法生成四边形网格（例如每个块体周长上的网格单元数为奇数）；此时将显示错误。

目标网格单元尺寸

该参数指定块体内部所需的网格单元尺寸（目标尺寸）f ≥ 0。默认值为 0。

目标尺寸是包围四边形或三角形网格单元的圆的半径。随着远离块体边界，网格单元尺寸趋于该值。目标网格单元尺寸可小于或大于在块体边上指定的默认网格单元尺寸。

最大渐变率

该参数为非结构化网格划分器指定最大渐变率 f > 0。默认值为 0.5。

该参数控制网格单元尺寸从块体边界上指定的尺寸到块体内部由目标网格单元尺寸定义的尺寸之间的渐变。取值接近 0 时，网格单元尺寸的变化更平缓（更光滑）。

高级参数

优化级别

该参数为非结构化网格划分器指定优化级别 0 ≤ i ≤ 10。默认值为 5。

取值为零时网格划分器跳过优化步骤，速度最快但质量可能较差。从取值 1 开始，优化算法使用多种技术来同时改善网格单元的形状质量和尺寸质量。级别 5 通常是质量与速度之间的良好折中。

形状质量权重

该参数为非结构化网格划分器指定形状质量值 0 ≤ f ≤ 1。默认值为 0.7。

该参数控制形状优化与尺寸优化之间的折中。它是网格单元整体质量度量中形状质量的权重。默认值（0.7）略微偏重形状质量而非尺寸质量。

四边形权重

该参数为非结构化网格划分器指定四边形权重 0 ≤ f ≤ 1。默认值为 0.75。该参数不用于仅含四边形的非结构化网格。

该参数控制四边形比例较高与网格质量更好（三角形更多）之间的折中：

  • 当 f = 0 时，从不使用四边形，
  • 当 f = 0.5 时，仅当四边形能改善网格质量（即四边形优于两个三角形）时才使用四边形，
  • 当 0.5 < f < 1 时，四边形使用得越来越多，即使这会降低网格的整体质量，
  • 当 f = 1 时，使用最少数量的三角形以获得有效网格（质量可能较差）。

默认值（0.75）明显更偏重四边形/三角形比例而非网格质量。
