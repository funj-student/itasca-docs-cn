边工具

由背景几何创建边

导入挤出器集合的几何数据文件（例如 DXF、GEOM、STL 文件）包含描述几何的数值信息。利用这些信息可创建与背景几何一致的挤出器边。这可以按 背景图像 / 几何数据（Background Images / Geometric Data） 中所述手动完成，也可以通过单击“自动创建边”按钮（）自动完成。使用后一种选项时，将为背景几何中发现的每条边创建挤出器边。

仅在存在背景几何时才能自动创建边。

由背景几何创建边时，即使默认边参数设置为超过 1000 个网格单元，为边设置的最大网格单元数仍为 1000。这样做是为了加快数据处理并避免不必要的内存消耗。如果任何自动创建的边上的网格单元数被减少到 1000，将显示一条警告消息。此后可在 对象属性（Object Properties） 对话框中单独更改每条边的网格单元数，或使用 自动网格划分（Automatic Zoning） 更改所有边的网格单元数。

请注意，背景几何中的曲线边由若干直线段表示，挤出器边沿这些直线段创建。这些边随后可按下文所述合并为单条曲线边。

按转折角选择边

要一次选择若干相连的边，请单击“按转折角选择边”按钮（）并单击某条边。只要相邻两条边之间的夹角小于指定的转折角，与它相连的所有边都将被选中。如果某条边在任何一侧连接了不止一条其他边，选择也会停止。

边选择模式将保持活动，直到用户再次单击“按转折角选择边”按钮（）将其停用。

可将鼠标光标置于该数值上并滚动鼠标滚轮或按上、下按钮来指定转折角。

合并边

选择若干相连的边之后（手动选择或使用“按转折角选择边”工具），可将这些边合并为单条曲线边（由三次 Hermite 样条表示）。该操作通过单击“合并所选边”按钮（）完成。所选边将被一条曲线边替代，该边可包含多个控制点（用于指定局部曲率）。

要调整新曲线边与原始边的接近程度，请调整合并边的容差（单击附近的 按钮）。该容差影响新边上的控制点数量，从而影响局部曲率。容差越小，新边越接近原始几何，但控制点可能很多。

仅在选中两条或更多边时才能合并边。
